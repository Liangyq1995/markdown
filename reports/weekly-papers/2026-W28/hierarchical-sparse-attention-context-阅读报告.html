1. 概述

将大语言模型（LLM）扩展到长上下文受限于全注意力的二次复杂度、外推能力差、以及随上下文增长的 KV cache 成本。分块稀疏注意力（chunk-wise sparse attention）通过只对相关 chunk 做 attention 来保持常数计算预算，但所有现有方法都因chunk 选择不准确而无法达到全注意力水平。

本文指出这一问题的根源在于两点：(1) 非参数 chunk 摘要（如 mean-pooling）表达能力不足；(2) chunk 选择过程没有接受 LM loss 的端到端优化——分数选出 top-K 后就被丢弃，梯度无法回传到摘要或打分上。

为此，作者提出 HiLS-Attention（Hierarchical Landmark Sparse Attention），其两大设计为：

  • 可学习的 chunk mass 替代物：在每个 chunk 末尾追加一个 landmark token，以其 query 派生 chunk 摘要 key；该打分操作是全注意力诱导 chunk mass 的一阶 Taylor 展开，从而具备充分表达能力。
  • 层次化 softmax 因式分解：将注意力质量先在 chunk 之间分配（inter-chunk），再在每个 chunk 内 token 之间分配（intra-chunk）。由于替代物分数直接参与前向 attention 权重，LM loss 的梯度可直接监督 landmark 表征学习，实现原生稀疏训练。

实验上，HiLS-Attention 在 345M–7B 多个尺度上：域内长度性能与全注意力相当甚至更好；345M 模型仅以 8K 训练长度即可外推到 4M（512×）且保持 NIAH 90%+ 准确率；7B 全注意力模型仅需 50B token 续训即可转换为 HiLS 并显著超越 YaRN 外推基线；推理上 512K 长度 prefill/decode 分别加速 13.5×/15.7×。

2. 研究背景与动机

2.1 分块稀疏注意力的范式与瓶颈

分块稀疏注意力将序列划分为不重叠、大小为 $S$ 的 chunk，每个 query token 同时关注：(a) 一个局部滑动窗口（local sliding window, SWA）；(b) 全局检索到的 $K$ 个最相关远距离 chunk。这样可在常数计算预算下建模长上下文，并按需将 KV cache 换入快内存。

但论文 Fig. 2 的 in-context retrieval 实验显示：在参数受限（345M、8K 训练）的小模型上，现有稀疏方法（NSA、DashAttention、InfLLM v2）在 8K 域内 RULER 上与全注意力存在显著 retrieval gap。作者认为，chunk 选择不准是核心症结，而它又源于弱摘要与缺乏端到端优化。

2.2 从 Naive Block Sparse Attention 出发

作者以一个朴素基线 Naive BSA（Block Sparse Attention） 为出发点：先计算完整 attention，在每个 chunk 内汇总 token 级注意力质量，选 top-K chunk。Naive BSA 虽无计算节省，但能得到一个"由全注意力导出"的 chunk 选择模式（ground-truth pattern）。HiLS 的目标即是用一个可学习、可稀疏计算的机制去逼近这一模式，并进一步超过它。

3. 预备：Naive BSA 的形式化

给定输入序列 $x=\{x_1,\dots,x_N\}$，划分为大小 $S$ 的不重叠 chunk，第 $j$ 个 token 属于第 $c(j)=\lfloor j/S \rfloor$ 个 chunk。BSA 中 query 同时关注局部滑动窗口与 $K$ 个全局检索的远距离 chunk。为避免局部窗口与检索 chunk 重叠，将窗口左边界对齐到 chunk 边界：

$$\ell(i)=\left\lfloor \frac{i-W+1}{S} \right\rfloor S$$

其中 $W$ 为窗口大小。于是位置 $i$ 的可检索历史 chunk 索引集为 $C_i=\{0,1,\dots,\ell(i)/S - 1\}$。记 $q_i,k_j,v_j\in\mathbb{R}^d$ 为标准 query/key/value，token-to-token 注意力 logit 为 $s_{i,j}=q_i^\top k_j / \sqrt{d}$。全注意力下定义 chunk mass 为 token 级指数化 logit 之和：

$$Z_{i,\text{swa}}=\sum_{j=\ell(i)}^{i}\exp(s_{i,j}), \qquad Z_{i,c}=\sum_{j\in T_c}\exp(s_{i,j}) \tag{1}$$

由于按归一化注意力质量选 chunk 等价于按 $Z_{i,c}$ 选，naive BSA 选择 top-K：

$$I_i=\{c\in C_i \mid \mathrm{rank}_\downarrow(Z_{i,c}) \lt K\} \tag{2}$$

query 仅对被选中的 token（选中 chunk 的 token + 局部窗口）做注意力：

$$Z_i=\sum_{c\in I_i} Z_{i,c}+Z_{i,\text{swa}}, \quad w_{i,j}=\begin{cases}\exp(s_{i,j})/Z_i, & j \text{ 被选中}\\ 0, & \text{否则}\end{cases}, \quad o_i=\sum_{j\le i} w_{i,j} v_j \tag{3}$$

3.1 现有方法的表现力局限

naive BSA 给出精确 chunk 选择，但计算精确 $Z_{i,c}$ 需评估 chunk 内所有 token 级 logit，训练时无稀疏收益。理想情况下，若能构造 chunk 级摘要 key $k'_c$ 使得：

$$\exp\!\left(\frac{q_i^\top k'_c}{\sqrt{d}}\right) \approx Z_{i,c}=\sum_{j\in T_c}\exp(s_{i,j}) \iff \frac{q_i^\top k'_c}{\sqrt{d}} \approx \log Z_{i,c} \tag{4}$$

则可仅用 chunk 级表征高效选择。但目标 $\log Z_{i,c}$ 是一个 LogSumExp 函数，其行为取决于 chunk 内 logit 分布：

$$\log Z_{i,c}=\log\sum_{j\in T_c}\exp(s_{i,j}) \approx \begin{cases}\mathrm{mean}_{j\in T_c}(s_{i,j})+\log S, & \text{logit 近似均匀}\\ \max_{j\in T_c}(s_{i,j}), & \text{单个 logit 占主导}\end{cases} \tag{5}$$

多数方法用 mean-pooled key 作摘要（$k'_c=\frac{1}{S}\sum_{j\in T_c}k_j$），此时：

$$\frac{q_i^\top k'_c}{\sqrt{d}}=\frac{1}{S}\sum_{j\in T_c}\frac{q_i^\top k_j}{\sqrt{d}}=\mathrm{mean}_{j\in T_c}(s_{i,j}) \tag{6}$$

即 chunk 分数退化为 token 级 logit 的均值。这揭示了一个根本局限：均值仅在 logit 近似均匀时有效，max 仅在单 token 主导时有效。由于 logit 分布随 query、head、数据变化，mean 与 max 都无法稳定忠实地表示 chunk mass，从而错排 chunk、漏掉重要 chunk——这正是 NIAH 等任务退化的原因（NIAH 中只有少数 needle token 主导，mean 会将其稀释）。

4. 核心方法：HiLS-Attention

基于上述分析，作者用从可学习 chunk 摘要计算得到的替代物 $\hat{Z}_{i,c}$ 替换非参数摘要，并提出两个研究问题：

  • RQ1：能否仅用 query $q_i$ 与一个紧凑 chunk 摘要的交互，以可处理形式近似 LogSumExp chunk mass $\log Z_{i,c}$？
  • RQ2：如何端到端学习 $\hat{Z}_{i,c}$，使 chunk 选择与 LM loss 联合优化？

4.1 RQ1：chunk mass 的线性替代物（Proposition 3.1）

为找到 LogSumExp chunk mass 的可处理替代物，作者考察其一阶 Taylor 展开，揭示出 chunk 级打分的仿射结构：

Proposition 3.1（LogSumExp 线性化）：对任意 chunk $c$，query-key logit 的 LogSumExp 可线性化为：

$$\log\sum_{j\in T_c}\exp\!\left(\frac{q^\top k_j}{\sqrt{d}}\right) \approx \underbrace{\frac{q^\top k'_c}{\sqrt{d}} + b'_c}_{\text{surrogate score}} \tag{7}$$

其中 $k'_c$ 与 $b'_c$ 由一个可学习 query $q'_c$ 在 chunk $c$ 的 key 上诱导；记 chunk 内 key 拼接为 $K_c\in\mathbb{R}^{S\times d}$，有：

$$s_j=\frac{(q'_c)^\top k_j}{\sqrt{d}},\quad p_j=\frac{\exp(s_j)}{\sum_{k\in T_c}\exp(s_k)},\quad k'_c=\sum_{j\in T_c} p_j k_j,\quad b'_c=-\sum_{j\in T_c} p_j\log p_j \tag{8}$$

这里 $k'_c=\mathrm{Attn}(q'_c,K_c,K_c)$ 是 chunk 内注意力对 key 的加权求和，$b'_c$ 是该注意力分布的熵。推导要点（详见原文 Appendix B）：对 $f(q)=\log\sum_{j=1}^{S}\exp(q^\top K_j)$ 在 $q_c$ 处做一阶 Taylor 展开 $f(q)\approx f(q_c)+\nabla f(q_c)^\top(q-q_c)$，其梯度为：

$$\nabla f(q_c)=\frac{\sum_{j=1}^{S}\exp(q_c^\top K_j)\,K_j}{\sum_{j=1}^{S}\exp(q_c^\top K_j)}=\sum_{j=1}^{S}p_j K_j = k'_c \tag{9}$$

将 $q_c^\top K_j=\log p_j+\log\sum_{k}\exp(q_c^\top K_k)$ 代回并消去常数项，偏置恰化为熵的负值 $b'_c=-\sum_j p_j\log p_j$，最终得到式 (7)。每个 chunk 的计算成本为 $O(S)$，对长度 $N$（$N/S$ 个 chunk）总成本为 $O(N)$。

熵偏置的直观意义：$b'_c$ 自适应地在式 (5) 的两种 regime 间插值——logit 近似均匀时趋近 $\log S$，单 logit 主导时趋近 $0$。因此 surrogate 同时覆盖了 mean 与 max 两种情形，表达能力远超 mean-pooling。

实例化 $q'_c$：在每个 chunk 末尾追加一个特殊 landmark token，用其 query 向量作为 $q'_c$。得到的 $(k'_c, b'_c)$ 作为"熵校准的压缩 key"用于 chunk 级路由：按式 (7) 线性 surrogate 打分、选 top-K、估计配分函数：

$$\hat{s}_{i,c}=\frac{q_i^\top k'_c}{\sqrt{d}}+b'_c,\quad I_i=\{c\in C_i\mid \mathrm{rank}_\downarrow(\hat{s}_{i,c})\lt K\},\quad \hat{Z}_{i,c}=\exp(\hat{s}_{i,c}),\quad \hat{Z}_i=\sum_{c\in I_i}\hat{Z}_{i,c}+Z_{i,\text{swa}} \tag{10}$$

这构成了原生稀疏训练实现：每个 query 在所有 $N/S$ 个 chunk 摘要上路由、保留 top-K、仅对常数个选中 token 做 attention。唯一二次项是路由成本：每 token $O(N/S)$、每序列 $O(N^2/S)$。

4.2 RQ2：层次化 softmax 实现端到端学习

为让 $q'_c$ 可学习，核心思路是让 $\hat{Z}_{i,c}$ 参与注意力质量的前向计算。作者将注意力质量因式分解为chunk 内归一化项与chunk 间质量项，后者用可学习 surrogate 替换。对选中 chunk 与局部窗口内的 token，其归一化注意力权重可重写为：

$$w_{i,j}=\frac{\exp(s_{i,j})}{Z_i}=\underbrace{\frac{\exp(s_{i,j})}{Z_{i,c(j)}}}_{\text{intra-chunk}}\times\underbrace{\frac{Z_{i,c(j)}}{Z_i}}_{\text{inter-chunk}} \approx \frac{\exp(s_{i,j})}{Z_{i,c(j)}}\times\underbrace{\frac{\hat{Z}_{i,c(j)}}{\hat{Z}_i}}_{\text{surrogate}} \tag{11}$$

其中当 $\ell(i)\le j\le i$ 时 $\hat{Z}_{i,c(j)}=Z_{i,\text{swa}}$。直观上，模型先在每个选中 chunk 内聚合相关信息，再按学习到的 surrogate 质量融合 chunk 级信息。由于 $\hat{Z}_{i,c}$ 影响最终注意力权重，LM loss 的梯度可直接监督 landmark 表征学习，鼓励对预测更有用的 chunk 获得更大质量、抑制无关 chunk。作者指出，这种自监督 surrogate 甚至超过 naive BSA（见实验），说明端到端学习提供了比全注意力模式更有效的注意力分配。

4.4 算法伪代码

Algorithm 1: HiLS-Attention 前向（单层、MHA）

Input: 序列 x（已切分为大小 S 的 chunk，每 chunk 末尾含 landmark token）；超参 K（top-K）、窗口 W

// 1) Chunk 压缩：用 landmark query 诱导摘要

for 每个历史 chunk c: do

s_j = dot(q'_c, k_j) / √d, p_j = softmax(s_j) // j ∈ chunk c

k'_c = Σ p_j·k_j // 压缩 key = Attn(q'_c, K_c, K_c)

b'_c = − Σ p_j·log p_j // 熵偏置

// 2) Query 校正（低秩 Q-Cal）

Δq_i = W_up·W_down·h_i, q̂_i = q_i + Δq_i

// 3) Chunk 级 surrogate 打分 + top-K 路由

ŝ_{i,c} = dot(q̂_i, k'_c)/√d + b'_c

I_i = topK(ŝ_{i,c}, K) // 选 K 个远距离 chunk

Ẑ_{i,c} = exp(ŝ_{i,c}), Z_{i,swa} = Σ_{j=ℓ(i)}^{i} exp(s_{i,j})

Ẑ_i = Σ_{c∈I_i} Ẑ_{i,c} + Z_{i,swa}

// 4) 层次化融合：inter-chunk × intra-chunk

for 每个选中 token j: do

w_{i,j} = ( exp(s_{i,j}) / Z_{i,c(j)}} ) × ( Ẑ_{i,c(j)}} / Ẑ_i )

o_i = Σ w_{i,j}·v_j

return o_i // LM loss 梯度经 Ẑ 回传到 k'_c, b'_c, q'_c

5. 实用设计选择

5.1 架构设计

沿用 Qwen3 等主流开源 Transformer 架构，仅将标准全注意力替换为 HiLS。三项关键调整：

  • 位置编码（HoPE）：8K 训练时标准 RoPE 下 HiLS 的 PPL 劣于全注意力；改用 HoPE——保留旋转周期不超过训练长度的 RoPE 维，其余维度用 NoPE（不加位置编码）替换——使 HiLS 在 PPL 上反超全注意力。机制上：chunk 压缩对 key 做加权聚合，若对所有维度施加 RoPE 会聚合不同的位置旋转、扭曲语义；NoPE 维提供位置无关的语义子空间，利于 chunk 语义保持与外推。
  • 低秩 Query 校正（Q-Cal）：由于 $k'_c$ 是多 token 的压缩摘要而非 token key，原始 token 级 query $q_i$ 估计 chunk 级质量并非最优。引入轻量低秩校正：$\Delta q_i=W_{\text{up}}W_{\text{down}}h_i$，$\hat{q}_i=q_i+\Delta q_i$，其中 $W_{\text{up}}\in\mathbb{R}^{d\times r}$、$W_{\text{down}}\in\mathbb{R}^{r\times d_{\text{model}}}$，$r\ll d_{\text{model}}$。该模块显著改善 PPL 与外推。
  • GQA 适配：现代 LLM 常用 GQA（多 query head 共享 KV head）。同组 query head 应使用相同检索 chunk 集以便 gather 一次、批量 attention。但同组 head 可能关注不同 chunk。HiLS 对每个 query head 分别计算归一化 chunk 权重，再在组内取 max 聚合，按组级分数选 top-K——任一 head 重要的 chunk 都会被选中，兼顾共享检索与 head 级灵活性（完整形式见原文 Appendix C）。
  • 无 landmark 替代方案：为降低 landmark token 的工程开销，可用每层共享的可学习 query 替代 per-chunk landmark。该方案域内性能相当，但外推能力显著退化。

5.2 硬件高效 kernel 设计

稀疏注意力的实现挑战：不同 token 对应不同 chunk 集，朴素实现无法加速甚至内存爆炸。NSA 的 kernel 设计（Fig. 4a）每次处理一个 query token、加载其选中 K/V chunk，Tensor Core 计算形状为 $(G, d)\times(d, S)$（$G$ 为 GQA 组内 query head 数）。由于 Tensor Core 在 tile 维 $\ge 16$ 时最高效，MHA（$G=1$）会严重欠利用、需将 query-head 维从 1 padding 到 16。NSA 靠 $G\ge 16$ 缓解，但这隐式要求 query-to-KV head 比 $\ge 16$，限制适用性。

HiLS kernel（Fig. 4b）跨 query token 与 query head 批处理：相邻 query token 检索的 chunk 高度重叠（重叠率高达 80%），故将 $M$ 个相邻 query token 分组、对其选中 chunk 的并集做 attention，Tensor Core 计算变为 $(M\times G, d)\times(d, S)$，只需 $M\times G\ge 16$ 而非 $G\ge 16$。取并集还让打包 query 复用已加载 K/V chunk、减少冗余内存访问。该设计不依赖大 GQA 组、也可用于 speculative decoding。

5.3 续训策略

为保留原模型能力，评估两种续训策略：

  • Landmark Token Tuning（近 training-free）：冻结所有 base 参数，仅训练新引入的 landmark token embedding 与 $W_{\text{up}},W_{\text{down}}$ 投影（< 1% 参数）。≤ 5B token 即可达与 base 相当的性能。
  • Full-Parameter Tuning：landmark embedding 与低秩 adapter 随机初始化，其余参数继承自 base，全部联合更新。配合 HoPE 替换位置编码时效果最佳，最大化长度泛化。

6. 小尺度实验（345M）

6.1 实验设置

8. 分析

8.1 推理效率（Fig. 6）

在 SGLang 引擎、单张 NVIDIA H800、batch=1、bf16 下端到端测延迟（345M 架构，chunk 64、top-K 32、512 窗口）。HiLS 成本由固定检索预算（K×chunk=2048 token）+ 局部窗口决定，与全上下文长度无关：prefill 近线性增长、decode 每 token 近 $O(1)$。两方法在约 16K 处交叉，512K 时 HiLS prefill 5.0s vs 67.0s（13.5×）、decode 5.5ms vs 85.9ms（15.7×）。

下方为各长度的加速比（Full / HiLS，>1 表示 HiLS 更快）：8K 时 HiLS 略慢（prefill 0.62×、decode 0.73×，检索尚未摊销），16K 起反超并随长度迅速拉开差距。

8.2 相邻 query 的 chunk 重叠（Fig. 7）

验证 HiLS kernel 的关键假设：相邻 query 检索的 chunk 高度重叠。对 $M$ 个相邻 query，定义归一化重叠率：

$$\mathrm{Overlap}=\frac{MK-\left|\bigcup_{m=1}^{M} I_m\right|}{(M-1)K} \tag{12}$$

在 Olmo3-7B 续训 checkpoint 上（chunk 64、top-K 32）：最后 $M=16$ 个 query 的可见历史 chunk 池从 4K 时的 57 个增长到 64K 时的 1032 个，但加载的并集仅从 43.6 增长到 102.1，加载占比从 76.4% 降到 9.9%；且平均 92.8% 的 chunk 已出现在上一 query 块中——强力支持相邻 query 打包与 one-load-multiple-compute 策略。

9. 消融实验与关键发现

消融在 345M、8K 训练上进行（Table 5–7），考察 Q-Cal、Proposition 3.1、landmark token、位置编码等组件。主要发现：

消融变体说明关键影响
w/ Q-Cal (r=64)低秩 query 校正（默认）默认配置，PPL 与外推最佳
w/ Q-Cal (r=128)增大秩反而损害长度外推

关键发现：
  • landmark token 不可或缺：共享 query 表达力有限，无法捕捉多样 chunk 语义；landmark query 由完整 Transformer 计算（含 attention + MLP）产生，能自适应编码每个 chunk，是超长外推的关键。
  • Q-Cal 的机制仍未完全理解：作者推测 Δq 将 token 级 attention 与 chunk 级 mass surrogate 解耦（二者信息层次不同），但强调"底层机制尚未完全理解，留待未来工作"。
  • 压缩增强 in-context retrieval：HiLS 在 Variable Tracking（多跳推理）上甚至超过全注意力。作者给出分解 $k_i=\text{semantic}(k_i)+\text{noise}(k_i)$：压缩聚合多 key 时，互不对齐的噪声项部分相消、共享语义信号保留，得到更干净的检索表征。这解释了为何 HiLS 的强外推源于更强的域内检索能力。
  • HiLS 学到比 naive BSA 更鲁棒的分配：全注意力中只要 logit 非 −∞ 即获非零质量，无关 token 注入小噪声，长上下文下噪声累积使 BSA 的选择信号变噪；端到端学习的 HiLS 反而更有效。

10. 总结与启发

HiLS-Attention 通过"可学习 chunk 摘要 + 层次化 softmax 因式分解"，将检索分数融入前向 attention 计算，使 chunk 选择首次接受 LM loss 的端到端优化。其理论基础（Proposition 3.1）将 LogSumExp chunk mass 一阶线性化为"相关性项 + 熵偏置"，熵偏置自适应插值 mean/max 两种 regime，从根本上修复了 mean-pooling 的表达力缺陷。

面向无限上下文：HiLS 的原生稀疏性使训练时注意力成本有界——chunk 压缩为 $O(L)$、每 token 检索 $O(L/S)$、token 级 attention 限于选中 chunk 与窗口 $O(LKS)$，唯一超线性项是检索，可用 FAISS 等近似最近邻搜索降至约 $O(L\log(L/S))$。配合强长度外推（短上下文学到的检索模式可泛化到超长上下文），使无限上下文训练在工程上变得可行。

读后启发：

  • 端到端是关键：长久以来稀疏注意力的瓶颈不在稀疏本身，而在"选择"这一离散决策脱离了 loss 优化。HiLS 用层次化 softmax 让选择分数参与前向、梯度直达摘要，是把"检索"内化为可微前向计算的优雅范例。
  • 压缩即去噪：压缩不只是省算力，更是归纳偏置——它让 token 级噪声相消、语义信号保留。这为"为何压缩后检索更强"提供了清晰解释，也提示未来可设计更强的压缩算子。
  • 位置编码与稀疏耦合：RoPE 在 chunk 压缩时聚合不同旋转会扭曲语义，HoPE 的 NoPE 维提供位置无关语义子空间。说明长上下文建模中位置编码需与注意力稀疏化协同设计。
  • 工程可行性强：仅 50B token、<1% 参数即可将现成全注意力大模型转为 HiLS，且推理 512K 加速 13–15×——对工业部署极具吸引力。

10.1 局限性

  • HiLS-Attention 尚不支持 context parallelism，在更大训练上下文长度上的有效性有待验证。
  • 未被选中的 chunk 不接受梯度更新。
  • Q-Cal 改善外推与域内性能的底层机制尚未完全理解。
