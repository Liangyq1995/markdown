TRPO 深度阅读报告

两版本错误对比 · 正确推导重建 · 2026-05-13

标题Trust Region Policy Optimization (TRPO)
核心问题如何为策略梯度方法提供单调改进保证，同时允许足够大的步长？
版本对比v3（2015-06-08，原始投稿）vs v5（2017-04-20，最终发表版）
主要错误v3 以"代价最小化"框架撰写，符号约定与标准 RL 相反，并导致若干关键不等式方向错误

1. 核心问题与动机

策略梯度方法在每次迭代中更新参数 $\theta$，但步长难以确定：步长过小收敛慢，步长过大则可能导致性能灾难性下降。TRPO 的目标是回答：

能否找到一个代理目标函数，使得最大化它可以保证真实目标也在改进，同时允许非平凡（non-trivial）步长？

论文的核心贡献是：通过 KL 散度约束构建信任域，将策略更新转化为约束优化，从理论上保证单调改进。

2. v3 与 v5 的根本框架差异

这是理解所有具体错误的前提。两个版本使用了完全相反的优化方向：

❌ v3（有问题）

以代价函数（cost）为基础

  • $\eta(\pi)$ = 期望折扣代价（越小越好）
  • 目标：minimize $L_{\theta_\text{old}}(\theta)$
  • 改进 = 代价减小 = $\eta(\pi_\text{new}) \leq \eta(\pi_\text{old})$
  • Kakade-Langford 界：$\eta(\tilde{\pi}) \leq L_\pi(\tilde{\pi}) + C \cdot D_\text{KL}^\text{max}$
✅ v5（正确）

以奖励函数（reward）为基础

  • $\eta(\pi)$ = 期望折扣回报（越大越好）
  • 目标：maximize $L_{\theta_\text{old}}(\theta)$
  • 改进 = 回报增加 = $\eta(\pi_\text{new}) \geq \eta(\pi_\text{old})$
  • Kakade-Langford 界：$\eta(\tilde{\pi}) \geq L_\pi(\tilde{\pi}) - C \cdot D_\text{KL}^\text{max}$
v3 是 ICML 2015 的初始投稿版本，采用了"代价最小化"的写法，这在控制理论文献中常见，但与强化学习的标准符号惯例（reward 最大化）相反。v5（最终发表版）已将全文统一为奖励最大化框架。

3. 具体错误逐条分析

3.1 错误一：Kakade-Langford 界的不等号方向

核心 Bug
v3 错误写法（代价框架）
$$\eta(\pi_\text{new}) \leq L_{\pi_\text{old}}(\pi_\text{new}) + \frac{2\epsilon\gamma}{(1-\gamma)^2}\alpha^2$$ 其中 $\epsilon = \max_s |\mathbb{E}_{a\sim\pi'}[A_\pi(s,a)]|$

代价上界：真实代价 ≤ 代理代价 + 惩罚项

minimize 代理代价 → 真实代价不增

v5 正确写法（奖励框架）
$$\eta(\pi_\text{new}) \geq L_{\pi_\text{old}}(\pi_\text{new}) - \frac{4\epsilon\gamma}{(1-\gamma)^2}\alpha^2$$ 其中 $\epsilon = \max_{s,a} |A_\pi(s,a)|$

回报下界：真实回报 ≥ 代理回报 − 惩罚项

maximize 代理回报 → 真实回报不降

注意除不等号方向外还有两处数值差异：

  • 系数：v3 中为 $2\epsilon\gamma$，v5 修正为 $\mathbf{4\epsilon\gamma}$（来自耦合证明中两次 $2\alpha\epsilon$ 的累计）
  • $\epsilon$ 的定义：v3 对 $s$ 取 max 后再对 $a$ 取期望（更弱），v5 直接对 $(s,a)$ 联合取 max（更紧更自然）

3.2 错误二：KL 散度约束的符号

符号错误
v3 — 代价最小化
$$\eta(\tilde{\pi}) \leq L_\pi(\tilde{\pi}) + C \cdot D_\text{KL}^\text{max}(\pi, \tilde{\pi})$$ $$C = \frac{2\epsilon\gamma}{(1-\gamma)^2}$$ 对应 Algorithm 1： $$\pi_{i+1} = \arg\min_\pi \left[ L_{\pi_i}(\pi) + C \cdot D_\text{KL}^\text{max}(\pi_i, \pi) \right]$$
v5 — 回报最大化
$$\eta(\tilde{\pi}) \geq L_\pi(\tilde{\pi}) - C \cdot D_\text{KL}^\text{max}(\pi, \tilde{\pi})$$ $$C = \frac{4\epsilon\gamma}{(1-\gamma)^2}$$ 对应 Algorithm 1： $$\pi_{i+1} = \arg\max_\pi \left[ L_{\pi_i}(\pi) - C \cdot D_\text{KL}^\text{max}(\pi_i, \pi) \right]$$

3.3 错误三：单调性证明方向

逻辑方向
v3（代价最小化）

令 $M_i(\pi) = L_{\pi_i}(\pi) + C \cdot D_\text{KL}^\text{max}(\pi_i, \pi)$

由于 $\eta(\pi_{i+1}) \leq M_i(\pi_{i+1})$，最小化 $M_i$ 可保证：

$$\eta(\pi_0) \geq \eta(\pi_1) \geq \eta(\pi_2) \geq \cdots$$

非递增序列（代价减小）

v5（回报最大化）

令 $M_i(\pi) = L_{\pi_i}(\pi) - C \cdot D_\text{KL}^\text{max}(\pi_i, \pi)$

由于 $\eta(\pi_{i+1}) \geq M_i(\pi_{i+1})$，最大化 $M_i$ 可保证：

$$\eta(\pi_0) \leq \eta(\pi_1) \leq \eta(\pi_2) \leq \cdots$$

非递减序列（回报增加）

3.4 错误四：MM 算法类型的命名

术语错误
版本命名是否正确说明
v3 majorization-minimization (MM) 错误 v3 确实在最小化代价，majorization-minimization 是对的，但整体框架用了代价而不是奖励
v5 minorization-maximization (MM) 正确 $M_i$ 是 $\eta$ 的 minorizer（下界），最大化 minorizer 保证真实目标不下降

3.5 错误五：附录 C 搜索方向的符号

实现级错误
v3 附录 C — 求解搜索方向

求解线性系统：

$$Ax = -g \quad \Rightarrow \quad s \approx -A^{-1}g$$

这是梯度下降方向（最小化），符合 v3 的代价最小化框架

v5 附录 C — 求解搜索方向

求解线性系统：

$$Ax = g \quad \Rightarrow \quad s \approx A^{-1}g$$

这是梯度上升方向（最大化），符合 v5 的回报最大化框架

参数更新：$\theta_\text{new} = \theta_\text{old} + \frac{1}{\lambda} A^{-1}\nabla L$

3.6 错误六：Perturbation Theory 附录中的系数

数值错误

在 v3 附录 B 的扰动理论证明中，对 $\|G\Delta\tilde{G}\rho\|_1$ 的界有差异：

v3 — $\|\Delta\|_1 = \alpha$（错误）
$$\|G\Delta\tilde{G}\rho\|_1 \leq \|G\|_1 \cdot \|\Delta\|_1 \cdot \|\tilde{G}\|_1 \cdot \|\rho\|_1 = \frac{1}{1-\gamma} \cdot \alpha \cdot \frac{1}{1-\gamma} \cdot 1$$

TV 散度为 $\alpha$ 时，$\|\Delta\|_1 = \|\tilde{P}-P\|_1 \leq \alpha$ 是错误的

v5 — $\|\Delta\|_1 = 2\alpha$（正确）
$$\|G\Delta\tilde{G}\rho\|_1 \leq \frac{1}{1-\gamma} \cdot 2\alpha \cdot \frac{1}{1-\gamma} \cdot 1 = \frac{2\alpha}{(1-\gamma)^2}$$

TV 散度 $D_\text{TV}(p\|q) = \frac{1}{2}\sum_i|p_i - q_i|$，故 $\|\Delta\|_1 = \sum_a|\tilde{\pi}(a|s)-\pi(a|s)| = 2D_\text{TV} = 2\alpha$

正是这个系数 $\alpha$ vs $2\alpha$ 的差异，导致最终边界中系数从 $2$ 变为 $4$：

$$\gamma^2 |rG\Delta G\Delta\tilde{G}\rho| \leq \gamma \cdot 2\alpha\epsilon \cdot \frac{2\alpha}{(1-\gamma)^2} = \frac{4\gamma\epsilon\alpha^2}{(1-\gamma)^2}$$

4. 正确的 TRPO 算法完整推导（基于 v5）

4.1 基础设定

考虑无限时域折扣 MDP $(\mathcal{S}, \mathcal{A}, P, r, \rho_0, \gamma)$，定义：

$$\eta(\pi) = \mathbb{E}_{s_0, a_0, \ldots}\left[\sum_{t=0}^\infty \gamma^t r(s_t)\right], \quad s_0\sim\rho_0,\ a_t\sim\pi(\cdot|s_t),\ s_{t+1}\sim P(\cdot|s_t,a_t)$$ $$Q^\pi(s_t, a_t) = \mathbb{E}_{s_{t+1}, a_{t+1},\ldots}\left[\sum_{l=0}^\infty \gamma^l r(s_{t+l})\right]$$ $$V^\pi(s_t) = \mathbb{E}_{a_t, s_{t+1},\ldots}\left[\sum_{l=0}^\infty \gamma^l r(s_{t+l})\right]$$ $$A^\pi(s, a) = Q^\pi(s, a) - V^\pi(s)$$

折扣状态访问频率（未归一化）：

$$\rho_\pi(s) = P(s_0=s) + \gamma P(s_1=s) + \gamma^2 P(s_2=s) + \cdots$$

4.2 关键恒等式（Lemma 1）

这是整个 TRPO 理论的起点，由 Kakade & Langford (2002) 首先证明：

$$\eta(\tilde{\pi}) = \eta(\pi) + \mathbb{E}_{\tau \sim \tilde{\pi}}\left[\sum_{t=0}^\infty \gamma^t A^\pi(s_t, a_t)\right] \tag{1}$$

证明： 注意 $A^\pi(s,a) = \mathbb{E}_{s'\sim P(\cdot|s,a)}[r(s) + \gamma V^\pi(s') - V^\pi(s)]$，因此：

$$\mathbb{E}_{\tau|\tilde{\pi}}\left[\sum_{t=0}^\infty \gamma^t A^\pi(s_t, a_t)\right] = \mathbb{E}_{\tau|\tilde{\pi}}\left[\sum_{t=0}^\infty \gamma^t (r(s_t) + \gamma V^\pi(s_{t+1}) - V^\pi(s_t))\right]$$ $$= \mathbb{E}_{\tau|\tilde{\pi}}\left[-V^\pi(s_0) + \sum_{t=0}^\infty \gamma^t r(s_t)\right] = -\eta(\pi) + \eta(\tilde{\pi})$$

用状态访问频率改写式 (1)：

$$\eta(\tilde{\pi}) = \eta(\pi) + \sum_s \rho_{\tilde{\pi}}(s) \sum_a \tilde{\pi}(a|s) A^\pi(s,a) \tag{2}$$

4.3 代理目标函数 $L_\pi$

式 (2) 难以优化，因为 $\rho_{\tilde{\pi}}(s)$ 依赖于 $\tilde{\pi}$。用旧策略的访问频率 $\rho_\pi(s)$ 替换：

$$L_\pi(\tilde{\pi}) = \eta(\pi) + \sum_s \rho_\pi(s) \sum_a \tilde{\pi}(a|s) A^\pi(s,a) \tag{3}$$

可以验证 $L_\pi$ 与 $\eta$ 在当前策略处一阶相等：

$$L_{\pi_{\theta_0}}(\pi_{\theta_0}) = \eta(\pi_{\theta_0})$$ $$\nabla_\theta L_{\pi_{\theta_0}}(\pi_\theta)\big|_{\theta=\theta_0} = \nabla_\theta \eta(\pi_\theta)\big|_{\theta=\theta_0} \tag{4}$$

这意味着在当前策略附近，$L_\pi$ 是 $\eta$ 的一阶近似，但它忽略了策略改变对状态分布的影响（二阶效应）。

4.4 单调改进保证（Theorem 1）

TRPO 的核心定理：

Theorem 1（v5 正确版本）

令 $\alpha = D_\text{TV}^\text{max}(\pi_\text{old}, \pi_\text{new}) = \max_s D_\text{TV}(\pi_\text{old}(\cdot|s) \| \pi_\text{new}(\cdot|s))$，

$\epsilon = \max_{s,a} |A^\pi(s,a)|$，则：

$$\eta(\pi_\text{new}) \geq L_{\pi_\text{old}}(\pi_\text{new}) - \frac{4\epsilon\gamma}{(1-\gamma)^2}\alpha^2 \tag{5}$$

4.5 Theorem 1 的耦合证明（v5 方法一）

证明思路：对两个策略进行耦合，控制它们分歧的概率。

1
定义耦合：若 $D_\text{TV}(p_X \| p_Y) = \alpha$，则存在联合分布 $(X,Y)$，使得 $X=Y$ 的概率为 $1-\alpha$（Levin et al., 2009, Prop 4.7）。
2
定义 $\bar{A}(s)$：$\tilde{\pi}$ 在状态 $s$ 处的期望优势： $$\bar{A}(s) = \mathbb{E}_{a\sim\tilde{\pi}(\cdot|s)}[A^\pi(s,a)]$$
3
Lemma 2：若 $(\pi, \tilde{\pi})$ 是 $\alpha$-耦合对，则对所有 $s$： $$|\bar{A}(s)| \leq 2\alpha \max_{s,a}|A^\pi(s,a)| = 2\alpha\epsilon$$

证明：$\bar{A}(s) = \mathbb{E}_{(\alpha,\tilde{a})\sim(\pi,\tilde{\pi})}[A^\pi(s,\tilde{a}) - A^\pi(s,a)]$（因为 $\mathbb{E}_{a\sim\pi}[A^\pi(s,a)]=0$），然后用 $P(a\neq\tilde{a}|s)\leq\alpha$ 和 $|A^\pi(s,\tilde{a})-A^\pi(s,a)|\leq 2\epsilon$ 即得。

4
Lemma 3：设 $n_t$ 为 $t$ 步前 $\pi$ 与 $\tilde{\pi}$ 分歧的次数，则 $P(n_t > 0) \leq 1-(1-\alpha)^t$，因此： $$\left|\mathbb{E}_{s_t\sim\tilde{\pi}}[\bar{A}(s_t)] - \mathbb{E}_{s_t\sim\pi}[\bar{A}(s_t)]\right| \leq 4\alpha(1-(1-\alpha)^t)\epsilon$$
5
对时间求和： $$|\eta(\tilde{\pi}) - L_\pi(\tilde{\pi})| \leq \sum_{t=0}^\infty \gamma^t \cdot 4\epsilon\alpha(1-(1-\alpha)^t)$$ $$= 4\epsilon\alpha\left(\frac{1}{1-\gamma} - \frac{1}{1-\gamma(1-\alpha)}\right) = \frac{4\alpha^2\gamma\epsilon}{(1-\gamma)(1-\gamma(1-\alpha))} \leq \frac{4\alpha^2\gamma\epsilon}{(1-\gamma)^2}$$
6
利用 $D_\text{TV}^2 \leq D_\text{KL}$（Pinsker 不等式）：令 $D_\text{KL}^\text{max}(\pi,\tilde{\pi}) = \max_s D_\text{KL}(\pi(\cdot|s)\|\tilde{\pi}(\cdot|s))$，则 $\alpha^2 \leq D_\text{KL}^\text{max}$，从而： $$\eta(\tilde{\pi}) \geq L_\pi(\tilde{\pi}) - \frac{4\epsilon\gamma}{(1-\gamma)^2} D_\text{KL}^\text{max}(\pi, \tilde{\pi}) \tag{6}$$

4.6 扰动理论证明（v5 方法二）

令 $G = (1-\gamma P_\pi)^{-1}$，$\tilde{G} = (1-\gamma P_{\tilde{\pi}})^{-1}$，$\Delta = P_{\tilde{\pi}} - P_\pi$。 用 $\eta(\pi) = rG\rho_0$（其中 $r$ 为奖励向量），目标是界定：

$$\eta(\tilde{\pi}) - \eta(\pi) = r(\tilde{G} - G)\rho_0$$
1
一阶展开：$\tilde{G} = G + \gamma G\Delta G + \gamma^2 G\Delta G\Delta\tilde{G}$，故： $$\eta(\tilde{\pi}) - \eta(\pi) = \gamma rG\Delta G\rho_0 + \gamma^2 rG\Delta G\Delta\tilde{G}\rho_0$$
2
一阶项 = $L_\pi(\tilde{\pi}) - L_\pi(\pi)$：注意 $rG = V^\pi$，$G\rho_0 = \rho_\pi$，因此 $\gamma rG\Delta G\rho_0 = \gamma V^\pi \Delta\rho_\pi$，可验证这等于 $L_\pi(\tilde{\pi}) - \eta(\pi)$。
3
界定二阶项（关键 — v3 此处有误）： $$|(\gamma V^\pi \Delta)_s| = \left|\sum_a (\tilde{\pi}(a|s)-\pi(a|s))Q^\pi(s,a)\right| \leq 2\alpha\epsilon$$ $$\|G\Delta\tilde{G}\rho\|_1 \leq \|G\|_1 \cdot \|\Delta\|_1 \cdot \|\tilde{G}\|_1 \cdot \|\rho\|_1 = \frac{1}{1-\gamma} \cdot \underbrace{2\alpha}_{\text{v3 误写为 }\alpha} \cdot \frac{1}{1-\gamma} \cdot 1$$ $$\gamma^2|rG\Delta G\Delta\tilde{G}\rho| \leq \gamma \cdot 2\alpha\epsilon \cdot \frac{2\alpha}{(1-\gamma)^2} = \frac{4\gamma\epsilon\alpha^2}{(1-\gamma)^2} \tag{7}$$

v3 中将 $\|\Delta\|_1$ 写成了 $\alpha$ 而非 $2\alpha$，这是因为 TV 散度定义为 $D_\text{TV}(p\|q) = \frac{1}{2}\sum_i|p_i-q_i|$，所以 $\|\Delta\|_1 = \sum_a|\tilde{\pi}(a|s)-\pi(a|s)| = 2D_\text{TV} = 2\alpha$，差了一个因子 2，导致最终系数从 4 变为 2。

4.7 从理论到算法：TRPO 优化问题

由式 (6)，最大化下界 $M_i(\pi) = L_{\pi_i}(\pi) - C \cdot D_\text{KL}^\text{max}(\pi_i, \pi)$ 可保证 $\eta$ 单调不减：

Algorithm 1（理论版）

$$\pi_{i+1} = \arg\max_\pi \left[L_{\pi_i}(\pi) - \frac{4\epsilon\gamma}{(1-\gamma)^2} D_\text{KL}^\text{max}(\pi_i, \pi)\right]$$

实践中，惩罚系数 $C$ 过大导致步长很小，改为信任域约束：

TRPO 实用形式（最终算法）

$$\max_\theta \; L_{\theta_\text{old}}(\theta) \quad \text{s.t.} \quad \bar{D}_\text{KL}^{\rho_{\theta_\text{old}}}(\theta_\text{old}, \theta) \leq \delta \tag{8}$$ 其中 $\bar{D}_\text{KL}^{\rho}(\theta_1, \theta_2) := \mathbb{E}_{s\sim\rho}[D_\text{KL}(\pi_{\theta_1}(\cdot|s)\|\pi_{\theta_2}(\cdot|s))]$（平均 KL 散度，替代难以处理的 max KL）

将 $L_{\theta_\text{old}}$ 展开为可采样形式（重要性采样）：

$$\max_\theta \; \mathbb{E}_{s\sim\rho_{\theta_\text{old}}, a\sim q}\left[\frac{\pi_\theta(a|s)}{q(a|s)} Q_{\theta_\text{old}}(s,a)\right] \quad \text{s.t.} \quad \mathbb{E}_{s\sim\rho_{\theta_\text{old}}}[D_\text{KL}(\pi_{\theta_\text{old}}(\cdot|s)\|\pi_\theta(\cdot|s))] \leq \delta \tag{9}$$

4.8 共轭梯度求解（v5 正确版本）

用线性近似目标 + 二阶近似约束，原问题化为：

$$Ax = g, \quad A_{ij} = \frac{\partial^2}{\partial\theta_i\partial\theta_j}\bar{D}_\text{KL}(\theta_\text{old}, \theta)\bigg|_{\theta=\theta_\text{old}}$$ （Fisher 信息矩阵的解析估计）

得到搜索方向 $s \approx A^{-1}g$，步长 $\beta = \sqrt{2\delta / s^T A s}$，再做回溯线搜索。

v3 附录 C 中为 $Ax = -g$（梯度下降方向），v5 修正为 $Ax = g$（梯度上升方向）。在实现 TRPO 时必须使用 v5 的正号版本。

TRPO 的意义不仅在于算法本身，更在于它提供了一个理论框架：用代理目标的下界来约束策略更新。PPO 正是在此基础上，用更简单的剪切操作近似信任域约束，成为目前最广泛使用的策略梯度算法。

9. 局限性

  • 理论常数过于保守：Theorem 1 中的 $C = 4\epsilon\gamma/(1-\gamma)^2$ 通常极大（$\epsilon$ 可以很大），导致理论步长接近于零。实践中直接用 $\delta$ 约束代替。
  • 计算代价高：每次迭代需要共轭梯度（约 10 次 Fisher-vector product），比一阶方法贵一个数量级。
  • 最大 KL 替换为平均 KL 未有理论保证：用 $\bar{D}_\text{KL}$ 替换 $D_\text{KL}^\text{max}$ 是启发式近似，理论保证丢失。
  • 需要二阶信息：需要计算 Fisher 信息矩阵，在分布式/流式场景下较难扩展。
  • 理论忽略优势估计误差：实践中优势函数是用蒙特卡洛或 GAE 估计的，误差未纳入理论分析。
