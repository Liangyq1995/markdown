Search Beyond What Can Be Taught：Agentic 视觉生成中的知识边界演化

1. 概述

标题Search Beyond What Can Be Taught: Evolving the Knowledge Boundary in Agentic Visual Generation
核心问题视觉生成器擅长渲染却会"自信地编造"未知内容；用户请求无界、演化、长尾（新角色、热门实体、cutoff 后事件），构成结构性"世界知识瓶颈"——生成器在固定语料训练，而视觉世界开放。论文提出通过 agentic 检索 + 生成器/reasoner 协同训练来发现并演化这条"知识边界"。
机构HKUST（香港科技大学）、University of Waterloo（滑铁卢大学）、Qwen Applications（阿里巴巴）、Imperial College London（帝国理工）
核心作者Haozhe Wang, Weijia Feng, Jinpeng Yu, Che Liu, Ping Nie, Fangzhen Lin, Jiaming Liu, Ruihua Huang, Jimmy Lin, Wenhu Chen, Cong Wei
开源地址https://haozheh3.github.io/SearchGen（代码、模型、数据集、co-training corpus、search corpus 全部释放）
arXiv2607.05382（v3, 2026-07-09）

现代视觉生成器在标准基准上已接近饱和，但在一类真实用户请求上仍然失败——它们会用精细的笔触"自信地编造"未知的世界知识（2025 大阪世博会吉祥物、斯巴达方阵的青铜甲胄、不丹国旗的雷龙图案等）。论文把这一现象诊断为世界知识瓶颈（world-knowledge bottleneck）而非视觉合成瓶颈：生成器在固定语料、固有知识 cutoff 下训练，而用户请求是无界、演化、深度长尾的。

为系统研究该问题，作者分析了生产级 AIGC 平台的 20,840 条用户 prompt，提炼出12 类失败模式，并构建了 SEARCHGEN-20K / SEARCHGEN-BENCH（20,839 条 prompt，覆盖 12 类失败、22 个域），配套预执行的多模态 SEARCHGEN-CORPUS-1M（145,642 条归档搜索会话、559,973 个唯一 URL、370,733 条缓存下载）以支持离线、可复现研究。在 SEARCHGEN-Bench 上，前沿开源生成器仅得 21–28/100，相比在仅需参数化知识的 prompt 上的 63–75 分出现高达 40 分的崩塌，而这一崩塌在现有基准上完全不可见。

自然解药是给生成器装上搜索工具（agentic visual generation）。但作者发现naive search 会失败：无差别检索会给生成器本已能处理的 prompt 注入噪声，反而降低质量。根因被追溯到一个生成器特定的、可演化的知识边界——介于"生成器可通过训练内化的知识"与"必须保留在外部上下文的知识"之间的分野。这条边界虽难以预先指定，却可通过一个 teach-then-search 协同训练框架被发现：先用在线迭代 DPO 教生成器内化它能吸收的知识，再用 rejection-sampling finetuning 重新校准 reasoner 去搜索生成器学不会的部分。即便最简配方（1 次 DPO + 1 次 RFT，4B 生成器 + 8B reasoner）也产生单调改进，校准后的 8B reasoner 在同一 4B 生成器上甚至略超万亿参数前沿 oracle。

核心命题（论文 Conclusion）：关键不是构建一个知道一切的模型，而是构建一个"知道自己不知道什么"的系统。这条 split 形成生成器特定的知识边界，虽难以 a priori 指定，却可通过 co-training 发现——而此自觉察来自 co-training 动力学，而非单纯 scale。

2. 研究背景与动机

2.1 世界知识瓶颈：忠实生成受限于知识而非渲染

视觉生成器在固定语料上训练，带有固有的知识 cutoff；而用户请求所依赖的世界是开放、演化、长尾的。两者的不匹配即世界知识瓶颈。该瓶颈被一个结构性盲点加剧：生成器被训练为"永远产出一张图像"，因此没有任何机制识别自己不知道什么——无法说出"我缺乏忠实渲染此内容的知识"，也没有获取它的协议。论文把这一瓶颈端到端地刻画出来：从真实用户行为中测绘世界知识生成全景、构建大规模数据集与基准、量化它对前沿生成器的削弱程度，并指出 naive search 不但不能解决，反而引入新的失败。

作者从生产级 text-to-image 平台分析了 20,840 条真实用户 prompt，发现需求远比现有基准所暗示的更多样、长尾、快速演化。从中提炼出 12 类复发失败模式（见 §3.1 表）。这些类别沿一条结构性轴分裂，直接决定搜索设计：

  • 需要视觉参考、难以用语言指定：游戏角色的服装剪影、国旗的精确色域——任何文本描述都无法完全指定，但一旦检索到，生成器即可条件化其上。例如《崩坏：星穹铁道》的角色 Jingliu 需要精确的视觉身份（服装、武器、配色）。
  • 需要文本知识、无视觉捷径：中国朝代时间线（含日期与开国皇帝）完全依赖结构化事实内容；DNA 复制的阿兹特克风格信息图需要精确的生化标签与流程顺序，视觉捷径罕见而百科文本可供应。
  • 介于两者之间、需双模态同时：墨西哥瓦哈卡的 alebrije 龙需视觉参考（文化专属色谱惯例）+ 文本知识（alebrije 与普通龙之别）；2025 大阪世博会吉祥物需时间新鲜的视觉参考 + 晚于模型训练的文本语境。

这种"视觉身份 × 事实精确"双轴结构直接催生了 §3 的模态感知搜索协议：纯视觉或纯文本搜索都不够，模态选择必须按知识缺口逐个决定。论文使用 Google Search API，把 image search 与 web search 作为 reasoner 在每个知识缺口之间调用的两件不同工具。

2.2 现有基准的盲区

现有基准评估的都是"已知视觉概念内"的组合性与美学质量：GenAI-Bench 测 prompt 遵循、T2I-CompBench 测空间推理与属性绑定、DALL-Eval 测物体关系、HEIM 做整体多维评估；VLM 自动评判如 TIFA、人工 grounded 度量如 Gecko 使可扩展的忠实度评估成为可能。但"a red cube on a blue sphere"这类 prompt 测的是空间推理，假设生成器已知道 cube 与 sphere 长什么样。SEARCHGEN-Bench 互补：它瞄准训练分布之外的概念（文化符号、近期实体、小众字体），衡量的是知识缺失而非推理失败。差距触目惊心：Flux.2-Klein-9B 在 GenAI-Bench 上得分高于 4.0/5.0，却在 SEARCHGEN-Bench 上低于 30/100——超过 60 个百分点的落差，没有现有评估能捕捉。

更结构性的证据来自 §4 的实验：在仅需参数化知识的 prompt 上，开源与商业生成器得分相当（67–75/100）；而在搜索密集型 prompt 上，同一批开源生成器崩塌到 22–28，而带集成搜索的商业系统几乎不掉。这个 40 分的分化被现有基准完全忽视。

2.3 与 agentic RAG / 工具增强生成的区别

论文在 Related Work 中清晰地把自己与三条前驱工作流区分开来：

工作流代表关键设定本文区别

核心定位：论文不是又一个"搜索增强扩散模型"，而是把"何时搜索 / 搜索什么 / 如何集成"作为与生成器联合的一阶设计变量，并提出该变量所依赖的"知识边界"虽 generator-specific 且随训练漂移，却可通过 co-training 被发现——为视觉生成的递归自改进奠定基础。

3. 核心方法

3.1 方法总览

整套系统围绕一个核心哲学展开：只在缺失知识位于生成器边界之外时才搜索，并控制检索内容如何进入生成。这需要决定三件事——何时搜索、用哪种模态、如何在不引入搜索噪声的前提下集成证据。论文用两个互锁组件实现它：(1) 一个抗噪 agentic reasoner，通过 gate–filter–integrate 三阶段协议控制搜索触发、参考选择与外部信息集成（§3.3）；(2) 一个 co-training 框架，先教生成器扩展知识边界，再把 reasoner 重新校准到强化后生成器的新边界（§3.5）。

3.2 SearchGen 数据构建

SEARCHGEN-20K 的构建是"answer-first 策略"驱动的：先从一个前沿模型出发，基于 seed 上下文选择自包含的世界知识缺口，使每条 prompt 在构造时即携带知识缺口引用——结构化 slot 指明生成器可能缺乏的视觉或文本知识，每个 slot 带 severity 标签（critical / important / moderate / minimal）与 justification 字段。这些标注大幅减轻了自动评估的负担。

构建三步走：

  1. Layer 1（seed 实体库）：从 10,840 条真实用户 prompt 提取 31,537 个实体，跨 22 个主域，每个标注 canonical name、估计训练集频率、ground-truth 视觉参考（若有）与区分属性；分布刻意长尾以镜像真实需求。其中 93.1% 的实体仅出现在单条 prompt——任何可行训练集的参数化学习都无法覆盖这种尾部需求，搜索在结构上不可避免。
  2. Layer 2（prompt 合成）：模板实例化生成结构化草稿 → 前沿 LLM 重写为自然用户风格请求（保留 grounded 实体、模态要求与 checklist 可验证事实，温度调高以多样化表面形式）→ 质控剔除歧义/文化敏感/与失败模式错位的 prompt。每条 prompt 配 2–4 个 ground-truth 搜索查询、3–8 个关键视觉元素的二值 checklist、1–5 评估 rubric。
  3. 标注可靠性：两名标注者独立标注 2,000 个失败样本，迭代精炼 schema 至 Cohen's κ > 0.85，再应用到全部 10,840 条生产 prompt。

最终数据集统计：20,188 行（20,187 unique prompt），平均每 prompt 5.2 个多模态知识缺口（90.5% 带 3+ 缺口），标注 34,694 个视觉参考 slot、16,345 个文本知识 slot；划分为 train（20,000）、validation（128）、test（751）。语料刻意双语：英文 58%（平均 266 字符，偏描述性展开）、中文 42%（平均 89 字符，偏密集隐式指定），捕捉真实跨语言 prompt 行为而非翻译模板。文化覆盖横跨东亚、南亚、中东、非洲、拉美等，因为知识缺口集中在长尾文化概念上，西方中心基准会低估失效严重度。

3.3 知识边界：形式化定义

§2 的观察揭示了一个隐含假设：在"生成器已知的"与"必须搜索的"之间存在一个良定义的 partition。该 partition 真实存在，但它是 generator-specific 且在训练下漂移——搜索对某些 prompt 有益、对另一些有害，而平衡随生成器能力变化。论文把这一量定义为知识边界。

Definition 1（Knowledge Boundary）。设 $K$ 为分布 $P$ 中 prompt 所需的世界知识单元（实体、文化符号、字体身份、流程规范等）的集合。对参数为 $\theta$ 的生成器 $G_\theta$、prompt $p \in P$、条件上下文 $c$（搜索返回的参考与文本），设 $Q(G_\theta, p, c) \in [0,1]$ 为有界质量函数。对固定容差 $\epsilon \gt 0$，定义可内化知识与上下文知识集合：

$$K_\mathrm{int}(\theta) = \left\{\, k \in K \;:\; \mathbb{E}_{p \mid k}\!\left[\, Q(G_\theta,\, p,\, \mathrm{SEARCH}(k)) - Q(G_\theta,\, p,\, \varnothing)\,\right] \lt \epsilon \,\right\}$$

$$K_\mathrm{ctx}(\theta) = K \,\setminus\, K_\mathrm{int}(\theta)$$

其中期望遍历 $P$ 中所有需要知识单元 $k$ 的 prompt，$\mathrm{SEARCH}(k)$ 表示对知识单元 $k$ 执行搜索协议所得的条件上下文。二元组 $(K_\mathrm{int}(\theta), K_\mathrm{ctx}(\theta))$ 构成 $K$ 的一个 generator-specific partition，称为知识边界 $B(\theta)$。若 prompt $p$ 需要 $k \in K_\mathrm{ctx}(\theta)$，则称 $p$ 相对 $G_\theta$ 是 search-intensive 的。该边界是 generator-specific 的：依赖 $\theta$ 且在训练下漂移——当 $\theta'$ 来自对搜索增强示范做 DPO 时，$K_\mathrm{int}(\theta) \subseteq K_\mathrm{int}(\theta')$。

关键洞察：某些知识可内化，搜索不应为其触发；另一些知识是上下文性的，搜索在结构上必不可少。且边界不必 a priori 可知——作者发现它可通过 co-training 被发现：通过测量每 prompt 的"有无搜索"质量差，其分布在 co-training 下会漂移（Figure 9b 中，DPO 后 per-prompt no-search 质量的 CDF 右移，shaded 区域即"新内化"的知识——先前质量差超过 $\epsilon$、如今落入 $\epsilon$ 之内、从 $K_\mathrm{ctx}$ 迁移到 $K_\mathrm{int}$）。

3.4 抗噪 Agentic Reasoner：Gate–Filter–Integrate 三阶段

Naive search 之所以降低生成质量，是因为噪声在三个结构上不同的点进入：是否搜索的决定、参考的选择、外部内容的集成。单一 filter 无法同时应对三者，每个都需要专属防御。论文提出三阶段 agentic 搜索协议，在每一点上按序抑制噪声。这三个阶段构成 agent 的 reason-and-act 循环，并对应 SFT 语料中的 Task A / B / C 轨迹。

三阶段细节：

  • Stage 1 Gate：给定 prompt $p$，reasoner 识别知识缺口、按类型与严重度分类、提出带模态标签（image | web）的搜索查询。仅 critical 或 important 缺口触发搜索，其余被过滤，产生最多 3 条查询或 SKIP。论文给出对照案例：对"上海中心大厦黄昏海报"（critical 视觉身份缺口）触发 image search；对"蓝白瓷茶壶产品照"（无命名实体/事件/文化专属）SKIP——这种纪律防止过检索。
  • Stage 2 Filter：多模态搜索执行后，选择"恰好填满特定缺口同时最小化无关内容"的参考。实证表明此阶段减少 copy effect（§2.5）——视觉捷径被从搜索结果中过滤。例如亚特兰大 UV 指数仪表盘的 3 个候选中，仅候选 1 带城市专属布局，filter 按索引选中。
  • Stage 3 Integrate：即便精选的视觉参考也可能携带远超知识缺口所需的信息，被生成器当作视觉捷径利用——原始像素 conditioning 泄漏风格、背景、布局。故集成阶段把视觉参考经自然语言路由：reasoner 把原始 prompt、缺口分析、检索到的视觉/文本知识融合为 enriched 文本规范。除原始照片外，生成器还收到 grounded citation 指明确切借用什么，如"following Image I, render the character in a teal-and-gold robe"。这为忠实生成保留缺失知识、丢弃会主导输出的像素级噪声。

论文把两类搜索失败模式对应到阶段：搜索对生成器本已处理的 prompt 触发、返回参考覆盖准确内部知识——这是 concept corruption（gating failure）；参考携带过多原始信息成为复制模板而非知识补充——这是 copy effect（filtering failure）。两者直接催生 gate–filter–integrate 协议。

3.5 Co-Training：Teach, Then Search

知识边界只在生成器参数改变时才会漂移，因此发现边界必须训练生成器本身、而非仅调整搜索策略。Co-training 在两侧按序作用：先强化生成器使更少 prompt 需搜索，再把 reasoner 重新校准到强化后生成器的边界。两个阶段执行边界上互补的运动：Phase 1 把边界外推（内化稳定知识 + 构建抗噪），Phase 2 把搜索策略内收以匹配，使搜索恰在知识仍处于生成器扩展容量之外时触发。

Phase 0：监督暖启动

Co-training 需要一个遵循三阶段协议的 reasoner。先用约 10,000 条专家标注 Task A/B/C 轨迹对 Qwen3-VL-8B 做监督微调（对应 gate/filter/integrate）。所得 reasoner 产出结构良好的分析，但仍 generator-agnostic：它对任何可能困难的内容都搜索，而非只对某一具体生成器实际失败的内容搜索。

Phase 1：Teach what the generator can internalize（在线迭代 DPO）

暖启动后的 reasoner 提供搜索增强输入（视觉参考 + 文本 prompt），把生成器暴露于其先前缺乏的知识。基于原始文本 prompt 与增强输入，通过在线迭代 Diffusion-DPO 训练生成器内化世界知识。每个 episode 中，生成器每 prompt 采样 $M$ 张图像，由 SEARCHGEN-20K 评估协议评分，从最高分与最低分世代构造偏好对。DPO 强化生成器自身的最佳产出，内化视觉身份足够稳定可吸收进参数的知识。Phase 1 后生成器 $G^{(1)}_\theta$ 扩展了知识边界：先前需搜索的概念现在驻留于参数。DPO 训练还构建了视觉生成的抗噪性：因生成器在搜索增强输入上训练，它学会在不被噪声主导的前提下纳入不完美视觉参考——只学干净输入的生成器会把每个 conditioning 信号视作权威，正是 concept corruption 与 copy effect 的根因。

Phase 1 适配 flow-matching 的 DPO 损失（论文 Algorithm 1 给出）：设 $v_\theta$ 为 flow-matching 速度场、$t$ 为扩散时间步、$\beta=100$ 为 DPO 温度、$\theta_\mathrm{ref}$ 经 EMA（decay 0.99）更新，偏好对由每 prompt 的 $M$ 张世代组构造：

$$\mathcal{L}_\mathrm{DPO}(\theta) = -\,\mathbb{E}_{(x_w, x_l, \tilde{p}, t)}\!\left[\,\log \sigma\!\left(\beta \log \frac{v_\theta(x_{w,t} \mid \tilde{p})}{v_{\theta_\mathrm{ref}}(x_{w,t} \mid \tilde{p})} - \beta \log \frac{v_\theta(x_{l,t} \mid \tilde{p})}{v_{\theta_\mathrm{ref}}(x_{l,t} \mid \tilde{p})}\right)\right]$$

其中 $x_w, x_l$ 分别为组内最高分与最低分世代（chosen/rejected），$\tilde{p}=R_{\phi_0}(p)$ 为经 gate–filter–integrate 的搜索增强规范。偏好构造附 SSIM 惩罚（$0.95$）以抑制 chosen/rejected 近同的退化对；flow-matching 用 Flow-SDE 调度（noise 1.0、time shift 1.0、时间步截断 0.1）。梯度更新为 $\theta \leftarrow \theta - \eta_1 \nabla_\theta \mathcal{L}_\mathrm{DPO}(\theta)$。

Phase 2：Search what the generator cannot be taught（rejection-sampling finetuning）

生成器边界已漂移，reasoner 策略失配——仍在搜索生成器已内化的概念。重新校准使用 rejection-sampling finetuning（RFT）：从 Phase 0 reasoner 配 $G^{(1)}_\theta$ rollout $N_\mathrm{traj}$ 条轨迹，对结果图像评分，计算 group-relative advantage，仅保留正优势轨迹用于 reasoner 续训。正确 abstain 的轨迹得高分被强化，不必要搜索腐蚀输出的轨迹得低分被丢弃。Reasoner 无需显式边界标签即学会强化后生成器的边界——边界从奖励信号中浮现。把 search agent 的 trace rollout、评分、强化正优势轨迹，本质是把 agent 策略针对"生成器作为环境"做优化。

group-relative advantage（论文 Algorithm 1 第 18 行）：设 $\bar{s} = \frac{1}{N_\mathrm{traj}}\sum_n s_n$、$\sigma_s = \mathrm{std}(\{s_n\})$，则

$$A_n = \frac{s_n - \bar{s}}{\sigma_s + \delta}$$

仅保留 $A_n \gt 0$ 的轨迹 $\tau_n$ 进入 $\mathcal{T}_\mathrm{rft}$，reasoner 经 $R_{\phi'} \leftarrow \arg\min_\phi \sum_{\tau \in \mathcal{T}_\mathrm{rft}} \mathcal{L}_\mathrm{SFT}(\phi; \tau)$ 完成 SFT。完整 RFT 周期约 $4 \times 8$ GPU-hours。

Algorithm 1: Co-Training — Teach, Then Search

Require: 生成器 G_θ，base VLM R_ϕ，数据集 D = {p_i}_{i=1}^{N}，质量函数 Q，容差 ϵ

Ensure: 协同训练后生成器 G_{θ'}，校准后 reasoner R_{ϕ'}

— Phase 0: 监督暖启动 —

1: 收集专家轨迹 T_sft = {(p_i, a_i^A, a_i^B, a_i^C)} 对应 Task A/B/C ▷ 约 20K

2: R_{ϕ0} ← arg min_ϕ L_SFT(ϕ; p, a) ▷ 结构化任务输出的交叉熵

— Phase 1: 在线迭代 DPO（生成器）—

3: for 每个 episode e = 1, ..., T1 do

4: 采样 batch B_e ⊂ D

5: for 每个 p ∈ B_e do

6: p̃ ← R_{ϕ0}(p) ▷ gate–filter–integrate 增强规范

7: 生成 M 张图：{x_j}_{j=1}^{M} ~ G_θ(· | p̃)

8: 评分：s_j ← Score(p, x_j) ▷ 与 Def.1 的 Q 不同的图像评分函数

9: 构偏好对：x_w ← x_{arg max s_j}，x_l ← x_{arg min s_j}

10: end for

11: 经 flow-matching DPO 损失更新：L_DPO(θ)（见上方公式）

12: θ ← θ − η_1 ∇_θ L_DPO(θ)

13: end for

14: G_{θ'} ← G_θ ▷ DPO 强化生成器

— Phase 2: rejection finetuning（reasoner）—

15: for 每个 p ∈ D_rft ⊂ D do

16: rollout N_traj 条轨迹 {τ_n}_{n=1}^{N_traj}，τ_n = R_{ϕ0}(p)，得图像 x_n ~ G_{θ'}(· | τ_n)

17: 评分：s_n ← Score(p, x_n)

18: group-relative advantage：A_n ← (s_n − s̄) / (σ_s + δ)

19: end for

20: 过滤：T_rft ← {τ_n : A_n > 0} ▷ 保留正优势轨迹

21: R_{ϕ'} ← arg min_ϕ Σ_{τ ∈ T_rft} L_SFT(ϕ; τ) ▷ 滤后轨迹上 SFT

22: return (G_{θ'}, R_{ϕ'})

3.6 评估协议

评估目标是把世界知识失败与渲染失败区分开来，全自动化。论文采用两套互补评分组件（9 维，每维 0–100，整体取适用维均值）：

  • 知识敏感（prompt-adaptive，5 维）：Checklist Verification（3–10 条二值关键视觉元素检查）、Rubric-adaptive Scoring（2–4 个类别定制加权维度）、Prompt Faithfulness（请求的主体/属性/动作/场景/风格的呈现与准确）、Visual Reference Fidelity（对参考图像的身份/属性/风格忠实度）、Textual Knowledge Fidelity（事实/系统/概念/流程等文本知识缺口正确性）。这些组件随 prompt 变化、直接衡量知识在场。
  • 渲染质量（knowledge-invariant，4 维）：Image Quality、Text Rendering、AI Naturalness、Composition & Aesthetics、Physical Plausibility。固定跨所有 prompt、独立于知识衡量生成能力。

评分由 Gemini-3-Flash VLM judge 完成，在 500 条 prompt–image 对上与人工评分的 Spearman ρ = 0.87。每条评分附 Anchor/Adjustment/Computed 三段可审计理由。搜索密集 prompt（651 条）按 Nano Banana Pro no-search 质量三分为 Set I（最易）、Set II、Set III（最难），partition 跨所有实验固定。
