概述：全模态世界模型的宏大愿景

人工智能的终极目标之一，是构建一个能够真正理解物理世界、并在其中采取行动的智能体。这要求模型不仅能"看"（视觉），能"说"（语言），更要能"听"（音频），能"动"（动作），还要理解这些感知与行动之间复杂的因果关系。Cosmos 3 正是朝这一目标迈出的关键一步——它是 NVIDIA 发布的一个全模态世界模型（Omnimodal World Model）家族，能够在统一的单一架构内，联合处理和生成语言、图像、视频、音频和动作序列五种模态。

传统的多模态模型往往是"拼凑式"的——用一个语言模型处理文本，另一个扩散模型生成图像，再用独立的音频模型处理声音，最后通过复杂的接口将它们串联起来。这种架构不仅带来巨大的工程复杂度，更重要的是，它阻止了不同模态之间深层语义的共同学习。Cosmos 3 的核心贡献在于，通过一个统一的 Mixture-of-Transformers（MoT） 骨干网络，将所有五种模态纳入同一个参数空间进行端到端联合训练，从而实现真正意义上的跨模态理解与生成。

核心定位：Cosmos 3 不是一个"多模态"模型（处理多种输入），而是一个"全模态"模型（在所有模态上均可作为输入，也可作为输出），其灵活的输入-输出配置使其能够胜任从视频生成到机器人策略学习的广泛任务。

发布后，Cosmos 3 在多个权威榜单上取得了里程碑式的成绩：在 Artificial Analysis 评测中荣登最佳开源文本转图像模型和最佳开源图像转视频模型；在 RoboArena 机器人策略排行榜上斩获第一名。更重要的是，NVIDIA 将其在 Linux Foundation 的 OpenMDW-1.1 协议下完全开源，包括代码、模型权重、合成数据集和评测基准，为整个 Physical AI 研究社区提供了一个强大的开放基础。

研究背景

理解 Cosmos 3 为何重要，需要从三个维度审视其所处的历史节点：Physical AI 的迫切需求、世界模型技术的演进脉络，以及多模态统一所面临的根本性挑战。

Physical AI 的迫切需求

"Physical AI"指的是能够在物理世界中感知、推理并采取行动的人工智能系统，其典型代表是具身机器人、自动驾驶汽车和工业自动化系统。这类系统面临的核心挑战与纯数字 AI（如聊天机器人、代码生成器）有本质不同：

  • 多感官融合：机器人需要同时处理视觉、触觉、听觉等多种感官输入，并将其映射到精确的运动指令。
  • 物理因果推理：智能体必须理解"如果我推这个杯子，它会向右滑动并可能掉落"这类物理因果关系，而非仅仅识别"杯子"这个概念。
  • 数据稀缺性：真实机器人数据采集成本极高，且难以覆盖长尾场景。世界模型可以作为"物理模拟器"生成合成训练数据，这是解决数据瓶颈的关键路径。
  • 实时决策：机器人控制通常要求毫秒级的响应，对模型推理效率提出了严苛要求。

世界模型的演进脉络

世界模型（World Model）的概念最早由 David Ha 和 Jürgen Schmidhuber 在 2018 年系统化提出，其核心思想是让智能体学习一个内部的环境动力学模型，从而在"脑内"进行规划和预演。近年来，随着大规模语言模型（LLM）和视频生成模型的突破，世界模型研究进入了快车道：

阶段 代表工作 核心能力 主要局限
早期世界模型 Ha & Schmidhuber (2018) VAE + RNN，用于 Atari 游戏规划 仅限低维离散动作，无法处理真实视觉
视频预测模型 DALL-E Video, Sora (2024) 高质量视频生成，物理场景建模 仅支持视觉模态，无动作条件
动作条件世界模型 UniSim, Genie, GameNGen 动作驱动的交互式视频生成 单一领域，模态支持有限
多模态世界模型 Cosmos 1/2, Wan, Emu3 视频+文本联合生成 缺乏音频和动作模态的统一处理
全模态世界模型 Cosmos 3 (2026) 语言+图像+视频+音频+动作统一建模 缺乏显式物理模拟器

多模态统一的根本挑战

将五种模态统一到一个模型中，面临的技术挑战远比表面看起来复杂。不同模态在以下维度上存在根本性差异：

  • 信号性质：文本是离散符号序列；图像和视频是连续像素张量；音频是时序波形；动作是连续或离散的控制向量。
  • 时间尺度：文本 token 的时间粒度可以是任意的；视频帧率通常为 24-30 FPS；音频采样率为 16-44kHz；机器人动作频率为 10-30 Hz。
  • 生成范式：文本生成天然适合自回归（AR）建模；图像/视频/音频生成则更适合扩散模型（DM）的连续空间去噪过程。
  • 语义层次：语言携带高层抽象语义；像素携带低层感知细节；动作携带物理执行信号——三者的语义空间差异巨大。

正是为了克服这些挑战，Cosmos 3 提出了 Mixture-of-Transformers 架构，以一种优雅的方式将离散自回归生成与连续扩散生成统一在同一个 Transformer 骨干下。

Mixture-of-Transformers 架构

Cosmos 3 的架构核心是 Mixture-of-Transformers（MoT）——一种将自回归 Transformer 与扩散 Transformer 融合在同一骨干网络中的统一架构。这一设计的精妙之处在于，它既保留了自回归模型在语言推理上的优势，又发挥了扩散模型在连续信号生成上的强大能力，两者共享参数，实现深度的跨模态知识迁移。

双塔融合原理

MoT 架构包含两条互补的计算路径，它们共享相同的 Transformer 层（包括多头注意力权重），但在特定组件上进行模态特化：

  • 自回归塔（AR Tower）：用于处理离散 token（主要是文本），采用因果自注意力（causal self-attention），通过标准的 next-token 预测进行训练。在推理时，文本 token 按顺序逐个生成。
  • 扩散塔（Diffusion Tower）：用于处理连续信号（图像、视频、音频、动作），采用全注意力（full attention），通过迭代去噪（iterative denoising）生成连续值 token。扩散过程在潜在空间中进行，由各模态的专用 Tokenizer 负责编解码。

统一位置编码：3D mRoPE

为了让模型能够统一感知不同模态的时空结构，Cosmos 3 采用了三维多维旋转位置编码（3D Multimodal Rotary Position Embedding, mRoPE）。该编码方案能够同时表达：

  • 时间维度（T）：视频帧的时序位置、音频的时间步
  • 空间高度维度（H）：图像/视频的垂直空间位置
  • 空间宽度维度（W）：图像/视频的水平空间位置

对于纯文本 token，mRoPE 退化为标准的 1D RoPE。这种统一的位置编码使得模型可以在同一注意力层中对齐不同模态的时空信息，是实现跨模态联合建模的关键基础设施。

模态专家路由

在 MoT 框架中，每个 Transformer 层包含一组模态专家（Modality Experts）。当不同模态的 token 流经同一层时，路由机制会将每个 token 分发给对应的专家子网络进行处理，而注意力层则对所有模态的 token 保持共享。这种设计实现了：

  • 共享语义空间：所有模态的 token 在注意力计算中相互可见，促进跨模态对齐。
  • 模态特化处理：每种模态的 FFN 专家可以学习该模态特有的特征变换，避免模态间的干扰。
  • 参数效率：相比为每种模态训练独立模型，MoT 通过参数共享大幅减少总参数量。

推理器与生成器双模式

Cosmos 3 在功能上划分为两个互补的工作模式：

模式 输入 输出 典型任务
推理器（Reasoner） 文本 + 视觉（图像/视频） 文本 视频描述、时序定位、具身推理、物理合理性分析、2D目标定位
生成器（Generator） 文本/视觉/音频/动作（任意组合） 视觉/音频/动作 文本转图像/视频、前向动力学预测、逆向动力学、动作策略生成

五模态处理机制

Cosmos 3 对五种模态的处理方式各有侧重，每种模态都有专门设计的编码器（Tokenizer）将原始信号转换为 Transformer 可处理的 token 序列，再经由对应的解码器将 token 还原为原始信号。以下逐一解析各模态的编码方式及其设计动机。

语言（Language）

文本是 Cosmos 3 中唯一采用离散 token 表示的模态。模型使用标准的 BPE（Byte Pair Encoding）分词器将文本转化为整数 token 序列。在生成端，文本通过自回归解码头（AR head）以 next-token 预测的方式逐步生成，训练目标为标准的交叉熵损失。

文本模态在 Cosmos 3 中承担着双重角色：一方面作为条件信号（prompt）引导其他模态的生成；另一方面作为推理输出，使模型能够用自然语言描述所观察到的视觉场景。支持高达 256K token 的上下文窗口，使模型能够处理长视频的完整描述和复杂的多轮对话。

图像（Image）

图像使用基于变分自编码器（VAE）的 Tokenizer 进行处理。输入图像被编码为低维连续潜在向量（latent code），再经由扩散解码器重建。这种设计的优势在于：

  • 连续潜在空间比离散 VQ-VAE 码本保留更丰富的细节信息
  • 扩散过程在潜在空间中进行，计算效率远高于像素空间
  • VAE 的 KL 正则化使潜在空间具有良好的插值性质

支持的输出分辨率包括 256p、480p 和 720p，宽高比支持 16:9、4:3、1:1、3:4 和 9:16 五种标准格式。

视频（Video）

视频是 Cosmos 3 中最复杂的模态，使用3D-VAE（三维变分自编码器）进行时空联合编码。3D-VAE 在时间维度和空间维度上同时进行下采样，将视频压缩为紧凑的时空潜在表示。3D mRoPE 位置编码确保模型能够准确感知帧间的时序关系。

支持的视频规格：帧率 10/16/24/30 FPS，帧数 5–400 帧，分辨率最高 720p。这使得 Cosmos 3 能够生成长达数十秒的高质量视频，覆盖从快速动作（30 FPS）到慢速叙事（10 FPS）的广泛场景。

音频（Audio）

音频模态使用神经音频编解码器（Neural Audio Codec）进行处理，将连续音频波形编码为离散或连续的潜在 token。音频编码器专门针对物理场景声音（碰撞声、环境音、机器运转声等）进行了优化，以支持 Physical AI 场景中的声音生成需求。

音频与视频的联合生成是 Cosmos 3 的重要能力之一——模型能够在生成视频的同时，生成与画面内容在时序上高度对齐的音频，实现视听同步输出。

动作（Action）

动作模态是 Cosmos 3 区别于所有前代世界模型的关键创新。动作序列（如机器人的关节角度轨迹、末端执行器位姿）被编码为连续向量，通过扩散解码头生成。Cosmos 3 支持多种机器人本体的动作空间：

  • 单臂 Franka Panda + RobotiQ 夹爪：10 维动作空间
  • 双臂 Franka Panda：20 维动作空间
  • WidowX 250：10 维动作空间
  • UMI（Universal Manipulation Interface）：9 维动作空间
  • Google Robot：10 维动作空间

动作模态的引入使 Cosmos 3 能够支持前向动力学（Forward Dynamics）预测（给定当前状态和动作，预测未来状态）和逆向动力学（Inverse Dynamics）推断（给定初末状态，推断中间动作序列），这是机器人规划与控制的核心能力。

灵活输入输出配置

Cosmos 3 最令人印象深刻的能力之一，是其对任意模态组合的灵活支持。在传统多模态系统中，输入输出的模态类型通常是固定的（如"文本输入→图像输出"）。而 Cosmos 3 允许用户在推理时自由指定输入模态和输出模态的任意组合，这种灵活性源于其统一 token 序列的架构设计。

统一序列拼接机制

无论输入包含哪些模态，Cosmos 3 都将它们统一编码为 token 序列后，按照特定的排列顺序拼接成一个多模态 token 序列。每个 token 携带其模态类型标记（modality type tag），使模型能够区分不同模态的 token 边界。3D mRoPE 为每个 token 分配与其模态语义一致的位置编码。

生成时，模型根据任务需求，选择激活 AR 解码头（生成文本）或扩散解码头（生成图像/视频/音频/动作）。扩散过程在目标模态的潜在空间中进行，以输入 token 的条件信息为引导，通过迭代去噪生成目标内容。

配置灵活性的技术保障

实现这种灵活配置的关键技术包括：

  • 模态类型嵌入（Modality Type Embedding）：每个 token 在输入时附加一个模态类型的可学习嵌入，使模型能够区分来自不同模态的 token，并学习模态间的对齐关系。
  • 掩码注意力策略：对于因果生成任务（如视频预测），使用因果掩码确保当前 token 只能看到历史 token；对于条件生成任务（如 Image-to-Video），条件 token（图像）对所有目标 token 完全可见，而目标 token 之间保持因果关系。
  • 分类器自由引导（CFG）：在扩散生成过程中，通过随机丢弃条件信号进行无条件训练，推理时使用 CFG 技术增强条件信号的影响力，提升生成质量和条件遵循度。
  • 统一训练目标：模型在训练时同时优化 AR 损失（文本 token 的交叉熵）和扩散损失（连续 token 的去噪 MSE），两个目标通过权重平衡联合训练，使单一模型能够胜任推理和生成两类任务。

Physical AI 应用

Cosmos 3 的设计初衷是服务于 Physical AI——即在物理世界中运作的智能体系统。相比纯数字 AI，Physical AI 对世界模型有着更为严苛的要求：模型不仅要理解语义，更要理解物理因果；不仅要生成视觉内容，更要输出可执行的动作指令。以下从三个核心应用方向展开分析。

机器人策略学习

机器人学习的核心挑战之一是数据稀缺性：真实机器人演示数据采集成本极高，且难以覆盖所有任务变体和长尾场景。Cosmos 3 通过以下方式赋能机器人策略学习：

  • 合成数据生成：利用 Cosmos 3 的视频生成能力，从少量真实演示出发，生成大量多样化的合成训练视频，为下游策略模型提供丰富的训练数据。NVIDIA 已发布多个针对数字人、物理交互、机器人操作、仓储场景和自动驾驶的合成数据集。
  • 直接策略输出：Cosmos3-Nano-Policy-DROID 模型直接以视觉观测和语言指令为输入，输出机器人动作轨迹，无需额外的策略网络。该模型在 RoboArena 机器人策略排行榜上排名第一，证明了全模态世界模型作为直接策略模型的可行性。
  • 前向/逆向动力学：前向动力学模式（视觉 + 动作 → 未来视频）可用于模型预测控制（MPC）；逆向动力学模式（初末状态视觉 → 动作序列）可用于从视频中自动标注动作标签，大幅降低数据标注成本。

具身智能推理

Cosmos 3 的推理器模式（Reasoner）专门针对具身场景的视觉理解进行了优化，支持以下高级推理能力：

  • 具身推理（Embodied Reasoning）：理解智能体自身与环境的空间关系，推断"我在哪里"、"物体在哪里"、"我能到达吗"等具身问题。
  • 物理合理性分析（Physical Plausibility Analysis）：判断给定场景中的物理交互是否符合现实物理规律，为机器人规划提供物理约束反馈。
  • 2D 目标定位（2D Object Grounding）：在图像/视频中精确定位物体的边界框，支持机器人抓取规划中的目标识别。
  • 时序定位（Temporal Grounding）：在长视频中定位特定事件发生的时间段，支持机器人从视频演示中提取关键操作步骤。

推理器支持高达 256K token 的上下文窗口，能够处理长达数分钟的视频序列，这对于理解复杂的多步骤机器人操作任务至关重要。

世界模拟与数字孪生

Cosmos 3 的生成器模式可以作为一个神经世界模拟器，为 Physical AI 的训练和测试提供虚拟环境：

  • 场景泛化测试：通过文本描述生成各种光照条件、背景环境和物体摆放的测试场景，在不需要真实部署的情况下评估机器人策略的鲁棒性。
  • 交互式模拟：在动作条件下生成交互式视频（给定动作序列，预测执行后的视觉结果），使机器人能够在"脑内"预演动作效果，辅助规划决策。
  • 数据增强：对现有机器人演示视频进行风格迁移、背景替换、光照变化等增强，在保持动作语义不变的前提下，大幅扩充训练数据的多样性。

值得注意的是，Cosmos 3 的技术报告明确指出，模型缺乏显式的物理模拟器，其物理理解来自于对大量真实视频数据的统计学习，而非基于物理方程的精确计算。这意味着在涉及精确物理交互的安全关键场景中，仍需额外的验证和保障机制。

实验结果

Cosmos 3 在多个权威基准测试上取得了全面领先的成绩。以下从文本转图像、图像转视频、机器人策略三个维度展示实验结果，并与主流开源和闭源模型进行对比。

开放生态

Cosmos 3 的开放策略是其区别于众多商业闭源模型的重要特征。NVIDIA 选择在 Linux Foundation 的 OpenMDW-1.1（Open Model and Data Weights License 1.1） 协议下完全开源，这一决策对整个 Physical AI 研究社区具有深远意义。

OpenMDW-1.1 协议解析

OpenMDW-1.1 是由 Linux Foundation 主导制定的开放模型许可协议，专为大规模 AI 模型设计。相比 Apache 2.0 等传统开源协议，它在以下方面有所扩展：

条款维度 OpenMDW-1.1 规定 实际影响
商业使用 允许商业应用，无需授权费 初创公司和企业可直接基于 Cosmos 3 构建商业产品
模型修改 允许微调、蒸馏、继续训练 研究者可针对特定领域（如手术机器人、自动驾驶）进行专项微调
衍生模型 衍生模型须保留协议声明 确保开放生态的持续传播
安全限制 禁止用于生成有害内容、武器系统 平衡开放性与安全责任
数据权重 模型权重和部分训练数据均开放 研究者可复现训练过程，验证实验结果

全栈开放的战略意义

Cosmos 3 的开放不仅限于模型权重，而是涵盖了从数据到评测的完整研究栈：

  • 代码开源（github.com/nvidia/cosmos）：包括训练框架、推理代码、数据处理流程和评测脚本。支持 PyTorch、Diffusers、vLLM-Omni 和 vLLM 四种推理后端，覆盖从研究原型到生产部署的全链路需求。
  • 模型权重开放（HuggingFace）：五个模型变体（Nano、Super、Text2Image、Image2Video、Policy-DROID）均在 HuggingFace 上公开，Cosmos3-Nano 已获得超过 17,900 次下载，Cosmos3-Super 超过 16,800 次下载（截至报告日期）。
  • 合成数据集开放：NVIDIA 同步发布了用于训练 Cosmos 3 的合成数据集，涵盖数字人场景、物理交互、机器人操作、仓储环境和自动驾驶五大领域，为缺乏大规模真实数据的研究团队提供了宝贵资源。
  • 评测基准开放：开放评测基准使社区能够以统一标准评估和比较不同世界模型的能力，推动领域内的良性竞争和快速迭代。

对 Physical AI 社区的影响

Cosmos 3 的全栈开放对 Physical AI 研究社区的影响体现在多个层面：

  • 降低入门门槛：高校和小型研究团队无需从头训练大规模世界模型，可直接基于 Cosmos 3 进行微调和应用研究。
  • 推动标准化：统一的接口（Diffusers、vLLM）和评测基准有助于建立 Physical AI 领域的技术标准。
  • 促进生态繁荣：开放的模型权重和数据集吸引了大量开发者参与，HuggingFace 上的高下载量已经证明了社区的积极响应。
  • 加速产业落地：OpenMDW-1.1 的商业友好性使企业能够快速将 Cosmos 3 集成到工业机器人、自动驾驶等实际应用中。

总结与启发

Cosmos 3 是 AI 发展历史上的一个重要里程碑，它不仅是一个性能卓越的多模态模型，更代表了一种全新的 AI 系统设计范式。在这一节，我们从技术范式、研究启发和未来展望三个维度进行深度总结。

统一世界模型的范式意义

Cosmos 3 最深刻的贡献，是证明了五种模态可以在单一架构中实现真正的统一建模，而非简单的管道拼接。这一范式转变的意义体现在：

  • 模态间的深层对齐：在共享的 MoT 架构中，语言、视觉、音频和动作 token 在同一注意力空间中相互可见，模型能够学习到跨模态的深层语义对应关系。例如，"推"这个动作词在语言空间中的表示，会与视频中物体被推动的视觉模式，以及机器人执行推动动作的控制信号在语义上对齐。
  • 涌现的跨模态能力：统一训练往往能够产生单模态训练无法获得的涌现能力。Cosmos 3 在物理推理和具身推理上的强大表现，很可能来自于语言推理能力与视觉感知能力的深度融合。
  • 数据效率的提升：跨模态的参数共享使得每种模态的数据都能够间接提升其他模态的能力。机器人动作数据的训练，可以通过共享的 Transformer 层，间接提升模型对物理场景的视觉理解能力。

MoT 架构的技术洞见

Cosmos 3 的 Mixture-of-Transformers 架构提供了一个重要的技术洞见：AR 和扩散不是对立的生成范式，而是互补的。文本的离散自回归特性和视觉/音频/动作的连续扩散特性，恰好对应了信息的两种基本形态——符号化的语义表达和连续的感知信号。MoT 通过共享 Transformer 骨干、分离生成头的方式，优雅地将两者统一，为未来的多模态模型设计提供了重要参考。

Physical AI 的未来图景

Cosmos 3 所代表的全模态世界模型，为 Physical AI 的未来描绘了一幅令人振奋的图景：

  • 通用机器人基础模型：类似 GPT 之于 NLP，未来可能出现一个通用的机器人基础模型，能够通过少量微调适应各种机器人平台和操作任务。Cosmos 3 的 Policy-DROID 模型已经展示了这一方向的可行性。
  • 自主数据飞轮：世界模型生成合成数据 → 合成数据训练更好的策略模型 → 策略模型在真实环境中收集更多数据 → 更多数据训练更强的世界模型，这一正向循环有望大幅加速 Physical AI 的能力提升。
  • 物理 AI 的 Scaling Law：Cosmos 3 的 Nano（16B）和 Super（64B）两个规模版本已经展示了参数量与能力的正向关系。随着计算资源的增加，全模态世界模型的能力边界还有巨大的提升空间。

局限性与未来方向

诚实地面对 Cosmos 3 的局限性，对于研究社区同样重要：

  • 缺乏显式物理引擎：模型的物理理解来自统计学习，在精确物理交互（如精密装配、流体动力学）上仍难以与基于方程的物理模拟器媲美。未来的方向可能是将神经世界模型与可微分物理引擎结合。
  • 长时域一致性：在生成超长视频或执行长时域机器人任务时，模型可能出现时序不一致和动作状态漂移，这是当前所有生成模型的共同挑战。
  • 实时推理延迟：64B 参数的 Super 模型在单 GPU 上生成 189 帧视频需要约 170 秒，距离机器人控制所需的实时响应（<100ms）仍有数量级的差距。模型压缩、量化和专用硬件加速是必要的研究方向。
  • 安全关键场景的可靠性：在手术机器人、核电站维护等安全关键场景中，模型的幻觉和不确定性问题需要额外的形式化验证和安全保障机制。
核心启发：Cosmos 3 告诉我们，真正的 Physical AI 需要的不是五个独立的专家模型，而是一个能够在语言、视觉、听觉、触觉和行动之间自由流转的统一智能体。这一愿景的实现，将是通向通用人工智能的关键一步。
