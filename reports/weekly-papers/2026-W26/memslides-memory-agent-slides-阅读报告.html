概述

MemSlides 是一个面向个性化演示文稿生成的层级记忆驱动智能体框架。现有的幻灯片生成系统往往将个性化视为提示词工程的副产品，而非通过显式记忆机制来实现。MemSlides 将记忆体系拆分为三个互补层次：用户画像记忆（User Profile Memory）、工作记忆（Working Memory）和工具记忆（Tool Memory），分别解决跨任务的偏好持久化、多轮修订中的会话约束追踪、以及可靠的局部编辑执行三大核心挑战。

在修订策略上，MemSlides 提出作用域局部修订（Scoped Slide-Local Revision）机制，每次修订仅作用于受影响的最小幻灯片区域，而非重新生成整个演示文稿，从而大幅降低上下文压力并避免意外内容漂移。实验结果表明，该框架在个性化对齐、局部修订可靠性和会话级偏好延续三个维度上均超越现有基线系统。

核心洞察：演示文稿的有效个性化依赖于将持久用户画像、会话级工作记忆与可复用执行经验三者分离管理，而非将它们混入一个无差别的对话缓冲区。

研究背景与动机

自动化演示文稿生成是 AI 辅助内容创作的重要场景，近年来随着大语言模型能力的提升，该领域涌现出 PPTAgent、DeepPresenter、SlideTailor 等系统。然而，这些系统在面对真实用户场景时均存在明显短板，推动了 MemSlides 的研究动机。

现有方法的三大痛点

  • 跨任务偏好无法持久化：现有系统每次生成都从零开始，无法记住用户在历史任务中表达的风格偏好（如配色方案、字体选择、内容密度等），导致用户需要反复重申相同需求。
  • 多轮修订中约束丢失：当用户在第一轮提出"将标题改为蓝色"后，第二轮继续修订时，系统往往忘记上一轮已确认的约束，产生回归性错误，破坏修订的连贯性。
  • 全局重生成效率低且易漂移：多数系统在每次修订时重新生成整个幻灯片组，不仅计算开销大，还会无意间修改用户已满意的其他部分，造成内容漂移（unintended drift）。

相关工作对比

系统/方向 代表工作 局限性
端到端幻灯片生成 AutoPresent, PPTAgent 个性化为提示副产品，无显式记忆
个性化生成 SlideTailor, DeepPresenter 无跨任务记忆，修订依赖全局重写
智能体记忆研究 MemGPT, Generative Agents 通用记忆框架，未针对幻灯片编辑特化
长上下文处理 MemAgent, RAPTOR 面向文档理解，非生成/编辑场景

MemSlides 的核心思路是：将记忆作为一等公民（first-class citizen）纳入幻灯片生成智能体的设计，而非将其作为对话历史的被动附属物。

核心方法

MemSlides 的方法体系由两个相辅相成的部分构成：层级记忆框架（解决个性化信息的存储与调用）和作用域局部修订策略（解决多轮编辑的精准性与稳定性）。下图展示了整体架构及三类记忆的交互关系。

三类记忆详解

1. 用户画像记忆（User Profile Memory）

是什么：一种以用户为键、以意图为条件的长期持久化记忆，存储用户在不同任务意图下的多维偏好画像。

为什么：不同用户对幻灯片的期望差异显著（学术报告 vs. 商业提案），同一用户在不同意图下的偏好也不同。将偏好显式持久化，使智能体在 Round-0 生成时就能直接个性化，而非依赖用户实时描述。

怎么做：偏好按六个维度组织——主题（theme）、内容（content）、视觉（visual）、布局（layout）、模板（template）、通用（general）。当一个新任务启动时，系统根据用户 ID 和检测到的任务意图，将相应的画像路由进工作记忆，作为初始生成的个性化约束。

效果：实验证明用户画像记忆显著提升了 Round-0（首轮生成）的人格对齐得分，在 GLM-5 骨干下 Specificity 维度达到 8.89/10。

2. 工作记忆（Working Memory）

是什么：会话级的临时记忆，维护当前幻灯片编辑会话的状态，包括活跃偏好和用户在各修订轮次中引入的新约束。

为什么：多轮修订的核心挑战在于"约束累积"——用户每轮反馈都是增量式的，系统必须在保留已确认偏好的同时接纳新约束。若缺乏工作记忆，每轮修订都是无状态的，极易发生约束遗忘和回归错误。

怎么做：工作记忆在任务开始时从用户画像记忆加载初始偏好，随后在每个修订轮次结束后更新，将本轮用户反馈（新偏好、新约束）合并进当前会话状态。后续修订轮次读取更新后的工作记忆，确保偏好的跨轮次延续。

效果：定性案例研究展示了工作记忆成功将第一轮修订中引入的偏好（如"使用更大的字体"）延续到第二、三轮修订，而不因新的修订请求而丢失。

3. 工具记忆（Tool Memory）

是什么：一种存储可复用执行经验的长期记忆，记录历史修订任务中成功的工具调用序列和编辑策略。

为什么：幻灯片的局部编辑涉及复杂的 HTML/CSS 操作（定位元素、修改样式规则、调整布局），LLM 在闭环工具调用中容易犯重复性错误。将成功的执行经验持久化，可以在新任务中直接复用，提升修订的可靠性。

怎么做：每次成功完成的局部修订操作（包括工具调用序列、目标选择器、样式修改）被结构化存储进工具记忆。执行新修订任务时，系统检索相似的历史经验，将其注入当前执行上下文，引导智能体采用经过验证的操作模式。

效果：工具记忆注入在诊断性匹配对比实验（diagnostic matched-pair）中显著提升了闭环修改行为的正确率，减少了无效工具调用和格式错误。

作用域局部修订（Scoped Slide-Local Revision）

这是 MemSlides 的修订执行策略，与记忆框架协同工作，解决"如何可靠地执行局部编辑"的问题。

sequenceDiagram
    participant U as 用户反馈
    participant A as MemSlides 智能体
    participant WM as 工作记忆
    participant TM as 工具记忆
    participant S as 幻灯片

    U->>A: "将第3页标题改为蓝色，字号加大"
    A->>WM: 读取当前会话约束
    WM-->>A: 返回活跃偏好（含历史约束）
    A->>S: 请求投影：定位最小受影响区域（第3页标题元素）
    S-->>A: 返回局部快照（布局结构 + CSS选择器 + 样式规则）
    A->>TM: 检索相似修订经验
    TM-->>A: 返回匹配的执行策略
    A->>S: 写回补丁（仅修改 .slide-3 .title 的 color 和 font-size）
    S-->>A: 修订完成确认
    A->>WM: 更新会话状态（记录本轮新约束）
    A->>TM: 存储成功执行经验
    A->>U: 返回修订结果

局部修订的关键设计原则：

  • 读取局部化：仅读取受影响区域的结构化快照（局部布局结构、可用选择器、暴露的样式规则），而非整个幻灯片的完整 HTML/CSS。
  • 写入局部化：补丁仅写回到显式指定的选择器或样式规则，不触碰其他元素，从根本上避免意外漂移。
  • 上下文压力降低：局部化读写显著减少了每次修订所需的上下文长度，降低了 LLM 的认知负担，提升了精准度。

多画像多意图评估基准

论文还构建了一个专用于个性化演示文稿生成评估的基准数据集——多画像多意图用户画像库（multi-persona, multi-intent profile bank）。该基准涵盖不同背景用户（学术研究者、商业分析师、教育工作者等）在不同任务意图（技术汇报、销售提案、教学课件等）下的偏好组合，用于系统性评估个性化对齐能力。

实验结果

论文从三个维度展开实验评估：个性化对齐质量、通用演示质量（DeepPresenter 风格检查）、以及局部修订的诊断性评估。核心实验在三个主干模型（GPT-5、GLM-5、Gemini 3.1 Pro）上与两个基线系统（DeepPresenter、SlideTailor）进行对比。

消融实验分析

论文通过控制变量实验验证了三类记忆各自的贡献：

实验设置 主要发现 验证维度
有/无用户画像记忆 用户画像记忆显著提升 Round-0 人格对齐得分，Specificity 维度提升最为明显 个性化对齐
有/无工具记忆注入 工具记忆注入在诊断性匹配对比实验中显著改善闭环修改行为，减少无效工具调用 局部修订可靠性
有/无工作记忆（多轮） 工作记忆成功实现跨轮次偏好延续，定性案例展示约束不丢失 多轮修订连贯性

关键实验结论

  • GLM-5 + MemSlides 组合表现最优：在四个个性化维度上均超过 9 分（满分10分），相比 DeepPresenter + GLM-5 提升约 20-60%，相比 SlideTailor + GLM-5 提升约 100%+。
  • 记忆框架对模型骨干有放大效应：MemSlides 在 GLM-5 上的提升幅度远大于在 GPT-5 上，说明记忆框架能够帮助能力较强的模型更好地利用结构化偏好信息。
  • 局部修订策略减少漂移：作用域局部修订相比全局重生成，在保持已对齐内容不变的同时，成功完成目标区域的修改，内容漂移现象显著减少。

总结与启发

MemSlides 在方法论和工程实践两个层面都提供了有价值的参考，以下从研究贡献和实践启发两个角度进行总结。

研究贡献总结

贡献维度 具体内容 意义
记忆分层设计 将长期记忆（用户画像 + 工具经验）与工作记忆（会话约束）显式分离 为个性化智能体提供了清晰的记忆架构范式
意图感知路由 用户画像按意图维度组织，任务启动时按意图路由相关偏好 解决了"同一用户不同场景需求不同"的细粒度个性化问题
局部修订策略 Scoped Slide-Local Revision：读写均限定在最小受影响区域 从根本上消除多轮修订中的内容漂移问题
评估基准 多画像多意图用户画像库 + 四维度个性化评估指标 填补了个性化幻灯片生成领域的评估基准空白

对智能体系统设计的启发

启发1 — 记忆分层是个性化智能体的基础设施：MemSlides 的实践表明，将"用户是谁"（用户画像记忆）、"这次会话发生了什么"（工作记忆）、"如何可靠执行"（工具记忆）三类信息分开管理，比混入一个对话缓冲区效果好得多。这一设计原则可推广到任何需要个性化的智能体系统。
启发2 — 工具记忆是降低 LLM 工具调用错误率的有效手段：工具记忆的本质是"经验重放"——将历史成功案例结构化存储并在新任务中检索复用。这对于任何依赖复杂工具调用链的 Agent 系统都有借鉴价值，类似于 few-shot 但更系统化、更动态。
启发3 — 局部作用域编辑是多轮 Agent 交互的通用原则：每次修订只读取和写入最小必要的上下文，不仅降低了 LLM 的认知负担，也从架构上保证了已对齐内容的稳定性。这一"最小作用域"原则对代码编辑、文档修改等类似场景同样适用。
启发4 — 意图感知的偏好路由值得关注：将用户偏好按意图维度组织（而非简单地按用户 ID 聚合），使系统能够处理"同一用户在不同场景下有不同期望"的真实情况。这对构建更精细的个性化推荐和生成系统有参考价值。

局限性与未来方向

  • 记忆更新策略：论文未详细讨论当用户偏好发生变化时，用户画像记忆如何动态更新（遗忘旧偏好、接纳新偏好），这是个性化记忆系统的核心难题。
  • 冷启动问题：新用户没有历史画像，系统如何快速建立初始偏好模型需要进一步研究。
  • 跨模态扩展：当前框架主要针对 HTML/CSS 幻灯片，扩展到 PowerPoint、PDF 等格式的局部编辑需要适配不同的文档表示。
  • 实时偏好学习：从用户的修订行为中自动学习和更新偏好（而非依赖显式反馈）是下一步值得探索的方向。
