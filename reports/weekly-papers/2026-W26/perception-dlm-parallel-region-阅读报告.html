PerceptionDLM：基于多模态扩散语言模型的并行区域感知

arXiv: 2606.19534  |  代码: MSALab-PKU/PerceptionDLM  |  机构: ByteDance & 北京大学  |  发布: 2026年6月  |  HF Upvotes: 61

作者: Yueyi Sun, Yuhao Wang, Jason Li, Ye Tian, Tao Zhang, Jacky Mai, Yihan Wang, Haochen Wang, Jinbin Bai, Ling Yang, Yunhai Tong

概述

现有的多模态大语言模型（MLLM）普遍依赖自回归（Autoregressive, AR）生成范式，在需要同时对图像中多个区域进行描述的任务中，只能逐一串行处理每个区域，导致推理延迟随区域数量线性增长，成为高效感知的瓶颈。

本文提出 PerceptionDLM，首次将扩散语言模型（Diffusion Language Models, DLM）的天然并行解码特性应用于多区域感知任务，通过高效提示设计与结构化注意力掩码机制，实现在序列级和 Token 级同时生成多个区域描述。在新构建的 ParaDLC-Bench 基准上，PerceptionDLM 在保持竞争性描述质量的同时，推理吞吐量最高提升 3.5 倍。

研究背景

理解 PerceptionDLM 的动机，需要从两个维度切入：扩散语言模型的生成范式，以及区域级视觉感知任务的现有瓶颈。

扩散语言模型（DLM）

是什么：扩散语言模型是一类基于 Masked Diffusion 框架的生成模型，与 GPT 系列的自回归逐 token 生成不同，DLM 在推理时对所有 token 位置同时进行去噪迭代，本质上是一个并行解码器。

为什么：AR 模型的 KV-Cache 机制虽然优化了单序列生成，但面对 N 个独立区域描述任务时，必须串行调用 N 次，总延迟为 $O(N \cdot L)$（L 为单个描述长度）。DLM 的并行特性使得多个独立输出可以在一次前向传播中同时生成，理论延迟为 $O(L)$，与区域数量无关。

代表工作：LLaDA（Large Language Diffusion with mAsking）是目前主流的离散扩散语言模型基础架构，PerceptionDLM-Base 即构建于此框架之上，并在 16 个多模态基准上超越了 LLaDA-V。

区域感知与详细局部描述

是什么：区域级感知（Region Perception）要求模型针对图像中用 mask 或 bounding box 标注的特定区域，生成详细、准确的自然语言描述。DLC-Bench（Detailed Localized Captioning Benchmark）是该任务的权威评测基准。

现有瓶颈：现有 AR 方法（如 DAM、GRASP 等）在单区域描述上已取得较好效果，但在多区域场景下，串行处理带来的推理延迟随区域数量线性增长，在实际应用（如图像标注流水线、密集场景理解）中成为显著瓶颈。

关键空白：在 PerceptionDLM 之前，尚无工作探索利用 DLM 的并行特性来解决多区域描述的效率问题，也没有专门评测并行区域感知的基准。

核心方法

PerceptionDLM 的核心贡献在于两个相互配合的设计：高效区域提示（Region Prompting）和结构化注意力掩码（Structured Attention Masking）。两者共同赋予 DLM 在单次前向传播中独立生成多个区域描述的能力。

高效区域提示设计

是什么：区域提示（Region Prompting）是一种将空间区域信息编码为模型可理解的嵌入 token 的机制，使模型在生成描述时能够"感知"到每个区域的位置和形状。

为什么：DLM 的并行解码需要模型在单次前向传播中同时处理 N 个区域，每个区域的描述必须有对应的"锚点"来引导生成，否则模型无法区分哪段输出对应哪个区域。

怎么做：系统包含两个互补组件：

  • Visual Prompt Embedding：将区域 Mask（二值掩码）通过专用编码器映射为区域嵌入向量，与对应区域的描述 token 序列对齐拼接。
  • RoI-Aligned Feature Replay：通过 RoI-Align 模块从全图特征图中提取与每个区域精确对齐的局部特征 token，作为区域特有的视觉上下文注入解码过程。

效果（消融实验）：去掉区域提示后，模型 Avg 准确率从 53.7% 骤降至 1.1%（几乎完全失效）；去掉 RoI 对齐特征回放后，准确率降至 51.3%，说明两者缺一不可。

结构化注意力掩码机制

是什么：结构化注意力掩码（Structured Attention Masking）是一种在 Transformer 注意力矩阵上施加块对角约束的机制，确保不同区域的描述 token 在生成过程中相互独立，不产生跨区域的信息干扰。

为什么：在 DLM 的并行解码中，所有区域的 token 同时存在于同一序列中。若使用全注意力（Full Attention），区域 i 的描述 token 会"看到"区域 j 的 RoI 特征和描述 token，导致跨区域信息泄露，生成结果混乱。

怎么做：对于区域 $R_i$ 对应的 token，其注意力范围被严格限制为：

  1. 全局视觉 token（所有区域共享，提供图像全局上下文）
  2. 共享文本提示 token（任务指令等公共部分）
  3. 仅属于 $R_i$ 的 RoI 特征 token
  4. 仅属于 $R_i$ 的描述输出 token 序列

其他区域的 RoI 特征和描述 token 被完全屏蔽，形成块对角（Block-Diagonal）注意力模式。

效果（消融实验）：使用全注意力（Full Attention）时，Avg 准确率为 47.5%，而结构化注意力掩码将其提升至 53.7%，提升 6.2 个百分点，验证了区域独立性约束的必要性。

序列级与 Token 级双重并行

PerceptionDLM 的并行性体现在两个层次：

  • 序列级并行（Sequence-level）：N 个区域的描述序列在同一次前向传播中同时生成，无需像 AR 模型那样串行调用 N 次。
  • Token 级并行（Token-level）：在每个扩散去噪步骤内，每个区域描述序列中的所有 token 位置同时被预测和更新（DLM 的固有特性），而非逐 token 顺序生成。

两者叠加使得推理效率相对 AR 基线有根本性提升，且提升幅度随区域数量增加而增大。

ParaDLC-Bench 设计

为系统评测 DLM 在并行区域感知任务上的能力，论文构建了 ParaDLC-Bench（Parallel Detailed Localized Captioning Benchmark），这是首个同时评测描述质量与推理效率的多区域感知基准。

基准设计原则

ParaDLC-Bench 基于已有的 DLC-Bench 扩展而来，核心改变是将单区域评测扩展为每张图像包含多个区域 Mask（如 1、2、3、5 个区域），从而能够：

  • 评测描述质量：沿用 DLC-Bench 的 GPT 裁判评分协议，分别统计 Positive 得分（正确描述信息）和 Negative 得分（错误/幻觉信息），综合计算 Avg 分数。
  • 评测推理效率：在相同模型规模下，测量不同区域数量时的推理延迟和吞吐量，直接量化并行化收益。
  • 联合评测：将质量与效率纳入同一框架，避免"以牺牲质量换速度"的虚假并行。

评分协议

GPT 裁判评分机制

采用 GPT-5.2 作为评判模型，对生成描述进行细粒度评分：

  • Pos.（正分）：描述中正确识别的属性、关系、细节，越高越好
  • Neg.（负分）：描述中出现的错误信息或幻觉，越高（惩罚越少）越好
  • Avg.：综合得分，当惩罚项主导时可能为负值

训练数据：ParaCaption-5.7M

为训练 PerceptionDLM 的并行区域感知能力，论文构建了 ParaCaption-5.7M 数据集，包含 570 万条多区域描述样本，由强 AR 教师模型 GAR-8B 合成生成，作为监督信号训练 PerceptionDLM 的并行解码能力。

总结与启发

PerceptionDLM 是一篇思路清晰、工程完整的工作，其核心贡献不在于提出全新的模型架构，而在于识别并利用了 DLM 与多区域感知任务之间天然的结构匹配。以下是几点值得关注的启发：

启发 1：任务结构与模型范式的匹配是效率优化的关键

多区域描述天然是 N 个独立子任务的并集，而 DLM 的并行解码恰好对应这种结构。这提示我们：在选择生成范式时，应优先考虑任务的结构特征，而非默认使用 AR 模型。类似的机会可能存在于其他"多路独立输出"场景（如多轮问答批处理、多标签分类生成等）。

启发 2：结构化约束是并行生成质量的保障

消融实验清楚地表明，全注意力（Full Attention）会因跨区域信息干扰导致明显的质量下降。在并行生成中，显式的独立性约束（结构化掩码）比隐式期望模型自行学习独立性更可靠。这一原则对其他并行生成任务（如并行多文档摘要、并行代码补全）同样适用。

启发 3：评测基准设计与方法创新同等重要

ParaDLC-Bench 将推理效率纳入评测框架，弥补了现有基准只关注质量、忽视效率的缺陷。一个好的基准能够推动研究方向的正确演进，避免"以牺牲效率换质量"的虚假进步。

启发 4：DLM 在视觉理解领域仍有大量未开发空间

PerceptionDLM 是 DLM 在多模态领域应用的早期探索。目前 DLM 在视觉生成（如 SDXL、Flux）领域已广泛应用，但在视觉理解领域的研究仍相对匮乏。DLM 的并行特性在视频理解、3D 场景描述、密集预测等任务中可能带来类似收益，值得进一步探索。

启发 5：合成数据驱动的 Bootstrapping 策略

ParaCaption-5.7M 由 AR 教师模型（GAR-8B）合成，用于训练并行扩散学生模型。这种"强 AR 教师 → 高效 DLM 学生"的蒸馏范式为在没有大规模并行标注数据的情况下训练并行模型提供了实用路径。
