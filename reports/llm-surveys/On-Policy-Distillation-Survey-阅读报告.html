机构腾讯（Mingyang Song, Mao Zheng）
核心问题Off-Policy 蒸馏的暴露偏差（Exposure Bias）导致复合误差 $O(\epsilon T^2)$，On-Policy Distillation（OPD）如何从根本上将其降至 $O(\epsilon T)$？

DAgger 界（核心理论）：On-Policy 将复合误差从 $O(\epsilon T^2)$ 降至 $O(\epsilon T)$，差异是序列长度 $T$ 的倍数。对于生成数千 token 的 LLM，$T \approx 1000$ 时，两者相差约 1000 倍——理论上证明了 OPD 的必要性。

2. 统一数学框架：f-散度

2.1 标准 KD 的 KL 散度（温度控制）

$$\mathcal{L}_\mathrm{KD} = \tau^2 D_\mathrm{KL}(p_T(\cdot|x;\tau) \| p_\theta(\cdot|x;\tau))$$

$\tau \to \infty$ 时退化为 MSE（最小化学生与教师的原始 logit 差异）。$\tau = 1$ 时为标准 KL 散度。

2.2 统一 OPD 目标

$$\mathcal{L}_\mathrm{OPD}(\theta) = \mathbb{E}_{y \sim \pi_\mathrm{mix}}\!\left[\sum_{t=1}^{|y|} D_f\!\left(p_T(\cdot|x,y_{\lt t}),\; p_\theta(\cdot|x,y_{\lt t})\right)\right]$$

三个自由度构成 OPD 方法的设计空间：

  • 行为策略 $\pi_\mathrm{mix}$：谁的轨迹？（教师/学生/混合）
  • 散度选择 $D_f$：怎么度量差距？（Forward KL/Reverse KL/JSD 等）
  • 参数顺序：教师在前 vs 学生在前

4. 核心方法详析

4.1 GKD（Generalized Knowledge Distillation）

将 DAgger 思想直接移植到 LLM：学生从自身分布采样，再在这些学生轨迹上最小化与教师的 KL 散度：

$$\mathcal{L}_\mathrm{GKD} = \mathbb{E}_{y \sim p_\theta}\!\left[D_\mathrm{KL}(p_T(\cdot|x,y_{\lt t}) \| p_\theta(\cdot|x,y_{\lt t}))\right]$$

4.2 MiniLLM（Reverse KL + 策略梯度）

Reverse KL（学生优先），通过 REINFORCE 估计梯度：

$$\nabla_\theta \mathcal{L}_\mathrm{MiniLLM} = -\mathbb{E}_{y \sim p_\theta}\!\left[\sum_{t=1}^{|y|}(R_t - 1)\nabla_\theta \log p_\theta(y_t|y_{\lt t})\right]$$

其中 $R_t = \sum_{t'=t}^{|y|}\log\frac{p_T(y_{t'}|y_{\lt t'})}{p_\theta(y_{t'}|y_{\lt t'})}$ 为到尾部的累积奖励。缺点：策略梯度高方差导致训练不稳定。

4.3 DistiLLM（偏斜 KL 双目标）

通过偏斜混合解决 Forward KL 的零除不稳定性：

$$\tilde{p} = \alpha p_T + (1-\alpha)p_\theta \quad \Rightarrow \quad D_\mathrm{skFKL} = D_\mathrm{KL}(p_T \| \tilde{p})$$ $$\text{偏斜 Reverse KL}: D_\mathrm{skRKL} = D_\mathrm{KL}(p_\theta \| (1-\alpha)p_T + \alpha p_\theta)$$

两目标协同：前者保证教师模式被覆盖（稳定性），后者在学生样本上寻求模式（精准性）。

5. 工业部署场景

场景OPD 的特别价值代表应用
模型压缩小模型部署时分布匹配更精确LLaMA 70B→7B 同质蒸馏
推理能力迁移长 CoT 在小模型上的 OPD 比 Off-Policy 更稳定o1/R1 能力→小模型
投机解码草稿模型在主模型真实前缀上训练，接受率显著提升AlphaCode 2, SpecDecoding
指令跟随黑盒 API 蒸馏时 On-Policy 减少分布外输出Alpaca 风格数据生成
投机解码的特殊案例：草稿模型（Draft Model）必须在主模型真实自回归状态下工作。Off-Policy 训练的草稿模型在主模型的实际前缀上验证率低，因为训练和测试前缀分布不同。OPD 让草稿模型见到真实推理状态，直接提升接受率。

7. 核心洞见与读后评注

OPD 与 RLHF 的深层联系
On-Policy Distillation 和 RLHF/RLVR 都是"在线优化"范式——都让模型对自己生成的内容负责，而非只模仿静态数据。区别在于信号来源：OPD 用教师分布作为监督信号，RLHF 用奖励模型。两者可以结合：用教师提供密集 token 级信号，同时用奖励模型提供稀疏结果级信号。
暗知识（Dark Knowledge）的重要性
教师对非最优类别的概率质量（如将"猫"误分类为"狗"的小概率）包含了类间关系信息，是传统硬标签（one-hot）所没有的。这是白盒 OPD 相比黑盒的核心优势——不只是知道教师"说了什么"（最高概率输出），还知道教师"几乎说了什么"（完整分布）。
