Ch.4动态规划算法

前提假设

动态规划（Dynamic Programming, DP）要求完整的环境模型：转移概率 \(P(s'|s,a)\) 和奖励函数 \(R(s,a)\) 已知。DP 利用贝尔曼方程的递推结构，将复杂的全局优化问题分解为局部子问题。

4.1 策略评估（Policy Evaluation）

目标：给定固定策略 \(\pi\)，计算其对应的状态价值函数 \(V^\pi\)。

贝尔曼期望方程（精确形式）
$$V^\pi(s) = \sum_a \pi(a|s)\left[R(s,a) + \gamma \sum_{s'} P(s'|s,a)\, V^\pi(s')\right], \quad \forall s \in \mathcal{S}$$
这是关于 \(V^\pi\) 的线性方程组，理论上可直接求解，但实践中用迭代法。

迭代贝尔曼更新

$$V_{k+1}(s) = \sum_a \pi(a|s)\left[R(s,a) + \gamma \sum_{s'} P(s'|s,a)\, V_k(s')\right]$$

定义贝尔曼策略算子 \(T^\pi\)：

$$(T^\pi V)(s) \triangleq \sum_a \pi(a|s)\left[R(s,a) + \gamma \sum_{s'} P(s'|s,a)\, V(s')\right]$$
收敛性 — 压缩映射定理

在 \(\infty\)-范数下，\(T^\pi\) 是压缩系数为 \(\gamma\) 的压缩映射：

$$\|T^\pi V - T^\pi U\|_\infty \leq \gamma \|V - U\|_\infty$$

由 Banach 不动点定理，迭代序列 \(V_k = (T^\pi)^k V_0\) 以几何速率收敛到唯一不动点 \(V^\pi\)，收敛误差满足：

$$\|V_k - V^\pi\|_\infty \leq \frac{\gamma^k}{1-\gamma}\|V_1 - V_0\|_\infty$$

算法伪代码

// 策略评估算法（迭代法）
Algorithm PolicyEvaluation(π, P, R, γ, θ):
  // 初始化价值函数
  for all s ∈ S: V[s] ← 0

  repeat:
    Δ ← 0
    for all s ∈ S:
      v ← V[s]
      // 贝尔曼期望更新
      V[s] ← Σ_a π(a|s) · [R(s,a) + γ · Σ_{s'} P(s'|s,a) · V[s']]
      Δ ← max(Δ, |v - V[s]|)
  until Δ < θ        // θ 为收敛阈值（如 1e-6）

  return V

4.2 策略提升（Policy Improvement）

策略提升定理

设 \(\pi'\) 满足：对所有 \(s \in \mathcal{S}\)，

$$Q^\pi(s, \pi'(s)) \geq V^\pi(s)$$

则 \(\pi'\) 是对 \(\pi\) 的一次提升，即 \(V^{\pi'}(s) \geq V^\pi(s)\) 对所有 \(s\) 成立。

贪婪策略提升

$$\pi'(s) = \arg\max_a Q^\pi(s,a) = \arg\max_a \left[R(s,a) + \gamma \sum_{s'} P(s'|s,a)\, V^\pi(s')\right]$$

完整证明推导

定理证明：策略提升定理
起点：利用假设条件
$$V^\pi(s) \leq Q^\pi(s, \pi'(s)) = \mathbb{E}_{\pi'}\!\left[r_{t+1} + \gamma V^\pi(s_{t+1}) \,\Big|\, s_t = s\right]$$
再次展开 \(V^\pi(s_{t+1})\)
$$\leq \mathbb{E}_{\pi'}\!\left[r_{t+1} + \gamma Q^\pi(s_{t+1}, \pi'(s_{t+1})) \,\Big|\, s_t = s\right]$$
继续展开 \(Q^\pi(s_{t+1}, \pi'(s_{t+1}))\)
$$\leq \mathbb{E}_{\pi'}\!\left[r_{t+1} + \gamma r_{t+2} + \gamma^2 Q^\pi(s_{t+2}, \pi'(s_{t+2})) \,\Big|\, s_t = s\right]$$
无限展开取极限（\(\gamma < 1\) 保证收敛）
$$\leq \mathbb{E}_{\pi'}\!\left[\sum_{k=0}^{\infty} \gamma^k r_{t+k+1} \,\Big|\, s_t = s\right] = V^{\pi'}(s) \qquad \blacksquare$$

4.3 策略迭代（Policy Iteration）

策略迭代交替执行策略评估和策略提升，直至策略不再改变。

收敛保证

有限 MDP 中，策略数量有限（至多 \(|\mathcal{A}|^{|\mathcal{S}|}\) 个），且每次迭代策略严格改善（或不变），因此策略迭代必然在有限步内收敛到最优策略 \(\pi^*\)。

4.4 价值迭代（Value Iteration）

价值迭代将策略提升嵌入价值更新，直接用贝尔曼最优方程迭代，无需显式维护策略。

$$V_{k+1}(s) = \max_a \left[R(s,a) + \gamma \sum_{s'} P(s'|s,a)\, V_k(s')\right] = (T^* V_k)(s)$$

其中贝尔曼最优算子 \(T^*\) 定义为：

$$(T^* V)(s) \triangleq \max_a \left[R(s,a) + \gamma \sum_{s'} P(s'|s,a)\, V(s')\right]$$
收敛性证明 — ∞-范数压缩
证明 \(T^*\) 是 \(\gamma\)-压缩
$$|(T^*V)(s) - (T^*U)(s)| = \left|\max_a [\cdots V\cdots] - \max_a [\cdots U\cdots]\right| \leq \gamma \max_{s'} |V(s') - U(s')|$$
取上确界得到范数不等式
$$\|T^*V - T^*U\|_\infty \leq \gamma \|V - U\|_\infty$$
Banach 不动点定理给出收敛速率
$$\|V_k - V^*\|_\infty \leq \frac{\gamma^k}{1-\gamma}\|V_1 - V_0\|_\infty \xrightarrow{k\to\infty} 0$$

策略迭代 vs 价值迭代 对比

维度 策略迭代（PI） 价值迭代（VI）
每轮操作 完整策略评估（多次扫描）+ 一次提升 单次贝尔曼最优更新
内层循环 需要内层收敛（策略评估） 无内层循环
迭代轮数 较少（策略数有限） 较多（但每轮代价低）
实现复杂度 较高 较低
适用场景 状态空间较小，精确策略重要 大状态空间，近似最优即可
收敛到 \(\pi^*\)（有限步精确） \(V^*\)（渐近收敛）

4.5 动态规划的局限

核心局限
  • 需要完整环境模型：转移概率 \(P(s'|s,a)\) 和奖励 \(R(s,a)\) 必须已知，现实中往往无法获得。
  • 维度灾难（Curse of Dimensionality）：状态空间 \(|\mathcal{S}|\) 指数增长时，存储 \(V\) 和计算贝尔曼更新的代价爆炸式增长。
  • 同步扫描代价高：标准 DP 每轮需扫描全部状态，对大规模问题不可行。
  • 引出无模型方法：蒙特卡洛（MC）和时序差分（TD）方法无需环境模型，通过与环境交互直接学习。

Ch.5时序差分算法

核心思想

时序差分（Temporal Difference, TD）方法结合了蒙特卡洛的无模型采样和动态规划的自举（bootstrapping），在每一步交互后立即更新价值估计，无需等待整条轨迹结束。

5.1 TD 学习基本思想

三种方法的回报对比

方法更新目标特点
动态规划 \(\sum_a \pi(a|s)\left[R + \gamma \sum_{s'} P\cdot V(s')\right]\) 需要模型，无采样
蒙特卡洛 \(G_t = r_{t+1} + \gamma r_{t+2} + \gamma^2 r_{t+3} + \cdots\) 无模型，需完整轨迹，无偏但高方差
TD(0) \(r_{t+1} + \gamma V(s_{t+1})\) 无模型，单步更新，有偏但低方差

TD(0) 更新规则

$$V(s_t) \leftarrow V(s_t) + \alpha \underbrace{\left[r_{t+1} + \gamma V(s_{t+1}) - V(s_t)\right]}_{\delta_t \text{（TD 误差）}}$$
TD 误差（Temporal Difference Error）：
$$\delta_t = r_{t+1} + \gamma V(s_{t+1}) - V(s_t)$$
  • \(\delta_t > 0\)：实际回报优于预期，上调 \(V(s_t)\)
  • \(\delta_t < 0\)：实际回报劣于预期，下调 \(V(s_t)\)
  • \(\delta_t = 0\)：预测准确，无需更新

TD 误差与蒙特卡洛回报的关系

$$G_t - V(s_t) = \sum_{k=0}^{T-t-1} \gamma^k \delta_{t+k}$$

蒙特卡洛误差可分解为 TD 误差的加权累积和，揭示了两者的内在联系。

5.2 Sarsa（On-Policy TD 控制）

命名来源：Sarsa 由五元组 \((s_t,\, a_t,\, r_{t+1},\, s_{t+1},\, a_{t+1})\) 的首字母组成，完整描述了一次转移所需的全部信息。

完整更新公式

$$Q(s_t, a_t) \leftarrow Q(s_t, a_t) + \alpha \Big[\underbrace{r_{t+1} + \gamma\, Q(s_{t+1}, a_{t+1})}_{\text{TD 目标}} - Q(s_t, a_t)\Big]$$

On-Policy 特性

On-Policy 定义

行为策略（用于与环境交互采集数据）= 目标策略（被优化的策略）

Sarsa 使用 \(\varepsilon\)-贪婪策略同时扮演两个角色：

$$\pi(a|s) = \begin{cases} 1 - \varepsilon + \varepsilon/|\mathcal{A}| & \text{若 } a = \arg\max_{a'} Q(s,a') \\ \varepsilon/|\mathcal{A}| & \text{其他} \end{cases}$$

因此 Sarsa 学到的是最优 \(\varepsilon\)-贪婪策略，而非纯贪婪最优策略。

收敛条件

  • 学习率满足 Robbins-Monro 条件：\(\sum_t \alpha_t = \infty\)，\(\sum_t \alpha_t^2 < \infty\)
  • 所有 \((s,a)\) 对被无限次访问（探索充分）
  • \(\varepsilon \to 0\) 的速率足够慢

5.3 Q-learning（Off-Policy TD 控制）

完整更新公式

$$Q(s_t, a_t) \leftarrow Q(s_t, a_t) + \alpha \Big[\underbrace{r_{t+1} + \gamma \max_{a'} Q(s_{t+1}, a')}_{\text{TD 目标（贪婪）}} - Q(s_t, a_t)\Big]$$

Off-Policy 特性

Off-Policy 定义

行为策略（\(\varepsilon\)-贪婪，负责探索）≠ 目标策略（纯贪婪 \(\pi^* = \arg\max Q\)）

Q-learning 直接对贪婪目标策略进行优化，与行为策略无关，因此可以用任意探索策略收集数据。

收敛性证明思路
将 Q-learning 写成随机近似（Stochastic Approximation）形式
$$Q_{t+1}(s,a) = Q_t(s,a) + \alpha_t(s,a)\left[F(Q_t, s, a) + \varepsilon_t\right]$$

其中 \(F(Q,s,a) = R(s,a) + \gamma \sum_{s'} P(s'|s,a)\max_{a'}Q(s',a') - Q(s,a)\)，\(\varepsilon_t\) 为零均值噪声。

验证贝尔曼最优算子 \(T^*\) 是 \(\gamma\)-压缩
$$\|T^*Q - T^*Q'\|_\infty \leq \gamma\|Q - Q'\|_\infty$$
应用 Watkins-Dayan 定理（随机近似引理）

满足 Robbins-Monro 条件 + 所有 \((s,a)\) 无限次访问 + 奖励有界，则 Q-learning 以概率 1 收敛到 \(Q^*\)。

Q-learning vs Sarsa：悬崖漫步实验

经典对比实验

悬崖漫步（Cliff Walking）：网格世界，靠近悬崖边缘奖励为 -100，到达目标奖励为 0，其余步 -1。

算法学到的路径原因在线表现
Sarsa 保守路径（远离悬崖） On-policy，考虑 \(\varepsilon\)-探索时偶尔会跌落悬崖，因此绕远路 在线累积奖励较高
Q-learning 激进路径（紧贴悬崖） Off-policy，优化贪婪策略（最短路），不考虑探索时的意外 在线累积奖励较低

5.4 多步 TD（n-step TD）

n 步回报定义

$$G_t^{(n)} = r_{t+1} + \gamma r_{t+2} + \gamma^2 r_{t+3} + \cdots + \gamma^{n-1} r_{t+n} + \gamma^n V(s_{t+n})$$

对应的 n 步 TD 更新：

$$V(s_t) \leftarrow V(s_t) + \alpha\left[G_t^{(n)} - V(s_t)\right]$$

特殊情形

n 值退化为更新目标
\(n = 1\) TD(0) \(r_{t+1} + \gamma V(s_{t+1})\)
\(n = 2\) 2-step TD \(r_{t+1} + \gamma r_{t+2} + \gamma^2 V(s_{t+2})\)
\(n \to \infty\) 蒙特卡洛 \(G_t = \sum_{k=0}^{\infty} \gamma^k r_{t+k+1}\)
方差-偏差权衡（Bias-Variance Tradeoff）：
  • 小 n（TD）：自举强，偏差高（依赖不准确的 \(V\) 估计），方差低（仅用少量随机步骤）
  • 大 n（MC）：自举弱，偏差低（使用真实回报），方差高（累积多步随机奖励）
  • 最优 n：通常在中间值，具体取决于任务特性

6.2 Dyna-Q 框架

核心组件

模型学习

Dyna-Q 使用一个确定性查找表模型，存储每个 \((s,a)\) 对最近一次观测到的结果：

$$\text{Model}(s, a) \leftarrow (r, s') \quad \text{（每次真实交互后更新）}$$

对于随机环境，可扩展为存储 \((r, s')\) 的经验分布。

Q-Planning（虚拟经验更新）

从已访问过的 \((s,a)\) 中随机采样，用模型生成虚拟转移，执行 Q-learning 更新：

$$\text{采样 }(s, a) \sim \text{已访问集合}$$ $$(r, s') \leftarrow \text{Model}(s, a)$$ $$Q(s, a) \leftarrow Q(s, a) + \alpha\left[r + \gamma \max_{a'} Q(s', a') - Q(s, a)\right]$$

完整算法流程

// Dyna-Q 算法
Algorithm DynaQ(α, γ, ε, n_planning):
  // 初始化
  for all s, a: Q[s,a] ← 0
  Model ← empty dict

  for each episode:
    s ← env.reset()

    for each step:
      // (1) 选择动作（ε-贪婪）
      a ← ε-greedy(Q[s, ·])

      // (2) 真实交互，获取 (r, s')
      r, s' ← env.step(a)

      // (3) 直接 Q-learning 更新（真实数据）
      Q[s,a] ← Q[s,a] + α · [r + γ · max_a' Q[s',a'] - Q[s,a]]

      // (4) 更新环境模型
      Model[s, a] ← (r, s')

      // (5) 规划：用模型生成虚拟经验，重复 n_planning 次
      repeat n_planning times:
        s_sim, a_sim ← random sample from Model.keys()
        r_sim, s'_sim ← Model[s_sim, a_sim]
        Q[s_sim,a_sim] ← Q[s_sim,a_sim] + α · [r_sim + γ · max_a' Q[s'_sim,a'] - Q[s_sim,a_sim]]

      s ← s'
      if s is terminal: break
