Ch.4动态规划算法

前提假设

动态规划（Dynamic Programming, DP）要求完整的环境模型：转移概率 \(P(s'|s,a)\) 和奖励函数 \(R(s,a)\) 已知。DP 利用贝尔曼方程的递推结构，将复杂的全局优化问题分解为局部子问题。

4.1 策略评估（Policy Evaluation）

目标：给定固定策略 \(\pi\)，计算其对应的状态价值函数 \(V^\pi\)。

贝尔曼期望方程（精确形式）
$$V^\pi(s) = \sum_a \pi(a|s)\left[R(s,a) + \gamma \sum_{s'} P(s'|s,a)\, V^\pi(s')\right], \quad \forall s \in \mathcal{S}$$
这是关于 \(V^\pi\) 的线性方程组，理论上可直接求解，但实践中用迭代法。

迭代贝尔曼更新

$$V_{k+1}(s) = \sum_a \pi(a|s)\left[R(s,a) + \gamma \sum_{s'} P(s'|s,a)\, V_k(s')\right]$$

定义贝尔曼策略算子 \(T^\pi\)：

$$(T^\pi V)(s) \triangleq \sum_a \pi(a|s)\left[R(s,a) + \gamma \sum_{s'} P(s'|s,a)\, V(s')\right]$$
收敛性 — 压缩映射定理

在 \(\infty\)-范数下，\(T^\pi\) 是压缩系数为 \(\gamma\) 的压缩映射：

$$\|T^\pi V - T^\pi U\|_\infty \leq \gamma \|V - U\|_\infty$$

由 Banach 不动点定理，迭代序列 \(V_k = (T^\pi)^k V_0\) 以几何速率收敛到唯一不动点 \(V^\pi\)，收敛误差满足：

$$\|V_k - V^\pi\|_\infty \leq \frac{\gamma^k}{1-\gamma}\|V_1 - V_0\|_\infty$$

算法伪代码

// 策略评估算法（迭代法）
Algorithm PolicyEvaluation(π, P, R, γ, θ):
  // 初始化价值函数
  for all s ∈ S: V[s] ← 0

  repeat:
    Δ ← 0
    for all s ∈ S:
      v ← V[s]
      // 贝尔曼期望更新
      V[s] ← Σ_a π(a|s) · [R(s,a) + γ · Σ_{s'} P(s'|s,a) · V[s']]
      Δ ← max(Δ, |v - V[s]|)
  until Δ < θ        // θ 为收敛阈值（如 1e-6）

  return V

4.2 策略提升（Policy Improvement）

策略提升定理

设 \(\pi'\) 满足：对所有 \(s \in \mathcal{S}\)，

$$Q^\pi(s, \pi'(s)) \geq V^\pi(s)$$

则 \(\pi'\) 是对 \(\pi\) 的一次提升，即 \(V^{\pi'}(s) \geq V^\pi(s)\) 对所有 \(s\) 成立。

贪婪策略提升

$$\pi'(s) = \arg\max_a Q^\pi(s,a) = \arg\max_a \left[R(s,a) + \gamma \sum_{s'} P(s'|s,a)\, V^\pi(s')\right]$$

完整证明推导

定理证明：策略提升定理
起点：利用假设条件
$$V^\pi(s) \leq Q^\pi(s, \pi'(s)) = \mathbb{E}_{\pi'}\!\left[r_{t+1} + \gamma V^\pi(s_{t+1}) \,\Big|\, s_t = s\right]$$
再次展开 \(V^\pi(s_{t+1})\)
$$\leq \mathbb{E}_{\pi'}\!\left[r_{t+1} + \gamma Q^\pi(s_{t+1}, \pi'(s_{t+1})) \,\Big|\, s_t = s\right]$$
继续展开 \(Q^\pi(s_{t+1}, \pi'(s_{t+1}))\)
$$\leq \mathbb{E}_{\pi'}\!\left[r_{t+1} + \gamma r_{t+2} + \gamma^2 Q^\pi(s_{t+2}, \pi'(s_{t+2})) \,\Big|\, s_t = s\right]$$
无限展开取极限（\(\gamma < 1\) 保证收敛）
$$\leq \mathbb{E}_{\pi'}\!\left[\sum_{k=0}^{\infty} \gamma^k r_{t+k+1} \,\Big|\, s_t = s\right] = V^{\pi'}(s) \qquad \blacksquare$$

收敛保证

有限 MDP 中，策略数量有限（至多 \(|\mathcal{A}|^{|\mathcal{S}|}\) 个），且每次迭代策略严格改善（或不变），因此策略迭代必然在有限步内收敛到最优策略 \(\pi^*\)。

4.4 价值迭代（Value Iteration）

价值迭代将策略提升嵌入价值更新，直接用贝尔曼最优方程迭代，无需显式维护策略。

$$V_{k+1}(s) = \max_a \left[R(s,a) + \gamma \sum_{s'} P(s'|s,a)\, V_k(s')\right] = (T^* V_k)(s)$$

其中贝尔曼最优算子 \(T^*\) 定义为：

$$(T^* V)(s) \triangleq \max_a \left[R(s,a) + \gamma \sum_{s'} P(s'|s,a)\, V(s')\right]$$
收敛性证明 — ∞-范数压缩
证明 \(T^*\) 是 \(\gamma\)-压缩
$$|(T^*V)(s) - (T^*U)(s)| = \left|\max_a [\cdots V\cdots] - \max_a [\cdots U\cdots]\right| \leq \gamma \max_{s'} |V(s') - U(s')|$$
取上确界得到范数不等式
$$\|T^*V - T^*U\|_\infty \leq \gamma \|V - U\|_\infty$$
Banach 不动点定理给出收敛速率
$$\|V_k - V^*\|_\infty \leq \frac{\gamma^k}{1-\gamma}\|V_1 - V_0\|_\infty \xrightarrow{k\to\infty} 0$$

内层循环 需要内层收敛（策略评估） 无内层循环
迭代轮数 较少（策略数有限） 较多（但每轮代价低）
实现复杂度 较高 较低
适用场景 状态空间较小，精确策略重要 大状态空间，近似最优即可
收敛到 \(\pi^*\)（有限步精确） \(V^*\)（渐近收敛）

4.5 动态规划的局限

核心局限
  • 需要完整环境模型：转移概率 \(P(s'|s,a)\) 和奖励 \(R(s,a)\) 必须已知，现实中往往无法获得。
  • 维度灾难（Curse of Dimensionality）：状态空间 \(|\mathcal{S}|\) 指数增长时，存储 \(V\) 和计算贝尔曼更新的代价爆炸式增长。
  • 同步扫描代价高：标准 DP 每轮需扫描全部状态，对大规模问题不可行。
  • 引出无模型方法：蒙特卡洛（MC）和时序差分（TD）方法无需环境模型，通过与环境交互直接学习。

Ch.5时序差分算法

核心思想

时序差分（Temporal Difference, TD）方法结合了蒙特卡洛的无模型采样和动态规划的自举（bootstrapping），在每一步交互后立即更新价值估计，无需等待整条轨迹结束。

5.1 TD 学习基本思想

三种方法的回报对比

方法更新目标特点
动态规划 \(\sum_a \pi(a|s)\left[R + \gamma \sum_{s'} P\cdot V(s')\right]\) 需要模型，无采样
蒙特卡洛 \(G_t = r_{t+1} + \gamma r_{t+2} + \gamma^2 r_{t+3} + \cdots\) 无模型，需完整轨迹，无偏但高方差
TD(0) \(r_{t+1} + \gamma V(s_{t+1})\) 无模型，单步更新，有偏但低方差

TD(0) 更新规则

$$V(s_t) \leftarrow V(s_t) + \alpha \underbrace{\left[r_{t+1} + \gamma V(s_{t+1}) - V(s_t)\right]}_{\delta_t \text{（TD 误差）}}$$
TD 误差（Temporal Difference Error）：
$$\delta_t = r_{t+1} + \gamma V(s_{t+1}) - V(s_t)$$
  • \(\delta_t > 0\)：实际回报优于预期，上调 \(V(s_t)\)
  • \(\delta_t < 0\)：实际回报劣于预期，下调 \(V(s_t)\)
  • \(\delta_t = 0\)：预测准确，无需更新

TD 误差与蒙特卡洛回报的关系

$$G_t - V(s_t) = \sum_{k=0}^{T-t-1} \gamma^k \delta_{t+k}$$

蒙特卡洛误差可分解为 TD 误差的加权累积和，揭示了两者的内在联系。

5.2 Sarsa（On-Policy TD 控制）

命名来源：Sarsa 由五元组 \((s_t,\, a_t,\, r_{t+1},\, s_{t+1},\, a_{t+1})\) 的首字母组成，完整描述了一次转移所需的全部信息。

完整更新公式

$$Q(s_t, a_t) \leftarrow Q(s_t, a_t) + \alpha \Big[\underbrace{r_{t+1} + \gamma\, Q(s_{t+1}, a_{t+1})}_{\text{TD 目标}} - Q(s_t, a_t)\Big]$$

On-Policy 特性

On-Policy 定义

行为策略（用于与环境交互采集数据）= 目标策略（被优化的策略）

Sarsa 使用 \(\varepsilon\)-贪婪策略同时扮演两个角色：

$$\pi(a|s) = \begin{cases} 1 - \varepsilon + \varepsilon/|\mathcal{A}| & \text{若 } a = \arg\max_{a'} Q(s,a') \\ \varepsilon/|\mathcal{A}| & \text{其他} \end{cases}$$

因此 Sarsa 学到的是最优 \(\varepsilon\)-贪婪策略，而非纯贪婪最优策略。

收敛条件

  • 学习率满足 Robbins-Monro 条件：\(\sum_t \alpha_t = \infty\)，\(\sum_t \alpha_t^2 < \infty\)
  • 所有 \((s,a)\) 对被无限次访问（探索充分）
  • \(\varepsilon \to 0\) 的速率足够慢

5.3 Q-learning（Off-Policy TD 控制）

完整更新公式

$$Q(s_t, a_t) \leftarrow Q(s_t, a_t) + \alpha \Big[\underbrace{r_{t+1} + \gamma \max_{a'} Q(s_{t+1}, a')}_{\text{TD 目标（贪婪）}} - Q(s_t, a_t)\Big]$$

Off-Policy 特性

Off-Policy 定义

行为策略（\(\varepsilon\)-贪婪，负责探索）≠ 目标策略（纯贪婪 \(\pi^* = \arg\max Q\)）

Q-learning 直接对贪婪目标策略进行优化，与行为策略无关，因此可以用任意探索策略收集数据。

收敛性证明思路
将 Q-learning 写成随机近似（Stochastic Approximation）形式
$$Q_{t+1}(s,a) = Q_t(s,a) + \alpha_t(s,a)\left[F(Q_t, s, a) + \varepsilon_t\right]$$

其中 \(F(Q,s,a) = R(s,a) + \gamma \sum_{s'} P(s'|s,a)\max_{a'}Q(s',a') - Q(s,a)\)，\(\varepsilon_t\) 为零均值噪声。

验证贝尔曼最优算子 \(T^*\) 是 \(\gamma\)-压缩
$$\|T^*Q - T^*Q'\|_\infty \leq \gamma\|Q - Q'\|_\infty$$
应用 Watkins-Dayan 定理（随机近似引理）

满足 Robbins-Monro 条件 + 所有 \((s,a)\) 无限次访问 + 奖励有界，则 Q-learning 以概率 1 收敛到 \(Q^*\)。

Q-learning vs Sarsa：悬崖漫步实验

经典对比实验

悬崖漫步（Cliff Walking）：网格世界，靠近悬崖边缘奖励为 -100，到达目标奖励为 0，其余步 -1。

算法学到的路径原因在线表现
Sarsa 保守路径（远离悬崖） On-policy，考虑 \(\varepsilon\)-探索时偶尔会跌落悬崖，因此绕远路 在线累积奖励较高
Q-learning 激进路径（紧贴悬崖） Off-policy，优化贪婪策略（最短路），不考虑探索时的意外 在线累积奖励较低

5.4 多步 TD（n-step TD）

n 步回报定义

$$G_t^{(n)} = r_{t+1} + \gamma r_{t+2} + \gamma^2 r_{t+3} + \cdots + \gamma^{n-1} r_{t+n} + \gamma^n V(s_{t+n})$$

对应的 n 步 TD 更新：

$$V(s_t) \leftarrow V(s_t) + \alpha\left[G_t^{(n)} - V(s_t)\right]$$

特殊情形

n 值退化为更新目标
\(n = 1\) TD(0) \(r_{t+1} + \gamma V(s_{t+1})\)
\(n = 2\) 2-step TD \(r_{t+1} + \gamma r_{t+2} + \gamma^2 V(s_{t+2})\)
\(n \to \infty\) 蒙特卡洛 \(G_t = \sum_{k=0}^{\infty} \gamma^k r_{t+k+1}\)
方差-偏差权衡（Bias-Variance Tradeoff）：
  • 小 n（TD）：自举强，偏差高（依赖不准确的 \(V\) 估计），方差低（仅用少量随机步骤）
  • 大 n（MC）：自举弱，偏差低（使用真实回报），方差高（累积多步随机奖励）
  • 最优 n：通常在中间值，具体取决于任务特性

6.2 Dyna-Q 框架

核心组件

模型学习

Dyna-Q 使用一个确定性查找表模型，存储每个 \((s,a)\) 对最近一次观测到的结果：

$$\text{Model}(s, a) \leftarrow (r, s') \quad \text{（每次真实交互后更新）}$$

对于随机环境，可扩展为存储 \((r, s')\) 的经验分布。

Q-Planning（虚拟经验更新）

从已访问过的 \((s,a)\) 中随机采样，用模型生成虚拟转移，执行 Q-learning 更新：

$$\text{采样 }(s, a) \sim \text{已访问集合}$$ $$(r, s') \leftarrow \text{Model}(s, a)$$ $$Q(s, a) \leftarrow Q(s, a) + \alpha\left[r + \gamma \max_{a'} Q(s', a') - Q(s, a)\right]$$

完整算法流程

// Dyna-Q 算法
Algorithm DynaQ(α, γ, ε, n_planning):
  // 初始化
  for all s, a: Q[s,a] ← 0
  Model ← empty dict

  for each episode:
    s ← env.reset()

    for each step:
      // (1) 选择动作（ε-贪婪）
      a ← ε-greedy(Q[s, ·])

      // (2) 真实交互，获取 (r, s')
      r, s' ← env.step(a)

      // (3) 直接 Q-learning 更新（真实数据）
      Q[s,a] ← Q[s,a] + α · [r + γ · max_a' Q[s',a'] - Q[s,a]]

      // (4) 更新环境模型
      Model[s, a] ← (r, s')

      // (5) 规划：用模型生成虚拟经验，重复 n_planning 次
      repeat n_planning times:
        s_sim, a_sim ← random sample from Model.keys()
        r_sim, s'_sim ← Model[s_sim, a_sim]
        Q[s_sim,a_sim] ← Q[s_sim,a_sim] + α · [r_sim + γ · max_a' Q[s'_sim,a'] - Q[s_sim,a_sim]]

      s ← s'
      if s is terminal: break

动态规划（DP）有两条主路：策略迭代和价值迭代。两者的共同核心是反复把贝尔曼方程当作"刷新规则"，每刷一轮就让价值估计更接近真值，直到变化量小到可以忽略为止。下面通过一个具体数值案例，完整走一遍策略迭代的两个阶段。

案例设定：4 状态线性链

环境描述：
  • 状态空间：\(s_1 \to s_2 \to s_3 \to s_4\)，\(s_4\) 为终止状态（价值固定为 0）
  • 动作空间：每个非终止状态可选 左（L） 或 右（R）
  • 转移：确定性，向左/右移动一格；\(s_1\) 向左原地不动，\(s_3\) 向右到达 \(s_4\)
  • 奖励：进入 \(s_4\) 获得 \(r = +1\)，其余所有转移 \(r = 0\)
  • 折扣因子 \(\gamma = 0.9\)

第一轮：策略评估——计算"一直向右"的 \(V^\pi\)

初始策略 \(\pi_0\)：所有状态均选 右（R）。初始化 \(V_0 = [0,\,0,\,0,\,0]\)，对每个状态反复应用：

$$V_{k+1}(s) = \sum_a \pi(a|s)\left[R(s,a) + \gamma \sum_{s'} P(s'|s,a)\, V_k(s')\right]$$

由于策略确定（\(\pi(R|s)=1\)），更新退化为：

$$V_{k+1}(s_i) = R(s_i,\,R) + \gamma\, V_k(s_{i+1})$$
迭代轮次 \(k\) \(V(s_1)\) \(V(s_2)\) \(V(s_3)\) \(V(s_4)\)（固定） \(\Delta = \max|V_{k+1}-V_k|\)
初始（\(k=0\)）0000—
\(k=1\) \(0 + 0.9 \times 0 = 0\) \(0 + 0.9 \times 0 = 0\) \(1 + 0.9 \times 0 = 1\) 0 1.000
\(k=2\) \(0 + 0.9 \times 0 = 0\) \(0 + 0.9 \times 1 = 0.9\) \(1 + 0.9 \times 0 = 1\) 0 0.900
\(k=3\) \(0 + 0.9 \times 0.9 = 0.81\) \(0 + 0.9 \times 1 = 0.9\) 1 0 0.810
\(k=4\)（收敛） 0.81 0.90 1.00 0 < 1e-6
直觉：奖励信号从 \(s_4\) 向左"反向传播"。每迭代一轮，信号多传递一格，所以需要 3 轮才能让 \(s_1\) 的价值从 0 变为 0.81（= \(0.9^2 \times 1\)，即距离目标两步的折扣价值）。

第二轮：策略提升——更新策略

用已收敛的 \(V^{\pi_0} = [0.81,\;0.9,\;1,\;0]\) 计算每个状态的贪婪动作：

$$\pi_1(s) = \arg\max_a \left[R(s,a) + \gamma \sum_{s'} P(s'|s,a)\, V^{\pi_0}(s')\right]$$
状态 选 Left 的价值 选 Right 的价值 新策略 \(\pi_1\)
\(s_1\)（向左原地） \(0 + 0.9 \times V(s_1) = 0.729\) \(0 + 0.9 \times V(s_2) = 0.81\) 右（Right）
\(s_2\) \(0 + 0.9 \times V(s_1) = 0.729\) \(0 + 0.9 \times V(s_3) = 0.9\) 右（Right）
\(s_3\) \(0 + 0.9 \times V(s_2) = 0.81\) \(1 + 0.9 \times 0 = 1.0\) 右（Right）

\(\pi_1 = \pi_0\)（均为一直向右），策略未变，策略迭代终止，输出最优策略 \(\pi^* = \text{一直向右}\)，对应最优价值函数：

$$V^* = \bigl[0.81,\;\;0.9,\;\;1.0,\;\;0\bigr]$$ $$\text{验证：} V^*(s_1) = \gamma^2 \cdot 1 = 0.9^2 = 0.81,\quad V^*(s_2) = \gamma \cdot 1 = 0.9,\quad V^*(s_3) = 1$$

与价值迭代的对比

如果改用价值迭代，把贝尔曼最优算子直接代替策略评估：

$$V_{k+1}(s) = \max_a\left[R(s,a) + \gamma V_k(s'(s,a))\right]$$

在本例中，每个状态"向右"始终优于"向左"，因此价值迭代与策略评估轨迹完全一致，同样 3 轮收敛。对于更复杂的 MDP（不同状态最优动作不同），价值迭代省去内层收敛循环，每轮代价更低，但需要更多轮次才能令策略稳定。

关键规律总结：
  • 传播方向：DP 的价值信号从"奖励来源"沿贝尔曼方程向周围状态扩散，每轮扩散一步
  • 收敛速率：由压缩系数 \(\gamma\) 决定——\(\gamma = 0.9\) 时误差每轮缩小 10 倍（几何收敛）
  • 完全更新：每轮必须扫描所有状态；状态数 \(|\mathcal{S}|\) 越大，单轮代价越高（维度灾难的根源）

价值迭代具体怎么做？

A

价值迭代只做一件事：反复把贝尔曼最优方程当更新规则刷 \(V\)，直到收敛，最后一次性提取贪婪策略。全程不需要维护显式策略，也没有"内层评估循环"。

算法三步

初始化

令所有状态 \(V_0(s) = 0\)（终止状态保持 0，不参与更新）。

反复用贝尔曼最优算子刷新
$$V_{k+1}(s) = \max_{a \in \mathcal{A}}\left[R(s,a) + \gamma \sum_{s'} P(s'|s,a)\,V_k(s')\right]$$

每轮扫描所有状态做一次更新，记录最大变化量 \(\Delta = \max_s|V_{k+1}(s)-V_k(s)|\)，直到 \(\Delta \lt \theta\) 停止。

提取贪婪策略
$$\pi^*(s) = \arg\max_{a}\left[R(s,a) + \gamma \sum_{s'} P(s'|s,a)\,V^*(s')\right]$$

对收敛后的 \(V^*\) 做一次贪婪选择，得到最优策略。

为什么时序差分算法的更新公式是 \(V(s_t) \leftarrow V(s_t) + \alpha[r_{t+1} + \gamma V(s_{t+1}) - V(s_t)]\)？

A

这条公式不是凑出来的，它由三个相互独立的思想组合推导得到：价值函数的目标定义、贝尔曼方程的递推结构、随机近似的更新形式。下面逐层拆解。

第一层：更新目标从哪里来？

我们希望 \(V(s_t)\) 收敛到真实值 \(V^\pi(s_t) = \mathbb{E}_\pi[G_t \mid s_t]\)。在线学习中，每次只能观测到一条样本轨迹，标准做法是用随机梯度下降最小化均方误差：

$$\min_{V}\;\mathbb{E}\!\left[(G_t - V(s_t))^2\right]$$

对 \(V(s_t)\) 求梯度并取一步负梯度更新：

$$V(s_t) \;\leftarrow\; V(s_t) + \alpha\underbrace{[T - V(s_t)]}_{\text{误差} = \text{目标} - \text{当前估计}}$$

这就是 "误差乘以学习率" 的通用形式。现在问题变成：目标 \(T\) 用什么？

第二层：为什么不直接用 \(G_t\)？

蒙特卡洛方法令 \(T = G_t = r_{t+1} + \gamma r_{t+2} + \cdots\)，是无偏估计，但必须等整条轨迹走完才能计算，无法在线更新，不支持连续任务。

TD 的思路是：把 \(G_t\) 用贝尔曼方程拆成两部分——

$$G_t = r_{t+1} + \gamma G_{t+1}$$

对两侧取期望（以 \(s_t\) 为条件）：

$$V^\pi(s_t) = \mathbb{E}_\pi\!\left[r_{t+1} + \gamma\, V^\pi(s_{t+1})\right]$$

右侧 \(r_{t+1} + \gamma V^\pi(s_{t+1})\) 就是贝尔曼方程的期望形式，是 \(G_t\) 的单步展开版本。

第三层：自举（Bootstrapping）——用估计替换未知量

上式右侧的 \(V^\pi(s_{t+1})\) 是真实值，我们不知道。TD 的核心操作是用当前的估计值 \(V(s_{t+1})\) 代替 \(V^\pi(s_{t+1})\)，同时只对期望取一次样本，得到：

$$T_{\text{TD}} = r_{t+1} + \gamma\, V(s_{t+1}) \quad \text{（TD 目标，one-step bootstrap）}$$
这里有个微妙之处：\(T_{\text{TD}}\) 是有偏估计（因为 \(V(s_{t+1}) \neq V^\pi(s_{t+1})\)），但随着迭代，\(V\) 不断向 \(V^\pi\) 逼近，偏差越来越小，最终消失。这是"用自身引导自身"——这就是自举的含义。

三层组合，得到最终公式

推导路径
目标：向真实价值移动
$$V(s_t) \leftarrow V(s_t) + \alpha\left[T - V(s_t)\right]$$
贝尔曼方程给出目标结构
$$T = r_{t+1} + \gamma\, V^\pi(s_{t+1})$$
自举：用当前估计 \(V(s_{t+1})\) 替换未知 \(V^\pi(s_{t+1})\)
$$T_{\text{TD}} = r_{t+1} + \gamma\, V(s_{t+1})$$
代入，得 TD(0) 更新规则
$$\boxed{V(s_t) \leftarrow V(s_t) + \alpha\underbrace{\left[r_{t+1} + \gamma V(s_{t+1}) - V(s_t)\right]}_{\delta_t\;\text{（TD 误差）}}}$$

每一项的含义

符号含义角色
\(\alpha\) 学习率（步长） 控制每次更新的幅度；\(\alpha\) 过大震荡，过小收敛慢
\(r_{t+1} + \gamma V(s_{t+1})\) TD 目标 用下一步的即时奖励 + 折扣后的下一状态估计值，作为"更好的目标"
\(V(s_t)\) 当前估计 被更新的量
\(\delta_t = r_{t+1} + \gamma V(s_{t+1}) - V(s_t)\) TD 误差 目标与当前估计的差距；\(\delta_t = 0\) 时恰好满足贝尔曼方程，无需更新

与蒙特卡洛、动态规划的对比

方法更新目标 \(T\)需要模型？需要完整轨迹？
动态规划 \(\sum_a\pi(a|s)\left[R(s,a)+\gamma\sum_{s'}P(s'|s,a)V(s')\right]\)（全期望） 是否
蒙特卡洛 \(G_t = r_{t+1}+\gamma r_{t+2}+\cdots\)（真实回报） 否是
TD(0) \(r_{t+1}+\gamma V(s_{t+1})\)（单步自举） 否否
本质：TD = MC 的"提前截断" + DP 的"自举"
MC 对 \(G_t\) 展开无限步；DP 对期望精确积分。TD 只展开一步，剩下的用当前估计 \(V(s_{t+1})\) 补齐，从而既不需要环境模型，也不需要等到轨迹结束——这正是它在在线、连续任务中有实用价值的根本原因。

Sarsa 具体如何做？请提供案例。

A

Sarsa 是把 TD 思路从"评估价值函数 \(V\)"扩展到"直接学习动作价值函数 \(Q\)"的在策略（on-policy）控制算法。理解它需要先回答两个前置问题：为什么要用 \(Q\)，以及为什么要"五元组"。

为什么用 \(Q(s,a)\) 而不是 \(V(s)\)？

TD(0) 学的是 \(V(s_t)\)，但 无模型 时没法从 \(V\) 直接推出最优动作——选动作需要知道 \(R(s,a)\) 和 \(P(s'|s,a)\)（贪婪公式含模型）。直接学 \(Q(s,a)\) 则不需要模型： $$\pi(s) = \arg\max_a Q(s,a)$$ 不依赖转移概率，只需查表比较。

为什么叫"五元组"？

Sarsa 的一次更新需要 \((s_t,\;a_t,\;r_{t+1},\;s_{t+1},\;a_{t+1})\) 五个量：

元素作用
\(s_t\)当前状态——被更新的 Q 表格行
\(a_t\)当前动作——被更新的 Q 表格列
\(r_{t+1}\)即时奖励——TD 目标的即时部分
\(s_{t+1}\)下一状态——查 Q 表做自举
\(a_{t+1}\)下一动作——on-policy 的关键，必须由当前策略选出，而非取 max
$$Q(s_t,a_t) \leftarrow Q(s_t,a_t) + \alpha\underbrace{\bigl[r_{t+1}+\gamma\,Q(s_{t+1},a_{t+1})-Q(s_t,a_t)\bigr]}_{\delta_t}$$

与 TD(0) 对比：把 \(V(s_{t+1})\) 换成 \(Q(s_{t+1},a_{t+1})\)，其余结构完全一样。

案例设定：3 状态链

  • 状态：\(A \to B \to C\)，其中 \(C\) 为终止状态
  • 动作：左（L） 或 右（R）；\(A\) 向左原地不动
  • 奖励：\(B \xrightarrow{R} C\) 得 \(+1\)，其余转移得 \(0\)
  • 参数：\(\gamma=0.9\)，\(\alpha=0.5\)，\(\varepsilon=0.1\)（\(\varepsilon\)-贪婪）
  • 初始 Q 表：所有 \(Q(s,a)=0\)

每幕的执行流程

每幕开始于状态 \(A\)，以到达 \(C\) 结束。先选好 \(a_t\)，执行后再选 \(a_{t+1}\)，然后立即更新 \(Q(s_t,a_t)\)，再把 \((s_{t+1},a_{t+1})\) 作为下一步的起点。

第 1 幕（Q 全为 0，动作随机）

步骤 1：在 \(A\) 选动作。\(Q(A,L)=Q(A,R)=0\)，随机选 \(a_0=R\)（向右）。

执行 \(R\)：到达 \(B\)，\(r_1=0\)。

在 \(B\) 选 \(a_1\)：\(Q(B,L)=Q(B,R)=0\)，随机选 \(a_1=R\)。

$$Q(A,R) \leftarrow 0 + 0.5\bigl[0 + 0.9\times\underbrace{Q(B,R)}_{0} - 0\bigr] = \mathbf{0}$$

步骤 2：在 \(B\) 执行 \(R\)：到达 \(C\)，\(r_2=+1\)。\(C\) 为终止，\(Q(C,\cdot)=0\)。

$$Q(B,R) \leftarrow 0 + 0.5\bigl[1 + 0.9\times 0 - 0\bigr] = \mathbf{0.5}$$
第 2 幕（Q(B,R)=0.5 已更新）

步骤 1：在 \(A\) 选动作。\(Q(A,R)=0=Q(A,L)\)，仍随机，选 \(a_0=R\)。

执行：到达 \(B\)，\(r_1=0\)。

在 \(B\) 选 \(a_1\)：\(Q(B,R)=0.5 > Q(B,L)=0\)，\(\varepsilon\)-贪婪选 \(a_1=R\)（概率 \(0.9+0.05=0.95\)）。

$$Q(A,R) \leftarrow 0 + 0.5\bigl[0 + 0.9\times\underbrace{Q(B,R)}_{0.5} - 0\bigr] = 0.5\times0.45 = \mathbf{0.225}$$

步骤 2：在 \(B\) 执行 \(R\)：到 \(C\)，\(r_2=+1\)。

$$Q(B,R) \leftarrow 0.5 + 0.5\bigl[1 + 0 - 0.5\bigr] = \mathbf{0.75}$$
第 3 幕（Q 持续增大）

步骤 1：\(Q(A,R)=0.225>Q(A,L)=0\)，\(\varepsilon\)-贪婪选 \(R\)。执行：到 \(B\)，\(r_1=0\)。

在 \(B\)：\(Q(B,R)=0.75>Q(B,L)=0\)，选 \(a_1=R\)。

$$Q(A,R) \leftarrow 0.225 + 0.5\bigl[0 + 0.9\times0.75 - 0.225\bigr] = 0.225+0.5\times0.45=\mathbf{0.45}$$

步骤 2：\(B\) 执行 \(R\)：\(r_2=+1\)。

$$Q(B,R) \leftarrow 0.75 + 0.5\bigl[1 + 0 - 0.75\bigr] = \mathbf{0.875}$$

  a ← ε-greedy(Q[s, ·])  // 先选好第一个动作

    执行 a，观测 r, s'
    a' ← ε-greedy(Q[s', ·])  // 用当前策略选下一动作

    // Sarsa 更新：用 (s,a,r,s',a') 五元组
    Q[s,a] ← Q[s,a] + α · (r + γ·Q[s',a'] - Q[s,a])

    s ← s';  a ← a'   // 滚动向前，a' 不重新选
    if s is terminal: break
On-Policy 的关键细节：\(a_{t+1}\) 必须用 当前 \(\varepsilon\)-贪婪策略 选出，而不是取 \(\max\)。这意味着 Sarsa 学到的 \(Q\) 值反映了"带探索的策略"的真实价值——在有悬崖的环境中，它会把偶尔走错边的风险计入价值，因此学到更保守的路线（而 Q-learning 取 \(\max\)，默认自己不会走错，学到更激进的最短路）。
Q

Q-learning 具体如何做？请提供案例。

A

Q-learning 与 Sarsa 的公式结构几乎相同，只有一处关键差异：更新时不使用实际执行的下一动作 \(a_{t+1}\)，而是直接对下一状态取 \(\max\)。这一字之差决定了它是 off-policy 算法。

更新公式对比

Sarsa（on-policy）Q-learning（off-policy）
更新目标 \(r_{t+1}+\gamma\,Q(s_{t+1},\,\textbf{a}_{t+1})\) \(r_{t+1}+\gamma\,\textbf{max}_{a'}Q(s_{t+1},\,a')\)
需要提前选 \(a_{t+1}\)？ 是（更新前必须知道） 否（只需 \(s_{t+1}\)）
学习的是哪个策略的价值 当前 \(\varepsilon\)-贪婪策略 贪婪最优策略（与探索行为无关）
$$Q(s_t,a_t)\leftarrow Q(s_t,a_t)+\alpha\bigl[\underbrace{r_{t+1}+\gamma\max_{a'}Q(s_{t+1},a')}_{\text{TD 目标（贪婪）}}-Q(s_t,a_t)\bigr]$$

案例：与 Sarsa 相同的 3 状态链

设定与 Sarsa 问答完全一致： \(A\to B\to C\)（终止），\(B\xrightarrow{R}C\) 得 \(+1\)，其余得 \(0\)，\(\gamma=0.9\)，\(\alpha=0.5\)，\(\varepsilon=0.1\)，初始 \(Q=0\)。
第 1 幕

步骤 1：在 \(A\) 选 \(R\)（随机），执行后到 \(B\)，\(r=0\)。

更新 \(Q(A,R)\)，只需知道 \(s_{t+1}=B\)，无需提前选 \(a_{t+1}\)：

$$Q(A,R)\leftarrow 0+0.5\bigl[0+0.9\times\underbrace{\max(Q(B,L),Q(B,R))}_{=0}-0\bigr]=\mathbf{0}$$

步骤 2：在 \(B\) 选 \(R\)（随机），执行后到 \(C\)，\(r=+1\)。

$$Q(B,R)\leftarrow 0+0.5\bigl[1+0.9\times\underbrace{\max_{a'}Q(C,a')}_{=0}-0\bigr]=\mathbf{0.5}$$
第 2 幕

步骤 1：在 \(A\) 随机选 \(R\)，到 \(B\)，\(r=0\)。

$$Q(A,R)\leftarrow 0+0.5\bigl[0+0.9\times\underbrace{\max(0,\,0.5)}_{=0.5}-0\bigr]=\mathbf{0.225}$$

步骤 2：在 \(B\) 选 \(R\)（贪婪），到 \(C\)，\(r=+1\)。

$$Q(B,R)\leftarrow 0.5+0.5\bigl[1+0-0.5\bigr]=\mathbf{0.75}$$
第 3 幕

步骤 1：在 \(A\) 贪婪选 \(R\)，到 \(B\)，\(r=0\)。

$$Q(A,R)\leftarrow 0.225+0.5\bigl[0+0.9\times\underbrace{\max(0,\,0.75)}_{=0.75}-0.225\bigr]=\mathbf{0.45}$$

步骤 2：在 \(B\) 选 \(R\)，到 \(C\)，\(r=+1\)。

$$Q(B,R)\leftarrow 0.75+0.5\bigl[1+0-0.75\bigr]=\mathbf{0.875}$$

Off-Policy 的真正含义：探索不污染学习

在简单直线环境中 Q-learning 与 Sarsa 数值相同。差异在 行为策略走了次优动作 时才显现。以下是关键场景对比：

场景：当前 \(Q(B,R)=0.5\)，\(Q(B,L)=0\)，\(Q(A,R)=0.225\)，\(Q(A,L)=0\)。
智能体处于 \(B\)，\(\varepsilon\)-探索触发，意外选了 \(L\)（走回 \(A\)），\(r=0\)。
然后又在 \(A\) 随机选了 \(L\)（原地不动）。
SarsaQ-learning
更新 \(Q(B,L)\) 时用什么目标 \(r+\gamma\,Q(A,\,\textbf{a}_{t+1})\)
\(=0+0.9\times Q(A,L)=0\)
（实际选了 L，\(Q(A,L)=0\)）		 \(r+\gamma\,\textbf{max}_{a'}Q(A,a')\)
\(=0+0.9\times Q(A,R)=0.203\)
（不管实际选了什么，取最优 R）
\(Q(B,L)\) 更新后 \(0+0.5\times[0-0]=\mathbf{0}\) \(0+0.5\times0.203=\mathbf{0.101}\)
意义 Sarsa 认为"从 \(B\) 走左"很差，因为探索时下一步也走了差动作 Q-learning 认为"从 \(B\) 走左回 \(A\)，再从 \(A\) 走最优路"有 0.101 的价值——不受探索行为影响
核心结论：Q-learning 的 \(\max\) 让它始终在学"如果此后执行最优策略能得到多少"，即 \(Q^*\)，与实际行为无关。Sarsa 学的是"在当前 \(\varepsilon\)-贪婪策略下能得到多少"，探索带来的代价会被计入 \(Q\) 值。这直接导致了悬崖漫步实验中的差异：Sarsa 把悬崖边缘的探索风险计入价值，所以选择远离悬崖的保守路线；Q-learning 忽略探索风险，选最短的危险路。

算法完整流程（伪代码）

// Q-learning 算法
for each episode:
  s ← 初始状态

  for each step:
    a ← ε-greedy(Q[s, ·])   // 行为策略：探索用
    执行 a，观测 r, s'

    // Q-learning 更新：只需 (s,a,r,s')，无需 a'
    Q[s,a] ← Q[s,a] + α · (r + γ · max_a' Q[s',a'] - Q[s,a])

    s ← s'   // 不需要滚动 a'
    if s is terminal: break
与 Sarsa 伪代码的差异只有两处：
  1. 不需要在循环顶部提前选 \(a\)（上一步末尾不保留 \(a'\)）
  2. 更新公式里 \(Q(s_{t+1}, a_{t+1})\) 换成 \(\max_{a'} Q(s_{t+1}, a')\)
这两处改动使 Q-learning 可以用任意行为策略采集数据（经验回放、多智能体共享数据等），是 DQN 等深度 RL 算法的直接前身。
Q

蒙特卡洛方法是怎么做的？请提供案例。

A

蒙特卡洛（MC）方法的核心思想极简单：把整条轨迹走完，算出真实回报 \(G_t\)，直接用它更新价值估计。没有自举，没有环境模型，代价是必须等到幕结束才能更新。

算法三步

完整采集一幕轨迹

按当前策略与环境交互，记录所有 \((s_t, a_t, r_{t+1})\)，直到终止状态。

从轨迹末尾向前计算各时刻的真实回报 \(G_t\)
$$G_T = 0\quad(\text{终止状态}),\qquad G_t = r_{t+1} + \gamma\, G_{t+1}$$

从后往前递推，每步 \(O(1)\)，效率高于正向求和。

用 \(G_t\) 更新访问到的状态的价值估计
$$V(s_t)\leftarrow V(s_t)+\alpha\bigl[G_t - V(s_t)\bigr]$$

与 TD 公式结构相同，差别只在"目标"：TD 用 \(r+\gamma V(s')\)（自举），MC 用真实 \(G_t\)（无自举）。

首次访问 vs 每次访问

一幕内同一状态可能被多次访问，两种变体处理方式不同：

首次访问 MC（First-Visit）每次访问 MC（Every-Visit）
更新时机 每个状态只取本幕第一次访问时的 \(G_t\) 本幕每次访问都用对应的 \(G_t\) 更新
无偏性 对真实 \(V^\pi(s)\) 无偏 有轻微偏差（同幕内重复访问相关），但方差更低
常用场景 理论分析、收敛证明 实践中更常用

案例：含状态重访的轨迹

环境：与 Sarsa/Q-learning 案例相同——状态 \(A,B,C\)（\(C\) 终止），\(B\xrightarrow{R}C\) 得 \(+1\)，其余得 \(0\)，\(\gamma=0.9\)，\(\alpha=0.5\)，初始 \(V=0\)。
本幕轨迹（含一次探索回头）： $$A\xrightarrow{R,\;r=0}B\xrightarrow{L,\;r=0}A\xrightarrow{R,\;r=0}B\xrightarrow{R,\;r=+1}C$$

第一步：从末尾向前算 \(G_t\)

时刻 \(t\)状态动作奖励 \(r_{t+1}\)计算过程\(G_t\)
终止\(C\)——\(G_T=0\)0
3\(B\)\(R\)\(+1\) \(G_3=1+0.9\times0\)1.0
2\(A\)\(R\)\(0\) \(G_2=0+0.9\times1.0\)0.9
1\(B\)\(L\)\(0\) \(G_1=0+0.9\times0.9\)0.81
0\(A\)\(R\)\(0\) \(G_0=0+0.9\times0.81\)0.729

第二步：更新价值函数

首次访问 MC

状态 \(A\) 首次出现在 \(t=0\)，\(G=0.729\)；状态 \(B\) 首次出现在 \(t=1\)，\(G=0.81\)。\(t=2,3\) 的重访跳过。

$$V(A)\leftarrow 0+0.5\times(0.729-0)=\mathbf{0.365}$$ $$V(B)\leftarrow 0+0.5\times(0.81-0)=\mathbf{0.405}$$
每次访问 MC

\(t=0,2\) 都更新 \(V(A)\)；\(t=1,3\) 都更新 \(V(B)\)（按顺序依次执行）：

$$V(A)\xleftarrow{t=0}0+0.5\times(0.729-0)=0.365$$ $$V(B)\xleftarrow{t=1}0+0.5\times(0.81-0)=0.405$$ $$V(A)\xleftarrow{t=2}0.365+0.5\times(0.9-0.365)=\mathbf{0.633}$$ $$V(B)\xleftarrow{t=3}0.405+0.5\times(1.0-0.405)=\mathbf{0.703}$$

每次访问 MC 在同一幕内把第二次更高的 \(G\) 也利用了，使价值更快上升。

真值收敛方向验证（最优策略一直向右）： $$V^\pi(A)=0+0.9\times V^\pi(B)=0.9\times0.9=0.81,\quad V^\pi(B)=0+0.9\times1=0.90$$ 两个变体的值均在向真值 \([0.81,\;0.90]\) 收敛。

MC 用于控制（学 \(Q\) 而非 \(V\)）

无模型时无法从 \(V\) 推出最优动作，MC 控制同样改学 \(Q(s,a)\)：

$$Q(s_t,a_t)\leftarrow Q(s_t,a_t)+\alpha\bigl[G_t-Q(s_t,a_t)\bigr]$$

每个状态-动作对 \((s_t,a_t)\) 在轨迹中的首次（或每次）出现都用对应的 \(G_t\) 更新。需要保持 \(\varepsilon\)-贪婪探索确保所有 \((s,a)\) 被充分访问。
