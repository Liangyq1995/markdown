1.1 总体介绍

Boogu-Image-0.1 是一个开源的统一多模态理解与生成模型族，包含 Base / Turbo / Edit / Edit-Turbo 四类变体，覆盖高质量文生图 (T2I)、快速推理、指令式图像编辑 (TI2I) 与中英双语文字渲染四类核心能力。论文的核心论点是：闭源系统（如 Nano-Banana-Pro、GPT-Image-2）的强大表现来自系统级集成而非单一模型，其内部实践大多不公开；Boogu 团队证明，只要在模型理解能力、数据质量、训练管线三条轴线上做针对性改进，并叠加 agentic inference-time scaling（由 Deepseek-V4-Flash 驱动的智能体重写 prompt、路由模型、做 reflection），即便在高度受限的算力预算下也能大幅提升生成与编辑性能。

关键数字（原文）：

  • 整个训练管线仅使用 2.0862 亿（208.62M）张唯一图像；
  • 基础模型理论训练成本仅约 40 万美元（$400K）；
  • Boogu Syllabus 仅含 21.62M 唯一样本，按预设权重上采样到 47.19M，性能即显著超过训练于 187M 原始开源数据的模型；
  • DiT 基础模型约 10B（10,292.56M）可训练参数，叠加可选 Prompt Tuning Transformer 后为 11,022.55M；
  • 在 Boogu Arena 上，Boogu 系列在开源梯队中全面领先，仅次于闭源前沿 GPT-Image-2（Elo 1196）与 Nano-Banana-Pro（Elo 1087）；Boogu-Turbo-Thinking 达 Elo 1048。

论文将"理解 (understanding)"提升为与数据质量、训练配方、推理管线并列的一等设计目标，并提出图像生成正从 Text-to-Image 迈向 Requirement-to-Image 范式：用户不再满足于单一描述性 prompt，而期望模型解读复杂意图、隐式约束、多层级指令与跨模态上下文线索。围绕这一目标，Boogu 把理解分解为三个互补维度——理解用户意图（text encoder + prompt rewriter）、理解训练图像（caption 策略）、理解任务复杂度（inference-time 模型路由）——分别针对当前 T2I 管线中不同来源的误差。

2. 研究背景与动机

2.1 统一多模态理解与生成的演进

论文在 Appendix B 系统梳理了视觉合成从孤立生成任务走向集成多模态框架的轨迹，可分为四条脉络：

  • Text-to-Image 扩散模型：扩散模型 [DDPM] 奠基，LDM 与 DALL-E 2 确立了高保真文本条件生成范式；DALL-E 3 通过 recaption 数据集提升 prompt 遵从；架构从 U-Net 转向 Transformer（DiT）解锁可扩展性，SD3 的 rectified flow 与 Sora 的视频生成进一步推动，最终汇聚为闭源的 Nano-Banana 系列与 ChatGPT Images 系列。
  • 可控生成与编辑：ControlNet 引入辅助条件以尊重空间线索（深度/姿态）；InstructPix2Pix 开创指令驱动编辑，无需复杂手工掩膜。
  • 视觉-语言模型 (VLM)：LLaVA 将 ViT 与 LLM 对齐；Ovis、Qwen-VL 系列精化结构对齐与视觉推理，支持高分辨率输入。
  • 统一多模态生成：OmniGen / OmniGen2 率先在单一框架内原生处理多种生成与编辑任务；闭源 Nano-Banana 系列通过 interleaved prompt 引入推理引导合成；开源 Qwen-Image、Z-Image 将深度视觉理解与可扩展高效生成结合。

2.2 闭源系统级集成 vs 单一模型

论文反复强调一个判断：闭源系统的强大来自系统级集成而非单一模型。观察到的事实线索包括：GPT-Image-2 生成"a beautiful girl"这类极简 prompt 时，耗时可达 Z-Image-Turbo 的 100 倍——这一延迟先验暗示其内部存在一个稳健的理解模块去仔细分析与拆解用户指令。Boogu 早期架构曾尝试用 72B VLM 驱动 10B DiT（VLM 冻结、仅训 DiT），但训练与推理开销过高，开源社区难以复现。最终采用解耦的算力高效范式：中等规模 VLM（如 32B）作为 Instruction Reasoner 处理复杂逻辑，轻量 VLM（8B）作为 Instruction Encoder 提取隐藏状态作为 DiT 的条件信号，显著降低训练与推理成本。

3.1 模型架构：解耦的"理解 + 生成"

Boogu 采用解耦架构，把"理解"与"生成"分到不同模块，既保留了强理解能力又控制了算力。其宏架构（Appendix B.2）由三部分构成：

3.1.1 Instruction Reasoner（指令推理器）

使用中等规模 VLM（如 32B）处理复杂逻辑理解，对输入文本指令（经 chat template + system prompt 格式化）做全面分析、拆解与重写，输出结构化、无歧义的条件 prompt。编辑场景下额外拼接参考图像。系统根据是否有视觉输入自动判定任务模态：无参考图 → T2I 任务 + T2I system prompt；有参考图 → 编辑任务 + 编辑 system prompt。

3.1.2 Instruction Encoder（指令编码器）+ 图像生成

Instruction Encoder 本质是一个 Autoregressive Transformer（即 VLM，采用 Qwen3-VL-8B-Instruct），其子模块包括：

  • Text Tokenizer & Embedding Table：将重写后的指令 tokenize 并投影为 embedding 序列；
  • ViT：编码参考图像到与文本 prompt 同一潜空间（下采样到 384×384 防止序列过长）；无参考图时 ViT 被旁路，即为纯 T2I；
  • System Prompt：按任务类型自适应构建；
  • Prompt Tuning Transformer（可选）：极轻量可训练模块（3 层、仅 32 个可训练 prompt token、causal mask），输出 prepended 到 Encoder 输入序列；因 Encoder 训练时冻结，该模块在数学上对 Encoder 输出隐藏态序列的 embedding 分布做全局调制，使其更好对齐 DiT 所需语义空间。

3.1.3 DiT（Diffusion Transformer）

DiT 子模块含 VAE（采用 FLUX.1-dev VAE，将参考图映射到潜空间）、Embedder/Refiner（线性投影 + 轻量 2 层 Transformer，指令/参考图/噪声各有独立 Embedder 与 Refiner）、以及 dual-stream + single-stream 堆叠：

3.2 训练目标与公式

Boogu 的生成主干基于 Flow Matching / Rectified Flow（Lipman et al.；SD3；Lumina 系列），在潜空间内训练。其核心训练目标包含 logit-normal 时间步采样 + resolution-dependent 动态时间偏移 (dynamic time shifting)。下面按原文完整还原这套公式，并给出 Boogu 针对 2K 原生训练提出的修正版动态时间偏移。

3.2.1 标准 logit-normal 采样

标准 logit-normal 时间步采样为：

$$t = \mathrm{Sigmoid}(u) = \frac{1}{1 + e^{-u}}; \quad u \sim \mathcal{N}(0, 1)$$

其中 $t$ 为扩散时间步（Boogu 设定中 $t \to 0$ 表示高噪声态，$t \to 1$ 表示干净样本）。

3.2.2 动态时间偏移（resolution-dependent）

为建模潜 token 数 $n_T$ 对时间步分布的影响，用两个参考点 $(x_1, y_1)$、$(x_2, y_2)$ 校准线性插值得到 shift 因子：

$$\mu(n_T) = k \cdot n_T + b, \quad k = \frac{y_2 - y_1}{x_2 - x_1}, \quad b = y_1 - k \cdot x_1$$

其中 $n_T$ 为分辨率相关的潜空间 token 数。偏移后的时间步：

$$t_{\mathrm{shift}} = \tau\left(t;\, \mu(n_T), \sigma\right) = \frac{t^{\sigma}}{t^{\sigma} + e^{\mu(n_T)} \cdot (1-t)^{\sigma}}; \quad \sigma \gt 0$$

该操作本质上是 logit 空间的仿射变换：

$$\mathrm{logit}(t_{\mathrm{shift}}) = \log\left(\frac{t_{\mathrm{shift}}}{1 - t_{\mathrm{shift}}}\right) = \sigma \cdot \mathrm{logit}(t) - \mu(n_T)$$

当 $\sigma = 1$ 时退化为纯平移 $-\mu(n_T)$。更大的 $\mu(n_T)$（更高分辨率图像诱导）会把整体分布推向更小的 $t$。

3.2.3 修正版动态时间偏移（Rectified Dynamic Time Shifting）

Boogu 是最早原生 2K 训练的开源模型之一，作者发现标准动态偏移在 2K 下产生过挤压效应 (over-squeezing)：偏移过度降低训练时信噪比，拖慢收敛、早期生成出现噪声伪影。设 $(x_1,y_1)=(256,0.5)$、$(x_2,y_2)=(4096,1.15)$ 时，2K（16384 tokens）下中位数从 1K 的 0.24 坍缩至 0.04。Boogu 采用简单有效的钳制 (clamp) 有效 token 数方案：

$$\tilde{\mu}(n_T) = \mu\left(\min(n_T, n_{\mathrm{cap}})\right) = \min\left(\mu(n_T),\, \mu(n_{\mathrm{cap}})\right)$$

其中 $n_{\mathrm{cap}} = 4096$（即 1K 分辨率区间）。超出 1K 区间后不再施加额外时间偏移，直接继承 1K 上调好的偏移行为并扩展到 2K。通过分位函数刻画 $t_{\mathrm{shift}}$ 分布：

$$P_q = Q_{t_{\mathrm{shift}}}(q;\, \mu(n_T), \sigma) = \mathrm{Sigmoid}\left(\sigma \cdot \Phi^{-1}(q) - \mu(n_T)\right); \quad q \in (0,1),\, \sigma \gt 0$$

其中 $\Phi(x) = \int_{-\infty}^{x} \frac{1}{\sqrt{2\pi}} e^{-s^2/2}\, ds$ 为标准正态 CDF，默认 $\sigma=1$。该修正消除了过挤压伪影，无需重新拟合 $(\alpha,\beta)$（对比对数曲线 $\tilde{\mu}(n_T)=\alpha\log(n_T)+\beta$ 方案，后者仍是单调曲线且需拟合优化）。

3.2.4 Classifier-Free Guidance 与 BOG（见 3.6 节）

条件生成采用 CFG。在概率流 ODE 框架下，前向加噪等价于确定性 ODE：

$$dx_t = -\sigma(t)\,\nabla_{x_t}\log p_t(x_t)\, d\sigma(t) = -\frac{\dot{\sigma}(t)}{\sigma(t)}\nabla_{x_t}\log p_t(x_t)\, dt$$

生成即从 $t=0$（纯噪声 $p_0 = \mathcal{N}(0, \sigma^2_{\max}I)$）到 $t=1$（干净数据 $p_1 = p_{\mathrm{data}}$）数值积分该 ODE。不可解析的 score 由 DiT $D_\theta(x_t, t, c)$ 近似。

3.3 数据质量与去重策略

Boogu 的数据哲学可概括为"足够的数据并不够 (Just Enough Data Is Not Enough)"——单纯数据量远不足以训练 SOTA 模型，必须以人类先验组织成结构化课程。其数据策略包含若干反直觉但效果显著的设计。

3.3.1 头部冗余数据无用论

互联网数据呈严重长尾分布：热门概念可用数据比稀有概念多数量级。以地标为例（Figure 21），埃菲尔铁塔的搜索热度远超其余。作者论证：头部数据的冗余对训练无必要，超过某点后对已充分覆盖概念的额外样本收益递减。这为数据均衡化提供依据——但仅在算力受限时才值得（否则均衡化构建成本可能超过直接训练非均衡数据的成本）。

3.3.2 显式标注缺陷，而非过滤缺陷数据

与 Qwen-Image、Z-Image、JoyAI-Image 等强调过滤带可见伪影图像的做法不同，Boogu 主张：欠曝、构图差、模糊、水印等次优数据不应被完全丢弃，只要配以详尽准确 caption 即可保留。通过显式描述所有视觉与逻辑内容及其具体缺陷（如详述水印存在、模糊确切性质），这些图像可按适当比例纳入训练集，使模型不仅学会基础视觉模式，还理解"负向视觉元素"，获得更全面、可控的生成能力。原文例示四类常见伪影（水印 / 弱光彩色噪点 / 运动模糊 / 严重过曝）配以点名缺陷的 caption。

3.3.3 Boogu Syllabus：人类先验课程

作者援引三条视觉理解研究的关键洞见：(1) 模型能力相对训练数据呈严重长尾分布；(2) 多模态模型需指数级数据曝光才能掌握一个概念（zero-shot 性能仅随指数增长的相似数据曝光线性增长）；(3) 单纯放大参数无法补偿未见数据类型。T2I（维度扩展任务）比视觉理解（维度压缩任务）对数据与训练要求更严苛。据此提出三条数据策展原则：

  • 系统化细粒度拆解：像物理教科书把知识拆为热力学/电动力学等分支一样，把数据拆解为细粒度、逻辑互联的组件，构成结构化课程；
  • 全面覆盖：理想情况下，任何所需能力都不应落在计划范围之外；必须主动为每个目标能力策展数据，而非指望模型靠规模"顿悟"；"训练时没见过猫，就认为它生成不了猫"；
  • 每类充足数据：每个细粒度域需足够数据量，确保达到曝光阈值。

Boogu Syllabus 最终含 21.62M 唯一样本，训练时按预设权重上采样到 47.19M。宏观分布（Figure 25）：design 34.9%、people 34.7%、general 17.0%、object/style/scene/animal 各 3.4%–3.7%、unknown 0.7%。微观上 design 被细分为 poster/text rare/product poster design/diagram slides/logo 等多子类，反映其多面性（精确排版、logo/海报设计、构图）。仅靠这 47.19M（远小于 187M 开源数据），性能即显著超越（见 Table 8）。

3.3.4 汉字词汇枚举：≥300 次曝光

为提升视觉文字渲染（尤其汉字），提出基于词汇枚举的系统化数据构建策略，远比无方向数据增强有效。经验发现：模型几乎无法渲染未见汉字，每个字形至少需 300 次训练曝光才能准确生成。资源受限无法枚举全部汉字词汇时，优先覆盖 3500 个最常用现代汉字（现代汉语常用字表）。确保每个字至少出现 300 次后，模型即可满足日常中文文字渲染需求。Table 9 显示针对性 SFT 后 LongTextBench(ZH) 从 0.9055 → 0.9538。

3.3.5 质量优于数量：开源数据不保证高性能

初始预训练阶段混合公开语料（COYO、DataComp、PixelProse、BLIP-3o 单图文对 + OmniCorpus 交错图文）。实验证明仅靠开源数据（187M）会给性能设下严格天花板：开源语料普遍存在语义噪声、事实错误、严重数据重复，且 caption 简短浅薄，缺乏高保真生成所需的细粒度属性、空间关系与稠密图文对齐，且严重偏向通用网页内容，缺乏高质量领域特定（科学/逻辑/本地化）数据。要追平专有前沿模型，必须超越公开数据集，构建精密数据精炼管线、高质量合成数据与专家级策展。

3.3.6 文化偏见难以靠 SFT 修复

作者识别出跨文化语境的能力差距：模型习得西方概念（如白人特征）比东方概念更容易，根源在大规模开源预训练数据的西方中心偏见。实验发现即便 SFT 阶段引入大规模高质量中文数据集也无法完全纠正——基础世界观与文化关联在大规模预训练阶段建立，下游 SFT 仅触及行为对齐表面，不根本改变潜表示空间。结论：文化多样性必须在预训练阶段解决，而非作为微调的事后补救。

3.4 Agentic Inference-Time Scaling（推理时扩展）

Boogu 不把模型当作被动的 text-to-image 映射，而是用 agent 在推理时注入理解。该 agent 由 Deepseek-V4-Flash 驱动，执行三类操作：(1) agentic prompt rewriting（重写 prompt）、(2) model selection（在 Base/Turbo 等变体间路由）、(3) inference-time techniques（如 Reflection）。Figure 1 显示，注入的理解能力越多，模型性能逐步提升（Raw Model → +Prompt Enhance → +Best-of-N → +Reflection → Agentic Model）。

3.4.1 Agentic Prompt Rewriter：翻译者而非增强者

现有 prompt rewriter 的两大局限：(1) 输出过长，引入冗余或幻觉细节偏离原意并推高推理成本；(2) 单次前向，无法在重写前对模糊/组合指令做推理。Boogu 采用推理式 prompt rewriter，把重写视为推理过程而非单次变换——解读用户意图、消歧、产出忠实且作用域适当的指令。其四大能力维度：

  • Reasoning：间接指定目标的 prompt（如"会下蛋且产奶的动物"、"$7\times8$ 的结果"）需多步推理才能确定可视主体，rewriter 将隐式描述解析为可渲染指令；
  • Counting：生成模型在精确计数上 notoriously 不可靠，rewriter 显式枚举实例（把"五个苹果"扩展为结构化、位置感知的描述）缓解计数错误；
  • NSFW prompts：不安全请求在重写阶段即被识别并净化，提供可解释的内容审核第一道防线；
  • Text rendering：用户加文字意图常模糊或格式不精确（如"加标题"未指定确切文字/风格），rewriter 解析为明确、结构良好、固定精确字符串与位置的规范，显著提升渲染准确性与视觉质量。

核心设计原则：rewriter 应被恒等变换下界约束——当用户 prompt 已清晰、规范、无冲突时，rewriter 应几乎不变地保留，而非 compulsively 扩写。这样重写只会帮忙、不会伤害：最坏情况逐字保留原意，更好情况消解歧义/欠规范/冲突。这正是"翻译者"与"增强者"的区别：前者仅在意图不清时干预，后者无条件改变输入。

缩放规律（Figure 18a）：用不同 thinking 模型做重写，advantage score 随模型规模增长（0.8B→0.71, 2B→0.98, 4B→1.31, 9B→1.53, 27B→1.80, 122B→1.59, 397B→2.16）。更强世界知识与推理 → 更连贯、意图忠实、上下文感知的重写。122B（MoE）相对 27B 的回落可能归因 MoE 架构或路由行为，但整体趋势不变。技能维度（Figure 18b）：为 Counting/Infographic/Reasoning/NSFW/Scene-Text 引入专属 PE 技能后，对应维度 advantage score 均提升，Infographic(2.33) 与 Scene-Text(5.93) 增益最显著。NSFW 分数低于 1 是因不安全 prompt 被有意净化。

advantage score 定义为：

$$S_{\mathrm{adv}} = \left(\frac{N_{\mathrm{win}} + N_{\mathrm{good\,tie}}}{N_{\mathrm{tie}} + N_{\mathrm{bad\,tie}}}\right) \Big/ \left(\frac{N_{\mathrm{lose}} + N_{\mathrm{good\,tie}}}{N_{\mathrm{tie}} + N_{\mathrm{bad\,tie}}}\right)$$

$S_{\mathrm{adv}} \gt 1$ 表示相对 baseline 有优势。

作者还强调：不同 T2I 模型需要不同的 prompt rewriter——各模型在不同轴注入人类偏好（有的偏真实、有的偏插画/美学），训练时采用不同 caption 策略（期待不同风格结构的输入）。为某模型 caption 分布调优的 rewriter 对另一模型可能产生 OOD 输入而劣化输出。因此在相同 prompt 下比较两模型常不公平，有意义比较应为每个模型配其适配的 prompt。

3.4.2 Model Router：为任务选对模型

如同人类画家完成简单速写与复杂构图耗时差异巨大，Boogu 用 agent 决定调用哪个模型以控制质量-效率权衡。GPT-Image-2 生成"a beautiful girl"可比 Z-Image-Turbo 慢 100×；Boogu 系列内 Turbo 与 Base 输出常难以区分，但推理成本差 50–100 倍。据此，agent 按估计难度把请求路由到最合适变体：简单请求给轻量 Turbo，复杂需求留给重 Base。类似思路见 LLM 路由框架 FrugalGPT、RouteLLM、Hybrid-LLM。

Algorithm（概念）：Agentic Inference-Time Scaling

Input: 用户请求 req；模型变体集 {Base, Turbo, Edit, Edit-Turbo}；agent 骨干 Deepseek-V4-Flash

// 步骤 1：agentic prompt 重写（推理式翻译）

prompt' = Reasoner.rewrite(req) // 消歧/计数/NSFW/文字规范，恒等下界

3.5 Turbo 加速机制

Boogu 系列通过Turbo 蒸馏实现快速推理：Base 模型（高保真但慢）经蒸馏得到 Turbo 变体（少步快速推理），编辑侧对应 Edit-Turbo。Figure 1 右侧展示推理时间-质量权衡：放大推理时间带来更高 T2I 生成质量。变体谱系包括 Boogu-Image-0.1-Turbo → Turbo-PE → Turbo-Thinking → Pro，沿推理时间轴逐级提升质量。关键权衡：Turbo 在中短文本渲染（≤100 字符/词）上与 Base 难以区分，但在超密集文本场景会引入可见伪影，此时推荐部署专为 2K 高保真密集文本优化的 Base 模型。

3.6 Boosted Orthogonal Guidance (BOG)

BOG 是一种免训练、推理时的 DiT 文生图方法，针对 CFG 在大 guidance scale $\omega$ 下出现的过饱和、色调扁平、过平滑等失效模式。其核心洞见源自 APG：guidance 更新可分解为平行与正交于模型预测流的两分量，BOG 强调保信息的正交分量以避免色彩炸裂与纹理塌缩。关键创新：不再把 DiT 每步预测视为展平的高维向量，而是当作与图像空间结构对齐的 2D 矩阵（shape $[B,C,H,W]$ 中 $[H,W]$ 是有意义网格），呼应矩阵感知优化器（如 Muon）。对该矩阵施加正交化近似，作为结构化归一化，不仅控幅度更丰富行列方向，保留更多空间维度的有效变异（更高有效秩）。

3.6.1 矩阵归一化 MNorm

设 $D \in \mathbb{R}^{m\times n}$（$m \geq n$），做 SVD：$D = U\Sigma V^\top$，$\Sigma = \mathrm{diag}(\sigma_1,\dots,\sigma_n)$。定义标量函数（输入为奇异值索引 $i$ 与奇异值 $\sigma_i$）：

$$\sigma'_i = \mathrm{norm}(\sigma_i, i) \in \left\{\,\mathrm{Sigmoid}(\sigma_i),\ \lambda\cdot\frac{\exp(\sigma_i/\tau)}{\sum_{j=1}^{n}\exp(\sigma_j/\tau)},\ \dots,\ 1\,\right\}$$

矩阵归一化：

$$\mathrm{MNorm}(D) = U \cdot \mathrm{diag}\left(\mathrm{norm}(\sigma_1,1),\dots,\mathrm{norm}(\sigma_n,n)\right) \cdot V^\top$$

当 $\mathrm{norm}(\sigma_i,i)=1$ 时，$\mathrm{MNorm}(D)$ 等价于 $D$ 的最优正交（半正交）近似：

$$\mathrm{MNorm}(D) = \arg\min_{O \in \mathbb{R}^{m\times n}} \left\{\|O - D\|_F \;\middle|\; O^\top O = I_n \text{ 或 } OO^\top = I_m\right\}$$

实践中不必显式算 SVD，可用 Newton-Schulz 迭代（Muon 风格，batched GEMM）估计。最优性的证明（Appendix C.4）通过将 $\min\|D-O\|_F^2$ 化为 $\max\,\mathrm{tr}(O^\top D)$，用 Von Neumann 迹不等式得界 $\sum_i \sigma_i$，并在 $O^\star = UV^\top$ 取等。

3.6.2 平行-正交分解 (POD)

CFG 在每步把 DiT 输出修正为：

$$D_{\mathrm{CFG}}(x_t,t,c) = D_\theta(x_t,t,c_\emptyset) + \omega\left(D_\theta(x_t,t,c) - D_\theta(x_t,t,c_\emptyset)\right) = D_\theta(x_t,t,c) + (\omega-1)\,\Delta D_{\theta,x_t,t}$$

记 $\Delta D := \Delta D_{\theta,x_t,t} \in \mathbb{R}^{H\times W}$，$D^{(c)} := D_\theta(x_t,t,c)$。以条件输出矩阵的列向量 $D^{(c)}_{[:,j]}$ 为参考方向，对 $\Delta D$ 各列做 Gram-Schmidt 式平行-正交分解：

$$\Delta D^{\|}_{[:,j]} = \mathrm{Parall}\left(\Delta D_{[:,j]},\, D^{(c)}_{[:,j]}\right) = \frac{{D^{(c)}_{[:,j]}}^\top \Delta D_{[:,j]}}{\|D^{(c)}_{[:,j]}\|_2^2}\, D^{(c)}_{[:,j]}$$

$$\Delta D^{\perp}_{[:,j]} = \mathrm{Ortho}\left(\Delta D_{[:,j]},\, D^{(c)}_{[:,j]}\right) = \Delta D_{[:,j]} - \Delta D^{\|}_{[:,j]}$$

对每列得 $\Delta D^{\|}_{\mathrm{col}}, \Delta D^{\perp}_{\mathrm{col}} \in \mathbb{R}^{H\times W}$；对每行同理得 $\Delta D^{\|}_{\mathrm{row}}, \Delta D^{\perp}_{\mathrm{row}}$。合并：

$$\Delta D_{\mathrm{pod}} = \mathrm{POD}(\Delta D, D^{(c)}) = \lambda_c \cdot \left(\Delta D^{\perp}_{\mathrm{col}} + \mu\,\Delta D^{\|}_{\mathrm{col}}\right) + \lambda_r \cdot \left(\Delta D^{\perp}_{\mathrm{row}} + \mu\,\Delta D^{\|}_{\mathrm{row}}\right)$$

其中 $\lambda_c = \frac{W}{H+W+\zeta}$、$\lambda_r = \frac{H}{H+W+\zeta}$（$\zeta$ 为小常数），超参 $\mu \leq 1$（如 0, 0.1, 0.25）以在大 $\omega$ 时缓解过饱和。

3.6.3 Rolling-Sum 动量

受优化中动量启发，推理时引入轨迹"惯性"：

$$\Delta D^{(i)} = \mathrm{RollSumUpdate}(\Delta D, i) = \eta\,\Delta D^{(i)} + \rho\,\Delta D^{(i-1)}, \quad \Delta D^{(0)} = 0$$

默认 $\eta=0.9$、$\rho=0.1$。这与 APG 的"反向动量"（$\rho \lt 0$）相反——作者经验发现 $\rho \lt 0$ 会导致 $\Delta D^{(i)}$ 在向量场中跨迭代方向抖动。

3.6.4 完整 BOG 单步算法

Algorithm 1: Single Step of Boosted Orthogonal Guidance (BOG)

Input: 推理步 i；当前潜态 x_t；条件 c；无条件态 c_empty；guidance scale ω

Output: BOG 修正后的预测 D_BOG(i)

1: t ← scheduler(i) // 取连续扩散时间步

2: ΔD(c)(i) ← D_θ(x_t, t, c); ΔD(c_empty)(i) ← D_θ(x_t, t, c_empty) // 计算 DiT 预测

3: ΔD(i) ← ΔD(c)(i) − ΔD(c_empty)(i) // 原始 guidance 方向

4: ΔD(i) ← RollSumUpdate(ΔD(i), i) // 动量

5: ΔD(i) ← MNorm(ΔD(i)) // 矩阵归一化，保留空间秩

6: ΔD(i) ← POD(ΔD(i), ΔD(c)(i)) // 平行-正交分解，弱化平行分量

7: D_BOG(i) ← ΔD(c)(i) + (ω−1)·ΔD(i) // 最终 BOG 张量

8: return D_BOG(i)

BOG Interval $\Delta_{\mathrm{BOG}}$：BOG 会增加结构扭曲概率、降低文字渲染成功率，故作为可选模块。引入超参 $\Delta_{\mathrm{BOG}}$：每隔 $\Delta_{\mathrm{BOG}}$ 步应用 BOG，其余步用标准 CFG。如 10 步去噪中 $\Delta_{\mathrm{BOG}}=2$ 表示偶数步 (2,4,6,8,10) 用 BOG、奇数步用标准 CFG；$\Delta_{\mathrm{BOG}}=1$ 为全程 BOG。推荐默认 $\Delta_{\mathrm{BOG}}=2$，显著缓解上述伪影，代价是略微损失 BOG 式摄影质感。

3.6.5 关键消融：身份记忆阈值与 RL 谨慎使用

身份记忆（Figure 29）：将志愿者（陈国轩）170 张日常照片（中英 × 短长描述 = 4 种 caption）过采样到 11,628 张（5814/语言），混入 12.6M SFT 数据（占 ~0.13%）。128 设备、global batch 1024、500 步 warmup 后 constant lr=1e-4。约 5k 步开始出现可辨认面部特征，8k–9k 步完全可辨认——即约 4500 次语言匹配曝光可让模型稳健记忆一个完全未见的人类身份。Flow Matching 模型倾向于学习这些变体的平均表示（受试者体重 70→80kg 期间变化被平均化）。

谨慎使用 RL（Figure 30）：重美学 RL 会把输出分布塌缩到窄域（如 Seedream 肖像一致地漂亮年轻）。给 prompt"一位六十岁的中国女性"，重美学 RL 模型产出精致妆容、理想化特征，而 Boogu 产出更自然真实的结果。作者强调 RL 驱动的分布塑形不是弱点而是合法产品策略，只是与 Boogu 最大化多样性的目标冲突。因此 Boogu 刻意避免重美学 RL，把人类偏好嵌入理解系统而非不可逆地烤进生成器，让风格（含人脸属性）在推理时灵活可控、保留生成器底层多样性。RL 仅用于不损害多样性的定向问题（解剖畸变、文字渲染），因 RL 训练算力开销显著（reward 推理、重复采样、额外优化步）。

3.6.6 指令编码器缩放：更强 LLM → 更强文生图

把指令编码器视作 T2I 模型的"传感器 (sensor)"：它定义了系统可用信息的上界。弱编码器会在与图像 token 交互前丢弃重要信息，且因编码器训练时冻结，该限制贯穿训练与推理——任何推理时计算都无法恢复输入端丢失的信息。Table 7 显示，固定训练数据/超参/DiT（1B）仅缩放冻结编码器，GenEval 单调提升：Qwen3-1.7B → 0.6034，Qwen3-4B → 0.6251，Qwen3-14B → 0.6477，无饱和。收益不来自参数量本身而来自编码器理解与编码指令的能力。考虑开源可及性，最终采用 Qwen3-VL-8B 平衡质量与部署成本。

4. 实验结果与分析

4.1 评测方法学：为何重构开源评测

Boogu 团队首先论证了一个重要前提：公共基准已不可靠地反映真实能力。Figure 5 把六个近期 T2I 模型在 LMArena Elo（人类偏好）与 GenEval/DPG-Bench 分数对比，观察到明显排名倒置——人类偏好最强的 GPT-Image-2 在两个基准上仅排中游。作者自身模型也如此：GenEval 上某 SANA-VAE 配置达 0.92，而部署的更强模型仅 0.85。归因三点：(1) 多数公共基准不反映真实应用场景，在受限合成条件下评估孤立能力，与生产使用背离；(2) 主流基准接近饱和，顶尖模型近天花板，压缩比较动态范围，小分差不具统计意义（受方差/prompt 格式/基准特定过拟合驱动）；(3) 数据污染与测试集泄露普遍，大规模预训练语料常纳入公共评测集，分数反映记忆而非泛化。

为此 Boogu 自建 Boogu Arena：忠实模拟 Arena pipeline 的 prompt 设计与盲配对决。prompt 空间分三类（照片级与电影感、文字渲染、风格化艺术），每类约 400 个细粒度子场景关键词，由强 VLM 沿 prompt 长度（短中长 3:4:3）与用户画像（27 角色，初/中/专 5:3:2）两轴实例化（两轴耦合而非独立抽取），共产出 1200 双语 prompt。测试时随机选一种语言并跨模型共享，每模型每 prompt 仅评一次（随机种子）。采用加权逆频率策略的样本选择与模型配对，收集超 4000 票，经 Bradley-Terry 模型聚合为 Elo。Boogu Arena 与 LMArena 一致性：Pearson r=0.986、Spearman ρ=1.0，证明其忠实复现大规模公开人类偏好投票建立的排名。

5. 总结与启发

5.1 局限性

  • 世界知识差距：在需大量常识与领域知识（艺术风格、地标、公众人物、商业产品）的任务上仍落后领先闭源系统，且该差距难以可靠度量，实际可能超过报告分数所示。
  • 文字渲染语言受限：目前仅优化中文与英文。
  • 人体结构：多人交互、重度遮挡或非典型视角下可能出现解剖不一致（扭曲的手与肢体）。
  • VAE 瓶颈：采用开源 FLUX.1 VAE，其重建误差进一步瓶颈化小脸/肢体/文字等细粒度细节，原生 2K 生成仅部分缓解。
  • 评测可信度：作者自身反复警示 ImgEdit-Bench 等 VLM 评测与人类偏好倒置（Nano-Banana-Pro 基准分更低却人类更优），静态基准饱和且与真实场景背离。
  • BOG 代价：增强电影质感但增加结构扭曲概率、降低文字渲染成功率，故作可选模块并需 BOG Interval 调节。

5.2 核心洞见与读后评注

洞见 1：理解是生成的上界，编码器是传感器

Boogu 把"理解"提升为一等设计目标，并把指令编码器类比为"传感器"——它定义系统可用信息的上界。Table 7 的消融给出干净证据：固定一切只换冻结编码器，GenEval 从 1.7B 的 0.6034 单调升至 14B 的 0.6477，无饱和。这意味着开源 T2I 模型的瓶颈往往不在生成器而在文本理解。更深层的是：因编码器训练时冻结，输入端丢失的信息"任何下游推理时计算都无法恢复"——这是对"靠 inference-time scaling 救场"思路的有力反驳：理解能力的缺失是不可由推理时计算补偿的，必须在模型/数据侧前置解决。

洞见 2：数据课程 > 数据规模，人类先验是关键

Boogu 仅用 208.62M 唯一图像（基础模型 ~$400K）即追平用十亿级数据的开源同行，核心在于Boogu Syllabus 课程（21.62M 唯一 → 47.19M 上采样）显著优于 187M 原始开源数据。这与"指数曝光"洞见一致：zero-shot 仅随指数增长曝光线性提升。读后评注：这挑战了 scaling-law 的朴素外推——在受限算力下，结构化课程是比堆数据更高效的杠杆，但前提是算力受限（否则均衡化构建成本可能超过直接训非均衡数据）。这是对中小团队最有价值的可操作结论。

洞见 3：缺陷即信号，过滤是浪费

反直觉但有力：水印/模糊/过曝等"坏数据"不应过滤，而应配以显式点名缺陷的 caption 纳入训练。这让模型不仅学视觉模式，还理解"负向元素"，获得可控生成能力。这与可控生成社区"用负面 prompt/ControlNet 显式建模缺陷"的思路同源，但 Boogu 把它前移到数据策展阶段。评注：这是把"数据清洗"从"减法"转为"加标注"的范式转变，对低成本训练尤其实用。

洞见 4：Agentic 推理时扩展是闭源优势的可复现分解

Boogu 用 Deepseek-V4-Flash 驱动的 agent 做推理时重写、路由、reflection，把闭源系统的"系统级集成"拆解为开源可复现组件。关键设计是 prompt rewriter 的恒等下界——已清晰 prompt 不改写，只消歧不增强——使重写"只会帮忙不会伤害"。评注：这把"prompt 工程"从用户负担转移到系统内部，但用数学化下界保证不退化，是工程上很优雅的保证。Figure 18 的 rewriter 缩放规律（到 397B 仍升）也说明：重写能力的天花板不在重写管线而在骨干 VLM 的世界知识与推理——这是开源-闭源差距的具体映射。

洞见 5：评测方法论本身就是贡献

Boogu 对评测的反思极具价值：GPT-Image-2 人类偏好最强却在 GenEval/DPG-Bench 仅中游；自建 Boogu Arena 与 LMArena 达 Pearson r=0.986、Spearman ρ=1.0。更难得的是作者主动警示自家高分基准的不可信——ImgEdit-Bench 上 Edit-Thinking 4.64 居首，但作者坦承人类评测 Nano-Banana-Pro 更优。这种"不自卖自夸"的评测诚实度在技术报告中罕见。评注：论文提出的"单 baseline A/B vs 开源能力前沿"、"质量-延迟 Pareto 前沿"、"ImageNet-like 训练/测试分离 T2I 基准"等主张，是对整个 T2I 评测生态的建设性提案。

洞见 6：2K 原生训练的陷阱与修正

Boogu 是最早原生 2K 训练的开源模型之一，发现标准动态时间偏移在 2K 下"过挤压"——中位数从 1K 的 0.24 坍缩至 0.04，拖慢收敛。修正方案极简：钳制有效 token 数 $n_{\mathrm{cap}}=4096$，直接继承 1K 调好的偏移。评注：这是典型的"高分辨率新工程问题"——很多在 1K 上验证的标准配方在高分辨率下失效，需重新审视。该发现与修正对后续 2K/4K 开源训练有直接参考价值。

洞见 7：BOG 把 CFG 看作矩阵而非向量

BOG 的理论新意在于：把 DiT 每步预测从展平向量重新看作 $[H,W]$ 空间矩阵，用 SVD/Newton-Schulz 做矩阵归一化保留空间有效秩，再用平行-正交分解弱化导致过饱和的平行分量。这呼应 Muon 等矩阵感知优化器。评注：这是把"优化器的矩阵几何直觉"迁移到"推理时 guidance"的有趣跨界，且 Von Neumann 迹不等式给出了最优半正交近似的严格证明。零训练、无显著开销即获更丰富微结构、更深色调、更连贯电影光感，是高性价比的推理时增强。代价（结构扭曲、文字渲染降）通过 BOG Interval 调节，工程上可控。

洞见 8：RL 的边界——多样性 vs 平均质量

Boogu 刻意避免重美学 RL（Seedream 式肖像一致漂亮年轻），把人类偏好嵌入理解系统而非不可逆烤进生成器。评注：这揭示了一个被低估的 trade-off——对齐提升平均质量同时收窄可达分布。Boogu 选择保留多样性（"六十岁中国女性"产出自然而非精致妆容），把 RL 限定在解剖畸变/文字渲染等不损多样性的定向问题。这是对"RLHF 一律提升"叙事的有益修正，对追求生成多样性的开源社区有指导意义。

5.3 未来方向（原文呼吁社区共建）

  • 更透明忠实的评测：静态基准已饱和且误导，即便统治基准也未必保证真实效能；真正效用在于忠实翻译复杂多面意图（多轮可编辑、身份一致、长上下文 prompt 遵从）。
  • 突破开源数据瓶颈：公共数据集语义噪声普遍、缺乏认知深度，设下严格天花板；追平前沿需转向高保真数据合成与专家级策展。
  • 更强 agentic 图像生成：推理时注入理解已有效，但当前 agentic 管线仍浅，在更紧的推理-生成循环、自验证、工具使用上有大量空间，推动生成从被动映射走向主动规划、批评、精炼自身输出的系统。
