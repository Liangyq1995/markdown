概述

本文提出 Grouped Query Experts（GQE），一种将稀疏混合专家（MoE）思想引入 Grouped-Query Attention（GQA）查询头维度的新型注意力机制。其核心洞察是：在 GQA 的每个 KV 组内，不同 token 实际上并不需要激活所有查询头——通过一个轻量路由器，每个 token 只选择 $k$ 个查询头专家，而 KV 头始终保持稠密不变。这样既保留了 GQA 的 KV 缓存优势，又将活跃查询头计算量减半。

实验在 250M 参数、30B token（FineWeb-Edu）规模下进行，GQE 在 HellaSwag、ARC-E、PIQA 三个基准上的平均得分达到 56.04，超过全激活 GQA 基线的 55.86，同时每 token 仅激活一半路由查询头（加上共享头后共 9/16 个注意力计算）。

核心贡献：首次将条件计算（MoE 路由）应用于注意力机制的查询头维度，提出带有重归一化加权求和槽（renormalized weighted-sum slot）与常开共享头（always-on shared head）的完整路由方案，解决了朴素路由导致的性能下降问题。

研究背景

GQE 的设计动机来自两个相互独立却相互补充的研究方向：以 GQA 为代表的 KV 缓存优化，以及以稀疏 MoE 为代表的条件计算。本节分别回顾这两个背景，并说明它们如何共同催生了 GQE 的设计思路。

Grouped-Query Attention（GQA）背景

标准多头注意力（MHA）为每个注意力头维护独立的 Q、K、V 投影，推理时 KV 缓存大小与头数成正比，在长序列场景下内存开销极大。GQA 将查询头分成 $G$ 组，组内所有查询头共享同一对 KV 头，从而将 KV 缓存从 $N_h \cdot d_h$ 压缩至 $N_{kv} \cdot d_h$，内存节省比例为 $N_h / N_{kv}$。

GQA 已被 LLaMA-2/3、Mistral、Gemma 等主流大模型广泛采用，成为工业界推理优化的标配。然而 GQA 仍保留了一个问题：无论 token 的复杂度或信息量如何，所有查询头对每个 token 都会被激活，存在计算冗余。

稀疏混合专家（MoE）方法

MoE 通过路由器为每个 token 动态选择激活的专家子网络，在不增加推理计算量的前提下扩大模型容量。Mixtral、DeepSeek-MoE 等模型已将 MoE 应用于 FFN 层，取得显著效果。

然而，MoE 在注意力层的应用仍相对空白。将路由机制引入注意力头存在非平凡挑战：注意力输出的聚合方式与 FFN 不同，且路由器需要获得有效的学习信号（梯度）。GQE 正是填补这一空白的尝试。

核心方法：GQE 设计

GQE 在 GQA 的基础上，为每个 GQA 组内的查询头引入稀疏路由机制。整体设计包含三个关键组件：查询头专家池、组内路由器，以及解决路由器梯度问题的重归一化加权求和槽与常开共享头。

组内路由机制

给定 $G$ 个 GQA 组，每组有 $M$ 个查询头专家。对于序列中第 $i$ 个 token $x_i$，路由器计算每个专家的得分，并在每组内选出得分最高的 $k$ 个专家：

$$\mathcal{K}_g(x_i) = \text{Top-}k\!\left(\{p_{i,g,m}\}_{m=1}^{M}\right), \quad p_{i,g,m} = \text{softmax}\!\left(\mathbf{r}_g \cdot x_i\right)_m$$

其中 $\mathbf{r}_g$ 是第 $g$ 组路由器的线性权重。KV 头在所有 token 上始终保持稠密计算，不受路由影响。

重归一化加权求和槽

朴素的硬拼接（hard concat）方式会截断路由器得分到输出的梯度路径，导致路由器无法获得有效学习信号。为此，GQE 额外引入一个重归一化加权求和输出：

$$\bar{o}_i = \sum_{g=1}^{G}\sum_{m \in \mathcal{K}_g(x_i)} w_{i,g,m}\, o_{i,g,m}, \quad w_{i,g,m} = \frac{p_{i,g,m}}{\sum_{g'=1}^{G}\sum_{m' \in \mathcal{K}_{g'}(x_i)} p_{i,g',m'}}$$

这个槽通过可微的加权求和将路由器概率传递到输出，为路由器提供梯度。它作为额外的第 $k+1$ 个槽与硬拼接专家输出一起送入输出投影。

常开共享头

为进一步稳定训练并提供全局注意力锚点，GQE 在每层额外保留一个常开共享头（always-on shared head），该头对所有 token 无条件激活，其输出 $o_{i,s}$ 作为第三类槽参与最终拼接。

最终输出拼接

最终输出由三部分拼接后送入输出投影 $W_O$：

$$y_i = \text{Concat}\!\left(O_i,\, \bar{o}_i,\, o_{i,s}(x_i)\right) W_O$$

在论文的实验配置（16 查询头 / 8 KV 头，$k=1$）中：路由器选出 8 个查询专家（每组 1 个），产生 8 个硬拼接槽；加上 1 个重归一化加权求和槽和 1 个共享头槽，共 10 个槽。因此 $W_O$ 从 $16 d_h \times d$ 缩减为 $10 d_h \times d$。

数学推导

本节系统梳理从标准注意力到 GQA 再到 GQE 的数学演化脉络，重点说明每一步变化的动机与形式。

标准缩放点积注意力

标准注意力（单头）定义为：

$$\text{Attn}(Q, K, V) = \text{softmax}\!\left(\frac{QK^T}{\sqrt{d_k}}\right)V$$

其中 $Q \in \mathbb{R}^{n \times d_k}$，$K, V \in \mathbb{R}^{n \times d_k}$，$n$ 为序列长度。计算复杂度为 $O(n^2 d_k)$，随序列长度平方增长。多头注意力（MHA）将 $d$ 维输入投影到 $N_h$ 个独立的 $(Q_j, K_j, V_j)$ 三元组，并行计算后拼接：

$$\text{MHA}(X) = \text{Concat}(\text{head}_1, \ldots, \text{head}_{N_h})\, W_O, \quad \text{head}_j = \text{Attn}(XW_j^Q, XW_j^K, XW_j^V)$$

GQA 公式

GQA 将 $N_h$ 个查询头分成 $G$ 组，每组包含 $M = N_h / G$ 个查询头，组内所有查询头共享同一对 KV 头。设第 $g$ 组的 KV 头为 $K_g, V_g$，则第 $g$ 组第 $m$ 个查询头的输出为：

$$\text{head}_{g,m} = \text{Attn}(X W_{g,m}^Q,\; X W_g^K,\; X W_g^V)$$

GQA 总输出：$\text{GQA}(X) = \text{Concat}(\text{head}_{1,1}, \ldots, \text{head}_{G,M})\, W_O$

KV 缓存从 $2 N_h d_h n$ 压缩至 $2 G d_h n$，节省比例 $N_h / G = M$。

GQE 路由公式

GQE 在 GQA 基础上，对每个 token $x_i$ 在第 $g$ 组内只激活 $k$ 个查询头。路由器得分：

$$p_{i,g,m} = \text{softmax}(\mathbf{r}_g \cdot x_i)_m, \quad m = 1, \ldots, M$$

选出的专家集合：$\mathcal{K}_g(x_i) = \text{Top-}k(\{p_{i,g,m}\}_{m=1}^{M})$

各被选专家的注意力输出：

$$o_{i,g,m} = \text{Attn}(x_i W_{g,m}^Q,\; K_g,\; V_g), \quad m \in \mathcal{K}_g(x_i)$$

重归一化加权求和（提供路由器梯度信号）：

$$\bar{o}_i = \sum_{g=1}^{G}\sum_{m \in \mathcal{K}_g(x_i)} w_{i,g,m}\, o_{i,g,m}, \quad w_{i,g,m} = \frac{p_{i,g,m}}{\displaystyle\sum_{g'=1}^{G}\sum_{m' \in \mathcal{K}_{g'}(x_i)} p_{i,g',m'}}$$

最终输出（含常开共享头 $o_{i,s}$）：

$$y_i = \text{Concat}\!\left(\{o_{i,g,m}\}_{g \in [G], m \in \mathcal{K}_g},\; \bar{o}_i,\; o_{i,s}\right) W_O$$

实验结果

所有实验均在 250M 参数规模、30B tokens（FineWeb-Edu 数据集）的固定预算下进行，以排除训练数据差异的干扰。评测基准包括 HellaSwag（常识推理）、ARC-E（初等科学）和 PIQA（物理常识）。

关键发现

核心结论：在 30B token 预算下，GQE（重归一化 + 共享头）以 56.04 的平均分超过全激活 GQA 基线（55.86），同时每 token 仅激活 8/16 个路由查询头（加共享头后为 9/16 个注意力计算）。朴素路由（仅硬拼接）比基线低 0.43，说明路由器梯度信号的设计至关重要。

总结与启发

GQE 是一项设计精巧的工作，它在几乎不改变 GQA 整体框架的前提下，将 MoE 的条件计算思想成功引入注意力机制的查询头维度。以下是几点关键启发：

1. 路由器梯度设计是稀疏注意力的核心挑战

论文最重要的实验发现是：朴素路由不仅无法带来收益，反而会损害性能。这与 FFN-MoE 的经验不同——在 FFN-MoE 中，硬路由通常能工作，因为专家输出通过加权求和聚合，路由器得分直接参与梯度计算。而注意力头的输出是拼接而非加权求和，这使得路由器梯度的设计成为非平凡问题。重归一化加权求和槽是解决这一问题的关键工程创新。

2. 常开共享头的设计哲学

共享头的设计类似于 MoE 中的"共享专家"（如 DeepSeek-MoE 的 shared expert 设计），为模型提供不依赖路由决策的稳定信息流。这种设计在稀疏路由系统中具有普遍意义：路由器的随机性需要一个确定性的锚点来平衡。

3. KV 缓存与查询计算的解耦

GQE 的一个优雅之处在于它只对查询头做路由，完全不触动 KV 路径。这使得 GQA 的 KV 缓存优势得以完整保留，同时在查询头维度上实现了计算节省。这种"正交优化"思路值得借鉴：在已有优化方案的基础上，寻找正交的优化维度。

4. 局限性与未来方向

当前工作的局限主要体现在以下几点：（1）实验规模仅为 250M 参数，更大规模（1B+）的验证有待进行；（2）输出投影 $W_O$ 的维度因槽数变化而与基线不完全参数匹配，影响公平对比；（3）路由器的专家利用率（load balancing）分析未见于论文；（4）长序列场景下的实际推理加速尚未实测。

未来方向包括：将 GQE 扩展至更大规模模型、与 FlashAttention 等硬件优化结合实现实际加速、探索动态 $k$ 值（根据 token 复杂度自适应调整激活头数）等。

一句话评价：GQE 是一篇执行严谨、洞察清晰的方法论论文。它的贡献不仅在于提出了一个有效的稀疏注意力方案，更在于通过精心设计的消融实验，揭示了"为什么朴素路由会失败"这一反直觉现象，为后续在注意力层引入条件计算的工作提供了重要的设计指南。
