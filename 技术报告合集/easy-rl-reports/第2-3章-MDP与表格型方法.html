第2-3章 马尔可夫决策过程与表格型方法

来源：蘑菇书 EasyRL  |  章节合并原因：第2章建立MDP理论框架，第3章在此基础上推导免模型算法，两章高度连贯

概述

马尔可夫决策过程（MDP）是强化学习的数学基础，提供了序列决策问题的精确形式化描述。第2章从马尔可夫性质出发，逐步构建马尔可夫链→马尔可夫奖励过程→马尔可夫决策过程的完整理论体系，并给出贝尔曼方程的推导与求解方法。第3章在MDP框架下，研究当环境模型未知时如何通过采样学习——引入蒙特卡洛、时序差分两大估计方法，以及Sarsa和Q学习两大控制算法，完成从理论到实践的跨越。

第2章：马尔可夫决策过程

马尔可夫性质与马尔可夫链

是什么：马尔可夫性质是指系统下一状态仅依赖当前状态，与历史无关：

$$p(X_{t+1}=x_{t+1} \mid X_{0:t}=x_{0:t}) = p(X_{t+1}=x_{t+1} \mid X_t=x_t)$$

为什么重要：有了马尔可夫性质，状态成为充分统计量，使得数学分析大幅简化——只需记录当前状态，无需存储完整历史。

马尔可夫链：离散时间、有限状态的马尔可夫过程，由状态集合 $S$ 和状态转移矩阵 $\mathcal{P}$ 完整描述。

马尔可夫奖励过程（MRP）

MRP在马尔可夫链基础上增加奖励函数 $R$ 和折扣因子 $\gamma$，是四元组 $(S, \mathcal{P}, R, \gamma)$。

回报（Return）：从时间步 $t$ 开始的折扣累积奖励：

$$G_t = r_{t+1} + \gamma r_{t+2} + \gamma^2 r_{t+3} + \cdots = \sum_{k=0}^{\infty} \gamma^k r_{t+k+1}$$

状态价值函数：回报的期望值：

$$V(s) = \mathbb{E}[G_t \mid s_t = s]$$

贝尔曼方程：MRP的递推核心

完整推导：从价值函数定义出发，利用回报的递推性质推导贝尔曼方程。

注意到回报满足递推关系 $G_t = r_{t+1} + \gamma G_{t+1}$，将其代入价值函数定义：

$$V(s) = \mathbb{E}[G_t \mid s_t = s] = \mathbb{E}[r_{t+1} + \gamma G_{t+1} \mid s_t = s]$$

对期望按下一状态 $s'$ 展开（利用全期望公式）：

$$= \mathbb{E}[r_{t+1} \mid s_t = s] + \gamma \mathbb{E}[G_{t+1} \mid s_t = s]$$

$$= R(s) + \gamma \sum_{s' \in S} p(s'|s) \mathbb{E}[G_{t+1} \mid s_{t+1} = s']$$

由马尔可夫性质，$\mathbb{E}[G_{t+1} \mid s_{t+1}=s'] = V(s')$，因此得到：

$$V(s) = \underbrace{R(s)}_{\text{即时奖励}} + \underbrace{\gamma \sum_{s' \in S} p(s'|s) V(s')}_{\text{未来折扣价值期望}}$$

矩阵形式与解析解：将上式写成向量形式 $\boldsymbol{V} = \boldsymbol{R} + \gamma \boldsymbol{P} \boldsymbol{V}$，移项整理：

$$\boldsymbol{V} - \gamma \boldsymbol{P} \boldsymbol{V} = \boldsymbol{R} \implies (\boldsymbol{I} - \gamma \boldsymbol{P})\boldsymbol{V} = \boldsymbol{R}$$

当 $\gamma < 1$ 时矩阵 $(\boldsymbol{I} - \gamma\boldsymbol{P})$ 可逆（特征值绝对值均小于1，故行列式非零），两边左乘逆矩阵：

$$\boldsymbol{V} = (\boldsymbol{I} - \gamma \boldsymbol{P})^{-1} \boldsymbol{R}$$

计算方法对比：解析解复杂度 $O(n^3)$ 仅适合小规模问题；实际上采用蒙特卡洛或动态规划迭代求解。

马尔可夫决策过程（MDP）

MDP在MRP基础上引入动作，是五元组 $(S, A, \mathcal{P}, R, \gamma)$。智能体的策略 $\pi(a|s)$ 将MDP还原为MRP，从而可以评估策略的好坏。

两类价值函数及其关系推导：

$V_\pi(s)$ 是在策略 $\pi$ 下对所有动作取期望：

$$V_\pi(s) = \sum_{a \in A} \pi(a|s) Q_\pi(s,a)$$

$Q_\pi(s,a)$ 的贝尔曼展开：执行动作 $a$ 后获得即时奖励，再从新状态 $s'$ 按策略继续：

$$Q_\pi(s,a) = R(s,a) + \gamma \sum_{s' \in S} p(s'|s,a) V_\pi(s')$$

贝尔曼期望方程推导：将 $Q_\pi$ 代入 $V_\pi$ 的表达式：

$$V_\pi(s) = \sum_{a \in A}\pi(a|s) Q_\pi(s,a) = \sum_{a \in A}\pi(a|s)\left(R(s,a) + \gamma\sum_{s' \in S}p(s'|s,a)V_\pi(s')\right)$$

将 $V_\pi(s') = \sum_{a'}\pi(a'|s')Q_\pi(s',a')$ 代入 $Q_\pi$ 的表达式，得到Q的贝尔曼方程：

$$Q_\pi(s,a) = R(s,a) + \gamma\sum_{s' \in S}p(s'|s,a)\sum_{a' \in A}\pi(a'|s')Q_\pi(s',a')$$

贝尔曼最优方程：最优策略满足：

$$V^*(s) = \max_a Q^*(s,a), \qquad Q^*(s,a) = R(s,a) + \gamma\sum_{s'}p(s'|s,a)\max_{a'}Q^*(s',a')$$

动态规划：已知模型时的求解

动态规划利用贝尔曼方程迭代计算价值函数，要求环境模型完全已知（即 $p(s'|s,a)$ 和 $R(s,a)$ 已知）。

问题类型算法核心方程思路
预测（策略评估）迭代策略评估贝尔曼期望方程固定策略，迭代计算 $V_\pi$
控制策略迭代贝尔曼期望方程评估→改进交替，直至收敛
控制价值迭代贝尔曼最优方程直接迭代最优值函数

价值迭代更新规则：

$$V(s) \leftarrow \max_{a \in A}\left(R(s,a) + \gamma\sum_{s'}p(s'|s,a)V(s')\right)$$

第3章：表格型方法（免模型）

免模型的核心问题

现实中环境模型 $p(s'|s,a)$ 通常未知，无法直接套用动态规划。免模型方法通过与环境的真实交互采集数据来估计价值函数，分为预测（评估给定策略）和控制（寻找最优策略）两类问题。

Q表格

表格型方法用二维表格存储所有状态-动作对的Q值 $Q(s,a)$。为什么可行：状态和动作空间有限时，可以穷举存储所有值。当空间连续或极大时，需改用函数近似（深度网络）。

蒙特卡洛策略评估（MC）

是什么：完成完整回合后，用实际累积回报估计价值函数。为什么：不依赖环境模型，直接从经验中学习。

怎么做：对每个被访问状态 $s$，累积回报并取均值：

$$V(s_t) \leftarrow V(s_t) + \alpha(G_t - V(s_t))$$

特点：无偏差但方差大（累积多步奖励），且必须等待完整回合结束。

时序差分学习（TD）

是什么：用下一状态的估计值引导当前状态的更新，无需等待完整回合。为什么：结合了MC（采样）和DP（自举）的优点。

TD(0) 更新规则：

$$V(s_t) \leftarrow V(s_t) + \alpha\underbrace{\left(r_{t+1} + \gamma V(s_{t+1}) - V(s_t)\right)}_{\text{TD误差 }\delta_t}$$

n步TD：在TD(0)（单步）和MC（无穷步）之间取得平衡：

$$G_t^{(n)} = r_{t+1} + \gamma r_{t+2} + \cdots + \gamma^{n-1}r_{t+n} + \gamma^n V(s_{t+n})$$

三种方法的统一视角

方法自举采样方差偏差是否需完整回合
动态规划 DP✓✗低低（需精确模型）否

Sarsa：同策略TD控制

推导来源：将Q函数的贝尔曼期望方程 $Q_\pi(s,a) = R(s,a) + \gamma\sum_{s'}p(s'|s,a)\sum_{a'}\pi(a'|s')Q_\pi(s',a')$ 改写为采样更新形式：用单次观测的 $(r_{t+1}, s_{t+1}, a_{t+1})$ 替代期望，并以步长 $\alpha$ 做增量更新：

$$Q(s_t, a_t) \leftarrow Q(s_t, a_t) + \alpha\left[\underbrace{r_{t+1} + \gamma Q(s_{t+1}, a_{t+1})}_{\text{TD目标（采样贝尔曼期望）}} - Q(s_t, a_t)\right]$$

为什么：直接用实际执行的动作 $a_{t+1}$ 更新，策略更保守、更安全，适合悬崖行走等有惩罚的环境。

ε-贪心策略改进定理：设当前策略 $\pi$，ε-贪心改进后策略 $\pi'$，可证明 $Q_\pi(s,\pi'(s)) \geq V_\pi(s)$：

$$Q_\pi(s,\pi'(s)) = \frac{\varepsilon}{|A|}\sum_a Q_\pi(s,a) + (1-\varepsilon)\max_a Q_\pi(s,a)$$

$$\geq \frac{\varepsilon}{|A|}\sum_a Q_\pi(s,a) + (1-\varepsilon)\sum_a \frac{\pi(a|s) - \varepsilon/|A|}{1-\varepsilon} Q_\pi(s,a)$$

$$= \sum_a \pi(a|s) Q_\pi(s,a) = V_\pi(s)$$

第二行使用了 $(1-\varepsilon)$ 部分的权重是满足 $\sum_a \frac{\pi(a|s)-\varepsilon/|A|}{1-\varepsilon}=1$ 的概率分布，因此 $\max$ 不小于该加权和。此不等式保证了ε-贪心每次改进策略后价值不降低。

Q学习：异策略TD控制

推导来源：将贝尔曼最优方程 $Q^*(s,a) = R(s,a) + \gamma\sum_{s'}p(s'|s,a)\max_{a'}Q^*(s',a')$ 改写为采样更新形式。与Sarsa不同，这里用 $\max_{a'}Q(s_{t+1},a')$ 而非实际执行的 $Q(s_{t+1},a_{t+1})$，直接逼近最优Q值而无需依赖当前策略：

$$Q(s_t, a_t) \leftarrow Q(s_t, a_t) + \alpha\left[\underbrace{r_{t+1} + \gamma \max_a Q(s_{t+1}, a)}_{\text{TD目标（采样贝尔曼最优）}} - Q(s_t, a_t)\right]$$

异策略合理性：目标策略（贪心 $\max$）与行为策略（ε-贪心探索）解耦——行为策略负责探索收集数据，目标策略始终朝最优方向更新，因此历史数据可以重复使用。

收敛保证：在步长满足 Robbins-Monro 条件（$\sum\alpha=\infty, \sum\alpha^2<\infty$）且所有状态-动作对被无限次访问时，Q学习收敛到 $Q^*$。

效果：Q学习比Sarsa更激进，在悬崖行走中会走靠近悬崖的捷径；Sarsa会绕道更安全的路径。

总结与启发

MDP框架提供了强化学习的数学语言：马尔可夫性质使状态足够充分，贝尔曼方程建立了时间上的递推关系，动态规划在已知模型时可以精确求解。当模型未知时，表格型方法通过采样来近似——蒙特卡洛用真实回报、时序差分用引导估计，两者各有权衡。Sarsa和Q学习的对比揭示了同策略与异策略的本质差异：前者更保守安全，后者更高效但有风险。这些方法是后续深度强化学习算法（DQN、PPO等）的直接理论来源。
