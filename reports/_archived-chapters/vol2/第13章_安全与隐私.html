第13章 安全与隐私（Security & Privacy）

《Machine Learning Systems at Scale》Vijay Janapa Reddi · MIT Press · Vol.2 · 生成日期：2026-07-04

核心主线攻击面扩大 → 威胁建模 → 模型/数据/硬件攻击 → 防御架构 → 差分隐私 → 成熟度模型
学习目标对 LLM API 与训练管道做 STRIDE 式分析；量化 DP $\epsilon$ 与模型提取 query 预算

一、扩大的攻击面

单模型 API 有输入/输出边界；舰队级增加：checkpoint 存储、训练数据湖、GPU 共享租户、边缘更新通道、feature store。任一 S3 公开 bucket 可泄露 10TB 预训练语料或 LoRA 权重。

资产威胁规模放大
模型权重提取、窃取公开 API 百万 query 可复制小模型
训练数据投毒、成员推断web-scale crawl 单条毒样可隐藏
推理日志PII 泄露十亿用户 prompt 入库 = 高价值目标
GPU 固件侧信道多租户 MIG 共享物理 die

二、模型提取与 API 滥用

提取经济学

若 API 返回 logits/top-k：~$10^4$–$10^6$ query 可蒸馏出功能等价小模型（视输出丰富度）。防御：rate limit（如 100 req/min/key）、输出截断（仅 top-1 token）、水印、异常 query 模式检测（同一 prompt 网格扫描）。

成本对称：攻击者 spend $ ≈ 合法用户 fine-tune 预算 — 高价值模型必须 assume 提取经济可行。

三、数据投毒与后门

训练时注入 $(x_{\text{trigger}}, y_{\text{target}})$ 对，模型在触发器上输出攻击者标签、其余数据正常。大规模 crawl：0.01% 毒样（1M 条中 100 条）可植入后门。防御：数据 provenance、异常 loss 样本审计、人工 red-team 触发器集、训练时 gradient clipping + 鲁棒聚合（第 14 章）。

四、差分隐私（DP）

$$\Pr[\mathcal{M}(D) \in S] \leq e^\epsilon \cdot \Pr[\mathcal{M}(D') \in S] + \delta$$

SGD + DP：每步梯度 clip 到范数 $C$，加噪 $\sigma C$。隐私预算 $\epsilon$ 随训练步数累积——1000 epoch 无 composition 分析会严重低估泄露。工程上：RDP/zCDP 会计 + 目标 $\epsilon \leq 8$、$\delta = 10^{-5}$（n=10⁶ 量级常见起点，须法务定）。

五、防御架构要点

  • 零信任：训练/worker 节点 mTLS；artifact 签名验证
  • 最小权限：checkpoint 桶仅训练 SA 写、serving SA 读
  • 机密计算：TEE/SGX 保护推理输入（延迟 +10–30%）
  • 审计：数据 lineage 到 shard ID；证明「10K GPU 训练未 ingest 禁止集」

六、章节总结

  1. 舰队 = 更多入口；安全须内建 pipeline 非年终合规
  2. 模型提取是 $/query 问题——输出面与 rate limit 是产品决策
  3. 投毒在 web-scale 数据是基数问题——provenance + 审计
  4. DP $\epsilon$ 须 composition；与 FL（第 11 章）同一数学框架
