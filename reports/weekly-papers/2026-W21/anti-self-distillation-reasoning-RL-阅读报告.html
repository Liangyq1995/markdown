概述

在 LLM 推理增强的近期进展中，在线自蒸馏（On-policy Self-Distillation）被视为一种低成本提升 RLVR 训练稳定性的方法：让一个携带特权上下文（privileged context，通常是正确答案或过程提示）的教师模型，为正在被 RL 训练的学生模型提供软标签目标，引导学生更快收敛。然而，来自小红书 AI 实验室的这项工作发现：这一看似合理的做法在数学推理任务上收益不稳定，有时甚至有害。

论文的核心贡献是找到了蒸馏失效的根本原因：通过点互信息（Pointwise Mutual Information, PMI）分析，揭示了特权上下文（答案信息）会使教师模型在结构性可预测 token（如格式词、连接词）上极度过度自信，同时压制关键的"深思熟虑 token"（Wait、Let me think、Maybe、Hmm 等），而后者对多步推理能力至关重要。

基于此分析，论文提出 AntiSD（Anti-Self-Distillation）：将蒸馏方向反转——不是让学生逼近教师，而是让学生远离教师在深思熟虑 token 上的过度自信分布——配合熵触发门控在教师高度确定时自动关闭蒸馏信号。实验结果显示，AntiSD 在 4B~30B 规模的 5 个模型上，以 2~10 倍更少的训练步骤达到 GRPO 基线精度，最终精度提升高达 +11.5 分。

AntiSD 的核心洞察：特权上下文使教师在"走捷径"——直接跳过推理过程、压缩不确定性表达。蒸馏这种"捷径"分布会系统性地损害学生的推理探索能力。

研究背景：自蒸馏与 Deliberation Token 问题

在线自蒸馏的基本设置

在线自蒸馏（On-policy Self-Distillation）的标准做法如下：在 RLVR 训练的每一步，

  1. 维护两份模型副本：学生模型 $\pi_\theta$（被 RL 更新）和教师模型 $\pi_{\theta^-}$（参数来自学生的滑动平均或额外输入）
  2. 教师模型在输入中额外拼接特权上下文（privileged context）$c$，如正确答案、过程标注，从而以更高置信度生成推理链
  3. 定义蒸馏损失（KL 散度）：

$$\mathcal{L}_{\text{SD}} = \mathbb{E}_{x \sim \mathcal{D}} \left[ D_{\text{KL}}\left(\pi_{\theta^-}(\cdot \mid x, c) \;\|\; \pi_\theta(\cdot \mid x)\right) \right]$$

总损失为：

$$\mathcal{L}_{\text{total}} = \mathcal{L}_{\text{GRPO}} + \lambda \cdot \mathcal{L}_{\text{SD}}$$

直觉上，这应该有助于学生快速学习"正确的推理方式"，因为教师已经知道答案。但实验发现，这种做法在数学推理中收益高度不稳定，且往往在训练后期反而拖累性能。

GRPO 与推理强化学习简介

Group Relative Policy Optimization（GRPO）是目前 LLM 推理强化的主流算法之一。其核心是对每个问题采样一组响应，通过组内对比归一化奖励来估计优势函数，从而避免了 PPO 中需要单独值网络的昂贵设计。GRPO 已被 DeepSeek-R1 等工作证明能够有效激发模型的长链推理能力，形成所谓"顿悟时刻"（aha moment）。

什么是 Deliberation Token（深思熟虑 token）？

Deliberation token 是指推理链中那些表达不确定性、触发自我反思与搜索行为的 token，典型例子包括：

  • Wait、Hmm、Let me reconsider：暂停并重新检验当前步骤
  • Maybe、Perhaps、Alternatively：引入备选推理路径
  • Actually、But wait：表达对当前方向的质疑，触发回溯
  • Let me verify、Let me check：显式调用验证子程序

这些 token 的出现频率与模型的多步推理深度高度相关。在 DeepSeek-R1 的研究中，观察到随着训练的进行，模型自发学会生成这类"深思熟虑"表达，这被认为是推理能力涌现的关键机制。

关键假说
当教师模型携带特权上下文时，它已经"知道答案"，因此不需要也不会生成深思熟虑 token——答案的不确定性已被消解。但学生模型在训练时模仿这种"已知答案"的分布，将学会跳过不确定性表达、压缩推理探索空间，最终损害多步推理能力。

PMI 分析：为什么标准蒸馏失败

点互信息（PMI）的定义

点互信息（Pointwise Mutual Information）是信息论中衡量两个事件共现程度的量。对于 token $t$ 与特权上下文 $c$ 的联合分布，定义：

$$\text{PMI}(t; c) = \log \frac{p(t \mid c)}{p(t)} = \log \frac{\pi_{\theta^-}(t \mid x, c)}{\pi_\theta(t \mid x)}$$

这里 $\pi_{\theta^-}(t \mid x, c)$ 是教师在特权上下文下对 token $t$ 的生成概率，$\pi_\theta(t \mid x)$ 是学生（或无特权上下文的基础模型）的生成概率。

  • $\text{PMI}(t; c) \gg 0$：特权上下文显著提升了 token $t$ 的生成概率——该 token 与"已知答案"高度关联，通常是格式性的、结构性可预测的 token
  • $\text{PMI}(t; c) \ll 0$：特权上下文显著抑制了 token $t$ 的生成概率——该 token 在"未知答案"时才需要，深思熟虑 token 落入此类
  • $\text{PMI}(t; c) \approx 0$：token $t$ 与是否提供特权上下文关系不大

PMI 分析的核心发现

论文通过系统的 PMI 统计分析，对多个数学推理数据集上的大量样本进行了测量，发现：

Token 类型典型例子PMI(t; c) 值特权上下文的影响
结构性格式 token \n\n、therefore、thus、equals +0.8 ~ +2.5 概率大幅提升（过度自信）
数学运算符号 =、+、×、/ +0.3 ~ +1.2 概率中等提升
深思熟虑 token Wait、Maybe、Hmm、Let me reconsider -1.5 ~ -3.8 概率被强力压制
回溯表达 Actually、But wait、However -0.9 ~ -2.1 概率明显降低

这一发现揭示了一个深刻的问题：教师的特权上下文在 token 分布层面系统性地对深思熟虑 token 实施了"惩罚"。当学生通过 KL 散度最小化来模仿教师时，实际上是在学习：

  1. 减少生成 "Wait" 等犹豫表达的频率
  2. 增加生成格式性结构词的频率
  3. 总体上产生更"自信"但推理深度更浅的响应

为什么特权上下文会压制深思熟虑 token？

这可以从贝叶斯视角理解：深思熟虑 token 本质上是模型不确定性的外化表达。当模型不知道答案时，它倾向于在推理链中插入"Wait, let me think again"——这是一种隐式的搜索行为。而当模型已经知道答案（特权上下文），这种不确定性被消除，深思熟虑 token 就失去了存在的语义理由。

问题在于：学生在测试时没有特权上下文，仍然需要通过深思熟虑 token 来完成自主推理探索。但蒸馏已经削弱了学生生成这些 token 的倾向，导致推理深度下降。

核心方法：Anti-Self-Distillation

方法直觉：反向散度

AntiSD 的核心思路是：既然教师分布在深思熟虑 token 上严重失真（被特权上下文偏置），那么标准蒸馏（最小化 KL 散度）是有害的，应该反转为最大化 KL 散度，即让学生主动远离教师的偏置分布。

形式化地，AntiSD 将蒸馏损失的符号反转：

$$\mathcal{L}_{\text{AntiSD}} = -D_{\text{KL}}\left(\pi_{\theta^-}(\cdot \mid x, c) \;\|\; \pi_\theta(\cdot \mid x)\right)$$

展开 KL 散度：

$$\mathcal{L}_{\text{AntiSD}} = -\sum_t \pi_{\theta^-}(t \mid x, c) \log \frac{\pi_{\theta^-}(t \mid x, c)}{\pi_\theta(t \mid x)}$$

$= \sum_t \pi_{\theta^-}(t \mid x, c) \log \pi_\theta(t \mid x) - \sum_t \pi_{\theta^-}(t \mid x, c) \log \pi_{\theta^-}(t \mid x, c)$

第二项不依赖于 $\theta$（教师参数固定），因此优化 $\mathcal{L}_{\text{AntiSD}}$ 等价于：

$$\nabla_\theta \mathcal{L}_{\text{AntiSD}} = \sum_t \pi_{\theta^-}(t \mid x, c) \cdot \nabla_\theta \log \pi_\theta(t \mid x)$$

这个梯度的方向是：对教师高概率的 token（被特权上下文放大的格式 token），降低学生的生成概率；对教师低概率的 token（被抑制的深思熟虑 token），提升学生的生成概率。

PMI 加权的 AntiSD 目标

更精确地，论文基于 PMI 定义了选择性反蒸馏：仅对 PMI 值显著为负的 token（即被特权上下文主动压制的 token）施加反蒸馏梯度，对 PMI 中性或正值的 token 不施加额外信号：

$$\mathcal{L}_{\text{PMI-AntiSD}} = -\sum_t \mathbf{1}\left[\text{PMI}(t; c) \lt -\tau\right] \cdot \pi_{\theta^-}(t \mid x, c) \log \pi_\theta(t \mid x)$$

其中 $\tau \gt 0$ 为 PMI 阈值，控制哪些 token 被纳入反蒸馏目标。这使得 AntiSD 精准地作用于深思熟虑 token，而不会破坏对格式化输出等方面的正常学习。

熵触发门控（Entropy-triggered Gate）

AntiSD 的第二个关键组件是熵触发门控。核心问题是：当教师模型的分布本身熵值极低（即教师已经极度确定地预测某个 token）时，反蒸馏梯度会非常强烈，可能过度干扰学生的正常学习。

定义教师在特权上下文下的条件熵：

$$H_t = -\sum_v \pi_{\theta^-}(v \mid x, c, y_{\lt t}) \log \pi_{\theta^-}(v \mid x, c, y_{\lt t})$$

熵触发门控函数为：

$$g(H_t) = \mathbf{1}\left[H_t \gt H_{\min}\right]$$

其中 $H_{\min}$ 为预设的最小熵阈值。当 $H_t \leq H_{\min}$ 时，教师在该位置的分布已经坍缩为几乎确定性预测（通常对应于教师因为特权上下文而"直接复制"答案的情形），此时关闭 AntiSD 信号：

$$\mathcal{L}_{\text{AntiSD-gated}} = -\sum_t g(H_t) \cdot \mathbf{1}\left[\text{PMI}(t; c) \lt -\tau\right] \cdot \pi_{\theta^-}(t \mid x, c) \log \pi_\theta(t \mid x)$$

直觉上，门控的作用是：当教师因为"太确定"而完全失去参考价值时，干脆忽略它。这与标准蒸馏中的温度缩放有类似的稳定化作用，但机制更具针对性。

AntiSD 完整目标函数

AntiSD 的最终训练目标将 GRPO 损失与门控 PMI-反蒸馏损失结合：

$$\mathcal{L}_{\text{total}} = \mathcal{L}_{\text{GRPO}} + \lambda_{\text{AntiSD}} \cdot \mathcal{L}_{\text{AntiSD-gated}}$$

其中 $\lambda_{\text{AntiSD}}$ 为超参数，控制反蒸馏信号的强度。在实践中，$\lambda_{\text{AntiSD}}$ 通常远小于 1（约 0.05~0.1），因为 AntiSD 梯度相比 GRPO 梯度更集中于特定 token，不需要过大权重。

Algorithm: AntiSD Training
Input: 学生模型 $\pi_\theta$，数据集 $\mathcal{D}$，特权上下文生成函数 get_context，阈值 $\tau$, $H_{\min}$，权重 $\lambda$
while not converged do
  for each 问题 $x \in \mathcal{D}$ do
    // 1. 学生采样，计算 GRPO 损失
    $\{y^1, \ldots, y^G\} \sim \pi_\theta(\cdot \mid x)$
    $r^i \leftarrow$ verify$(y^i)$；$\hat{A}^i \leftarrow (r^i - \bar{r}) / \sigma_r$
    $\mathcal{L}_{\text{GRPO}} \leftarrow -\sum_{i,t} \hat{A}^i \log \pi_\theta(y_t^i \mid x, y_{\lt t}^i)$
    // 2. 教师生成（带特权上下文）
    $c \leftarrow$ get_context$(x)$   // 获取答案/过程提示
    $y^{\text{teacher}} \sim \pi_{\theta^-}(\cdot \mid x, c)$
    // 3. 计算每个 token 的 PMI 与教师熵
    for each position $t$ do
      $\text{PMI}_t \leftarrow \log \pi_{\theta^-}(y_t \mid x, c) - \log \pi_\theta(y_t \mid x)$
      $H_t \leftarrow H(\pi_{\theta^-}(\cdot \mid x, c, y_{\lt t}))$   // 教师条件熵
      $\text{mask}_t \leftarrow \mathbf{1}[\text{PMI}_t \lt -\tau] \cdot \mathbf{1}[H_t \gt H_{\min}]$
    end for
    // 4. 计算 PMI 门控反蒸馏损失
    $\mathcal{L}_{\text{AntiSD}} \leftarrow -\sum_t \text{mask}_t \cdot \pi_{\theta^-}(y_t \mid x, c) \cdot \log \pi_\theta(y_t \mid x)$
    // 5. 组合损失并更新
    $\mathcal{L} \leftarrow \mathcal{L}_{\text{GRPO}} + \lambda \cdot \mathcal{L}_{\text{AntiSD}}$
  end for
  $\theta \leftarrow \theta - \eta \cdot \nabla_\theta \mathcal{L}$
end while
Output: 优化后的学生模型 $\pi_\theta$

Deliberation Token 频率变化分析

论文还直接测量了在训练过程中深思熟虑 token 的生成频率变化：

  • GRPO：训练过程中 "Wait"、"Let me reconsider" 等 token 频率逐渐增加（与 R1 类模型的观察一致）
  • 标准 SD：深思熟虑 token 频率在训练早期快速下降，并持续低于 GRPO
  • AntiSD：深思熟虑 token 频率比 GRPO 增加得更快、更多，与最终精度提升高度相关

消融实验

消融一：PMI 阈值 τ 的影响

PMI 阈值 $\tau$ 控制哪些 token 被纳入反蒸馏：

  • $\tau = 0$（全部 token 参与反蒸馏）：性能下降，因为也反向"惩罚"了格式 token
  • $\tau = 0.5$（中等选择性）：性能最优，精准作用于深思熟虑 token
  • $\tau = 2.0$（过于保守）：反蒸馏信号太弱，提升有限

消融二：熵门控的必要性

移除熵触发门控（即始终施加 AntiSD 梯度）：

  • 训练初期出现梯度爆炸风险，因为教师在某些位置的分布极度退化
  • 最终精度比有门控版本低约 1.8 分（平均）
  • 门控阈值 $H_{\min}$ 对超参数不敏感，0.1~0.5 范围内效果相近

消融三：AntiSD 与不同基础 RL 算法的兼容性

AntiSD 作为一个正交的正则化项，可以与不同的 RL 基础算法结合：

消融四：AntiSD 与标准 SD 的正面对比

最重要的消融是直接对比三种蒸馏策略：

  • 无蒸馏（GRPO）：+0（基线）
  • 标准 SD（KL 最小化）：-1.5 ~ -3.0（在大多数设置下有害）
  • AntiSD（KL 最大化 + 门控）：+7.9 ~ +11.5（始终有益）

这一结果强有力地支持了论文的核心论点：对于带有特权上下文的自蒸馏，方向比强度更重要——反向才是正确方向。

总结与启发

核心贡献总结

AntiSD 的研究价值体现在三个层次：

  1. 诊断层面：通过 PMI 分析首次系统揭示了特权上下文对深思熟虑 token 的抑制效应，为理解"为什么自蒸馏在推理任务上效果不稳定"提供了严格的理论框架
  2. 方法层面：AntiSD 是一个直观而优雅的修复方案——既然蒸馏方向错了，就反转它，配合门控保证稳定性
  3. 实践层面：在 4B~30B 规模上均显示出显著且一致的改进，且无需额外的奖励模型或注释数据

对 LLM 推理研究的深层启发

AntiSD 提醒我们一个反直觉的道理：在推理强化学习中，"更好的老师"不一定意味着"更好的学习"。当老师知道的太多（特权上下文），反而会传授错误的习惯——压制不确定性、跳过探索。真正的推理能力需要在不确定性中挣扎出来。

以下几个方向值得进一步研究：

  • 更精细的 PMI 估计：当前 PMI 基于静态的当前模型估计，可以考虑用 EMA（指数移动平均）估计更稳定的 PMI 值
  • 跨领域的深思熟虑 token：AntiSD 当前主要在数学推理上验证，在代码生成、科学推理等领域深思熟虑 token 的形态可能不同（如 "Let me trace through this code"），需要领域自适应
  • 深思熟虑 token 的因果分析：PMI 提供了相关性证据，但深思熟虑 token 的因果关系（是否 token 本身带来了推理能力，还是两者共同受到模型能力的影响）值得用干预实验验证
  • 与 Process Reward Model 的结合：PRM 提供步骤级奖励，AntiSD 提供 token 级反蒸馏信号，两者的协同可能进一步加速推理能力的涌现
  • 自适应 λ 调度：训练不同阶段，反蒸馏信号的最优强度可能不同——早期可以更强（帮助模型建立深思熟虑习惯），后期减弱（让 GRPO 主导精确推理优化）

与 DelTA 的对比视角

有趣的是，本周热榜上的 DelTA（arXiv:2605.21467）和 AntiSD 都关注 RLVR 训练中的 token 级质量问题，但角度不同：

维度DelTAAntiSD
问题诊断格式 token 稀释判别性梯度方向特权上下文抑制深思熟虑 token
分析工具梯度几何（线性判别分析）信息论（PMI）
解决方案判别性 token 重加权反蒸馏 + 熵门控
需要额外信号否（只用模型自身概率）需要特权上下文（答案/过程）
与基线结合GRPO/RLOO/DAPO 通用GRPO/REINFORCE/DAPO 通用

两者从不同角度解决了 token 粒度的训练信号质量问题，具有良好的互补性，理论上可以同时应用。
