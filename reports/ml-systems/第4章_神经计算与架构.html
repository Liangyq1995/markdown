第4章 神经计算与架构

Vol.1 · Part II 构建 · 整合原第 5–6 章 · 生成日期：2026-07-04

整合主题从原子算子（MAC/梯度/激活内存）到架构族谱（MLP→CNN→Transformer→DLRM），理解 Silicon Contract 如何在 Algorithm 轴上押注不同硬件瓶颈
学习目标把 NN 从「黑盒 API」还原为可算 workload，并据此选型架构与部署形态

一、从逻辑到算术

编译好的数据集不会自己学习。模型边界上，数据通过 矩阵乘、激活、梯度更新 变成行为——这是 Silicon Contract 在 Algorithm 轴上的原子操作。本章前半沿 MNIST 贯穿这条链；后半问：这些算子如何组合成对硬件有不同「押注」的架构。

War Story：Ariane 5 Flight 501 (1996)

复用 Ariane 4 惯性参考软件；更快水平速度使 64-bit 值溢出 protected conversion → 异常关闭制导数据 → 约 40 s 后解体。教训：数值范围与物理 regime 是系统契约，与 ML 中 FP16 溢出 → Inf/NaN 静默传播同构。

MNIST 28×28 手写数字识别（本章贯穿案例）：一次前向约 109,184 MAC，无一分支——bug 在 learning rate、饱和激活、激活内存，不在 if-else 语法。

1.1 深度学习的系统定义

Deep Learning：通过多层非线性变换从原始数据学习层次特征，用增加 $O$（算量）换泛化，免手工特征。深度 $k$ 层可组合 $k$ 级抽象；铁律绑定约束从「算法（手工特征）」转向「机器（算力/内存）」。

二、三种范式对比

同一 MNIST 数字，三种范式给出截然不同的算量/内存 profile——系统工程师据此判断「该上 GPU 还是 CPU 就够」。

范式算量/内存硬件系统含义
显式规则~100 次比较，784 BCPU L1 即可无学习，规则维护成本高
HOG + SVM7×7 细胞×9 方向 → 441 维；~8000 ops，~2 KBCPU SIMD专家特征，跨域迁移差
小型 MLP109,184 MAC；权重+激活需 GPU 并行算力绑定数据驱动，算量跳 10×+

HOG：8×8 像素格梯度方向直方图（Dalal & Triggs 2005）——专家设计、CPU 友好但不可跨域迁移。2012 年 AlexNet 在 ImageNet 上证明：端到端 CNN 可超越手工特征；其系统侧先例是模型数学超单卡内存——双 GTX 580 各仅 3 GB VRAM，被迫模型并行。此后「更大模型 / 更大 batch」与「VRAM / 带宽 / 算力」的拉锯成为 DL 系统主线（后文架构节不再重复此案例）。

三、NN 基础：前向/反向/激活

3.1 单层与参数量

784→128→10 MNIST MLP：

$$W_1 \in \mathbb{R}^{128 \times 784},\; b_1 \in \mathbb{R}^{128} \Rightarrow 128 \times 784 + 128 = 100{,}480$$ $$W_2 \in \mathbb{R}^{10 \times 128},\; b_2 \in \mathbb{R}^{10} \Rightarrow 1{,}290 \quad \text{合计 } \approx 101{,}770 \text{ 参数}$$

batch=32 前向 MAC：$32 \times (784 \times 128 + 128 \times 10) \approx 3.5 \times 10^6$（不含激活等非线性开销）。

3.2 激活函数对比

激活公式梯度/系统
Sigmoid$\sigma(x)=1/(1+e^{-x})$20 层链式 $\approx 0.25^{20} \sim 10^{-12}$ → 消失梯度
ReLU$\max(0,x)$正区梯度=1；ResNet 直连进一步保梯度（见第七节）
Softmax$e^{z_i}/\sum_j e^{z_j}$多类输出；数值稳定需 $z_i - \max(z)$

3.3 张量布局代价

ImageNet 224×224×3 ≈ 151 KB。NCHW↔NHWC 转置：读+写 ≈ 301 KB/图 纯内存流量、零算术——latency 预算在「有用计算」前就被吃掉。

3.4 前向、损失与反向传播

$$\mathcal{L} = -\sum_{c=1}^{C} y_c \log \hat{p}_c \quad \text{单样本正确类 } y_k=1$$

logits $z$ → softmax $\hat{p}$ → 交叉熵；$\partial \mathcal{L}/\partial z_i = \hat{p}_i - y_i$（简洁梯度形式，反向实现友好）。两层网络：$\delta^{(2)} = \hat{y} - y$，$\delta^{(1)} = (W_2^T \delta^{(2)}) \odot \sigma'(z^{(1)})$。训练须存每层激活供 backward → 激活内存 ≈ batch × 各层激活元素和，常为推理的 2–3×。

3.5 SGD 更新

$$W \leftarrow W - \eta \frac{1}{B}\sum_{i=1}^{B} \nabla_W \mathcal{L}_i \quad \eta=0.01 \text{ 过大可振荡；} \eta=10^{-4} \text{ 过慢}$$

学习率是系统旋钮：不报错，只表现为 loss NaN 或平台期。

美国邮政 1990 年代 OCR（USPS）：16×16 灰度、10 类。比 MNIST 更小输入 → 更少 MAC，适合嵌入式；但邮件字体/污渍/扫描噪声与实验室 MNIST 分布不同——再次说明 Data 轴设上限（第 3 章 lab-to-field）。算子与流水线搞清后，自然的问题是：算子如何组合成架构，以及架构对 Silicon Contract 押了什么注。

五、架构作为 Silicon Contract 押注

每种架构是对硬件的隐性押注：先饱和算力、带宽还是内存容量。选架构 = 选铁律哪一项成为瓶颈。

架构/负载绑定资源铁律项
ResNet-50 训练 batch≥32算力$O/(R_{\text{peak}}\cdot\eta)$
Llama3 8B decode batch=1HBM 带宽$D_{\text{vol}}/BW$（读全权重/层）
DLRM 推荐Embedding TB 级 + 稀疏 lookup内存容量 + 随机访问

ResNet-50：~25.6M 参数 FP32 ≈ 102 MB 权重；单图 224×224 前向 ~4.1 GFLOP。batch=64 训练时算力绑定；batch=1 边缘推理可能转 memory bound（读权重主导）。

六、架构族谱 MLP/CNN/RNN/Transformer/DLRM

6.1 MLP

全连接：$y = \sigma(Wx+b)$。参数 $O(d_{\text{in}} \cdot d_{\text{out}})$，对高维图像（784→…）参数爆炸 → 需 inductive bias。

6.2 CNN

$$\text{Conv FLOPs} \approx 2 \cdot H \cdot W \cdot C_{\text{in}} \cdot C_{\text{out}} \cdot K^2 \quad \text{例：}224^2 \times 64 \times 3 \times 7^2 \approx 1.2 \times 10^8$$

局部连接 + 权值共享：参数从 MLP 的 $784 \times 10^6$ 级降到 $3\times3\times3\times64=1{,}728$ 首层量级。押注：空间局部性 → GEMM 友好、SIMD/GPU 吞吐。

6.3 RNN 与序列

隐藏状态 $h_t = f(W_x x_t + W_h h_{t-1})$。时间步串行 → 难并行，长序列梯度消失/爆炸。LSTM (1997) 门控缓解，但训练仍 $O(T)$ 顺序依赖——押注顺序计算，与现代 GPU 批量并行错位。

6.4 Attention 与 Transformer

$$\text{Attention}(Q,K,V)=\text{softmax}\left(\frac{QK^T}{\sqrt{d_k}}\right)V \quad \text{复杂度 } O(n^2 d)$$

$n=2048$, $d=64$ → $QK^T$ 为 $2048^2 \approx 4.2\times10^6$ 次点积/头。GPT-3 175B 训练算力 beast；decode $n=1$ 时变 memory bandwidth bound。

七、共享块与选型框架

7.1 共享构建块

  • BatchNorm：训练 batch 统计 vs 推理 running mean——serving 须切换 model.eval()
  • Dropout：训练随机置零，推理关闭
  • Residual：$y=x+F(x)$，梯度高速公路，使 100+ 层可训

7.2 架构选型框架

数据类型首选原因
网格图像CNN / ViT空间局部性 / 全局依赖
序列Transformer并行训练；长上下文贵 $O(n^2)$
表格+高基数 IDDLRMEmbedding + MLP
小数据边缘MobileNet 等深度可分离卷积（DR 512 MB 案例）

八、D·A·M 与谬误总结

8.1 D·A·M 贯穿本章

轴神经计算侧架构侧
Data784 维归一化、标签 one-hot；USPS 分布偏移图像网格 vs 序列 vs 高基数 ID 决定 inductive bias
Algorithm101k 参数、109k MAC、CE+SGD、激活内存MLP/CNN/Attention 承诺不同 $O$ 与内存访问模式
MachineSIMD/GPU 适合 GEMM；布局转置纯 $D_{\text{vol}}$ResNet 算力 bound vs Llama decode 带宽 bound vs DLRM 容量 bound

8.2 谬误对照

谬误现实
「看懂 API 就够」维度/精度/学习率错误无 stack trace
「更深 = 更宽 shallow 网络」深度提供组合层次，非参数量 alone
「训练 acc 高即可部署」预处理/量化/延迟未纳入同一数学契约
「最新架构总是更好」512 MB 平板无法跑 ViT-L
「参数量 = 算力需求」DLRM 参数在 lookup，不在 MAC
「训练选型 = 推理选型」大模型 distill 到小模型部署

章节总结

  • NN = 算术 workload：MAC、激活内存、梯度链；MNIST 规则 ~100 ops → HOG ~8k → MLP ~109k MAC
  • 推理流水线三阶段须与训练契约一致；USPS 说明 Data 轴上限
  • 架构 = 对 Silicon Contract 的押注：CNN 局部性、Transformer $O(n^2)$、DLRM 稀疏 lookup
  • BatchNorm/Dropout/Residual 是训练–推理行为切换的系统关注点
