概述

Mixture-of-Experts（MoE）已成为当前大语言模型扩展算力的核心范式。其中路由器（Router）是 MoE 的心脏组件：对每个输入 token，路由器通过计算其与路由矩阵各行的相似度，决定激活哪些专家。然而本文的核心洞察在于：传统路由器设计从未系统地约束路由矩阵的行向量去编码其对应专家的内在特征。这一设计缺口导致路由行向量与专家矩阵之间的语义耦合不足，可能造成路由决策的次优性。

本文从线性代数角度出发，提出一个清晰的设计原则：路由矩阵第 $i$ 行 $R_{[i]}$ 应与其对应专家权重矩阵 $W_i$ 的主奇异方向（Principal Singular Direction）对齐。主奇异方向是矩阵最具信息量的压缩表示——它在 Frobenius 意义下最大化保留了矩阵的几何结构。因此，让路由行指向这个方向，就是在有限维向量中对专家做最优的"代理编码"。

基于此原则，作者提出 Manifold Power Iteration（MPI）。其核心是"Power-then-Retract"两步范式：（1）幂迭代步：将路由权重与专家矩阵做矩阵乘积，将其推向主奇异方向；（2）收缩步：对更新后的路由行施加 L2 范数约束，防止数值爆炸并消除专家偏置。从优化视角，MPI 等价于在球面流形上对最大投影目标（Rayleigh 商）做自适应步长的最速上升，理论上保证路由行收敛至主奇异方向。

实验层面，作者在 1B、3B、11B 三个规模上进行了充分的预训练验证。MPI 在所有规模、所有优化器（AdamW / Muon / AdamH / MuonH）下均带来一致的收益：更快的训练收敛、更低的验证困惑度、更好的下游任务表现，以及意外改善的负载均衡。更重要的是，MPI 引入的额外计算开销不足 0.2%，推理阶段零开销，具备极强的工程可落地性。

研究背景

MoE 架构基础

标准 Transformer 的 FFN 层被替换为 $N$ 个并行专家模块 $\{E_k\}$，每个专家是一个独立的 GLU（Gated Linear Unit）网络。对于输入 token $x \in \mathbb{R}^D$，路由矩阵 $R \in \mathbb{R}^{N \times D}$ 计算门控权重：

$$w = \text{Softmax}\!\left(\text{TopK}\!\left(xR^\top\right)\right)$$

激活 Top-K 个专家后，MoE 层输出为加权和：

$$\text{MoE}(x) = \sum_{k=1}^{K} w_k \cdot E_k(x)$$

每个专家 $E_k$ 的结构为：

$$E_k(x) = \left(\text{SiLU}(xW_g^k) \odot (xW_p^k)\right) W_o^k$$

其中 $W_g^k, W_p^k \in \mathbb{R}^{D \times d}$ 为门控和投影矩阵，$W_o^k \in \mathbb{R}^{d \times D}$ 为输出矩阵。MoE 的稀疏激活特性使得在相同计算预算下可以大幅扩展模型参数量。

现有路由设计的问题

传统路由设计存在以下根本性缺陷：

  • 无显式耦合约束：路由矩阵行 $R_{[i]}$ 作为第 $i$ 个专家的"代理向量"，但训练过程中没有任何机制强制其编码专家的内在特征。
  • 范数偏置问题：不同专家对应的路由行范数可能差异悬殊，范数较大的行天然获得更高的门控分数，导致专家负载不均衡。
  • 收敛次优：路由行与专家特征的弱耦合使得 token-expert 亲和度估计不准确，降低训练效率。

问题形式化

路由矩阵与专家矩阵

设路由矩阵 $R \in \mathbb{R}^{N \times D}$，其中 $N$ 为专家数量，$D$ 为隐层维度。第 $i$ 行 $R_{[i]} \in \mathbb{R}^{1 \times D}$ 作为第 $i$ 个专家的代理向量。对应专家的门控权重矩阵记为 $W_g^i \in \mathbb{R}^{D \times d}$（论文中简写为 $W_i^{*}$）。

SVD 分解与主奇异方向

对专家矩阵进行 SVD 分解：

$$W_i = U_i \Sigma_i V_i^\top$$

其中 $U_i \in \mathbb{R}^{D \times D}$，$\Sigma_i = \text{diag}(\sigma_1^{(i)}, \sigma_2^{(i)}, \ldots)$ 为奇异值（$\sigma_1^{(i)} \geq \sigma_2^{(i)} \geq \cdots \geq 0$），$V_i \in \mathbb{R}^{d \times d}$。

主奇异方向（Principal Singular Direction）是 $U_i$ 的第一列 $u_i^{(1)}$（左奇异向量）或 $V_i$ 的第一列 $v_i^{(1)}$（右奇异向量），对应最大奇异值 $\sigma_1^{(i)}$。由 Eckart-Young 定理，主奇异方向是在 Frobenius 范数意义下对矩阵做秩一近似时保留信息最多的方向。

对齐目标：Rayleigh 商最大化

理想的路由行 $R_{[i]}$ 应最大化其在专家行空间上的投影，等价于最大化 Rayleigh 商：

$$\max_{R_{[i]}} \varphi(W_i^{*}, R_{[i]}) = \frac{\|R_{[i]} W_i^{*}\|_2^2}{\|R_{[i]}\|_2^2}$$

由矩阵分析理论，上述优化问题的解恰好是 $W_i^{*} W_i^{*\top}$ 的主特征向量，即 $W_i^{*}$ 的主左奇异向量。因此，对齐目标为：

$$R_{[i]} \approx v_i^{(1)} \quad \text{（趋向 } W_i^{*} \text{ 的主奇异方向）}$$

直观理解：让路由行指向专家矩阵"最具表达力"的方向，使得 token 与路由行的内积能最大程度反映 token 与该专家的真实亲和度。

对齐度量 $\lambda$

作者定义如下归一化对齐度量来量化路由行与主奇异方向的对齐程度：

$$\lambda = \frac{\|R_{[i]}' W_g^i\|_2}{\|R_{[i]}'\|_2 \cdot \|W_g^i\|_2}$$

其中分母用谱范数归一化，使 $\lambda \in [0, 1]$。$\lambda$ 越大表示路由行与专家主奇异方向越对齐。实验表明，MPI 将 $\lambda$ 从约 0.25–0.37 大幅提升至 0.62–0.70。

MPI 算法

Power-then-Retract 范式

MPI 在每个训练步对路由矩阵执行两步操作：

步骤一：幂迭代（Power Iteration）

对路由矩阵第 $i$ 行执行单步幂迭代：

$$\hat{R}_{[i]} = R_{[i]} W_g^i W_g^{i\top}$$

幂迭代的原理：反复乘以 $M = W_g W_g^\top$（一个半正定矩阵），向量会指数级快速向 $M$ 的主特征向量（即 $W_g$ 的主左奇异向量）收敛。单步迭代已足够有效，更多迭代反而引入不稳定（实验验证）。

步骤二：收缩（Retraction）

将 $\hat{R}_{[i]}$ 的 L2 范数约束至超参数 $C$：

$$R_{[i]}' = C \cdot \frac{\hat{R}_{[i]}}{\|\hat{R}_{[i]}\|_2}$$

收缩步将路由行投影回以原点为中心、半径为 $C$ 的球面流形（Spherical Manifold），防止幂迭代引起的范数爆炸或坍塌，同时消除专家间的范数偏置。

超参数 $C$ 的设计原则

为使路由 logit 的无穷范数保持 $O(1)$ 量级（防止爆炸），推导得：

$$\|xR^{\prime\top}\|_\infty \leq \sqrt{\sum_{i=1}^{N}(xR_{[i]}^{\prime\top})^2} \sim O(C\sqrt{N})$$

因此令 $C = C' / \sqrt{N}$，其中 $C'$ 为与专家数无关的全局超参数（实验最优值为 $C' = 2$）。

MPI 伪代码

Algorithm 1: Manifold Power Iteration (MPI) — PyTorch 风格

Input: x ∈ ℝB×D (token 批次)，路由矩阵 R ∈ ℝN×D，专家门控权重 W_g ∈ ℝN×D×d，超参 C'，Top-K 数 K

Output: MoE 层输出 y

// Step 1: Power Iteration — 将路由行推向专家主奇异方向

// R: [N, D], W_g: [N, D, d]

// [N,1,D] @ [N,D,d] @ [N,d,D] → [N,D]

R_hat = (R.unsqueeze(1) @ W_g @ W_g.transpose(1,2)).squeeze(1)

// Step 2: Retraction — L2 范数约束到球面流形

C = C' * (N ** -0.5) // 按专家数缩放

R_prime = normalize(R_hat, p=2, dim=-1) * C

// Step 3: 计算路由 logits

logits = x @ R_prime.T // [B, N]

scores = softmax(topk(logits, K))

// Step 4: 加权求和专家输出

y = weighted_sum(scores, experts(x))

return y

收敛性分析

幂迭代收敛速度由专家矩阵奇异值的间隔比（Gap Ratio）决定。设 $M = W_g W_g^\top$ 的特征值为 $\lambda_1 \geq \lambda_2 \geq \cdots$，则经过 $t$ 步迭代后：

$$\sin\theta_t \leq \left(\frac{\lambda_2}{\lambda_1}\right)^t \cdot \sin\theta_0$$

其中 $\theta_t$ 为当前路由行与主特征向量的夹角。当 $\lambda_1 \gg \lambda_2$ 时（即专家矩阵具有明显主导奇异方向），单步迭代已能快速收敛。论文实验验证单步迭代效果最优，10 步迭代反而因过度对齐干扰路由优化稳定性（预训练 loss 上升 0.002–0.003）。

理论保证

MPI 等价于流形上的最速上升

本节给出 MPI 与最大投影约束优化等价性的推导。考虑如下约束优化问题（以 $C=1$ 为例）：

$$\max_{\Delta r} \Phi(W_g, R_{[i]}' + \Delta r), \quad \text{s.t.} \; \|R_{[i]}' + \Delta r\|_2 = 1, \; \|\Delta r\|_2 \leq \eta$$

其中目标函数 $\Phi = \|R_{[i]}' W_g\|_2^2 = R_{[i]}' W_g W_g^\top R_{[i]}^{\prime\top}$。

第一步：对目标函数做一阶 Taylor 展开：

$$\Phi(W_g, R_{[i]}' + \Delta r) \approx \Phi(W_g, R_{[i]}') + \langle G, \Delta r \rangle$$

其中梯度 $G = 2 R_{[i]}' W_g W_g^\top = 2 R_{[i]}' M$（令 $M = W_g W_g^\top$）。

第二步：将梯度 $G$ 投影到球面流形的切空间（Tangent Space），得到流形梯度上升更新量：

$$\Delta r_g = \eta \left(I - R_{[i]}' R_{[i]}^{\prime\top}\right) R_{[i]}' M = \eta \left(R_{[i]}' M - R_{[i]}'(R_{[i]}' M R_{[i]}^{\prime\top})\right)$$

第三步：推导 MPI 引入的实际更新量 $\Delta r_M$。由幂迭代和收缩的组合，可以证明：

$$\Delta r_M \approx \frac{1}{R_{[i]}' M R_{[i]}^{\prime\top}} \left(R_{[i]}' M - R_{[i]}'(R_{[i]}' M R_{[i]}^{\prime\top})\right)$$

结论：比较 $\Delta r_g$ 与 $\Delta r_M$，两者具有完全相同的更新方向，差异仅在步长因子 $\eta$ 与 $\frac{1}{R_{[i]}' M R_{[i]}^{\prime\top}}$。后者是一个自适应步长：当路由行与主奇异方向接近时（$R_{[i]}' M R_{[i]}^{\prime\top}$ 大），步长自动缩小以避免震荡；当偏离较大时，步长自动增大以加速收敛。这解释了为何 MPI 在单步迭代下就能有效驱动路由行收敛。

Appendix A 详细推导

论文附录给出了公式 (10) 的完整推导。将 $\hat{R}_{[i]} = R_{[i]}' M / \|R_{[i]}' M\|_2$ 分解为平行于 $R_{[i]}'$ 的分量与正交分量之和：

$$R_{[i]}' M = R_{[i]}'(R_{[i]}' M R_{[i]}^{\prime\top}) + \underbrace{\left(R_{[i]}' M - R_{[i]}'(R_{[i]}' M R_{[i]}^{\prime\top})\right)}_{\text{正交于 } R_{[i]}' \text{ 的分量}}$$

当迭代充分多步后，$R_{[i]}'$ 渐近趋向主奇异方向，正交分量趋于零，从而得到：

$$\frac{R_{[i]}' M}{\|R_{[i]}' M\|_2} \approx R_{[i]}' + \frac{R_{[i]}' M - R_{[i]}'(R_{[i]}' M R_{[i]}^{\prime\top})}{R_{[i]}' M R_{[i]}^{\prime\top}}$$

整理即得 $\Delta r_M$ 的近似表达式，完成推导。

消融实验

核心设计选择消融（3B 模型，200B tokens）

消融结论

  • 仅 Retraction（无幂迭代）：性能与 Vanilla MoE 几乎持平。说明单纯的范数归一化不能带来改善，幂迭代是核心贡献。
  • 仅 Power Iteration（无 Retraction）：在 AdamW 和 Muon 优化器下出现训练崩溃（loss spike + 梯度异常），说明收缩步对训练稳定性至关重要。即使在 Hyperball 优化器下避免了崩溃，预训练 loss 仍上升约 0.003。
  • 完整 MPI：两步协同才能既保证稳定性又实现性能提升。

专家权重矩阵选择

在 $W_g$、$W_p$、$W_o$ 三种候选专家矩阵中，均未观察到显著的预训练 loss 或下游性能差异。默认选择 $W_g$ 作为幂迭代目标，因其在当前实验设置下具有微弱优势。

局限性

  • 单一专家矩阵选择：当前仅对 $W_g$（门控矩阵）执行幂迭代，未探索多矩阵组合（如 $W_g + W_p$ 的联合奇异方向）的潜力。
  • 超大规模验证缺失：实验规模最大为 11B 参数 / 350B tokens，尚未在 100B+ 参数级别验证 MPI 的效果是否持续。
  • MBPP 代码任务下降：在 3B 和 11B 规模的 MBPP 基准上，MPI 出现轻微性能下降（约 4–6 点），原因尚不明确，可能与代码任务对路由多样性的特殊需求有关。
  • 负载均衡机制待深究：MPI 带来的负载均衡改善被作者标注为"意外收获"，其内在机制尚未被充分理论化，留待未来工作。
  • 与 Expert Choice / Soft MoE 的兼容性：论文仅验证了与标准 Top-K 路由、辅助损失、z-loss 的兼容性，与 Expert Choice Routing 等非标准路由范式的兼容性未被探索。
  • 多专家矩阵幂迭代：每个专家由 $W_g, W_p, W_o$ 三个矩阵组成，如何联合利用三者的奇异信息是未来方向。

总结与启发

核心贡献总结

本文从一个简洁而深刻的线性代数观察出发：路由矩阵行向量作为专家的"代理"，其最优形态应是对应专家矩阵的主奇异方向。这一洞察将 MoE 路由器设计问题转化为一个有理论基础的优化问题，并提出了计算高效的 MPI 算法加以实现。

对 MoE 路由器设计的深度思考

1. 从"隐式学习"到"显式约束"的范式转变
传统 MoE 路由器依赖梯度下降隐式地学习路由行与专家特征的对应关系，这一过程缺乏明确的归纳偏置（Inductive Bias）。MPI 的贡献在于将"路由行应编码专家信息"这一直觉转化为可操作的显式约束，使得每个训练步都在主动推动路由-专家对齐。这与正则化方法的哲学一致：与其期待网络自发学到某种结构，不如直接在优化过程中强制这种结构。

2. 幂迭代作为"在线 SVD"的巧妙工程化
精确 SVD 的计算复杂度为 $O(D^2 d)$，对所有专家在每个训练步执行一次代价过高。幂迭代以 $O(Dd)$ 的代价实现"近似 SVD"，且每步只需单次矩阵向量乘积，与前向传播的计算模式完全兼容。这种"用迭代次数换计算精度"的思路是数值线性代数中的经典智慧，本文将其优雅地嵌入到深度学习训练循环中。

3. 球面流形约束的多重效益
收缩步（Retraction）表面上是为了数值稳定性而设计，但实际上带来了多重收益：消除路由行范数偏置（负载均衡改善）、将路由器参数约束在紧凑的参数空间中（正则化效果）、以及与 Hyperball Optimization 等现代优化器的天然兼容性。这提示我们，参数空间的几何约束可能是一个被低估的设计维度。

4. 对未来 MoE 研究的启示
MPI 的成功暗示了一个更广泛的研究方向：如何利用专家矩阵的谱结构来指导路由器设计？ 例如，是否可以利用多个奇异方向来设计多头路由器？是否可以利用奇异值的相对大小来动态调整专家的激活优先级？此外，MPI 与 Expert Merging、模型剪枝等下游技术的结合也值得探索——主奇异方向本身就是模型压缩的重要工具，路由行与之对齐后，是否能改善专家合并的质量？

5. 理论与实践的完美闭环
本文的另一个亮点是理论与实践的高度一致性：从 Rayleigh 商最大化的理论动机，到幂迭代的算法实现，再到流形梯度上升的等价性证明，最后到大规模预训练实验的经验验证，形成了完整的闭环。这种"有理论、有算法、有实验"的研究范式值得在 MoE 领域推广，以对抗当前许多路由器改进工作中理论依据不足的问题。
