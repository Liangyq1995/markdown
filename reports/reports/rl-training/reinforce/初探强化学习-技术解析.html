1.1 简介

强化学习（Reinforcement Learning，RL）是机器学习的一个重要分支，处理序贯决策（sequential decision making）任务。与预测任务不同，序贯决策中每次动作都会带来"后果"——改变环境状态，进而影响未来所有的决策和回报。

强化学习与预测的本质区别
  • 预测（监督学习）：给定输入，产生对目标的估计，不改变未来的数据分布。
  • 决策（强化学习）：给定状态，选择动作，动作会改变环境，进而影响后续所有可观测的数据分布。

正因如此，强化学习的数学形式与优化逻辑与有监督学习有根本性差异，本章将逐步揭示这一差异。

1.2 什么是强化学习

强化学习的核心是一个智能体（agent）与环境（environment）持续交互的过程。智能体通过感知环境状态、执行动作、接收奖励信号，逐步学习一个能最大化长期累积回报的决策策略。

三大核心要素

要素形式说明
感知$s_t \in \mathcal{S}$智能体观测到当前环境状态
决策（策略）$a_t \sim \pi(\cdot \mid s_t)$根据状态按策略采样动作
奖励$r_{t+1} \in \mathbb{R}$环境产生标量信号，衡量动作的即时好坏

智能体不仅感知环境，还能通过决策直接改变环境——这是与被动观测模型最本质的区别。

策略的数学定义

随机策略与确定性策略

随机策略：$\pi(a \mid s) = P[A_t = a \mid S_t = s]$，在每个状态 $s$ 给出动作的概率分布。

确定性策略：$a = \pi(s)$，在每个状态确定性地输出一个动作。

随机策略是更一般的形式，确定性策略是其特例（某个动作概率为 1，其余为 0）。许多理论分析在随机策略框架下进行，实际算法（如 DQN）常输出确定性策略。

1.3 强化学习的环境

强化学习的环境是一个动态随机过程——每轮交互中存在两类叠加的随机性，正是这两层随机性使得以"期望回报"作为优化目标成为必要。

两方面随机性

每轮状态转移中存在两类随机性，相互叠加：

  1. 动作的随机性：智能体按策略 $\pi(a \mid s_t)$ 随机采样动作 $a_t$
  2. 转移的随机性：环境按 $P(s_{t+1} \mid s_t, a_t)$ 随机采样下一状态 $s_{t+1}$

正是这两层随机性，使得即使策略和初始状态完全固定，每次交互产生的轨迹仍可能不同——这直接导致了以"回报的期望"作为优化目标的必要性。

1.4 强化学习的目标

智能体与环境交互时，每步都会获得即时奖励 $r_{t+1}$。强化学习的目标不是最大化单步奖励，而是最大化整个交互过程的累积折扣回报的期望——即价值（value）。本节依次定义回报、折扣因子、状态价值函数、动作价值函数及优势函数，并给出完整的推导。

1.4.1 回报（Return）$G_t$ 的定义

定义：累积折扣回报
$$G_t \;\triangleq\; \sum_{k=0}^{\infty} \gamma^k\, r_{t+k+1} \;=\; r_{t+1} + \gamma r_{t+2} + \gamma^2 r_{t+3} + \cdots$$

其中 $\gamma \in [0,1]$ 为折扣因子（见下节）；在有限回合（episodic）任务中，回合结束后 $r=0$，和式自然截断。

回报的递归形式（用于后续所有推导的基础）

推导：$G_t = r_{t+1} + \gamma G_{t+1}$
展开定义，将 $k=0$ 项分离：
$$G_t = \sum_{k=0}^{\infty} \gamma^k r_{t+k+1} = r_{t+1} + \sum_{k=1}^{\infty} \gamma^k r_{t+k+1}$$
对余下的和式变量替换 $j = k-1$（即 $k = j+1$）：
$$\sum_{k=1}^{\infty} \gamma^k r_{t+k+1} = \sum_{j=0}^{\infty} \gamma^{j+1} r_{t+j+2} = \gamma \sum_{j=0}^{\infty} \gamma^j r_{(t+1)+j+1}$$
认出右侧即为 $G_{t+1}$ 的定义：
$$\gamma \sum_{j=0}^{\infty} \gamma^j r_{(t+1)+j+1} = \gamma G_{t+1}$$
合并得到递归式：
$$\boxed{G_t = r_{t+1} + \gamma G_{t+1}}$$

此式表明：当前回报 = 即时奖励 + 折扣后的未来回报。这一递归是贝尔曼方程的直接来源。

1.4.2 折扣因子 $\gamma$ 的含义

$\gamma$ 取值行为语义典型场景
$\gamma = 0$完全短视，只关注即时奖励 $r_{t+1}$单步决策
$0 < \gamma < 1$兼顾即时与未来，距离越远权重指数衰减连续任务（需保证级数收敛）
$\gamma = 1$完全长远，等权重求和所有未来奖励有限回合任务（和式有限，可收敛）

收敛性：当 $\gamma < 1$ 且奖励有界（$|r_t| \leq r_{\max}$）时，$G_t \leq r_{\max} \cdot \frac{1}{1-\gamma} < \infty$，和式绝对收敛。

直观解释：距当前时刻 $k$ 步后的奖励 $r_{t+k+1}$ 的权重为 $\gamma^k$，指数衰减体现了"近期回报比远期回报更确定、更可信"的归纳偏置。

1.4.3 状态价值函数 $V^\pi(s)$

由于交互具有随机性，即使在相同状态和策略下，不同轨迹的回报 $G_t$ 也可能不同。因此强化学习关注的是回报的期望。

定义：状态价值函数
$$V^\pi(s) \;\triangleq\; \mathbb{E}_\pi\bigl[G_t \mid s_t = s\bigr]$$

含义：在策略 $\pi$ 下，从状态 $s$ 出发，沿轨迹交互所能获得的期望累积折扣回报。

下标 $\mathbb{E}_\pi$ 表示：期望对策略 $\pi$ 诱导的动作分布和环境的状态转移分布同时积分。

1.4.4 动作价值函数 $Q^\pi(s,a)$（Q 函数）

定义：动作价值函数
$$Q^\pi(s,a) \;\triangleq\; \mathbb{E}_\pi\bigl[G_t \mid s_t = s,\; a_t = a\bigr]$$

含义：在策略 $\pi$ 下，从状态 $s$ 先固定执行动作 $a$，之后再按策略 $\pi$ 交互，所能获得的期望累积折扣回报。

$Q^\pi$ 比 $V^\pi$ 更细粒度——它区分了同一状态下不同动作的好坏，是策略改进的直接依据。

1.4.5 $V^\pi$ 与 $Q^\pi$ 的关系推导

推导：$V^\pi(s) = \sum_a \pi(a \mid s)\, Q^\pi(s,a)$
从 $V^\pi$ 的定义出发：
$$V^\pi(s) = \mathbb{E}_\pi[G_t \mid s_t = s]$$
应用条件期望的迭代法则（law of iterated expectation），在 $a_t$ 上进一步条件化：
$$V^\pi(s) = \mathbb{E}_\pi\bigl[\mathbb{E}_\pi[G_t \mid s_t = s,\; a_t]\;\big|\; s_t=s\bigr]$$
内层期望正是 $Q^\pi(s, a_t)$ 的定义；外层期望对 $a_t$ 按策略 $\pi(\cdot \mid s)$ 加权求和：
$$\boxed{V^\pi(s) = \sum_{a \in \mathcal{A}} \pi(a \mid s)\, Q^\pi(s,a)}$$

物理含义：状态 $s$ 的价值 = 在该状态下按策略选取各动作的概率 × 对应动作价值的加权平均。

1.4.6 $Q^\pi(s,a)$ 的递归展开

推导：$Q^\pi(s,a) = r(s,a) + \gamma \sum_{s'} P(s'\mid s,a)\, V^\pi(s')$
从 $Q^\pi$ 的定义代入回报递归式 $G_t = r_{t+1} + \gamma G_{t+1}$：
$$Q^\pi(s,a) = \mathbb{E}_\pi\bigl[r_{t+1} + \gamma G_{t+1} \mid s_t=s,\; a_t=a\bigr]$$
利用期望的线性性拆分：
$$= \mathbb{E}_\pi[r_{t+1} \mid s_t=s, a_t=a] + \gamma\, \mathbb{E}_\pi[G_{t+1} \mid s_t=s, a_t=a]$$
第一项为即时奖励的条件期望，记作 $r(s,a)$：
$$\mathbb{E}_\pi[r_{t+1} \mid s_t=s, a_t=a] = r(s,a)$$
第二项对 $s_{t+1}$ 应用全概率公式，将期望展开为对下一状态的求和：
$$\mathbb{E}_\pi[G_{t+1} \mid s_t=s, a_t=a] = \sum_{s' \in \mathcal{S}} P(s'\mid s,a)\;\mathbb{E}_\pi[G_{t+1} \mid s_{t+1}=s']$$
认出 $\mathbb{E}_\pi[G_{t+1} \mid s_{t+1}=s'] = V^\pi(s')$（价值函数定义），代入得最终结果：
$$\boxed{Q^\pi(s,a) = r(s,a) + \gamma \sum_{s' \in \mathcal{S}} P(s'\mid s,a)\, V^\pi(s')}$$

含义：动作价值 = 即时奖励期望 + 折扣后的下一状态价值的转移期望。

1.4.9 优势函数 $A^\pi(s,a)$

定义：优势函数衡量动作相对于平均水平的"超额价值"
$$A^\pi(s,a) \;\triangleq\; Q^\pi(s,a) - V^\pi(s)$$

含义：在状态 $s$ 下采取动作 $a$，相比按策略 $\pi$ 平均选择动作，额外带来的期望回报。

  • $A^\pi(s,a) > 0$：动作 $a$ 比平均水平好，策略改进应提高其概率
  • $A^\pi(s,a) < 0$：动作 $a$ 比平均水平差，策略改进应降低其概率
  • $A^\pi(s,a) = 0$：动作 $a$ 与平均水平持平

重要性质：$\sum_a \pi(a\mid s) A^\pi(s,a) = \sum_a \pi(a\mid s)[Q^\pi(s,a) - V^\pi(s)] = V^\pi(s) - V^\pi(s) = 0$，即策略 $\pi$ 下所有动作的加权平均优势为零。

优势函数在策略梯度算法（PPO、TRPO 等）中用于减小梯度估计的方差（以 $V^\pi(s)$ 作为基线）。

1.5 强化学习中的数据

强化学习的训练数据来自智能体与环境的交互，与监督学习的固定数据集有根本差异。本节引入占用度量（occupancy measure），用数学语言精确刻画"策略决定数据分布"这一核心事实。

占用度量的定义

定义：归一化折扣占用度量
$$\rho^\pi(s,a) \;\triangleq\; (1-\gamma)\sum_{t=0}^{\infty} \gamma^t\, P_\pi(S_t=s,\; A_t=a)$$

其中 $P_\pi(S_t=s, A_t=a)$ 是在策略 $\pi$ 下，$t$ 时刻恰好处于状态 $s$ 并采取动作 $a$ 的概率。

前置因子 $(1-\gamma)$ 保证归一化（当 $\gamma < 1$ 时 $\sum_{s,a}\rho^\pi(s,a) = 1$），使其成为状态-动作空间上的合法概率分布。

直觉：$\rho^\pi(s,a)$ 衡量的是在整个交互过程中，以 $\gamma^t$ 折扣权重加权，智能体处于状态 $s$ 并执行动作 $a$ 的概率——即"哪些状态-动作对会被访问、访问多频繁"的分布。

用占用度量重写优化目标

推导：期望回报 = 奖励函数在占用度量下的期望
策略 $\pi$ 的优化目标——期望累积折扣回报：
$$J(\pi) = \mathbb{E}_\pi[G_0] = \mathbb{E}_\pi\!\left[\sum_{t=0}^{\infty}\gamma^t r_{t+1}\right]$$
利用期望的线性性将无限和与期望交换：
$$J(\pi) = \sum_{t=0}^{\infty} \gamma^t\, \mathbb{E}_\pi[r_{t+1}]$$
对 $\mathbb{E}_\pi[r_{t+1}]$ 应用全概率公式，展开为对 $(s,a)$ 的求和：
$$\mathbb{E}_\pi[r_{t+1}] = \sum_{s,a} P_\pi(S_t=s,A_t=a)\, r(s,a)$$
代入并交换求和次序：
$$J(\pi) = \sum_{s,a}\left[\sum_{t=0}^{\infty}\gamma^t P_\pi(S_t=s,A_t=a)\right]r(s,a)$$
令 $\mu^\pi(s,a) = \sum_{t=0}^{\infty}\gamma^t P_\pi(S_t=s,A_t=a)$（未归一化占用），则归一化后 $\rho^\pi = (1-\gamma)\mu^\pi$，从而：
$$\boxed{J(\pi) = \frac{1}{1-\gamma}\sum_{s,a}\rho^\pi(s,a)\, r(s,a) = \frac{1}{1-\gamma}\,\mathbb{E}_{(s,a)\sim\rho^\pi}[r(s,a)]}$$

结论：最大化期望回报等价于最大化奖励函数在占用度量 $\rho^\pi$ 下的期望。

占用度量的核心性质

性质：占用度量与策略一一对应
给定两个策略 $\pi_1, \pi_2$ 及其与同一 MDP 交互得到的占用度量 $\rho^{\pi_1}, \rho^{\pi_2}$：
$\pi_1 = \pi_2 \;\Longleftrightarrow\; \rho^{\pi_1} = \rho^{\pi_2}$

即：策略唯一确定占用度量，占用度量唯一确定策略——两者之间存在双射关系。

逆向重构策略：给定占用度量 $\rho^\pi$，可按下式恢复策略：

$$\pi(a\mid s) = \frac{\rho^\pi(s,a)}{\sum_{a'}\rho^\pi(s,a')}$$

此性质的两个关键推论：

  1. 策略改变 → 占用度量改变 → 训练数据分布改变（强化学习的核心难点）
  2. 寻找最优策略等价于寻找最优占用度量（可将 RL 转化为分布优化问题）

1.6 强化学习的独特性

了解了强化学习的数学结构后，我们回过头来从优化视角对比有监督学习与强化学习的本质差异。

优化目标的公式对比

有监督学习
$$\min_f\; \mathbb{E}_{(x,y)\sim\mathcal{D}}\bigl[\mathcal{L}(y,\, f(x))\bigr]$$
  • 优化变量：模型参数（$f$ 的参数）
  • 数据分布 $\mathcal{D}$：固定不变
  • 损失函数 $\mathcal{L}$：固定
  • 数据：独立同分布（i.i.d.）
强化学习
$$\max_\pi\; \mathbb{E}_{(s,a)\sim\rho^\pi}\bigl[r(s,a)\bigr]$$
  • 优化变量：策略 $\pi$
  • 奖励函数 $r(s,a)$：固定不变
  • 数据分布 $\rho^\pi$：随策略改变
  • 数据：非独立、非同分布

本质差异的深度分析

一句话总结：监督学习改变目标函数，强化学习改变数据分布
维度有监督学习强化学习
改变什么模型 $f$（目标函数的形状）策略 $\pi$（数据分布 $\rho^\pi$）
不变什么训练数据分布 $\mathcal{D}$奖励函数 $r(s,a)$
数据特性i.i.d.，分布稳定非 i.i.d.，分布随策略漂移
优化稳定性标准凸优化/SGD 可直接适用需处理"分布漂移"（distribution shift）
泛化依据泛化误差（generalization error）价值估计误差 + 策略改进单调性

为什么数据分布随策略改变是核心难点

强化学习三大独特挑战
  1. 数据分布漂移（Distribution Shift）： 策略 $\pi$ 更新一步后，$\rho^\pi$ 随之改变，之前采集的样本不再来自新策略的分布。直接用旧数据优化新策略会引入偏差——这是 on-policy 与 off-policy 算法的根本分野。
  2. 探索-利用权衡（Exploration-Exploitation Dilemma）： 智能体如果不执行某个动作，就永远无法观测到该动作的回报——"未观测到的数据"无法用于监督学习式的优化。智能体必须主动探索，但探索本身消耗学习资源。
  3. 奖励信号稀疏与延迟（Sparse & Delayed Reward）： 奖励往往只在任务结束时给出（如棋局胜负），中间步骤的功劳无法直接分配——即信用分配问题（credit assignment problem）。

$Q$ 的展开$Q^\pi(s,a) = r(s,a) + \gamma\sum_{s'} P(s'\mid s,a)\, V^\pi(s')$
贝尔曼方程（V）$V^\pi(s) = \sum_a \pi(a\mid s)\!\left[r(s,a) + \gamma\sum_{s'} P(s'\mid s,a) V^\pi(s')\right]$
贝尔曼方程（Q）$Q^\pi(s,a) = r(s,a) + \gamma\sum_{s'} P(s'\mid s,a)\sum_{a'}\pi(a'\mid s') Q^\pi(s',a')$
优势函数$A^\pi(s,a) = Q^\pi(s,a) - V^\pi(s)$
占用度量$\rho^\pi(s,a) = (1-\gamma)\sum_{t=0}^\infty \gamma^t P_\pi(S_t=s, A_t=a)$
优化目标（等价形式）$J(\pi) = \frac{1}{1-\gamma}\mathbb{E}_{(s,a)\sim\rho^\pi}[r(s,a)]$
强化学习与监督学习的本质差异（一句话）

监督学习在固定数据分布下优化模型；强化学习通过改变策略来改变数据分布，进而最大化固定奖励函数下的期望——这一"数据分布随学习动态变化"的特性，是强化学习独有难点与算法设计的根本出发点。
