一、Meta-Learning：学会快速学习

传统机器学习需要大量标注数据才能训练新任务模型；Meta-Learning（元学习）的目标是让模型"学会如何学习"——经过在大量任务上训练后，面对只有少量样本的新任务，能够快速适应。

核心直觉：人类看到三张猫的照片就能识别猫，是因为积累了"学习策略"。Meta-Learning 试图让模型也具备这种能力。

1.1 问题设定：N-way K-shot

Meta-Learning 的标准评测范式称为 N-way K-shot 分类：

  • Support Set：每类 $K$ 个样本，共 $N$ 类，用于快速适应
  • Query Set：待预测样本，用于评估适应效果
  • Episode：每次训练从任务分布 $p(\mathcal{T})$ 采样一个任务，构成一个 episode

形式化目标：

$$\theta^* = \arg\max_\theta \mathbb{E}_{\mathcal{T} \sim p(\mathcal{T})} \left[ \mathbb{E}_{(x,y) \sim \mathcal{T}} \left[ \log P_\theta(y \mid x, \mathcal{D}^\text{support}_\mathcal{T}) \right] \right]$$

1.3 Metric-based：度量学习

Siamese Network

使用两个共享权重的子网络分别编码两个输入，通过对比损失学习距离度量：

$$\mathcal{L} = y \cdot d(f(x_1), f(x_2))^2 + (1-y) \cdot \max(0,\, m - d(f(x_1), f(x_2)))^2$$

其中 $y=1$ 表示同类，$m$ 是间隔超参数，$d$ 通常为欧氏距离。

Prototypical Networks

每类的"原型"是该类所有 support 样本嵌入的均值：

$$\mathbf{c}_k = \frac{1}{|S_k|} \sum_{(x_i, y_i) \in S_k} f_\phi(x_i)$$

分类概率通过 softmax over 欧氏距离得到：

$$P(y=k \mid x) = \frac{\exp\left(-d(f_\phi(x), \mathbf{c}_k)\right)}{\sum_{k'} \exp\left(-d(f_\phi(x), \mathbf{c}_{k'})\right)}$$

Matching Networks

引入注意力机制，用 support set 对 query 进行加权投票：

$$\hat{y} = \sum_{i=1}^{k} a(x, x_i) \cdot y_i, \quad a(x, x_i) = \frac{\exp(\cos(f(x), g(x_i)))}{\sum_j \exp(\cos(f(x), g(x_j)))}$$

$f$ 和 $g$ 分别是 query 和 support 的编码器，可用 LSTM 引入 support set 的上下文信息（full context embedding）。

1.4 MAML：模型无关元学习

MAML（Model-Agnostic Meta-Learning） 由 Finn et al. 2017 提出，核心思想是：找到一组初始化参数 $\theta$，使得对任意新任务 $\mathcal{T}_i$，只需少量梯度步就能达到很好的性能。

为什么 MAML 有效？
MAML 并不是找一个"平均好"的参数，而是找一个"容易被快速优化"的参数。这个初始化点位于所有任务最优参数的几何中心附近，每个任务只需沿各自的梯度方向走几步就能到达。

内层循环（Task-level adaptation）

对任务 $\mathcal{T}_i$，从 support set 计算损失并更新参数（可执行 $k$ 步）：

$$\theta'_i = \theta - \alpha \nabla_\theta \mathcal{L}_{\mathcal{T}_i}(f_\theta)$$

外层循环（Meta-level optimization）

用适应后的参数在 query set 上评估，并对原始参数 $\theta$ 进行更新：

$$\theta \leftarrow \theta - \beta \nabla_\theta \sum_{\mathcal{T}_i \sim p(\mathcal{T})} \mathcal{L}_{\mathcal{T}_i}(f_{\theta'_i})$$

展开后可见需要二阶导数（Hessian-vector product）：

$$\nabla_\theta \mathcal{L}_{\mathcal{T}_i}(f_{\theta'_i}) = \nabla_{\theta'_i} \mathcal{L}_{\mathcal{T}_i}(f_{\theta'_i}) \cdot \left(I - \alpha \nabla^2_\theta \mathcal{L}_{\mathcal{T}_i}(f_\theta)\right)$$

1.5 Reptile：简化版 MAML

Reptile（Nichol et al., 2018，OpenAI）是 MAML 的一阶近似，无需二阶导数，实现更简单，计算更高效。

核心更新规则

对每个任务，用 SGD 执行 $k$ 步更新，得到任务最优参数 $W^*_i$，然后将元参数向所有任务最优参数的平均方向移动：

$$\theta \leftarrow \theta + \epsilon \cdot \frac{1}{n} \sum_{i=1}^{n} (W^*_i - \theta)$$

理论分析

Reptile 的更新方向可以分解为两项：

$$\text{Reptile 更新} \approx \underbrace{\mathbb{E}_\mathcal{T}[\nabla \mathcal{L}_\mathcal{T}]}_{\text{联合训练项（迁移学习）}} + \underbrace{\text{任务间梯度内积最大化}}_{\text{MAML 核心项}}$$

第二项即 MAML 的核心：最大化不同任务梯度的内积，使初始化对所有任务都"指向正确方向"。

1.6 Model-based：记忆增强网络

MANN（Memory-Augmented Neural Networks）

MANN 使用外部记忆矩阵 $M \in \mathbb{R}^{N \times W}$，通过注意力机制读写记忆：

  • 读操作：$r_t = \sum_i w^r_t(i) \cdot M_t(i)$，权重由内容寻址决定
  • 写操作（LRUA）：最近最少使用的记忆槽被优先覆盖，确保记忆不被无限稀释

内容寻址权重：$w^c_t(i) = \frac{\exp(K(k_t, M_t(i)) / \tau)}{\sum_j \exp(K(k_t, M_t(j)) / \tau)}$，其中 $K$ 为余弦相似度，$\tau$ 为温度参数。

NTM（Neural Turing Machine）

NTM 将记忆访问分为内容寻址和位置寻址两阶段，支持更灵活的读写模式，是 MANN 的基础架构。位置寻址允许顺序访问（卷积偏移），适合程序性任务。

二、Meta Reinforcement Learning：元强化学习

将 Meta-Learning 思想应用于强化学习（RL），目标是训练一个 agent，使其在面对新的 MDP 时，能够用少量交互快速找到最优策略。

挑战：RL 中没有直接的监督信号，奖励稀疏且延迟；任务分布通常是不同的 MDP，而非不同的分类任务。

2.1 元 RL 问题设定

元 RL 的任务分布 $p(\mathcal{M})$ 是 MDP 的分布，每个 $\mathcal{M}_i = (\mathcal{S}, \mathcal{A}, P_i, R_i, \gamma)$，其中转移函数 $P_i$ 和奖励函数 $R_i$ 随任务变化。

目标：找到策略 $\pi_\theta$，使得在采样到新任务 $\mathcal{M}_i$ 后，经过少量 episode 的交互，累积回报最大化：

$$\theta^* = \arg\max_\theta \mathbb{E}_{\mathcal{M}_i \sim p(\mathcal{M})} \left[ \mathbb{E}_{\tau \sim \pi_{\theta'_i}} \left[ R(\tau) \right] \right]$$

2.2 RL²：用 LSTM 跨 Episode 记忆

RL²（Duan et al., 2016 / Wang et al., 2016）是最直接的 Model-based 元 RL 方法：将整个学习过程视为一个 RNN 的前向传播，LSTM 的隐状态充当"跨 episode 的记忆"。

输入设计

每个时间步，LSTM 的输入不仅包含当前观测 $o_t$，还包含上一步动作 $a_{t-1}$、奖励 $r_{t-1}$ 和终止标志 $d_{t-1}$：

$$h_t = \text{LSTM}(o_t, a_{t-1}, r_{t-1}, d_{t-1};\, h_{t-1})$$ $$a_t \sim \pi_\theta(\cdot \mid h_t)$$
关键设计：LSTM 在同一任务的多个 episode 中保持隐状态不重置。这使得模型能够跨 episode 积累对该任务的理解（如探索过哪些状态、哪些动作有效），从而实现隐式的"快速适应"。

2.3 MAML for RL：Policy Gradient 版本

将 MAML 应用于 RL，内层循环使用 policy gradient（如 REINFORCE）更新策略参数：

内层循环

在任务 $\mathcal{T}_i$ 上采集轨迹，用 REINFORCE 更新：

$$\theta'_i = \theta + \alpha \nabla_\theta \mathbb{E}_{\tau \sim \pi_\theta} [R(\tau) \mid \mathcal{T}_i]$$ $$= \theta + \alpha \mathbb{E}_{\tau \sim \pi_\theta} \left[ R(\tau) \sum_t \nabla_\theta \log \pi_\theta(a_t \mid s_t) \right]$$

外层循环

用适应后的策略 $\pi_{\theta'_i}$ 在任务上再次采集轨迹，计算外层目标：

$$\theta \leftarrow \theta + \beta \nabla_\theta \sum_i \mathbb{E}_{\tau \sim \pi_{\theta'_i}} [R(\tau) \mid \mathcal{T}_i]$$
挑战：RL 中的 MAML 需要对 policy gradient 进行二阶求导，计算开销极大。实践中通常使用 TRPO 作为外层优化器，或采用 ProMP 等方差减小技术。

2.4 记忆增强元 RL

除了 RL²，还有其他将记忆增强引入元 RL 的方法：

2.5 元 RL 的探索问题

元 RL 中的探索比监督学习的元学习更复杂：agent 在测试任务上的探索行为必须高效，因为交互次数有限。

  • MAESN：在隐变量空间中学习结构化探索策略，不同隐变量对应不同探索模式
  • PEARL：用概率编码器推断任务上下文，结合 SAC 实现高效的 off-policy 元 RL
  • E-MAML：将探索 episode 的奖励也纳入外层目标，显式鼓励信息收集行为

三、Domain Randomization：Sim2Real 迁移

Domain Randomization（域随机化） 是一种让在仿真中训练的策略能够直接迁移到真实世界的技术。核心思想是：通过在训练时随机化仿真环境的各种参数，使得真实世界看起来像是仿真中"已经见过的某个变体"。

Sim2Real 的核心困境：仿真与真实世界之间存在不可避免的差距（Reality Gap）——物理参数不准确、传感器噪声不同、视觉外观差异等。Domain Randomization 通过"用随机性覆盖差距"来解决这一问题。

3.3 Uniform Domain Randomization

最基础的方法：对每个参数 $\xi_i$ 在预设范围 $[\xi_i^{\min}, \xi_i^{\max}]$ 内均匀采样：

$$\xi \sim \text{Uniform}(\xi^{\min}, \xi^{\max})$$

策略在随机化参数下训练，目标是最大化期望回报：

$$\pi^* = \arg\max_\pi \mathbb{E}_{\xi \sim p(\xi)} \left[ \mathbb{E}_{\tau \sim \pi, \xi} [R(\tau)] \right]$$

策略通常将随机化参数 $\xi$ 作为输入（或使用 LSTM 从历史观测中隐式推断），以实现自适应行为。

OpenAI 的 Dactyl 项目（2019）使用 LSTM 策略 + 大规模 Domain Randomization，成功让机械手在真实世界中完成魔方旋转任务。

3.5 Guided Domain Randomization：自适应随机化

均匀随机化的问题：随机化范围太大会使任务过难，太小则泛化不足。Guided DR 通过自适应调整随机化范围来解决这一问题。

ADR（Automatic Domain Randomization）

OpenAI 提出的 ADR 算法：根据策略的当前性能自动扩大或缩小随机化范围。

对每个参数 $\xi_i$，维护一个范围 $[\phi_i^L, \phi_i^H]$：

  • 如果策略在当前范围内表现良好（超过阈值 $p_{\text{high}}$），则扩大范围：$\phi_i^H \leftarrow \phi_i^H + \delta$
  • 如果表现差（低于阈值 $p_{\text{low}}$），则缩小范围：$\phi_i^H \leftarrow \phi_i^H - \delta$

CMA-ES 优化随机化参数

另一种方法是用 CMA-ES（协方差矩阵自适应进化策略）来优化随机化参数分布，使得训练后的策略在真实世界中表现最好：

$$\phi^* = \arg\max_\phi \mathbb{E}_{\xi \sim p(\xi;\phi)} \left[ \text{RealWorldPerformance}(\pi_\phi) \right]$$

四、Evolution Strategies：进化策略

Evolution Strategies（ES，进化策略） 是一类受生物进化启发的黑盒优化算法，不需要梯度信息，通过对参数空间进行采样、评估和更新来优化目标函数。

与梯度优化的对比：梯度下降需要目标函数可微；ES 只需要能够评估目标函数值，因此可以优化不可微、不连续甚至随机的目标。

4.1 基本框架

ES 的基本流程：从参数分布中采样 $\rightarrow$ 评估每个样本 $\rightarrow$ 更新分布均值 $\rightarrow$ 重复。

4.2 CMA-ES：协方差矩阵自适应

CMA-ES（Covariance Matrix Adaptation Evolution Strategy） 是目前最强大的无梯度优化算法之一，通过自适应更新协方差矩阵来控制搜索方向和步长。

采样

从多元高斯分布采样种群：

$$\theta_i^{(g+1)} = \mu^{(g)} + \sigma^{(g)} \cdot \mathcal{N}(0, C^{(g)}), \quad i = 1, \ldots, \lambda$$

其中 $\mu^{(g)}$ 是当前均值，$\sigma^{(g)}$ 是步长（全局缩放），$C^{(g)}$ 是协方差矩阵。

均值更新

对种群按适应度排序，用加权均值更新：

$$\mu^{(g+1)} = \sum_{i=1}^{\mu} w_i \cdot \theta_{i:\lambda}^{(g+1)}$$

其中 $\theta_{i:\lambda}$ 表示第 $i$ 好的个体，权重 $w_i \propto \ln(\mu + 0.5) - \ln(i)$（对数递减）。

协方差矩阵更新

CMA-ES 维护两个演化路径（evolution path）$p_\sigma$ 和 $p_c$：

$$p_\sigma^{(g+1)} = (1 - c_\sigma) p_\sigma^{(g)} + \sqrt{c_\sigma(2-c_\sigma)\mu_\text{eff}} \cdot C^{(g)^{-1/2}} \cdot \frac{\mu^{(g+1)} - \mu^{(g)}}{\sigma^{(g)}}$$ $$p_c^{(g+1)} = (1 - c_c) p_c^{(g)} + h_\sigma \sqrt{c_c(2-c_c)\mu_\text{eff}} \cdot \frac{\mu^{(g+1)} - \mu^{(g)}}{\sigma^{(g)}}$$

协方差矩阵更新（秩一更新 + 秩 $\mu$ 更新）：

$$C^{(g+1)} = (1 - c_1 - c_\mu) C^{(g)} + c_1 p_c p_c^T + c_\mu \sum_{i=1}^{\mu} w_i \frac{(\theta_{i:\lambda} - \mu^{(g)})(\theta_{i:\lambda} - \mu^{(g)})^T}{\sigma^{(g)^2}}$$

步长控制

通过累积路径长度控制（CSA）自适应调整步长：

$$\sigma^{(g+1)} = \sigma^{(g)} \cdot \exp\left(\frac{c_\sigma}{d_\sigma} \left(\frac{\|p_\sigma^{(g+1)}\|}{E\|\mathcal{N}(0,I)\|} - 1\right)\right)$$

4.3 OpenAI ES：并行化神经网络优化

OpenAI ES（Salimans et al., 2017）将 ES 应用于深度神经网络优化，核心创新是：利用固定随机种子实现极高效的通信，使得在 1000+ 个 CPU 上并行训练成为可能。

核心公式

对参数 $\theta$ 添加高斯噪声，估计梯度：

$$\nabla_\theta \mathbb{E}_{\epsilon \sim \mathcal{N}(0,I)} [F(\theta + \sigma\epsilon)] \approx \frac{1}{n\sigma} \sum_{i=1}^{n} F(\theta + \sigma\epsilon_i) \cdot \epsilon_i$$

更新规则：

$$\theta_{t+1} = \theta_t + \alpha \cdot \frac{1}{n\sigma} \sum_{i=1}^{n} F(\theta_t + \sigma\epsilon_i) \cdot \epsilon_i$$

高效并行通信

关键技巧：每个 worker 只需发送一个随机种子（整数），而非整个参数向量。接收方用相同种子重新生成噪声 $\epsilon_i$，然后用收到的 $F_i$ 值计算梯度更新。

工程技巧

  • 适应度塑形（Fitness Shaping）：对奖励进行排名归一化，减少离群值影响：$F_i \leftarrow \text{rank}(F_i) / (n-1) - 0.5$
  • 镜像采样（Antithetic Sampling）：同时评估 $\theta + \sigma\epsilon$ 和 $\theta - \sigma\epsilon$，减少方差
  • 权重衰减：$\theta_{t+1} = (1-\lambda)\theta_t + \alpha \cdot \hat{g}$，防止参数过大
  • 虚拟批归一化：固定参考批次的统计量，使不同噪声下的网络输出可比

4.4 NES：自然进化策略

NES（Natural Evolution Strategies） 将自然梯度的思想引入 ES，用 Fisher 信息矩阵对梯度进行归一化，使更新在参数分布空间中更加均匀。

对数似然梯度技巧

对参数化分布 $p_\psi(\theta)$，目标是最大化期望适应度：

$$J(\psi) = \mathbb{E}_{\theta \sim p_\psi} [F(\theta)] = \int F(\theta) p_\psi(\theta) d\theta$$

利用对数似然梯度技巧：

$$\nabla_\psi J(\psi) = \mathbb{E}_{\theta \sim p_\psi} [F(\theta) \nabla_\psi \log p_\psi(\theta)]$$

自然梯度更新

普通梯度在欧氏空间中更新，可能导致分布变化不均匀。自然梯度用 Fisher 信息矩阵 $F_\psi$ 进行归一化：

$$\tilde{\nabla}_\psi J = F_\psi^{-1} \nabla_\psi J(\psi)$$

对于高斯分布 $p_\psi = \mathcal{N}(\mu, \sigma^2 I)$，Fisher 信息矩阵的逆有解析形式，使得自然梯度计算高效。

5.4 开放问题与未来方向

  • 任务分布的设计：Meta-Learning 的性能高度依赖训练任务分布与测试任务分布的匹配程度，如何自动生成多样化任务仍是开放问题
  • 持续元学习：如何在不遗忘旧任务的情况下持续学习新任务（Meta-Continual Learning）
  • DR 的上限：过度随机化可能使任务过难，如何找到最优随机化范围是关键挑战
  • ES 的扩展性：CMA-ES 的 $O(n^2)$ 协方差矩阵限制了其在大规模神经网络中的应用，分块/低秩近似是研究方向
  • 元 RL 的样本效率：尽管测试时样本高效，元 RL 的训练阶段仍需大量样本，如何提升训练效率是重要方向
