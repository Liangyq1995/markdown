一、从逻辑到算术

编译好的数据集不会自己学习。模型边界上，数据通过 矩阵乘、激活、梯度更新 变成行为——这是 Silicon Contract 在 Algorithm 轴上的原子操作。

War Story：Ariane 5 Flight 501 (1996)

复用 Ariane 4 惯性参考软件；更快水平速度使 64-bit 值溢出 protected conversion → 异常关闭制导数据 → 约 40 s 后解体。教训：数值范围与物理 regime 是系统契约，与 ML 中 FP16 溢出 → Inf/NaN 静默传播同构。

MNIST 28×28 手写数字识别（本章贯穿网络）：一次前向约 109,184 MAC，无一分支——bug 在 learning rate、饱和激活、激活内存，不在 if-else 语法。

1.1 深度学习的系统定义

Deep Learning：通过多层非线性变换从原始数据学习层次特征，用增加 $O$（算量）换泛化，免手工特征。深度 $k$ 层可组合 $k$ 级抽象；铁律绑定约束从「算法（手工特征）」转向「机器（算力/内存）」。

二、三种计算范式（同一 MNIST 数字）

范式算量/内存硬件
显式规则~100 次比较，784 BCPU L1 即可
HOG + SVM7×7 细胞×9 方向 → 441 维；~8000 ops，~2 KBCPU SIMD
小型 MLP109,184 MAC；权重+激活需 GPU 并行算力绑定

HOG：8×8 像素格梯度方向直方图（Dalal & Triggs 2005）——专家设计、CPU 友好但不可跨域迁移。AlexNet (2012) 双 GTX 580：每卡仅 3 GB VRAM，模型数学超单卡内存 被迫模型并行——系统约束驱动架构先例。

三、神经网络基础

3.1 单层与参数量

784→128→10 MNIST MLP：

$$W_1 \in \mathbb{R}^{128 \times 784},\; b_1 \in \mathbb{R}^{128} \Rightarrow 128 \times 784 + 128 = 100{,}480$$ $$W_2 \in \mathbb{R}^{10 \times 128},\; b_2 \in \mathbb{R}^{10} \Rightarrow 1{,}290 \quad \text{合计 } \approx 101{,}770 \text{ 参数}$$

batch=32 前向 MAC：$32 \times (784 \times 128 + 128 \times 10) \approx 3.5 \times 10^6$（不含激活等非线性开销）。

3.2 激活函数对比

激活公式梯度/系统
Sigmoid$\sigma(x)=1/(1+e^{-x})$20 层链式 $\approx 0.25^{20} \sim 10^{-12}$ → 消失梯度
ReLU$\max(0,x)$正区梯度=1；第 6 章 ResNet 直连进一步保梯度
Softmax$e^{z_i}/\sum_j e^{z_j}$多类输出；数值稳定需 $z_i - \max(z)$

3.3 张量布局代价

ImageNet 224×224×3 ≈ 151 KB。NCHW↔NHWC 转置：读+写 ≈ 301 KB/图 纯内存流量、零算术——latency 预算在「有用计算」前就被吃掉。

四、学习过程

4.1 前向与交叉熵

$$\mathcal{L} = -\sum_{c=1}^{C} y_c \log \hat{p}_c \quad \text{单样本正确类 } y_k=1$$

logits $z$ → softmax $\hat{p}$ → CE；$\partial \mathcal{L}/\partial z_i = \hat{p}_i - y_i$（简洁梯度形式，反向实现友好）。

4.2 反向传播（矩阵形式）

两层网络：$\delta^{(2)} = \hat{y} - y$，$\delta^{(1)} = (W_2^T \delta^{(2)}) \odot \sigma'(z^{(1)})$。训练须存每层激活供 backward → 激活内存 ≈ batch × 各层激活元素和，常为推理的 2–3×。

4.3 SGD 更新

$$W \leftarrow W - \eta \frac{1}{B}\sum_{i=1}^{B} \nabla_W \mathcal{L}_i \quad \eta=0.01 \text{ 过大可振荡；} \eta=10^{-4} \text{ 过慢}$$

学习率是系统旋钮：不报错，只表现为 loss NaN 或平台期。

六、USPS 部署案例

美国邮政 1990 年代 OCR：16×16 灰度、10 类。比 MNIST 更小输入 → 更少 MAC，适合嵌入式；但邮件字体/污渍/扫描噪声与实验室 MNIST 分布不同——再次说明数据轴设上限（第 4 章 lab-to-field）。

八、谬误与总结

谬误现实
「看懂 API 就够」维度/精度/学习率错误无 stack trace
「更深 = 更宽 shallow 网络」深度提供组合层次，非参数量 alone
「训练 acc 高即可部署」预处理/量化/延迟未纳入同一数学契约
  • NN = 算术 workload：MAC、激活内存、梯度链
  • MNIST：规则 ~100 ops → HOG ~8k → MLP ~109k MAC
  • Sigmoid 深度 → ReLU/ResNet；布局转置纯 $D_{\text{vol}}$
