1. 概述

标题Read It Back: Pretrained MLLMs Are Zero-Shot Reward Models for Text-to-Image Generation
核心问题如何在无需偏好标签、无需奖励模型微调、无需问题分解的前提下，把任意预训练 MLLM 直接当作文本到图像生成强化学习的奖励模型？SpectraReward 给出的答案是：度量原始 prompt 能否从生成图像中“读回”——用单次 image-conditioned teacher-forced 前向得到 prompt 的平均 log-likelihood 作为奖励。
核心贡献(1) SpectraReward：training-free、开箱即用的 prompt-likelihood 奖励函数；(2) Self-SpectraReward：统一多模态模型（UMM）中策略自身的理解分支充当其生成分支的奖励模型，形成无外部依赖的闭环自改进；(3) 覆盖 2 个扩散模型 / 3 种 RL 算法 / 9 个 reward MLLM backbone（4B–235B，4 个 MLLM 家族）/ 5 个 OOD 基准的大规模 RL 研究。
作者 / 机构Runhui Huang, Qihui Zhang, Zhe Liu, Yu Gao, Jie Wu, Hengshuang Zhao · The University of Hong Kong（港大）、ByteDance Seed（字节跳动）、Peking University（北京大学）
开源地址Project Page: https://huangrh99.github.io/SpectraReward/

图像生成强化学习（RL）的成败取决于两大支柱：优化算法决定长程训练的稳定性，而奖励模型决定策略最终能达到的上限。后者尤其难设计——既要在判别力上足够强，又要工程上高效、可复现。当前主流要么依赖昂贵的人类偏好标注与奖励模型微调（成本高、迭代重、与 MLLM 预训练分布存在偏移），要么用预训练 MLLM 做 zero-shot 判官（直接打分或问题分解），但前者受判分校准与噪声影响、后者引入两阶段流水线与分解质量瓶颈。

本文提出 SpectraReward，跳过“让 MLLM 判断图像”或“让 MLLM 回答分解问题”这两条路径，转而直接调用 MLLM 最根本的能力——看图并把它与语言描述对齐。具体做法：把生成图像作为视觉条件喂给冻结的 MLLM，对原始 prompt 做一次 teacher-forced 前向，得到每个 prompt token 的 image-conditioned log-likelihood；这些逐 token 似然构成所谓“语义谱（semantic spectrum）”，对其取平均即得到标量奖励。该奖励直接复用 MLLM 在大规模预训练中学到的图文对齐知识，无需偏好标签、无需奖励模型微调、无需打分提示或问题分解。

在统一多模态模型（UMM，如 BAGEL）上，SpectraReward 退化为一个特例 Self-SpectraReward：策略自身的理解分支充当其生成分支的奖励模型，二者共享 tokenizer、视觉编码器与预训练分布，从而奖励信号天然对齐于策略自身的生成图像分布，形成无外部奖励模型、无外部知识的闭环自改进。实验表明：SpectraReward 与 Self-SpectraReward 在 5 个 OOD 基准上一致显著超越 BAGEL 基线与 AlphaGRPO；更反直觉的是——更大的 reward MLLM 并不总更好，而 Self-SpectraReward 可匹敌甚至超过大 4×–30× 的外部 reward MLLM，提示“奖励-策略对齐”是与“奖励模型规模”同等关键的因素。

2. 研究背景与动机

2.1 T2I 强化学习与奖励模型的三条技术路线

图像生成 RL 的成功依赖两个互补支柱：优化算法（如 FlowGRPO、AWM、DiffusionNFT）与奖励模型。论文把现有 T2I 奖励模型归纳为三条谱系，并逐一指出其局限：

  • 偏好数据训练的奖励模型（ImageReward、Pick-a-Pic、HPSv2/v3、VisionReward、OneReward、RewardDance 等）：基于大规模人类偏好或 prompt–image 对齐数据训练判别器。能力强，但受限于对“与文本无关的美学细节”的固有偏置，且需要昂贵标注、训练开销大，并使分布偏离 MLLM 预训练知识。
  • 微调 MLLM 作奖励架构：把判别器升级为微调后的 MLLM，提升上限，但仍需大量标注数据与训练开销，且分布偏移问题依旧。
  • 预训练 MLLM 作 zero-shot 判官（VIEScore、Uniworld-V2 隐式反馈等）：免训练，但通常走两条子路——(a) 直接标量打分，对判分校准与打分噪声敏感；(b) 问题分解（AlphaGRPO 的 DVReward），把 prompt 拆成原子问题逐一验证，可靠但引入两阶段流水线、依赖分解质量、工程复杂度高。

由此留下一个空白：能否设计一个既高效、又免偏好标签、又开箱即用的奖励模型，尤其面向开源图像生成器。SpectraReward 正是填补该空白——它既不需要偏好标签也不需要奖励模型微调，更回避了“打分”与“分解”两条 zero-shot 子路的固有缺陷。

2.3 核心动机：把“判断”降维成“读回”

作者的关键洞察是：与其要求 MLLM 输出一个抽象的“这张图好不好”的判断（这本质上是一个对齐不良、噪声大的判别任务），不如逆向提问——从 MLLM 的视角看，这张生成图像能多好地被翻译回原始 prompt？ 这一逆问题恰好就是 MLLM 预训练阶段已经在海量图文对上求解的目标函数：image-conditioned next-token likelihood。因此该奖励直接调用 MLLM 最根本的图文对齐能力，而非要求其完成一个额外训练才能胜任的判别任务。

“SpectraReward reuses the fundamental visual-language grounding ability already learned during MLLM pretraining.”

进一步，在 UMM 中，理解分支与生成分支共享 tokenizer、视觉编码器与预训练分布，于是理解分支“读图”的方式天然匹配生成分支“采样图像”的分布。作者据此假设：这种内在的分布对齐使策略自身的理解分支成为对其自身生成尤其合适的奖励来源——即便该理解分支在通用视觉理解上未必强于外部 MLLM。这一假设被第 4 节的 backbone 规模实验直接验证：Self-SpectraReward（7B）反超大 4×–30× 的外部 reward MLLM。

3. 核心方法

3.1 方法总览

SpectraReward 的完整流程可概括为：扩散策略从 prompt 采样图像 → 冻结 MLLM 以图像为条件对 prompt 做 teacher-forced 前向 → 逐 token 的 image-conditioned log-likelihood 构成“语义谱” → 取均值得标量奖励 → 组内 G=16 个 rollout 计算相对优势 → 用 RL 算法（默认 AWM）在采样的去噪步上更新扩散策略，形成闭环。下图刻画了该数据流。

3.2 SpectraReward 奖励函数推导

记文本到图像策略为 $G_\theta$，它从 prompt $x=(x_1,\dots,x_T)$ 采样图像 $y\sim G_\theta(\cdot\mid x)$；$M$ 为冻结的预训练 MLLM。目标是：在不需要偏好标签、奖励模型微调或任何辅助流水线的前提下，从 $M$ 中提取一个标量奖励 $R_M(x,y)$，度量生成图像 $y$ 对 prompt $x$ 的实现程度。

核心思想是把评估图像转化为一个逆问题：从 $M$ 的视角，生成图像 $y$ 能多好地被“翻译回”prompt $x$？为此把 $y$ 作为视觉条件输入 $M$，对 prompt token 序列 $x$ 做单次 teacher-forced 前向，得到逐 token 的 image-conditioned 似然。最终奖励为：

$$R_M(x, y) = \frac{1}{T-1} \sum_{t=1}^{T-1} \log p_M\left(x_{t+1} \mid x_{\leq t},\, y\right)$$

即在 M 下 prompt 的平均 image-conditioned log-likelihood。其中 $x_{\leq t}$ 表示到位置 $t$ 为止的 prompt 前缀，$y$ 是生成图像。求和从 $t=1$ 到 $T-1$，对应预测 $x_2,\dots,x_T$ 这 $T-1$ 个 token（首个 token 不计，因其无条件前缀；EOS 亦被屏蔽，见 3.3）。

逐 token 似然构成图像-文本对的语义谱：

$$\mathcal{S}(x, y) = \left\{\,\log p_M\left(x_{t+1} \mid x_{\leq t},\, y\right)\,\right\}_{t=1}^{T-1}$$

它描述图像 $y$ 中的视觉证据如何在 prompt 的不同 token 上支撑语义 $x$。SpectraReward 把该语义谱聚合为标量：奖励越高，说明 prompt 越能从图像中预测出来，即生成图像越能支撑 prompt 的语义内容。

设计要点：该奖励直接调用预训练 MLLM 最根本的能力——“理解图像并把它与对应语言描述关联”——而非训练一个独立奖励模型或提示 MLLM 产出抽象判断分。因此它把“奖励建模”问题还原为“image-conditioned 语言建模”问题，复用预训练已习得的图文对齐。

3.3 Teacher-Forced 前向与语义谱的性质

Teacher-forced 前向：计算奖励时，prompt 的每个 token $x_{t+1}$ 作为“答案”被喂给 $M$（教师强制），$M$ 在已见前缀 $x_{\leq t}$ 与图像 $y$ 的条件下输出对 $x_{t+1}$ 的概率。整个过程只需单次前向（一次性算出所有 $T-1$ 个位置），无自回归生成、无多轮问答，因此高效且确定性。

语言先验抵消（Language-prior cancellation）：一个自然顾虑是式 (1) 包含 MLLM 对 prompt 的语言先验（有些词无论图像如何都更容易预测）。一个可能的修正项是减去纯文本似然，得到 PMI 风格奖励：

$$R^{\mathrm{PMI}}_M(x, y) = \log p_M(x \mid y) - \log p_M(x)$$

但作者论证：由于采用 group-relative RL，这一修正并非必要。对同一固定 prompt，纯文本似然 $\log p_M(x)$ 在该 prompt 组内所有生成图像间共享，在计算组内相对优势时被自动抵消。因此 PMI 归一化只会影响跨 prompt 的绝对奖励校准，而不提供组内额外优化信号。这意味着 SpectraReward 的朴素均值形式已对 group-relative RL 足够。

EOS 屏蔽：作者在检查逐 token 似然分布时发现，[EOS] token 的似然往往远低于普通 prompt token；因 SpectraReward 对 token 取均值，这个异常低的似然会显著拉偏最终奖励，尤其对短 prompt（EOS 占比大）。由于 EOS 仅表示序列终止、不承载图文对齐语义，故计算时将其屏蔽。消融（附录 C）显示屏蔽 EOS 在 GenEval 上提升 1.0、TIIF-Bench 持平。

奖励前缀：默认不给 reward MLLM 加任何“请描述图像”之类的前缀——这类前缀虽改变绝对似然值，但不实质影响组内相对排序（group-relative RL 所用量）。唯一例外是 InternVL3.5 家族，经验上需加前缀 “Describe the image” 才能获得稳定奖励值。

3.4 Self-SpectraReward：统一多模态模型的自闭环

当策略 $G_\theta$ 本身是统一多模态模型（UMM）时，它同时含生成分支 $G^{\mathrm{gen}}_\theta$ 与理解分支 $G^{\mathrm{und}}_\theta$。Self-SpectraReward 即 SpectraReward 在 UMM 上的特例——用 $G^{\mathrm{und}}_\theta$ 作为 $G^{\mathrm{gen}}_\theta$ 所采样图像的奖励 MLLM $M$：

$$R^{\mathrm{Self}}_\theta(x, y) = R_{G^{\mathrm{und}}_\theta}(x, y), \qquad y \sim G^{\mathrm{gen}}_\theta(\cdot \mid x)$$

模型用自身的理解能力给自身生成的图像打分——衡量原始 prompt 在自身 image-conditioned 理解分支下的似然——形成无外部奖励模型、无外部知识的闭环自改进框架。这同时消除了部署大规模外部 MLLM 的算力开销，简化了 RL 流水线。

奖励-策略对齐（Reward-policy alignment）：Self-SpectraReward 在同一 UMM 内耦合了两种对偶能力——生成分支把文本映射到图像，奖励函数用理解分支度量生成图像能多好地翻译回文本。由于两分支共享 tokenizer、视觉编码器与预训练分布，奖励信号天然兼容于策略自身的生成知识。关键在于：这并不要求理解分支在通用视觉理解上强于外部 MLLM，而是提供一个对策略自身生成图像分布校准更好的奖励信号。用此自奖励优化生成分支，会鼓励 T2I 策略变得与其自身的“图→文”理解能力更一致。下图刻画该闭环与共享结构。

3.6 奖励信号的判别性质分析

论文在第 3.3 节围绕三个问题分析了 SpectraReward 的判别性：(1) 语言先验是否影响准确性——答：group-relative 下被抵消，无需 PMI 修正；(2) token 级似然是否对视觉错配敏感——答：是，下降集中在错配词（见 3.3 表）；(3) 标量奖励能否在同 prompt 组内可靠区分样本——答：能，奖励排序与视觉质量排序一致（Figure 4）。这三点共同支撑“image-conditioned prompt likelihood 是 T2I RL 可靠的组内排序信号”这一结论。

4. 实验结果与分析

4.1 实验设置

默认配置：RL 算法为 AWM（4.3 节消融证明其在三种 RL 算法中总体最佳）；策略模型为 BAGEL（原生 AR-Diffusion 统一多模态模型，预训练兼图像理解与生成）；SpectraReward 默认 reward MLLM 为 Qwen3-VL-30B-A3B；Self-SpectraReward 用 BAGEL 自身理解分支算奖励。训练设置：T=16 采样步，从前 10 个去噪步随机选 6 步训练；每步 32 prompt，组大小 G=16；图像 512×512；CFG=4，timestep shift=3；lr=1e-4；32×A100，batch 2 × 梯度累积 8；共 380 步；在 AlphaGRPO20k 上训练。评估：5 个 OOD 基准——GenEval、TIIF-Bench、DPG-Bench、GenEval2、WISE，均用与训练不同的协议与测试集。

5. 总结与启发

5.1 局限性与未来工作（附录 A）

  • 受限于 MLLM 视觉推理能力：SpectraReward 依赖预训练 MLLM 的 image-conditioned prompt likelihood，奖励质量受所选 reward backbone 的视觉理解与推理能力上限制约。
  • 主要捕捉显式语义对齐，弱化隐式蕴含：因为似然仅在原始 prompt token 上计算，奖励主要刻画生成图像与 prompt 间的显式语义对齐，对未直接写进文本的隐式视觉蕴含可能欠关注。例如 “hot coffee” 物理上隐含“冒蒸汽”，但该蕴含在原始 prompt token 的似然上可能很弱。可缓解方案：用具备丰富世界知识的更强 MLLM backbone，或把 SpectraReward 扩展到推理式 T2I 生成，让中间推理把隐式需求显式化。
  • 不直接优化美学与安全：可通过与互补的专门奖励模型（美学、安全）结合来补足。
  • 闭环自奖励的安全隐患（Broader Impacts）：Self-SpectraReward 的闭环会进一步鼓励模型对齐其自身理解分支，可能不完全反映人类偏好或安全要求；作者建议部署时配合标准安全过滤、偏差审计与人工评估。

5.2 核心洞见与读后评注

洞见一：把奖励建模“降维”为预训练已求解的逆问题。本文最漂亮的转身是回避判别任务、改用生成式似然。让 MLLM 打分或答原子问题，本质是在预训练目标之外要求一个判别头——校准差、噪声大、或需分解工程。而“图像能否读回 prompt”恰是 image-conditioned 语言建模本身，预训练已为其准备了海量监督。这一设计选择把奖励的可靠性从“判别校准”转移到“预训练对齐质量”，是 training-free 奖励能跑通的根本原因。

洞见二：group-relative 让 PMI 修正变得不必要。语言先验本可能污染奖励，但因为相对优势在同一 prompt 组内比较，纯文本似然项被天然抵消。这是一个常被忽视的工程性结论：选择 group-relative RL 等价于免费获得 PMI 归一化，简化了奖励设计。也提示绝对奖励校准对这类方法无关紧要，只需组内排序可靠——作者用 Figure 3/4 的 token 敏感性与排序一致性给出了直接证据。

洞见三：奖励-策略对齐 ≥ 奖励模型规模（反直觉）。最具冲击力的实验是 Self-SpectraReward（7B 自身理解分支）反超大 4×–30× 的外部 reward MLLM，且 reward 规模非单调（30B→235B 反降）。这说明：(a) SpectraReward 所需的“基础 image-captioning 能力”在中等规模已饱和，更大的 MLLM 把容量投到了与该奖励无关的高级推理/指令任务；(b) 与策略共享 tokenizer/视觉编码器/预训练分布带来的分布对齐，比通用判别力更值钱。这对工业界的启示是——不必盲目堆大 reward MLLM，而应优先保证 reward 与 policy 的表示对齐。

洞见四：预训练阶段 > 指令微调阶段（作为 reward backbone）。Gemma3-12B-Pretrain 一致优于 -Instruct，呼应了洞见一：SpectraReward 要的是“图文对齐”，而这正是预训练目标本身；指令微调反而把模型推向与该奖励不直接相关的能力。这是一个反直觉但可复用的选型经验：做 likelihood 奖励，优先选预训练/基础模型，而非 instruct 版。

洞见五：闭环自改进的工程意义。Self-SpectraReward 让 UMM 用自身理解分支奖励自身生成分支，去除了外部大 MLLM 的部署/服务开销，简化 RL 流水线，并提供了对齐更好的信号。这与 LLM 自奖励（Self-Rewarding LM）范式一脉相承，但在多模态生成上首次系统证明“自奖励可比外部更强”。潜在风险也正在于此：闭环可能放大自身偏差、偏离人类偏好，需安全护栏。

读后评注：SpectraReward 的“读回”思想与 PromptEcho（concurrent，cross-entropy）高度相似，但本文把它从“领域专用 T2I backbone”推广到通用扩散模型与 UMM，并首次系统量化了 reward backbone 的规模/家族/阶段效应与 reward-policy 对齐效应，是该方向目前最完整的实证。其局限性也清晰：奖励只覆盖 prompt 显式语义，对美学/安全/隐式常识无能为力，需与互补奖励组合。可作为 T2I RL 的一条“base reward”，与美学/安全奖励正交叠加，构成多目标奖励栈。
