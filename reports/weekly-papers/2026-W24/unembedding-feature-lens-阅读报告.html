概述

本文提出了一个令人意外却又直觉上令人信服的发现：大语言模型（LLM）内部的 unembedding 矩阵（即 lm_head，$W_U \in \mathbb{R}^{|V| \times d}$）不仅仅是一个将隐藏状态映射到词表概率的解码器，它同时也是一面"特征透镜"——其奇异值分解所揭示的谱结构，精确编码了哪些隐空间方向负责将高频低语义 token 写入嵌入表示。

当我们把 LLM 的最后一层隐状态直接当作文本嵌入使用时，这些向量在 Logit Lens 分析下会优先对齐 "the"、","、"\n" 等高频但语义空洞的 token，而非输入文本中真正有意义的关键词。这种现象跨越 Qwen、Llama、Mistral 等不同模型家族普遍存在，揭示了一个 LLM 嵌入能力的系统性瓶颈：文本嵌入被拉向一个"平均 token"方向，在这个方向上所有句子都高度相似，掩盖了真正的语义差异。

作者将这一现象与嵌入的各向异性问题（anisotropy）联系起来。前人研究已发现 LLM 嵌入分布在一个极窄的锥形区域内，而本文更进一步：这个锥形的中心方向（质心）恰好对应于训练语料上的词频加权平均嵌入，即"平均 token"。通过对 $W_U$ 做 SVD 分解，并用 Logit Spectroscopy 工具分析每个奇异子空间对高频 token logit 的贡献，作者发现：谱的两端（最大与最小奇异值对应的右奇异向量）构成的"边缘谱"（edge spectrum）子空间，正是写入高频 token 的主要通道。

基于此，作者提出 EmbedFilter：将原始嵌入投影到 $W_U$ 奇异谱的"中间体"（bulk spectrum）子空间，一步线性变换即可滤除高频 token 偏置，无需任何微调。更令人惊喜的是，这一投影天然具有降维效果——由于 $V$（右奇异矩阵）是正交变换，距离关系得到严格保持，将维度压缩到原来的 $1/\tau$ 倍后仍能维持甚至超越原始嵌入的检索质量，同时带来 $\tau$ 倍的检索加速与存储节省。在 MTEB 基准上，EmbedFilter 在 Qwen2.5-0.5B 上实现了最高 14.1% 的整体性能提升，在三个 LLM 骨干上均表现出稳健的改善。

核心洞见：unembedding 矩阵不只是解码头，它是 LLM 内部表示空间的一面镜子——通过读取它的奇异谱，我们可以精确定位并手术式地切除那些污染嵌入质量的"噪声方向"。

研究背景

LLM-as-Embedder 的困境

近年来，以 LLM 为骨干的文本嵌入模型（如 E5-mistral、GTE-Qwen、BGE-M3）在 MTEB 排行榜上取得了显著成绩，但这些模型都经过了大规模的对比学习微调。当研究者尝试直接将预训练 LLM 的隐状态用作嵌入（零样本场景）时，性能往往远不及专门训练的小型双编码器（如 SimCSE-BERT）。这一现象被称为 LLM-as-Embedder 的性能鸿沟。

为弥补这一差距，研究者提出了多种提示工程方法：

  • PromptEOL（Jiang et al., 2023）：使用"one word limitation"模板，引导 LLM 将语义压缩到最后一个 token 的隐状态中
  • ECHO（Springer et al., 2024）：复制输入文本，从第二次出现的末尾提取嵌入，缓解因果注意力的单向性瓶颈
  • MetaEOL（Lei et al., 2024）：利用强大的商业 LLM 生成元提示，增强语义表达
  • GenEOL（Cho et al., 2024）：通过多次生成并聚合嵌入来提升质量

这些方法虽有改善，但仍是启发式的，且改进幅度有限、对提示选择敏感。本文的核心贡献在于提供了一个机制性解释，并基于此设计了原理性的解决方案。

Logit Lens 与 Logit Spectroscopy 工具

本文借助两个机制可解释性工具来分析 LLM 嵌入：

  • Logit Lens（nostalgebraist, 2020）：将中间层隐状态 $h$ 直接乘以 unembedding 矩阵 $W_U$，得到词表上的 logit 分布，从而可视化该隐状态"最像"哪些 token。Nie et al. (2023) 将此工具应用于文本嵌入，发现嵌入能与输入文本的关键词对齐——但本文进一步发现，原始嵌入更多地对齐高频无意义 token。
  • Logit Spectroscopy（Dar et al., 2023）：在 Logit Lens 基础上，先将 $h$ 在 $W_U$ 的某个奇异子空间上的投影去除，再做 Logit Lens 分析，从而定量测量每个奇异方向对最终 logit 的贡献。过滤算子定义为 $\Psi_i = I - V_{[i]} V_{[i]}^\top$。

问题分析：高频 Token 偏置的数学根源

嵌入各向异性与"平均 Token"假说

前人研究（Ethayarajh 2019，Li et al. 2020）已记录了 LLM 嵌入的各向异性现象：所有文本嵌入都集中在一个极窄的锥形区域，导致任意两个句子的余弦相似度都偏高，掩盖了真实的语义差异。

本文提出了一个更具体的假说：这个锥形区域的质心对应于训练语料上的词频加权平均嵌入——即"平均 token"（average token）。Lv et al. (2024) 将此质心描述为"频率加权平均嵌入"，本文进一步将其与高频 token 的 logit 主导现象联系起来，提供了各向异性问题的机制性解释。

平均 Token 的逆向工程

设 $\hat{p}$ 为从训练语料（RedPajama）估计的词频分布。LLM 的标准解码步骤为：

$$q = \text{Softmax}(h W_U^\top)$$

其中 $q_i = \exp(w_i) / \sum_j \exp(w_j)$。对 logit 取对数：$w_i = \log(q_i) + b$（$b$ 为所有 logit 共享的偏置项）。因此：

$$h W_U^\top = \log(q) + b \implies h = (\log(q) + b) W_U^{+}$$

其中 $W_U^{+}$ 是 $W_U^\top$ 的 Moore-Penrose 伪逆。将 $q$ 替换为观测词频 $\hat{p}$，忽略偏置项 $b$（不影响谱分析），得到平均 token 表示：

$$\hat{h} = \log(\hat{p}) \cdot W_U^{+}$$

这个 $\hat{h}$ 代表"如果一个隐状态以训练语料的词频分布预测下一个 token，它应该是什么样的"——即所有文本嵌入的公共基底，也是各向异性锥形的质心所在。

Unembedding 矩阵的 SVD 分解与边缘谱发现

对 unembedding 矩阵 $W_U \in \mathbb{R}^{|V| \times d}$ 进行奇异值分解：

$$W_U = U \Sigma V^\top$$

其中 $U \in \mathbb{R}^{|V| \times d}$，$\Sigma \in \mathbb{R}^{d \times d}$（奇异值对角矩阵，按降序排列），$V \in \mathbb{R}^{d \times d}$（正交矩阵，右奇异向量）。$V$ 的每一列 $V_{[i]}$ 构成隐空间 $\mathbb{R}^d$ 的一组正交基。

对每个奇异维度 $i \in \{0, \ldots, d-1\}$，定义过滤后的扰动表示：

$$\tilde{h}^{(i)} = \hat{h} \left(I - V_{[i]} V_{[i]}^\top\right)$$

取高频 token 集合 $\mathcal{V}^+ = \{j \mid j \in \text{argtop}_k(\hat{p})\}$（$k=100$），定义高频 token logit 的相对扰动量：

$$\Delta\pi(i) = \frac{\sum_{j \in \mathcal{V}^+} |\tilde{w}_j^{(i)} - \hat{w}_j|}{\sum_{j \in \mathcal{V}^+} |\hat{w}_j|}$$

实验结果（Figure 2）显示，$\Delta\pi$ 在谱的两端（最大和最小奇异值对应的维度）显著高于中间部分，在 Qwen、Llama、Mistral 三个模型上均呈现一致的"U 形"分布。相比之下，低频 token 和随机 token 对边缘谱的敏感度显著更低，进一步证实了边缘谱与高频 token 的专属关联。

边缘谱（Edge Spectrum）：由 $W_U$ 最大和最小奇异值对应的右奇异向量张成的子空间，是将高频低语义 token 写入嵌入表示的主要通道。过滤这个子空间即可释放嵌入中被压制的语义信息。

Bulk Spectrum Transformation 公式推导

给定过滤比例 $\tau \in \{1, 2, 4, 8\}$，定义左右截断索引：

$$l_\tau = \left\lfloor d \cdot \frac{\tau - 1}{2\tau} \right\rfloor, \quad r_\tau = \left\lceil d \cdot \frac{\tau + 1}{2\tau} \right\rceil$$

中间谱子空间由 $V_{[l_\tau : r_\tau]} \in \mathbb{R}^{d \times (r_\tau - l_\tau)}$ 构成（去掉最大奇异值端的 $l_\tau$ 个维度和最小奇异值端的 $d - r_\tau$ 个维度）。Bulk Spectrum Transformation 定义为：

$$\Phi_\tau = V_{[l_\tau : r_\tau]} \cdot V_{[l_\tau : r_\tau]}^\top \in \mathbb{R}^{d \times d}$$

对原始嵌入 $e_i$ 应用 EmbedFilter，得到精化表示：

$$\tilde{e}_i = e_i \cdot \Phi_\tau^\top$$

由于 $V$ 是正交矩阵，$\Phi_\tau$ 是一个正交投影算子（满足 $\Phi_\tau^2 = \Phi_\tau$ 和 $\Phi_\tau^\top = \Phi_\tau$），它将嵌入投影到"中间谱"子空间，同时过滤掉两端的边缘谱分量。与"直接减去边缘谱投影"的表达方式等价：

$$\tilde{e}_i = e_i - e_i V_{\text{edge}} V_{\text{edge}}^\top$$

其中 $V_{\text{edge}}$ 包含两端奇异向量，但实践中通过保留中间谱实现更为简洁。

降维的保距性证明

EmbedFilter 的降维版本用 $V_{[l_\tau : r_\tau]}$ 直接替换 $\Phi_\tau^\top$，将嵌入压缩到 $d/\tau$ 维。由于 $V$ 是正交矩阵，对任意 $x, y \in \mathbb{R}^d$，有：

$$\|x \Phi_\tau^\top - y \Phi_\tau^\top\|_2 = \|x V_{[l_\tau : r_\tau]} - y V_{[l_\tau : r_\tau]}\|_2$$

这意味着降维后的欧氏距离（以及余弦相似度）与全维投影结果完全等价，不会因降维而损失相对距离信息。这一性质使得 EmbedFilter 的降维是"无损"的——在语义检索中，$\tau$ 倍降维带来 $\tau$ 倍检索加速和 $1/\tau$ 倍存储占用，而排名顺序不变。

算法伪代码

Algorithm 1: EmbedFilter — 离线预处理与在线推理

// === 离线阶段（一次性，基于模型权重）===

Input: W_U ∈ ℝ|V|×d（unembedding 矩阵），过滤比例 τ ∈ {1, 2, 4, 8}

U, Σ, V ← SVD(W_U) // V ∈ ℝ^{d×d}，列按奇异值降序排列

l_τ ← ⌊d · (τ−1) / (2τ)⌋ // 左截断索引（去掉最大 SV 端）

r_τ ← ⌈d · (τ+1) / (2τ)⌉ // 右截断索引（去掉最小 SV 端）

V_bulk ← V[:, l_τ : r_τ] // 中间谱子空间，ℝ^{d × (r_τ - l_τ)}

Φ_τ ← V_bulk · V_bulk⊤ // Bulk Spectrum Transformation，ℝ^{d×d}

// 缓存 V_bulk 和 Φ_τ，供在线阶段使用

// === 在线阶段（每条文本）===

Input: 原始嵌入集合 {e_i}i=1N，e_i ∈ ℝd

for i = 1 to N do

// 选项 A：全维精化（保持 d 维，用于高精度场景）

ẽ_i ← e_i · Φ_τ⊤ // ∈ ℝ^d，O(d²) 计算

// 选项 B：降维版本（压缩到 d/τ 维，用于高效检索）

ẽ_i_dim ← e_i · V_bulk // ∈ ℝ^{d/τ}，O(d·d/τ) 计算，距离保持

end for

return {ẽ_i} 或 {ẽ_i_dim} // 用于下游检索/STS等任务

计算复杂度分析：离线 SVD 分解为 $O(\min(|V|, d) \cdot d^2)$，仅执行一次，可预先缓存；在线推理每条嵌入仅需一次矩阵乘法，全维版本为 $O(d^2)$，降维版本为 $O(d \cdot d/\tau)$，相比 LLM 推理本身的开销可忽略不计。

关键结论：

  • 改进非来自降维本身：配置①②虽也降维到 d/2，但性能反而下降，证明 EmbedFilter 的提升来自子空间选择，而非维度压缩。
  • 两端谱均有害，次级谱更甚：配置④（过滤最小 SV 端）效果优于③（过滤最大 SV 端），与 Figure 2 中次级谱 $\Delta\pi$ 更大一致。
  • EmbedFilter 接近理论上界：与需要任务特定校准的最优配置⑥相比，EmbedFilter 无需额外信息即可达到相近效果（54.57 vs 54.19），甚至略优。

过滤比例 τ 的影响与效率权衡

随着 $\tau$ 增大（维度减少），性能逐渐轻微下降，但即使 $\tau=8$（维度压缩到原来的 1/8），EmbedFilter 仍能保持相对基线的正向增益。这提供了灵活的效率-效果权衡空间：

  • $\tau=1$：全维精化，最大性能提升，无降维
  • $\tau=2$：维度减半，性能接近 $\tau=1$，检索速度提升 2 倍，推荐默认配置
  • $\tau=4$：维度压缩 4 倍，仍优于基线，适合资源受限场景
  • $\tau=8$：维度压缩 8 倍，轻微性能损失，检索速度提升 8 倍、存储节省 87.5%

在复杂提示框架中的泛化性（Table 2, 3）

EmbedFilter 不仅在简单提示基线上有效，在更复杂的框架上也持续改善：

  • MetaEOL + EmbedFilter：Qwen 上 52.23 → 55.39（+6.1%），Llama 上 56.73 → 58.79（+3.6%）
  • GenEOL + EmbedFilter：STS 平均分 77.73 → 78.39（+0.66%）

这表明 EmbedFilter 可以作为通用的嵌入后处理模块，与任意提示工程方法叠加使用，且不会因基线方法更复杂而失效。

局限性

  • 对已微调嵌入模型的适用性未验证：EmbedFilter 的设计假设基于 LLM 的 unembedding 矩阵保留了预训练时的词频偏置。对于已经过对比学习微调的嵌入模型（如 E5、BGE），其 unembedding 矩阵可能已发生显著变化，边缘谱的语义含义有待验证。
  • 非对称边缘谱的最优过滤策略待探索：消融实验显示最大 SV 端和最小 SV 端对高频 token 的贡献并不对称（次级谱 $\Delta\pi$ 更大），但 EmbedFilter 采用对称截断。如何为不同模型自适应地确定最优的非对称截断比例，仍是未解问题，作者明确将其列为未来工作。
  • 检索任务评测范围有限：受计算资源限制，检索任务仅评测了 MTEB 的子集，遵循前人协议（Behnamghader et al., Muennighoff et al.），在全量检索数据集上的表现有待进一步验证。
  • 词频分布的代理质量：平均 token 的计算依赖于对训练语料词频的估计（用 RedPajama 代理）。当代理分布与真实预训练分布差异较大时，边缘谱识别的准确性可能受影响，但作者在多个语料上的平行实验得到了一致结果。
  • 多语言与多模态场景未探索：论文实验主要在英文 MTEB 上进行，高频 token 的分布在多语言模型中可能有所不同，EmbedFilter 的跨语言泛化性有待探索。

总结与启发

核心贡献回顾

本文的工作在方法论层面的贡献可以总结为三个维度：发现（边缘谱现象）、解释（高频 token 偏置的机制性根源）、利用（EmbedFilter 的无训练纯化方案）。这三者形成了一条完整的从观察到原理再到应用的研究链条，是高质量 NLP 研究的典范。

对 LLM 内部表示的深度思考

本文最深刻的洞见在于：unembedding 矩阵 $W_U$ 不仅是解码头，更是一面映射隐空间结构的透镜。这一视角挑战了我们对 LLM 组件功能的传统认知——我们习惯于将 lm_head 视为"输出层"而忽视其对表示空间的反向约束。事实上，由于 LLM 在预训练中需要最大化下一 token 的预测概率，$W_U$ 必然编码了大量关于 token 分布的统计信息，而这些信息通过反向传播"渗透"进了隐状态的几何结构。

从信息论角度看，高频 token 的"平均方向"是一种低熵、高冗余的表示成分——它在任何输入下都以高概率被激活，因此在隐空间中对应一个强烈的、跨句子共享的方向。这个方向的存在使得所有嵌入都向同一个"公共区域"靠拢，降低了嵌入的区分能力。EmbedFilter 通过手术式地切除这个方向，本质上是在执行一种语义去噪操作。

更广泛地说，本文揭示了一个重要原则：LLM 的预训练目标（语言建模）与下游目标（语义相似度）之间存在内在张力。语言模型需要准确预测高频 token，因此在隐空间中为这些 token 保留了大量"容量"；而语义嵌入需要捕捉低频但信息丰富的语义差异。这两个目标在表示空间中竞争有限的维度资源，导致了观察到的性能鸿沟。EmbedFilter 的成功表明，通过识别并分离这两种"成分"，可以在不牺牲语言建模能力的前提下提升嵌入质量。

对嵌入系统设计的启发

本文的发现对嵌入系统的设计有几个重要启发：

  • 后处理的价值被低估：学界过度关注训练阶段的改进（更好的对比学习目标、更多的训练数据），而对推理时的表示净化关注不足。EmbedFilter 以极低的计算开销（一次矩阵乘法）实现了媲美微调方法的性能提升，提示我们应当更系统地探索后处理空间。
  • 降维应与语义结构对齐：传统的 PCA 降维或 Matryoshka 表示学习都基于统计方差最大化，而不考虑哪些方向是"语义噪声"。EmbedFilter 的降维方案以语义质量为导向，提供了一个更有原则的降维框架。
  • 可解释性工具的实用价值：本文展示了机制可解释性研究（Logit Lens、Logit Spectroscopy）如何从分析工具转化为实用的工程方法。这为可解释性研究的"落地"提供了一个成功范例，也提示研究者：理解模型内部机制不只是学术目的，更能直接指导系统改进。
  • 对 Matryoshka 嵌入的补充：当前流行的 Matryoshka Representation Learning（MRL）通过训练来实现多粒度嵌入，但无法在推理时动态调整"哪些维度是有用的"。EmbedFilter 提供了一种基于模型内部结构的无训练替代方案，两者可以互补——先用 MRL 训练，再用 EmbedFilter 过滤边缘谱，可能获得更好的效果。

未来研究方向

基于本文的工作，以下方向值得进一步探索：

  1. 将边缘谱过滤思想应用于嵌入模型的微调阶段，在训练目标中显式地惩罚嵌入在边缘谱方向上的投影，从源头减轻高频 token 偏置。
  2. 研究不同预训练数据配比对边缘谱形态的影响，以及是否可以通过调整数据分布来从预训练阶段改善嵌入质量。
  3. 探索 EmbedFilter 与量化技术（INT8、FP16）的结合，在降维的同时进行 bit 压缩，进一步降低部署成本。
  4. 将类似的谱分析方法应用于多模态嵌入（图像-文本对齐），研究视觉特征是否也存在类似的"平均视觉 token"问题。
  5. 系统研究非对称边缘谱的最优截断策略，为不同模型自动确定最佳的 $l_\tau$ 和 $r_\tau$ 参数。
