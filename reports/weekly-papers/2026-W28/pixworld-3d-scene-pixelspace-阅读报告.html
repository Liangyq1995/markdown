1. 概述

3D 场景的重建（从真实多视图捕获恢复 3D）与生成（从稀疏/想象条件合成场景）长期是两条独立的研究线：重建以 feed-forward 回归为主流，生成则以潜空间扩散（latent diffusion）为主流。近期的 Gen3R 尝试用潜空间生成管线同时处理两者，但存在两个根本性缺陷：

  • 扩散目标定义在 VAE/RAE 编码出的中间潜特征上，无法直接优化底层 3D 表示；
  • 两条分支都承受 VAE/RAE 编码带来的信息损失，且该自编码器本身需要额外预训练。

PixWorld 把统一问题重新表述到像素空间扩散范式下：扩散变量与渲染输出同处 RGB 域，损失直接施加在多视图可微渲染图上，从而让训练信号与 3D 场景保真度对齐，而非与某个中间潜空间目标对齐。统一进一步简化为“如何让两种任务共享一次前向”——PixWorld 通过把多视图输入划分为 clean 子集（驱动重建）与 noisy 子集（以 clean 为条件去噪生成），让一个双流 DiT 同时输出像素对齐的 3DGS。

由于纯像素级的光度/感知损失不足以约束真实 3D 几何（深度可沿视线漂移、半透明 floater 可平均出合理颜色），PixWorld 进一步提出 Geometry Perception Loss：在冻结的 3D 基础模型（π3 / VGGT）的几何感知特征空间中，拉近渲染视图与真值视图，提供超越 2D 的 3D 结构监督。

核心论点：去掉 VAE/RAE 这层中间瓶颈，把扩散目标直接放到渲染像素上，是统一 3D 生成与重建、并提升保真度的关键；再叠加 3D 几何感知监督，弥补纯 2D 损失的几何盲区。

2.2 3D 场景重建

经典管线依赖 MVS / SfM 估计稠密几何，NeRF 与 3DGS 推动了逐场景优化。为避免昂贵的逐场景拟合，feed-forward 方法直接把稀疏/稠密多视图映射到 3D 表示（LRM 回归 triplane，pixel-aligned 高斯回归器预测逐像素高斯）。这类方法确定性且以观测为条件，无法合成输入视图之外未见内容——这正是 PixWorld 通过 clean/noisy 划分要补齐的能力。

2.3 像素空间生成的启发

潜在扩散主导大规模图像生成，但在生成目标与像素输出之间引入间接性。一批工作（Dhariwal & Nichol、Jabri、Hoogeboom、PixFlow、JiT 等）证明：容量与数据足够时，像素空间生成在保真度上可追平甚至超越潜空间。PixWorld 把这一视角推广到 3D：直接在像素空间扩散，移除中间 VAE/RAE，并通过预测 3DGS 的可微渲染直接监督 3D 表示。

3. 核心方法

3.1 预备：像素空间扩散 vs 潜空间扩散

在潜扩散中，图像 $x$ 先被预训练自编码器映射到紧凑潜表示 $E_\mathrm{AE}: x \mapsto z$，扩散在潜空间进行，去噪后的潜再由 $D_\mathrm{AE}: \hat{z} \mapsto \hat{x}$ 映回 RGB。这降低了维度与计算量，但在扩散变量与最终图像监督之间插入了自编码瓶颈。

PixWorld 跟随 JiT 采用像素空间图像预测。给定干净图像 $x\in\mathbb{R}^{H\times W\times 3}$、高斯噪声 $\epsilon\sim\mathcal{N}(0,I)$ 与时间步 $t\in[0,1]$，加噪输入由线性插值构造：

$$x_t = t\,x + (1-t)\,\epsilon$$

去噪器直接参数化为图像预测器：

$$f_\theta:(x_t,t,c)\mapsto\hat{x} \tag{1}$$

其中 $c$ 为条件（类别标签或文本嵌入）。预测图像转化为速度场 $\hat{v}=(\hat{x}-x_t)/(1-t)$，得到 flow-matching 目标：

$$\mathcal{L}_\mathrm{FM}=\mathbb{E}_{x,\epsilon,t}\left[\lVert\hat{v}-v\rVert_2^{2}\right]=\mathbb{E}_{x,\epsilon,t}\left[\frac{\lVert\hat{x}-x\rVert_2^{2}}{(1-t)^{2}}\right] \tag{2}$$

其中 $v=x-\epsilon$ 为真值速度。该参数化对 3D 设置尤为诱人：潜扩散把目标定义在编码潜上，使扩散过程与渲染输出及它应监督的 3D 表示解耦；而像素空间扩散让扩散变量与渲染输出同处 RGB 域，损失可直接施加在渲染图上，与 3D 场景保真度对齐。

3.2 PixWorld 框架与任务表述

给定含 $N$ 个带位姿视图的场景，记 RGB 图像与相机参数为 $I=\{I_n\}_{n=1}^{N}$、$T=\{T_n\}_{n=1}^{N}$。将视图索引划分为 clean 子集 $\Omega_c$ 与 noisy 子集 $\Omega_n$：

$$\Omega_c\cup\Omega_n=\{1,\dots,N\},\quad \Omega_c\cap\Omega_n=\varnothing,\quad |\Omega_c|\ge 1 \tag{3}$$

当 $\Omega_n=\varnothing$ 时退化为纯多视图重建；否则 PixWorld 在 clean 条件下预测 noisy 视图。可选文本提示 $y$ 进一步指定场景。每个视图 $n$ 的模型输入定义为：

$$\tilde{I}_t^{\,n}=\begin{cases} I_n, & n\in\Omega_c \\ t\,I_n+(1-t)\,\epsilon_n, & n\in\Omega_n,\ \epsilon_n\sim\mathcal{N}(0,I) \end{cases} \tag{4}$$

同一场景的所有 noisy 视图共享同一时间步 $t$。记混合多视图输入为 $\tilde{I}_t=\{\tilde{I}_t^{\,n}\}_{n=1}^{N}$。

双流扩散 Transformer。给定 $\tilde{I}_t$，PixWorld 用双流 DiT：

$$f_\theta:(\tilde{I}_t,T,y)\mapsto(\hat{D},\hat{G}) \tag{5}$$

其中 $\hat{D}=\{\hat{D}_n\}_{n=1}^{N}$ 为预测多视图深度图，$\hat{G}$ 为像素对齐 3D 高斯场景表示。clean 与 noisy 视图由独立输入投影嵌入，再由共享 transformer block 联合处理；noisy 流以采样 $t$ 为条件，clean 流恒接收 $t=1$ 的全去噪时间嵌入；相机参数经 PRoPE 注入，可选文本经交叉注意力融合。

3D 高斯解码与渲染。对第 $n$ 视图第 $p$ 个像素，用预测深度 $\hat{d}_p^{\,n}$ 反投影得到高斯中心：

$$\mu_p^{\,n}=\Pi^{-1}(p,\hat{d}_p^{\,n},T_n)$$

其中 $\Pi^{-1}$ 为到世界空间的逆投影。聚合所有像素与视图得到 $\hat{G}$，再由可微渲染器 $\mathcal{R}:(\hat{G},T_n)\mapsto\bar{I}_n$ 渲染出多视图集 $\bar{I}=\{\bar{I}_n\}_{n=1}^{N}$。

3.3 渲染、深度与几何感知损失

FM 渲染与深度目标。为与速度参数化对齐，渲染损失同样写成 FM 形式。对每个 noisy 视图 $n\in\Omega_n$，定义渲染速度与真值速度：

$$\bar{v}_n=\frac{\bar{I}_n-\tilde{I}_t^{\,n}}{1-t},\qquad v_n=\frac{I_n-\tilde{I}_t^{\,n}}{1-t}$$

由式 (4) 可知 $v_n=I_n-\epsilon_n$。对每个 clean 视图 $n\in\Omega_c$，渲染图 $\bar{I}_n$ 直接以 MSE 监督（clean 视图作为无噪声重建锚点）。总渲染损失：

$$\mathcal{L}_\mathrm{render}=\underbrace{\frac{1}{|\Omega_c|}\sum_{n\in\Omega_c}\lVert\bar{I}_n-I_n\rVert_2^{2}}_{\mathcal{L}_\mathrm{recon}}+\mathbf{1}_{[|\Omega_n|>0]}\left(\underbrace{\frac{1}{|\Omega_n|}\sum_{n\in\Omega_n}\lVert\bar{v}_n-v_n\rVert_2^{2}}_{\mathcal{L}_\mathrm{FM}}+\lambda_\mathrm{lpips}\,\mathcal{L}_\mathrm{lpips}\right) \tag{6}$$

其中 FM 项等价地写为图像空间形式 $\frac{1}{|\Omega_n|}\sum_{n\in\Omega_n}\frac{\lVert\bar{I}_n-I_n\rVert_2^{2}}{(1-t)^{2}}$，感知项定义为 $\mathcal{L}_\mathrm{lpips}=\mathbf{1}_{[t>t_\mathrm{th}]}\frac{1}{N}\sum_{n=1}^{N}\mathrm{LPIPS}(\bar{I}_n,I_n)$。指示函数 $\mathbf{1}_{[|\Omega_n|>0]}$ 在纯重建（$\Omega_n=\varnothing$）时关闭 FM 项；LPIPS 仅在 $t>t_\mathrm{th}$ 时激活，因加噪输入接近纯噪声时感知监督不可靠。此外每次迭代采样 4–8 个新视图，用 MSE+LPIPS 监督其渲染，正则 3DGS 在任意视角下良好渲染。

预测深度用 DA3（Depth Anything 3）伪深度标签 $D^\star=\{D_n^\star\}_{n=1}^{N}$ 监督：

$$\mathcal{L}_\mathrm{depth}=\frac{1}{N}\sum_{n=1}^{N}\rho\!\left(\log\hat{D}_n-\log D_n^\star\right) \tag{7}$$

其中 $\rho(\cdot)$ 为逐元素 Huber 损失再对像素平均。

几何感知损失（Geometry Perception Loss）。光度损失本质上无法完全约束 3D 结构：深度可沿视线漂移、半透明 floater 可平均出合理颜色、视角相关纹理可部分补偿几何错位。为此在冻结 3D 基础模型 $\Psi$（如 VGGT、π3）的特征空间中引入几何监督。对渲染视图集 $\bar{I}$ 与真值视图集 $I$（同相机 $T$）：

$$\bar{H}=\Psi(\bar{I},T)=\{\bar{H}_n\}_{n=1}^{N},\qquad H^\star=\Psi(I,T)=\{H_n^\star\}_{n=1}^{N} \tag{8}$$

仅当时间步足够大时，最小化两特征场每个位置的余弦距离：

$$\mathcal{L}_\mathrm{geo}=\mathbf{1}_{[t>t_\mathrm{th}]}\frac{1}{N\,H'W'}\sum_{n=1}^{N}\sum_{p}\left(1-\frac{\bar{h}_p^{\,n}\cdot h_p^{\star n}}{\lVert\bar{h}_p^{\,n}\rVert_2\,\lVert h_p^{\star n}\rVert_2}\right) \tag{9}$$

其中 $\bar{h}_p^{\,n}$、$h_p^{\star n}$ 分别为 $\bar{H}_n$、$H_n^\star$ 在位置 $p$ 的特征向量。因 $\Psi$ 联合处理所有视图与相机，其特征编码的是跨视图 3D 结构而非单图外观——两个单独光度一致但 3D 互不一致的渲染仍会产生不同特征图并产生较大 $\mathcal{L}_\mathrm{geo}$。训练时冻结 $\Psi$，对参考分支 $H^\star$ 停止梯度，仅通过渲染分支 $\bar{H}$ 反传，使 $\Psi$ 纯粹充当结构判据。

总目标：

$$\mathcal{L}=\mathcal{L}_\mathrm{render}+\lambda_\mathrm{depth}\,\mathcal{L}_\mathrm{depth}+\lambda_\mathrm{geo}\,\mathcal{L}_\mathrm{geo}$$

论文设定 $\lambda_\mathrm{depth}=1.0$，$\lambda_\mathrm{lpips}=\lambda_\mathrm{geo}=0.1$，感知与几何项均在 $t>t_\mathrm{th}=0.3$ 时门控。

3.4 模型架构（双流 MMDiT）

去噪器 $f_\theta$ 为 24 层 DiT，隐藏宽度 $d=1024$，16 注意力头（头维 64），SwiGLU 前馈，Q/K 上 RMSNorm，adaLN-Zero 以扩散时间步为条件。沿用 SD3 风格 MMDiT：每个 block 含两条并行流（拓扑共享、但独立的 pre-LayerNorm / QKV 输出投影 / MLP / adaLN-Zero 权重），clean 流处理 $\Omega_c$，noise 流处理 $\Omega_n$。注意力算子内，两流的 Q/K/V 沿 token 轴拼接（共享 q/k-RMSNorm），对 $[\Omega_c;\Omega_n]$ 联合做一次全注意力，使条件与 noisy token 在每层都交叉；联合输出再拆分回流特定输出投影。两流共享对文本的交叉注意力与单一时间步嵌入器（clean 流取 $t=1$，noise 流取采样 $t$）。输入用 16×16 patchify + 可学习位置嵌入，末层经流特定多任务头输出逐像素深度与 3DGS 属性，高斯中心由预测深度反投影得到。可训练参数共 1.044B。

3.5 训练算法伪代码

Algorithm 1: PixWorld 训练（单次迭代）

Input: 带 pose 多视图场景 $\{I_n, T_n\}_{n=1}^{N}$；可选文本 $y$；冻结 3D 批评器 $\Psi=\pi 3$；超参 $\lambda_\mathrm{depth}=1.0,\ \lambda_\mathrm{lpips}=\lambda_\mathrm{geo}=0.1,\ t_\mathrm{th}=0.3$

repeat

# 1. 视图划分：偏向小 |Ωc| 以强化条件生成，保留全 clean 退化以训练几何头

采样 $N\in\{4,\dots,8\}$ 视图，划分为 $\Omega_c,\Omega_n$（满足式3）

# 2. 构造加噪输入（同一场景 noisy 视图共享 t）

采样 $t\sim\mathcal{U}(0,1)$；对 $n\in\Omega_n$ 采 $\epsilon_n\sim\mathcal{N}(0,I)$，按式4 得 $\tilde{I}_t^{\,n}$

# 3. 双流 DiT 前向 + 解码

$(\hat{D},\hat{G}) \leftarrow f_\theta(\tilde{I}_t,T,y)$；按深度反投影聚合得 $\hat{G}$

# 4. 可微渲染 noisy + clean + 4~8 新视角

$\bar{I}_n \leftarrow \mathcal{R}(\hat{G},T_n)$；采样新视图位姿并渲染

# 5. 计算损失（各项门控）

若 $\Omega_n\neq\varnothing$：$\mathcal{L}_\mathrm{FM}\leftarrow\frac{1}{|\Omega_n|}\sum\lVert\bar{v}_n-v_n\rVert^{2}$；否则仅 $\mathcal{L}_\mathrm{recon}$

若 $t>t_\mathrm{th}$：启用 $\mathcal{L}_\mathrm{lpips}$ 与 $\mathcal{L}_\mathrm{geo}=\mathrm{cosdist}(\Psi(\bar{I}),\mathrm{sg}[\Psi(I)])$

$\mathcal{L}_\mathrm{depth}\leftarrow\frac{1}{N}\sum\rho(\log\hat{D}-\log D^\star)$（$D^\star$ 来自 DA3）

$\mathcal{L}\leftarrow\mathcal{L}_\mathrm{render}+\lambda_\mathrm{depth}\mathcal{L}_\mathrm{depth}+\lambda_\mathrm{geo}\mathcal{L}_\mathrm{geo}$

# 6. 反传更新（文本以 0.2 概率 CFG 丢弃）

AdamW 步更新 $\theta$；EMA 衰减 0.9995；梯度裁剪 1.0

until 收敛（约 200K steps）

3.6 训练细节

  • 数据：Re10K + DL3DV-10K 约 67K 带 pose 场景；每场景采样 $N\in\{4,\dots,8\}$ 视图并划分 $\Omega_c/\Omega_n$（偏小 $|\Omega_c|$）；混入 BLIP-3o 语料的 10M 单图分支，共享扩散骨干作 2D 外观先验。
  • 批处理：每 GPU 每步交替 32 图单视图 batch 与至多 32 图多视图 batch（4–8 视图 × 4–8 场景）。
  • 优化：AdamW，学习率线性衰减 $1\times10^{-4}\to1\times10^{-5}$，EMA 0.9995，梯度裁剪 1.0，CFG 文本丢弃率 0.2。
  • 硬件/规模：32× NVIDIA A800-SXM4-80G，约 200K steps，训练分辨率 336×448，从零训练（无图像/视频模型预训练）。
  • 几何批评器：冻结 π3，参考分支停梯度。

4. 实验结果与分析

实验覆盖四类协议：RealEstate10K (RE10K) 与 DL3DV-10K 上各随机采 200 个测试场景（限定大相机位姿范围以施压宽基线推理），WorldScore 官方静态 split（2000 场景）。生成协议下所有 baseline 均以相机位姿为条件，除 LVSM 外均额外接收文本条件。指标分三组：新视图合成保真度（PSNR/SSIM/LPIPS）、VBench 式生成质量（I2V Subj/BG、Image Quality、Aesthetic Quality）、相机控制精度（π3 估计的 AUC@{30°,15°,5°}）。

5.2 关键发现小结

  • 像素空间直接监督 3D 表示有效：即便从零训练、无 VAE/RAE，PixWorld 在重建上匹敌 SOTA、在生成上全面超越潜空间方法，证伪了“3D 必须依赖潜空间压缩”的隐性假设。
  • clean/noisy 划分即统一：同一前向、同一损失公式（式6 指示函数切换）即可在重建（$\Omega_n=\varnothing$）与生成间无缝切换，无需双分支或任务特定头。
  • 2D 损失的几何盲区真实存在：消融显示移除几何感知后 VBench 式分数几乎不动，但 PSNR/SSIM/位姿大幅退化——证明“单帧好看”与“3D 几何正确”是两个不同目标。
  • 难侧优势最大：分配置结果（Appendix C）显示所有方法在 First-Frame / Extrapolation 上退化最严重，而 PixWorld 恰恰在这些难侧优势最大，说明像素空间 + 几何监督对外推、强视差更具泛化性。
  • 3D 基础模型作结构判据：冻结 π3 + 参考分支停梯度，使其纯作 critic，避免被训练分布污染，是低成本引入 3D 监督的优雅做法。

6. 局限性

  • 实验集中于 RealEstate10K、DL3DV-10K 等场景级数据集，对更多样的户外/物体中心场景的泛化仍待评估。
  • 像素空间扩散 + 可微渲染在有限分辨率与算力预算下训练，细粒度纹理保真度与向高分辨率多视图扩展仍有提升空间。
  • 当前为未蒸馏 base 模型，推理加速（蒸馏 + 量化）是后续工作。
  • 潜在社会影响：高质量 3D 重建/生成可能引发隐私敏感场景捕获、合成内容滥用、安全关键场景不可靠部署等风险。

7. 总结与启发

PixWorld 的核心贡献是把 3D 生成与重建统一到像素空间 flow matching + 可微渲染这一单一范式：去掉 VAE/RAE 中间瓶颈，让扩散目标直接监督底层 3D 高斯；以 clean/noisy 视图划分天然统一两任务；再以冻结 3D 基础模型的几何感知特征弥补 2D 损失的几何盲区。一个 1.04B 的从零训练模型即可在重建上匹敌 SOTA、在生成与 WorldScore 上全面领先潜空间方法。

读后启发：
  1. “去潜空间化”趋势。从 VAE→RAE→3D 基础模型表示空间，潜空间方法一直在追平像素保真度；PixWorld 显示在 3D 这一可微渲染天然提供“像素级可验证目标”的领域，直接回像素空间反而更顺。这暗示凡有可微前向模拟器的生成任务（3D、视频、物理），像素空间监督都可能成为更优解。
  2. 统一 ≠ 两套头，而是一种条件化。PixWorld 把“重建 vs 生成”简化为“输入子集是否含噪声”，本质是把任务差异编码进输入的时间步。这种“通过输入构造而非架构分叉实现统一”的思路值得迁移到其他多任务模型。
  3. 2D 评价指标会骗人。消融中 VBench 几乎无变化但 PSNR/AUC 大幅退化，提醒：评估 3D/world model 必须有几何维度的指标（位姿 AUC、3D 一致性），否则会被“单帧好看”误导。
  4. 基础模型即 critic。冻结一个强 3D 几何模型（π3/VGGT）做特征空间判据，是低成本引入 3D 结构监督的通用范式，可推广到任意“有可微渲染/前向”的生成训练。
  5. 速度优势来自表示而非蒸馏。PixWorld 无需物化稠密帧（8 关键帧 + 光栅化），在未蒸馏下已达 FlashWorld 量级，说明 3D 表示路线在长程生成上具结构性效率优势。
