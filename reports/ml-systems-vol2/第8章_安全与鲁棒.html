一、开篇：舰队扩大攻击面

单模型 API 有输入/输出边界；175B 舰队级系统增加整条 supply chain：checkpoint 存储、训练数据湖、GPU 多租户、边缘 FL 更新通道、feature store、prompt 日志。任一 S3 公开 bucket 可泄露 10 TB 语料或 LoRA 权重；十亿用户 prompt 入库是高价值 PII 目标。

安全问「谁能动模型与数据」；鲁棒问「输入/分布/硬件偏离假设时输出是否仍有界」。二者在 fleet 上共享同一运维入口——准确率降而延迟正常时，须一条诊断流分诊，而非两套工单系统。

二、模型提取与 API 滥用经济学

提取成本对称

若 API 返回 logits/top-k：~$10^4$–$10^6$ query 可蒸馏功能等价小模型。防御：rate limit（100 req/min/key）、输出截断（仅 top-1 token）、水印、异常 query 模式（prompt 网格扫描）。

攻击者 spend $ ≈ 合法 fine-tune 预算——高价值模型必须 assume 提取经济可行，rate limit 是产品决策非纯安全补丁。

三、数据投毒：训练期后门

注入 $(x_{\text{trigger}}, y_{\text{target}})$ 对，模型在触发器上输出攻击者标签、其余正常。web-scale crawl：0.01% 毒样（1M 中 100 条）可植入后门。防御：provenance、异常 loss 审计、red-team 触发器集、训练时 gradient clipping + 鲁棒聚合。

投毒是训练期威胁；对抗样本是推理期威胁——二者均可表现为「正常请求、错误输出」，但响应不同：前者需重训+数据清洗，后者需输入过滤或对抗训练（§6）。

四、差分隐私：与第 7 章 FL 同一账本

$$\Pr[\mathcal{M}(D) \in S] \leq e^\epsilon \cdot \Pr[\mathcal{M}(D') \in S] + \delta$$

SGD + DP：每步梯度 clip 到 $C$，加噪 $\sigma C$。$\epsilon$ 随训练步数累积——1000 epoch 无 composition 分析会严重低估泄露。工程：RDP/zCDP 会计；目标 $\epsilon \leq 8$、$\delta = 10^{-5}$（须法务定）。

第 7 章 FL 在设备侧 clip+noise；数据中心 DP-SGD 在 batch 侧——数学相同，composition 规则相同。隐私-精度 Pareto 是跨章共享约束，非边缘专属。

五、防御架构：零信任与 lineage

  • 零信任：训练/worker mTLS；artifact 签名验证
  • 最小权限：checkpoint 桶训练 SA 写、serving SA 读
  • 审计 lineage：shard ID → 证明「16k GPU 训练未 ingest 禁止集」
  • 机密计算：TEE/SGX（延迟 +10–30%）——与第 6 章 SLO 张力

安全防线把外部攻击挡在边界外；下一节处理边界内仍可能出错的情况——传统软件大声崩溃，ML 系统静默失败。

六、静默失败与三柱威胁

传统软件大声失败：异常、断言。ML 系统静默失败：OOD 输入仍高置信；对抗样本与正常请求无异；漂移时 uptime 稳定而准确率下滑数周。临床 NLP 2019 训练、2021 部署不重训，准确率可降 15–25%——概念漂移不触发 crash。

鲁棒 AI 定义

在分布漂移、对抗扰动、软硬件故障下，预测仍落在指定误差界内——95% i.i.d. 准确率 ≠ 鲁棒。Security 定义访问权；Robustness 定义偏离假设时的有界性。

War Story：Google Photos（2015）

黑人照片误标「Gorillas」——临时缓解是删除标签而非修复分类器。slice-level 评估与 harmful fallback 须上线前完成。

Meta SDC：~6–8 台/百万机器/日，corrupted gradient 污染 optimizer——比 SQL 丢行 blast radius 大，须回滚 checkpoint（第 5 章 verify）。软件 Bug 可放大或伪装为漂移/对抗——三柱须分诊。

七、对抗扰动：$\epsilon$ 与决策边界

ImageNet 基准：$\epsilon=8/255$（人眼不可见）足以让标准 ResNet 在 PGD 下失效。

$$\min_{\|\delta\|_\infty \le \epsilon} \; \mathcal{L}(f(x+\delta), y)$$
防御机制系统代价
对抗训练训练注入 PGD训练 +2–4×，干净精度 −2–5 pt
Certification区间传播证明推理 5–50× 慢
输入过滤激活空间异常+5–15% 算力，误拒 5–15%

第 6 章 INT4 量化压缩鲁棒 margin——压缩与鲁棒是张力对，须在 playbook 中联合验收。

八、分布漂移：PSI → KS → 动作

Vol.1 引入 PSI；本章给出运维响应链（与第 7 章 per-model 监控对接）：

$$\mathrm{PSI} = \sum_{i=1}^{k} (p_i - q_i) \cdot \ln\frac{p_i}{q_i}$$
PSI动作
< 0.1继续监控
0.1 – 0.25调查 + KS 确认
≥ 0.2548h 内 shadow 验证或重训

8.1 KS 显著性

$$D_{n,m} > c(\alpha)\sqrt{\frac{n+m}{nm}} \Rightarrow \text{拒绝「无差异」}$$

PSI 量化幅度；KS 问是否超过抽样噪声。高维须 MMD 或 per-feature PSI 组合。

8.2 概念漂移 vs 数据漂移

数据漂移：$p(x)$ 变、$p(y|x)$ 不变——重采样可恢复。概念漂移：$p(y|x)$ 变——仅监控 $p(x)$ 的 PSI 无信号，须 ground-truth 反馈环。DR 农村子群精度跌而全局 PSI 绿——典型概念/slice 漂移。

九、Golden Replay 与鲁棒性预算

准确率降、延迟正常——保存 golden input 重放 pipeline：

  • 输出与历史不一致 → 系统/SDC（ECC、回滚、第 5 章 verify）
  • 输出一致 + PSI 高 → 漂移（调查、重训）
  • 微小扰动即翻转 → 对抗（过滤、降级模型）

鲁棒性资源预算

  • 监控算力：+5–15%
  • 冗余/ensemble：2–3× 能耗
  • 内存带宽：+12–25%

10 W 无人机无法承担 datacenter 全栈冗余——选择性加固关键路径，其余 graceful degradation（ simpler model / reduced-feature mode）。与第 7 章边缘 DR 同一逻辑。

十、章节总结

安全 × 鲁棒诊断链

  1. 舰队 = 更多入口；提取是 $/query 问题，投毒是基数问题——pipeline 内建 provenance + rate limit
  2. DP $\epsilon$ 须 composition；与第 7 章 FL 共享 Pareto
  3. 静默失败须 golden replay 分诊三柱；勿把 SDC 当漂移、把漂移当对抗
  4. PSI ≥0.25 → 重训；0.1–0.25 → 调查；与 KS 组合
  5. 鲁棒预算是 C³ coordination 成本——边缘 selective hardening，数据中心 selective monitoring
投毒与对抗是重叠威胁面；PSI 告警是漂移的运维入口——一条 golden replay 流，比两套安全/质量团队更快分诊。
