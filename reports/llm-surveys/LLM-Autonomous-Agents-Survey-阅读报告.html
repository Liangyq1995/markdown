1. 核心问题与动机

为什么 LLM 使 Agent 产生范式转变：传统 Agent 在孤立受限环境中训练，行为策略简单，与人类决策方式差距巨大。LLM 通过海量 Web 知识获取，展现出人类级智能潜力，使构建真正通用的自主 Agent 成为可能。这是 AI Agent 从"规则专家"到"通用智能体"的跨越。

2.1 档案模块（Profiling）

方式说明优缺点
手工设计人工编写档案信息（角色、性格、专业背景）灵活精确，但劳力密集
LLM 生成提供规则和种子样例，LLM 批量生成效率高，但控制精度差
数据集对齐从真实数据集提取档案真实性强，受限于数据集覆盖

2.3 规划模块（Planning）

类型代表方法特点
无反馈 · 单路径CoT / Zero-shot CoT单一线性推理链，简单高效
无反馈 · 多路径CoT-SC / ToT / GoT树状/图状结构，允许回溯探索

有反馈 · 人类反馈交互式 Agent用户修正和引导

2.4 行动模块（Action）

  • 行动目标：任务完成 / Agent 间通信 / 环境探索
  • 行动空间：工具调用（API/外部工具）/ 数据库查询 / 外部存储 / 内在状态更新
  • 动作产生：记忆回溯（从历史检索）+ LLM 直接生成（新动作）

3. 能力获取策略

flowchart TD
    AGENT_ERA["Agent 时代：三策略并行"]
    FT["微调（Fine-tuning）\n调整参数，最强效果\n仅限开源模型"]
    PE["提示工程（Prompt Engineering）\n无需参数更新\n适用于闭源模型\nFew-shot / CoT / ReAct"]
    ME["机制工程（Mechanism Engineering）\n设计专用模块和工作规则\nAgent 时代的新范式\nTrial-and-Error / 众包辩论\n教师-学生框架 / 多 Agent 协作"]
    AGENT_ERA --> FT & PE & ME
机制工程：Agent 时代的新范式
传统 AI 只有两种能力获取方式：学习（参数更新）和程序（规则编程）。Agent 时代出现了第三种：通过设计 Agent 的协作机制（试错、辩论、角色分工）来涌现更强能力，而无需改变单个模型的参数。这是多 Agent 系统能力超越单模型的根本机制。

4. 应用领域

领域代表应用特点
社会科学心理健康支持、政治经济分析、法律辅助、社会模拟需要角色扮演一致性，伦理风险高
自然科学化学实验助理、科学知识管理、数学教育需要精确性，错误零容忍
工程领域软件工程（SWE-Bench）、代码生成、推荐系统、机器人可执行验证，反馈闭环清晰

5. 评估体系

评估类型方法特点
主观评估人工标注 / 图灵测试反映人类偏好，成本高，难以规模化
客观评估（指标）任务成功率、步骤效率、工具调用次数可量化，但指标设计难
客观评估（基准）WebShop、SWE-Bench、GAIA、tau2-Bench标准化，支持横向对比

6. 挑战与未来方向

  • 有限上下文长度：长任务中 Agent 无法保持足够长的历史记忆——可参见 Long-Context LM Survey 中的解决方案
  • 幻觉问题：LLM 可能生成不实信息影响决策，Agent 的多步执行会放大单步错误
  • 角色扮演一致性：长期交互中身份和性格保持困难
  • 知识过时：训练数据截止导致无法处理新知识（RAG 是当前主流缓解方案）
  • 安全与伦理：自主行动可能带来不可控风险，尤其在高风险域

7. 核心洞见与读后评注

四模块框架的普适性
档案/记忆/规划/行动四个模块不只是描述性分类，而是构建 Agent 系统时的设计清单。任何一个真实部署的 Agent 系统都需要回答：（1）这个 Agent 是谁（档案）；（2）它记住了什么、忘记了什么（记忆）；（3）它如何做决策（规划）；（4）它能做什么动作（行动）。这个框架可以直接指导系统设计。
记忆反思：元认知的 Agent 实现
"记忆反思"——从低层原始记忆提炼高层洞察——对应人类认知科学中的"元认知"（metacognition）：对自己思维过程的思考。这不只是存储更多信息，而是形成更高级的知识结构。Voyager 和 Generative Agents 等工作证明，具有反思能力的 Agent 在长期任务中能形成"战略性知识"，而不仅仅是战术性记忆。
