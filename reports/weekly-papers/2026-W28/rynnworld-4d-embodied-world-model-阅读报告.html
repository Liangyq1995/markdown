1. 概述

RynnWorld-4D 提出一个核心论点：同步的 RGB、深度、光流（RGB-DF）构成一种物理上 grounded 的表示，能够刻画场景底层的 4D 动力学。相比 2D 像素视频，这种多模态协同将"视觉外观—几何结构—时序运动"三者对齐，使得表示空间显著更接近机器人末端执行器所需的低层动作，从而缩小"世界预测"与"策略学习"之间的鸿沟。

基于此，论文做出四点贡献：

  • 投影式 4D 表示：协同生成 RGB、深度、光流，并自然支持反投影为 3D 场景流（3D Scene Flow），在保持几何/运动显式的同时兼容大规模视频扩散先验。
  • RynnWorld-4D 三分支世界模型：在单一去噪循环内，通过跨模态互注意力同步生成物理一致的 RGB-DF 序列。
  • Rynn4DDataset 1.0：超 2.544 亿帧的大规模混合 4D 具身视频数据集，附带深度与光流伪标签。
  • RynnWorld-4D-Policy：逆动力学头，单次前向消费世界模型内部 4D 表示，绕过多步去噪，实现高频闭环控制。

实验显示：在真实灵巧双臂操作任务上达到 SOTA，尤其在需要空间精度与时序协调的任务上优势明显（如 Lid Placement / Bowl Stacking 成功率 65.71%，较次优 DP 高 8.57%）。

2. 研究背景与动机

2.1 2D 视频世界模型的根本局限

近期生成式视频模型在策略合成、数据仿真、长程规划上取得进展，但受限于2D 投影本质：丢失关键空间关系，无法精确做 6-DoF 位姿估计与深度感知交互；缺乏几何 grounding 导致物体尺度波动、非物理形变等时序不一致，阻碍稳健策略学习。因此，从 2D 视频迈向几何集成的 4D 场景演化是具身智能的基础关键步。

2.2 现有 4D 场景建模的两类路线及其不足

类别代表方法特点局限
NeRF / 3DGS 类4D-FY、L4GM、CAT4D、SG-GS 等分优化式（scene-specific，计算密集）与前馈式（快，偏物体中心）需多视角输入、难扩展到复杂场景级、难与视频扩散先验结合
动态 SfM 类MegaSAM、Continuous 3D Perception重建时变点云缺乏从单图预测未来的生成能力

最相关的工作：TesserAct（Zhen et al., 2025）用 RGB-DN（RGB+深度+法线）建模 4D 并支持语言条件控制；4DNeX（Chen et al., 2025）生成高质量动态点云用于新视角视频合成。本文目标同为可扩展 4D 预测，但引入光流，使帧间 3D 运动显式化——这是 TesserAct 依赖静态几何（法线）所不具备的。对灵巧操作而言，物体与末端执行器的精细轨迹恰恰是成败关键。

2.3 面向具身控制的未来预测

SuSIE、UniPi 等用 2D 未来预测引导策略学习，通过在线规划、离线策略合成或逆动力学模型导出动作。但这些管线完全在 2D 像素空间且每步动作都要反复去噪，几何精度与控制响应性都受限。RynnWorld-4D-Policy 直接消费世界模型内部预测特征，单次前向生成动作 chunk，绕过逐步视频解码与去噪。

3.1 Rynn4DDataset 1.0 数据集

为填补 4D 生成训练数据空白，构建混合数据集：2.544 亿帧，来自人本位视频（Epic-Kitchens、EgoVid）与机器人操作视频（RoboMIND、RDT-1B、Galaxea、RoboCoin、AgiBot）。每帧附带高质量 4D 伪标注：细粒度指令、单目深度、稠密光流。

多模态标注流水线：

  • 视频描述：Qwen3-VL，1 FPS 采样、5 秒分段，最大输出 512 token、温度 0.7，存为 JSON。
  • 光流标注：DPFlow，原生分辨率逐帧对，颜色编码存为 25 FPS MP4。
  • 深度标注：Depth Anything 3（DA3NESTED-GIANT-LARGE-1.1），30 FPS、短边 392px；上采样到原分辨率，裁剪到全局范围 $[0.0, 5.0]$ 米并 8-bit 量化：

$$I = \left\lfloor \frac{d}{d_{max}}\times 255\right\rfloor$$

3.2 投影式 4D 表示与 3D 场景重建

RGB-DF 的关键优势是几何可解释性：将协同生成的深度与光流结合，可重建时间一致的 3D 场景并导出度量场景流。

几何反投影。给定帧 $t$ 的深度图 $D_t$，每个齐次坐标像素 $p_t=[u,v,1]^\top$ 反投影到 3D 相机空间：

$$P_t = D_t(u,v)\cdot K^{-1}p_t \tag{1}$$

其中 $K$ 为相机内参矩阵。该过程将 2D 投影序列提升为度量 3D 点云 $C_t=\{P_t^i\}_{i=1}^{H\times W}$。

度量场景流推导。利用协同生成的稠密光流 $f_{opt}=[\Delta u,\Delta v]^\top$ 建立时序对应。3D 点 $P_t$ 被追踪到 $t+1$ 时刻：

$$P_{t+1} = D_{t+1}(u+\Delta u,\, v+\Delta v)\cdot K^{-1}\left(p_t + [\Delta u,\Delta v,0]^\top\right) \tag{2}$$

3D 场景流定义为每点度量位移：

$$f_{3D} = P_{t+1} - P_t$$

这一显式 4D 映射保证生成轨迹不是视觉幻觉，而是对应物理可实现的 3D 运动。

细化与可视化。为抑制深度不连续处的伪影，应用基于深度梯度的边缘滤波，屏蔽 $\|\nabla D\| \gt \tau$ 的像素；细化后 3D 轨迹投影到鸟瞰图（BEV）渲染为彩色轨迹。

3.3 RynnWorld-4D 三分支架构

将预训练视频生成模型扩展为三分支结构。模态 $m\in\{rgb, depth, flow\}$ 的潜变量记为 $z_t^m$，$t\in[0,1]$ 为 flow-matching 时间步，每个 $z_t^m\in\mathbb{R}^{T\times C\times H\times W}$ 包含 $T$ 帧完整时序。

三分支设计。将 Wan 的单分支骨干扩展为三分支：RGB（复杂纹理）、depth（空间几何）、flow（运动位移）各自建模独特分布，缓解表征干扰。深度/流分支由复制预训练组件（patch embedding、self-attn、norm、FFN）初始化，继承时空先验。文本 cross-attention 的 K/V 投影三分支共享（语言语义是模态无关的），降低开销。

Joint Cross-Modal Attention（JA）。每 3 个 transformer block 插入一个 JA 模块，30 层共 10 个（层 0,3,6,...,27），置于各分支 intra-modal self-attention 之后。跨模态融合前，每个分支 $m$ 接收可学习的模态嵌入 $e^m\in\mathbb{R}^{1\times1\times d}$（零初始化以纯残差起步），并用每模态 LayerNorm 对齐数值尺度：

$$\tilde{z}_l^m = \mathrm{LN}_m\left(z_l^m + e^m\right) \tag{3}$$

每个分支产生一个 query 与一对被其他分支复用的共享 K/V，参数开销从 $18d^2$ 降到 $12d^2$：

$$Q_l^m = \mathrm{RMSNorm}_q\left(\mathrm{QProj}_l^m(\tilde{z}_l^m)\right) \tag{4}$$

$$[K_l^m, V_l^m] = \mathrm{KVProj}_l^m(\tilde{z}_l^m),\quad K_l^m \leftarrow \mathrm{RMSNorm}_k(K_l^m)$$

token 从 $[B, T\cdot S, d]$ reshape 为 $[B\cdot T, S, d]$，使跨模态注意力仅限于同一时间帧的跨模态 token；并对 $Q_l^m$、$K_l^{cross}$ 施加 3D RoPE 注入空间位置。每个 query 只 attend 另外两个互补模态的 K/V：

$$A_l^m = \mathrm{Attn}\left(\mathrm{RoPE}(Q_l^m),\, \mathrm{RoPE}(K_l^{cross}),\, V_l^{cross}\right) \tag{5}$$

$$K_l^{cross}=\mathrm{concat}\left(\{K_l^j\}_{j\neq m}\right),\quad V_l^{cross}=\mathrm{concat}\left(\{V_l^j\}_{j\neq m}\right)$$

关键初始化设计。论文指出 ControlNet 风格的"双重零初始化"会引入鞍点死锁（saddle-point deadlock）。因此采用：输出投影 $\mathrm{OutProj}_l^m$ 零初始化 + 可学习标量门 $g_l^m$ 初始化为 1：

$$\hat{z}_l^m = \tilde{z}_l^m + \tanh\left(g_l^m\right)\cdot \mathrm{OutProj}_l^m\left(A_l^m\right) \tag{6}$$

初始化时 $\mathrm{OutProj}\equiv 0$ 保证从 Stage-1 检查点的平滑热启动；而 $\tanh(g_l^m)=\tanh(1)\neq 0$ 确保非零梯度流入门，使其可增可减可变号，避免联合通路被困在原点。这是本文一个值得注意的工程细节。

Algorithm 1: Joint Cross-Modal Attention（JA）前向

Input: 三分支潜变量 z_l^rgb, z_l^depth, z_l^flow；模态嵌入 e^m；门 g_l^m

// 1. 模态对齐（零初始化残差）

for m in {rgb, depth, flow} do

ẑ̃_l^m = LN_m(z_l^m + e^m)

// 2. 各分支产出 Q 与共享 K/V（参数 12d²）

Q_l^m = RMSNorm_q(QProj(ẑ̃_l^m)); [K_l^m,V_l^m]=KVProj(ẑ̃_l^m)

// 3. reshape 到 [B·T,S,d]，按帧 mask + 3D RoPE

K_cross = concat({K_l^j}_{j≠m}); V_cross = concat({V_l^j}_{j≠m})

A_l^m = Attn(RoPE(Q_l^m), RoPE(K_cross), V_cross)

// 4. 门控残差融合（OutProj 零初始化，g 初始化为 1）

ẑ_l^m = ẑ̃_l^m + tanh(g_l^m) · OutProj(A_l^m)

return ẑ_l^rgb, ẑ_l^depth, ẑ_l^flow

分支 Dropout。Stage 2/3 中以概率 $p_{drop}$ 随机选 {depth, flow} 之一，将其噪声潜变量（frames [1:]）替换为纯高斯噪声，强制 JA 模块从可见模态重建。RGB 分支永不丢弃，因为它是外观锚点。

训练目标。三阶段均用 flow matching 目标。对每个模态 $m\in M=\{rgb,depth,flow\}$，学习速度场 $v_\theta^m$ 将高斯噪声 $\epsilon^m$ 传输到数据 $z_0^m$，路径为 $z_t^m=(1-t)z_0^m+t\epsilon^m$。每模态首帧为干净 image-to-video 条件潜变量（真实 RGB 帧、真实深度帧、零流帧），不参与监督，用切片 [1:] 表示帧 $1,\ldots,T-1$。总损失：

$$\mathcal{L}_{total} = \sum_{m\in M}\lambda_m\,\mathbb{E}_{z_0^m,\epsilon^m,t,c}\left[\left\|v_\theta^m(z_t^m,t,c)_{[1:]} - (\epsilon^m - z_0^m)_{[1:]}\right\|_2^2\right] \tag{7}$$

其中 $c$ 为文本 prompt + 初始 RGB-D 观测；$\epsilon^{rgb}=\epsilon^{depth}=\epsilon^{flow}$ 为三模态共享的单一高斯噪声，保证去噪轨迹时间对齐。模态权重：$\lambda_{rgb}=\lambda_{depth}=1$ 全程；$\lambda_{flow}=0.5$（Stage 1，光流首帧暖启动无信息），Stage 2/3 升至 1.0。

预备知识（rectified flow）。Wan 的前向过程为线性插值：

$$z_t = (1-t)z_0 + t\epsilon,\quad \epsilon\sim\mathcal{N}(0,I) \tag{13}$$

$$\mathcal{L}_{CFM} = \mathbb{E}_{t,z_0,\epsilon}\left[\left\|v_\Theta(z_t,t) - u_t(z_0\mid\epsilon)\right\|_2^2\right] \tag{14}$$

3.4 分阶段训练策略

为弥合模态间显著分布差异，采用三阶段课程（每阶段从上一阶段 model-only 检查点初始化，重置优化器/调度器）。优化器 AdamW（$\beta_1=0.9,\beta_2=0.95$，weight decay $1\times10^{-4}$），cosine 调度 + linear warmup，EMA decay 0.9999（CPU 影子权重）。训练分辨率 $81\times480\times640$，causal VAE 4× 时序压缩得 $T=21$ 潜帧（$T_{latent}=(T_{pixel}-1)/4+1$），bf16 混合精度 + gradient checkpointing；Stage 2/3 用 DeepSpeed ZeRO-2 + optimizer offload。

3.5 RynnWorld-4D-Policy 逆动力学头

将 RynnWorld-4D 作为预测式 4D 视觉编码器。给定当前 RGB-D 观测与指令，对冻结的世界模型做一次前向，得到编码未来动力学的潜轨迹。提取所有分支中间隐状态并在通道维拼接得 $F_p\in\mathbb{R}^{B\times T\times 3C\times H\times W}$（$C$ 为每分支潜通道）。RGB 分支提供视觉上下文，depth/flow 分支提供显式几何/运动线索。

实现细节：480×640 分辨率，$T=21$ 潜帧；在扩散时间步 $t=500$ 做单步特征提取，取 transformer block 15 的中间隐状态，三分支各 3072 维拼接。

Flow Former。用可学习 query $Q$ 压缩 4D 特征：逐帧空间 cross-attention + 时序 self-attention：

$$Q'_i = \mathrm{Spat\text{-}CrossAttn}(Q_i,\, F_p[i]),\quad Q'' = \mathrm{FFN}\left(\mathrm{Temp\text{-}SelfAttn}(Q')\right),\quad i\in\{1,\ldots,T\} \tag{8}$$

动作生成。flow matching 策略头（同 Eq.7 目标），速度场 $v_\phi$ 作用于动作空间 $a$，条件为预测 4D token $Q''$、文本嵌入 $l_{emb}$、本体感知 $p_0$。推理用 ODE solver N=4 步。动作 chunk 长度 10，每动作 54 维。

Algorithm 2: RynnWorld-4D-Policy 推理（闭环控制）

Input: 当前 RGB 观测帧, 深度, 指令; 冻结 RynnWorld-4D 骨干; chunk K=10

// 单次前向提取 4D 预测特征（N=1，t=500）

F_p = concat_channels(RynnWorld-4D(RGB, depth, 指令, block=15))

Q'' = FlowFormer(F_p) // 逐帧空间交叉注意力 + 时序自注意力

// 4 步 ODE 采样动作 chunk（仅在轻量策略头内）

a = ODESolve(v_φ, steps=4, cond=[Q'', l_emb, p_0])

// 并行执行 + 重规划

while 机器人执行 a 的 K 步 do 异步预计算下一 chunk

return 有效控制频率 ≈ 9 Hz

3.6 推理延迟与实时控制

部署于 NVIDIA RTX 5090，FP8 量化 + FlashAttention 3。4D 视觉特征仅在冻结骨干中前向一次（N=1），后续 4 步 ODE 采样只在轻量策略头内进行。$K=10$ 动作/前向，总周期约 1.1s，有效控制频率约 9 Hz（规划频率约 0.9 Hz，但 10 个动作顺序执行时下一规划周期并行计算）。

5. 消融实验与关键发现

  • 三分支融合的必要性：独立分支（Independent Branches）虽能各自生成模态，但 depth（AbsRel 0.737 vs 0.310）与 flow（AEPE 0.247 vs 0.170）大幅退化——互特征交互对跨模态一致性与物理保真度至关重要。
  • 模态适配（MA）的必要性：跳过 Stage 1 直接联合训练，深度/流分支难以弥合继承的 RGB 先验与自身分布的差距，$\delta_1$ 从 0.610 降到 0.479。模态专属适配是多模态融合的前提。
  • 大规模 4D 预训练的必要性：仅用任务专属机器人数据训练，AEPE 从 0.170 飙升至 0.729，全面崩塌——任务数据缺乏掌握复杂时空动力学所需的多样性。
  • 预测式潜变量的有效性：用 ResNet-18 替换预测编码器，所有任务下降，Dual Picking 从 94.29% 跌到 71.43%——静态 2D 特征不足以支撑复杂任务。
  • 4D 模态贡献：仅 RGB 次优；加 depth 在 Hand-over、Bimanual Lifting 等空间精度任务上显著增益；加 flow 增强运动敏感任务；三者合一最优，证明"视觉上下文 + 空间几何 + 运动动力学"协同不可或缺。
  • JA 中 3D RoPE 的作用：去掉后虽 intra-modal self-attn 保留局部结构，但跨分支通路失去共享位置偏置，破坏相同 $(u,v)$ 坐标处的几何对应，$\delta_1$ 从 0.610 降到 0.450，AEPE 从 0.170 升到 0.210。3D RoPE 是像素级空间感知融合的"对齐桥"。
  • 每分支 FFN vs 共享 FFN：共享 FFN 导致系统性崩塌（AbsRel 0.580 / $\delta_1$ 0.380 / AEPE 0.280）。RGB 纹理、深度流形、运动场的潜空间本质异质，强制共享非线性变换引发灾难性干扰——模态专属容量不可或缺。

评测指标定义（Appendix B）：

$$\mathrm{AbsRel} = \frac{1}{|V|}\sum_{p\in V}\frac{|s\cdot\hat{d}_p - d_p^{*}|}{d_p^{*}},\quad s=\mathrm{median}(d^{*})/\mathrm{median}(\hat{d}) \tag{10}$$

$$\delta_1 = \frac{1}{|V|}\sum_{p\in V}\mathbb{1}\!\left[\max\!\left(\frac{s\cdot\hat{d}_p}{d_p^{*}},\,\frac{d_p^{*}}{s\cdot\hat{d}_p}\right) \lt 1.25\right] \tag{11}$$

$$\mathrm{AEPE} = \frac{1}{|V|}\sum_{p\in V}\left\|\hat{f}_p - f_p^{*}\right\|_2 = \frac{1}{|V|}\sum_{p\in V}\sqrt{(\hat{u}_p-u_p^{*})^2+(\hat{v}_p-v_p^{*})^2} \tag{12}$$

注：预测与真值光流均以 Middlebury 色轮编码存储为可视化，故 AEPE 实为归一化 RGB 颜色空间上的逐像素 $\ell_2$ 距离，排除首帧（无时序参考）后取均值。

6. 总结与启发

  • 表示先行：RGB-DF 是一个"轻量但够用"的 4D 表示——既不像体素/4D 高斯那样重，又比 2D 像素多了显式几何与运动，且仍 2D 对齐、可继承视频扩散先验。这种"投影式 4D"是连接视频模型可扩展性与机器人几何严格性的实用折中。
  • 互正则化即物理先验：在单条去噪循环内联合建模 RGB/depth/flow，三者互为约束，使生成不只是视觉幻觉而是物理可实现的 3D 运动——$\delta_1$、AEPE 的领先本质来自此。
  • 共享噪声对齐时序：三模态共享同一高斯噪声 $\epsilon$ 保证去噪轨迹时间对齐，是协同生成的关键且低成本技巧。
  • 避开 ControlNet 鞍点：零初始化输出投影 + 门初始化为 1（$\tanh(1)\neq0$）保证梯度流入门、避免联合通路被困原点——比双重零初始化更稳，值得在多模态融合模块中复用。
  • 预测式潜变量直出动作：把世界模型当"4D 视觉编码器"，单次前向 + 轻量 ODE 头绕过多步去噪，是"世界模型用于实时控制"的现实路径。瓶颈在骨干前向（89.5%），未来可考虑蒸馏/缓存/更轻骨干。
  • 模态专属容量不可省：共享 FFN 灾难性干扰说明 RGB/depth/flow 潜空间异质，需独立 FFN 与独立分支建模。
  • 9Hz 闭环的鲁棒性来源：动作 chunk + 50Hz 缓存执行 + 3D 场景流 grounded 的更宽捕获范围，使略低于 PID（>500Hz）的频率仍可应对扰动。

7. 局限性

  • 延迟瓶颈：4D 生成依赖扩散去噪，RTX 5090 上有效控制频率约 9 Hz，对超高频率控制仍不足。
  • 视角受限：主要针对 egocentric 视角优化，扩展到多视角系统或协作多机器人仍为开放挑战。
  • 世界模型评测仅 50 段留出视频，规模偏小；AEPE 实为颜色空间距离而非度量光流误差，与原始定义有偏差。
