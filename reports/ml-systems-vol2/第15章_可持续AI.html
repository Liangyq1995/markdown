第15章 可持续 AI

《Machine Learning Systems at Scale》Vijay Janapa Reddi · MIT Press · Vol.2 Part IV · 生成日期：2026-07-04

核心主线能源墙 → PUE/碳强度公式 → 训练 vs 推理 生命周期 → 地理选址与碳感知调度 → embodied carbon
学习目标用 MWh、g/kWh、PUE 核算单次训练/服务碳足迹；判断优化应指向训练还是 inference 阶段

一、能源是硬约束，非运营费用

数据中心功率预算由电网与冷却容量封顶——超预算不是「贵」，是物理上不可行。Sustainable AI 将 joules、冷却负荷、embodied carbon、硬件更换周期与 accuracy/latency 并列写入架构决策。C³ 视角：再强的 compute/communication/coordination 也无法突破 facility 的 megawatt 上限——热力学极限闭合于 co-design。

定义：可持续 AI（Sustainable AI）

测量并优化 ML 全生命周期环境成本（训练/推理/制造的能源、水、碳），并将其作为显式约束纳入架构选择。

  • 与 CSR 报告区别：工作负载级决策——按 FLOP/s/W 选硬件、可再生窗口调度训练、选低 inference FLOPs 架构
  • 常见陷阱：「换绿电即可」——edge 设备 >50% 生命周期碳来自制造；硬件利用率与 longevity 与能源来源同等重要

Napkin Math：GPT-3 训练碳成本

训练能耗 1,287 MWh（≈120 美国家庭年用电 10.7 MWh/户）。

美国平均电网强度 429 g CO₂/kWh（0.429 kg/kWh）：

$C = 1{,}287{,}000 \text{ kWh} \times 429 \text{ g/kWh} = 552{,}123 \text{ kg} \approx \mathbf{552 \text{ t CO}_2}$

对比：NY–London 往返 ≈ 1 t/乘客 → 552 次跨大西洋往返。迁至 Quebec 水电（20 g/kWh）→ 约 25.7 次往返，21.4× 减排。

二、PUE 与运营碳公式

2.1 Power Usage Effectiveness

$$\mathrm{PUE} = \frac{P_{\text{facility}}}{P_{\text{IT}}}$$

PUE=1.0 为理想（不可能）；Google 高效设施 1.10–1.12；行业平均 1.5–2.0（50–100% 额外能耗用于冷却/配电）。低 PUE ≠ 低碳——煤电厂 PUE 1.1 仍可能比水电 PUE 1.5 碳强度高。

PUE 优化算例

2 MW IT 集群，PUE 从行业均值 1.58 → 1.10：

节省设施功率 $(1.58-1.10)\times 2\text{ MW}=0.96\text{ MW}$ → 年省约 8,409 MWh（@8760 h）。等价于不改一行训练代码使整个 fleet 算力效率 +30%。

2.2 运营碳：E × CI × PUE 链

$$E_{\text{total}} = E_{\text{IT}} \times \mathrm{PUE}, \qquad C_{\text{operational}} = E_{\text{total}} \times CI_{\text{grid}}$$

$CI_{\text{grid}}$：电网碳强度，单位 g CO₂/kWh（或 kg/kWh）。PUE 只进入 $E_{\text{total}}$ 一次，碳公式中不再重复乘 PUE。

10,000 MWh 训练任务：

三、训练 vs 推理：生命周期主导项

训练像发射火箭——单次集中消耗数千 MWh；推理像运营机队——按 query 连续燃烧，年复一年。优化靶点取决于哪项在生命周期中占主导。

阶段特征优化焦点
训练一次性；决定设施规格与 checkpoint 存储MFU、混合精度、碳感知时段/区域
推理随 QPS 线性扩展；Meta RM 模型以 inference 为主（图14 黑实条）量化、批处理、decode 带宽、edge 本地化

交叉点算例（7B / 64 A100 训练 5.7 t）

若每 query 0.001 kWh，日 1000 万 query → 日 10 MWh。

训练 1,287 MWh（GPT-3 级）匹配日 inference 约 130 天；7B 例（~13 MWh 级训练能耗）交叉约 1.3 天（书中 7B/64-GPU 场景）。

工程结论：广泛部署模型的最高杠杆通常是 inference 效率；频繁重训/实验迭代模型则优先训练效率。

3.1 Prefill vs Decode 能耗

Prefill：计算饱和，接近峰值 pJ/FLOP。Decode：每 token 读全量权重 + KV cache，算术强度低，计算单元空转耗静态功耗——decode 单 op 能耗可达 prefill 的 10–50×。1000 token 自回归 decode 可能比单次 prefill 1000 token 多耗一个数量级能量——驱动 memory-optimized NPU/TPU 设计。

3.2 Archetype A：能源墙

25,000 GPU × 700 W = 17.5 MW 仅加速器（不含服务器/网络/冷却）——这是电网容量问题，非财务问题。IEA 2025 预测 2030 数据中心用电 ~945 TWh（全球电力 ~3%）。2012–2019 AI 训练算力增 350,000×（约 4.6 月翻倍），硬件效率 ~1.5×/年——需求反弹（Jevons）使 per-FLOP 节能被部署规模吞没。

四、Embodied Carbon 与全生命周期

$$C_{\text{lifecycle}} = C_{\text{training}} + C_{\text{inference}} + C_{\text{embodied}}$$

H100 分摊 embodied ≈ 164 kg CO₂e/GPU（HGX 基板 1,312 kg / 8）。A100 ≈ 150 kg/片。电网 decarbonize 后，制造碳可成 dominant term——硬件 longevity + 利用率 成为一等杠杆。Edge 设备生命周期 >50% 碳在制造阶段。

Scope 2购入电力（训练/推理 kWh × CI）
Scope 3芯片制造、下游用户设备、CI/CD 实验算力

五、缓解策略与碳感知调度

Example 1.1：PlacementOptimizer 在 Quebec / 高碳区 / 低价煤电区间选 10,000 MWh 训练——引入 $100/t 内部碳税后，Quebec 水电 TCO $0.66M 全局最优（碳节约抵消电价差）。

  • 算法：稀疏/蒸馏降 FLOPs；early stopping 减无效实验
  • 基础设施：PUE、液冷、renewable 窗口调度
  • 硬件：延长刷新周期、refurbish、提高 utilization
  • 政策：内部碳价使外部性进入工程预算

175B 训练能量速算（Checkpoint 1.1）

$3.14\times 10^{23}$ FLOPs，效率 50 GFLOP/J，PUE 1.1 → 训练能量量级 ~10⁵ MWh 级（需按实际 MFU 校准）。 household-years = MWh / 10.7。MWh ≠ 碳——必须乘 CI。

六、章节总结

核心要点

  1. 能源/冷却是存在性约束；Sustainability 是 C³ co-design 的热力学闭合
  2. GPT-3：1,287 MWh → 552 t CO₂（US grid）；地理选址可达 20–40× 碳差
  3. $C = E_{\text{IT}} \times \mathrm{PUE} \times CI$；PUE 优化等价于「免费」算力增益
  4. 高流量服务：inference 生命周期碳可数月内超越一次性训练
  5. Decode memory-bound → 10–50× 于 prefill 的 per-op 能耗浪费
  6. Embodied carbon + Jevons 悖论：效率增益不保证绝对减排
可持续性的位移定律：省下的每瓦特 FLOP 若触发更大部署规模，fleet 总碳未必下降——需要绝对碳预算治理 usage growth。
