一、微调全景：从特征提取到全参数更新

原文：Finetuning Large Language Models

微调的核心问题是：在有限计算资源下，更新多少参数能获得最佳性价比？ Sebastian 通过在 DistilBERT 上的情感分类实验给出了系统性对比。

1.1 四种微调策略及实验结果

策略更新参数测试准确率计算开销适用场景
特征提取 + 逻辑回归0（冻结全部）83%最低资源极受限
微调 I：仅更新输出层仅最后2层87%低数据少、快速适配
微调 II：全层更新所有层92%高数据足够、追求最优
Adapter 微调~3.6% 参数≈全层微调低多任务、存储受限

1.2 三种微调方式代码对比

# 方式1：特征提取（冻结全部）
for param in model.parameters():
    param.requires_grad = False
# 只训练新增的分类头

# 方式2：微调输出层
for param in model.parameters():
    param.requires_grad = False
for param in model.classifier.parameters():
    param.requires_grad = True  # 只解冻分类层

# 方式3：全参数微调
for param in model.parameters():
    param.requires_grad = True  # 全部解冻

二、Adapter：插件式参数高效微调

原文：Finetuning LLMs Efficiently with Adapters

Adapter 方法由 Houlsby et al. 2019 提出，核心思想是在 Transformer 每层的注意力和 FFN 之后插入小型"适配器瓶颈模块"，微调时只更新这些模块，预训练权重完全冻结。

2.1 Adapter 模块结构

graph LR
  Input["层输出 h"] --> Down["下投影\n(d → r, r << d)"]
  Down --> Act["非线性激活\n(GeLU)"]
  Act --> Up["上投影\n(r → d)"]
  Up --> Add["残差相加"]
  Input --> Add
  Add --> Output["输出"]

其中 $r$ 是瓶颈维度（通常为原始维度的 1/8 到 1/32）。整个 Adapter 模块只有 $2rd$ 个参数，远少于原始层的 $d^2$ 参数。

2.2 为什么 Adapter 有效

  • Adapter 初始化为近恒等映射（下投影全零初始化），训练开始时对原模型无影响，保证稳定收敛
  • 只需要约 3.6% 的参数即可匹配全参数微调的性能（原始论文 BERT 结果）
  • 多任务场景优势明显：不同任务存储不同的 Adapter，共享同一预训练骨干

2.3 实验结果（DistilBERT 情感分类）

基线（只训练最后2层）: 87%
插入 Adapter 层:       ~90%（仅3.6%参数）
全参数微调:            92%
Adapter + 全参数微调:   ~92%（控制实验）

结论：Adapter 以极小参数代价接近全参数微调效果

三、LoRA：低秩分解的优雅方案

原文：Practical Tips for Finetuning LLMs Using LoRA

LoRA（Low-Rank Adaptation）是目前最流行的参数高效微调方法，由 Hu et al. 2021 提出。其核心洞察：预训练权重矩阵的更新量 ΔW 具有低内在秩（intrinsic rank），因此可以用两个小矩阵的乘积来近似。

3.1 LoRA 数学原理

原始权重更新：$W = W_0 + \Delta W$

LoRA 近似：$\Delta W \approx BA$，其中 $B \in \mathbb{R}^{d \times r}$，$A \in \mathbb{R}^{r \times k}$，$r \ll \min(d, k)$

前向传播：$h = W_0 x + \frac{\alpha}{r} BAx$

class LoRALayer(nn.Module):
    def __init__(self, in_features, out_features, rank=4, alpha=1.0):
        super().__init__()
        self.lora_A = nn.Parameter(torch.randn(in_features, rank))
        self.lora_B = nn.Parameter(torch.zeros(rank, out_features))  # B初始化为0
        self.scale = alpha / rank

    def forward(self, x):
        # lora_A @ lora_B 是低秩近似的权重增量
        return x @ (self.lora_A @ self.lora_B) * self.scale

class LinearWithLoRA(nn.Module):
    def __init__(self, linear, rank=4, alpha=1.0):
        super().__init__()
        self.linear = linear
        self.lora = LoRALayer(linear.in_features, linear.out_features, rank, alpha)

    def forward(self, x):
        return self.linear(x) + self.lora(x)  # 原始路径 + LoRA增量

3.2 LoRA 实战 10 问（Sebastian 实验总结）

问题实验结论
应该用多大的 rank r？r=4~16 通常足够；更大的 r 边际收益递减
应用到哪些层？Query + Value 效果最好；也可以加 FFN 层
训练多少 epoch？超过1个 epoch 通常性能下降（过拟合风险）
Adam vs SGD？小 r 时两者差异小；大 r 时 Adam 优势明显
内存消耗？AdamW: 17.86GB; SGD: 14.46GB（70B模型，r=64）

vs 全参数微调？通常接近全参数微调，但内存节省 3-10×

QLoRA 组合？4bit 量化 + LoRA，GPU 内存再减半，稍慢
层数选择规律？越高层（靠近输出）对任务特定知识越敏感

def freeze_linear_layers(model):
    for module in model.modules():
        if isinstance(module, LinearWithLoRA):
            module.linear.weight.requires_grad = False
            if module.linear.bias is not None:
                module.linear.bias.requires_grad = False

freeze_linear_layers(model)
# 验证只有 LoRA 参数可训练

四、DoRA：权重分解的低秩自适应

原文：Improving LoRA: Implementing DoRA from Scratch | 2024

DoRA（Weight-Decomposed Low-Rank Adaptation）是 LoRA 的改进版本，通过将权重矩阵分解为幅度（magnitude）和方向（direction）两个组成部分，让微调更像全参数训练的行为模式。

4.1 DoRA 核心思想

任意向量可以表示为幅度 × 方向。DoRA 将预训练权重 $W_0$ 分解为：

$$W_0 = m \cdot \frac{V}{\|V\|_c}$$

其中 $m$ 是列向量幅度，$V$ 是方向矩阵，$\|\cdot\|_c$ 是列向量范数。

微调时，DoRA 用 LoRA 更新方向分量 $V$，同时单独训练幅度向量 $m$：

$$W' = (m + \Delta m) \cdot \frac{V + \Delta V}{\|V + \Delta V\|_c}, \quad \Delta V = BA$$

4.2 PyTorch 实现

class DoRALayer(nn.Module):
    def __init__(self, d_in, d_out, rank=4, alpha=1.0):
        super().__init__()
        # 幅度向量（每列一个标量）
        self.m = nn.Parameter(torch.ones(1, d_out))
        # 方向的 LoRA 低秩更新
        self.lora = LoRALayer(d_in, d_out, rank, alpha)
        # 冻结的原始线性层（存储方向基准）
        self.linear = nn.Linear(d_in, d_out, bias=False)
        self.linear.weight.requires_grad = False

    def forward(self, x):
        # 获取当前方向：原始权重 + LoRA 更新
        lora_weight = self.linear.weight + (self.lora.lora_A @ self.lora.lora_B).T * self.lora.scale
        # 按列归一化（获取单位方向）
        norm = lora_weight.norm(p=2, dim=0, keepdim=True)
        direction = lora_weight / norm
        # 幅度 × 方向
        adapted_weight = self.m * direction
        return x @ adapted_weight

4.3 LoRA vs DoRA 对比

特性LoRADoRA

额外参数2rd2rd + d（幅度向量）
训练行为偏离全参数微调模式更接近全参数微调
升级难度基础实现在 LoRA 基础上小改动
效果强通常优于 LoRA

五、RLHF 与对齐：从 PPO 到 DPO

原文：LLM Training: RLHF and Its Alternatives

LLM 对齐的核心挑战是：如何让模型不只是"能力强"，还要"听话、无害、诚实"？RLHF（Reinforcement Learning from Human Feedback）是目前最成熟的方案，但其复杂性催生了一系列更简洁的替代方案。

5.1 完整 RLHF 流程

graph TD
  Step1["阶段1：监督微调 SFT\n用高质量人类示例微调预训练模型"]
  Step2["阶段2：训练奖励模型 RM\n收集人类偏好对(chosen/rejected)\n训练二元分类器"]
  Step3["阶段3：PPO 强化学习\n用 RM 作为奖励信号\n用 PPO 算法更新策略模型"]
  KL["KL 散度惩罚\n防止策略偏离 SFT 模型过远"]
  Step1 --> Step2 --> Step3
  Step3 --> KL --> Step3

5.2 DPO：无需强化学习的对齐

DPO（Direct Preference Optimization）将 RLHF 的三步流程压缩为一步监督学习。核心数学推导证明：在给定 KL 约束下，RLHF 的最优策略有闭合解，可以直接转化为分类损失：

$$\mathcal{L}_{DPO} = -\mathbb{E}\left[\log \sigma\left(\beta \log \frac{\pi_\theta(y_w|x)}{\pi_{ref}(y_w|x)} - \beta \log \frac{\pi_\theta(y_l|x)}{\pi_{ref}(y_l|x)}\right)\right]$$

其中 $y_w$ 是偏好回答，$y_l$ 是被拒绝回答，$\pi_{ref}$ 是参考模型（SFT 后的模型）。

5.3 RLHF 替代方案对比

方法是否需要RM是否需要RL核心思想特点
RLHF (PPO)是是奖励模型 + PPO 策略优化最强但最复杂
DPO否否偏好对 → 直接监督损失简单稳定，主流
RLVR (GRPO)否（规则验证）是可验证任务的规则奖励推理任务最优
Rejection Sampling SFT是（用于筛选）否生成K个样本，只训练最好的Llama 2 使用
CPL（对比偏好学习）否否对比损失（DPO 的特例）可用于机器人控制
ReST（强化自训练）弱监督类RL迭代生成+过滤+微调无需人类标注

5.4 实践选择指南

如何选择对齐方法？
  • 数学/代码任务（有明确答案）：优先选 RLVR，规则奖励信号最可靠
  • 通用对话/指令遵循：DPO 是最简单有效的起点
  • 需要最强对话质量：RLHF (PPO)，但要承受工程复杂度
  • 数据极少：Rejection Sampling SFT，利用模型自身生成能力
