计算机视觉长期停留在"专用模型"阶段：SAM 系列、Depth Anything 系列等虽然强大，但本质上仍是任务特定的架构，每个任务都需要定制化的 encoder/decoder/loss。本文作者提出一个宏大的命题——寻找 CV 中 next-token prediction 的等效物。他们论证：大规模文生视频生成恰好满足通用视觉基础模型预训练的三大核心要求，即 时空演化（Spatio-Temporal Evolution）、视觉-语言对齐（Vision-Language Alignment）、可扩展性（Scaled up）。

基于此，论文提出 GenCeption：把预训练的 text-to-video 扩散 backbone 当作"base model"，借助生成式预训练习得的丰富先验，再通过多任务 post-training（主要使用合成数据）将其改造为单次前馈（single forward-pass）的感知模型，由文本指令切换输出模态。该方法在 depth、normal、camera pose、分割、3D keypoint 等任务上全面达到或超越专用 SOTA，并展现出 sim-to-real 迁移、OOD 类别泛化等涌现行为，为"视频生成是通往物理世界通用视觉智能的基础路径"提供了有力证据。

2. 研究背景与动机

2.1 NLP 范式演进对 CV 的启发

NLP 从"为每个语言任务（翻译、摘要等）开发独立模型"的专用时代，演进到由大规模 next-token prediction 预训练 + 任务对齐 post-training 支撑的单一统一基础模型范式。这一范式将成千上万的语言任务"坍缩"为单一通用智能，并解锁了 chain-of-thought、in-context learning 等涌现行为。

与此形成鲜明对比，CV 仍停留在专用模型阶段。即便已有 SAM 系列、Depth Anything 系列等基础模型，它们仍是任务特定的，缺乏统一的任务无关（task-agnostic）架构。作者因此将"寻找通用视觉模型"本质上归结为"寻找通用预训练目标——next-token prediction 的视觉对应物"，并主张该预训练范式须满足三大核心要求：

1) 时空演化（Spatio-Temporal Evolution）：世界是 4D 连续体，预训练目标应迫使模型内化 4D 时间因果性与运动世界的物理规律。

2) 视觉-语言对齐（Vision-Language Alignment）：为继承语言模型的指令遵循能力与常识知识，视觉特征应在预训练与 post-training 阶段原生地与语言语义对齐。

3) 可扩展性（Scaled up）：范式应在数据与算力上都能扩展，最终使视觉智能得以涌现。

作者论证：大规模文生视频生成恰好唯一地满足全部三条要求。其一，生成高保真视频序列的目标迫使模型内化时空世界先验（3D 几何、物体恒存性、物理交互）；其二，这些模型原生以文本为条件，提供天然的视觉-语言对齐；其三，现代文生视频模型因标注成本低、商业价值高，已用海量数据与算力扩展，提供了通向涌现智能的直接路径。

3. 核心方法：GenCeption

3.1 方法总览

GenCeption 的方法论基于三条基本原则：(1) 多模态生成式预训练即表征学习——用预训练 text-to-video 扩散模型作 universal backbone，且为保留基础表征，核心设计原则是"最大化遵循原始预训练体制、最小化修改"；(2) 统一架构下的任务无关 post-training——把多样视觉任务当作统一的 sequence-to-sequence 映射，新任务只需改数据表示、无需改架构；(3) 前馈重构——把多步生成 backbone 变为单步前馈感知模型。

3.2 GenCeption 架构：从扩散 backbone 到前馈感知

模型基于 text-to-video 扩散模型，核心组件包括 VAE encoder-decoder 对、text encoder、transformer-based latent diffusion model (DiT)。原始 DiT 以高斯噪声初始化的 latent token + 文本 prompt 为输入，执行多步 denoising，逐步将其转为可解码为视频的 latent token；denoising 步索引 $t$ 作为额外输入来根据输入噪声量调制预测。DiT 可被训练来预测噪声 $\epsilon$ [24, 60]、velocity $v = \epsilon - x_0$（Rectified Flow [16, 44, 45]）或直接预测 target $x_0$ [39]。

前馈感知重构（Feedforward Perception Formulation）是本文的关键设计。作者不再以噪声视频 latent 为输入，而是直接把输入视频的 clean latent 喂给 DiT，仅做单次前向。为标记输入无噪声，将条件 timestep 固定为 $t = 0$（对应生成 Rectified Flow 过程的终点）。由于 DiT 在 Rectified Flow 目标下预测 velocity $v = \epsilon - x_0$，作者在传给 loss/decoder 之前对 DiT 原始输出取负：取负后的 $-v = x_0 - \epsilon$ 与目标视频的 latent 更紧密对齐，经验上加速收敛并提升性能。

直观上，这把 DiT 重塑为一个强大的特征提取器。关键设计要点：使用 Rectified Flow 而非传统噪声预测、条件于 $t=0$、对 velocity 输出取负，以从预训练 backbone 中提取最有信息量的特征；并且直接从最后一层而非中间层采集特征，使其天然与后续 decoder 对齐，无需对 base model 做任何架构修改。

设视频 token 在步骤 $t$ 输入 DiT 记为 $x_t$，$x_0$ 为原始视频的无噪声 latent。前馈感知的核心公式：

$$ v = \epsilon - x_0 \quad (\text{Rectified Flow velocity 目标}) $$

$$ \hat{x}_0 = -v + x_0^{\text{in}} \;\Rightarrow\; \text{取负: } -v = x_0 - \epsilon \quad (\text{与目标 latent 对齐更紧密}) $$

其中输入侧直接用 clean latent $x_0^{\text{in}}$ 并固定 $t=0$，仅前向一次得到 $-v$ 作为感知输出 latent。

3.3 条件化与指令控制：统一任务表示

密集任务统一到 RGB 空间

与以往为不同任务采用独立 backbone/decoder/loss 的做法不同，GenCeption 让所有任务共享同一架构与权重，目标任务仅通过文本 prompt调制。所有密集感知任务的输出表示为 $[0,1]$ 范围的 3 通道 RGB 空间：单维输出（depth、segmentation）将三通道复制；三维任务（surface normal、DensePose）则三通道表示不同维度。该表示还可扩展到更高维模态——例如 camera pose 传统表示为矩阵，作者采用 pixel-space 的 raymap [28, 83, 85] 来与视频生成格式原生对齐（见 Figure 5，作者称之为 "Rothko" Raymap）。为将其 6 通道格式塞入 3 通道约束，作者对帧做空间分区——中央区域放 ray origins，外围放 ray directions，从而保持单一 decoder 框架并充分利用预训练视觉先验。

作者将这一设计哲学类比为 LLM 把非文本数据重格式化为文本字符串：把视觉任务直接投射到连续像素空间——即预训练视觉先验被最佳利用的原生域。

稀疏任务用可学习 token

下游任务（如机器人控制）常需可直接操控的结构化输出（2D/3D 坐标）。为此引入轻量 token 扩展：在视频 latent 后追加 $T$ 个可学习 token（每个视频帧一个），经模型后由 MLP 解码每个 token 预测 $K$ 维目标。为遵循 base DiT，对这些额外 token 应用其原生 3D RoPE：由于这些 token 的空间位置未知，故设为可学习；时序定位上，因视频帧数 $T$ 被压成 latent 长度 $T'$，用 position interpolation [13] 下采样帧索引以落在预训练见过的时序范围内。经验上，这种"额外查询"方式优于新增额外 attention 层的方式。

3.4 训练目标与公式

联合多任务学习常因不同任务需要专门 loss 而带来手动平衡权重的工程开销。GenCeption 采用完全统一的 loss 设计：仅用标准 $L_2$ loss，镜像 LLM 用单一目标统一多样语言任务的做法。该单一 loss 直接在 latent space 应用于密集任务，在输出 space 应用于稀疏任务。

关键在于把任务特定定制从 loss 公式转移到数据表示设计。以单目深度估计为例（其尺度模糊性通常需要定制的尺度不变 loss），作者在数据层面直接解决：用场景的中值深度对每个视频深度图做归一化，从而天然消除尺度模糊。进一步把归一化深度 $d$ 对齐到 $[0,1]$ RGB 范围，采用非线性映射：

$$ d' = \mathrm{clip}\left(\alpha \log(d + 1),\; 0,\; 1\right) $$

其中 $\alpha$ 可动态调节模型在近场细节与远场结构之间的关注重心。该数据级定制有效消除了任何任务特定目标函数的需求——任务间平衡仅需通过数据混合比例管理，类比 LLM 的通行做法。

统一训练目标可写为：

$$ \mathcal{L} = \begin{cases} \| \hat{z} - z^{*} \|_2^2 & \text{密集任务 (latent space)} \\ \| \hat{y} - y^{*} \|_2^2 & \text{稀疏任务 (output space)} \end{cases} $$

其中 $\hat{z}$ 为 DiT 取负输出后的 latent 预测，$z^{*}$ 为目标视频 latent；$\hat{y}$ 为 MLP 解码的 keypoint，$y^{*}$ 为对应 ground truth。

3.5 推理算法伪代码

Algorithm 1: GenCeption 前馈感知推理

Input: 输入视频 V ∈ ℝT×3×H×W; 文本指令 prompt（指定目标模态）; 预训练 DiT G, VAE E/D, text encoder TE

Output: 目标模态预测（depth / normal / seg / raymap / 2D-3D keypoints）

// 1. 编码输入到 clean latent

z_in = E(V) // 无噪声 clean latent, 不加噪

c = TE(prompt) // 文本 embedding, 可切换任意模态

// 2. 若为稀疏任务, 追加 T 个可学习 token 到 z_in

if sparse task: z_in = concat(z_in, learnable_tokens)

// 3. 单次前馈: t 固定为 0, 直接取负 velocity

v = G(z_in, c, t=0) // 单次 forward, 非迭代 denoise

z_out = -v // 取负: -v = x0 - epsilon, 与目标 latent 对齐

// 4. 解码到目标模态

if dense task:

return D(z_out) // RGB 视频输出 (3 通道, [0,1])

else // sparse task

y = MLP(z_out[learnable_tokens]) // 每帧 K 维 keypoint

return y

推理效率：前馈模型消除了标准 WAN 的慢速 50 步扩散。在单张 v6e TPU 上（81 帧、480×832）：1.3B 模型耗时 5.92s（13.6 FPS，DiT 0.96s），显存 15.3GB；14B 模型耗时 10.03s（8.0 FPS，DiT 5.11s），显存 42.8GB。两者共享 10GB text encoder 与 0.25GB VAE，可 offload 到系统内存以速度换显存。

3.6 可扩展合成数据生成

训练需高质量、多样的视频数据及 ground truth（depth、normal、分割 mask、dense pose、2D/3D keypoint、camera pose）。真实数据集通常只含部分模态且规模有限，作者采用合成数据应对稀缺问题。具体设计了一套human-centric 合成数据生成流程：用 800 个 RenderPeople [54] 资产，配以 CMU 动捕数据集 [11] 的 200 个动作动画；使用多种 3D 全场景或 HDRI 背景（类似 [5]）增强背景多样性，并变化焦距、相机位置与轨迹。共生成 7,500 个视频。各视频裁到视频模型目标帧数。dense 任务的视频 normal、depth、分割 mask 用 Blender [7] 分 render pass 生成；从 rigged RenderPeople 资产恢复人体关节位置作 2D/3D keypoint 回归 GT。离线预处理阶段预计算并缓存输入 RGB 视频与目标模态视频到 video latent，文本 prompt 到 text embedding。

为增强训练数据多样性，作者用公开合成数据集补充：TartanAir [67]、Virtual KITTI [19]、MVS Synth [27] 提供额外 depth 标注，并利用 TartanAir 的相机轨迹数据。expression-referring 分割任务因真实数据立即可用，整合 MeViS [15]、Ref-COCO [80]、YouTube-VOS [72]。

实现细节：基于开源开权的 text-to-video 扩散模型 WAN 2.1 [63]，遵循其原始架构，在 480×832 分辨率、81 帧 / 24 FPS 训练。encoder 下采样时间因子 4、空间因子 8（宽高均）。batch size 64，256 张 v6e TPU；Adam 优化器 [35]，学习率 5e-5，训练 15000 步，前 250 步线性 warmup；为稳定训练采用 gradient clipping（梯度范数约束于某阈值内）与 gradient dropping（丢弃梯度范数超更高阈值的 batch）。

4.5 消融实验

联合训练 vs. 任务特定训练

从 specialist 转向统一 generalist 在不同任务/基准上行为不一：密集预测中，surface normal 在不同基准趋势分化；depth 与 camera pose 通常略有回退或持平（如 KITTI 上持平）；foreground segmentation 一致受益于联合训练；expression-referring 分割基本不变。最显著的是：联合训练严重损害 3D human keypoint 估计并波及其他密集任务。作者归因于两个架构因素：(1) 显式 token-based 坐标回归偏离了生成视频模型的连续像素空间预训练；(2) 从零训练的额外可学习 token 干扰了预训练 DiT 层的原生注意力机制，损害其已优化特征，需要更多数据收敛。这一现象给出重要 post-training 洞见：应尽量减少对预训练 backbone 的架构修改，或从根本上重新设计预训练范式以原生容纳高度多样的下游任务。

预训练重要性

对比视频生成预训练与其他表征学习：用 V-JEPA [4] 与 VideoMAE V2 [61] 的最大可用变体，在同一训练集 finetune。结果显示扩散预训练（WAN 2.1）显著优于其他。这提供了经验证据：生成式扩散目标本身——而非仅数据集或模型规模——是提取更优时空先验的关键。此外，VideoMAE 与 V-JEPA 缺乏对统一多任务模型的原生支持，常需任务特定训练，而本文模型可原生用文本 prompt 在任务间切换。Figure 9 显示从随机初始化训练 DiT 学习曲线几乎平坦，性能随使用更多预训练层而提升，确认预训练对下游收敛与性能至关重要。

初步 scaling 与数据效率

生成 backbone 在不同模型尺寸与数据集上展现 promising 的初步 scaling 性质：性能随模型尺寸与数据量增加而提升。同时展现卓越数据效率——用比 D4RT、VGGT-Ω 少 7×–500× 的训练数据达到可比性能。

4.6 涌现行为

  • 合成训练数据泛化：仅用合成视频训练，却对真实视频泛化良好——在所有基准上建立新 SOTA。定性上，模型输出的细粒度细节甚至超越用 Blender 常规图形学生成的训练数据质量（如 Figure 10b 猫的胡须、Figure 3 第二行头发的软分割）。
  • 多实例泛化：合成训练时每视频仅含单物体，却能零样本泛化到含多物体的真实视频（Figure 10a）。
  • OOD 类别泛化：仅用人体合成视频训练，却对真实视频中的人及其他类别（如动物、拟人化角色）泛化良好（Figure 10b）。

5. 总结与启发

5.1 局限性

  • 联合训练与稀疏任务的结构性冲突：联合训练严重损害 3D keypoint 估计并波及密集任务，根因是显式 token 坐标回归偏离生成模型的连续像素空间预训练，且从零训练的可学习 token 干扰预训练 DiT 的原生注意力。这提示当前范式对高度异质的稀疏任务仍不完美。
  • 合成数据的领域偏向：训练数据以 human-centric 合成视频为主（800 RenderPeople 资产 + 200 CMU 动作），对非人中心的场景/类别虽展现涌现泛化，但尚未系统量化其边界。
  • Scaling 仍属"初步"：作者谨慎地将 scaling 性质描述为 "preliminary"，最大模型为 14B，相对 LLM 动辄千亿规模仍有量级差距；视频级密集数据训练成本高仍是瓶颈。
  • 高维模态的 3 通道适配是工程妥协：raymap 的 "Rothko" 空间分区（中央放 origins、外围放 directions）虽巧妙，但属于为贴合单一 decoder 而做的表示妥协，可能不是最优。

5.2 核心洞见与读后评注

洞见 1：生成式预训练 → 感知，是一次范式级迁移。 本文把 NLP 的"生成式预训练（next-token prediction）→ 通用基础模型"剧本，在 CV 中以"文生视频生成 → 通用感知"复刻。其论证的三大要求（时空演化、视-语对齐、可扩展）切中 CV 长期"专用模型"困局的要害，且与 Kaiming He 近期"let denoising generative models denoise [39]"的思想一脉相承——生成目标本身就是强大的表征学习目标。

洞见 2：扩散 backbone 的"前馈化"是关键工程创新。 不用慢速 50 步迭代采样，而是固定 $t=0$、输入 clean latent、对 Rectified Flow velocity 取负 $-v = x_0 - \epsilon$，单次前向出感知结果。这把 DiT 重塑为特征提取器，且从最后一层取特征以原生对齐 decoder、零架构改动——是对"最小化修改预训练体制"原则的忠实落地，也解释了其推理效率（1.3B 仅 5.92s）。

洞见 3：任务定制从 loss 转移到数据表示，是 scaling 的钥匙。 全用 $L_2$、任务间平衡仅靠数据混合比例——这镜像了 LLM 用单一目标统一多样任务的做法。depth 的尺度模糊性不在 loss 层面解决，而在数据层面用中值归一化 + 非线性映射 $d' = \mathrm{clip}(\alpha \log(d+1),0,1)$ 消除。这种"数据为中心的协调（data-centric harmonization）"是把任务空间无限扩张而架构不变的根本机制。

洞见 4：数据效率与涌现行为是范式正确性的最强证据。 用 7.5K 合成视频（比 D4RT 少约 4 个数量级、比 VGGT-Ω 少约 5 个数量级）达到可比性能，且 sim-to-real、OOD 类别泛化、多实例零样本——这些不是简单的过拟合后微调，而是大规模文生视频预训练已内化"世界模型"的征兆。作者在结论中明确将其解读为"生成式视频 backbone 内存在通用 world model"的证据。

洞见 5：联合训练的失败点指明下一步。 稀疏 token 回归破坏预训练 DiT 注意力这一发现，提示未来的方向：要么坚持"最小架构修改"，要么"从根本上重新设计预训练范式以原生容纳异质下游任务"——后者可能意味着预训练阶段就需引入稀疏/结构化输出目标，而非仅在 post-training 阶段补丁式追加 token。这为后续"原生多模态/多任务视频预训练"留下了清晰的研究议程。
