1. 核心问题与动机

1.1 Agent 记忆 vs 相关概念的核心区分

graph TD

关键区别：Agent 记忆的核心是维持一个持久的、自进化的认知状态——而 LLM 记忆、RAG、上下文工程分别从架构容量、静态知识访问、资源管理角度出发，都不能满足"跨任务持久、自适应进化"的要求。

2.1 Token 级记忆：三维拓扑分类

维度类型代表方法能力边界
1D 平面记忆Chunk 集合 / 对话日志 / 经验池Mem0, MemGPT, ExpeL简单可扩展，缺乏关系理解，规模大时噪声积累
2D 平面结构记忆树结构 / 图结构 / 混合结构MemTree, A-Mem, HippoRAG支持关系推理，单层结构在复杂任务下冗余
3D 层次记忆金字塔 / 多层图G-Memory, HiAgent, SGMem按需粗细粒度访问，适合多跳推理，构建成本高

2.2 参数记忆：三种形式

类型代表方法机制特点
内部参数记忆DSI, DSI++模型直接输出文档 ID，记忆化文档-查询映射无外部存储，快速但难更新
外部参数记忆Generative Adapter为历史上下文块动态生成适配器 $\Delta_t$可增量更新，按需加载
YOROYORO将数据库 Schema 内化为参数减少 66%-98% 输入 token

2.3 潜在记忆

操作代表方法特点
生成（Generate）MemoryLLM, M+, MemGen生成新的潜在 KV 向量作为记忆存储
复用（Reuse）KV Cache 相关方法直接复用已计算的 KV 状态，零重算成本
变换（Transform）多模态记忆方法跨模态对齐后存储为统一潜在表示

    participant ENV as 环境/任务
    participant FORM as 记忆形成
    participant EVOL as 记忆进化
    participant RET as 记忆检索
    participant AGENT as Agent 决策

    ENV->>FORM: 原始交互数据
    FORM->>FORM: 语义摘要 / 知识蒸馏 / 结构构建 / 参数内化

    EVOL->>EVOL: 合并 / 更新 / 遗忘
    EVOL->>RET: 维护中的记忆库

    RET->>AGENT: 相关记忆内容
    AGENT->>ENV: 执行动作
    ENV->>FORM: 反馈驱动新一轮形成

5. 核心洞见与读后评注

三维分类（形式/功能/动态）的互补价值
这篇综述和"重思记忆机制"综述提出了两种不同但互补的分类框架：前者从"形式-功能-动态"三个维度分析（回答什么/为什么/怎么运作），后者从"基底-认知机制-主体"三维分类（存在哪里/发挥什么认知功能/为谁服务）。两个框架结合使用，能更全面地设计一个记忆系统。
RL 驱动的记忆形成：范式转变
从"让 LLM 自己摘要"到"用 RL 优化摘要策略"，Mem1 和 MemAgent 展示了记忆管理本身可以被强化学习优化。这不只是工程改进——它意味着记忆系统可以自进化：随着更多交互，模型学会在哪些信息上保留更多细节，哪些信息可以压缩丢弃。
技能记忆：最有价值的经验层次
案例记忆（高保真但不可执行）→ 策略记忆（可泛化但不可执行）→ 技能记忆（可执行+可验证）。技能记忆是三层中实用价值最高的：它既能跨任务迁移（像策略记忆），又可以直接运行而无需语言模型参与（不像案例记忆需要再次理解）。Voyager 的成功证明，持续积累可执行技能库是 Agent 自进化的最有效路径之一。
