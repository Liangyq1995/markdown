第1章 强化学习基础

来源：蘑菇书 EasyRL  |  原文：datawhalechina.github.io/easy-rl

概述

强化学习是机器学习的一个重要分支，研究智能体如何在不确定的环境中通过试错与反馈来学习最优决策策略。与监督学习不同，强化学习没有即时的正确标签，智能体需要在与环境的持续交互中最大化累积奖励。本章系统介绍强化学习的基本概念体系，包括智能体-环境交互框架、序列决策、核心组成成分，以及探索与利用这一核心矛盾。

1. 强化学习概述

强化学习研究智能体如何在不确定环境中通过与环境交互来学习最优策略。智能体观察环境状态，输出动作，环境返回下一状态与奖励信号。这一过程不断循环，智能体的目标是最大化长期累积奖励。

与监督学习的核心区别

强化学习与监督学习在本质上有三大不同：

  • 数据时序相关：输入是时序相关数据，非独立同分布，不满足监督学习的基本假设
  • 无即时标签：无法立即获得正确的动作标签，需要通过试错来探索
  • 延迟奖励：当前动作的奖励可能在未来很久才能体现，难以进行即时的信用分配

强化学习的历史与应用

强化学习起源于心理学的行为主义理论，后与动态规划、神经网络等技术融合，在游戏AI（Atari、围棋、星际争霸）、机器人控制、自动驾驶、推荐系统等领域取得突破。深度强化学习（DRL）将深度神经网络用于函数近似，是当前的主流方向。

2. 序列决策

序列决策是强化学习的核心问题——智能体在时间序列中做出一系列动作，每个动作都影响后续状态和奖励。理解历史、状态与可观测性之间的关系，是建立数学模型的基础。

历史与状态

智能体的历史是所有观测、动作、奖励的序列：

$$H_t = o_1, a_1, r_1, \ldots, o_t, a_t, r_t$$

状态是历史的函数，用于决策：$S_t = f(H_t)$。关键区分：

  • 环境状态 $s_t^e$：环境内部维护，智能体通常无法完全访问
  • 智能体状态 $s_t^a$：智能体基于历史信息构建的内部表示

完全可观测与部分可观测

类型条件模型示例
完全可观测$o_t = s_t^e = s_t^a$MDP（马尔可夫决策过程）棋盘游戏
部分可观测$o_t \neq s_t^e$POMDP（部分可观测MDP）扑克牌、机器人感知

POMDP是七元组 $(S, A, T, R, \Omega, O, \gamma)$，智能体需通过历史信息推断环境状态。

3. 动作空间

动作空间的类型决定了算法的选择，是强化学习问题的重要属性。

类型描述示例典型算法
离散动作空间有限个动作，可枚举围棋落子、雅达利游戏按键DQN、Q-Learning
连续动作空间实值向量，不可枚举机器人关节角度、驾驶转向角DDPG、PPO、SAC

4. 强化学习智能体的组成成分

一个完整的强化学习智能体可能包含三个核心组成部分：策略、价值函数和模型。并非所有智能体都拥有全部三个组成部分，这也构成了不同智能体类型的划分基础。

策略（Policy）

策略定义了智能体的行为方式，是从状态到动作的映射：

  • 随机性策略：$\pi(a|s) = p(a_t=a \mid s_t=s)$，输出动作的概率分布
  • 确定性策略：$a^* = \arg\max_a \pi(a \mid s)$，输出确定的最优动作

价值函数（Value Function）

价值函数量化了状态或状态-动作对的长期收益期望，是评估策略好坏的核心工具：

$$V_\pi(s) \doteq \mathbb{E}_\pi\left[\sum_{k=0}^{\infty} \gamma^k r_{t+k+1} \mid s_t=s\right]$$

Q函数（动作价值函数）进一步考虑了动作的选择：

$$Q_\pi(s,a) \doteq \mathbb{E}_\pi\left[\sum_{k=0}^{\infty} \gamma^k r_{t+k+1} \mid s_t=s, a_t=a\right]$$

折扣因子 $\gamma \in [0,1]$ 控制对未来奖励的重视程度：$\gamma=0$ 只看即时奖励，$\gamma \to 1$ 等权考虑长远未来。

模型（Model）

模型描述环境的动态特性，包含两个部分：

  • 状态转移模型：$p_{ss'}^a = p(s_{t+1}=s' \mid s_t=s, a_t=a)$
  • 奖励模型：$R(s,a) = \mathbb{E}[r_{t+1} \mid s_t=s, a_t=a]$

智能体类型

类型特征代表算法
基于价值（Value-Based）显式学习价值函数，隐式策略（贪心）Q-Learning、DQN
基于策略（Policy-Based）直接参数化并优化策略REINFORCE
演员-评论员（Actor-Critic）同时学习策略与价值函数A2C、PPO、SAC
有模型（Model-Based）学习环境转移模型，用于规划Dyna-Q、AlphaZero
免模型（Model-Free）直接与真实环境交互，无需建模大多数深度RL算法

5. 学习与规划

强化学习中两种根本不同的改进策略的方式：

graph LR
    subgraph 学习 Learning
      A1["环境未知"] --> B1["与真实环境交互"]
      B1 --> C1["收集数据"]
      C1 --> D1["更新策略"]
    end
    subgraph 规划 Planning
      A2["环境已知/学到模型"] --> B2["模型内部模拟"]
      B2 --> C2["推演最优解"]
      C2 --> D2["更新策略"]
    end
  • 学习：环境动态未知，智能体通过与真实环境交互逐步改进策略，Atari游戏即典型学习场景
  • 规划：已知或学到环境模型后，利用模型内部推演优化策略，如AlphaGo的蒙特卡洛树搜索

两者可以结合，先学习模型再利用模型规划，这正是有模型强化学习的思路。

6. 探索与利用

探索（Exploration）与利用（Exploitation）是强化学习中最核心的矛盾之一。利用是指选择当前已知的最优动作，探索是指尝试新动作以发现可能更优的选择。

"探索和利用是强化学习里面非常核心的问题。"

K-臂赌博机模型

K-臂赌博机（K-armed bandit）是研究探索-利用权衡的经典模型：K个摇臂各有未知奖励概率，智能体每次选择一个臂并获得奖励，目标是最大化累积奖励。

策略描述缺陷
仅探索均匀尝试所有臂不充分利用已有知识
仅利用始终选当前最优臂可能错过全局最优
ε-贪心以ε概率探索，1-ε概率利用探索随机，效率低
UCB基于置信上界选择计算依赖模型假设

7. 强化学习实验：OpenAI Gym

Gym是OpenAI开发的标准强化学习实验环境库，提供统一的接口规范，使研究者可以方便地测试和对比算法。

基本接口

import gym
env = gym.make("CartPole-v0")
observation = env.reset()

for _ in range(1000):
    env.render()
    action = env.action_space.sample()  # 随机采样动作
    observation, reward, done, info = env.step(action)
    if done:
        observation = env.reset()

env.close()

MountainCar-v0 示例

MountainCar 是经典连续控制问题：小车需通过左右摆动积累动能爬上山顶。

  • 观测空间：Box([-1.2, -0.07], [0.6, 0.07])，即位置和速度
  • 动作空间：Discrete(3)，向左/不动/向右
  • 成功标准：连续100回合平均奖励 > -110，SimpleAgent 实测约 -106.63

总结与启发

强化学习提供了一套完整的序列决策数学框架。从智能体-环境交互的基本循环，到策略、价值函数、模型三大组件的组合，再到MDP/POMDP的形式化描述，这些基础概念构成了后续所有复杂算法的理论基石。

探索与利用的矛盾贯穿强化学习始终——如何在已知信息和新探索之间取得平衡，是区分不同算法设计哲学的核心维度。理解这一矛盾，是深入学习后续章节的关键前提。
