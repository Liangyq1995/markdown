第14章 鲁棒 AI

《Machine Learning Systems at Scale》Vijay Janapa Reddi · MIT Press · Vol.2 Part IV · 生成日期：2026-07-04

核心主线静默失败 → 三类威胁（环境/对抗/系统故障）→ PSI/KS 漂移监控 → 对抗 $\epsilon$ 与防御 → 鲁棒性作为架构预算
学习目标将鲁棒性从「事后监控」提升为 Fleet Stack 治理层约束；能用 PSI/KS 触发重训决策，并量化对抗扰动与资源开销

一、静默失败：传统软件 vs ML 系统

传统软件大声失败：异常崩溃、类型错误、断言中断——烦人但可发现。ML 系统静默失败：面对分布外（OOD）输入仍输出高置信预测；遭遇对抗样本时与正常请求无异；分布漂移时延迟与 uptime 稳定而准确率悄然下滑。业务指标暴露问题时，损害可能已累积数周。

定义：鲁棒 AI（Robust AI）

在分布漂移、对抗扰动、软硬件故障下，预测仍落在指定误差界内——区别于 i.i.d. 条件下的平均准确率。

  • 与泛化区别：95% i.i.d. 测试准确率 ≠ 鲁棒；$\ell_\infty$ 半径 $\epsilon=8/255$ 的不可见扰动可使非鲁棒模型在 PGD 攻击下准确率趋近 0
  • 与 Security 关系：Security 定义谁能访问模型；Robustness 问输入/分布/硬件偏离训练假设时，集群是否仍有界、可恢复
  • 常见陷阱：鲁棒性主要在训练期决定，推理期置信度阈值无法替代对抗训练/certification

临床 NLP 模型 2019 年数据训练、2021 年部署不重训，准确率可降 15–25%——编码实践与术语演变属于概念漂移，不会触发进程崩溃。

War Story：Google Photos（2015）

Brooklyn 用户 Jacky Alciné 发现系统将黑人照片误标为「Gorillas」。临时缓解是删除 gorilla/chimp/monkey 标签而非修复分类器——说明 slice-level 评估与有害标签 fallback 必须在上线前完成；「临时」缓解可存续数年。

War Story：Meta 静默数据损坏（SDC）

Meta 报告约 6–8 台/百万机器/日发生 SDC，比软错误预测高数个数量级。分布式训练中 corrupted gradient 可污染 optimizer state，影响后续步——比单条 SQL 丢行 blast radius 大得多，常需回滚 checkpoint 重启训练。

二、对抗扰动：$\epsilon$ 与决策边界

认证鲁棒分类器证明：在测试点 $x$ 周围 $\ell_\infty$ 球 $B_\epsilon(x)=\{x':\|x'-x\|_\infty\le\epsilon\}$ 内预测不变。ImageNet 上 $\epsilon=8/255$（约 3.1/255 每通道，人眼不可见）足以让标准 ResNet 在强 PGD 下失效。

$$\min_{\|\delta\|_\infty \le \epsilon} \; \mathcal{L}(f(x+\delta), y) \quad \Rightarrow \quad \text{PGD: } \delta_{t+1} = \Pi_{B_\epsilon}\big(\delta_t + \alpha \cdot \mathrm{sign}(\nabla_x \mathcal{L})\big)$$
防御机制系统代价
对抗训练训练循环注入 PGD 样本训练时间 +2–4×，干净精度 −2–5 pt
Certification区间传播证明 $\epsilon$-ball 内不变推理 5–50× 慢（取决于网络深度）
输入过滤统计/激活空间异常检测服务路径 +5–15% 算力，误拒 5–15% 合法流量

算例：$\epsilon=8/255$ 的物理含义

像素值 $[0,1]$ 浮点：$\epsilon = 8/255 \approx 0.0314$，单像素最大变化 3.1%。CIFAR-10 上非鲁棒模型 clean acc 92% → PGD-20 $\epsilon=8/255$ 下可跌至 <10%。量化 INT8 部署进一步压缩鲁棒 margin——第 10 章压缩与第 14 章鲁棒性存在直接张力。

175B 模型分片多阶段 serving：单 stage 的 bit flip、分区或对抗 query 可拖垮整条 pipeline——鲁棒 margin（可吸收扰动而不翻转预测的量）与效率优化（INT8、激进剪枝）持续博弈。

三、分布漂移：PSI 与 KS 联动

Vol.1 第 3 章引入 PSI 监控；本章给出完整统计链：PSI 告警 → KS 显著性确认 → 业务指标关联 → 重训/回滚。

3.1 PSI 公式与阈值动作

$$\mathrm{PSI} = \sum_{i=1}^{k} (p_i - q_i) \cdot \ln\frac{p_i}{q_i}$$

$p_i$：基准分布第 $i$ 箱占比；$q_i$：当前分布对应占比。连续特征常用 10 箱、每箱 ≥5% 样本；零计数箱加 $\epsilon_{\mathrm{smooth}}=10^{-8}$ 防 $\ln 0$。

PSI解释动作
< 0.1可忽略继续监控
0.1 – 0.2轻微根因调查
0.2 – 0.25中等考虑重训
≥ 0.25重大48h 内启动重训或 shadow 验证

手算 PSI（4 箱收入分档）

基准 $p=[0.25,0.25,0.25,0.25]$；当前 $q=[0.20,0.22,0.28,0.30]$。

$\mathrm{PSI} \approx 0.044$ → 绿区，继续监控。若 $q=[0.10,0.15,0.35,0.40]$ 则 PSI ≈ 0.21 → 橙区，关联 precision/recall 是否退化后再决定是否重训。

3.2 KS 检验：显著性 vs 幅度

PSI 量化幅度；两样本 Kolmogorov-Smirnov 检验问是否超过抽样噪声：

$$D_{n,m} = \sup_x |F_n(x) - G_m(x)|, \quad D_{n,m} > c(\alpha)\sqrt{\frac{n+m}{nm}} \text{ 则拒绝「无差异」}$$

$\alpha=0.05$ 时 $c(0.05)\approx 1.36$。例：$n=m=1000$，$D=0.08$，临界值 $\approx 1.36\sqrt{2/1000}\approx 0.061$ → 拒绝 H0，确认漂移非随机。KS 对均值/方差移位敏感，对形状不变仅相关结构变的联合漂移弱——高维场景需 MMD 或 per-feature PSI 组合。

3.3 概念漂移 vs 数据漂移

数据漂移：$p(x)$ 变、$p(y|x)$ 不变——新 $x$ 重采样可恢复。概念漂移：$p(y|x)$ 变——同输入正确答案已变，仅监控 $p(x)$ 的 PSI 无信号，必须依赖 ground-truth 反馈环。补救成本 ≈ 原训练 O/(Rpeak·η) 的再标注预算。

四、三柱诊断与防御纵深

准确率下降但延迟正常——三柱（系统可靠性 / 输入攻击 / 环境漂移）表面症状相同。关键判别：golden input replay。保存输入重放 pipeline，若输出与历史不一致 → 系统/数值故障；若一致但统计分布已移 → 漂移；若输入经微小扰动即翻转 → 对抗。

鲁棒性资源预算（书中量级）

  • 内存带宽开销：+12–25%（冗余/ensemble）
  • 冗余计算能耗：2–3×
  • 持续监控算力：+5–15%

10 W 热预算工业无人机无法承担 datacenter 级全栈冗余——须选择性加固关键推理路径，其余 graceful degradation（ simpler model / reduced-feature mode）。

五、章节总结

核心要点

  1. 鲁棒 AI 位于 Fleet Stack 治理层：让静默失败可见、可测、可响应
  2. 三类威胁需不同响应；软件 Bug 可放大或伪装为漂移/对抗
  3. PSI ≥0.25 → 重训；0.1–0.25 → 调查；与 KS/MMD 组合避免误报/漏报
  4. $\epsilon=8/255$ 是 ImageNet 鲁棒性基准；certification 与效率存在硬 trade-off
  5. 概念漂移需 ground-truth 环，非 feature PSI alone
  6. 鲁棒性从设计期预算：监控、冗余、对抗训练均为 C³ 中的 coordination 成本
鲁棒性的守恒定律：可靠性不会从监控层「长出来」——它要么在训练期写入决策边界，要么用持续 verification 的算力税购买。
