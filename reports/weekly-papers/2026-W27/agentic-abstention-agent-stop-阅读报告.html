Agentic Abstention：Agent 知道何时停止行动吗？

LLM Agent安全性决策CONVOLVE

arXiv: 2606.28733 · 2026 · University of Washington · HuggingFace本周 #3 (137 upvotes)

标题Agentic Abstention: Do Agents Know When to Stop Instead of Act?
核心问题在顺序决策场景下，LLM Agent 如何判断何时应该主动放弃行动（abstain）而非继续干预
代码/数据lhannnn.github.io/agentic-abstention

1. 核心问题与动机

大多数 LLM Agent 研究关注的是"如何做得更好"——更准确的规划、更精准的工具调用。然而一个被忽视的关键能力是：知道什么时候不该做。

Agentic Abstention 研究的是 Agent 在多轮交互中识别"应当停止行动"的能力。与单次问答中的拒绝（refusal）不同，Agentic Abstention 是一个序列决策问题：Agent 在每一步都面临"继续行动 / 放弃 / 收集更多信息"的三叉选择。

核心矛盾：过于激进的 Agent 会在不确定的情况下继续行动导致错误；过于保守的 Agent 会过早放弃导致任务失败。"及时性"（timeliness）是区分好坏 abstention 的关键维度。

评测指标：及时召回率（Timely Recall Rate）

本文提出了核心评测指标 Timely Recall Rate（TRR）：不只看 Agent 最终是否放弃，更看放弃是否"及时"——即在积累足够证据后立即放弃，而非迟迟不决或过早放弃：

$$\text{TRR} = \frac{\text{正确且及时的 Abstention 次数}}{\text{应当 Abstain 的总任务数}}$$

4. CONVOLVE：上下文工程解决方案

作者提出 CONVOLVE（CONtext engineering for VOLatile ENvironments），一种无需修改模型参数的上下文工程方法：

提炼停止规则"]
    B --> C["Stopping Rules
停止规则库"]

    style C fill:#2a2a3e,stroke:#89b4fa

CONVOLVE 的核心思想：从大量历史轨迹中提炼出可复用的"停止规则"（Stopping Rules），并将其注入新任务的上下文中。这样 Agent 在新任务中可以参照先验经验判断何时停止，无需从零探索。

5. 实验结果

评测规模

  • 评估了 13个 LLM-as-Agent 系统 + 2种 Agent Scaffold
  • 在 28,000+ 个任务 上评测（WebShop、Terminal、QA 三类环境）
系统环境TRR（基线）TRR（+CONVOLVE）
Llama-3.3-70BWebShop26.757.4
GPT-4oWebShop41.263.8
Llama-3.3-70BTerminal31.552.1

反直觉发现

更强大的模型在 Agentic Abstention 上并非一定更好——某些更大模型由于更自信，反而更晚放弃，导致 TRR 更低。

6. 关键发现

  • 没有模型能自发地及时 Abstain：13个被测系统均存在显著的延迟放弃问题
  • 参数规模与 Abstention 能力不相关：70B模型的 TRR 不优于13B模型
  • Scaffold 的重要性：ReAct scaffold 比 vanilla 模式的 abstention 质量更好
  • CONVOLVE 无参数更新：纯上下文工程方法即可将 TRR 翻倍

7. 局限性

  • 评测的三类环境（WebShop、Terminal、QA）可能不覆盖所有 Agent 场景
  • CONVOLVE 需要预先积累历史轨迹数据，冷启动困难
  • "何时应当 Abstain"的真值标注本身存在主观性

8. 核心洞见与读后评注

关键洞见：Agent 安全性不只是"拒绝有害请求"，还包括在不确定情况下的"主动自我约束"。Agentic Abstention 提供了一个新的 Agent 评测维度，而 CONVOLVE 则证明了上下文工程在解决顺序决策中的强大潜力。

这篇论文的贡献有两个层次：第一，它定义了一个被忽视但重要的问题——"及时性"这一时序维度的缺失导致现有 Agent 评测不完整；第二，CONVOLVE 的"轨迹蒸馏为规则"思路极具实用价值，且无需任何参数更新，工程落地门槛低。

从 AI 安全角度，能够主动停止的 Agent 比永远执行到底的 Agent 更安全。这一研究为构建"有边界"的 Agent 系统提供了理论基础和实践工具。
