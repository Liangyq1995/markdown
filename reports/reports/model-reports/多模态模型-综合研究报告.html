一、视觉编码器：ViT 与主流变体

视觉编码器负责将像素图像转化为语义特征向量，是 MLLM 的感知基础。当前主流选择均基于 Vision Transformer（ViT），但在参数规模、预训练目标和分辨率处理策略上各有差异。

1.1 ViT 架构原理

ViT 将输入图像 $H \times W$ 切分为 $N$ 个固定大小的 patch（通常 $14 \times 14$ 或 $16 \times 16$ 像素），每个 patch 线性投影为 $D$ 维向量，加上可学习的 2D 位置编码后送入标准 Transformer Encoder。

图像切分：$N = \dfrac{H \times W}{P^2}$，其中 $P$ 为 patch 边长，$N$ 为 token 数

Patch 嵌入：$\mathbf{z}_0 = [\mathbf{x}_{\text{cls}}; \mathbf{x}_p^1 \mathbf{E}; \mathbf{x}_p^2 \mathbf{E}; \cdots; \mathbf{x}_p^N \mathbf{E}] + \mathbf{E}_{\text{pos}}$，$\mathbf{E} \in \mathbb{R}^{(P^2 \cdot C) \times D}$

SigLIP 与 CLIP 的关键差异

CLIP 使用 InfoNCE 损失，每个 batch 内所有负样本共享 softmax 分母，要求极大 batch size（65536）：

$$\mathcal{L}_{\text{CLIP}} = -\frac{1}{N}\sum_i \log \frac{\exp(s_{ii}/\tau)}{\sum_j \exp(s_{ij}/\tau)}$$

SigLIP 改用逐对 Sigmoid 二元交叉熵，正对标签为 +1，负对为 -1，消除 softmax 归一化，对小 batch 更友好：

$$\mathcal{L}_{\text{SigLIP}} = -\frac{1}{N^2}\sum_{i,j} \log \sigma\!\left(y_{ij} \cdot (s_{ij} - b)\right), \quad y_{ij} \in \{+1,-1\}$$

其中 $b$ 为可学习偏置项，$\sigma$ 为 sigmoid 函数，$s_{ij} = \langle v_i, t_j \rangle / \tau$。

二、模态对齐器：Q-Former vs MLP Projector

模态对齐器（Modal Aligner）是连接视觉编码器与 LLM 骨干的核心桥梁，其设计直接决定视觉信息的压缩率、对齐质量和训练效率。当前主流方案分为两大流派：Q-Former（重量级查询压缩）和 MLP Projector（轻量直接映射）。

2.1 Q-Former（BLIP-2 提出）

架构原理

Q-Former 是一个轻量 Transformer，包含 32 个可学习 Query Token（$768$ 维），通过跨注意力机制从冻结的视觉编码器输出中提取信息，再将 32 个压缩后的视觉 token 送入 LLM。

参数量：~188M（独立于视觉编码器和 LLM）

2.2 MLP Projector（LLaVA 路线）

架构原理

LLaVA 采用极简设计：将 ViT 输出的每个视觉 token 直接通过 2 层 MLP（含 GELU 激活） 投影到 LLM 的词嵌入维度，无任何压缩。

$\mathbf{H}_v = \text{MLP}(f_{\text{ViT}}(\mathbf{X}_v))$，其中 MLP：$\mathbb{R}^{D_v} \to \mathbb{R}^{D_{\text{LLM}}}$

$\text{MLP}(x) = W_2 \cdot \text{GELU}(W_1 x + b_1) + b_2$

参数量：CLIP ViT-L/14@336 → LLaMA-13B 时约 7.2M 参数，极轻量

输出 token 数：CLIP ViT-L/14@336 输出 576 个 patch token，LLaVA 直接输入 576 个视觉 token 给 LLM

为什么有效：更大量的视觉 token 保留了更多空间细节；实验表明 2-layer MLP 显著优于 1-layer（LLaVA 1.5 的主要改进之一）

4.2 CogVLM 的 Visual Expert 设计

核心思想：为视觉 token 建立独立的注意力参数

标准 LLaVA 让视觉 token 和文本 token 共用同一套 QKV 权重，但这两种 token 的语义空间差异极大。CogVLM 为每个 Transformer 层的视觉 token 维护 独立的 Q/K/V 投影矩阵和 FFN：

文本 token：$\text{Attn}(\mathbf{x}) = \text{softmax}\!\left(\frac{Q_L(\mathbf{x}) K_L(\mathbf{x})^\top}{\sqrt{d}}\right) V_L(\mathbf{x})$

视觉 token：$\text{Attn}(\mathbf{v}) = \text{softmax}\!\left(\frac{Q_V(\mathbf{v}) K_V(\mathbf{v})^\top}{\sqrt{d}}\right) V_V(\mathbf{v})$

其中 $Q_V, K_V, V_V$ 为视觉专属权重（Visual Expert），与文本权重 $Q_L, K_L, V_L$ 相互独立，无参数共享。

代价：额外引入约 6B 参数（~40% 参数增加）

收益：视觉 token 的深层语义处理更充分，在 NoCaps、TextVQA 等任务上超越 BLIP-2 和 Flamingo

4.3 Qwen2.5-VL 的原生动态分辨率

Naive Dynamic Resolution + 2D-RoPE

Qwen2-VL 不预定义任何网格，而是直接对原始分辨率图像提取 patch，通过 Window Attention 在视觉编码器内压缩 token 数：

  • Window Attention 压缩：将相邻 $2\times2=4$ 个 patch token 合并为 1 个，token 数减少 4 倍，同时保留局部相对位置关系
  • 2D-RoPE：为视觉 token 分配二维旋转位置编码 $(r, c)$（行×列），使模型感知图像的二维空间结构，区别于 LLaVA 的 1D 位置编码
  • 视频支持：扩展为 3D-RoPE $(t, r, c)$，天然支持视频序列的时序建模

2D-RoPE：$\text{PE}(\mathbf{x}, r, c) = \mathbf{x} \cdot R(\theta_r) \cdot R(\theta_c)$，其中 $\theta_r, \theta_c$ 为行列旋转角

效果：同一模型可处理 28×28 缩略图到 7680×3840 超高清图像，无需重新训练

5.2 损失函数设计

Stage 2 的标准语言建模损失

MLLM 在指令微调阶段通常只对 回答部分（Response）计算 CE Loss，问题部分（Question + Context）的 Loss 设为 0，避免让模型记忆提问方式而非学习视觉推理：

$$\mathcal{L} = -\sum_{t \in \text{response tokens}} \log P(y_t \mid \mathbf{X}_v, \mathbf{X}_q, y_{\lt t}; \Theta)$$

其中 $\mathbf{X}_v$ 为视觉输入，$\mathbf{X}_q$ 为问题文本，$\Theta$ 为可训参数，$y_{\lt t}$ 表示 $t$ 时刻之前所有生成 token。

注意：y_{\lt t} 此处用 \lt 表示 $\lt$，避免 HTML 解析歧义。

6.2 VCD：视觉对比解码

Visual Contrastive Decoding（VCD，2024）

核心思想：幻觉主要来自 LLM 语言先验（不看图也能猜出的内容）。VCD 通过对比"正常视觉输入"和"添加高斯噪声的视觉输入"的输出分布，消除语言先验的影响：

$$p_{\text{VCD}}(y \mid \mathbf{X}_v, \mathbf{X}_q) \propto p(y \mid \mathbf{X}_v, \mathbf{X}_q) - \alpha \cdot p(y \mid \mathbf{X}_v^{\text{noisy}}, \mathbf{X}_q)$$

其中 $\mathbf{X}_v^{\text{noisy}} = \mathbf{X}_v + \epsilon$（$\epsilon \sim \mathcal{N}(0, \sigma^2 I)$），$\alpha$ 控制对比强度。

优点：无需额外训练，推理时直接应用

效果：在 CHAIR 基准（幻觉评测）上将幻觉率降低约 10-15%

缺点：每次推理需要两次前向传播，速度降低约 60%

6.3 OPERA：过度信任惩罚

Over-trust Penalty and Retrospective Assistance（OPERA，2024）

问题诊断：OPERA 发现幻觉往往发生在模型注意力集中于少数"汇聚 token"（Attention Sink）时——模型忽略视觉 token，过度依赖文本上下文中的汇聚词。

解决方案：在 Beam Search 解码时引入两个机制：

  • Over-Trust Penalty：检测注意力矩阵中的 Sink 模式，对汇聚程度高的 token 施加对数概率惩罚
  • Retrospective Assistance：当检测到幻觉风险时，回溯到更早的 Beam 分支重新生成
$$\text{penalty}(t) = \lambda \cdot \max_h \left[\sum_s \mathbf{A}_h[s, t]^2\right], \quad \text{if } \text{SinkScore}(t) > \tau$$

效果：在 CHAIR-S 上降低幻觉率 15-20%，且不需要任何额外训练

6.4 RLHF-V：人类反馈强化学习

RLHF-V（2024）— 直接在幻觉行为上施加人类反馈

核心做法：收集模型在视觉问答任务上的幻觉样本，由人工标注修正，再通过 Behavior Cloning（BC）+ DDPO（直接偏好优化的多模态版本）训练奖励模型和策略模型：

1
人工收集 MLLM 在 5K 图片上的幻觉输出，标注正确答案与错误原因
2
构造偏好对 $(y^+, y^-)$，其中 $y^+$ 为无幻觉回答，$y^-$ 为幻觉回答
3
使用 DPO（Direct Preference Optimization）目标微调：
$$\mathcal{L}_{\text{DPO}} = -\mathbb{E}\left[\log \sigma\!\left(\beta \log \frac{\pi_\theta(y^+ \mid x)}{\pi_{\text{ref}}(y^+ \mid x)} - \beta \log \frac{\pi_\theta(y^- \mid x)}{\pi_{\text{ref}}(y^- \mid x)}\right)\right]$$

效果：在 MMHal-Bench 上幻觉分降低 34.8%，且不损失指令跟随能力

6.5 ICD：指令对比解码

Instruction Contrastive Decoding（ICD，2024）

思路：类似 VCD，但对比的是"正常指令"和"干扰指令"。干扰指令通过随机打乱或替换原始问题的关键词构造，能有效放大视觉内容对输出的影响：

$$p_{\text{ICD}}(y \mid \mathbf{X}_v, \mathbf{X}_q) \propto (1+\alpha) \cdot p(y \mid \mathbf{X}_v, \mathbf{X}_q) - \alpha \cdot p(y \mid \mathbf{X}_v, \mathbf{X}_q^{\text{perturb}})$$

其中 $\mathbf{X}_q^{\text{perturb}}$ 为扰动后的问题（如将"这张图片里有几只猫"改为"这张图片里有几个物体"）。

效果：在 CHAIR 基准上比 VCD 再降低 5-8% 幻觉率，同时推理速度优于 VCD（扰动问题比添加图像噪声更高效）

6.6 Woodpecker：后处理幻觉修正

无需重新训练的后处理修正框架

Woodpecker 是一个插件式后处理框架，通过 事实核查 + 外部工具 修正 MLLM 的幻觉输出，无需修改模型本身：

1
关键词提取：从 MLLM 输出中提取可验证的实体和关系（GPT-4 辅助）
2
视觉验证：用目标检测器（GLIP/Grounding DINO）在图像中验证实体是否存在
3
问题生成：针对待验证声明生成是/否问题，送回 VQA 模型二次确认
4
输出修正：将不一致的声明替换为验证通过的事实

效果：在 CHAIR 基准上幻觉率降低约 30%，但由于多次外部调用，延迟高（约 3-5 倍）

七、EMMA：端到端多模态自动驾驶技术细节

来源：Waymo 官方博客、arXiv:2410.23262

7.1 统一语言空间的实现细节

坐标序列化：将驾驶输出转化为文本

EMMA 将驾驶任务的所有输出序列化为自然语言文本。以轨迹规划为例：

输入（文本部分）：
  "导航目标：前方 200m 右转进入高速入口。当前速度：68km/h。"

输出（文本格式的轨迹）：
  "未来 3 秒轨迹：(0.0, 0.0), (5.2, 0.1), (10.8, 0.6),
   (16.9, 2.1), (23.5, 4.8), (30.2, 8.9)"
  "前方目标物体：[car, (15.3m, 1.2m), 65km/h]"

通过这种文本序列化，EMMA 将几何坐标、速度向量、3D 边界框等结构化输出全部纳入语言建模框架，实现真正的统一输入输出空间。

7.2 零样本 VLM 的自动驾驶局限

在 nuScenes 基准的详细评测中，零样本 VLM 存在以下系统性缺陷：

  • 速度感知错误：无法从连续帧中准确估计绝对速度，严重影响追车/让行决策
  • 空间关系推理弱：难以从 2D 图像准确估计 3D 深度和横向距离
  • 长时序规划不稳定：规划超过 3 秒的轨迹时一致性显著下降
  • 自车坐标系理解差：不理解"前方 15m 右侧 2m"等以自车为中心的坐标表达

八、原生多模态范式：Chameleon 与 Emu3

原生多模态（Native Multimodal）模型摒弃独立视觉编码器，将图像和文本统一 Tokenize 到同一离散词表空间，实现真正的模态融合。

8.1 图像离散化：VQ-VAE Tokenizer

核心技术：将图像压缩为离散 Token 序列

原生多模态模型的关键基础设施是 图像 Tokenizer，通常基于 VQ-VAE（Vector Quantized VAE）或改进版本 VQGAN：

1
Encoder：CNN 将图像 $H \times W \times 3$ 下采样为特征图 $\frac{H}{f} \times \frac{W}{f} \times C$（$f$ 为下采样倍数，通常 $f=16$）
2
量化：将每个 $C$ 维特征向量映射到 codebook $\mathcal{Z} = \{z_k\}_{k=1}^K$ 中最近邻的码字，$K$ 通常为 8192 或 16384
3
序列化：按行扫描顺序将 $\frac{H}{16} \times \frac{W}{16}$ 个码字 index 排列为 token 序列（如 256×256 图像 → 256 个图像 token）
$$z_q = \arg\min_{z_k \in \mathcal{Z}} \|f_\phi(x) - z_k\|_2$$

图像 token 与文本 token 共享同一个词表（如 Chameleon 词表大小 = 32K 文本 + 8192 图像 = 40192）

8.2 Chameleon 与模块化 LMM 的架构对比

模块化 LMM（LLaVA 路线）
  • ViT 连续特征（浮点数）
  • MLP/Q-Former 桥接
  • LLM 处理混合连续/离散输入
  • 不能生成图像（仅理解）
  • 视觉/语言参数可分别优化
原生多模态（Chameleon 路线）
  • VQ-VAE 离散 Token（整数 index）
  • 无需独立 Projector
  • 统一离散 Token 自回归建模
  • 可同时理解和生成图像
  • 所有参数联合端到端训练

训练稳定性挑战

Chameleon 的技术报告指出，原生多模态训练面临严重的稳定性问题：图像 token 和文本 token 的梯度量级差异高达 10-100 倍，容易导致梯度爆炸。Meta 团队采用了以下措施：

  • QK-Norm：对注意力的 Q/K 向量做 RMSNorm 归一化，防止注意力分数过大
  • Dropout 修正：图像 token 通道上使用更大的 Dropout 比例
  • 分阶段预热：先在纯文本数据上预热 LLM，再逐渐引入图像 token

九、前沿开放问题

问题现状代表性工作方向
原生多模态能否超越模块化 LMM？ 在大多数基准上仍弱于同规模模块化 LMM，MMMU 等高级推理任务差距明显 提升 VQ-VAE 重建质量；混合连续+离散 token（Show-o）
视觉 token 压缩与精度的帕累托最优？ Q-Former 32 tokens 太少（细节损失），LLaVA 576 tokens 太多（LLM 计算开销大），最优压缩率未知 动态 token 预算（LLaVA-PruMerge）；任务自适应压缩
幻觉能否从根本上消除？ GPT-5 降至 6.2% 但未达 0，推测需要视觉 grounding 的根本改进 细粒度视觉监督；幻觉感知解码算法
自动驾驶 VLM 的零样本能力何时实用化？ 当前零样本性能仅相当于常数速度基线，需要领域微调 驾驶场景专用预训练数据；3D-aware 视觉编码器
