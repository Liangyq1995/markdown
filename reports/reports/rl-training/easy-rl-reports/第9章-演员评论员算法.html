第9章 演员-评论员算法

来源：蘑菇书 EasyRL  |  定位：本章是策略梯度（第4-5章）与DQN（第6-8章）的交汇点，融合两种方法的优势

概述

演员-评论员（Actor-Critic，AC）算法将策略梯度与价值函数估计有机结合：演员（Actor）负责根据策略选择动作，评论员（Critic）负责估计价值函数以指导演员改进。AC方法继承了策略梯度处理连续动作的能力，同时借助TD学习降低方差，是现代主流深度强化学习算法（PPO、SAC、DDPG等）的基础架构。本章重点介绍A2C、A3C及路径衍生策略梯度，并揭示AC算法与GAN的深刻联系。

从策略梯度到Actor-Critic

策略梯度的方差问题与Q、V的关系推导

REINFORCE的策略梯度使用回报 $G_t^n$ 加权，而 $G_t^n$ 的期望正是Q函数：

$$\mathbb{E}_{\pi_\theta}[G_t^n] = Q_{\pi_\theta}(s_t^n, a_t^n)$$

Q与V的精确关系（来自贝尔曼期望方程）：

$$Q_\pi(s,a) = R(s,a) + \gamma\sum_{s'}p(s'|s,a)V_\pi(s')$$

在单步采样近似下，以观测到的 $(r_t, s_{t+1})$ 替代期望，得到单步估计：

$$Q_\pi(s_t,a_t) \approx r_t + \gamma V_\pi(s_{t+1})$$

（注意：严格等号需对 $s_{t+1}$ 求期望；这里的 $\approx$ 是用单次采样近似，引入方差但消去偏差。）

优势函数推导：将上述Q近似代入 $A = Q - V$：

$$A^\theta(s_t, a_t) = \underbrace{Q_{\pi}(s_t, a_t)}_{\approx\, r_t + \gamma V_\pi(s_{t+1})} - V_\pi(s_t) = r_t + \gamma V_\pi(s_{t+1}) - V_\pi(s_t)$$

这正是评论员网络的TD误差 $\delta_t = r_t + \gamma V_\pi(s_{t+1}) - V_\pi(s_t)$。

关键洞察：用 $V_\pi$ 作为基线（第二项），用 $r_t + \gamma V_\pi(s_{t+1})$ 作为Q的单步近似（第一项），只需学习一个 $V_\pi$ 网络（评论员），无需显式学习Q函数，同时将蒙特卡洛估计的高方差换为TD的低方差。

A2C：优势演员-评论员算法

A2C（Advantage Actor-Critic）用上述TD误差作为优势估计，完整推导链为：

$$\nabla\bar{R}_\theta \overset{\text{PG}}{=} \mathbb{E}\!\left[A^\theta(s_t,a_t)\nabla\log\pi_\theta(a_t|s_t)\right] \overset{\text{TD近似}}{\approx} \mathbb{E}\!\left[\delta_t\,\nabla\log\pi_\theta(a_t|s_t)\right]$$

用采样近似期望：

$$\nabla \bar{R}_\theta \approx \frac{1}{N}\sum_{n=1}^{N}\sum_{t=1}^{T_n} \underbrace{\left(r_t^n + \gamma V_\pi(s_{t+1}^n) - V_\pi(s_t^n)\right)}_{\text{TD误差 }\delta_t\text{（优势的单步近似）}} \nabla_\theta \log p_\theta(a_t^n | s_t^n)$$

A2C的两大工程技巧

技巧做法为什么
网络参数共享演员与评论员共享前几层（卷积层），只在最后分叉底层特征提取可共用，减少参数量，加速训练
熵约束探索在损失函数中加入策略熵正则项 $-\beta H(\pi)$防止策略过早收敛到确定性策略，鼓励持续探索

A3C：异步优势演员-评论员

为什么需要A3C

A2C单进程顺序收集数据效率低。A3C（Asynchronous Advantage Actor-Critic）用多个并行工作进程（Worker）同时与不同环境副本交互，异步更新全局网络。

效果：多进程并行产生多样化数据，天然打破数据相关性（类似经验回放），且是同策略方法——每个Worker用自己的本地网络采样，无需回放缓冲区。

类比：影分身之术——分身们分头探索世界，汇总经验更新本体。

路径衍生策略梯度

从DQN出发重推AC

DQN的 $\arg\max_a Q(s,a)$ 无法处理连续动作，若用策略网络 $\pi_\theta$ 替代 $\arg\max$ 操作，并额外训练 $\pi_\theta$ 以最大化Q值，就得到路径衍生策略梯度：

$$\pi'(s) = \arg\max_a Q_\pi(s,a) \implies \pi_\theta \text{ 最大化 } Q_w(s, \pi_\theta(s))$$

与原始DQN相比，四处关键改变：

  1. 用策略网络 $\pi_\theta(s)$ 输出动作，替代 $\arg\max$
  2. 新增对 $\theta$ 的梯度更新，使演员不断最大化评论员的评分
  3. 引入目标策略网络 $\hat{\pi}_{\hat\theta}$（类比DQN的目标Q网络）
  4. 保留经验回放，成为异策略算法

这就是DDPG的雏形（详见第12章）。

总结与启发

演员-评论员算法是现代深度强化学习的核心架构——演员提供策略灵活性，评论员提供低方差的价值信号。A2C用TD误差替代蒙特卡洛回报，大幅降低梯度方差；A3C通过异步并行进一步提升数据多样性和训练效率。路径衍生策略梯度揭示了DQN和策略梯度的内在联系，为DDPG等连续控制算法奠定基础。AC与GAN的深层对应关系则表明，对抗训练和策略优化在数学上是同构问题。
