3.1 DPO 损失函数（完整推导）

DPO（Direct Preference Optimization）是目前最广泛使用的无强化学习对齐算法。其核心洞察是：RLHF 中 PPO 的最优策略可以用闭合形式表达，从而绕过显式奖励模型训练。

推导路径

从带 KL 约束的 PPO 目标出发：

$$\mathcal{L}(\theta) = \max_{\pi_\theta} \mathbb{E}_{x \sim \mathcal{D}, y \sim \pi_\theta}\left[r(x,y)\right] - \beta\, \text{KL}\!\left[\pi_\theta(y|x) \,\|\, \pi_{\theta_\text{old}}(y|x)\right]$$

引入配分函数 $Z(x) = \sum_y \pi_{\theta_\text{old}}(y|x)\exp\!\left(\frac{r(x,y)}{\beta}\right)$，可得最优策略的闭合形式：

$$\pi^*(y|x) = \frac{1}{Z(x)}\,\pi_{\theta_\text{old}}(y|x)\exp\!\left(\frac{r(x,y)}{\beta}\right)$$

由此推导出奖励函数与策略的关系 $r(x,y) = \beta\log\frac{\pi^*(y|x)}{\pi_{\theta_\text{old}}(y|x)} + \beta\log Z(x)$，代入 Bradley-Terry 偏好模型后，配分函数 $Z(x)$ 在分子分母中约去，最终得到 DPO 损失函数：

$$\boxed{\mathcal{L}_\text{DPO}(\theta) = -\mathbb{E}_{(x,y_+,y_-)\sim\mathcal{D}}\!\left[\log\sigma\!\left(\beta\log\frac{\pi_\theta(y_+|x)}{\pi_{\theta_\text{old}}(y_+|x)} - \beta\log\frac{\pi_\theta(y_-|x)}{\pi_{\theta_\text{old}}(y_-|x)}\right)\right]}$$

其中 $y_+$ 为人类偏好的回答，$y_-$ 为不偏好的回答，$\pi_{\theta_\text{old}}$ 为参考策略（SFT 模型），$\beta$ 控制 KL 散度约束强度（默认 0.1）。

梯度分析

对 DPO 损失求导，令 $\hat{r}_\theta(x,y) = \beta\log\frac{\pi_\theta(y|x)}{\pi_{\theta_\text{old}}(y|x)}$，梯度为：

$$\nabla\mathcal{L}(\theta) = -\beta\,\mathbb{E}\!\left[\sigma\!\left(\hat{r}_\theta(x,y_-) - \hat{r}_\theta(x,y_+)\right)\!\left(\nabla\log\pi_\theta(y_+|x) - \nabla\log\pi_\theta(y_-|x)\right)\right]$$

系数 $\sigma(\hat{r}_\theta(x,y_-)-\hat{r}_\theta(x,y_+))$ 起到自适应权重作用：当模型已倾向于生成 $y_+$ 时权重小（防止过度更新），当模型仍倾向于 $y_-$ 时权重大（激进纠正）。

4. Chinchilla 扩展法则

扩展法则（Scaling Law）是理解 LLM 能力提升的核心理论框架。Chinchilla 扩展法则（Hoffmann et al., 2022）对早期 KM 扩展法则进行了重要修正，指出之前的工作严重低估了训练数据规模的重要性。

Chinchilla 损失函数

$$L(N, D) = E + \frac{A}{N^\alpha} + \frac{B}{D^\beta}$$

其中拟合参数为：$E=1.69$，$A=406.4$，$B=410.7$，$\alpha=0.34$，$\beta=0.28$。
$N$ 为模型参数量，$D$ 为训练 token 数。

算力约束下的最优分配

利用约束条件 $C \approx 6ND$（FLOPs），对损失函数求最优解：

$$N_\text{opt}(C) = G \left(\frac{C}{6}\right)^a, \qquad D_\text{opt}(C) = G^{-1}\left(\frac{C}{6}\right)^b$$

其中 $a = \frac{\alpha}{\alpha+\beta} \approx 0.46$，$b = \frac{\beta}{\alpha+\beta} \approx 0.54$，$G$ 为由 $A,B,\alpha,\beta$ 计算的扩展系数。

关键结论：Chinchilla 主张模型规模与数据规模等比例增加（$a \approx b$），而 KM 扩展法则（$a\approx 0.73, b\approx 0.27$）偏向增加模型规模。GPT-3（175B 参数仅用 300B tokens）严重"欠训练"，Chinchilla 70B 用 1.4T tokens 训练后性能超越 Gopher 280B。

5. 未来研究方向

本章从架构、训练、推理、知识四个维度总结了 LLM 最重要的未来研究方向，每个方向均有明确的技术路径和代表性工作。

5.1 线性注意力与 Mamba SSM

标准 Transformer 的自注意力计算复杂度为 $O(T^2 H)$，随序列长度平方增长，严重限制长文本处理能力。参数化状态空间模型（SSM）提供了 $O(T)$ 复杂度的替代方案。

标准 SSM 状态转移公式

$$\mathbf{S}_t = \mathbf{A} \otimes \mathbf{S}_{t-1} + \mathbf{B} \otimes \mathbf{x}_t$$ $$\mathbf{y}_t = \mathbf{C} \otimes \mathbf{S}_t$$

其中 $\mathbf{A} \in \mathbb{R}^{H\times N\times N}$，$\mathbf{B} \in \mathbb{R}^{H\times N\times 1}$，$\mathbf{C} \in \mathbb{R}^{H\times 1\times N}$ 为可学习参数，$\otimes$ 表示批量矩阵乘法。输出可展开为卷积形式：$\mathbf{y}_t = \sum_{i=1}^t \mathbf{C} \otimes \mathbf{A}^{t-i} \otimes \mathbf{B}\, \mathbf{x}_i$，支持快速傅里叶变换加速。

Mamba 的选择性机制

Mamba（Gu & Dao, 2023）的核心创新是将 SSM 参数矩阵 $(\mathbf{A}, \mathbf{B}, \mathbf{C})$ 改为依赖当前输入 $\mathbf{x}_t$ 的非线性函数，实现信息选择性过滤：

$$\mathbf{A}_t = f_A(\mathbf{x}_t), \quad \mathbf{B}_t = f_B(\mathbf{x}_t), \quad \mathbf{C}_t = f_C(\mathbf{x}_t)$$ $$\mathbf{S}_t = \mathbf{A}_t \otimes \mathbf{S}_{t-1} + \mathbf{B}_t \otimes \mathbf{x}_t, \qquad \mathbf{y}_t = \mathbf{C}_t \otimes \mathbf{S}_t$$

代价：由于引入了关于 $\mathbf{x}_t$ 的非线性关系，Mamba 无法使用 FFT 加速，训练复杂度为 $O(TN^2H + TH^2)$，但解码复杂度仅 $O(N^2H + H^2)$（无需访问历史词元）。

5.4 合成数据

随着高质量互联网文本数据接近饱和，合成数据成为扩展训练规模的关键路径。

合成数据的主要范式

  • 蒸馏式合成：用强模型（GPT-4）生成训练数据训练弱模型（Alpaca、WizardLM、Orca）
  • Self-Instruct：模型自我生成指令数据，迭代提升（Wang et al., 2022）
  • 数学合成：自动生成数学题及解题步骤（WizardMath、MetaMath）
  • 代码合成：从函数签名自动生成代码及测试（DeepSeek-Coder）
  • phi 系列：Textbooks Are All You Need——高质量教科书式合成数据训练小模型

5.5 持续学习

LLM 存在"知识截止日期"问题，本质上是灾难性遗忘（Catastrophic Forgetting）问题：在新数据上微调会覆盖旧知识。持续学习研究如何让模型在不遗忘旧知识的前提下学习新知识。

EWC（Elastic Weight Consolidation）正则化

$$\mathcal{L}_\text{CL} = \mathcal{L}_\text{new}(\theta) + \lambda \sum_i F_i (\theta_i - \theta_i^*)^2$$

其中：

  • $\mathcal{L}_\text{new}(\theta)$：新任务的训练损失
  • $F_i$：Fisher 信息矩阵的对角元素，衡量参数 $\theta_i$ 对旧任务的重要性
  • $\theta_i^*$：旧任务训练后的参数值
  • $\lambda$：正则化强度超参数

直觉：对旧任务重要的参数（$F_i$ 大）受到强约束，不能偏离 $\theta_i^*$ 太远；不重要的参数可以自由更新以适应新任务。

5.6 测试时计算（o1/o3 类）

OpenAI o1 的核心创新是在推理阶段允许模型进行更长时间的"思考"，通过增加测试时计算量来提升复杂任务性能。

测试时计算扩展规律

$$\text{性能} \propto \log(\text{测试时计算量})$$

这一对数规律意味着：通过增加推理时计算（而非增加训练参数），可以持续提升模型在困难任务上的性能，但边际收益递减。

5.7 知识编辑（ROME / MEMIT）

当 LLM 中的知识过时或错误时，重新训练成本极高。知识编辑技术允许精准修改特定知识而不影响其他能力。

ROME（Rank-One Model Editing）核心公式

ROME 的核心发现：Transformer 的 MLP 层可以看作键值存储，其中键 $\mathbf{k}$ 对应知识的"主语"表示，值 $\mathbf{v}$ 对应"宾语"表示。知识编辑等价于修改 MLP 的权重矩阵 $W$，使其对特定键 $\mathbf{k}$ 输出新值 $\mathbf{v}^*$：

$$W_\text{new} = W + \Delta W, \qquad \Delta W = \frac{(\mathbf{v}^* - W\mathbf{k})\,\mathbf{k}^\top}{\mathbf{k}^\top\mathbf{k}}$$

其中 $\mathbf{k}$ 为知识的"键"（输入隐状态），$\mathbf{v}^*$ 为期望的新"值"（目标输出表示）。这是一个秩一更新（Rank-One Update），仅修改权重矩阵的一个方向，对其他知识影响最小。

MEMIT 将 ROME 扩展到批量知识编辑，同时修改多层 MLP 权重，支持一次性编辑数千条知识。

7. 社会影响分析

LLM 的广泛应用不仅带来技术革新，也对社会产生深远影响。本书（第14章安全与对齐部分）及 GPT-3/4 技术报告均对此进行了讨论。

7.1 就业市场影响

研究表明，LLM 对认知型、语言型工作的影响远大于体力型工作，这与历史上工业革命（主要冲击体力劳动）的模式相反。新兴职业包括：提示工程师、AI 产品经理、LLM 评测专家、AI 安全研究员。

7.3 AGI 安全（存在性风险）

关于 AGI 的存在性风险，学界存在显著分歧：

担忧方（Hinton、Bengio 等）

  • 超人类 AI 可能产生与人类价值观不一致的目标
  • 一旦能力超过人类，对齐将极其困难
  • 需要在达到超人类水平前解决对齐问题
  • 当前 LLM 已展示出令人担忧的"欺骗性"行为

乐观方（LeCun 等）

  • 当前 LLM 与 AGI 存在根本性差距
  • 语言预测目标不会自然产生危险的目标
  • 人类有足够时间应对
  • AI 系统仍然依赖人类基础设施

超级对齐（Superalignment）研究方向：可解释性研究（理解模型内部表示）、可扩展监督（用弱监督指导强模型）、形式化验证（将安全性证明形式化）。

10. 结语

大语言模型代表了人工智能发展史上最重要的范式转变之一。本书系统梳理了这一技术革命的全貌：

  • 数据和架构奠定基础：大规模高质量语料 + Transformer 及其改进（RMSNorm/RoPE/SwiGLU/GQA/MoE/FlashAttention）
  • 预训练积累知识：Chinchilla 扩展法则指导算力最优分配，涌现能力随规模出现
  • 对齐塑造行为：从 RLHF 到 DPO，从 Constitutional AI 到超级对齐研究
  • 推理技术释放能力：CoT、ICL、Agent、测试时计算扩展（o1/o3）
  • 应用场景创造价值：搜索、推荐、代码、医疗、教育、科研等垂直领域

站在 2025 年的节点上，LLM 技术正向更强推理、更长上下文、更多模态、更高效部署、更安全对齐的方向快速演进。核心挑战包括：幻觉的根本解决、持续学习与知识更新、可扩展对齐方法、以及如何在算力约束下实现更强能力。

中国人民大学 AI Box 的 YuLan 系列工作及本书的撰写，是中国学术界在这一领域做出原创贡献的重要尝试，也为国内研究者和工程师提供了系统学习 LLM 技术的中文参考。
