概述

大型语言模型（LLM）Agent 在复杂任务上展现出强大能力，但其训练面临一个根本性困境：环境反馈稀疏且缺乏针对性。传统静态环境只能提供最终成功/失败的二值奖励，无法揭示 Agent 在哪些中间步骤上出现了偏差，也无法针对 Agent 的薄弱点动态调整训练任务。构建合成自适应环境虽然可以缓解这一问题，但需要额外的环境模型、任务生成器或调度机制，大幅增加了部署复杂度。

Role-Agent 提出了一个极具吸引力的解决思路：让同一个 LLM 同时扮演 Agent 和 Environment 两个角色，通过双角色自举共同进化（Bootstrapped Co-evolution）来突破上述限制。这一设计的核心直觉在于：一个足够强大的 LLM 不仅能够执行任务，还能够理解环境动力学、预测行动后果、分析失败原因，并为自身设计更有针对性的训练数据。

具体而言，Role-Agent 包含两个协同组件：WIA（World-In-Agent）让 LLM 在每次行动后预测未来状态，通过预测状态与实际状态的对齐程度构建过程奖励，鼓励环境感知推理；AIW（Agent-In-World）让同一个 LLM 充当环境角色，从失败轨迹中识别失败模式，检索具有相似失败模式的任务，并将其重新注入训练集，使 Agent 能够针对性地练习历史弱项。

这一框架的优雅之处在于：无需引入额外模型，仅凭单个 LLM 的角色切换，就能在 Agent 侧和 Environment 侧同时实现自我改进，形成一个闭环的自举进化系统。在多个基准上的实验验证了这一方法的有效性，平均增益超过 4%，尤其在需要稳定记忆和多步规划的复杂组合任务上表现更为突出。

研究背景

LLM Agent 训练的核心挑战

LLM Agent 的训练面临三大核心挑战：

  • 稀疏奖励问题：在开放世界任务（如家居导航、网购、多跳问答）中，奖励通常仅在轨迹末尾给出（成功/失败），中间步骤缺乏信用分配依据。
  • 静态环境局限：传统环境将任务集视为固定分布，无法根据 Agent 当前的能力缺陷动态调整训练难度，导致 Agent 在已掌握任务上过度训练，而忽视真正的薄弱点。
  • 探索效率低下：缺乏环境感知的 Agent 往往采用随机探索策略，在状态空间庞大的任务中收敛缓慢，甚至陷入重复失败的循环。

相关工作定位

Agentic RL（ARL）：将完整的多轮交互轨迹纳入 RL 框架，代表方法包括 PPO、RLOO、GRPO、DAPO、GSPO 和 GPG。这些方法依赖最终结果奖励，过程信用分配能力有限。

过程奖励模型（PRM）：DeepSeekMath、StepSearch 等工作尝试为每个步骤分配信用，但通常需要额外训练奖励模型。Role-Agent 的 WIA 通过状态预测对齐实现免监督的过程奖励，是一种轻量级的替代方案。

自进化 Agent：EvolveR 提出自包含生命周期，MAE 实例化 Proposer/Solver/Judge 三角色，AgentEvolver 利用自我提问和自我归因。这些工作的辅助角色主要停留在 Agent 侧，而 Role-Agent 实现了真正的 Agent-Environment 双侧共同进化。

双角色设计哲学

Role-Agent 的核心设计哲学来源于一个简洁的问题：能否用单个 LLM 同时充当 Agent 和 Environment，实现无需额外模型的自举共进化？

这一设计的合理性基于以下观察：（1）足够强大的 LLM 本身就内化了大量关于世界动力学的知识，具备预测行动后果的能力；（2）LLM 的语言理解能力使其能够分析失败轨迹、识别错误模式；（3）通过角色切换而非角色分离，避免了引入额外模型带来的分布偏移和部署复杂度。

关键洞见：传统 self-play 需要两个独立模型相互对弈；Role-Agent 通过提示词工程（prompt engineering）实现同一模型的角色切换，将"外部对手"内化为"内部视角"，是一种更轻量、更紧凑的自举范式。

形式化问题设置

给定任务提示 $x \in \mathcal{X}$，Agent 在每步 $t$ 基于当前状态 $s_t$ 和策略 $\pi_\theta(a_t | s_t, x)$ 生成动作 $a_t \in \mathcal{A}$。环境提供下一状态 $s_{t+1}$ 和即时奖励 $r_t$，生成轨迹：

$$\tau = \{(s_t, a_t, r_t)\}_{t=1}^{T}$$

批量轨迹记为 $\mathcal{T} = \{\tau_i\}_{i=1}^{N}$。在稀疏奖励场景中，过程级奖励 $r_t$ 通常被轨迹级奖励 $R_E(\tau_i)$（如最终是否达成目标）所替代。

WIA 组件：World-In-Agent

核心思想

WIA 受到世界模型（World Model）研究的启发，将环境动力学内化到 Agent 中。其核心机制是：在每次行动后，Agent 不仅执行动作，还被要求预测该动作在未来 $H$ 步内将导致的环境状态。预测状态与实际状态的对齐程度被用作过程奖励，鼓励 Agent 发展出对环境的精细感知能力。

状态预测机制

在轨迹 rollout 的每步 $t$，Agent 生成动作 $a_t$ 后，用增强提示 $x_{pre}$ 预测未来 $H$ 步的状态：

$$\hat{s}_{t,h} \sim \pi(\cdot \mid a_t, x_{pre}), \quad h \in \{1, \ldots, H\}$$

步骤 $t$ 的预测集合为 $\mathcal{E}_{pre,t} = \{\hat{s}_{t,h} \mid 1 \leq h \leq H\}$，全轨迹预测集合为：

$$\mathcal{E}_{pre} = \{\mathcal{E}_{pre,t} \mid 1 \leq t \leq T\}$$

使用最长公共子序列（LMS，Longest Matching Subsequence）度量预测状态与真实状态的文本相似度，得到预测奖励矩阵 $\tilde{r} \in \mathbb{R}^{T \times H}$：

$$\tilde{r}_{t,h} = \text{LMS}(\hat{s}_{t,h},\, s_{t+h}), \quad \tilde{r}_{t,h} \in [0, 1]$$

奖励调制公式

任务奖励和预测奖励分别定义为：

$$R_{task}(a_t) = \sum_{k=t}^{T} \gamma^{k-t} r_k, \qquad R_{pre}(a_t) = \sum_{h=1}^{H} \gamma^{h-1} \tilde{r}_{t,h}$$

最终调制奖励采用乘法组合（而非加法），确保预测奖励不能独立引入额外信用：

$$\boxed{R_t = R_{task}(a_t) \cdot \bigl(1 + R_{pre}(a_t)\bigr)}$$

这一设计遵循两个原则：（a）准确的状态预测保留并放大原始信用，反映可靠的环境感知；（b）不准确的预测削弱优势信号，降低那些碰运气获得高回报的动作的信用。乘法结构确保预测奖励仅调制任务奖励非零的动作，防止失败轨迹仅因合理的状态预测而获得奖励。

预测奖励与结果奖励的相关性实验（200 条 ALFWorld rollout，Qwen2.5-3B-Instruct）显示：点二列相关系数为 0.41（$p \lt 0.01$），且平均预测奖励从初始化时的约 0.60 上升到收敛时的 0.70 以上，表明状态预测质量随训练持续提升。

状态分组与状态级优势

受 GiGPO 启发，WIA 进一步引入状态分组机制。通过哈希映射识别批次中的非重复状态集合 $\mathcal{O} = \{s^\dagger_o\}_{o=1}^{|\mathcal{O}|}$，将相同状态下的动作分组：

$$\mathcal{G} = \bigl\{\{(s_t, a_t) \mid \text{hash}(s_t^{(i)}) = \text{hash}(s^\dagger_o)\} \mid s^\dagger_o \in \mathcal{O}\bigr\}$$

每个动作 $a_t^{(o)}$ 的状态级优势为：

$$A_S(a_t^{(o)}) = \frac{R_t^{(o)} - \text{avg}(\{R_t^{(o)} \mid (s_t^{(o)}, a_t^{(o)}) \in \mathcal{G}^{(o)}\})}{\text{std}(\{R_t^{(o)} \mid (s_t^{(o)}, a_t^{(o)}) \in \mathcal{G}^{(o)}\})}$$

最终优势将状态级与轨迹级优势以系数 $\alpha$ 混合：

$$A(a_t^{(i)}) = A_S(a_o^{(i)}) + \alpha \cdot A_E(\tau_i)$$

策略优化目标（GRPO 风格）为：

$$\mathcal{J}_{ours}(\theta) = \frac{1}{N} \sum_{i=1}^{N} \frac{1}{|\tau_i|} \sum_{t=1}^{|\tau_i|} \min\!\left(\rho_{\theta,t}^{(i)} A(a_t^{(i)}),\; \text{clip}(\rho_{\theta,t}^{(i)}, 1 \pm \epsilon) A(a_t^{(i)})\right) - \beta D_{KL}[\pi_\theta \| \pi_{ref}]$$

其中 $\rho_{\theta,t}^{(i)} = \pi_\theta(a_t^{(i)} \mid s_t^{(i)}, y_{\lt t}^{(i)}) / \pi_{old}(a_t^{(i)} \mid s_t^{(i)}, y_{\lt t}^{(i)})$ 为重要性采样比率。

AIW 组件：Agent-In-World

核心思想

AIW 解决了另一个关键问题：环境如何根据 Agent 的能力动态调整自身？传统静态训练集无法针对 Agent 的历史失败模式进行有针对性的练习。AIW 让同一个 LLM 充当环境角色，通过分析失败轨迹、建立失败模式库、检索相似任务，动态调整训练数据分布，使 Agent 能够反复练习其薄弱点。

失败模式分析

对每条失败轨迹，将完整交互序列、任务描述和目标输入 LLM，提示其进行结构化失败分析，输出包含以下字段的反思：

  • DOMINANT_TYPE：主要失败类型（如 ENTITY_CONFUSION、MISSING_PRECONDITION）
  • DETAIL：1-2 句话解释根本原因
  • CRITICAL_STEP：失败变得不可逆的关键步骤
  • CORE_LESSON：可推广的决策规则
  • RETRIEVAL_QUERY：用于检索相似失败任务的查询

在 ALFWorld 训练中，AIW 识别出 11 种独特失败模式：

任务检索与数据重塑的优势

AIW 的检索策略与简单的随机失败任务回放（random failed-task replay）或基于任务文本的检索（task-text retrieval）有本质区别：AIW 基于底层错误模式进行检索，能够连接表面不同但共享同一程序性弱点的任务。例如，"将干净的叉子放入抽屉"和"将切好的苹果放在柜台上"表面上完全不同，但它们都涉及 ENTITY_CONFUSION 模式（Agent 混淆了相似对象），因此在 AIW 中会被归入同一失败模式桶，相互检索。

在 ALFWorld 训练中，失败模式库的规模从第 15 步的 996 条快速增长到第 150 步的 3931 条，随后趋于饱和——这表明任务被快速分配到失败模式桶，随后每个模式的积累逐渐放缓，库趋于充分填充。

总结与启发

核心贡献回顾

Role-Agent 提出了一个简洁而有力的框架：单个 LLM 通过角色切换实现 Agent 与 Environment 的自举共同进化。WIA 将世界动力学内化为过程奖励，AIW 将失败经验转化为有针对性的训练数据，两者协同作用，在多个基准上实现了超越强基线 4% 以上的平均增益。

对 Self-Play 与 Bootstrapping 的深层思考

Role-Agent 的设计触及了 AI 训练中一个深刻的哲学问题：自我改进的边界在哪里？传统 self-play（如 AlphaGo）需要两个独立模型相互竞争，通过外部对手提供改进信号。Role-Agent 将这一范式推进到极致——用同一个模型扮演所有角色，通过提示词工程实现视角切换。这一方法的成功表明，LLM 内化的世界知识已经足够丰富，可以为自身提供有意义的对抗性反馈。

然而，这也引出了一个值得警惕的问题：自我评估的偏差（Self-Evaluation Bias）。当同一个模型既是学生又是老师时，其固有的偏见和盲点可能会被循环强化而非纠正。Role-Agent 通过两个机制部分缓解了这一问题：（1）WIA 的过程奖励基于客观的状态对齐度（LMS 分数），而非主观评判；（2）AIW 的失败模式识别依赖于真实交互历史中的失败信号，而非模型的主观臆测。但论文作者也承认，使用更强的冻结环境 LLM 可以提升 AIW 组件的质量，这暗示当前单模型设计存在能力上限。

从 Bootstrapping 的角度看，Role-Agent 的训练动力学非常有趣：早期阶段 Role-Agent 表现不如 GiGPO，但随着失败模式库的积累和训练分布的动态调整，它逐渐超越并拉开差距。这种"慢热"特性是自举系统的典型行为——需要足够的失败经验积累才能建立有效的自我改进循环。

对未来研究的启发：Role-Agent 的成功为以下方向提供了实证支持：（1）轻量级过程奖励：无需训练独立 PRM，通过状态预测对齐即可获得有意义的过程信号；（2）失败驱动的课程学习：基于错误模式而非难度分级的课程设计，能够更精准地定位 Agent 的薄弱点；（3）单模型多角色范式：随着 LLM 能力的提升，越来越多的辅助角色（评判者、环境、教师）可以被内化到单个模型中，降低系统复杂度。

局限性：当前评估局限于文本环境；状态分组的相似度阈值来自先前研究，限制了跨任务泛化；更强的冻结环境 LLM 虽能提升 AIW 质量，但会引入额外外部知识，影响对比公平性。多模态和实时具身场景的扩展是重要的未来方向。
