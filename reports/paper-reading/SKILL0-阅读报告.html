1. 核心问题与动机

1.1 推理时技能增强的根本局限

flowchart TD
    P["推理时技能增强（现有主流范式）\n每次推理从 SkillBank 检索 → 注入上下文 → 辅助推理"]
    P1["问题1：检索噪声\n无关或误导性技能污染上下文\n被错误引导执行错误动作"]
    P2["问题2：Token 开销\n多轮交互中技能内容快速累积\n上下文膨胀，限制可扩展性"]
    P3["问题3（最根本）\n模型只是在执行技能，而不是学习技能\n能力存在于上下文中，而非模型参数\n每次推理都需要重新检索——永远在第一阶段"]
    P --> P1 & P2 & P3
认知科学依据（Anderson, 1982）：技能获取分两个阶段——显式指令阶段（看着说明书做）→ 内化阶段（不用说明书也能自动完成）。推理时技能增强让 Agent 永远停在第一阶段。SKILL0 旨在让 Agent 达到第二阶段。

3.2 上下文渲染与自适应压缩

将文本交互历史和技能渲染为压缩 RGB 图像：

$$V_t = \mathrm{Enc}(h_t,\, S;\, c_t), \quad V_t \in \mathbb{R}^d$$

压缩比 $c_t \in (0,1]$ 由策略自动生成（非固定超参数）：

$$(a_t,\, c_t) \sim \pi_\theta(a_t, c_t \mid I, V_t)$$

3.3 复合奖励设计

$$r_t^{\mathrm{comp}} = \begin{cases} \ln(c_t) & \text{if } I_\mathrm{succ}(\tau) = 1 \\ 0 & \text{otherwise} \end{cases}$$ $$\tilde{r}_t = r_t + \lambda \cdot r_t^{\mathrm{comp}}$$

对数函数反映压缩的边际递减效益；$\lambda$ 控制任务性能与压缩效率的权衡。

3.4 SKILL0 训练目标函数

$$\mathcal{L}_\mathrm{SKILL0}(\theta) = \mathbb{E}_{\tau_i \sim \pi_{\theta_\mathrm{old}}(q),\, q\sim D}\!\left[\frac{1}{\sum_i |\tau_i|}\sum_{i=1}^{G}\sum_{t=1}^{|\tau_i|} \mathrm{clip}(r_{i,t}(\theta), A_i, \epsilon) - \beta \cdot D_\mathrm{KL}[\pi_\theta \| \pi_\mathrm{ref}]\right]$$

3.5 动态课程：技能预算线性递减

训练分 $N_S$ 个阶段，预算从全部技能线性递减至零：

$$M^{(s)} = \left\lfloor N \cdot \frac{N_S - s}{N_S - 1} \right\rfloor, \quad s = 1, \ldots, N_S$$

从 $M^{(1)} = N$ 线性递减至 $M^{(N_S)} = 0$（零技能）。每次阶段切换时，策略分布偏移被约束在 PPO 重要性采样比范围内，训练稳定。

5. 消融实验与关键发现

5.1 技能预算方案消融（核心发现）

预算方案有技能推理无技能推理迁移增益 Δ
SKILL0 [6,3,0]（递减至零）86.3%87.9%+1.6%（正向迁移）
[6,6,6]（始终保留技能）85.9%72.6%−13.3%（依赖技能）
[0,0,0]（始终无技能）—78.9%—
正向迁移的实验证明：只有递减到零的预算方案 [6,3,0] 实现了正向迁移——无技能推理（87.9%）超过有技能推理（86.3%）。这意味着内化后的模型参数中的知识比上下文中的技能更可靠、更精准。始终保留技能 [6,6,6] 的方案反而导致模型形成表面依赖，去掉技能后崩溃 −13.3%。

6. 局限性

  • 技能库质量依赖：初始 SkillBank 的质量直接影响内化效果；低质量技能可能引入错误知识
  • 离线分组需重新划分：相关性驱动的技能分组是离线完成的，新任务域需重新划分验证集
  • 视觉编码器依赖：上下文渲染依赖视觉语言模型（VLM）的图像理解，纯文本 LLM 无法直接使用

7. 核心洞见与读后评注

技能内化：从"查手册"到"本能"
SKILL0 解决的是一个深层的 AI 学习问题：如何将外部知识真正内化为内在能力，而不是每次推理都依赖外部脚手架。这与 AlphaGo → AlphaZero 的演进有相似之处：前者依赖人类棋谱作为先验，后者完全从自对弈中学习。SKILL0 的"有技能训练+无技能推理"是这一思路在 Agent 领域的具体实例。
帮助度驱动的动态课程：比固定退火更聪明
传统课程学习用固定的难度递增策略。SKILL0 的 Δk（帮助度）指标是一个在线的、自适应的技能效用估计——当策略已经从技能 Sk 中学到足够多时，Δk 自然下降，课程自动移除该技能。这比人工设计退火时间表更精准，且不需要额外的标注或监督。
5× token 效率的工程意义
推理时 0.38k tokens/步 vs SkillRL 的 2.21k，差距5倍。在长上下文、多轮交互的 Agent 任务中，这个效率差距意味着：相同的计算预算下，SKILL0 可以处理更多轮次的交互，或者在相同推理成本下部署更多并发 Agent 实例。技能内化不只是更聪明，还更便宜。
