概述

世界模型（World Model）根据当前观察和动作预测环境动态，是推理与规划的核心认知机制。本工作探索如何基于语言模型构建世界模型，以进一步突破通用 Agent 的能力边界。

本文提出 Qwen-AgentWorld，这是首个能够通过长链式思维推理（Long Chain-of-Thought）模拟 Agent 交互环境的原生语言世界模型（Language World Model，LWM）。与以往将世界建模作为事后适配的方法不同，Qwen-AgentWorld 从持续预训练（CPT）阶段起就将环境建模作为核心训练目标，真正实现了"原生"世界模型。

论文的核心贡献分为两大部分：

  1. 构建 Agent 环境模拟基础模型：通过三阶段训练流程（CPT → SFT → RL），在 AgentWorldBench 上超越 GPT-5.4、Claude Opus 4.8 等前沿模型。
  2. 探索两种 Agent 增强范式：（1）解耦环境模拟器，支持可扩展的强化学习训练；（2）统一 Agent 基础模型，世界模型训练作为高效预热，提升下游 7 个 Agent 基准的表现。

研究背景与动机

世界模型的价值

世界模型的概念源自认知科学与强化学习领域。在经典 RL 框架中，世界模型允许 Agent 在"脑内"模拟环境，无需与真实环境交互即可进行规划与推理。对于语言 Agent 而言，真实环境交互成本极高（API 调用费用、执行时间、安全风险），因此构建高质量的语言世界模型具有重要的工程与科研价值。

现有方法的局限

现有研究在以下方面存在明显不足：

  • 领域割裂：已有世界模型通常只针对单一或少数几个 Agent 领域，缺乏跨领域统一建模能力。
  • 事后适配：大多数方法将世界建模视为通用 LLM 的事后微调任务，而非从预训练阶段就以环境建模为目标。
  • 缺乏推理能力：现有模型通常不具备长链式思维推理能力，在复杂多步骤环境模拟中表现欠佳。
  • 评测基准缺失：语言世界模型领域缺乏系统性、多维度的评测基准。

七大 Agent 领域

Qwen-AgentWorld 覆盖的 7 个领域可分为两大类：

核心方法

总体架构

Qwen-AgentWorld 的核心设计原则是："CPT 注入，SFT 激活，RL 打磨"（CPT injects, SFT activates, RL sharpens）。整个训练流程从持续预训练阶段起就以环境建模为唯一目标，逐步构建世界建模能力。

阶段一：持续预训练（CPT）

CPT 阶段的目标是向模型注入通用世界建模能力，使其理解环境的状态转移动态。训练数据来源于两部分：

  • 环境交互轨迹：从 7 个领域收集超过 1000 万条真实环境交互记录，涵盖 MCP 工具调用、网页搜索、终端操作、软件工程任务、Android 操作、网页浏览和桌面 OS 任务。
  • 增强专业语料：针对各领域的专业知识文档，帮助模型建立领域知识基础。

CPT 阶段使用非思维链（Non-Thinking）轨迹进行训练，重点在于让模型掌握状态转移的基本模式，而非复杂推理。

阶段二：监督微调（SFT）

SFT 阶段的目标是激活下一状态预测的显式思维链推理模式，让模型学会"边思考边预测"。

阶段三：强化学习（RL）

RL 阶段通过混合 Rubric-and-Rule 奖励框架进一步打磨模型的仿真保真度（Simulation Fidelity）。

混合奖励框架 (Hybrid Rubric-and-Rule Rewards)
奖励信号 = Rubric 奖励 + Rule 奖励

-- Rubric 奖励（基于 LLM-as-Judge）--
  LLM_Judge(预测状态, 真实状态) → 五维度评分
  评估维度：格式 / 事实性 / 一致性 / 真实性 / 质量

-- Rule 奖励（基于规则的硬约束）--
  Format_Check(输出) → 0/1 （结构合规性）
  Consistency_Check(输出, 历史) → 0/1 （跨轮一致性）

混合奖励设计兼顾了语义质量（LLM 评判）和结构正确性（规则约束），避免了纯 LLM 评判可能带来的奖励黑客问题。

范式一：解耦环境模拟器（Decoupled Environment Simulator）

第一种 Agent 增强范式将 Qwen-AgentWorld 作为独立的环境模拟器，支持对数千个真实世界环境进行可扩展、可控制的模拟，用于 Agent 的强化学习训练。

sequenceDiagram participant A as Agent Policy participant W as Qwen-AgentWorld
(环境模拟器) participant R as 真实环境
(验证) Note over A,W: 模拟强化学习 (Sim RL) loop 大规模并行训练 A->>W: 动作 (Action) W->>W: 长链式思维推理 W-->>A: 模拟观察 (Simulated Obs) A->>A: 策略更新 end Note over A,R: 迁移验证 A->>R: 部署到真实环境 R-->>A: 真实反馈 (验证效果)

关键设计特性：

  • 可控模拟（Controllable Simulation）：通过控制指令引导模拟器生成更具针对性的环境响应，是 Sim RL 有效工作的前提条件。实验表明，无控制指令的 Sim RL 几乎无法带来收益（Tool Decathlon 甚至从 32.4 下降到 31.5），而加入可控模拟后提升显著（+3.7 和 +12.3）。
  • 虚构世界泛化：在完全虚构、自洽的世界中训练的 Agent 能够泛化到真实搜索任务，同时防止 Agent 将模拟事实与真实知识混淆。
  • 状态是瓶颈：Sim RL 的有效性取决于为世界模型提供足够详细的初始状态；缺乏初始状态会导致仿真保真度下降，下游收益减少。

范式二：统一 Agent 基础模型（Unified Agent Foundation Model）

第二种范式将世界模型训练视为高效的预热（Warm-up），在此基础上进行下游 Agent 任务的微调，从而提升跨领域 Agent 性能。

值得注意的是，LWM 训练流程中不包含 Claw 和函数调用数据，但在这些完全域外（Out-of-Domain）任务上仍然取得了显著提升（+11.3、+9.7、+9.0），说明世界模型训练具有强大的跨领域迁移能力。

AgentWorldBench 评测基准

基准构建

AgentWorldBench 是专为语言世界模型设计的综合评测基准，具有以下特点：

  • 数据来源：5 个前沿模型（GPT-5.4、Claude Opus 4.8/4.6、Claude Sonnet 4.6、Gemini 3.1 Pro）在 9 个已建立基准上的真实交互记录，包括 Tool Decathlon、Terminal-Bench 1.0 & 2.0、OSWorld-Verified 等。
  • 真实性保障：每个样本都配有来自真实环境的 ground-truth 观察，避免了纯合成数据的分布偏差。
  • 数据格式：7 个领域各对应独立 JSONL 文件（mcp_test.jsonl、search_test.jsonl 等）。

五维度评估体系

AgentWorldBench 通过 LLM 评判器对预测观察进行五维度开放式评分，最终得分归一化到 $[0, 100]$ 区间：

维度英文名评估内容示例（MCP 领域）
格式Format 输出是否遵循领域的结构约定 MCP 的 JSON Schema 合规性；Terminal 的 Shell 提示格式
事实性Factuality 陈述的事实是否正确 文件内容、搜索结果、工具返回值是否准确
一致性Consistency 输出是否内部连贯且与前序轮次一致 多轮对话中状态变量是否保持一致
真实性Realism 模拟输出是否符合真实环境的行为模式 错误信息格式、响应延迟模式是否真实
质量Quality 整体模拟质量的综合评估 信息丰富度、可用性、实用性

最终评分公式：

$$\text{Score} = \frac{1}{5} \sum_{d \in \{\text{Format, Factuality, Consistency, Realism, Quality}\}} \text{Score}_d \times 100$$

消融实验分析

三阶段训练流程的贡献

通过对比 Qwen-AgentWorld 与其基座检查点，可以量化三阶段流程的贡献：

  • 397B 规模：整体平均分从 54.74（Qwen3.5-397B-A17B 基座）提升至 58.71（+3.97 分）
  • 35B 规模：整体平均分从 47.73（Qwen3.5-35B-A3B 基座）提升至 56.39（+8.66 分），超越 Claude Sonnet 4.6（56.04）
  • 文本领域（397B）：平均分提升 3.35 分
  • GUI 领域（397B）：平均分提升 4.92 分

对比 Qwen3.6-Plus（50.81）和 Qwen3.6-Max-Preview（52.42）——这两个模型与 Qwen-AgentWorld 共享相同的架构系列但未经 LWM 训练——可以排除基础模型通用能力的干扰，证明提升确实来自世界模型训练本身。

可控模拟的重要性

针对解耦模拟器范式，实验对比了有无控制指令的 Sim RL 效果：

配置Tool DecathlonMCPMark
无 Sim RL（基线）32.4基线
Sim RL（无控制指令）31.5 (-0.9)边际提升
Sim RL（有控制指令）36.1 (+3.7)+12.3

实验揭示了一个关键发现：可控性不仅影响提升幅度，更是 Sim RL 能够工作的前提条件。MCPMark 上更大的提升（+12.3 vs +3.7）表明，可控模拟对于需要大量顺序工具调用和复杂中间结果处理的任务尤为有效。

模拟器质量的影响

两种模拟器的对比清晰展示了世界模型质量的重要性：通用 LLM（Qwen3.6-Plus）作为模拟器仅带来边际收益，而专门训练的 Qwen-AgentWorld-397B-A17B 在两个基准上均取得实质性提升，证明专用 LWM 训练流程对于构建高保真模拟器至关重要。

局限性与未来方向

当前局限性

  • 评测基准自建问题：AgentWorldBench 由 Qwen 团队自行构建，评判器也是 LLM-as-Judge，存在潜在的评测偏差风险。外部研究者指出，模型在自建基准上的优势需要通过独立第三方评测来进一步验证。
  • GUI 领域的表示限制：当前 GUI 领域使用无障碍树而非像素帧，限制了对视觉元素的精细建模，对于视觉高度依赖的任务可能存在信息损失。
  • 状态初始化依赖：Sim RL 的有效性高度依赖于提供足够详细的初始状态描述。在实际应用中，完整的初始状态往往难以获取，这限制了方法的适用范围。
  • 领域覆盖边界：尽管覆盖 7 个领域，但仍有许多重要的 Agent 交互场景（如数据库操作、代码执行、多模态交互）未被纳入。
  • 计算资源需求：397B 参数的 MoE 模型对推理计算资源要求较高，在资源受限场景下的应用存在挑战。

未来研究方向

  • 扩展到更多 Agent 交互领域，构建更全面的统一世界模型
  • 探索像素级 GUI 模拟，突破无障碍树表示的限制
  • 研究更高效的世界模型训练方法，降低计算资源需求
  • 将语言世界模型与多模态感知能力深度融合
  • 构建更客观、更全面的第三方评测基准

关键洞见与点评

技术洞见

洞见 1：原生世界模型 vs. 事后适配
Qwen-AgentWorld 的核心设计哲学是从 CPT 阶段起就以环境建模为目标，而非在通用 LLM 上事后添加世界建模能力。这种"原生"设计使模型能够从底层学习环境动态的表示，而非简单地在通用语言能力上叠加。实验数据支持这一设计：Qwen3.6-Plus 和 Qwen3.6-Max-Preview 尽管通用能力强，但在 AgentWorldBench 上显著落后于经过专用训练的 Qwen-AgentWorld。
洞见 2：长链式思维推理对世界建模的价值
SFT 阶段激活的长链式思维推理（Long CoT）是模型模拟复杂环境动态的关键。对于 MCP（平均 24.3 轮）和 SWE（平均 26.9 轮）这类长轨迹任务，显式的思维链推理允许模型追踪复杂的状态变化，维护跨轮次的一致性。
洞见 3：域外迁移的惊喜
最令人印象深刻的发现是 LWM 训练在域外任务上的强大迁移能力：在 Claw-Eval（+11.3）、QwenClawBench（+9.7）和 BFCL v4（+9.0）上的显著提升，尽管训练数据中完全不包含这些领域。这表明世界模型训练学到的是一种通用的"环境理解"能力，而非领域特定的记忆。
洞见 4：可控性是 Sim RL 的关键
实验清晰地表明，没有可控模拟，Sim RL 几乎无法工作（Tool Decathlon 甚至出现负提升）。这揭示了一个重要的系统设计原则：高质量的模拟训练需要精确的环境控制能力，不能简单地将通用 LLM 替换为模拟器。

综合评价

Qwen-AgentWorld 代表了语言 Agent 研究的一个重要方向：将世界模型从强化学习的配角提升为 Agent 能力构建的核心组件。其三阶段训练流程设计合理，两种 Agent 增强范式互补，AgentWorldBench 的构建也填补了领域空白。

然而，也需要注意一些值得关注的问题：AgentWorldBench 由 Qwen 团队自建，且使用 LLM-as-Judge 评判，存在一定的评测偏差风险。正如外部研究者指出的，模型在某些关键子任务（如 Terminal、MCP）上并未全面领先，部分优势可能来自评测设置的有利因素。独立第三方验证将是未来工作的重要环节。

从更宏观的视角来看，这项工作提出了一个有价值的研究假设：理解环境动态（世界建模）与执行 Agent 任务（策略学习）之间存在正向迁移。如果这一假设得到更广泛的验证，将为构建通用 Agent 提供一条新的技术路径——先教模型理解世界，再教模型行动于世界。

一句话总结：Qwen-AgentWorld 是首个跨 7 个 Agent 领域的原生语言世界模型，通过 CPT→SFT→RL 三阶段训练实现高保真环境模拟，并以此为基础探索了解耦模拟器和统一基础模型两种 Agent 增强范式，在 AgentWorldBench 上超越 GPT-5.4 等前沿模型，同时在域外任务上展现出强大的迁移能力。
