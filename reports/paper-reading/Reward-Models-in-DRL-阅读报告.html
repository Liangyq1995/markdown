1. 核心问题与动机

1.1 强化学习与奖励模型的基础

强化学习（RL）建立在马尔可夫决策过程（MDP）$\langle \mathcal{S}, \mathcal{A}, T, R, \gamma \rangle$ 上，智能体的目标是最大化期望折扣累积奖励：

$$J(\pi) = \mathbb{E}_{\pi, T}\!\left[\sum_{t=0}^{\infty} \gamma^t R(s_t, a_t)\right]$$

其中 $T(\cdot|s,a)$ 为转移函数，$R(s,a)$ 为奖励模型，$\gamma \in [0,1)$ 为折扣因子。

核心难题：状态空间 $\mathcal{S}$、动作空间 $\mathcal{A}$ 和转移模型 $T$ 由环境内在决定，但奖励模型 $R$ 必须由任务设计者精心构造。在真实应用中，往往只有描述性目标可用，需要将其转化为统计奖励模型——这一过程称为"奖励建模（Reward Modeling）"。

4. 奖励机制

4.1 外在奖励与内在奖励的结合

统一内在和外在奖励的标准公式：

$$r = \lambda r_\mathrm{int} + (1-\lambda) r_\mathrm{ext}, \quad 0 \leq \lambda \leq 1$$

4.2 内在动机的三大类型

类型代表方法奖励信号来源适用场景
探索型ICM（Pathak 2017）、RND（Burda 2018）状态转移预测误差 / 蒸馏误差稀疏奖励环境
计数型UCB、伪计数（Bellemare 2016）状态访问频率（少访问 → 高奖励）离散/连续状态空间
赋权型DIAYN（Eysenbach 2018）、Mazzaglia 2022最大化状态-技能互信息 $I(\tau; z)$无监督技能学习

DIAYN（多样性即技能）的内在奖励：

$$r_\mathrm{int}(s, z) = \log q_\phi(z \mid s) - \log p(z)$$

其中 $z$ 为技能变量，$q_\phi(z|s)$ 为技能判别器，鼓励不同技能产生可区分的状态访问分布。

5. 三大学习范式（含完整公式）

5.1 从演示学习：逆强化学习（IRL）

MaxEnt-IRL（Ziebart et al., 2008）：假设专家以正比于奖励的 Boltzmann 分布生成轨迹：

$$p(\tau \mid \theta) \propto \exp\!\left(R_\theta(\tau)\right) = \exp\!\left(\sum_{(s,a)\in\tau} R_\theta(s,a)\right)$$

最大化专家演示的对数似然，同时用最大熵正则化防止过拟合：

$$\max_\theta \mathbb{E}_{\tau \sim D_e}\!\left[R_\theta(\tau)\right] - \log Z(\theta), \quad Z(\theta) = \sum_\tau \exp\!\left(R_\theta(\tau)\right)$$

AIRL（Fu et al., 2017）：用对抗训练框架，在状态-动作级别分解：

$$D_\theta(s,a,s') = \frac{\exp(f_\theta(s,a,s'))}{\exp(f_\theta(s,a,s')) + \pi(a|s)}, \quad f_\theta = R_\theta(s,a) + \gamma V_\theta(s') - V_\theta(s)$$
Algorithm: MaxEnt-IRL 训练流程

Input: 专家演示 $D_e = \{\tau_e^{(i)}\}$，环境，参数 $\theta$

repeat

1. 用当前 $R_\theta$ 运行软值迭代，得到 $\pi_\theta$

2. 从 $\pi_\theta$ 采样轨迹 $D_\pi = \{\tau^{(i)}\}$

3. 梯度更新：$\theta \leftarrow \theta + \alpha \left(\mathbb{E}_{D_e}[\nabla_\theta R_\theta] - \mathbb{E}_{D_\pi}[\nabla_\theta R_\theta]\right)$

until 收敛

5.2 从目标学习（GCRL）

两类奖励设计：

$$\text{二值奖励（稀疏）：} R(s,g) = \mathbf{1}[s \text{ 达到目标 } g]$$ $$\text{距离奖励（密集）：} R(s,g) = -d(\phi(s),\, \psi(g))$$

时间距离（Temporal Distance）相比空间距离更适合非欧几里得状态空间，估计策略从 $s$ 到 $g$ 所需步数：

$$d_T(s,g) = \min_\pi \mathbb{E}_\pi\!\left[\sum_{t=0}^{\infty} \mathbf{1}[s_t \neq g] \,\Big|\, s_0 = s\right]$$

5.3 从偏好学习（PbRL / RLHF）

Bradley-Terry 偏好模型——RLHF 的理论基础：

$$P(\tau^0 \succ \tau^1;\, \theta) = \frac{\exp\!\left(\sum_{(s,a)\in\tau^0} R_\theta(s,a)\right)}{\sum_{j\in\{0,1\}} \exp\!\left(\sum_{(s,a)\in\tau^j} R_\theta(s,a)\right)}$$

奖励模型训练目标（最大化观测偏好的对数似然）：

$$\mathcal{L}(\theta) = -\mathbb{E}_{(\tau^0, \tau^1, y)\sim D}\!\left[y \log P(\tau^0 \succ \tau^1) + (1-y)\log P(\tau^1 \succ \tau^0)\right]$$
Algorithm: RLHF 三阶段训练流程

阶段1 — SFT：

用人类演示数据监督微调预训练 LLM → $\pi_\mathrm{SFT}$

阶段2 — 奖励模型训练：

收集偏好数据集 $D = \{(\tau^0, \tau^1, y)\}$（人类比较两个回答）

最小化 $\mathcal{L}(\theta)$ → 训练 $R_\theta$

阶段3 — PPO RL 微调：

最大化 $\mathbb{E}[R_\theta(s,a)] - \beta \cdot D_\mathrm{KL}(\pi_\theta \| \pi_\mathrm{SFT})$

// KL 惩罚防止策略偏离 SFT 基准太远

BT 模型的改进方向：

方法核心改进解决的问题
Preference Transformer注意力权重，关键状态-动作贡献更大均匀权重忽视关键时刻
Regret-based 模型用最优优势之和建模偏好，而非累计奖励奖励与优势混淆
序数反馈扩展多级评分（1-5分）代替二值偏好二值标注丢失程度信息
RLAIF（AI 反馈）LLM 直接生成偏好标签人工标注成本高

EPIC 距离（规范化奖励等价性）：对两个奖励函数 $R_1, R_2$，在潜势函数变换下计算等价性：

$$d_\mathrm{EPIC}(R_1, R_2) = \mathbb{E}\!\left[\left(\tilde{R}_1(s,a,s') - \tilde{R}_2(s,a,s')\right)^2\right]^{1/2}$$

其中 $\tilde{R}$ 为规范化后的奖励（消除潜势函数模糊性），使得等价的奖励函数 EPIC 距离为 0。

7. 奖励 Hacking 与过度优化

Goodhart 定律的 RL 版本：一旦某个度量成为目标，它就不再是好的度量。当智能体过度优化代理奖励模型时，真实性能反而下降——这是 RLHF 面临的核心挑战之一。

奖励 Hacking 的两类来源：

  • 奖励误设计：奖励函数不能精确反映任务目标（如 boat racing 中倒退碰撞反而得高分）
  • 奖励模型过拟合：RLHF 中策略不断优化有限的人类偏好数据训练的奖励模型，最终"欺骗"奖励模型

KL 惩罚是当前最常用的缓解手段：

$$\max_\pi \mathbb{E}[R_\theta(s,a)] - \beta \cdot D_\mathrm{KL}\!\left(\pi \| \pi_\mathrm{ref}\right)$$

8. 核心洞见与读后评注

奖励建模是 AI 对齐的核心问题
从 InstructGPT 到 DeepSeek-R1，奖励模型始终是连接人类意图与智能体行为的关键桥梁。这篇综述揭示了一个深刻事实：奖励模型的质量上限决定了 RL 训练的性能上限——你无法从一个错误的奖励信号中学到正确的行为。
三维分类框架的价值
论文将奖励建模从"来源/机制/范式"三个正交维度分类，这比传统的"RLHF vs IRL vs GCRL"分类更具系统性。尤其是将 AI 生成奖励（RLAIF、LLM 设计奖励函数）单独列为一个来源类别，预示了基础模型在 RL 奖励工程中日益重要的角色。
过程奖励模型（PRM）的崛起
ORM（Outcome Reward Model）只在轨迹末尾给信号，而 PRM 对每个推理步骤单独评分。论文中提到的 Preference Transformer 和 Regret-based 模型都是向 PRM 方向的步骤——这与 FIPO（Future-KL）等近期工作的核心思路高度一致：密集信用分配比稀疏结果奖励更有效。
开放问题：奖励模型的可靠性边界
目前奖励模型训练依赖有限的人类偏好数据，而智能体可能会找到超出人类标注分布的"漏洞"。如何在不增加标注成本的情况下提高奖励模型的可靠性（如通过集成方法、保守奖励估计、或 Constitutional AI 原则）是该领域最核心的开放问题之一。
