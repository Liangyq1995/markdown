1. 核心问题与动机

为什么是"下半场"？
AI "上半场"：以刷基准为目标，单轮/短程任务，性能提升主要来自模型规模扩展。
AI "下半场"：以真实效用为目标，长时程/动态/用户依赖任务，性能瓶颈从"理解能力"转向"记忆与积累"。2025 年记忆相关论文数量呈指数增长，正是这一需求的直接体现。

3. 记忆基底详解

3.1 外部记忆类型对比

格式代表方案适用场景挑战
向量索引RAG / 向量数据库语义检索，大规模知识库随规模增长检索噪声增加
结构存储知识图谱 / 关系型数据库关系推理，多跳问答构建成本高，维护复杂
层次存储MemGPT / MemOS / HippoRAG多级抽象，细粒度访问控制设计复杂，跨层检索延迟
文本记录对话日志 / 摘要简单历史保留token 成本随时程线性增长

3.2 内部记忆类型

类型机制优势局限
参数化记忆知识编入模型权重零延迟访问，推理无开销更新成本极高，灾难性遗忘风险
潜在状态隐藏激活 / KV Cache快速，会话内连贯不跨会话持久化

4. 五类认知记忆机制

认知类型功能角色Agent 实现代表工作
感觉记忆感知输入短暂缓冲多模态流嵌入队列、感知状态缓冲SAM2, ReKV, UBSLLM
工作记忆当前任务临时状态上下文压缩、KV 状态在线维护RAP, MemReasoner, MEM1
情节记忆跨会话的具体经历交互轨迹记录、情景事件库Synapse, COMEDY, JARVIS-1
语义记忆稳定的抽象知识知识图谱、分层语义结构ChatDB, HippoRAG, CAM
程序记忆可执行技能和工作流代码片段、API 调用序列MetaGPT, Voyager, COLT
短期 vs 长期记忆是涌现现象：短期和长期记忆不是独立的架构模块，而是从形成、进化、检索三个过程的时序调用模式中涌现出来的现象——这与认知科学中对记忆的理解一致。

5.1 多 Agent 记忆路由

多 Agent 设置引入了新挑战：记忆路由——哪个 Agent 的记忆应当与哪个 Agent 共享，以及如何在协作中保持记忆一致性。

挑战具体问题代表解法
路由策略谁的记忆与谁共享？G-Memory 三层图层次路由
一致性维护多 Agent 记忆冲突如何解决？KVCA 共识协议
隐私边界用户个人记忆不应跨 Agent 泄露选择性记忆保留 + 用户可控删除

6. 记忆学习策略

策略代表方法特点
提示工程少样本示例、指令优化无需训练，灵活但受限于上下文
微调在记忆操作数据上 SFT固化记忆管理策略，泛化更强
强化学习MemAgent（GRPO）, MEM1（PPO）端到端优化，超越 LLM 内置记忆能力
RL for Memory 的特殊挑战：记忆决策的效果在多步后才体现（稀疏奖励），需要精心设计奖励形成策略。MemAgent 用 GRPO 直接优化摘要质量，MEM1 用 PPO 优化多轮任务成功率——两者证明了 RL 驱动的记忆管理比启发式规则更优。

7. 用户中心 vs Agent 中心记忆

维度用户中心记忆Agent 中心记忆
内容用户偏好、身份、历史承诺Agent 策略、知识、过往经验
目标个性化、对话一致性任务执行能力、自我进化
挑战隐私保护、跨会话漂移策略泛化、技能转移
典型应用个性化助手、推荐系统软件工程、科学发现
隐私风险：用户记忆模块容易受到针对性提取攻击（adversarial extraction），在多 Agent 协作中风险更复杂——需要选择性记忆保留、安全存储和用户可控删除机制。这是"下半场"记忆研究中最被忽视但最重要的问题之一。

8. 核心洞见与读后评注

"下半场"框架的预测力
论文将 AI 发展划分为"上半场"（刷基准）和"下半场"（真实效用）是一个富有洞察的框架。它解释了为什么 GPT-4 级别的模型在推理基准上表现优异，却在需要长期记忆的真实任务（如长期项目助手、个人知识管理）中仍然薄弱——不是能力不足，而是记忆基础设施不足。
三维分类的正交性
基底（在哪里）/ 认知机制（做什么）/ 主体（为谁）三个维度的正交性使得分类体系清晰无交叉。这与传统的"情节/语义/程序"单维分类相比更具操作性——可以直接从三个维度设计系统：选什么存储格式，实现哪种认知功能，服务谁的需求。
