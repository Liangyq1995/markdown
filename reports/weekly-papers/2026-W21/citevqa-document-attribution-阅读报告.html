1. 核心问题与动机：文档智能的可信性危机

随着多模态大语言模型（MLLM）能力的飞速提升，文档问答（Doc-VQA）的准确率已进入一个新的量级——GPT-5.4 在纯答案评估上能达到约 87.1 分。然而这一亮眼数字背后潜藏着一个根本性问题：答案正确，不代表推理过程可靠。

在法律、金融、医疗等高风险场景中，文档问答系统的使用者不仅需要一个正确的结论，更需要知道这个结论来自文档的哪个具体位置。一旦系统给出正确答案却关联错误来源，后果可能是灾难性的：法律从业者基于错误引用作出判断、财务审计遗漏关键凭证页面、临床医生基于错误的病历片段下处方。

"Models frequently produce the right answer while citing the wrong region — a form of pseudo-faithful behavior that answer-only evaluation entirely misses."
— CiteVQA 论文核心发现

当前主流 Doc-VQA 基准（DocVQA、MMLongBench-Doc、SlideVQA 等）均采用答案匹配评分，无论是精确匹配、ANLS 还是 LLM-as-Judge，本质上都只问"结果对不对"，而不问"根据从哪来"。这种评估体系存在两个系统性盲点：

  • 幸运正确（Lucky Correct）：模型可能通过参数化记忆或领域先验知识直接猜出答案，而非真正在文档中定位证据。
  • 归因幻觉（Attribution Hallucination）：模型从文档中找到了答案，但引用的证据位置（页面、元素、坐标）与真实来源完全不一致，暗示其推理链条存在根本性错误。

CiteVQA 的核心价值在于将评估粒度从答案层面下探到元素层面（element-level），要求模型以边界框坐标（bounding-box）的形式标注证据来源，从而精确量化归因幻觉的普遍程度。这一设计理念与 RAG（Retrieval-Augmented Generation）评估中的 Citation Faithfulness 工作遥相呼应，但将应用场景从纯文本扩展至复杂多页 PDF 文档。

从行业应用视角看，该工作提出的 SAA 指标可以直接用于企业级文档 AI 系统的上线质检：只有当一个系统在特定文档集上通过了 SAA 评估，才意味着其输出既准确又可溯源，真正满足合规审计需求。

2.2 引用与归因评估的相关工作

在纯文本 RAG 领域，已有 WebGPT、MRAMG、RARE 等工作尝试评估生成答案的来源可信度，但这些方法均基于段落级（passage-level）匹配，无法应用于需要精确定位页面坐标的 PDF 文档场景。CiteVQA 将引用粒度细化到边界框像素坐标级别，是文档智能领域的首次系统性尝试。

CharXiv 和 ChartQA 关注图表理解，但同样不要求模型输出图表在页面中的坐标位置。从技术工具链看，CiteVQA 的构建依赖于 MinerU 2.5 的高精度 PDF 解析能力——它能将任意 PDF 页面解析为结构化的 (doc_id, page_idx, bbox, OCR_text) 四元组，为边界框级别的证据标注奠定基础。

2.3 现有指标的三大不足

不足一：答案匹配盲目性。 ANLS（Average Normalized Levenshtein Similarity）和精确匹配只度量字符串相似度，无法捕捉模型是否真正在文档中执行了信息定位。一个完全依赖参数记忆的模型与一个真正阅读文档的模型在这些指标上可能得分相同。

不足二：LLM-as-Judge 的盲区。 即便使用更强的模型评判答案质量，评判模型也仅看到"问题 + 预测答案 + 参考答案"，缺乏对文档实际内容的感知，无法判断答案来源是否合规。

不足三：缺乏位置感知。 即使文档被全文输入模型，现有评估也不要求模型输出具体的证据位置，因此无法量化模型对文档结构的理解深度——是真正理解了文档布局，还是借助语言模式做了表面匹配。

3. CiteVQA 基准设计

CiteVQA 的构建是一个精心设计的五阶段流水线，每个阶段都针对文档智能评估的核心痛点进行了专项设计。整个流程从 1 亿以上的原始 PDF 池出发，经过多轮筛选、链接、证据提取和质量控制，最终产出高质量的双语问答对，并为每道题标注精确的元素级证据边界框。

3.1 文档采集与领域均衡

从 Common Crawl 的 1 亿以上 PDF 中，通过分层采样策略选取约 25 万份候选文档，再经过两阶段 MLLM 标注（粗粒度领域 → 细粒度子类别）筛选出最终的 711 份文档。这 711 份文档覆盖 7 大宏观领域和 30 个子类别，其中英文 451 份（63.4%）、中文 260 份（36.6%），实现了语言维度的双语覆盖。

3.2 多文档链接策略

为了构建多文档推理场景，每份文档首先由 MLLM 生成语义摘要作为 Profile。随后通过密集向量检索（Dense Retrieval）找到每份文档的 Top-5 语义相似候选，再由 LLM 执行链式思考（Chain-of-Thought）跨文档章节对齐，输出包含相似度分数的结构化关联组。最终形成三类问题场景：单文档（52.0%）、多文档单金答案（25.7%）、多文档多金答案（22.3%）。

3.3 关键证据识别：逐元素 Masking 消融

CiteVQA 最具创新性的部分之一是关键证据（Crucial Evidence）的自动化识别机制。对 Evidence Package 中的每个边界框元素，系统逐一将其从上下文中遮蔽，然后重新调用模型回答问题。若遮蔽某元素后模型无法正确回答，则该元素被标记为关键证据。这种消融式验证方法确保了标注的因果性——而非仅仅的相关性。

3.4 质量控制四道门

  • 可答性验证：仅呈现证据截图，重新让模型回答；失败的 QA 对直接丢弃，确保每道题都有充分的文档支撑。
  • 问题改写：原始问题由 MLLM 进行语言多样化改写，避免问题措辞与文档原文过度相似（防止字符串匹配捷径）。
  • 相关性过滤（零文档自测）：不给模型任何文档内容，直接回答问题；若模型仍能答对，则认为该题是常识题而非文档依赖题，予以剔除。过滤模型为 Qwen3-VL-235B。
  • 专家人工复核：自动化流程完成后，由领域专家对高风险类别（法律、医疗）的问题进行抽样复核，确保标注质量。

4. 关键技术详解

4.1 SAA 指标的数学定义

Strict Attributed Accuracy（SAA）是 CiteVQA 的核心评估指标，其设计哲学是：只有答案正确且引用位置也正确的预测，才计为一次成功的文档智能。这是对传统答案匹配指标的严格扩展。

SAA 联合判定条件：

$$\text{SAA} = \mathbf{1}\!\left(\text{Ans} \geq 4 \;\wedge\; \left(\text{Rel} \geq 4 \;\vee\; \text{Rec} \geq 0.6\right)\right)$$

各分量的含义如下：

  • Ans（Answer Score，答案评分）：由 LLM-as-Judge 对预测答案的正确性在 1–5 分制上打分。阈值设为 4 分，即答案基本正确。
  • Rel（Relevance Score，相关性评分）：LLM-as-Judge 判断预测的引用区域文本与问题的语义相关程度，1–5 分制，阈值 4 分。
  • Rec（Bounding Box Recall，边界框召回率）：预测边界框与关键证据边界框的 IoU 匹配率，阈值 0.6（即至少 60% 的关键证据元素被正确定位）。

SAA 条件采用 OR 逻辑 组合 Rel 和 Rec 两个引用质量指标，体现了对引用验证的宽容性设计：只要语义相关 或 空间定位准确，引用即认为合格。这种设计避免了对无法精确输出坐标的纯语言模型的过度惩罚，同时保留了对引用完全错误情况的惩罚。

4.2 边界框级别引用评估机制

边界框评估是 CiteVQA 区别于一切前驱工作的核心技术细节。系统将每个证据元素表示为归一化坐标四元组 $(x_1, y_1, x_2, y_2)$，其中所有坐标均相对于页面尺寸归一化至 $[0, 1]$ 区间。

关键证据召回率（元素级）：

$$\text{Rec} = \frac{1}{|\mathcal{B}_{\text{crucial}}|} \sum_{b_{gt} \in \mathcal{B}_{\text{crucial}}} \mathbf{1}\!\left(\max_{b_{pred}} \text{IoU}(b_{pred},\, b_{gt}) \geq 0.5\right)$$

引用精确率（防幻觉惩罚）：

$$\text{Prec} = \frac{1}{|\mathcal{B}_{pred}|} \sum_{b_{pred} \in \mathcal{B}_{pred}} \mathbf{1}\!\left(\max_{b_{gt} \in \mathcal{B}_{all}} \text{IoU}(b_{pred},\, b_{gt}) \geq 0.5\right)$$

F1 综合得分：

$$F_1 = \frac{2 \cdot \text{Prec} \cdot \text{Rec}}{\text{Prec} + \text{Rec}}$$

值得注意的是，Rec 仅对关键证据集 $\mathcal{B}_{\text{crucial}}$ 计算，而 Prec 对全部证据集 $\mathcal{B}_{all}$（含非关键证据）计算。这种非对称设计合理地区分了两种误差：漏掉关键证据（低召回）和胡乱引用无关区域（低精确）。此外，系统还引入页面级别召回（Page-level Recall）作为辅助指标，仅要求预测的页码与关键证据所在页码一致，无需精确定位空间坐标，适用于仅能输出页码而非坐标的模型。

Algorithm 1: 关键证据元素识别（Masking Ablation）

Input: Evidence Package $\mathcal{E} = \{e_1, e_2, \ldots, e_n\}$，问题 Q，参考答案 A*，判定阈值 θ = 4

crucial ← ∅ // 初始化关键证据集合

for i = 1 to n do

E_masked ← E \ {e_i} // 遮蔽第 i 个元素

A_pred ← MLLM(Q, E_masked)

score ← LLM_Judge(A_pred, A*)

if score < θ then

crucial ← crucial ∪ {e_i} // 遮蔽后失效 → 关键证据

end if

end for

return crucial // 带 bbox 坐标的关键证据集

4.3 问题类型设计：四大模板

CiteVQA 将问题类型归纳为四大模板，覆盖从浅层检索到深层推理的完整能力谱系：

模板类型描述典型难度
事实性检索（Factual Retrieval）从文档中直接定位并提取具体数值、日期、人名等事实性信息低
复合综合（Complex Synthesis）需要整合文档多处信息进行综合推断，往往涉及跨节归纳中
数量推理（Quantitative Reasoning）基于文档中的数值数据进行计算、比较或统计分析中-高
多模态解析（Multimodal Parsing）需要理解文档中的图表、表格、公式等非文本元素高

5. 实验结果分析

5.1 整体 SAA 排行榜（20 个 MLLM）

论文对 20 个主流多模态大语言模型进行了系统性评估，涵盖 Gemini 系列、GPT 系列、Qwen-VL 系列、Gemma 系列等闭源与开源代表。评估结果揭示了令人警惕的归因幻觉现象——几乎所有模型的 SAA 分数都显著低于纯答案准确率（Ans 分数），且差距随模型能力下降而急剧扩大。

蓝色=闭源模型，绿色=开源模型。答案准确率(Ans)与SAA之差即为归因幻觉Gap。

5.3 场景难度对 SAA 的影响

三种场景的难度梯度非常明显：从单文档到多文档多金答案，所有模型的 SAA 分数均呈显著下降趋势。这表明当前 MLLM 在跨文档信息整合与多位置引用方面存在系统性能力缺口。

6. 归因幻觉深度分析

归因幻觉（Attribution Hallucination）是 CiteVQA 揭示的核心现象，也是当前 MLLM 在文档智能领域最严重的可靠性问题之一。与传统"幻觉"（模型编造不存在的事实）不同，归因幻觉的隐蔽性更高——模型给出了客观正确的答案，但无法（或错误地）指出答案在文档中的来源位置，呈现出一种"结果正确、过程虚假"的伪忠实行为。

"归因幻觉的危险性恰恰在于其隐蔽性：传统评估指标无法发现它，终端用户也难以察觉——直到在高风险场景下引发实质性错误。"

6.2 Ans–SAA Gap 的系统性分析

Ans–SAA Gap 是量化归因幻觉的核心指标。从实验数据来看，这一 Gap 呈现以下规律：

  • 模型越强，Gap 越小但不为零：Gemini-3.1-Pro 的 Gap 仅 10.1，表明顶级闭源模型在某种程度上已经在学习端到端的证据定位，但仍有约 10% 的"幸运正确"无法被证伪。
  • 开源模型 Gap 普遍更大：Qwen3-VL-235B 的 Ans 分数（72.3）与 SAA（22.5）相差近 50 分，说明开源模型目前主要依靠语言模式而非文档定位来回答问题。
  • 小模型的归因能力几乎完全崩溃：Qwen3-VL-8B 的 SAA 仅 7.5，意味着即使给出了正确答案，也有超过 87% 的情况无法正确定位来源。

6.3 归因幻觉与文档场景的交互效应

归因幻觉在不同文档场景下的表现差异显著。在多文档多金答案（Multi N-Gold）场景中，模型不仅需要从多份文档中分别定位证据，还需要判断哪些文档相关、哪些不相关，归因任务的复杂度呈指数级上升。实验数据显示，几乎所有模型在 Multi N-Gold 场景下的 SAA 都接近单文档场景的 1/3 甚至更低，证实了当前 MLLM 在跨文档归因能力上的系统性短板。

领域层面同样存在显著差异。学术技术类（含大量公式和图表）与工业建筑类（含大量结构图和规范表格）的归因难度最高，主要原因是这些领域的关键信息往往以非文本形式（方程、示意图）呈现，而当前 MLLM 对非文本内容的空间定位能力明显弱于纯文本。

7. 核心洞见与读后评注

洞见 1：答案准确率是不可信的单一指标

CiteVQA 最重要的贡献不是给出一个新的排行榜，而是揭示了一个范式性问题：在没有引用验证的情况下，答案准确率评估存在根本性缺陷。即便是顶级的 GPT-5.4，也有约 32% 的"正确答案"无法被文档证据所支撑。这意味着所有依赖纯答案评估来部署文档 AI 系统的组织，都面临着系统性的可信度风险。

洞见 2：闭源与开源之间存在不可忽视的能力代差

最强闭源模型（Gemini-3.1-Pro SAA 76.0）与最强开源模型（Qwen3-VL-235B SAA 22.5）之间存在超过 50 分的 SAA 差距。这一差距在答案准确率上并不明显（86.1 vs 72.3），说明开源模型在语言理解层面与闭源模型的差距相对较小，但在空间感知与文档结构理解层面存在显著短板。这一发现对开源模型的训练方向具有重要指导意义。

洞见 3：Masking Ablation 是一种通用的关键证据标注方法

逐元素遮蔽消融的关键证据识别机制不仅适用于 CiteVQA，更是一种可推广的标注方法论。在任何需要"因果性证据标注"的场景中——无论是法律条文归因、财务数据溯源还是医学文献引用——这种基于模型行为的自动化标注都比人工标注更具一致性和可扩展性。

洞见 4：SAA 指标可以直接用于系统级质量门控

对企业应用而言，SAA 可以作为文档 AI 系统上线的质量门槛指标。一个 SAA 低于 40 的系统，意味着超过 60% 的查询无法提供可信来源，不应被部署在法律合规、金融审计等场景。相比之下，Gemini-3.1-Pro 的 76.0 SAA 意味着其输出具有相对较高的可信度，适合作为辅助审核工具。

洞见 5：双语覆盖揭示中英文能力差异

CiteVQA 包含中文文档 260 份，这是目前文档归因评估中罕见的中文大规模覆盖。从数据分布看，中文文档占比约 36.6%，能够反映模型在中文专业文档（尤其是政府法规、医疗报告）上的归因能力。中英文场景的性能差异是未来研究的重要方向。

评注：这篇工作的局限性

尽管 CiteVQA 体量可观（1,897 题），但与大规模预训练数据集相比仍属小规模，且 30 个子类别在每类上的样本量相对有限。此外，关键证据的 Masking Ablation 依赖于一个"参考模型"（Qwen3-VL-235B）——若参考模型本身存在系统性偏差，标注质量会受到影响。评估框架对"只能用整页截图而非 bbox 坐标定位的模型"的惩罚也略显不公平，尽管可选的页面级召回指标部分缓解了这一问题。
