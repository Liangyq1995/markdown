Weak-to-Strong Generalization via Direct On-Policy Distillation

1. 概述

标题Weak-to-Strong Generalization via Direct On-Policy Distillation
核心问题RLVR 提升推理但每个强模型都要重跑大量 rollout，代价高昂；如何在小模型上跑 RL，再把所学迁移到强模型，且不被弱教师的能力上限所拖累。
开源地址https://bytedtsinghua-sia.github.io/Direct-OPD/
机构清华大学 AIR 研究院（SIA-Lab, Tsinghua AIR & ByteDance Seed）、清华大学计算机系、北京大学

论文提出 Direct On-Policy Distillation (Direct-OPD)，一种弱→强的后训练范式：在 rollout 更便宜的小模型上跑 RL，再把 RL 学到的"策略漂移"迁移到强学生。核心洞察是——不要迁移弱教师的最终策略（它把有用的 RL 收益与小模型的能力上限耦合在一起），而是迁移 RL 引发的策略漂移，即 post-RL 教师 $\pi_T$ 与其 pre-RL 参考 $\pi_{T}^{\mathrm{ref}}$ 的 log-ratio，把它当作作用在强学生 on-policy 状态上的 dense implicit reward。

这一信号直接复用了弱模型的 RL 监督，无需在目标模型上跑稀疏奖励 RL，也无需训练显式 reward model。关键结果：

  • 跨教师对（JustRL、QuestA）与学生家族（Qwen3、R1-Distill）一致提升，包括初始已超过 post-RL 教师的学生：Qwen3-1.7B 在 AIME 2024 上从 48.3 → 58.3 (+10.0)，Qwen3-4B 72.5 → 77.6，R1-Distill-7B 56.7 → 63.1。
  • 仅需 8×A100 约 4 小时的迁移阶段，即可达到 Polaris 直接在 Qwen3-1.7B 上跑 RL（32×A100 ≥1 周）的水平。
  • 在 matched-step 下，"小模型 RL + Direct-OPD 迁移"在精度与算力上均击败直接在 R1-Distill-7B 上跑 RL。
  • 两个独立学到的策略漂移可顺序组合，累加收益：Qwen3-1.7B 在 AIME 2024 上 48.3 → 58.3 → 63.8（累计 +15.5）。

2. 研究背景与动机

2.1 RLVR 的成本困境

RLVR（Reinforcement Learning with Verifiable Rewards）已成为激发 LLM 推理的主流后训练配方 [1,2,9-17]。其代价与被训练模型绑定：每次更新都要求当前策略生成 rollout、获取可验证结果分数、再基于轨迹更新。目标模型越大，单次 rollout 越慢、单步 RL 迭代越贵。当推理模型持续 scaling 时，为每个新强模型从零重跑 RLVR 会让后训练本身成为瓶颈。这正是本文动机的起点。

2.2 三条相关研究脉络

脉络一：推理模型的 on-policy 蒸馏（OPD）。 OPD 让学生在自己采样的状态上接受教师监督，已成为推理模型蒸馏的主导变体 [5,8,40-57]，还有与 RL 耦合的混合方案 [51,58-62]。已有分析将 OPD 成功归因于学生访问状态上师生 top-k 重叠 [5]，指出小模型难以复制强推理器 [63]，并将 OPD 重解释为 dense KL-constrained RL，通过奖励缩放外推超越教师 [64]。这些方法的共同点是：模仿或外推教师的"最终策略"。当教师是弱于目标的小 post-RL 模型时，这会把教师的能力上限也一并塞给学生。

脉络二：弱到强泛化。 弱到强泛化研究弱监督能否激发强模型能力 [65,66]，源于半监督与噪声标签学习 [67-76]，是 scalable oversight 的核心 [77-82]，并与 ELK、easy-to-hard 泛化相关 [83-86]。多数方法仍用弱模型的标签或分布监督，把学生封顶在监督者水平；self-rewarding 方案 [92] 用自身判断 bootstrap；与本文最接近的是 weak-to-strong preference optimization [93]，复用弱对齐模型的隐式奖励来引导强模型。本文同样追求"激发而非模仿"，但监督源是一对小 RL checkpoint。

脉络三：隐式奖励与训练模型复用。 Direct-OPD 基于 policy-as-reward 恒等式：KL 正则化 RL 下，策略/参考的 log-ratio 在常数意义下恢复奖励，这正是 DPO 及其变体 [6,94-96] 用以从偏好直接拟合策略的恒等式。本文反向使用该恒等式——从 post-RL checkpoint 及其参考读出 dense 隐式奖励，连接到推理的 dense/process reward [97-99] 与逐 token credit assignment [100,101]，并规避显式 reward model 的 over-optimization [102]。另一条互补路线在权重空间复用模型——task arithmetic、model merging、proxy tuning [103-105]；Direct-OPD 的信号是行为 log-ratio 而非权重 delta，且作用在学生自己的 on-policy 状态上，因此能跨家族、跨尺度迁移。

整体数据流分两阶段：(1) 廉价的小模型 RL——在小模型上跑 GRPO，得到一对 checkpoint（pre-RL 参考 $\pi_{T}^{\mathrm{ref}}$ 与 post-RL 教师 $\pi_T$）；(2) Direct-OPD 迁移——用这对 checkpoint 的 log-ratio 作为 dense 隐式奖励，作用在强学生自己采样的 on-policy 状态上，并用 KL 项把学生锚定在自身初始化 $\pi_S$。整个迁移只需短训练（默认 300 步），且因教师模型很小，打分不是速度瓶颈。

3.2 预备：On-Policy Distillation (OPD)

设自回归语言模型策略对 prompt $x$ 与响应 $y=(y_1,\dots,y_T)$ 分解为 $\log \pi(y \mid x)=\sum_{t=1}^{T} \log \pi(y_t \mid s_t)$，前缀 $s_t = (x, y_{\lt t})$。论文区分四个策略：被训练策略 $\pi_\theta$ 与其初始 checkpoint $\pi_S$；以及一对教师——pre-RL 参考 $\pi_{T}^{\mathrm{ref}}$ 与 post-RL 教师 $\pi_T$。弱→强设定下 $\pi_T$ 可能比目标学生更小更弱，但从 $\pi_{T}^{\mathrm{ref}}$ 到 $\pi_T$ 的转移仍编码了值得迁移的信息。

OPD 在学生自采样的轨迹上监督学生。给定 prompt $x$，学生采样 $\hat{y} \sim \pi_\theta(\cdot \mid x)$，在每个访问前缀读取学生与教师的下一 token 分布 $p_t(v)=\pi_\theta(v \mid s_t)$ 与 $q_t(v)=\pi_T(v \mid s_t)$。标准 OPD 最小化到教师的序列级 KL：

$$L_{\mathrm{OPD}}(\theta) = \mathbb{E}_{x \sim \mathcal{D}}\left[ D_{\mathrm{KL}}(\pi_\theta(\cdot \mid x) \| \pi_T(\cdot \mid x)) \right]$$

它精确分解为学生在实际访问状态上的 dense 逐 token 监督：

$$L_{\mathrm{OPD}}(\theta) = \mathbb{E}_{x \sim \mathcal{D},\, \hat{y} \sim \pi_\theta}\left[ \sum_{t=1}^{T} D_{\mathrm{KL}}(p_t \| q_t) \right]$$

实践中只在学生 top-k 支持 $S_t = \mathrm{TopK}_v\, p_t$ 上查询教师，得到局部估计：

$$L_{\mathrm{OPD}}^{\mathrm{top\text{-}k}}(\theta) = \mathbb{E}\left[ \sum_{t=1}^{T} D_{\mathrm{KL}}(\bar{p}_t^{S_t} \| \bar{q}_t^{S_t}) \right]$$

其中 $\bar{p}_t^{S_t}$、$\bar{q}_t^{S_t}$ 在 $S_t$ 上重归一化 [5]。该 top-k KL 估计产生含师生 log-ratio $\log q_t(v) - \log p_t(v)$ 的 dense 逐 token 信号。Direct-OPD 原封不动地继承这一 on-policy、top-k 接口，唯一改变的是从教师读出的信号。

3.3 策略漂移作为隐式奖励（核心推导）

迁移什么。 Direct-OPD 不模仿教师的绝对输出分布，而迁移其 RL 引发的策略漂移——post-RL 教师 $\pi_T$ 与 pre-RL 参考 $\pi_{T}^{\mathrm{ref}}$ 的序列级 log-ratio：

$$\Delta_T(y \mid x) = \log \pi_T(y \mid x) - \log \pi_{T}^{\mathrm{ref}}(y \mid x)$$

该减法丢弃了弱模型在 RL 前已有的偏好，只保留 RL 改变的部分：$\Delta_T$ 在 RL 提升概率的响应上为正，在被抑制的响应上为负。这一漂移并非任意启发式：在 KL 正则化 RL 的 policy-as-reward 视角下，它可解释为教师的隐式奖励。

推导（policy-as-reward 恒等式）。 对奖励 $r$、参考策略 $\pi_{\mathrm{ref}}$ 与惩罚 $\beta \gt 0$，KL 正则化目标

$$\max_\pi \, \mathbb{E}_{y \sim \pi}\left[ r(x,y) - \beta \log \frac{\pi(y \mid x)}{\pi_{\mathrm{ref}}(y \mid x)} \right]$$

有闭式最优 $\pi^{*} \propto \pi_{\mathrm{ref}} \exp(r/\beta)$，因此

$$\log \frac{\pi^{*}(y \mid x)}{\pi_{\mathrm{ref}}(y \mid x)} = \frac{1}{\beta} r(x,y) - \log Z(x)$$

由于 $\log Z(x)$ 对同一 prompt 的所有响应是常数，策略/参考 log-ratio 在正尺度与 per-prompt 常数意义下恢复了奖励。这正是 DPO [6] 背后的恒等式。论文反向使用：给定 post-RL 教师 $\pi_T$ 与其 pre-RL 参考 $\pi_{T}^{\mathrm{ref}}$，把 $\pi_T$ 视作锚定在 $\pi_{T}^{\mathrm{ref}}$ 的某个隐式奖励 $r_T$ 的 KL 正则化最优，于是漂移 $\Delta_T$ 可解释为教师的隐式奖励：

$$\Delta_T(y \mid x) = \frac{1}{\beta} r_T(x,y) - \log Z_T(x)$$

Direct-OPD 把这一 reward-like 信号迁移给学生。注意其幅度 $\frac{1}{\beta} r_T$ 由教师训练时的 KL 预算 $\beta$ 决定，且无法从 checkpoint 对中恢复——这正是后续需要自适应 KL 的根源。

3.4 Direct-OPD 目标与最优解

理想化序列级目标。 学生从 $\pi_S$ 初始化，Direct-OPD 在教师漂移信号 $\Delta_T$ 上优化学生，同时把学生正则向自身初始化：

$$J_{\mathrm{Direct\text{-}OPD}}(\theta) = \mathbb{E}_{x \sim \mathcal{D}}\left[ \mathbb{E}_{y \sim \pi_\theta(\cdot \mid x)}\left[\Delta_T(y \mid x)\right] - \alpha D_{\mathrm{KL}}(\pi_\theta(\cdot \mid x) \| \pi_S(\cdot \mid x)) \right]$$

其中 $\alpha \gt 0$ 控制 KL 惩罚。这一理想形式本身就是一个关于学生的 KL 正则化 RL 目标，其最优为：

$$\pi^{*}(y \mid x) \propto \pi_S(y \mid x) \exp\left(\frac{1}{\alpha} \Delta_T(y \mid x)\right) = \pi_S(y \mid x) \left(\frac{\pi_T(y \mid x)}{\pi_{T}^{\mathrm{ref}}(y \mid x)}\right)^{1/\alpha}$$

代入 Eq.7 的隐式奖励形式得 $\pi^{*} \propto \pi_S \exp(r_T / \alpha\beta)$。学生等价于在用小教师的隐式奖励跑 KL 正则化 RL，但以自身初始化 $\pi_S$ 为参考——而该 reward-like 信号完全来自 checkpoint 对，无需查询可验证奖励或在目标上跑稀疏奖励 RL。

从序列到 token 级。 由于两个教师都在相同前缀上自回归分解，序列漂移精确分解为 token 级漂移之和：

$$\Delta_T(y \mid x) = \sum_{t} r_t(y_t \mid s_t), \qquad r_t(v) = \log \pi_T(v \mid s_t) - \log \pi_{T}^{\mathrm{ref}}(v \mid s_t)$$

于是 $r_t(v)$ 可视为 dense 即时逐 token 奖励：$r_t(v) \gt 0$ 处教师 RL 鼓励 token $v$，$r_t(v) \lt 0$ 处抑制它。实践中使用对应的零折扣 token 级代理，按即时漂移 $r_t(v)$ 而非未来回报给每个候选 token 计分，复用 §3.2 的 on-policy、top-k 接口。

3.5 Top-k 解析梯度与 stop-gradient

Top-k 动作空间限制。 在每个访问前缀限制到学生 top-k 支持 $S_t = \mathrm{TopK}_v\, \pi_\theta(v \mid s_t)$ 并在其上重归一化学生概率：

$$\bar{p}_t(v) = \frac{\pi_\theta(v \mid s_t)}{\sum_{u \in S_t} \pi_\theta(u \mid s_t)}, \quad v \in S_t$$

解析 top-k 策略梯度。 即时 per-token 奖励 $r_t(v)$ 只依赖教师对，故直接用作局部优势。单样本 token 级策略梯度会给被采样 token 的对数似然加权即时奖励：

$$\nabla_\theta J_{\mathrm{MC}} = \mathbb{E}_{x,y}\left[ \sum_{t} r_t(y_t)\, \nabla_\theta \log \pi_\theta(y_t \mid s_t) \right]$$

但每步只用一个 token 估计方差很大。由于在每个访问前缀已有完整 top-k 奖励与概率，用其在限制分布 $\bar{p}_t$ 上的期望替代单 token 估计，即在仍采样轨迹 $y \sim \pi_\theta$ 的同时对每步动作 Rao–Blackwell 化：

$$\nabla_\theta J_{\mathrm{analytical}} = \mathbb{E}_{x,\, y \sim \pi_\theta}\left[ \sum_{t} \sum_{v \in S_t} \underbrace{\bar{p}_t(v)}_{\text{weight}} \, \underbrace{r_t(v)}_{\text{reward}} \, \underbrace{\nabla_\theta \log \pi_\theta(v \mid s_t)}_{\text{log-likelihood}} \right]$$

这给出限制 top-k 动作分布下的 Rao–Blackwell 化每步估计：消去 $\nabla_\theta J_{\mathrm{MC}}$ 的 token 采样方差，同时保持采样轨迹分布不变。

Stop-gradient 系数。 为使该代理匹配策略梯度形式，权重 $\bar{p}_t(v)$ 必须仅以标量进入。它通过学生 softmax 依赖 $\theta$，若对其求导会注入来自 top-k 分布的额外 Jacobian 项。因此把加权奖励 detach 为静态系数：

$$A_t^{w}(v) = \mathrm{stop\_gradient}\left(\bar{p}_t(v) \cdot r_t(v)\right)$$

给出零折扣目标的最终局部 top-k 代理：

$$\nabla_\theta J_{\mathrm{Direct\text{-}OPD}} \approx \mathbb{E}_{x \sim \mathcal{D},\, y \sim \pi_\theta}\left[ \sum_{t} \sum_{v \in S_t} A_t^{w}(v)\, \nabla_\theta \log \pi_\theta(v \mid s_t) \right] - \alpha \nabla_\theta D_{\mathrm{KL}}(\pi_\theta(\cdot \mid x) \| \pi_S(\cdot \mid x))$$

实践中不对 KL 解析求导，而是用 verl 中的标准 KL-penalty 实现把 $\pi_\theta$ 锚定到 $\pi_S$。

3.6 自适应 KL 控制

Direct-OPD 迁移的奖励带有一个它无法选择的尺度。由 Eq.7，$\Delta_T = \frac{1}{\beta} r_T - \log Z_T$：其幅度是教师奖励除以教师 KL 预算 $\beta$，二者在教师训练时固定、编码在 $\pi_T$ 偏离 $\pi_{T}^{\mathrm{ref}}$ 的程度中，且都无法从 checkpoint 对恢复。per-token 漂移 $r_t(v)$ 同样只依赖教师对；学生仅通过"信号在哪里读出"（rollout 访问的前缀与每个前缀保留的 top-k 动作）进入。

从 Eq.9 最优 $\pi^{*} \propto \pi_S \exp(\frac{1}{\alpha}\Delta_T)$ 看，$\alpha$ 是 $\pi_S$ 的指数倾斜温度，只有相对 $\Delta_T$ 的尺度才有意义。但 $\Delta_T$ 处于教师奖励单位（$\frac{1}{\beta} r_T$），而 $\alpha$ 是学生 KL 上的系数——两个尺度没有先验换算，教师的尺度不可观测。因此单一 $\alpha$ 无法跨教师-学生对预先标定，论文采用轻量控制器按 dense 信号运行尺度自适应 $\alpha$。

设 $\alpha_m$ 为第 $m$ 次迭代的 KL 系数，$\bar{r}_m$ 为学生加权漂移 $\bar{p}_t(v) r_t(v)$ 在访问前缀及其 top-k 候选上的 batch 级均值——即梯度所优化的同一 dense 奖励。在 actor 更新前：

$$\alpha_{m+1} = \mathrm{clip}\left(\alpha_m \,(1 + \epsilon \cdot \mathrm{sgn}(\bar{r}_m)),\; \alpha_{\min},\; \alpha_{\max}\right)$$

其中 $\mathrm{sgn}(0)=0$；默认 $\epsilon=0.01$，$[\alpha_{\min}, \alpha_{\max}] = [0.5, 2.5]$。$\mathrm{sgn}(\bar{r}_m)$ 报告在学生当前访问的前缀上，教师 RL 平均是提升还是压低了保留的候选 token——一个学生加权漂移直接携带的 batch 级符号。当平均漂移为正，控制器提高 $\alpha$ 以抑制过度放大该局部信号；为负则降低 $\alpha$，放松锚定使 dense 梯度能把概率从教师 RL 降低的 token 上移走。这与标准针对 in-reward KL 惩罚的自适应控制器（驶向目标 KL 值）不同：此处的更新由 Direct-OPD dense 奖励的符号驱动，作用于显式 actor KL loss 系数。

3.7 训练算法伪代码

Algorithm 1: Direct-OPD 训练（单次迭代）

Input: 教师 checkpoint 对 (pi_T, pi_Tref)；学生初始化 pi_S；数据集 D；KL 系数 alpha；自适应率 epsilon=0.01；top-k=16；响应长度 2048；训练步数 300

# 阶段一已完成：在小模型上跑 GRPO 得到 (pi_Tref, pi_T)

for iteration m = 1 to 300 do

采样 prompt x ~ D（Skywork-OR1 数学子集，DAPO 模板）

学生 on-policy rollout：y ~ pi_theta(. | x)， rollout n = 4

for 每个访问前缀 s_t in y do

S_t = TopK(pi_theta(. | s_t), 16) # 学生 top-k 支持

p_bar_t(v) = pi_theta(v|s_t) / Sum_{u in S_t} pi_theta(u|s_t), v in S_t # 重归一化

r_t(v) = log pi_T(v|s_t) - log pi_Tref(v|s_t) # 逐 token 隐式奖励

A_w_t(v) = stop_gradient(p_bar_t(v) * r_t(v)) # 加权优势，停止梯度

end for

梯度 g = Sum_t Sum_{v in S_t} A_w_t(v) * Grad_theta log pi_theta(v|s_t) - alpha * Grad_theta D_KL(pi_theta || pi_S)

r_bar_m = batch 均值 of p_bar_t(v) * r_t(v) over 访问前缀与 top-k

alpha ← clip(alpha × (1 + epsilon × sgn(r_bar_m)), 0.5, 2.5) # 自适应 KL

更新 theta（verl，LR = 1e-6）

end for

Output: 增强后的强学生 pi_theta

4. 实验结果与分析

论文围绕三个研究问题展开：RQ1 小教师的策略漂移能否提升已达到或超过教师能力的学生，且跨教师对/学生家族是否成立；RQ2 在固定 RL 步预算下，小模型 RL + Direct-OPD 是否在精度与算力上击败直接在大目标上跑 RL；RQ3 多个独立策略漂移能否顺序组合累加收益。

4.1 主实验：弱教师提升更强学生

4.2 弱到强击败直接 RL（算力与精度）

比较两条 matched-step 路线：direct-RL 路线直接在 R1-Distill-7B 上跑 RL；弱→强路线先在更小的 R1-Distill-1.5B 上跑 RL，再用 Direct-OPD 把得到的 RL/参考策略漂移迁移进 R1-Distill-7B。在 DAPO 数据集上训练 R1-Distill-1.5B，选取第 300/600/900/1200/1500 步 RL checkpoint 作为 $\pi_T$、base R1-Distill-1.5B 作 $\pi_{T}^{\mathrm{ref}}$ 构成教师对，再训练 R1-Distill-7B 并与 matched small-teacher RL step 的直接 R1-Distill-7B RL 比较（记号 T300…T1500）。

结论： 在相同 RL 步数下，小模型 RL + Direct-OPD 迁移在精度与算力上均优于直接在 R1-Distill-7B 上跑 RL；较晚的迁移点（T600–T1500）在可比耗时下位于 direct-RL 曲线之上。Qwen3 nonthinking 上同样：1.7B 跑 100 步 RL 后迁移到 Qwen3-4B-nonthinking，在 AIME 2025 上达到直接 Qwen3-4B RL 的 0.635 水平。

4.4 消融与分析

4.4.1 跨思维模式迁移：无需 token 重叠模仿

标准 OPD 认为师生思维模式兼容是成功关键——成功 OPD 体现在学生访问状态上高概率 token 的逐步对齐，少量共享 top-k token 集承载大部分概率质量 [5]。这对原始教师模仿是自然的，因为学生被要求匹配教师最终分布。Direct-OPD 改变了迁移对象：它不匹配 post-RL 教师分布，而是在学生访问的候选 token 上评估教师/参考 log-ratio。该信号能在学生自己的支持内对动作排序，因此有用迁移不必要求学生进入教师的高重叠 token 区。

per-state 重叠率定义为（$S$ 为学生、$C$ 为比较策略）：

$$\mathrm{Overlap}_k(S, C; s_t) = \frac{|T_k^{S}(s_t) \cap T_k^{C}(s_t)|}{k}$$

论文报告该指标对 post-RL 教师（$C=T$）与教师参考（$C=T_{\mathrm{ref}}$）的值。结果：模式对齐的 R1-Distill 迁移进入更高重叠区（符合标准 OPD 直觉）；而跨模式迁移与 post-RL 教师的重叠保持较低，且与教师参考的重叠也没有补偿性上升——即 Figure 2 的增益不能由对任一教师 checkpoint 的逐步模仿解释，而由"在学生访问 token 上使用 reference→post-RL 教师的 RL 方向"更好解释。同时 actor 熵保持受控、不崩塌，教师/参考熵差收窄，佐证同一机制。

4.4.2 短视野训练改变长 rollout 行为

论文刻意用短 2k token 响应视野训练，考察策略变化是否超越直接监督的前缀。对每个响应前缀 $x_{\le t}$，取 actor top-16 集合 $K_t$，计算 actor 概率加权的教师 gap：

$$g_t = \sum_{a \in K_t} \pi_{\mathrm{actor}}(a \mid x_{\le t}) \left[\log \pi_{\mathrm{JustRL}}(a \mid x_{\le t}) - \log \pi_{R1}(a \mid x_{\le t})\right]$$

前缀累积 gap $G_T = \sum_{t=1}^{T} g_t$。$G_T$ 越大表示沿 actor 自身可能 token，JustRL 教师赋予更高加权对数概率。

结果：训练 40 步（2k 响应长度）后，actor 在远超 2k 训练视野的固定长 rollout 上朝教师漂移方向移动——短视野已捕获可迁移信号。6k 视野使 actor 在该诊断上移动更远，但验证最差（step-40：2k 得 48.8，6k 仅 45.6，base 48.3）。合理解释：长视野带来的额外移动来自后期前缀，那里小教师对日益 off-distribution、log-ratio 大但不可靠（见 4.4.3），6k 可能在不可靠后期信号上过度驱动而不改善答案；2k 既避开该噪声又捕获并泛化了可靠的前期方向。

4.4.3 KL 控制教师漂移奖励的可靠性

教师/参考 log-ratio 充当 dense 奖励，但该奖励只在教师漂移对学生有意义的状态上可靠。这使 KL 不止是正则系数：它控制学生访问哪些 rollout 状态，进而决定 dense 奖励是否仍可靠。KL 太弱，学生会漂入教师与参考都低概率的区域，log-ratio 变成噪声目标；KL 太强，学生无法跟随教师策略漂移。

在固定 2k 响应下扫掠固定 KL 系数并与自适应 KL 对比：最佳固定 KL 值不通用，不同师生对偏好不同约束强度；dense token 奖励也不提供跨对规则——某设定中更大正值伴随更差验证，另一设定中却跟踪最佳曲线。因此 dense 奖励不应被视为独立于 rollout 分布最大化标量目标。自适应 KL 运行在初始校正后把 dense token 奖励拉向零，而非保持强正或强负——这与"让学生停留在教师/参考比较仍 informative 的区域"的预期角色一致；持续大奖励常表示学生采样到 post-RL 教师与其参考强烈不一致的 token（往往因已漂离两者支持，log-ratio 量大但不再是可信改进方向），近零 batch 均值提示更平衡的局部排序 regime。

Takeaway： dense 教师/参考奖励应被视作rollout-分布相关而非孤立优化对象。固定 KL 扫掠表明正确约束依赖师生对，自适应 KL 经验地把均值奖励拉向更平衡的 regime。这也解释了为何 4.4.2 中更长响应反而验证更差——更长 rollout 把学生带到 log-ratio 量大但不可靠的后期状态。

5. 总结与启发

5.1 局限性

论文明确指出 Direct-OPD 的信号是有条件的：

  • 信号条件性：当教师/参考的改进在学生访问状态上不再有意义时，Direct-OPD 会失败。dense 奖励的可靠性依赖学生当前采样到的状态——这由 KL 与响应长度共同决定。
  • 超参依赖：最佳响应长度与 KL 强度仍是师生对相关的，没有一对通用取值；论文以自适应 KL 缓解但仍需经验调参。
  • 教师对依赖：迁移效果取决于选哪个小教师 RL checkpoint（T300 vs T900–T1500 携带不同漂移，并非每个都对大学生同样有用）。
  • 评测范围：实验集中在 AIME 2024/2025 数学推理基准，其他推理域（代码、长程 agent）的迁移性有待验证。

5.2 核心洞见与读后评注

洞见一：把 RL 成果重新定义为"可复用的改进信号"而非"最终模型"。 这是全文最深刻的范式转换。传统蒸馏把 post-RL 模型当作要模仿的终点；Direct-OPD 把一对 checkpoint 视作存储了 RL 监督信号的载体——signal 在 policy space 里以 log-ratio 形式存在。这与 DPO 的 policy-as-reward 恒等式同源，但方向相反：DPO 从偏好拟合策略，Direct-OPD 从已训练策略读回奖励。这种"奖励可逆读出"的视角对后续工作有启发意义——任何 post-RL 模型都隐含一个可迁移的奖励函数。

洞见二：弱→强迁移的真正载体是"改进方向"而非"能力水平"。 Figure 1a 的反例极具说服力：R1-Distill-7B 初始 56.7 已超过 JustRL 教师 51.3，vanilla OPD 把它拖到约 50——因为模仿弱教师最终策略会用教师的能力上限覆盖学生更强行为。Direct-OPD 通过"教师与自身前后对比"做减法，剥离出纯粹的 RL 方向 $\log \pi_T - \log \pi_{T}^{\mathrm{ref}}$，于是即使学生已超教师仍能继续受益。这回应了 weak-to-strong 领域"激发而非模仿"的核心诉求，也呼应 [64] 把 OPD 视作奖励外推的观点，但本文外推的"教师"是一对 checkpoint 而非单一终点。

洞见三：最优解的形式 $\pi^{*} \propto \pi_S (\pi_T/\pi_{T}^{\mathrm{ref}})^{1/\alpha}$ 给出清晰直觉。 学生等于在其自身初始化 $\pi_S$ 上做了一次指数倾斜，倾斜方向由教师漂移决定、倾斜强度由 $1/\alpha$ 决定。这意味着 Direct-OPD 在几何上是在 $\pi_S$ 的概率测度上重新加权，而非替换——这正是它不会"覆盖"学生既有强行为的数学根源，也是 KL 锚定的意义所在。

洞见四：算力经济学的重构。 "小模型 RL + 短迁移"相对"大模型直接 RL"的双重优势——小模型 RL 更稳更易更廉（1.5B 1500 步约 160h@32A100 vs 7B 约 320h@32A100），迁移阶段仅约 4h@8A100——指向一种新的 post-training 流水线：把 RL 当作在小模型上"生产奖励"，再批量迁移到多个强学生。结合 4.3 的顺序组合，甚至可设想"能力模块化生产 + 组装"的范式。

洞见五：dense 奖励的可靠性是 rollout-分布相关的。 4.4.3 的 KL 扫掠与 4.4.2 的长度扫掠共同揭示一个反直觉现象——更多信号不等于更好。更长响应让学生进入 log-ratio 量大但不可靠的 off-distribution 后期状态，反而验证下降；自适应 KL 通过把均值奖励拉回近零来维持"局部仍能排序动作"的 regime。这对实际部署是重要工程教训：implicit reward 不能脱离学生当前状态分布独立优化。

评注与展望。 Direct-OPD 的优雅在于它几乎"免费"——复用 OPD 的 on-policy、top-k 接口，只换读出的信号；不需要 reward model、不在目标上跑 RL、可顺序组合。其局限同样源于此：信号质量完全取决于教师漂移在学生访问状态上是否仍 meaningful。一个自然的后续方向是在学生侧主动选择/构造访问状态以最大化漂移可靠性（如 curriculum 或基于不确定性的前缀选择），以及把该框架推广到非数学域（代码、工具使用）与多教师漂移的更复杂组合策略。论文为"RL 成果跨尺度复用"提供了一个简洁、可验证的基线，预计会被后续弱→强与 post-training 流水线工作大量引用并扩展。
