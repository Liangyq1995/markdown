1. 深度学习概述

Lilian Weng 于 2017 年撰写的深度学习综述，面向对深度学习感兴趣的初学者，系统梳理了从感知机到现代深度网络的演进历程，深入分析了深度学习在这一时期"为什么突然有效"的根本原因，并详细讲解了 CNN、RNN/LSTM 等主流架构以及各类训练技巧。

1.1 深度学习复兴的三大驱动力

数据规模爆炸

  • ImageNet：1400万张标注图像，1000个类别
  • 互联网文本语料达到万亿 token 级别
  • 数据量与模型性能呈对数线性正相关
  • 大数据让深层网络真正发挥表达优势

算力革命

  • GPU 并行计算：矩阵运算加速 100×
  • CUDA 生态系统成熟，编程门槛降低
  • 云计算按需弹性扩展，无需购买硬件
  • Google TPU 等专用 AI 芯片相继问世

算法突破（最关键）

  • ReLU 激活函数：$f(x)=\max(0,x)$，梯度恒为 1（正区间），解决梯度消失，训练速度提升 6× 以上
  • Dropout 正则化：训练时随机丢弃比例 $p$ 的神经元，等价于以指数级数量的子网络做集成，显著抑制过拟合
  • Batch Normalization：对每个 mini-batch 的激活值做归一化，允许使用更大学习率，加速收敛，减少对初始化的敏感性
  • 残差连接（ResNet）：跳跃连接 $\mathbf{y}=F(\mathbf{x})+\mathbf{x}$，让梯度直接回传，训练超千层网络成为可能
  • Adam 优化器：结合动量和自适应学习率，大幅减少超参调整负担

  • LeNet-5 (1998)：手写数字识别，奠定 CNN 基本结构
  • AlexNet (2012)：ImageNet 冠军，引入 ReLU 和 Dropout，GPU 训练
  • VGGNet (2014)：堆叠 3×3 小卷积核，深度达 19 层
  • GoogLeNet/Inception (2014)：Inception 模块，多尺度并行卷积
  • ResNet (2015)：残差连接，152 层，Top-5 错误率 3.57%

1.3 循环神经网络（RNN）与 LSTM

RNN 通过隐状态 $h_t$ 传递序列信息，但原始 RNN 存在严重的梯度消失/爆炸问题，导致无法学习长期依赖。

标准 RNN 更新：

$$h_t = \tanh(W_h h_{t-1} + W_x x_t + b)$$ $$\frac{\partial h_T}{\partial h_1} = \prod_{t=2}^{T} W_h \cdot \text{diag}(\tanh'(\cdot))$$

当 $T$ 很大时，连乘项指数级衰减（梯度消失）或爆炸

LSTM 的门控机制

LSTM 引入细胞状态 $C_t$ 和三种门，精确控制信息的保留与遗忘：

graph TD subgraph LSTM单元 F["遗忘门\nf_t = σ(W_f·[h_{t-1},x_t]+b_f)\n决定丢弃哪些旧信息"] I["输入门\ni_t = σ(W_i·[h_{t-1},x_t]+b_i)\n决定更新哪些信息"] C["细胞状态更新\nC_t = f_t⊙C_{t-1} + i_t⊙tanh(W_C·[h_{t-1},x_t]+b_C)"] O["输出门\no_t = σ(W_o·[h_{t-1},x_t]+b_o)\nh_t = o_t⊙tanh(C_t)"] F --> C I --> C C --> O end style F fill:#313244,stroke:#f38ba8,color:#cdd6f4 style I fill:#313244,stroke:#a6e3a1,color:#cdd6f4 style C fill:#313244,stroke:#89b4fa,color:#cdd6f4 style O fill:#313244,stroke:#f9e2af,color:#cdd6f4

细胞状态 $C_t$ 通过加法而非乘法更新，梯度可以沿时间轴无阻碍地流动，从根本上解决了梯度消失问题。

1.4 关键训练技巧总结

Adam一阶矩（动量）+ 二阶矩（自适应学习率）超参敏感、稀疏梯度可能收敛到更差的极值

2. 词嵌入（Word Embedding）

词嵌入是将离散词汇映射到连续稠密向量空间的技术，使语义相似的词在向量空间中距离相近。Lilian Weng 的这篇文章系统讲解了从 Word2Vec 到 FastText 的主流词嵌入方法，以及高效训练的关键技术。

核心直觉："You shall know a word by the company it keeps"（Firth, 1957）——词的含义由其上下文决定。

2.1 Word2Vec：CBOW 与 Skip-gram

Word2Vec 提出两种互补的训练目标，均基于分布假说：

CBOW（连续词袋模型）

用上下文词预测中心词

目标：$\max P(w_t \mid w_{t-c}, \ldots, w_{t+c})$

  • 输入：窗口内 $2c$ 个上下文词的平均向量
  • 适合：词频高、数据量大的场景
  • 优点：训练速度快，对高频词效果好

Skip-gram

用中心词预测上下文词

目标：$\max \sum_{-c \le j \le c, j\ne 0} \log P(w_{t+j} \mid w_t)$

  • 输入：中心词向量
  • 适合：小数据集、低频词
  • 优点：对低频词和罕见词效果更好

负采样（Negative Sampling，NEG）

原始 softmax 需要对全词表归一化，计算复杂度 $O(|V|)$ 无法接受（$|V|$ 通常为百万级）。负采样将多分类问题转化为多个二分类问题：

$$\mathcal{L}_\text{NEG} = \log \sigma(\mathbf{v}_{w_O}^\top \mathbf{v}_{w_I}) + \sum_{k=1}^{K} \mathbb{E}_{w_k \sim P_n(w)} \left[\log \sigma(-\mathbf{v}_{w_k}^\top \mathbf{v}_{w_I})\right]$$

对正样本（真实上下文词）最大化相似度，对 $K$ 个负样本最小化相似度； 负采样分布 $P_n(w) \propto f(w)^{3/4}$（词频的 3/4 次方，平衡高低频词）

2.2 GloVe：全局共现矩阵分解

Word2Vec 基于局部窗口，无法利用全局统计信息。GloVe（Global Vectors）直接对整个语料的词共现矩阵进行分解：

$$J = \sum_{i,j=1}^{|V|} f(X_{ij}) \left(\mathbf{w}_i^\top \tilde{\mathbf{w}}_j + b_i + \tilde{b}_j - \log X_{ij}\right)^2$$

$X_{ij}$：词 $i$ 和词 $j$ 在窗口内的共现次数； $f(x)$：加权函数，对高频词降权避免过度主导； 同时学习词向量 $\mathbf{w}$ 和上下文向量 $\tilde{\mathbf{w}}$

GloVe 的关键洞见：词向量的差值编码了词关系，例如 $\mathbf{v}_\text{ice} - \mathbf{v}_\text{steam}$ 方向对应固态/气态的语义差异。

2.3 FastText：子词嵌入

Word2Vec 和 GloVe 将每个词视为原子单元，无法处理词汇表外（OOV）词和形态丰富的语言。FastText 将每个词拆分为字符 n-gram 子词：

例如，词 "where"（n=3）拆分为：<wh>, whe, her, ere, re> 以及整词 <where>。 词向量 = 所有子词向量之和。
  • OOV 鲁棒性：未见词可通过子词组合得到合理向量
  • 形态感知：run、running、runner 共享子词，向量自然相近
  • 多语言优势：对德语、芬兰语等形态复杂语言效果显著

2.4 NCE（噪声对比估计）

NCE 是比负采样更严格的理论框架，将语言模型训练转化为区分真实数据与噪声数据的二分类问题：

$$P(D=1 \mid w, c) = \frac{p_\theta(w \mid c)}{p_\theta(w \mid c) + k \cdot p_n(w)}$$

$D=1$ 表示真实数据，$D=0$ 表示噪声；$k$ 为每个正样本对应的噪声样本数； 当 $k \to \infty$ 时，NCE 等价于最大似然估计

负采样可视为 NCE 的简化版：当 $k$ 较小时，NCE 的归一化常数近似为常数，退化为负采样目标。

2.5 词嵌入评估

内在评估（词类比任务）

经典问题："king - man + woman = ?"

向量运算：$\mathbf{v}_\text{king} - \mathbf{v}_\text{man} + \mathbf{v}_\text{woman} \approx \mathbf{v}_\text{queen}$

  • 语义类比：首都-国家、性别关系
  • 语法类比：时态、比较级
  • 数据集：Google Analogy、BATS

外在评估（下游任务）

  • 词语相似度：WordSim-353, SimLex-999
  • 命名实体识别（NER）
  • 情感分析、文本分类
  • 机器翻译质量

内在评估快速，但与外在评估相关性不总是高

方法训练目标核心优势局限性
Word2Vec CBOW上下文→中心词速度快，高频词好忽略全局统计

3. 信息论与深度学习

Lilian Weng 在这篇文章中介绍了 Tishby 等人提出的信息瓶颈（Information Bottleneck）理论，尝试用信息论的语言解释深度神经网络的学习过程，特别是为什么深层网络能够泛化。

3.1 信息论基础

Shannon 熵

$$H(X) = -\sum_x p(x)\log p(x)$$

衡量随机变量的不确定性。均匀分布熵最大，确定性分布熵为 0。

KL 散度

$$D_{KL}(P\|Q) = \sum_x p(x)\log\frac{p(x)}{q(x)}$$

衡量两个分布的差异。非对称，$D_{KL}(P\|Q) \ge 0$，等号当且仅当 $P=Q$。

互信息

$$I(X;Y) = H(X) - H(X|Y) = D_{KL}(P_{XY}\|P_X P_Y)$$

衡量两个变量的共享信息量。$I(X;Y)=0$ 当且仅当 $X,Y$ 独立。

数据处理不等式（DPI）

若 $X \to Y \to Z$ 构成 Markov 链，则： $$I(X;Z) \le I(X;Y) \quad \text{且} \quad I(X;Z) \le I(Y;Z)$$

数据处理只能减少信息，不能增加信息。这是信息论的基本定理，对深度学习有深刻含义。

3.2 DNN 作为 Markov 链

将深度神经网络的每一层视为对输入信息的变换，整个网络构成一条 Markov 链：

由 DPI，随着层数加深：$I(X;T_1) \ge I(X;T_2) \ge \ldots \ge I(X;T_L)$，每一层都是对上一层的有损压缩。

3.3 信息瓶颈理论

信息瓶颈目标：寻找输入 $X$ 的压缩表示 $T$，在最大化对目标 $Y$ 的预测能力的同时，最小化对 $X$ 的冗余信息保留。 $$\min_{p(t|x)} \left[ I(X;T) - \beta \cdot I(T;Y) \right]$$ 其中 $\beta$ 是拉格朗日乘子，控制压缩率与预测精度的权衡。

两阶段训练动态（Tishby & Schwartz-Ziv, 2017）

通过可视化训练过程中每一层的 $(I(X;T), I(T;Y))$ 变化，Tishby 等人观察到两个明显阶段：

阶段一：Fitting（拟合）

  • $I(X;T)$ 快速增大
  • $I(T;Y)$ 快速增大
  • 网络学习记忆训练数据
  • 对应 SGD 的快速下降阶段
  • 梯度均值 > 梯度标准差（信噪比高）

阶段二：Compression（压缩）

  • $I(X;T)$ 缓慢减小
  • $I(T;Y)$ 保持稳定
  • 网络丢弃输入中的冗余信息
  • 对应 SGD 的随机游走阶段
  • 梯度均值 < 梯度标准差（信噪比低）

3.4 基于压缩的泛化界

信息瓶颈理论提供了一个新的泛化界，将泛化能力与输入压缩程度直接联系起来：

$$\epsilon \le \sqrt{\frac{I(X;T) + \log(2\sqrt{n}/\delta)}{2n}}$$

$\epsilon$：泛化误差（训练误差与测试误差之差）； $n$：训练样本数；$\delta$：置信度参数； $I(X;T)$：中间层对输入的互信息（压缩程度）

关键洞见：压缩程度越高（$I(X;T)$ 越小），泛化界越紧。这从理论上解释了为什么深度学习能够泛化——深层网络天然地压缩了输入信息。

争议与局限

Tishby 的信息瓶颈理论引发了大量讨论，也受到了一些质疑：

  • 压缩阶段的观察依赖于激活函数的选择（tanh 有压缩，ReLU 不明显）
  • 互信息的估计在高维连续空间中非常困难
  • Saxe 等人（2018）发现压缩并非泛化的必要条件
  • 理论框架在实践中的可操作性仍有争议

4. 过拟合与泛化

Lilian Weng 在 2019 年的这篇文章中深入探讨了一个令人困惑的现象：深度神经网络拥有远超数据量的参数，却仍然能够泛化良好。这挑战了经典统计学习理论的直觉。

4.1 经典偏差-方差权衡的失效

经典统计学习理论预测：随着模型复杂度增加，测试误差先降后升（U 形曲线）。但深度学习实践中观察到了截然不同的现象。

4.2 双重下降现象

Belkin 等人（2019）提出了双重下降（Double Descent）曲线，统一了经典理论和现代深度学习的观察：

双重下降的关键区域：

  • 欠参数化区域（参数 < 数据）：经典 U 形曲线，增加参数先降后升
  • 插值阈值（参数 ≈ 数据）：模型恰好能插值所有训练数据，测试误差达到峰值
  • 过参数化区域（参数 > 数据）：继续增加参数，测试误差再次下降并趋于平稳

4.3 Lottery Ticket 假说

Frankle & Carlin（2019）提出了令人惊讶的"彩票假说"：

Lottery Ticket Hypothesis：随机初始化的稠密神经网络包含一个稀疏子网络（"中奖彩票"），这个子网络单独训练时能够达到与完整网络相当的性能。

迭代剪枝算法（Iterative Magnitude Pruning）

关键发现：

  • 中奖彩票通常只有完整网络 10%-20% 的参数
  • 必须使用原始初始化值（而非重新随机初始化）才能成功训练
  • 中奖彩票训练速度更快，有时泛化性能更好
  • 大型网络（如 ResNet、BERT）的中奖彩票需要"早期重绕"（Early Rewinding）

4.4 隐式正则化：SGD 的噪声

SGD 的随机性并非缺陷，而是一种隐式正则化机制。在过参数化网络中存在无数个全局最优解，SGD 倾向于收敛到平坦极小值（Flat Minima）：

尖锐极小值（Sharp Minima）

  • Hessian 矩阵特征值大
  • 损失曲面陡峭
  • 对参数微小扰动敏感
  • 泛化性能差
  • 小 batch size 更难收敛到此处

平坦极小值（Flat Minima）

  • Hessian 矩阵特征值小
  • 损失曲面平缓
  • 对参数扰动鲁棒
  • 泛化性能好
  • SGD 噪声自然偏向此处

SGD 的有效批大小（Effective Batch Size）与学习率之比 $\eta / B$ 控制了噪声水平，进而影响最终收敛到的极小值的平坦程度。

4.5 MDL 原则与奥卡姆剃刀

最小描述长度（MDL）原则将模型选择与数据压缩统一：最好的模型是能够最短描述数据的模型。

$$\text{MDL：} \quad \hat{\theta} = \arg\min_\theta \left[ L(\mathcal{D}|\theta) + L(\theta) \right]$$

$L(\mathcal{D}|\theta)$：用模型 $\theta$ 编码数据 $\mathcal{D}$ 所需的比特数（拟合质量）； $L(\theta)$：编码模型参数所需的比特数（模型复杂度）

MDL 视角下，泛化 = 压缩：能够高度压缩训练数据的模型，必然捕获了数据的真实规律，而非记忆了噪声，因此具有良好的泛化性。这与信息瓶颈理论形成呼应。

5. 神经正切核（NTK）

Jacot 等人（2018）提出的神经正切核（Neural Tangent Kernel）理论，从核方法的视角理解无限宽神经网络的训练动态，揭示了深度学习与经典核方法之间的深刻联系。Lilian Weng 于 2022 年撰文梳理了其背后的数学原理。

5.1 无限宽网络与高斯过程

Neal（1994）首先证明：当单隐层神经网络的宽度 $\to \infty$ 时，网络输出收敛为高斯过程（GP）。这一结论被 Matthews 等人推广到任意深度的网络：

对于随机初始化的 $L$ 层全连接网络，当每层宽度 $n_l \to \infty$ 时： $$f(x) \sim \mathcal{GP}(0, K_\infty(x, x'))$$

核函数 $K_\infty$ 由网络结构（激活函数、深度）唯一确定，与参数初始化无关

5.2 神经正切核的定义

NTK 描述了梯度下降训练过程中，网络输出的变化速率：

$$\Theta(\mathbf{x}, \mathbf{x}') = \left\langle \frac{\partial f(\mathbf{x};\theta)}{\partial \theta}, \frac{\partial f(\mathbf{x}';\theta)}{\partial \theta} \right\rangle$$

NTK 是两个输入点的梯度向量的内积，衡量了参数更新对两个输入点输出的协同影响

5.3 训练动态：梯度下降 ≈ 核回归

在无限宽极限下，NTK 在训练过程中保持常数不变（即 $\Theta$ 不随参数更新而变化）。这使得训练动态变得线性且可分析：

graph LR A["有限宽神经网络\n非线性训练动态\n难以分析"] -->|"宽度→∞"| B["无限宽神经网络\nNTK 保持不变\n训练动态线性化"] B --> C["等价于核回归\nf* = K(X,·)K(X,X)^{-1}y\n闭合解析解"] style A fill:#313244,stroke:#f38ba8,color:#cdd6f4 style B fill:#313244,stroke:#f9e2af,color:#cdd6f4 style C fill:#313244,stroke:#a6e3a1,color:#cdd6f4

在连续时间梯度流下，损失的演化满足：

$$\frac{d\mathcal{L}}{dt} = -\mathbf{u}^\top \Theta \mathbf{u}$$ $$\mathbf{u}(t) = f(\mathbf{X};\theta(t)) - \mathbf{y}$$

$\mathbf{u}(t)$：预测值与真实标签的差；若 $\Theta$ 为正定常数矩阵，则 $\mathbf{u}(t) \to 0$ 以指数速率收敛

5.4 NTK 的递推计算

对于 $L$ 层全连接网络，NTK 可以递推计算：

$$K^{(L)}(\mathbf{x}, \mathbf{x}') = K^{(L-1)}(\mathbf{x}, \mathbf{x}') \cdot \dot{K}^{(L)}(\mathbf{x}, \mathbf{x}') + K^{(L)}(\mathbf{x}, \mathbf{x}')$$

$K^{(l)}$：第 $l$ 层的 NNGP 核（网络输出的协方差）； $\dot{K}^{(l)}$：激活函数导数的期望核； NTK 由 NNGP 核和导数核共同决定

5.5 NTK 理论的意义与局限

理论贡献

  • 将神经网络训练与核方法统一
  • 提供收敛性的严格理论保证
  • 解释了过参数化网络的全局收敛性
  • 连接高斯过程与深度学习
  • 为网络架构设计提供理论指导

实践局限

  • 无限宽假设在实践中不成立
  • 有限宽网络的 NTK 会随训练变化
  • NTK 核回归性能不如实际深度学习
  • 无法解释特征学习（feature learning）
  • 计算 NTK 矩阵的复杂度 $O(n^2 p)$

6.2 检索器（Retriever）

稀疏检索：TF-IDF 与 BM25

传统检索方法基于词袋模型，通过词频统计衡量文档与查询的相关性：

$$\text{BM25}(q,d) = \sum_{t \in q} IDF(t) \cdot \frac{tf(t,d) \cdot (k_1+1)}{tf(t,d) + k_1 \cdot (1-b+b\cdot\frac{|d|}{avgdl})}$$

$k_1 \approx 1.5$：词频饱和参数；$b \approx 0.75$：文档长度归一化参数； BM25 是 TF-IDF 的改进版，加入了词频饱和和文档长度归一化

6.3 阅读器（Reader）

阅读器负责从检索到的段落中提取精确答案，通常基于机器阅读理解（MRC）模型：

$\mathbf{H}$：BERT 输出的上下文表示；答案为 $[i, j]$ 区间的文本片段； 训练目标：最大化正确起始位置和结束位置的概率

7.2 LIME：局部线性近似

LIME（Local Interpretable Model-agnostic Explanations，Ribeiro et al., 2016）的核心思想：在待解释样本的局部邻域内，用简单的线性模型近似复杂黑盒模型。

$$\xi(x) = \arg\min_{g \in G} \mathcal{L}(f, g, \pi_x) + \Omega(g)$$

$f$：黑盒模型；$g$：简单解释模型（如线性模型）；$G$：解释模型类； $\pi_x$：以 $x$ 为中心的局部权重函数；$\Omega(g)$：模型复杂度惩罚

LIME 算法步骤

  1. 对待解释样本 $x$ 进行扰动采样（随机遮盖特征/词语/超像素）
  2. 用黑盒模型 $f$ 对扰动样本打分
  3. 根据与 $x$ 的距离为扰动样本加权（近的权重大）
  4. 在加权数据集上训练稀疏线性模型作为局部解释
  5. 线性模型的系数即为特征重要性

7.3 SHAP：Shapley 值

SHAP（SHapley Additive exPlanations，Lundberg & Lee, 2017）基于博弈论中的 Shapley 值，为每个特征分配公平的贡献度：

$$\phi_i = \sum_{S \subseteq F \setminus \{i\}} \frac{|S|!(|F|-|S|-1)!}{|F|!} \left[f(S \cup \{i\}) - f(S)\right]$$

$F$：所有特征集合；$S$：不包含特征 $i$ 的子集； Shapley 值 = 特征 $i$ 在所有可能的特征子集中的平均边际贡献

SHAP 满足四个公理性质：局部精确性（加和等于预测值）、缺失性（缺失特征贡献为0）、一致性（重要特征贡献更大）、对称性（等价特征贡献相等）。这使得 SHAP 成为理论上最严格的特征归因方法。

7.4 梯度显著图

对于神经网络，梯度提供了最直接的特征重要性信号：

梯度 × 输入（Gradient × Input）

$$\text{Saliency}(x) = \left|\frac{\partial f(x)}{\partial x}\right| \odot |x|$$

梯度衡量输入变化对输出的影响；乘以输入绝对值可以减少噪声，突出重要区域

GradCAM（Gradient-weighted Class Activation Mapping）

Selvaraju 等人（2017）提出 GradCAM，利用卷积层的梯度生成类别激活热图：

$$\alpha_k^c = \frac{1}{Z} \sum_{i,j} \frac{\partial y^c}{\partial A_{ij}^k}$$ $$L_\text{GradCAM}^c = \text{ReLU}\left(\sum_k \alpha_k^c A^k\right)$$

$A^k$：第 $k$ 个特征图；$\alpha_k^c$：类别 $c$ 对特征图 $k$ 的权重（梯度全局平均池化）； ReLU 只保留正向激活（对类别 $c$ 有正贡献的区域）

7.5 BETA 框架：黑箱解释

BETA（Black box Explanations through Transparent Approximations）框架将全局解释问题形式化为：找到一组规则/决策集，在保持足够保真度的同时最大化可解释性。

方法解释类型适用场景计算复杂度理论保证
LIME局部线性任意黑盒，单样本解释低（采样）局部近似
SHAP加性特征归因任意黑盒，特征重要性中（树模型快）唯一满足4公理
GradCAM空间热图CNN 图像分类低（一次反传）梯度近似

8.2 数据并行（Data Parallelism）

数据并行是最简单的并行策略：每个 GPU 持有完整的模型副本，处理不同的数据分片，然后同步梯度。

DDP（Distributed Data Parallel）

  • 前向传播：每个 GPU 独立处理其数据分片
  • 反向传播：计算局部梯度
  • 梯度同步：All-Reduce 操作（Ring-AllReduce，通信量 $O(2(N-1)/N \cdot M)$，$M$ 为参数量）
  • 参数更新：所有 GPU 使用相同的平均梯度更新

ZeRO（Zero Redundancy Optimizer）

微软 DeepSpeed 提出的 ZeRO 通过分片消除数据并行中的内存冗余：

ZeRO 阶段分片内容内存节省通信开销
Stage 1优化器状态（动量、方差）4× 降低与 DDP 相同
Stage 2优化器状态 + 梯度8× 降低轻微增加
Stage 3优化器状态 + 梯度 + 参数$N$× 降低（$N$ 为 GPU 数）增加 1.5×

8.3 模型并行（Model Parallelism）

当模型本身无法放入单个 GPU 时，需要将模型分割到多个设备：

张量并行（Tensor Parallelism，Megatron-LM）

将单个矩阵乘法操作分割到多个 GPU：

$$Y = XA = X[A_1, A_2] = [XA_1, XA_2]$$

矩阵 $A$ 按列分割，每个 GPU 计算一部分；前向传播需要 All-Gather，反向传播需要 All-Reduce； 适合 Transformer 的 MLP 层和注意力头分割

8.4 流水线并行（Pipeline Parallelism）

将模型的不同层分配到不同 GPU，形成流水线：

GPipe（Google）

  • 将 mini-batch 分为 $m$ 个微批次（micro-batch）
  • 不同阶段（设备）流水线处理不同微批次
  • 气泡开销：$(p-1)/m$，$p$ 为流水线阶段数，$m$ 越大气泡越小
  • 需要重计算（Recomputation）以节省激活内存

PipeDream（Microsoft）

  • 引入异步流水线：不等待所有微批次完成即可更新参数
  • 使用权重存储（Weight Stashing）解决参数版本不一致问题
  • 1F1B 调度：交替执行前向和反向传播，减少气泡

8.5 专家混合（Mixture of Experts，MoE）

MoE 通过稀疏激活在不增加推理计算量的前提下大幅扩展模型参数：

$$y = \sum_{i=1}^{N} G(x)_i \cdot E_i(x)$$ $$G(x) = \text{Softmax}(\text{TopK}(x \cdot W_g))$$

$N$：专家总数（可达数千个）；$K$：每次激活的专家数（通常 $K=1$ 或 $2$）； 门控网络 $G$ 决定路由，每个 token 只经过 $K$ 个专家，计算量不随 $N$ 增加

GShard（Google）

  • 每个 token 路由到 top-2 专家
  • 专家分布在不同 TPU/GPU 上
  • 辅助损失平衡专家负载
  • 支持万亿参数量级模型

Switch Transformer（Google）

  • 简化为 top-1 路由（每次只用1个专家）
  • 容量因子（Capacity Factor）控制专家缓冲
  • FP16 训练稳定性技巧
  • 1.6T 参数，训练速度提升 7×

8.6 混合精度训练

使用 FP16 进行前向/反向传播，保留 FP32 主权重（Master Weights）用于参数更新：

graph LR FP32["FP32 主权重\n(精确参数)"] -->|"转换为FP16"| FP16["FP16 工作权重\n(计算用)"] FP16 --> FW["FP16 前向传播\n(速度快，内存少)"] FW --> BW["FP16 反向传播\n(梯度计算)"] BW -->|"损失缩放\nLoss Scaling"| GS["FP32 梯度累积\n(防止下溢)"] GS -->|"参数更新"| FP32 style FP32 fill:#313244,stroke:#a6e3a1,color:#cdd6f4 style FP16 fill:#313244,stroke:#fab387,color:#cdd6f4 style GS fill:#313244,stroke:#89b4fa,color:#cdd6f4

损失缩放（Loss Scaling）：FP16 的最小正数约为 $6\times10^{-5}$，梯度下溢是主要问题。损失缩放通过将损失乘以大数 $S$（如 $2^{15}$），再将梯度除以 $S$，有效避免下溢。

9.1 问题定义与挑战

股票价格预测本质上是一个时间序列回归问题，但面临诸多挑战：

  • 非平稳性：均值和方差随时间变化，需要差分或归一化处理
  • 噪声高：短期价格波动受随机因素主导，信噪比极低
  • 非线性：价格受多种复杂因素影响，线性模型难以捕捉
  • 前瞻偏差：特征工程中必须严格避免使用未来数据

9.2 数据预处理

特征工程（Part 2 引入）

  • 技术指标：移动平均线（MA5/MA10/MA20）、RSI（相对强弱指数）、MACD
  • 价格归一化：使用滚动窗口归一化，避免使用全局统计量（前瞻偏差）
  • 滑动窗口：以过去 $T$ 天的特征预测第 $T+1$ 天的收盘价
# 滑动窗口数据集构建（避免前瞻偏差）
def create_dataset(data, look_back=20):
    X, y = [], []
    for i in range(len(data) - look_back):
        # 只使用过去 look_back 天的数据作为输入
        X.append(data[i:i+look_back])
        y.append(data[i+look_back, 0])  # 预测下一天收盘价
    return np.array(X), np.array(y)

9.3 LSTM 模型架构

import torch
import torch.nn as nn

class StockLSTM(nn.Module):
    def __init__(self, input_size=1, hidden_size=64, num_layers=2, dropout=0.2):
        super().__init__()
        self.lstm = nn.LSTM(
            input_size=input_size,
            hidden_size=hidden_size,
            num_layers=num_layers,
            batch_first=True,
            dropout=dropout
        )
        self.fc = nn.Linear(hidden_size, 1)

    def forward(self, x):
        # x: (batch, seq_len, input_size)
        out, (h_n, c_n) = self.lstm(x)
        # 取最后一个时间步的输出
        out = self.fc(out[:, -1, :])
        return out

9.4 训练策略与评估

训练要点

  • 损失函数：MSE（均方误差）
  • 优化器：Adam，学习率 0.001
  • 早停（Early Stopping）：防止过拟合
  • 学习率衰减：验证集误差不下降时降低 LR
  • 时间序列分割：严格按时间顺序分 train/val/test

评估指标

  • MSE / RMSE：绝对误差，受量纲影响
  • MAPE：平均绝对百分比误差，直观
  • 方向准确率：预测涨跌方向是否正确（更实用）
  • 回测收益：基于预测的交易策略实际收益

9.5 关键教训与局限

Lilian Weng 在文章末尾坦诚地指出：股票价格预测是极其困难的问题。LSTM 能够拟合训练数据的历史模式，但并不意味着能够预测未来。模型在测试集上往往只是在预测"昨天的价格"（延迟一步），而非真正的预测。
  • 效率市场假说：所有公开信息已反映在价格中，技术分析理论上无效
  • 过拟合风险：金融数据量少，模型极易过拟合历史模式
  • 分布漂移：市场结构随时间变化，历史规律不稳定
  • 实践价值：这个项目更大的价值在于学习 LSTM 和时序数据处理，而非真正用于交易
