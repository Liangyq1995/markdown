本报告系统整理深度学习核心理论，涵盖神经网络基础、正则化、优化、卷积网络、循环网络、注意力机制、词向量、无监督学习、强化学习与LLM等内容，所有数学推导完整呈现。

一、深度学习概论

1.1 机器学习 vs 表示学习 vs 深度学习

机器学习（Machine Learning）是从数据中自动学习规律并做出预测的方法。传统机器学习依赖人工设计特征，模型对输入的原始表示进行处理。

表示学习（Representation Learning）不仅学习从表示到输出的映射，还自动学习数据的良好表示（特征）。表示学习将特征工程自动化，减少对领域知识的依赖。

深度学习（Deep Learning）是表示学习的一种，通过多层非线性变换，逐层学习从低级到高级的抽象特征表示。深度学习的核心思想：

  • 多层次特征提取：低层学习边缘/纹理，中层学习部件，高层学习语义概念
  • 端到端训练：特征提取与分类器联合优化
  • 大数据+大模型：充分利用海量数据和强大计算资源
机器学习

人工特征工程 → 线性/浅层模型 → 预测

依赖领域知识，泛化能力受限

深度学习

原始数据 → 多层非线性变换 → 自动特征 → 预测

端到端，自动特征，强泛化

1.2 归纳偏置（Inductive Bias）

归纳偏置是指学习算法在训练数据之外对假设空间所做的先验假设，用于在无穷多个与训练数据一致的假设中选择特定的解。

  • CNN的归纳偏置：局部性（局部感受野）+ 平移等变性（权重共享）
  • RNN的归纳偏置：时序顺序性 + 参数共享（时间步之间）
  • GNN的归纳偏置：置换等变性 + 图结构先验
  • Transformer的归纳偏置：较弱（需要大量数据），全局注意力
归纳偏置越强，模型在小数据上泛化越好，但灵活性越差；归纳偏置越弱，模型越灵活，但需要更多数据。

1.3 局部表示 vs 分布式表示

局部表示（Local Representation）：每个概念由单个神经元表示，例如One-hot编码。特点：稀疏、可解释，但维度高，泛化差。

分布式表示（Distributed Representation）：每个概念由多个神经元共同表示，每个神经元参与多个概念的表示。特点：

  • 低维稠密，表达能力强：$n$个二值神经元可表示 $2^n$ 个概念（局部表示只能表示 $n$ 个）
  • 泛化能力强：相似概念有相似表示（如词向量中"猫"和"狗"距离近）
  • 组合性：复杂概念由简单特征组合而成
表达能力对比：局部表示 $n$ 个神经元表示 $n$ 个概念；分布式表示 $n$ 个二值神经元可表示 $2^n$ 个概念，指数级提升。

1.4 贡献度分配问题（Credit Assignment Problem）

在深度神经网络或序列决策中，当得到最终奖励/损失时，如何将功劳或惩罚分配给每一个中间步骤或参数，称为贡献度分配问题。

  • 时间维度：强化学习中，最终奖励如何分配给之前的每个动作
  • 空间维度：深度网络中，最终损失如何分配给每一层的每个参数

反向传播算法（Backpropagation）是解决深度网络中贡献度分配问题的核心方法，通过链式法则将梯度从输出层传播到输入层。

1.5 端到端学习（End-to-End Learning）

端到端学习是指从原始输入直接映射到最终输出，中间所有模块联合优化，无需人工设计中间表示。

  • 优点：避免中间表示的信息损失，各模块协同优化，减少人工干预
  • 缺点：需要大量标注数据，可解释性差，调试困难
  • 典型例子：语音识别（原始波形→文字），自动驾驶（图像→方向盘角度）

1.6 网络结构分类

前馈网络（Feedforward Network）

信息单向流动，无循环连接。代表：MLP、CNN。适合静态模式识别。

反馈网络（Feedback Network）

包含循环连接，具有记忆能力。代表：RNN、LSTM、GRU。适合序列数据。

图网络（Graph Neural Network）

处理非欧几里得结构数据（图结构）。节点、边、全局信息传播。代表：GCN、GAT、GraphSAGE。

1.7 代价函数与最大似然准则

深度学习中，代价函数通常由最大似然估计（MLE）导出。给定训练集 $\{(x^{(n)}, y^{(n)})\}_{n=1}^N$，模型参数 $\theta$ 的最大似然估计为：

$$\theta^* = \arg\max_\theta \prod_{n=1}^N p_{model}(y^{(n)}|x^{(n)};\theta)$$

取对数后等价于最小化负对数似然：

$$J(\theta) = -\mathbb{E}_{\hat{p}_{data}}[\log p_{model}(x;\theta)] = -\frac{1}{N}\sum_{n=1}^N \log p_{model}(y^{(n)}|x^{(n)};\theta)$$

其中经验分布定义为：

$$\hat{p}_{data}(x,y) = \frac{1}{N}\sum_{n=1}^N \delta(x-x^{(n)})\delta(y-y^{(n)})$$

最大化对数似然等价于最小化模型分布与经验分布之间的KL散度：

$$D_{KL}(\hat{p}_{data}||p_{model}) = \mathbb{E}_{\hat{p}_{data}}[\log\hat{p}_{data}] - \mathbb{E}_{\hat{p}_{data}}[\log p_{model}]$$

由于 $\mathbb{E}_{\hat{p}_{data}}[\log\hat{p}_{data}]$ 与 $\theta$ 无关，最小化KL散度等价于最大化 $\mathbb{E}_{\hat{p}_{data}}[\log p_{model}]$。

重要联系：均方误差（MSE）对应高斯分布的负对数似然；交叉熵损失对应伯努利/分类分布的负对数似然。

二、神经网络基础

2.1 神经元模型

神经元是神经网络的基本计算单元，模拟生物神经元的工作方式。

净输入（Net Input）：

$$z = w^T x + b = \sum_{i=1}^d w_i x_i + b$$

激活值（Activation）：

$$a = f(z)$$

其中 $f(\cdot)$ 为激活函数，$w$ 为权重向量，$b$ 为偏置，$x$ 为输入向量。

2.2 输出单元

2.2.1 线性单元

输出 $\hat{y} = w^T h + b$，适用于回归任务。代价函数为均方误差：

$$J = \frac{1}{2}\|\hat{y} - y\|^2$$

2.2.2 Sigmoid单元

用于二分类，输出概率 $\hat{y} = \sigma(w^T h + b) \in (0,1)$：

$$\sigma(z) = \frac{1}{1+e^{-z}}$$

代价函数（交叉熵）：

$$J = -[y\log\hat{y} + (1-y)\log(1-\hat{y})]$$

使用交叉熵而非MSE的原因：sigmoid+MSE存在梯度消失问题（当预测错误且置信度高时梯度接近0），而sigmoid+交叉熵梯度为 $\hat{y}-y$，不存在饱和问题。

2.2.3 Softmax单元

用于多分类，输出各类别概率：

$$\text{softmax}(z)_j = \frac{e^{z_j}}{\sum_{k=1}^K e^{z_k}}$$

数值稳定版本（防止溢出）：

$$\text{softmax}(z)_j = \frac{e^{z_j - \max_k z_k}}{\sum_{k=1}^K e^{z_k - \max_k z_k}}$$

对数似然（交叉熵损失）：

$$J = -\sum_{j=1}^K y_j \log \text{softmax}(z)_j = -z_{y^*} + \log\sum_k e^{z_k}$$

其中 $y^*$ 为真实类别。梯度为 $\text{softmax}(z) - y$，形式简洁。

2.3 激活函数详细对比

2.3.1 ReLU（Rectified Linear Unit）

$$g(z) = \max(0, z) = \begin{cases} z & z > 0 \\ 0 & z \leq 0 \end{cases}$$

优点：计算简单，梯度不消失（正区间梯度为1），稀疏激活，加速收敛。

缺点：负区间梯度为0（Dead ReLU问题），不以0为中心，无上界（可能导致激活值爆炸）。

2.3.2 Leaky ReLU 与 Parametric ReLU

$$h = g(z, \alpha) = \max(0,z) + \alpha\min(0,z)$$

Leaky ReLU：$\alpha$ 固定为小值（如0.01），解决Dead ReLU问题。

Parametric ReLU (PReLU)：$\alpha$ 作为可学习参数，通过反向传播更新。

2.3.3 Maxout单元

将输入分为 $k$ 组，每组取最大值：

$$z_{i,j} = x^T W_{\cdot,i,j} + b_{i,j}, \quad h_i = \max_{j\in[1,k]} z_{i,j}$$

矩阵形式（多组线性变换取最大）：

$$y = \max(W_1 x + b_1, W_2 x + b_2, \ldots, W_k x + b_k)$$

Maxout是ReLU和Leaky ReLU的泛化，可逼近任意凸函数，但参数量增加 $k$ 倍。

2.3.4 Sigmoid 与 tanh

$$\sigma(z) = \frac{1}{1+e^{-z}}, \quad \tanh(z) = \frac{e^z - e^{-z}}{e^z + e^{-z}} = 2\sigma(2z) - 1$$

饱和问题：当 $|z|$ 很大时，梯度接近0，导致梯度消失。tanh以0为中心（输出范围$(-1,1)$），比sigmoid收敛更快，但仍有饱和问题。

关系：$\tanh(z) = 2\sigma(2z) - 1$，即tanh是sigmoid的缩放平移版本。

2.3.5 Softplus

$$g(z) = \log(1 + e^z)$$

Softplus是ReLU的平滑近似：$\frac{d}{dz}\text{softplus}(z) = \sigma(z)$。处处可微，但实践中ReLU更常用。

2.3.6 RBF（径向基函数）隐单元

$$h_i = \exp\left(-\frac{\|W_{i,:} - x\|^2}{2\sigma_i^2}\right)$$

当输入接近权重中心时激活最强，常用于径向基函数网络（RBFN）。

2.3.7 激活函数选取准则

  • 默认选择：ReLU（简单高效，适合大多数情况）
  • 存在Dead ReLU问题时：Leaky ReLU 或 ELU
  • 输出层二分类：Sigmoid；多分类：Softmax；回归：线性
  • RNN/LSTM：tanh（有界，利于梯度稳定）
  • 现代大模型：SiLU（Swish）、GELU（平滑、无负值截断）

2.4 反向传播算法完整推导

2.4.1 链式法则（多维形式）

设 $y = f(g(x))$，标量对向量的导数（雅可比矩阵）：

$$\frac{\partial \vec{y}}{\partial \vec{x}} = \frac{\partial \vec{y}}{\partial \vec{g}} \cdot \frac{\partial \vec{g}}{\partial \vec{x}}$$

其中雅可比矩阵 $J = \frac{\partial \vec{y}}{\partial \vec{x}}$，元素 $J_{ij} = \frac{\partial y_i}{\partial x_j}$。

2.4.2 前向传播

对于 $L$ 层网络，第 $l$ 层的前向传播：

$$z^{(l)} = W^{(l)} a^{(l-1)} + b^{(l)}, \quad a^{(l)} = f_l(z^{(l)})$$

其中 $a^{(0)} = x$（输入），$\hat{y} = a^{(L)}$（输出）。

2.4.3 误差项（Error Signal）推导

定义第 $l$ 层的误差项（delta）为损失对该层净输入的梯度：

$$\delta^{(l)} = \frac{\partial \mathcal{L}}{\partial z^{(l)}}$$

输出层误差项（以交叉熵+softmax为例）：

$$\delta^{(L)} = \hat{y} - y$$

隐藏层误差项反向传播：

推导过程

由链式法则：

$$\frac{\partial \mathcal{L}}{\partial z^{(l)}} = \frac{\partial \mathcal{L}}{\partial a^{(l)}} \odot f'_l(z^{(l)})$$

其中 $\frac{\partial \mathcal{L}}{\partial a^{(l)}} = (W^{(l+1)})^T \frac{\partial \mathcal{L}}{\partial z^{(l+1)}} = (W^{(l+1)})^T \delta^{(l+1)}$

因此：

$$\delta^{(l)} = f'_l(z^{(l)}) \odot (W^{(l+1)})^T \delta^{(l+1)}$$
$$\delta^{(l)} = f'_l(z^{(l)}) \odot (W^{(l+1)})^T \delta^{(l+1)}$$

2.4.4 权重梯度与偏置梯度

权重梯度推导

$z^{(l)} = W^{(l)} a^{(l-1)} + b^{(l)}$，因此：

$$\frac{\partial \mathcal{L}}{\partial W^{(l)}} = \frac{\partial \mathcal{L}}{\partial z^{(l)}} \cdot \frac{\partial z^{(l)}}{\partial W^{(l)}} = \delta^{(l)} (a^{(l-1)})^T$$

偏置梯度：

$$\frac{\partial \mathcal{L}}{\partial b^{(l)}} = \frac{\partial \mathcal{L}}{\partial z^{(l)}} \cdot \frac{\partial z^{(l)}}{\partial b^{(l)}} = \delta^{(l)}$$
$$\frac{\partial \mathcal{L}}{\partial W^{(l)}} = \delta^{(l)}(a^{(l-1)})^T, \quad \frac{\partial \mathcal{L}}{\partial b^{(l)}} = \delta^{(l)}$$

2.4.5 反向传播完整算法流程

  1. 前向传播：逐层计算 $z^{(l)}$ 和 $a^{(l)}$，存储中间值
  2. 计算输出层误差：$\delta^{(L)} = \nabla_{a^{(L)}}\mathcal{L} \odot f'_L(z^{(L)})$
  3. 反向传播误差：从 $l=L-1$ 到 $l=1$，计算 $\delta^{(l)} = f'_l(z^{(l)}) \odot (W^{(l+1)})^T\delta^{(l+1)}$
  4. 计算梯度：$\nabla_{W^{(l)}}\mathcal{L} = \delta^{(l)}(a^{(l-1)})^T$，$\nabla_{b^{(l)}}\mathcal{L} = \delta^{(l)}$
  5. 参数更新：$W^{(l)} \leftarrow W^{(l)} - \eta \nabla_{W^{(l)}}\mathcal{L}$
计算复杂度

反向传播的时间复杂度与前向传播相同（均为 $O(W)$，$W$ 为参数总数）。这是深度学习高效训练的关键。

三、正则化

正则化是防止过拟合、提高模型泛化能力的技术集合。

3.1 L2正则化完整推导

L2正则化（权重衰减，Weight Decay）在目标函数中添加权重的L2范数惩罚项：

$$\tilde{J}(w; X, y) = J(w; X, y) + \frac{\alpha}{2} w^T w$$

梯度为：

$$\nabla_w \tilde{J} = \nabla_w J + \alpha w$$

权重更新公式（权重衰减）：

$$w \leftarrow (1 - \epsilon\alpha)w - \epsilon \nabla_w J$$

每次更新前，权重先乘以 $(1-\epsilon\alpha) < 1$，即权重向0收缩。

3.1.1 在最优点邻域的泰勒展开分析

L2正则化的特征值分解分析

设无正则化时的最优参数为 $w^*$，在 $w^*$ 邻域对 $J$ 进行二阶泰勒展开：

$$J(w) \approx J(w^*) + \frac{1}{2}(w-w^*)^T H (w-w^*)$$

（一阶项为0，因为 $w^*$ 是极小值点，$\nabla_w J(w^*) = 0$）

加入L2正则化后，目标函数变为：

$$\tilde{J}(w) = J(w^*) + \frac{1}{2}(w-w^*)^T H (w-w^*) + \frac{\alpha}{2}w^T w$$

对 $\tilde{J}$ 求梯度并令其为0：

$$H(w-w^*) + \alpha w = 0$$ $$(H + \alpha I)w = Hw^*$$ $$\tilde{w}^* = (H + \alpha I)^{-1} H w^*$$

对Hessian矩阵进行特征值分解：$H = Q\Lambda Q^T$，代入：

$$\tilde{w}^* = Q(\Lambda + \alpha I)^{-1}\Lambda Q^T w^*$$
$$\tilde{w}^* = Q(\Lambda + \alpha I)^{-1}\Lambda Q^T w^*$$

物理意义：在Hessian特征向量方向上，参数被缩放因子 $\frac{\lambda_i}{\lambda_i + \alpha}$ 压缩。

  • 当 $\lambda_i \gg \alpha$：$\frac{\lambda_i}{\lambda_i+\alpha} \approx 1$，该方向几乎不受正则化影响（Hessian特征值大 = 该方向曲率大 = 重要方向）
  • 当 $\lambda_i \ll \alpha$：$\frac{\lambda_i}{\lambda_i+\alpha} \approx \frac{\lambda_i}{\alpha} \approx 0$，该方向参数被强烈压缩（曲率小 = 不重要方向）

3.2 L1正则化完整推导

L1正则化在目标函数中添加权重的L1范数惩罚项：

$$\tilde{J}(w) = J(w) + \alpha \|w\|_1 = J(w) + \alpha \sum_i |w_i|$$

梯度（次梯度）：

$$\nabla_w \tilde{J} = \nabla_w J + \alpha \text{sign}(w)$$

其中 $\text{sign}(w_i) = \begin{cases} 1 & w_i > 0 \\ -1 & w_i < 0 \\ 0 & w_i = 0 \end{cases}$

3.2.1 L1正则化解析解（软阈值）

L1正则化解析解推导

假设Hessian矩阵为对角矩阵（各参数独立），$H = \text{diag}(H_{11}, \ldots, H_{dd})$，对目标函数二阶展开：

$$\tilde{J}(w) \approx J(w^*) + \sum_i \left[\frac{1}{2}H_{ii}(w_i - w_i^*)^2 + \alpha|w_i|\right]$$

对每个分量独立求解，令导数为0：

$$H_{ii}(w_i - w_i^*) + \alpha \text{sign}(w_i) = 0$$

分情况讨论：

  • 若 $w_i^* > \alpha/H_{ii}$：$w_i > 0$，解为 $w_i = w_i^* - \alpha/H_{ii}$
  • 若 $w_i^* < -\alpha/H_{ii}$：$w_i < 0$，解为 $w_i = w_i^* + \alpha/H_{ii}$
  • 若 $|w_i^*| \leq \alpha/H_{ii}$：$w_i = 0$（参数被截断为0）

统一写为软阈值（Soft Thresholding）函数：

$$\tilde{w}_i^* = \text{sign}(w_i^*) \max\left(|w_i^*| - \frac{\alpha}{H_{ii}}, 0\right)$$

L1产生稀疏性的原因：当 $|w_i^*| \leq \alpha/H_{ii}$ 时，参数被直接截断为0。L1正则化对所有参数施加等量的绝对值惩罚（与值大小无关），小参数更容易被截断为0，从而产生稀疏解。相比之下，L2正则化对大参数惩罚更重，倾向于使参数均匀缩小但不为0。

3.3 显式约束正则化

通过约束参数范数实现正则化，等价于带约束的优化问题：

$$\min_w J(w) \quad \text{s.t.} \quad \Omega(w) \leq k$$

拉格朗日函数形式：$\mathcal{L}(w, \lambda) = J(w) + \lambda(\Omega(w) - k)$，KKT条件给出 $\lambda \geq 0$，$\lambda(\Omega(w)-k)=0$。

3.4 数据增强

数据增强通过对训练数据施加变换来人为扩充数据集，是最有效的正则化方法之一。

线性变换：对输入 $x$ 施加线性变换 $Tx$，标签不变（或已知变换规律）。

图像增强方法：

  • 平移（Translation）：随机水平/垂直平移若干像素，填充边界（镜像/零填充）
  • 旋转（Rotation）：随机旋转 $\pm\theta$ 度（如 $\pm 15°$），对旋转不变的任务有效
  • 翻转（Flip）：水平翻转（图像分类常用）；垂直翻转（需注意语义）
  • 颜色抖动（Color Jitter）：随机调整亮度、对比度、饱和度、色调，增强颜色鲁棒性
  • 裁剪（Crop）：随机裁剪并缩放到固定大小（如ResNet训练常用）
  • 混合增强：Mixup（线性插值两张图片及标签），CutMix（区域替换）

3.5 噪声注入

输入噪声注入

训练时在输入 $x$ 上添加高斯噪声 $\tilde{x} = x + \epsilon$，$\epsilon \sim \mathcal{N}(0, \sigma^2 I)$。等价于数据增强，提高对输入扰动的鲁棒性。

权重噪声注入

训练时在权重上添加噪声 $\tilde{W} = W + \epsilon$，$\epsilon \sim \mathcal{N}(0, \eta^2 I)$。对于RNN，权重噪声注入等价于Bayesian推断，鼓励权重进入平坦极小值区域。

输出噪声注入（标签平滑）

标签平滑正则化（Label Smoothing）：将硬标签替换为软标签：

$$\tilde{y}_k = (1-\epsilon) y_k + \frac{\epsilon}{K}$$

其中 $K$ 为类别数，$\epsilon$ 为平滑参数（通常0.1）。防止模型过于自信，提高校准性。

3.6 早停（Early Stopping）

策略：监控验证集损失，当验证集损失连续 $p$ 轮不下降时停止训练，保存验证集损失最低时的参数。

代价：需要定期评估验证集（计算开销），保存最佳参数（存储开销）。

二次训练策略（利用所有数据）：

  • 策略一：用全部数据（训练集+验证集）重新训练，训练轮数等于早停确定的最优轮数
  • 策略二：继续用全部数据训练早停得到的模型，直到验证集损失降至早停时的水平
早停的正则化效果

可以证明，在二次损失函数下，早停等价于L2正则化，正则化强度与训练步数成反比。

3.7 参数共享（Parameter Sharing）

强制某些参数相等，减少有效参数数量。最典型的例子：

  • CNN的权重共享：同一卷积核在不同位置共享权重，参数量从 $O(HWC_{in}C_{out})$ 降至 $O(k^2 C_{in}C_{out})$
  • RNN的时间步共享：循环权重矩阵在所有时间步共享

3.8 Dropout完整描述

Dropout是一种高效的集成正则化方法，训练时随机"丢弃"部分神经元。

训练阶段

对每个神经元独立采样掩码 $m_i \sim \text{Bernoulli}(1-p_{drop})$（保留概率为 $1-p_{drop}$）：

$$y = f(Wx) \odot m, \quad m_i \sim \text{Bernoulli}(1-p_{drop})$$

训练目标为期望损失（对所有可能的掩码 $\mu$）：

$$\mathbb{E}_\mu[J(\theta, \mu)]$$

测试阶段

使用全部神经元，但对权重进行缩放以保持期望输出不变：

$$y = (1 - p_{drop}) \cdot f(Wx)$$

或等价地，使用Inverted Dropout：训练时将保留的激活值除以保留概率 $1-p_{drop}$，测试时直接使用原始权重：

$$y_{train} = \frac{f(Wx) \odot m}{1-p_{drop}}, \quad y_{test} = f(Wx)$$

Dropout = 指数级子网络集成

对于有 $n$ 个神经元的网络，Dropout相当于训练了 $2^n$ 个共享权重的子网络（Bagging近似）。测试时使用全部神经元相当于对所有子网络的预测取几何平均。

注意事项

  • 推断期间权重调整：若训练时未使用Inverted Dropout，推断时需将权重乘以 $p/(1-p_{drop})$
  • 通常对全连接层使用较高的dropout率（0.5），对卷积层使用较低的dropout率（0.1-0.2）
  • Dropout不适合小数据集（子网络无法充分训练）
  • 与BatchNorm一起使用时需谨慎（存在方差偏移问题）

3.9 半监督学习

通过让生成模型和判别模型共享参数来利用无标注数据。

  • 生成模型：学习数据分布 $p(x)$，利用无标注数据
  • 判别模型：学习条件分布 $p(y|x)$，利用有标注数据
  • 共享参数：底层表示共享，联合训练，无标注数据通过生成任务间接帮助分类任务

四、优化算法

4.1 神经网络优化挑战

4.1.1 病态Hessian矩阵

病态矩阵（ill-conditioned matrix）指条件数 $\kappa(H) = \lambda_{max}/\lambda_{min}$ 很大的Hessian矩阵。

对损失函数进行泰勒展开，梯度下降一步后的损失变化：

$$f(x_0 - \epsilon g) \approx f(x_0) - \epsilon g^T g + \frac{1}{2}\epsilon^2 g^T H g$$

当 $g^T H g \gg g^T g$ 时（Hessian病态），即使梯度范数不大，二阶项也可能导致损失上升。此时需要很小的学习率，收敛极慢。

4.1.2 局部极小值

深度网络中存在大量局部极小值，但实验表明：大多数局部极小值的损失值与全局极小值相近（"等价极小值"）。

梯度范数诊断方法：若训练过程中梯度范数 $\|\nabla J\|$ 持续接近0但损失仍高，说明陷入局部极小值（而非鞍点）。

4.1.3 鞍点

鞍点处梯度为0，但Hessian矩阵有正有负特征值（既非极大也非极小）。

  • 高维更常见：在 $n$ 维空间中，随机临界点是鞍点的概率远高于极小值
  • 一阶方法的影响：SGD因噪声可以逃离鞍点，但收敛慢
  • 牛顿法的影响：牛顿法会被鞍点吸引（因为 $H^{-1}g$ 在负曲率方向会走错方向）

4.1.4 悬崖（Cliffs）与梯度截断

RNN中常出现梯度悬崖：损失曲面在某些方向上极其陡峭，一步梯度更新可能导致参数跳跃到很远的位置。

梯度截断（Gradient Clipping）策略：

  • 按值截断：$g_i \leftarrow \text{clip}(g_i, -c, c)$
  • 按模截断：若 $\|g\| > c$，则 $g \leftarrow \frac{c}{\|g\|} g$（保持方向）

4.1.5 长期依赖与梯度消失/爆炸

在RNN中，梯度从时刻 $t$ 反向传播到时刻 $i$：

$$\nabla_{h_i} J = (W^{t-i})^T \nabla_{h_t} J$$

设 $W$ 的特征值分解为 $W = Q\Lambda Q^T$，则 $W^{t-i} = Q\Lambda^{t-i}Q^T$。

  • 若 $|\lambda_i| > 1$：梯度指数爆炸
  • 若 $|\lambda_i| < 1$：梯度指数消失

这导致RNN难以学习长期依赖关系。解决方案：LSTM/GRU（门控机制），梯度截断（解决爆炸），残差连接。

4.2 Mini-Batch梯度下降

三种梯度下降变体对比：

方法批大小梯度估计收敛性计算效率
批梯度下降（BGD）全部N精确稳定，可能局部极小低（每步计算全部数据）
随机梯度下降（SGD）1噪声大震荡，有助逃离局部极小高但硬件利用率低
Mini-batch SGD32-512适中噪声平衡最优（向量化）

使用Mini-batch的理由：

  • 梯度估计误差随批大小 $B$ 增大，误差降低正比于 $1/\sqrt{B}$（低于线性收益）
  • 大批量中存在大量冗余样本（梯度相似）
  • 小批量引入的噪声有正则化效果，有助于泛化
  • GPU并行化：批大小太小无法充分利用硬件

批大小的权衡：大批量收敛快但泛化差（sharp minima），小批量收敛慢但泛化好（flat minima）。

4.3 基本优化算法详细推导

4.3.1 SGD（随机梯度下降）

$$\theta \leftarrow \theta - \epsilon \hat{g}$$

其中 $\hat{g} = \frac{1}{B}\sum_{i=1}^B \nabla_\theta L(f(x^{(i)};\theta), y^{(i)})$ 为mini-batch梯度估计。

收敛条件（学习率序列 $\{\epsilon_k\}$）：

$$\sum_{k=1}^\infty \epsilon_k = \infty, \quad \sum_{k=1}^\infty \epsilon_k^2 < \infty$$

第一个条件确保可以到达任何点，第二个条件确保最终收敛（噪声积累有界）。

学习率衰减公式：

$$\epsilon_k = \epsilon_0 \cdot \frac{\tau}{\max(k, \tau)}, \quad \text{或} \quad \epsilon_k = \epsilon_0 \cdot \gamma^k$$

4.3.2 动量方法（Momentum）

引入速度向量 $v$ 累积历史梯度方向：

$$v \leftarrow \alpha v - \epsilon \hat{g}$$ $$\theta \leftarrow \theta + v$$

$\alpha \in [0,1)$ 为动量系数，通常取0.9或0.99。等效学习率为 $\epsilon/(1-\alpha)$，动量越大等效学习率越大。

物理直觉：参数更新如同小球在损失曲面滚动，在一致方向上加速，在震荡方向上抑制。

4.3.3 Nesterov动量

在"预测位置"处计算梯度，而非当前位置：

$$v \leftarrow \alpha v - \epsilon \nabla_\theta J(\theta + \alpha v)$$ $$\theta \leftarrow \theta + v$$

Nesterov动量比标准动量收敛更快，在凸优化中有更好的理论保证（$O(1/k^2)$ vs $O(1/k)$）。

4.3.4 AdaGrad

自适应学习率：为每个参数维护累积平方梯度 $r$：

$$r \leftarrow r + \hat{g} \odot \hat{g}$$ $$\Delta\theta = -\frac{\epsilon}{\sqrt{r + \delta}} \odot \hat{g}$$

$\delta$ 为小常数（如 $10^{-7}$）防止除零。历史梯度大的参数学习率小，历史梯度小的参数学习率大。

缺点：$r$ 单调递增，学习率单调递减，可能过早停止学习。

4.3.5 RMSProp

用指数移动平均代替累积，解决AdaGrad学习率过度衰减问题：

$$r \leftarrow \rho r + (1-\rho) \hat{g} \odot \hat{g}$$ $$\Delta\theta = -\frac{\epsilon}{\sqrt{r + \delta}} \odot \hat{g}$$

$\rho$ 为衰减率（通常0.9），$r$ 估计近期梯度的均方。

学习率分析：有效学习率为 $\epsilon/\sqrt{r}$，自动适应各参数的梯度尺度。

4.3.6 RMSProp + 动量

$$r \leftarrow \rho r + (1-\rho) \hat{g} \odot \hat{g}$$ $$v \leftarrow \alpha v - \frac{\epsilon}{\sqrt{r+\delta}} \odot \hat{g}$$ $$\theta \leftarrow \theta + v$$

4.3.7 Adam完整步骤

Adam（Adaptive Moment Estimation）结合了动量和RMSProp，并引入偏差修正：

  1. 计算梯度：$g \leftarrow \nabla_\theta J(\theta)$
  2. 更新一阶矩（动量）：$s \leftarrow \rho_1 s + (1-\rho_1) g$
  3. 更新二阶矩（梯度平方的EMA）：$r \leftarrow \rho_2 r + (1-\rho_2) g \odot g$
  4. 偏差修正（初始时刻矩估计偏低）：$\hat{s} = \frac{s}{1-\rho_1^t}, \quad \hat{r} = \frac{r}{1-\rho_2^t}$
  5. 参数更新：$\theta \leftarrow \theta - \frac{\epsilon}{\sqrt{\hat{r}} + \delta} \odot \hat{s}$
$$\hat{s} = \frac{s}{1-\rho_1^t}, \quad \hat{r} = \frac{r}{1-\rho_2^t}, \quad \Delta\theta = -\frac{\epsilon}{\sqrt{\hat{r}}+\delta} \odot \hat{s}$$

推荐超参数：$\rho_1=0.9$，$\rho_2=0.999$，$\epsilon=10^{-3}$，$\delta=10^{-8}$。

Adam vs SGD泛化能力对比

实验表明，Adam在训练损失上收敛更快，但在某些任务（如图像分类）上泛化能力不如SGD+动量。原因分析：

  • Adam倾向于找到"尖锐"的极小值（sharp minima），泛化差
  • SGD的噪声有助于找到"平坦"的极小值（flat minima），泛化好
  • Adam对学习率不敏感（自适应），但可能过早停止探索

4.4 贪心监督预训练

逐层预训练策略（已较少使用，但有理论意义）：

  1. 训练第1层（或前几层）网络，冻结其他层
  2. 将第1层输出作为第2层输入，训练第2层
  3. 重复直到所有层预训练完毕
  4. 联合微调所有层（fine-tuning）

预训练提供更好的初始化，有助于深层网络训练（在BatchNorm普及前尤为重要）。

4.5 参数初始化

权重初始大小的影响

  • 对称性破坏：若所有权重初始化为相同值，所有神经元更新相同（对称性），网络无法学习不同特征。必须随机初始化。
  • 梯度消失/爆炸：权重过小 → 前向信号逐层缩小 → 梯度消失；权重过大 → 信号爆炸 → 梯度爆炸

均匀分布初始化

$$W_{ij} \sim U\left(-\sqrt{\frac{1}{m}}, \sqrt{\frac{1}{m}}\right)$$

其中 $m$ 为输入维度（fan-in）。

Xavier初始化（Glorot初始化）

使前向传播和反向传播的方差保持一致：

$$W_{ij} \sim U\left(-\sqrt{\frac{6}{m+n}}, \sqrt{\frac{6}{m+n}}\right)$$

其中 $m$ 为fan-in，$n$ 为fan-out。适合tanh激活函数。

He初始化（Kaiming初始化）

$$W_{ij} \sim \mathcal{N}\left(0, \frac{2}{m}\right)$$

专为ReLU激活设计，考虑到ReLU将一半激活截断为0。

偏置初始化

  • 通常初始化为0（偏置不存在对称性问题）
  • ReLU：有时初始化为小正值（如0.1）防止Dead ReLU
  • 遗忘门偏置（LSTM）：初始化为1，鼓励初期记忆

4.6 梯度截断

按值截断：

$$g_i \leftarrow \max(-c, \min(c, g_i))$$

按模截断（推荐，保持梯度方向）：

$$\text{若} \|g\| > c, \quad g \leftarrow \frac{c}{\|g\|} g$$

按模截断保持梯度方向不变，只调整步长，效果更好。

五、归一化方法

5.1 Batch Normalization完整推导

5.1.1 内部协变量偏移（Internal Covariate Shift, ICS）

在深度网络训练中，每层输入的分布随着前层参数的更新而不断变化，这一现象称为内部协变量偏移（ICS）。ICS导致：

  • 每层需要不断适应新的输入分布，减慢训练速度
  • 需要使用更小的学习率和更谨慎的初始化
  • 饱和激活函数（sigmoid/tanh）更容易饱和

5.1.2 BN算法完整推导

对于一个mini-batch $\mathcal{B} = \{x^{(1)}, \ldots, x^{(m)}\}$，BN对每个特征维度独立归一化：

  1. 计算mini-batch均值：$\mu_\mathcal{B} = \frac{1}{m}\sum_{i=1}^m h_i$
  2. 计算mini-batch方差：$\sigma_\mathcal{B}^2 = \frac{1}{m}\sum_{i=1}^m (h_i - \mu_\mathcal{B})^2$
  3. 归一化：$h_i^1 = \frac{h_i - \mu_\mathcal{B}}{\sqrt{\sigma_\mathcal{B}^2 + \epsilon}}$
  4. 缩放和平移（恢复表达能力）：$h_i^2 = \gamma \odot h_i^1 + \beta$
$$h_i^1 = \frac{h_i - \mu_\mathcal{B}}{\sqrt{\sigma_\mathcal{B}^2 + \epsilon}}, \quad h_i^2 = \gamma \odot h_i^1 + \beta$$

其中 $\gamma, \beta$ 为可学习参数，$\epsilon$ 为数值稳定常数（如 $10^{-5}$）。

5.1.3 BN反向传播完整公式

BN反向传播推导

设 $\frac{\partial L}{\partial h_i^2}$ 已知，逐步反传：

对 $\gamma, \beta$ 的梯度：

$$\nabla_\gamma L = \sum_{i=1}^m \frac{\partial L}{\partial h_i^2} \odot h_i^1, \quad \nabla_\beta L = \sum_{i=1}^m \frac{\partial L}{\partial h_i^2}$$

对归一化输出的梯度：

$$\frac{\partial L}{\partial h_i^1} = \frac{\partial L}{\partial h_i^2} \odot \gamma$$

对方差的梯度：

$$\nabla_{\sigma^2} L = \sum_{i=1}^m \frac{\partial L}{\partial h_i^1} \odot (h_i - \mu) \cdot \left(-\frac{1}{2}\right)(\sigma^2+\epsilon)^{-3/2}$$

对均值的梯度：

$$\nabla_\mu L = \sum_{i=1}^m \frac{\partial L}{\partial h_i^1} \cdot \frac{-1}{\sqrt{\sigma^2+\epsilon}} + \nabla_{\sigma^2} L \cdot \frac{\sum_i -2(h_i-\mu)}{m}$$

对输入的梯度：

$$\nabla_{h_i} L = \frac{\partial L}{\partial h_i^1} \cdot \frac{1}{\sqrt{\sigma^2+\epsilon}} + \nabla_{\sigma^2} L \cdot \frac{2(h_i-\mu)}{m} + \frac{\nabla_\mu L}{m}$$

5.1.4 BN的优点

  • 允许使用更大学习率，加速训练
  • 减少对参数初始化的敏感性
  • 有正则化效果（mini-batch统计量引入噪声），可减少Dropout使用
  • 缓解梯度消失/爆炸（归一化后激活值处于合适范围）

5.1.5 BN的不足

  • 依赖batch size：batch size太小时统计量不稳定（通常需要 $\geq 32$）
  • 不适合RNN：序列长度变化，不同时间步batch统计量不同
  • 训练和推断行为不同（需要维护运行均值/方差）
  • 不适合在线学习（单样本无法计算batch统计量）

5.1.6 权重伸缩不变性与数据伸缩不变性

权重伸缩不变性：若权重 $W$ 缩放为 $cW$，BN归一化后的输出不变：

$$\text{BN}(cWx) = \text{BN}(Wx)$$

这意味着BN对权重的绝对尺度不敏感，梯度更新更稳定。

数据伸缩不变性：若输入数据缩放，BN归一化后结果不变，模型对输入尺度鲁棒。

5.1.7 测试阶段处理

测试时使用训练集的运行均值（Running Mean）和运行方差（Running Variance）：

$$\mu_{run} \leftarrow \beta \mu_{run} + (1-\beta)\mu_\mathcal{B}$$ $$\sigma^2_{run} \leftarrow \beta \sigma^2_{run} + (1-\beta)\sigma^2_\mathcal{B}$$

测试时使用 $\mu_{run}$ 和 $\sigma^2_{run}$ 进行归一化，确保推断确定性。

5.2 Layer Normalization

LayerNorm对同一样本的所有特征进行归一化（而非同一特征的不同样本）：

$$\mu = \frac{1}{H}\sum_{i=1}^H h_i, \quad \sigma^2 = \frac{1}{H}\sum_{i=1}^H (h_i-\mu)^2$$ $$\hat{h}_i = \frac{h_i - \mu}{\sqrt{\sigma^2+\epsilon}}, \quad y_i = \gamma_i \hat{h}_i + \beta_i$$

与BN的区别：

特性Batch NormLayer Norm
归一化维度沿batch维度（同特征不同样本）沿特征维度（同样本不同特征）
batch size依赖强依赖无依赖
适用场景CNN（大batch）RNN、Transformer、在线学习
训练/推断一致性不同（需运行统计量）相同

LayerNorm适合在线学习和RNN：每个样本独立归一化，不需要batch统计量，适合序列长度变化的RNN和单样本推断。

5.3 局部响应归一化（LRN）

LRN在同一位置的相邻通道间进行归一化（模拟侧抑制）：

$$b_{x,y}^i = a_{x,y}^i \left(k + \alpha \sum_{j=\max(0,i-n/2)}^{\min(N-1,i+n/2)} (a_{x,y}^j)^2\right)^{-\beta}$$

其中 $a_{x,y}^i$ 为位置 $(x,y)$ 第 $i$ 通道的激活值，$k, \alpha, \beta, n$ 为超参数。AlexNet使用LRN，但后来证明效果有限，BatchNorm出现后LRN基本被取代。

5.4 RMSNorm

RMSNorm是LayerNorm的简化版，只使用均方根归一化（去掉均值中心化）：

$$\text{RMSNorm}(x) = \frac{x}{\text{RMS}(x)} \cdot \gamma, \quad \text{RMS}(x) = \sqrt{\frac{1}{H}\sum_{i=1}^H x_i^2}$$

计算更简单，在LLaMA等大模型中广泛使用。

5.5 Pre-norm vs Post-norm

Post-norm（原始Transformer）：LayerNorm在残差连接之后：

$$x_{l+1} = \text{LayerNorm}(x_l + F(x_l))$$

Pre-norm（现代LLM常用）：LayerNorm在子层之前：

$$x_{l+1} = x_l + F(\text{LayerNorm}(x_l))$$

梯度稳定性：Pre-norm中，梯度可以通过残差连接 $x_l$ 直接传到输入层，梯度路径更短，训练更稳定，允许更大学习率。Post-norm在深层网络中梯度消失问题更严重，但最终性能可能略好。

六、卷积神经网络

6.1 CNN动机

全连接网络处理图像存在的问题：

  • 参数量巨大：$224\times224\times3$ 的图像输入全连接层，仅第一层参数就达 $224^2\times3 \approx 150K$
  • 忽略空间结构：像素的空间位置关系被打平忽略
  • 平移不变性差：同一物体在不同位置需要重新学习

CNN三大特性：

  • 局部连接（Local Connectivity）：每个神经元只连接输入的局部区域（感受野），参数大幅减少
  • 权重共享（Weight Sharing）：同一卷积核在所有位置共享参数，进一步减少参数，赋予平移等变性
  • 池化（Pooling）：下采样，减少特征图尺寸，增加感受野，提供平移不变性

6.2 卷积定义

6.2.1 一维卷积

$$y_t = \sum_{k=1}^m w_k x_{t-k+1} = (w * x)_t$$

卷积核 $w \in \mathbb{R}^m$ 在序列 $x$ 上滑动，输出序列 $y$。

6.2.2 二维卷积

$$y_{ij} = \sum_{u=1}^{m_1}\sum_{v=1}^{m_2} w_{uv} x_{i-u+1,j-v+1}$$

其中 $w \in \mathbb{R}^{m_1 \times m_2}$ 为卷积核，$x \in \mathbb{R}^{H \times W}$ 为输入特征图。

6.2.3 互相关（Cross-Correlation）

深度学习中实际使用的是互相关（不翻转卷积核）：

$$y_{ij} = \sum_{u,v} w_{uv} x_{i+u-1, j+v-1}$$

与卷积的区别：卷积需要将卷积核旋转180°，互相关不需要。由于卷积核参数通过学习得到，旋转与否不影响表达能力，深度学习中统称"卷积"但实际为互相关。

6.2.4 循环矩阵表示

一维卷积可表示为矩阵乘法 $y = Wx$，其中 $W$ 为循环矩阵（Toeplitz矩阵）：

$$W = \begin{pmatrix} w_1 & 0 & \cdots & w_m & \cdots & w_2 \\ w_2 & w_1 & 0 & \cdots & w_m & \cdots \\ \vdots & & \ddots & & & \vdots \\ w_m & \cdots & w_2 & w_1 & 0 & \cdots \end{pmatrix}$$

6.2.5 三种卷积模式

模式输出尺寸（输入$n$，核$m$，步长$s$，填充$p$）特点
窄卷积（Valid）$\lfloor(n-m)/s\rfloor + 1$（$p=0$）输出最小，无填充
等宽卷积（Same）$\lceil n/s \rceil$（$p=(m-1)/2$）步长1时输出与输入同尺寸
宽卷积（Full）$n+m-1$（$p=m-1$）输出最大，充分填充

6.3 卷积层反向传播

对卷积核的梯度

$$\frac{\partial f}{\partial W} = \frac{\partial f}{\partial Y} \otimes X$$

即损失对卷积核的梯度等于输出梯度与输入的互相关。

对输入的梯度

$$\frac{\partial f}{\partial X} = \text{rot180}(W) \tilde{\otimes} \frac{\partial f}{\partial Y}$$

其中 $\tilde{\otimes}$ 表示全卷积（宽卷积），$\text{rot180}(W)$ 为将卷积核旋转180°。

误差项传播

从卷积层传到池化层（上采样）：

$$\delta^{(l,p)} = f'_l(Z^{(l,p)}) \odot \text{up}(\delta^{(l+1,p)})$$

其中 $\text{up}(\cdot)$ 为上采样操作（将池化层的误差扩展到卷积层大小）。

从卷积层传到前一卷积层：

$$\delta^{(l,p)} = f'_l(Z^{(l,p)}) \odot \sum_q \text{rot180}(W^{(l+1,pq)}) \tilde{\otimes} \delta^{(l+1,q)}$$

6.4 池化层

  • 最大池化（Max Pooling）：取感受野内最大值，保留最强特征，梯度只传到最大值位置
  • 平均池化（Average Pooling）：取感受野内平均值，梯度均匀分配到所有位置

池化的作用：减少特征图尺寸（降低计算量），增大感受野，提供局部平移不变性，防止过拟合。

6.5 连接表（Connection Table）

不同输入特征图与不同卷积核之间的连接关系表，控制哪些输入通道参与生成哪些输出通道。稀疏连接表可以减少参数量，实现不同通道间的选择性连接（如LeNet-5中使用）。

6.6 卷积变体详细

6.6.1 局部连接 vs 卷积

局部连接：每个位置有独立权重 $W_{i,j,k,l,m,n}$（输出位置 $(i,j)$，输出通道 $k$，感受野位置 $(l,m)$，输入通道 $n$），不共享权重。卷积是局部连接的特例（权重共享）。

6.6.2 拼接卷积（Tile Convolution）

在 $t$ 种卷积核之间循环使用，不同位置使用不同但周期性重复的卷积核：

$$y_{i,j,k} = \sum_{l,m,n} W_{k, l, m, n, (i\%t), (j\%t)} x_{i+l-1, j+m-1, n}$$

介于全连接局部和权重共享卷积之间，参数量是卷积的 $t^2$ 倍。

6.6.3 分组卷积（Group Convolution）

将输入通道分为 $g$ 组，每组独立进行卷积：

  • 参数量：标准卷积 $C_{in} \times C_{out} \times k^2$，分组卷积 $\frac{C_{in}}{g} \times \frac{C_{out}}{g} \times k^2 \times g = \frac{C_{in} \times C_{out} \times k^2}{g}$，减少 $g$ 倍
  • 计算量：同样减少 $g$ 倍
  • AlexNet中使用（因显存限制），后被ShuffleNet、MobileNet等广泛采用

6.6.4 小卷积核替代大卷积核

两个 $3\times3$ 卷积核堆叠等效感受野为 $5\times5$，三个等效 $7\times7$：

$$n = (k-1)/2 \text{（当 } k'=3 \text{时，堆叠 } n \text{ 层等效感受野为 } 2n+1）$$

优势：两个 $3\times3$ 参数量 $2\times9=18 < 25$（$5\times5$），且包含更多非线性变换，表达能力更强。

6.6.5 非对称卷积核

用 $1\times n$ 和 $n\times1$ 两个卷积核替代 $n\times n$ 卷积核：

$$\text{参数量比} = \frac{2n}{n^2} = \frac{2}{n}$$

$n=3$ 时减少33%，$n=7$ 时减少71%。Inception-v3中大量使用。

6.6.6 多尺寸卷积核（Inception思想）

同一层使用多种尺寸的卷积核（$1\times1$, $3\times3$, $5\times5$）并行处理，拼接输出，捕获不同尺度的特征。

6.6.7 1×1卷积核

三个主要作用：

  • 通道数调整：升维或降维（瓶颈层，Bottleneck）
  • 增加非线性：$1\times1$ 卷积后接激活函数，增加网络深度而不增加感受野
  • 跨通道特征融合：对各通道线性组合

瓶颈层参数量对比（以ResNet bottleneck为例）：

$$\text{标准}: 3\times3\times256\times256 = 589824$$ $$\text{瓶颈}: 1\times1\times256\times64 + 3\times3\times64\times64 + 1\times1\times64\times256 = 69632 \approx 1/8$$

6.6.8 DepthWise卷积（深度可分离卷积）

将标准卷积分解为：

  • 深度卷积（Depthwise Conv）：每个输入通道独立卷积（$C_{in}$ 个 $k\times k$ 核）
  • 逐点卷积（Pointwise Conv）：$1\times1$ 卷积混合通道

参数量：

$$\text{标准卷积}: k^2 C_{in} C_{out}$$ $$\text{深度可分离}: k^2 C_{in} + C_{in} C_{out} = C_{in}(k^2 + C_{out})$$ $$\text{压缩比}: \frac{1}{C_{out}} + \frac{1}{k^2}$$

MobileNet中 $k=3, C_{out}=256$ 时，压缩约8-9倍。与分组卷积区别：DepthWise是 $g=C_{in}$（每通道一个核），分组卷积 $g < C_{in}$。

6.6.9 通道混洗分组卷积（ShuffleNet）

分组卷积后进行通道混洗（Channel Shuffle），使不同组的特征能够交互：

  1. 分组卷积：将 $C$ 个通道分为 $g$ 组，各组独立卷积
  2. 通道混洗：将输出reshape为 $(g, C/g)$，转置为 $(C/g, g)$，再flatten
  3. 再次分组卷积

混洗操作使不同组的信息得以交流，弥补分组卷积通道隔离的缺点。

6.6.10 通道加权卷积 SENet（Squeeze-and-Excitation）

三个步骤：

  1. Squeeze（压缩）：全局平均池化 $z_c = \frac{1}{HW}\sum_{i,j} u_c(i,j)$，将 $H\times W\times C$ 压缩为 $1\times1\times C$
  2. Excitation（激励）：两层全连接网络学习通道权重 $s = \sigma(W_2 \text{ReLU}(W_1 z))$
  3. Reweight（重标定）：$\tilde{u}_c = s_c \cdot u_c$，对每个通道特征图加权

SENet通过自适应地重标定通道特征，显式建模通道间的相互依赖关系，以极少的参数开销提升性能。

6.6.11 空洞卷积（Dilation Convolution）

在卷积核元素间插入空洞（间隔 $d$），扩大感受野而不增加参数：

$$S(i,j) = \sum_{m,n} I(i+m(d+1), j+n(d+1)) K(m,n)$$

等效核大小：$k_{eff} = k + (k-1)(d-1) = (k-1)d + 1$。空洞率 $d=1$ 为标准卷积。

网格效应（Gridding Effect）：若所有层使用相同空洞率，感受野内存在"盲点"，部分位置信息丢失。

混合空洞卷积（HDC）三特性：

  • 各层空洞率不同（如1, 2, 5），避免网格效应
  • 空洞率最大公因数为1，确保无盲点
  • 空洞率序列非递减，感受野逐渐增大

6.6.12 转置卷积（矩阵乘法视角）

转置卷积（反卷积）用于上采样，是卷积的"逆操作"（但不是真正的逆，而是转置）：

$$y = Cx \Rightarrow x' = C^T y$$

其中 $C$ 为卷积操作的矩阵表示，$C^T$ 为转置卷积。转置卷积可以学习上采样方式，常用于语义分割（FCN）、生成模型（DCGAN）等。

6.7 卷积网络模型

6.7.1 AlexNet

2012年ImageNet竞赛冠军，深度学习复兴的标志。主要贡献：

  • 使用ReLU激活函数（代替tanh），加速训练
  • GPU并行训练（两块GTX580）
  • Dropout正则化（0.5）
  • 数据增强：随机裁剪 $224\times224$，水平翻转
  • PCA颜色噪声：对RGB通道加入PCA主成分方向的噪声，增强颜色不变性

LRN公式（见5.3节）

预测方法：测试时取10个裁剪块（4角+中心，水平翻转），对10个预测取平均。

6.7.2 VGGNet

2014年，Oxford VGG组提出，ImageNet亚军。主要贡献：

  • 全程使用 $3\times3$ 小卷积核，堆叠深度（16-19层）
  • 证明深度比宽度更重要
  • 通道数随深度加倍（64→128→256→512）
  • 数据预处理：通道零均值化（减去训练集均值）

6.7.3 Inception网络

原始Inception模块：并行使用 $1\times1$, $3\times3$, $5\times5$ 卷积和 $3\times3$ 最大池化，拼接输出。

1×1降维改进：在 $3\times3$ 和 $5\times5$ 卷积前加入 $1\times1$ 卷积降维，大幅减少计算量。

Inception v2/v3差异：v2引入BatchNorm；v3将 $5\times5$ 分解为两个 $3\times3$，将 $n\times n$ 分解为 $1\times n + n\times1$。

Inception设计4原则：

  1. 避免表示瓶颈（特征图尺寸减小时通道数应增加）
  2. 高维表示更易处理（更多通道，更多ReLU，更快学习）
  3. 低维嵌入空间可以进行空间聚合而不损失表达能力
  4. 平衡网络的宽度和深度

6.7.4 ResNet（残差网络）

2015年，微软亚洲研究院提出，ImageNet冠军（152层）。

退化问题：随着网络深度增加，训练误差反而上升（非过拟合），深层网络难以优化。

残差学习：设计残差块，让网络学习残差映射 $F(x) = H(x) - x$（而非直接学习 $H(x)$）：

$$y = F(x, \{W_i\}) + x$$

若恒等映射是最优的，则残差 $F(x)=0$ 比恒等映射 $H(x)=x$ 更容易学习。

跳跃连接（Skip Connection）：将输入直接加到输出，梯度可以直接流过跳跃连接，缓解梯度消失。

解决退化问题的原因：残差块提供了恒等映射的捷径，使深层网络至少不差于浅层网络。

七、循环神经网络

7.1 延时神经网络（DTNN）

延时神经网络（Delay Temporal Neural Network）在输入层引入时间延迟，使用固定窗口内的历史信息：

$$h_t = f(x_t, x_{t-1}, \ldots, x_{t-d})$$

等价于在时间维度上进行卷积，参数量固定，但只能处理固定长度的历史。

7.2 NARX外部输入模型

非线性自回归外部输入模型（Nonlinear AutoRegressive with eXogenous input）：

$$h_t = f(x_t, x_{t-1}, \ldots, x_{t-d_x}, h_{t-1}, \ldots, h_{t-d_h})$$

同时考虑历史输入和历史输出，是RNN的一种变体。

7.3 简单RNN

Elman网络（简单RNN）：

$$z_t = U h_{t-1} + W x_t + b, \quad h_t = f(z_t)$$

其中 $U \in \mathbb{R}^{d_h \times d_h}$ 为循环权重矩阵，$W \in \mathbb{R}^{d_h \times d_x}$ 为输入权重矩阵，$h_t$ 为隐状态。

7.4 三种序列处理模式

模式1：序列→类别

输入序列，输出单个标签（如情感分类）：

$$\hat{y} = g(h_T) \quad \text{或} \quad \hat{y} = g\left(\frac{1}{T}\sum_t h_t\right)$$

模式2：同步序列→序列

输入序列，输出等长序列（如序列标注）：

$$\hat{y}_t = g(h_t), \quad t = 1, \ldots, T$$

模式3：异步序列→序列（Encoder-Decoder）

输入输出序列长度不同（如机器翻译）：

$$\text{Encoder}: h_t = f(h_{t-1}, x_t), \quad c = q(h_1, \ldots, h_T)$$ $$\text{Decoder}: s_t = f(s_{t-1}, y_{t-1}, c), \quad \hat{y}_t = g(s_t, y_{t-1}, c)$$

上下文向量 $c$ 通常取最后隐状态 $h_T$，或加权平均（注意力机制）。

7.5 BPTT完整推导

随时间反向传播（Backpropagation Through Time, BPTT）。

总损失：$\mathcal{L} = \sum_{t=1}^T \mathcal{L}_t$

对循环权重矩阵 $U$ 的梯度：

$$\frac{\partial \mathcal{L}}{\partial U} = \sum_{t=1}^T \frac{\partial \mathcal{L}_t}{\partial U}$$

对 $\mathcal{L}_t$ 关于 $U$ 的梯度需要通过时间反向传播：

BPTT推导

定义误差项 $\delta_{t,k} = \frac{\partial \mathcal{L}_t}{\partial z_k}$（时刻 $t$ 的损失关于时刻 $k$ 净输入的梯度）

对输出时刻：$\delta_{t,t} = \frac{\partial \mathcal{L}_t}{\partial z_t} = \frac{\partial \mathcal{L}_t}{\partial h_t} \odot f'(z_t)$

向前传播（$k < t$）：

$$\delta_{t,k} = \frac{\partial \mathcal{L}_t}{\partial z_k} = \frac{\partial \mathcal{L}_t}{\partial h_k} \odot f'(z_k)$$ $$\frac{\partial \mathcal{L}_t}{\partial h_k} = U^T \frac{\partial \mathcal{L}_t}{\partial z_{k+1}} = U^T \delta_{t,k+1}$$

因此：

$$\delta_{t,k} = \text{diag}(f'(z_k)) U^T \delta_{t,k+1}$$
$$\delta_{t,k} = \text{diag}(f'(z_k)) U^T \delta_{t,k+1}$$

对 $U$ 的梯度：

$$\frac{\partial \mathcal{L}_t}{\partial U} = \sum_{k=1}^t \delta_{t,k} h_{k-1}^T$$

对 $W$ 和 $b$ 的梯度：

$$\frac{\partial \mathcal{L}_t}{\partial W} = \sum_{k=1}^t \delta_{t,k} x_k^T, \quad \frac{\partial \mathcal{L}_t}{\partial b} = \sum_{k=1}^t \delta_{t,k}$$

7.6 RTRL（实时递归学习）

前向计算偏导数，递推公式：

$$\frac{\partial h_t}{\partial \theta} = f'(z_t) \left(\frac{\partial z_t}{\partial \theta} + U \frac{\partial h_{t-1}}{\partial \theta}\right)$$

RTRL vs BPTT比较：RTRL前向传播，适合在线学习，但计算量 $O(d_h^4)$ 更大；BPTT反向传播，需存储所有时刻激活值，适合离线训练，计算量 $O(d_h^2 T)$。

7.7 梯度消失/爆炸

梯度从时刻 $t$ 传到时刻 $k$：

$$\delta_{t,k} = \prod_{i=k}^{t-1} \text{diag}(f'(z_i)) U^T \cdot \delta_{t,t}$$

若 $U$ 的最大特征值 $|\lambda_{max}| > 1$，梯度指数爆炸；若 $|\lambda_{max}| < 1$，梯度指数消失。

解决爆炸：梯度截断（见4.6节）。

改进隐状态更新：引入加性连接，使梯度可以直接流过：

$$h_t = h_{t-1} + g(x_t, h_{t-1}; \theta)$$

这是LSTM/GRU的核心思想。

7.8 LSTM完整公式

长短期记忆网络（Long Short-Term Memory, LSTM）通过门控机制控制信息流动：

候选记忆状态

$$\tilde{c}_t = \tanh(W_c x_t + U_c h_{t-1} + b_c)$$

三个门

$$i_t = \sigma(W_i x_t + U_i h_{t-1} + b_i) \quad \text{（输入门）}$$ $$f_t = \sigma(W_f x_t + U_f h_{t-1} + b_f) \quad \text{（遗忘门）}$$ $$o_t = \sigma(W_o x_t + U_o h_{t-1} + b_o) \quad \text{（输出门）}$$

状态更新

$$c_t = f_t \odot c_{t-1} + i_t \odot \tilde{c}_t$$ $$h_t = o_t \odot \tanh(c_t)$$

遗忘门控制保留多少历史记忆，输入门控制写入多少新信息，输出门控制输出多少记忆。

矩阵合并形式

$$\begin{pmatrix} i_t \\ f_t \\ o_t \\ \tilde{c}_t \end{pmatrix} = \begin{pmatrix} \sigma \\ \sigma \\ \sigma \\ \tanh \end{pmatrix} \left( W \begin{pmatrix} x_t \\ h_{t-1} \end{pmatrix} + b \right)$$

Peephole连接

门控除了依赖 $x_t$ 和 $h_{t-1}$，还直接观察记忆状态 $c_{t-1}$（$c_t$ 对输出门）：

$$i_t = \sigma(W_i x_t + U_i h_{t-1} + V_i c_{t-1} + b_i)$$ $$f_t = \sigma(W_f x_t + U_f h_{t-1} + V_f c_{t-1} + b_f)$$ $$o_t = \sigma(W_o x_t + U_o h_{t-1} + V_o c_t + b_o)$$

其中 $V_i, V_f, V_o$ 为对角矩阵（只连接对应位置的记忆单元）。

耦合输入遗忘门

简化LSTM：$f_t = 1 - i_t$，遗忘和输入互补，减少一个门的参数：

$$c_t = (1-i_t) \odot c_{t-1} + i_t \odot \tilde{c}_t$$

7.9 GRU完整公式

门控循环单元（Gated Recurrent Unit, GRU）是LSTM的简化版，合并记忆状态和隐状态：

重置门

$$r_t = \sigma(W_r x_t + U_r h_{t-1} + b_r)$$

控制使用多少历史信息计算候选状态。

候选状态

$$\tilde{h}_t = \tanh(W_h x_t + U_h (r_t \odot h_{t-1}) + b_h)$$

更新门与状态更新

$$z_t = \sigma(W_z x_t + U_z h_{t-1} + b_z)$$ $$h_t = z_t \odot h_{t-1} + (1-z_t) \odot \tilde{h}_t$$

更新门 $z_t$ 控制保留多少历史状态和写入多少新状态（类似LSTM的遗忘门+输入门的组合）。

GRU比LSTM参数少（无输出门，无记忆状态），在许多任务上性能相近。

7.10 深层RNN

堆叠RNN（Stacked RNN）

$$h_t^{(l)} = f(W^{(l)} h_t^{(l-1)} + U^{(l)} h_{t-1}^{(l)} + b^{(l)})$$

多层RNN，低层学习低级特征，高层学习高级抽象。

双向RNN（Bidirectional RNN）

$$\overrightarrow{h}_t = f(W_f x_t + U_f \overrightarrow{h}_{t-1} + b_f)$$ $$\overleftarrow{h}_t = f(W_b x_t + U_b \overleftarrow{h}_{t+1} + b_b)$$ $$h_t = [\overrightarrow{h}_t; \overleftarrow{h}_t]$$

同时利用前向和后向上下文，适合序列标注等需要全局信息的任务（但不适合语言模型/生成任务）。

递归神经网络（Recursive NN）

处理树形结构数据，节点 $v$ 的表示由其子节点表示计算：

$$h_v = f(W [h_{c_1}; h_{c_2}; \ldots; h_{c_k}] + b)$$

适合句法树、语义组合等结构化任务。

图网络RNN

将RNN扩展到图结构，节点 $v$ 的更新考虑所有邻居：

$$h_v^{(t)} = f\left(W x_v + \sum_{u \in \mathcal{N}(v)} U h_u^{(t-1)} + b\right)$$

八、注意力机制与序列模型

8.1 注意力机制

聚焦式注意力：模仿人类视觉系统，在处理信息时有选择地关注部分输入，而非均匀处理全部输入。

基于显著性的注意力：自下而上，根据输入的显著性特征自动分配注意力权重。

注意力机制的核心：对输入的不同部分计算权重，加权求和得到上下文向量：

$$c = \sum_i \alpha_i h_i, \quad \alpha_i = \frac{\exp(e_i)}{\sum_j \exp(e_j)}, \quad e_i = a(q, h_i)$$

其中 $q$ 为查询（query），$h_i$ 为键值（key-value），$a(\cdot, \cdot)$ 为注意力评分函数。

8.2 指针网络（Pointer Network）

用注意力机制直接从输入序列中选择元素（而非生成新词），适用于组合优化问题。

条件概率分解：

$$p(c_1, \ldots, c_m | x_1, \ldots, x_n) = \prod_{i=1}^m p(c_i | c_1, \ldots, c_{i-1}, x)$$

注意力分数（Bahdanau注意力）：

$$s_{i,j} = v^T \tanh(W x_j + U h_i)$$

输出层通过softmax得到指向输入位置的概率分布：$p(c_i = j | \cdot) = \text{softmax}(s_{i,j})$。

8.3 自注意力模型

自注意力（Self-Attention）：序列中每个位置都对序列中其他位置计算注意力权重，建立动态连接（不同于RNN的固定连接结构）：

$$\text{Attention}(Q, K, V) = \text{softmax}\left(\frac{QK^T}{\sqrt{d_k}}\right) V$$

其中 $Q = XW_Q$，$K = XW_K$，$V = XW_V$，$d_k$ 为键的维度。自注意力的动态连接权重可以捕获任意距离的依赖关系，不受序列长度限制。

8.4 外部记忆（结构化记忆）

神经图灵机（NTM）等模型使用外部记忆单元扩展网络的存储能力：

  • 主网络：控制器，负责读写操作
  • 外部记忆单元：$M \in \mathbb{R}^{N \times d}$，$N$ 个 $d$ 维记忆槽
  • 读取模块：$r = \sum_i w_i^r M_i$，加权读取
  • 写入模块：$M_i \leftarrow M_i + w_i^w e$（擦除+写入）

8.5 端到端记忆网络

读取操作（单跳）：

$$a_i = \text{softmax}(q^T m_i), \quad r = \sum_i a_i c_i$$

其中 $m_i$ 为记忆的输入嵌入，$c_i$ 为记忆的输出嵌入，$q$ 为查询向量。

多跳操作：多次读取，每次更新查询：$q^{k+1} = q^k + r^k$，最终输出 $\hat{y} = \text{softmax}(W(q^K + r^K))$。

8.6 Seq2Seq模型与注意力

带注意力的Seq2Seq模型（Bahdanau Attention）：

注意力权重：

$$\alpha_{t,i} = \text{softmax}(\text{score}(s_{t-1}, h_i))$$

常用评分函数：

  • 加性注意力（Bahdanau）：$\text{score}(s, h) = v^T \tanh(W_s s + W_h h)$
  • 点积注意力（Luong）：$\text{score}(s, h) = s^T h$
  • 缩放点积：$\text{score}(s, h) = s^T h / \sqrt{d}$

上下文向量：

$$c_t = \sum_{i=1}^T \alpha_{t,i} h_i$$

8.7 序列生成

序列 $y = (y_1, y_2, \ldots, y_T)$ 的概率链式分解：

$$p(y) = \prod_{t=1}^T p(y_t | y_1, \ldots, y_{t-1})$$

自回归（Autoregressive）：每步生成依赖之前所有生成的词，是主流生成范式。

束搜索（Beam Search）：维护 $B$ 个候选序列，每步扩展并保留得分最高的 $B$ 个：

$$\text{score}(y_{1:t}) = \frac{1}{t}\sum_{i=1}^t \log p(y_i | y_{1:i-1})$$

长度惩罚防止偏好短序列。

8.8 N元统计语言模型

N元模型（N-gram）假设当前词只依赖前 $n-1$ 个词：

$$p(w_t | w_1, \ldots, w_{t-1}) \approx p(w_t | w_{t-n+1}, \ldots, w_{t-1})$$

平滑技术（解决零概率问题）：

  • 加一平滑（Laplace）：$p(w|h) = \frac{c(h,w)+1}{c(h)+|V|}$
  • Kneser-Ney平滑：利用词在不同上下文中出现的多样性
  • 插值平滑：高阶N-gram和低阶N-gram线性插值

8.9 评价指标

困惑度（Perplexity, PPL）

$$\text{PPL}(W) = p(w_1, w_2, \ldots, w_N)^{-1/N} = \exp\left(-\frac{1}{N}\sum_{i=1}^N \log p(w_i | w_1, \ldots, w_{i-1})\right)$$

PPL越低，语言模型越好。等价于每步平均分支因子（模型的不确定度）。

BLEU（机器翻译评价）

$$\text{BLEU} = BP \cdot \exp\left(\sum_{n=1}^N w_n \log p_n\right)$$

其中 $p_n$ 为 $n$-gram精确率，$w_n = 1/N$（通常 $N=4$），$BP$ 为长度惩罚：

$$BP = \begin{cases} 1 & c > r \\ e^{1-r/c} & c \leq r \end{cases}$$

$c$ 为候选长度，$r$ 为参考长度。

ROUGE-N（摘要评价）

$$\text{ROUGE-N} = \frac{\sum_{s \in \text{ref}} \sum_{\text{gram}_n \in s} \text{Count}_{match}(\text{gram}_n)}{\sum_{s \in \text{ref}} \sum_{\text{gram}_n \in s} \text{Count}(\text{gram}_n)}$$

ROUGE-N衡量召回率（参考摘要中有多少n-gram被候选摘要覆盖），BLEU衡量精确率。

8.10 曝光偏差与计划采样

曝光偏差（Exposure Bias）：训练时使用真实词（teacher forcing），推断时使用自己生成的词，训练和推断分布不一致，导致错误积累。

计划采样（Scheduled Sampling）：训练时以概率 $\epsilon_i$ 使用模型自己的预测（而非真实词），随训练进行 $\epsilon_i$ 逐渐增大，平滑过渡。

8.11 层次化Softmax

当词表 $|V|$ 很大时，标准Softmax计算量 $O(|V|)$。层次化Softmax使用Huffman树，词表示为叶节点，每个内部节点是二分类器：

$$p(w | h) = \prod_{j=1}^{L(w)-1} \sigma(\text{sign}(n(w,j+1)) \cdot v_{n(w,j)}^T h)$$

其中 $L(w)$ 为词 $w$ 在树中的深度，$n(w,j)$ 为路径上第 $j$ 个节点。计算量降至 $O(\log|V|)$。

高频词（Huffman编码短）计算量小，低频词计算量大，平均复杂度 $O(\log|V|)$。

8.12 重要性采样与噪声对比估计

重要性采样：用提议分布 $q(w)$ 近似归一化常数，避免遍历全部词表。

噪声对比估计（NCE, Noise Contrastive Estimation）：将语言模型训练转化为二分类问题，区分真实词和噪声词（从噪声分布 $q(w)$ 采样）：

$$\mathcal{L}_{NCE} = \log \sigma(\log p_\theta(w) - \log kq(w)) + \sum_{i=1}^k \log(1 - \sigma(\log p_\theta(w_i) - \log kq(w_i)))$$

负采样（Word2Vec使用）是NCE的简化版（固定 $k$ 个噪声样本，噪声分布为词频的3/4次方）。

九、词向量

9.1 One-Hot编码缺点

  • 维度高：词表大小 $|V|$ 可达数十万，向量稀疏
  • 无语义信息：任意两个词的余弦相似度为0，无法反映语义关系
  • 无法泛化：未见词无法处理

9.2 TF-IDF

词频-逆文档频率，衡量词在文档中的重要性：

$$\text{TF}(t,d) = \frac{\text{词 } t \text{ 在文档 } d \text{ 中出现次数}}{\text{文档 } d \text{ 的总词数}}$$ $$\text{IDF}(t) = \log\frac{N}{|\{d: t \in d\}|}$$ $$\text{TF-IDF}(t,d) = \text{TF}(t,d) \times \text{IDF}(t)$$

高TF-IDF：该词在本文档频繁出现，但在其他文档少见，是文档的关键词。

9.3 VSM（向量空间模型）

文档-单词矩阵 $M \in \mathbb{R}^{|D|\times|V|}$，每行为一个文档的词频（或TF-IDF）向量。

文档相似度（余弦相似度）：

$$\text{sim}(d_i, d_j) = \frac{d_i \cdot d_j}{\|d_i\|\|d_j\|}$$

9.4 LSA（潜在语义分析）

对文档-单词矩阵进行SVD分解：

$$M = U \Sigma V^T$$

取前 $k$ 个奇异值/向量，得到低维近似 $M_k = U_k \Sigma_k V_k^T$。

  • 文档-主题向量：$U_k \Sigma_k$（$|D| \times k$）
  • 单词-主题向量：$V_k$（$|V| \times k$）

新文档映射：给定新文档词向量 $\vec{w}_s$，映射到主题空间：

$$\vec{p}^s = \Sigma_k^{-1} V_k^T \vec{w}_s$$

9.5 Word2Vec完整推导

9.5.1 CBOW（Continuous Bag of Words）

用上下文词预测中心词。

网络结构：

  • 输入：上下文词的one-hot向量 $x_1, \ldots, x_C$
  • 输入权重矩阵 $W \in \mathbb{R}^{V\times N}$（词嵌入矩阵）
  • 输出权重矩阵 $W' \in \mathbb{R}^{N\times V}$

单词上下文CBOW（$C=1$）：

隐向量（输入词嵌入）：

$$h = W^T x = w_I$$

输出层得分：

$$u_j = w'_j \cdot h, \quad j = 1, \ldots, V$$

输出概率：$y_j = \text{softmax}(u_j)$

损失函数（负对数似然）：

$$E = -\log p(w_O | w_I) = -u_{j^*} + \log\sum_{j=1}^V e^{u_j}$$

CBOW参数更新推导

CBOW反向传播

输出层误差（预测概率与真实标签之差）：

$$e_j = y_j - t_j, \quad j = 1, \ldots, V$$

（$t_j = 1$ 当 $j = j^*$，否则为0）

对输出权重的梯度：

$$\frac{\partial E}{\partial w'_j} = e_j \cdot h$$

更新：$w'^{new}_j = w'^{old}_j - \eta e_j h$

反传到隐层的误差（EH向量）：

$$\overrightarrow{EH} = \sum_{j=1}^V e_j w'_j = W' \vec{e}$$

对输入权重的梯度（只更新输入词 $w_I$ 对应的行）：

$$\frac{\partial E}{\partial w_I} = \overrightarrow{EH}$$

更新：$v'^{new}_{w_I} = v'^{old}_{w_I} - \eta \overrightarrow{EH}$

多词上下文CBOW

隐向量为上下文词嵌入的平均：

$$h = \frac{1}{C}\sum_{c=1}^C W^T x_c = \frac{1}{C}\sum_{c=1}^C v_{w_c}$$

参数更新规则：EH向量相同，对每个上下文词的嵌入都进行相同更新（除以C）。

9.5.2 Skip-Gram

用中心词预测上下文词（与CBOW相反）。

网络结构：输入中心词，预测 $C$ 个上下文词（多个独立Softmax输出）。

损失函数：

$$E = -\sum_{c=1}^C \log p(w_{O,c} | w_I) = -\sum_{c=1}^C u_{j^*_c} + C \log\sum_{j=1}^V e^{u_j}$$

输出层误差（对每个输出词汇表位置）：

$$EI_j = \sum_{c=1}^C e_j^c, \quad e_j^c = y_j - t_{j,c}$$

参数更新：与CBOW类似，但 $\overrightarrow{EH} = W' \overrightarrow{EI}$，只更新中心词嵌入。

9.5.3 分层Softmax（Hierarchical Softmax）

用Huffman树替代标准Softmax，降低计算复杂度：

  1. 构建Huffman树：词频越高，路径越短
  2. 每个内部节点 $n$ 有参数向量 $v_n$
  3. 词 $w$ 的概率等于从根到叶节点路径上所有二分类概率的乘积
$$p(w | \text{context}) = \prod_{j=1}^{L(w)-1} \sigma\left([n(w,j+1) = \text{left}] \cdot v_{n(w,j)}^T h\right)$$

其中 $[\cdot]$ 为Iverson括号，左子为正类，右子为负类。每个内部节点用逻辑回归拟合二分类。

9.5.4 负采样（Negative Sampling）

将多分类问题转化为二分类：正类为真实上下文词，负类为从噪声分布采样的词。

目标函数：

$$E = -\log\sigma(w'^T_{j^*} h) - \sum_{j \in W_{neg}} \log\sigma(-w'^T_j h)$$

其中 $W_{neg}$ 为 $k$ 个负样本集合（通常 $k=5\sim20$）。

输出层误差：

$$e_j = \sigma(w'^T_j h) - t_j, \quad t_j = \begin{cases}1 & j = j^* \\ 0 & j \in W_{neg}\end{cases}$$

参数更新：

$$w'^{new}_j = w'^{old}_j - \eta e_j h, \quad j \in \{j^*\} \cup W_{neg}$$ $$\overrightarrow{EH} = \sum_{j \in \{j^*\} \cup W_{neg}} e_j w'_j$$

噪声分布：词频的3/4次方 $p(w) \propto f(w)^{3/4}$，使低频词被采样概率提高。

9.5.5 降采样（Subsampling）

高频词（如"the", "a"）提供的信息少，以一定概率丢弃：

$$p(\text{keep}, w) = \left(\sqrt{\frac{z(w)}{\text{ratio}}} + 1\right) \times \frac{\text{ratio}}{z(w)}$$

其中 $z(w)$ 为词 $w$ 的词频比例，ratio通常为 $10^{-5}$。频率越高，保留概率越低。

9.5.6 Subword Embedding

FastText将词分解为字符N-gram，词向量等于所有N-gram向量之和，可处理未登录词（OOV）。

9.6 GloVe（全局词向量）

共现矩阵：$X_{ij}$ 为词 $j$ 在词 $i$ 上下文中出现的次数，$X_i = \sum_k X_{ik}$。

关键观察：共现概率比值 $R_{ij}^k = P(k|i)/P(k|j)$ 能反映词间关系：

$$R_{ij}^k = \frac{P(k|i)}{P(k|j)} = \frac{X_{ik}/X_i}{X_{jk}/X_j}$$

损失函数：

$$J = \sum_{i,k} f(X_{ik}) \left(w_i^T \tilde{w}_k + b_i + \tilde{b}_k - \log X_{ik}\right)^2$$

权重函数（限制高频词的影响）：

$$f(x) = \begin{cases} (x/x_{max})^\alpha & x < x_{max} \\ 1 & x \geq x_{max} \end{cases}$$

通常 $x_{max} = 100$，$\alpha = 3/4$。GloVe结合了全局统计信息（共现矩阵）和局部上下文信息（窗口）。

9.7 FastText

与CBOW的区别：FastText用于文本分类，输入为文档所有词（及N-gram特征）的平均，输出为类别标签。

$$h = \frac{1}{N}\sum_{n=1}^N (v_{w_n} + \sum_{g \in G(w_n)} z_g)$$

其中 $G(w_n)$ 为词 $w_n$ 的N-gram集合，$z_g$ 为N-gram向量。

损失函数：softmax交叉熵（类别数大时用层次softmax）。

与Word2Vec词向量的区别：Word2Vec学习词级别嵌入，FastText学习字符N-gram嵌入，能处理OOV词，对形态丰富的语言效果更好。

9.8 ELMo（上下文词向量）

ELMo使用双向LSTM语言模型，学习上下文相关的词向量。

目标函数：最大化前向和后向语言模型的对数似然：

$$\mathcal{L} = \sum_{k=1}^N \left(\log p(t_k | t_1, \ldots, t_{k-1}; \Theta_x, \overrightarrow{\Theta}_{LSTM}, \Theta_s) + \log p(t_k | t_{k+1}, \ldots, t_N; \Theta_x, \overleftarrow{\Theta}_{LSTM}, \Theta_s)\right)$$

词向量加权公式：ELMo向量为各层表示的加权和：

$$\overrightarrow{EM}_k^{task} = \gamma^{task} \sum_{j=0}^L s_j^{task} \vec{v}_k^{LM,j}$$

其中 $s_j^{task}$ 为softmax归一化的层权重（可学习），$\gamma^{task}$ 为缩放因子，$\vec{v}_k^{LM,j}$ 为第 $j$ 层的双向表示。不同任务可学习不同的层权重。

9.9 GPT

使用单向（从左到右）Transformer的语言模型，预训练目标为预测下一个词：

$$\mathcal{L} = \sum_i \log p(u_i | u_{i-k}, \ldots, u_{i-1}; \Theta)$$

使用masked self-attention（因果掩码），只能看到当前位置之前的词。下游任务通过fine-tuning适配。

9.10 BERT（双向Transformer）

BERT（Bidirectional Encoder Representations from Transformers）使用双向Transformer预训练。

预训练任务1：Masked LM（MLM）：随机mask 15%的词，预测被mask的词。mask策略：

  • 80%替换为[MASK]
  • 10%替换为随机词
  • 10%保持不变

预训练任务2：Next Sentence Prediction（NSP）：判断两个句子是否相邻（50%正例，50%随机负例），学习句子间关系。

输入三部分Embedding：

$$E = E_{token} + E_{segment} + E_{position}$$

Token Embedding：词嵌入；Segment Embedding：区分句子A/B；Position Embedding：位置编码（可学习，非固定）。

Fine-tuning：在下游任务上微调全部参数，只在顶层加简单分类头，适用于分类、NER、QA等多种任务。

十、模型独立的学习方式

10.1 自训练（Self-Training）

流程：

  1. 用有标注数据 $D_L$ 训练初始模型 $f$
  2. 用 $f$ 对无标注数据 $D_U$ 进行预测，得到伪标签
  3. 选择置信度高的样本加入训练集
  4. 重新训练模型，重复迭代

缺点：早期错误会被放大（错误的伪标签被加入训练集，导致后续更多错误）；依赖初始模型质量。

10.2 协同训练（Co-Training）

使用两个视角（两组特征）训练两个分类器，互相为对方标注无标注数据。

两个假设：

  • 条件独立性假设：给定标签 $y$，两个视角 $x^{(1)}$ 和 $x^{(2)}$ 条件独立：$p(x^{(1)}, x^{(2)} | y) = p(x^{(1)}|y) p(x^{(2)}|y)$
  • 充足冗余假设：每个视角单独足以预测标签

算法流程：

  1. 用 $D_L$ 分别训练分类器 $f_1$（视角1）和 $f_2$（视角2）
  2. $f_1$ 对 $D_U$ 预测，选置信度高的样本（含伪标签）加入 $f_2$ 的训练集
  3. $f_2$ 对 $D_U$ 预测，选置信度高的样本加入 $f_1$ 的训练集
  4. 重新训练 $f_1, f_2$，重复迭代

10.3 多任务学习

四种共享模式

硬共享（Hard Sharing）

底层参数完全共享，顶层各任务独立。代表：MTL-MLP。参数效率高，但共享可能不充分。

软共享（Soft Sharing）

各任务独立参数，通过正则化（L2距离）约束参数相近。灵活但参数量增加。

层次共享（Hierarchical Sharing）

不同任务共享不同深度的层：简单任务共享浅层，复杂任务共享深层。

共享-私有（Shared-Private）

每个任务有私有参数和共享参数，通过对抗训练分离任务特定特征和共享特征。

目标函数

$$\mathcal{L}(\theta) = \sum_{m=1}^M \sum_{n=1}^{N_m} \eta_m \mathcal{L}_m(f_m(x^{(m,n)}, \theta), y^{(m,n)})$$

其中 $\eta_m$ 为任务 $m$ 的权重，$f_m$ 为任务 $m$ 的预测函数（共享参数 $\theta$ + 任务特定参数）。

两阶段训练

  1. 联合训练：所有任务数据混合，联合优化上述目标函数
  2. 单任务精调：对目标任务单独fine-tuning，进一步优化

多任务学习更好泛化的四个原因

  • 隐式数据增强：多任务数据增加了有效训练样本，降低过拟合风险
  • 注意力聚焦：辅助任务强制模型关注对多任务都重要的特征，忽略任务特定噪声
  • 窃听（Eavesdropping）：某些特征对任务A容易学习，对任务B难以学习，多任务学习使任务B可以"窃听"任务A的表示
  • 表示偏置：多任务学习偏向对多任务都有用的表示，更可能是正确的归纳偏置

10.4 迁移学习

基本概念

领域（Domain）：$\mathcal{D} = \{\mathcal{X}, P(X)\}$，特征空间及其边缘分布。

任务（Task）：$\mathcal{T} = \{\mathcal{Y}, f(\cdot)\}$，标签空间及预测函数。

归纳迁移（Inductive Transfer）：目标任务与源任务不同（标签空间或条件分布不同）。

转导迁移（Transductive Transfer）：源域和目标域不同（特征空间或边缘分布不同），但任务相同。

归纳迁移

  • 无标注源域：用自编码器或密度估计学习源域表示，迁移到目标任务
  • 有标注源域，基于特征：固定源域预训练的特征提取器，只训练目标任务的分类头
  • 有标注源域，精调（Fine-tuning）：用源域预训练参数初始化，在目标任务数据上微调全部或部分参数

转导迁移（领域适应）

协变量偏移（Covariate Shift）：$P_S(x) \neq P_T(x)$，但 $P_S(y|x) = P_T(y|x)$。

概念偏移（Concept Shift）：$P_S(y|x) \neq P_T(y|x)$，标签关系发生变化。

先验偏移（Prior Shift）：$P_S(y) \neq P_T(y)$，类别分布不同。

领域无关表示学习

目标：学习对领域不变的特征表示，使源域和目标域的特征分布一致。目标函数：

$$\mathcal{R}_T(\theta_f, \theta_g) = \mathcal{R}_S(\theta_f, \theta_g) + \gamma d_g(S, T)$$

其中 $\mathcal{R}_S$ 为源域分类损失，$d_g(S,T)$ 为源域和目标域特征分布的距离（如MMD、CORAL），$\gamma$ 为权衡系数。

对抗学习领域适应

引入领域判别器 $D$，通过对抗训练使特征提取器学习领域无关表示：

领域判别器损失：

$$\mathcal{L}_D = -\mathbb{E}_{x \sim S}[\log D(f(x))] - \mathbb{E}_{x \sim T}[\log(1-D(f(x)))]$$

对抗最优化问题：

$$\min_{\theta_f, \theta_g} \max_{\theta_D} \mathcal{R}_S(\theta_f, \theta_g) - \lambda \mathcal{L}_D(\theta_f, \theta_D)$$

特征提取器 $f$ 最小化分类损失，同时最大化领域判别器的困惑度（使两个领域的特征不可区分）。

10.5 终生学习与灾难性遗忘

终生学习（Lifelong Learning）：模型持续学习新任务，同时保留旧任务的知识。

灾难性遗忘（Catastrophic Forgetting）：在新任务上训练后，模型在旧任务上性能急剧下降。原因：神经网络参数被新任务覆盖，旧任务的重要权重被破坏。

解决方法：EWC（弹性权重巩固）通过正则化保护重要权重，渐进式神经网络（PNN）为每个任务添加新列，记忆回放（Replay）混合旧任务样本。

10.6 元学习

元学习（Learning to Learn）：学习如何快速适应新任务，而非学习特定任务。

基于优化器的元学习

用LSTM作为优化器，学习如何更新参数：

$$\mathcal{L}(\phi) = \mathbb{E}_f\left[\sum_{t=1}^T w_t \mathcal{L}_t(\theta_t)\right]$$

其中 $\phi$ 为LSTM优化器参数，$\theta_t$ 为被优化模型在第 $t$ 步的参数，$w_t$ 为时间步权重。

MAML（模型无关元学习）

学习一个好的初始化参数 $\theta$，使其能在少量梯度步后快速适应新任务。

任务内适配（内循环）：

$$\theta_m' = \theta - \alpha \nabla_\theta \mathcal{L}_m(f_\theta)$$

元优化目标（外循环）：

$$\min_\theta \sum_{m=1}^M \mathcal{L}_m(f_{\theta_m'}) = \sum_{m=1}^M \mathcal{L}_m(f_{\theta - \alpha \nabla_\theta \mathcal{L}_m(f_\theta)})$$

元更新公式：

$$\theta \leftarrow \theta - \beta \nabla_\theta \sum_{m=1}^M \mathcal{L}_m(f_{\theta_m'})$$

元更新需要计算二阶梯度（通过 $\theta_m'$ 对 $\theta$ 求导），计算量较大。First-Order MAML（FOMAML）忽略二阶项，近似计算。

十一、无监督学习

11.1 稀疏编码

稀疏编码（Sparse Coding）学习数据的稀疏字典表示：

$$L(A, Z) = \sum_{n=1}^N \left(\|x^{(n)} - A z^{(n)}\|^2 + \eta \rho(z^{(n)})\right)$$

其中 $A \in \mathbb{R}^{d \times k}$ 为字典矩阵（$k > d$，过完备字典），$z^{(n)} \in \mathbb{R}^k$ 为稀疏编码（系数），$\rho(\cdot)$ 为稀疏性惩罚。

稀疏衡量函数：

  • L1范数：$\rho(z) = \|z\|_1 = \sum_i |z_i|$（最常用，产生精确稀疏解）
  • 对数稀疏：$\rho(z) = \sum_i \log(1 + z_i^2)$（更接近L0，但非凸）
  • 指数稀疏：$\rho(z) = \sum_i \exp(-z_i^2/\sigma^2)$

交替优化：

  1. 固定 $A$，对每个样本求解稀疏编码 $z^{(n)}$（LASSO问题）
  2. 固定 $Z = [z^{(1)}, \ldots, z^{(N)}]$，更新字典 $A$（最小二乘）
  3. 重复直到收敛，对 $A$ 的列进行L2归一化防止尺度退化

11.2 自编码器

自编码器（Autoencoder）通过编码-解码结构学习数据的低维表示：

$$z = f_{enc}(x; \theta_e), \quad \hat{x} = f_{dec}(z; \theta_d)$$

重构误差（MSE）：

$$\mathcal{L} = \|x - \hat{x}\|^2 = \|x - f_{dec}(f_{enc}(x))\|^2$$

稀疏自编码器

在重构误差上添加稀疏性约束，使隐层激活稀疏（大多数神经元不激活）：

$$\mathcal{L} = \|x - \hat{x}\|^2 + \beta \sum_j KL(\rho || \hat{\rho}_j)$$

其中 $\hat{\rho}_j$ 为第 $j$ 个隐层神经元的平均激活率，$\rho$ 为目标稀疏率（如0.05），KL散度：

$$KL(\rho || \hat{\rho}_j) = \rho \log\frac{\rho}{\hat{\rho}_j} + (1-\rho)\log\frac{1-\rho}{1-\hat{\rho}_j}$$

降噪自编码器（DAE）

训练时向输入添加噪声 $\tilde{x} = x + \epsilon$，要求重构干净的输入 $x$：

$$\mathcal{L} = \|x - f_{dec}(f_{enc}(\tilde{x}))\|^2$$

强制模型学习鲁棒的特征表示，不仅仅记住输入。

11.3 密度估计

参数密度估计：假设数据服从参数化分布（如高斯），用MLE估计参数。

非参数密度估计：不假设分布形式，直接从数据估计密度。

核密度估计（Parzen窗）：

$$p(x) = \frac{1}{N}\sum_{n=1}^N K_h(x - x^{(n)}) = \frac{1}{Nh^d}\sum_{n=1}^N K\left(\frac{x-x^{(n)}}{h}\right)$$

其中 $K(\cdot)$ 为核函数（如高斯核），$h$ 为带宽。

简单估计：$p(x) \approx K/(NV)$，其中 $K$ 为落入体积 $V$ 内的样本数，$N$ 为总样本数。

11.4 变分自编码器（VAE）完整推导

生成模型

VAE假设数据由潜变量 $z$ 生成：

$$p(x, z | \theta) = p(x | z, \theta) p(z | \theta)$$

先验 $p(z|\theta) = \mathcal{N}(0, I)$，生成网络 $p(x|z,\theta)$ 为参数化解码器。

ELBO推导

证据下界（ELBO）推导

对数似然分解：

$$\log p(x|\theta) = \log \int p(x|z,\theta)p(z|\theta) dz$$

引入任意变分分布 $q(z|x,\phi)$：

$$\log p(x|\theta) = \log \int q(z|x,\phi) \frac{p(x,z|\theta)}{q(z|x,\phi)} dz$$

由Jensen不等式（$\log$ 为凹函数）：

$$\geq \int q(z|x,\phi) \log \frac{p(x,z|\theta)}{q(z|x,\phi)} dz = ELBO(q, x|\theta, \phi)$$

等式成立当且仅当 $q(z|x,\phi) = p(z|x,\theta)$。

另一形式：

$$\log p(x|\theta) = ELBO(q, x|\theta, \phi) + D_{KL}(q(z|x,\phi) || p(z|x,\theta))$$

由于KL散度 $\geq 0$，ELBO是对数似然的下界。

$$\log p(x|\theta) = ELBO(q, x|\theta, \phi) + D_{KL}(q(z|x,\phi) || p(z|x,\theta))$$

推断网络（编码器）

用神经网络近似后验分布：

$$q(z|x,\phi) = \mathcal{N}(\mu_I, \sigma_I^2 I)$$

两层网络：

$$h = \text{ReLU}(W_1 x + b_1)$$ $$\mu_I = W_\mu h + b_\mu, \quad \log\sigma_I^2 = W_\sigma h + b_\sigma$$

总目标函数（最大化ELBO）

$$\max_{\theta, \phi} \mathbb{E}_{z \sim q(z|x,\phi)}[\log p(x|z,\theta)] - D_{KL}(q(z|x,\phi) || p(z|\theta))$$

第一项为重构损失（期望对数似然），第二项为正则化（使后验接近先验）。

重参数化技巧

直接从 $q(z|x,\phi)$ 采样无法反向传播（采样操作不可微）。重参数化：

$$z = \mu_I + \sigma_I \odot \epsilon, \quad \epsilon \sim \mathcal{N}(0, I)$$

将随机性转移到 $\epsilon$（与参数无关），使梯度可以通过 $z$ 传到 $\mu_I, \sigma_I$。

KL散度公式（两高斯分布）

$$D_{KL}(\mathcal{N}(\mu, \sigma^2 I) || \mathcal{N}(0, I)) = \frac{1}{2}\sum_j (\mu_j^2 + \sigma_j^2 - \log\sigma_j^2 - 1)$$

损失化简（对角高斯先验）：

$$\mathcal{L}_{VAE} = \mathbb{E}_\epsilon[\|x - \hat{x}\|^2] + \frac{1}{2}\sum_j (\mu_j^2 + \sigma_j^2 - \log\sigma_j^2 - 1)$$

11.5 GAN（生成对抗网络）

判别网络目标

$$\max_\phi \left(\mathbb{E}_{x \sim p_r}[\log D(x, \phi)] + \mathbb{E}_{z \sim p(z)}[\log(1 - D(G(z, \theta), \phi))]\right)$$

生成网络目标（对偶形式）

$$\max_\theta \mathbb{E}_{z \sim p(z)}[\log D(G(z, \theta), \phi)]$$

（原始形式为 $\min_\theta \mathbb{E}[\log(1-D(G(z)))]$，但梯度消失问题更严重）

最小最大博弈目标

$$\min_\theta \max_\phi V(G, D) = \mathbb{E}_{x \sim p_r}[\log D(x)] + \mathbb{E}_{z \sim p(z)}[\log(1 - D(G(z)))]$$

最优判别器推导

最优判别器推导

固定生成器 $G$，对判别器 $D$ 求最优解：

$$V(G,D) = \int_x [p_r(x)\log D(x) + p_\theta(x)\log(1-D(x))] dx$$

对被积函数关于 $D(x)$ 求导并令其为0：

$$\frac{p_r(x)}{D(x)} - \frac{p_\theta(x)}{1-D(x)} = 0$$

解得：

$$D^*(x) = \frac{p_r(x)}{p_r(x) + p_\theta(x)}$$
$$D^*(x) = \frac{p_r(x)}{p_r(x) + p_\theta(x)}$$

代入最优判别器：等价于最小化JS散度

GAN与JS散度的等价性

将 $D^*$ 代入 $V(G, D^*)$：

$$V(G, D^*) = \mathbb{E}_{x \sim p_r}\left[\log\frac{p_r(x)}{p_r(x)+p_\theta(x)}\right] + \mathbb{E}_{x \sim p_\theta}\left[\log\frac{p_\theta(x)}{p_r(x)+p_\theta(x)}\right]$$

注意到 $D_{JS}(p||q) = \frac{1}{2}D_{KL}(p||\frac{p+q}{2}) + \frac{1}{2}D_{KL}(q||\frac{p+q}{2})$，化简得：

$$V(G, D^*) = 2D_{JS}(p_r || p_\theta) - 2\log 2$$
$$\mathcal{L} = 2D_{JS}(p_r || p_\theta) - 2\log 2$$

JS散度梯度消失问题

当 $p_r$ 和 $p_\theta$ 支撑集不重叠（或重叠极少）时，$D_{JS}(p_r||p_\theta) = \log 2$（常数），梯度为0，生成器无法学习。这在高维空间中很常见（生成图像的流形与真实图像流形几乎不相交）。

模式坍塌（Mode Collapse）

前向KL（$D_{KL}(p_r || p_\theta)$，最大似然）：

$$D_{KL}(p_r || p_\theta) = \mathbb{E}_{x \sim p_r}[\log p_r(x) - \log p_\theta(x)]$$

当 $p_r(x) > 0$ 但 $p_\theta(x) \approx 0$ 时，KL趋于无穷。优化时强制 $p_\theta$ 覆盖 $p_r$ 的所有模式（均值寻找，mean-seeking），生成多样但可能模糊的样本。

逆向KL（$D_{KL}(p_\theta || p_r)$，GAN使用）：

$$D_{KL}(p_\theta || p_r) = \mathbb{E}_{x \sim p_\theta}[\log p_\theta(x) - \log p_r(x)]$$

当 $p_\theta(x) > 0$ 但 $p_r(x) \approx 0$ 时，KL趋于无穷。优化时强制 $p_\theta$ 集中在 $p_r$ 的高概率区域（模式寻找，mode-seeking），导致模式坍塌（只生成少数清晰但单一的样本）。

DCGAN改进技巧

  • 用步长卷积替代池化（判别器），用转置卷积替代上采样（生成器）
  • 在判别器和生成器中使用BatchNorm（输入层和输出层除外）
  • 生成器使用ReLU（输出层用tanh），判别器使用Leaky ReLU
  • 去除全连接隐藏层，使用全卷积架构
  • 使用Adam优化器，较小学习率（0.0002），$\beta_1 = 0.5$

12.2 RLHF两阶段流程

  1. SFT（监督微调）+ 训练奖励模型：
    • 收集人类偏好数据：对同一问题的多个回答进行排序
    • 训练奖励模型（RM）学习人类偏好
  2. PPO强化学习优化：
    • 用PPO算法优化LLM，使其生成奖励模型评分高的回答
    • 同时加入KL惩罚防止偏离SFT模型过远

12.3 奖励模型（RM）

结构：在LLM基础上，将语言模型头（LM Head）替换为奖励头（Reward Head，线性层输出标量）。

输入：问题 $x$ + 回答 $y$ 的拼接序列。

输出：标量奖励值 $r(x, y) \in \mathbb{R}$。

训练损失（Bradley-Terry偏好模型）：

$$\mathcal{L}_{RM} = -\mathbb{E}_{(x, y_w, y_l) \sim D}[\log\sigma(r(x, y_w) - r(x, y_l))]$$

其中 $y_w$ 为人类偏好的回答（winner），$y_l$ 为不偏好的回答（loser），$\sigma$ 为sigmoid函数。最大化偏好回答和非偏好回答的奖励差。

12.4 RLHF四模型架构

模型作用输入输出参数更新
策略模型（Policy）生成回答，被优化的主模型问题 $x$回答 $y$（token序列）是（PPO更新）
参考模型（Reference）SFT模型，提供KL基准问题 $x$ + 回答 $y$每个token的对数概率否（冻结）
奖励模型（Reward）评估回答质量问题 $x$ + 回答 $y$标量奖励 $r$否（冻结）
价值模型（Value/Critic）估计状态价值，用于PPO优势估计问题 $x$ + 部分回答标量价值 $V$是（与策略联合更新）

12.5 KL距离计算

RLHF中，KL惩罚防止策略模型偏离参考模型太远（避免奖励黑客）：

$$\text{reward}(x, y) = r(x, y) - \beta \cdot D_{KL}(\pi_{\theta}(y|x) || \pi_{ref}(y|x))$$

LogProbs提取：对策略模型和参考模型分别进行前向传播，提取每个token位置的对数概率，逐位置相减得到KL近似（采样近似）。

12.6 PPO整体流程

  1. 经验收集（Rollout）：
    • 从数据集采样问题 $x$
    • 策略模型生成回答 $y$（自回归）
    • 奖励模型计算奖励 $r(x,y)$
    • 参考模型计算参考对数概率
    • 将所有数据存入缓冲区（Buffer）
  2. 多轮PPO训练：
    • 从缓冲区采样mini-batch
    • 计算优势函数（GAE）：$A_t = \sum_{l=0}^\infty (\gamma\lambda)^l \delta_{t+l}$
    • 计算PPO-Clip目标：$L^{CLIP} = \mathbb{E}[\min(r_t(\theta)A_t, \text{clip}(r_t(\theta), 1-\epsilon, 1+\epsilon)A_t)]$
    • 同时更新策略模型和价值模型
  3. 重复收集和训练，直到收敛

缓冲区中的数据是由旧版本策略模型（old policy）生成的，PPO通过重要性采样比 $r_t(\theta) = \pi_\theta(a_t|s_t)/\pi_{old}(a_t|s_t)$ 校正分布差异，允许多次使用同一批数据（提高数据效率）。

12.7 拒绝采样微调（Rejection Sampling Fine-tuning, RSF）

比PPO更简单的RLHF变体：

  1. 策略模型对每个问题生成 $k$ 个回答
  2. 奖励模型选择奖励最高的回答
  3. 用这些"最优回答"对策略模型进行SFT微调
  4. 重复迭代

12.8 RLAIF vs RLHF

RLHF（Reinforcement Learning from Human Feedback）：奖励信号来自人类标注，成本高但质量高。

RLAIF（Reinforcement Learning from AI Feedback）：奖励信号来自另一个AI模型（如Claude、GPT-4），成本低，可扩展，但受限于AI的判断能力。

12.9 CAI（Constitutional AI）

Anthropic提出的RLAIF变体，使用宪法原则（Constitution）指导AI自我改进：

宪法原则：一组描述有益、无害、诚实行为的原则（如"不要提供有害信息"）。

5步训练流程：

  1. SL-CAI：用有害问题提示初始模型生成有害回答，再用宪法原则提示模型自我批评和修订，得到修订后的回答
  2. SFT微调：用修订后的（问题，回答）对进行监督微调
  3. AI反馈偏好数据：对同一问题生成多个回答，用宪法原则提示AI模型（如Claude）判断哪个更好，生成偏好数据
  4. RLAIF训练RM：用AI生成的偏好数据训练奖励模型
  5. RL优化：用奖励模型通过PPO优化SL-CAI模型

12.10 MCTS（蒙特卡洛树搜索）在LLM中的应用

MCTS用于增强LLM的推理能力（如AlphaCode、OpenAI o1）：

四个关键步骤：

  1. 选择（Selection）：从根节点出发，用UCB策略选择子节点：$UCB = Q(s,a) + c\sqrt{\ln N(s)/N(s,a)}$，直到到达叶节点
  2. 扩展（Expansion）：对叶节点展开新的子节点（新的推理步骤或token）
  3. 模拟（Simulation/Rollout）：从新节点出发，用策略模型模拟完整推理过程，得到最终答案
  4. 回传（Backpropagation）：根据最终奖励（答案正确性），更新路径上所有节点的访问次数和价值估计

多数投票（Majority Voting）：生成多个推理路径，选择出现最多次的最终答案（Self-Consistency），简单有效。

12.11 SwiGLU激活函数

SwiGLU是GLU（Gated Linear Unit）的变体，在LLaMA等大模型中广泛使用：

$$\text{SwiGLU}(x, W, V, b, c) = \text{SiLU}(xW + b) \odot (xV + c)$$

其中 $\text{SiLU}(x) = x \cdot \sigma(x)$（Sigmoid Linear Unit，也称Swish）。

双路线性 + SiLU门控：一路经过SiLU激活，另一路保持线性，两路逐元素相乘。SwiGLU比ReLU/GELU在语言模型任务上表现更好。

12.12 RoPE（旋转位置编码）

RoPE（Rotary Position Embedding）通过旋转矩阵将位置信息编码到注意力计算中：

旋转位置编码原理：对位置 $m$ 的查询向量 $q$ 和位置 $n$ 的键向量 $k$，施加旋转变换：

$$q_m^T k_n = (R_m q)^T (R_n k) = q^T R_m^T R_n k = q^T R_{n-m} k$$

其中 $R_m$ 为旋转矩阵（2D旋转块对角阵）：

$$R_m = \begin{pmatrix} \cos m\theta_1 & -\sin m\theta_1 & & \\ \sin m\theta_1 & \cos m\theta_1 & & \\ & & \ddots & \\ & & & \cos m\theta_{d/2} & -\sin m\theta_{d/2} \\ & & & \sin m\theta_{d/2} & \cos m\theta_{d/2} \end{pmatrix}$$

其中 $\theta_i = 10000^{-2i/d}$（类似Transformer的位置编码基频）。

相对位置特性：内积 $q_m^T k_n$ 只依赖相对位置 $n-m$，而非绝对位置，天然具有相对位置感知能力，且可以外推到训练时未见过的更长序列（通过调整基频）。
