1. 核心问题：Exposure Bias

传统知识蒸馏（Off-Policy KD）让学生在教师生成的静态数据集上训练，推理时却在自己生成的前缀上续写——分布错配导致推理误差逐步累积放大。

Off-Policy（有缺陷）

$p_\theta(y_t \mid x,\; y^T_{1:t-1})$

前缀 $y^T$ 来自教师，学生从未在自己的错误前缀上训练

On-Policy（正确）

$p_\theta(y_t \mid x,\; \hat{y}_{1:t-1})$

前缀来自学生自己，训练与推理完全对齐

维度Off-Policy 蒸馏On-Policy 蒸馏（OPD）
训练数据来源教师生成的静态数据集学生自己采样的轨迹
Exposure Bias存在，推理时误差累积消除，训练与推理分布一致
计算成本低（数据预生成）高（每步需要学生采样 + 教师打分）
数据多样性受教师分布限制覆盖学生可能探索的所有区域
典型方法SeqKD, Standard KDGKD, MiniLLM, DistiLLM

On-Policy 蒸馏的核心思路：让学生在自己生成的轨迹上接受教师反馈，从根本上消除训练-推理分布错配。这与交互式模仿学习（DAgger）和策略梯度优化在哲学上同源。

2. 数学基础：自回归生成作为 MDP

将 LLM 自回归生成形式化为有限序贯决策过程（MDP），是 OPD 与强化学习统一的理论基础：

形式化：文本生成 = 有限 MDP
  • 状态 $s_t = (x, y_{1:t})$：当前 prompt + 已生成前缀
  • 动作 $a_t = y_{t+1}$：下一个 token，动作空间 = 词表 $|\mathcal{V}|$（通常 $\sim 10^5$）
  • 策略 $\pi_\theta(a_t|s_t) = p_\theta(y_{t+1}|x, y_{1:t})$：学生模型
  • 教师策略 $\pi_T$：提供 soft logit 监督信号（白盒）或结果评分（黑盒）

OPD 的统一目标函数——在学生自采样序列上计算每步散度：

$$\mathcal{L}_\text{OPD}(\theta) = \mathbb{E}_{x}\;\mathbb{E}_{\hat{y}\sim p_\theta} \left[\frac{1}{|\hat{y}|}\sum_{t=1}^{|\hat{y}|} \mathcal{D}_f\!\left(p_T(\cdot|x,\hat{y}_{\lt t})\;\|\;p_\theta(\cdot|x,\hat{y}_{\lt t})\right)\right]$$

3. 散度选择：三种行为差异

散度公式梯度行为实践后果代表方法
Forward KL $\sum_v p_T\log\frac{p_T}{p_\theta}$ Zero-avoiding，强制 $p_\theta(v)\gt 0$ 处处 覆盖所有模式，质量分散 GKD（可选）
Reverse KL $\sum_v p_\theta\log\frac{p_\theta}{p_T}$ Zero-forcing，聚焦教师高概率区 输出精准，多样性差；需 REINFORCE MiniLLM, TML OPD
Skew KLD $D_\text{KL}(p_T\|\alpha p_T{+}(1{-}\alpha)p_\theta)$ 混合分布下界 $\gt 0$，永不除零 数值稳定，直接可微，无需 REINFORCE DistiLLM（SKL/SRKL）

维度1：反馈信号
  • Logit-Based：教师提供每个 token 位置的完整概率分布（白盒），信息量最丰富。主流方法（GKD、MiniLLM、DistiLLM）均属此类
  • Outcome-Based：教师仅对完整生成结果打分（RM），通过策略梯度优化。RLKD、KDRL 等属此类
  • Self-Play：学生与自身不同版本交互学习
维度2：教师访问方式
  • White-Box：可访问教师 logits，信息密度最高，需教师模型在线推理
  • Black-Box：只能获取教师的生成文本，适合 API 调用（如 GPT-4 蒸馏）
  • Self-Distillation：消除外部教师依赖——2025 年以来的主流趋势

5. GKD：最简洁的 On-Policy 框架（ICLR 2024）

GKD — Generalized Knowledge Distillation（Agarwal et al., ICLR 2024）

核心思想：最早系统性地将 On-Policy 采样引入 LLM 蒸馏。学生在自生成序列上接受教师反馈，支持多种散度选择。

优势：散度无关（Forward KL / Reverse KL / JSD 均可）、无需 REINFORCE 梯度估计（方差低）、实现极简。

局限：理论上对散度选择缺乏指导，实践中需要调试哪种散度最优。

核心改动只有一处：把训练数据从"教师生成的固定序列"换成"学生自采样的动态序列"。由于前缀 $\hat{y}_{1:t-1}$ 对 $\theta$ 是 stop-grad 常数，梯度仅流经 $p_\theta$ 的 logits，无需 REINFORCE，方差低，实现极简。

混合采样（$\lambda$ 比例来自学生）

以概率 $\lambda$ 让学生采样 $\hat{y}\sim p_\theta(\cdot|x)$（On-Policy）；以概率 $1{-}\lambda$ 从教师数据集取 $y^T$（Off-Policy 备用）。

教师完整 Forward（no_grad）

将序列 $\hat{y}$ 送入教师得到每个位置概率：$p_T^t=\text{softmax}(\text{Teacher}(x,\hat{y}_{1:t-1}))$，不参与反传。

学生 Forward + Token 级散度（梯度从这里流）

$\mathcal{L}=\frac{1}{|\hat{y}|}\sum_t \mathcal{D}_f(p_T^t\|p_\theta^t)$，FKL/RKL/JSD 均可，直接 backward。

Algorithm 1: GKD

Input: $p_\theta$，$p_T$，Prompt 集 $\mathcal{X}$，散度 $\mathcal{D}$，混合比 $\lambda$

for each step:  $x\leftarrow$sample$(\mathcal{X})$

if rand()$\lt\lambda$:  $\hat{y}$$\leftarrow$student_sample$(p_\theta,x)$ // On-Policy

else:                  $\hat{y}$$\leftarrow$dataset_fetch$(\mathcal{D},x)$ // Off-Policy 备用

with no_grad():  $p_T^t\leftarrow$teacher_fwd$(x,\hat{y}_{1:t-1})$ for all $t$

$\mathcal{L}\leftarrow\frac{1}{|\hat{y}|}\sum_t\mathcal{D}_f(p_T^t\|p_\theta^t)$;  optimizer.step($\mathcal{L}$.backward())

6. MiniLLM：Reverse KL + REINFORCE（2023）

MiniLLM（Gu et al., 2023）

核心创新：证明 Reverse KL 比 Forward KL 更适合 LLM 蒸馏——Reverse KL 的众数寻求（mode-seeking）特性使学生专注于教师的高质量输出，而非均摊覆盖低质量尾部。

实现挑战：$\mathbb{E}_{y\sim p_\theta}[\cdot]$ 依赖 $\theta$，直接求梯度需 REINFORCE（高方差）。需要奖励基线、长度惩罚、SFT 预热等工程 tricks。

梯度推导

$\nabla_\theta D_\text{KL}(p_\theta\|p_T)$，log-derivative trick：

$$\nabla_\theta\mathcal{L}=-\mathbb{E}_{y\sim p_\theta}\!\left[\sum_t(R_t-1)\nabla_\theta\log p_\theta(y_t|y_{\lt t},x)\right]$$

Per-token 回报（单步分量可精确计算，无需 MC）：

$$R_t=\underbrace{\log\frac{p_T(y_t|y_{\lt t})}{p_\theta(y_t|y_{\lt t})}}_{r_t,\,\text{精确}}+\gamma\sum_{k\gt t}r_k$$
Algorithm 2: MiniLLM

sft_train$(p_\theta,\mathcal{D})$ // Phase 1: SFT 预热，防 p_θ≈0 时 NaN

for each step:  $\hat{y}\leftarrow$sample$(p_\theta|x)$

with no_grad():  $r_t\leftarrow\log p_T(\hat{y}_t|\cdot)-\log p_\theta(\hat{y}_t|\cdot)$ for all $t$;  $R_t\leftarrow r_t+\gamma\sum_{k\gt t}r_k$

$\mathcal{L}_\text{RKL}\leftarrow-\frac{1}{|\hat{y}|}\sum_t(R_t-1)\log p_\theta(\hat{y}_t|\cdot)$ // REINFORCE with baseline=1

$\mathcal{L}_\text{LM}\leftarrow-\frac{1}{|y^T|}\sum_t\log p_\theta(y^T_t|\cdot)$ // 通用能力正则

optimizer.step($(\alpha\mathcal{L}_\text{RKL}+\beta\mathcal{L}_\text{LM})$.backward())

必须的工程 Tricks
  • SFT 预热：cold start 时 $p_\theta\approx 0$，$\log(p_T/p_\theta)\to\infty$，直接 NaN
  • 长度惩罚：mode-seeking 导致学生倾向极短输出
  • 梯度截断：clip_grad_norm（max_norm=1.0）
  • 基线=1：$(R_t-1)$ 减少方差

7. DistiLLM：Skew KLD + Replay Buffer（2024）

DistiLLM（Ko et al., 2024）

核心创新：设计 Skew KLD（SKL/SRKL）目标。混合分布 $\tilde{p}=\alpha p_T+(1-\alpha)p_\theta$ 使散度下界 $\gt 0$，梯度直接可微（无需 REINFORCE），从根本上避免 $p_\theta(v)\approx 0$ 时的数值不稳定。

自适应 Off-Policy 策略：引入 Replay Buffer，基于验证损失自适应决定何时更新 On-Policy 数据，大幅提升计算效率。

核心权衡：用超参复杂度（$\alpha$ + replay buffer + 自适应调度器）换取数值稳定性，工程实现复杂但性能领先。

SKL 梯度（直接反传，永不除零）

$$\nabla_\theta\text{SKL}=-\sum_v p_T(v)\cdot\frac{(1-\alpha)\nabla_\theta p_\theta(v)}{\alpha p_T(v)+(1-\alpha)p_\theta(v)}$$
Algorithm 3: DistiLLM

$\mathcal{B}\leftarrow$student_sample$(p_\theta,K)$;  $L_\text{prev}\leftarrow$eval$(p_\theta)$ // 初始化 Replay Buffer

for each step:

if step mod $N=0$ and $|L_\text{prev}-$eval$(p_\theta)|\gt\delta$:  $\mathcal{B}\leftarrow$student_sample$(p_\theta,K)$ // 自适应刷新

$(\hat{y}^i,x^i)\leftarrow$sample$(\mathcal{B},B)$ // 从 buffer 取 batch

with no_grad():  $p_T^{i,t}\leftarrow p_T(\cdot|x^i,\hat{y}^i_{\lt t})$

$\tilde{p}^{i,t}\leftarrow\alpha p_T^{i,t}+(1-\alpha)p_\theta(\cdot|x^i,\hat{y}^i_{\lt t})$

$\mathcal{L}\leftarrow\frac{1}{B}\sum_i\frac{1}{|\hat{y}^i|}\sum_t D_\text{KL}(p_T^{i,t}\|\tilde{p}^{i,t})$;  optimizer.step($\mathcal{L}$.backward())

8. DistiLLM-2：对比蒸馏（ICML 2025 Oral）

DistiLLM-2（Ko et al., ICML 2025 Oral）

核心洞察：现有方法对教师生成数据和学生生成数据使用相同的损失函数，忽视了两类数据的本质差异——教师数据是"好答案"，学生数据是"自己的错误"。

对比目标：同时：在教师生成数据上增大学生的预测概率（学习正确答案）；在学生生成数据上降低学生的预测概率（远离自身错误）。

实验结果：在指令跟随、代码生成、偏好对齐、视觉语言任务上全面超越 DistiLLM。

Algorithm 4: DistiLLM-2

for each epoch:  $\hat{Y}\leftarrow$vllm_batch_generate$(p_\theta,\mathcal{X})$ // Epoch 级批量，与 vLLM 兼容

for each mini-batch $(x,y^T,\hat{y})$:

$\mathcal{L}_+\leftarrow-\frac{1}{|y^T|}\sum_t\log p_\theta(y^T_t|\cdot)$ // ①提高教师数据概率

with no_grad():  $p_T^t\leftarrow p_T(\cdot|x,y^T_{\lt t})$

$\mathcal{L}_\text{KD}\leftarrow\frac{1}{|y^T|}\sum_t D_\text{KL}(p_T^t\|p_\theta^t)$ // ②软标签蒸馏

$\mathcal{L}_-\leftarrow+\frac{1}{|\hat{y}|}\sum_t\log p_\theta(\hat{y}_t|\cdot)$ // ③降低学生数据概率（正号=逆SFT）

optimizer.step($(\mathcal{L}_++\lambda_1\mathcal{L}_-+\lambda_2\mathcal{L}_\text{KD})$.backward())

9. TML On-Policy：一行代码改变（2025）

（Kevin Lu / Thinking Machines Lab）在已有 PPO/GRPO 框架中把 KL 正则的参考模型从"初始策略"换成"教师"，令外部奖励为 0，仅改一行。

Per-token 优势：$A_t=\log p_T(\hat{y}_t|\cdot)-\log p_\theta(\hat{y}_t|\cdot)$（stop-grad）

Algorithm 5: TML On-Policy Distillation

for each step:  $\hat{y}\leftarrow$student_sample$(p_\theta,x)$

with no_grad():  $A_t\leftarrow\log p_T(\hat{y}_t|\cdot)-\log p_\theta(\hat{y}_t|\cdot)$ // ← 唯一改动：ref=teacher

$\mathcal{L}\leftarrow-\frac{1}{|\hat{y}|}\sum_t A_t^\text{sg}\cdot\log p_\theta(\hat{y}_t|\cdot)$;  optimizer.step($\mathcal{L}$.backward())

# RL 框架中的实际改动（以 GRPO 为例）
# 原始：kl = log_student - log_initial_policy
log_teacher = teacher.compute_logprobs(sequences, prompts)  # <- 新增这一行
advantages  = log_teacher - log_student   # rewards=0，直接用负KL作为advantage
loss = -(advantages.detach() * log_student).mean()
loss.backward(); optimizer.step()

10. OPSD：同一模型教自己（2026）

OPSD — On-Policy Self-Distillation（Zhao et al., 2026）

核心问题：能否消除外部教师依赖，让模型从自身学习？

核心洞察：给定正确答案 $y^*$ 作为特权信息，足够强大的 LLM 可以"合理化"推理步骤，为弱化版自身（无特权信息的版本）提供密集的 token 级监督。

教师 Forward（有 $y^*$）

输入：$\text{concat}(x,\;y^*,\;\hat{y}_{1:n-1})$
输出：$p_T(\hat{y}_n|x,y^*,\hat{y}_{\lt n})$

学生 Forward（无 $y^*$）

输入：$\text{concat}(x,\;\hat{y}_{1:n-1})$
输出：$p_S(\hat{y}_n|x,\hat{y}_{\lt n})$

优化目标（策略梯度形式），优势 $A_n = \log p_T(\hat{y}_n | x, y^*, \hat{y}_{\lt n}) - \log p_S(\hat{y}_n | x, \hat{y}_{\lt n})$：

$$\mathcal{L}(\theta) = -\mathbb{E}_{\hat{y} \sim p_S} \left[ \frac{1}{|\hat{y}|} \sum_{n=1}^{|\hat{y}|} A_n(x, \hat{y}) \cdot \log p_S(\hat{y}_n | x, \hat{y}_{\lt n}) \right]$$
Algorithm 6: OPSD

for each step:  $\hat{y}\leftarrow$sample$(p_S(\cdot|x))$

with no_grad():  $\log p_T(\hat{y}_n|\cdot)\leftarrow$model_fwd$(\text{concat}(x,y^*,\hat{y}_{\lt n}))$ for all $n$

$A_n\leftarrow\log p_T(\hat{y}_n|x,y^*,\hat{y}_{\lt n})-\log p_S(\hat{y}_n|x,\hat{y}_{\lt n})$

$\mathcal{L}\leftarrow-\frac{1}{|\hat{y}|}\sum_n A_n^\text{sg}\cdot\log p_S(\hat{y}_n|\cdot)$;  optimizer.step($\mathcal{L}$.backward())

11. 推理任务专项：稀疏奖励难题

推理任务（数学、代码、逻辑推导）是 OPD 近年最活跃的应用方向。关键挑战是稀疏奖励——一条 500+ token 的推理链仅在最终答案处得到 ±1 奖励，信用分配极难。

RLKD / KDRL：KD + RL 融合

学生生成完整推理链 → RM 打分 → 策略梯度更新，同时最小化与教师的 KL 散度作为正则。KD 提供密集梯度稳定早期训练，RL 使学生超越教师分布。代表了"奖励 + 蒸馏"的工业化路径。

SDPO：文本反馈自蒸馏

学生生成代码/推理 → 接收结构化文本反馈（编译错误、测试输出）→ 教师（条件化于反馈的当前模型）为无条件学生提供 dense token 级信号。解决 RLVR 二进制奖励的信用分配瓶颈。

12. 训练动态稳定性：2025–2026 新前沿

随着方法成熟，研究重心转向 On-Policy 采样引入的训练不稳定性——这是 OPD 区别于静态数据集蒸馏的内在代价。

f-OPD：Freshness-Aware 异步控制

异步 On-Policy 训练中，生产者（采样）和消费者（训练）速度不一致导致"样本过期"问题：训练时用的样本已经不是当前策略生成的，引入隐性 off-policy 偏差。

f-OPD 解决方案：样本级 Staleness 评分 + 自适应 Buffer 刷新 + Rollout-Anchored KL，动态控制训练数据的"新鲜度"，平衡计算效率与 On-Policy 严格性。当前仍缺乏理论收敛分析。

Entropy-Aware OPD

Reverse KL 的众数寻求特性在教师分布高熵（模糊/多样性任务）时会导致生成多样性降低和不稳定的学习信号。

解决方案：根据教师熵动态切换——熵低时用 Reverse KL（精确追踪），熵高时融入 Forward KL（覆盖多样性），自适应平衡精度与多样性。

13. 工业部署实践

OPD 已从学术研究进入工业级 LLM 训练流水线，以 Qwen3 和 DeepSeek 为典型案例。

Qwen3 的 On-Policy 蒸馏实践（2025）
  • 关键发现：在推理任务上，On-Policy 蒸馏能以约 1/3 的 RL GPU 计算量达到等效性能
  • 核心优势：复用相同 prompt 多次训练不会导致答案记忆（不同于 RL），因为目标是匹配教师的完整分布而非记忆单一答案
  • 技术栈：结合多教师信号 + 课程学习（Curriculum）+ 自适应调度
系统OPD 应用方式关键效果
Qwen3On-Policy 蒸馏替代 RL，多教师 + 课程学习等效 RL 性能，大幅降低 GPU 成本（~1/3）
DeepSeek-V4自适应目标 + 多教师 + 课程稳定化三轴融合（目标 + 信号 + 动态）的工业实践
veRL 框架Async On-Policy KD Trainer，top-k sparse KL生产级异步蒸馏基础设施
为什么 On-Policy 蒸馏比 RL 高效（Qwen3 实践）

RL（GRPO）每条序列只有一个二进制奖励信号。On-Policy 蒸馏在每个 token 位置都有 $|\mathcal{V}|$ 维教师 logits 监督，信号密度高出词表大小倍（$\sim 10^5$×）。同一 prompt 可复用多轮不记忆答案（目标是匹配分布）。Qwen3：约 1/3 的计算量，等效 RL 推理性能。

16. 开放问题与未来方向

核心未解挑战
  • 极端架构差距：400B MoE → 1B dense 的蒸馏，线性投影或词表对齐效果不佳，非线性层级对齐是开放挑战
  • 黑盒教师的 On-Policy 蒸馏：当教师为封闭 API（仅提供文本输出）时，如何有效实现 On-Policy 软蒸馏
  • 长序列训练动态：长思维链（4000+ tokens）的 On-Policy 训练极不稳定，信用分配和梯度传播需要新方法
  • 多模态扩展：视觉-语言模型的 On-Policy 蒸馏，状态空间维度爆炸
  • 自蒸馏的理论边界：何种规模的模型能有效自我教导？如何防止 Mode Collapse？OPSD 在弱模型时 $A_n\approx 0$ 退化
  • 异步采样稳定性：f-OPD 的 freshness 控制还缺收敛理论分析

17. 核心洞见与读后评注

OPD 是 SFT → RL 的中间道路

Qwen3 团队的工作揭示了一个重要规律：On-Policy 蒸馏在推理任务上以 RL 成本的一小部分达到等效性能。这重新定义了后训练方法的选择逻辑——当有强大教师模型时，OPD 是 RL 的高性价比替代品；当需要超越教师时，RL 才是必要选择。

GKD → MiniLLM → DistiLLM 的权衡三角
  • GKD：简单低方差，散度选择无理论指导
  • MiniLLM：理论清晰（Reverse KL 有 mode-seeking 保证），高方差需大量 tricks
  • DistiLLM：数值稳定，但引入 $\alpha$ + buffer + 调度器三个超参

DistiLLM-2（对比）和 OPSD（自蒸馏）跳出此三角，开辟新方向。

三阶段演进的内在逻辑

Survey 识别的三阶段演进（目标函数 → 信号架构 → 训练动态）有其内在合理性：首先解决"学什么"（散度选择），再解决"从哪里学"（是否需要外部教师），最后解决"怎么稳定学"（异步采样与分布漂移）。当前的 f-OPD、Entropy-Aware OPD 等工作标志着领域进入工程成熟阶段。

自蒸馏趋势的深层含义

2025 年以来自蒸馏方法的崛起（OPSD、Vision-OPD、SDPO）不仅是工程便利性的产物，更反映了 LLM 能力的质变——当模型足够强大，其知识密度已足以自我引导提升。这与 Self-Play、Self-Reward、STaR 等方向共同描绘了一个不依赖外部标注的自进化 AI 学习范式。
