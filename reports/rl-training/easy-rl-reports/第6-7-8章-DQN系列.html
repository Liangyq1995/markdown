来源：蘑菇书 EasyRL  |  章节合并原因：第6章DQN基础→第7章DQN进阶技巧→第8章处理连续动作，构成完整的DQN技术体系

概述

深度Q网络（DQN）将Q-Learning与深度神经网络结合，用神经网络近似Q值函数，解决了表格型方法无法处理高维连续状态空间的问题。第6章介绍DQN的三大核心技术：目标网络、探索机制、经验回放。第7章系统梳理DDQN、Dueling DQN、优先级经验回放等7种进阶技巧及其组合（Rainbow）。第8章讨论DQN在连续动作空间中的局限与解决方案。

第6章：深度Q网络基础

价值函数近似

为什么需要：状态空间连续或极大（如像素输入）时，表格型Q值存储不可行，用参数化函数 $Q_\phi(s,a) \approx Q_\pi(s,a)$ 替代，通过梯度下降学习参数 $\phi$。

DQN训练目标的推导：出发点是贝尔曼最优方程：

$$Q^*(s,a) = R(s,a) + \gamma \sum_{s'} p(s'|s,a)\max_{a'} Q^*(s',a')$$

用单步采样 $(s_i, a_i, r_i, s_{i+1})$ 近似期望，并用当前 $Q_\phi$ 替代 $Q^*$，构造TD目标：

$$y_i = r_i + \gamma\max_a Q_\phi(s_{i+1}, a) \quad \text{（理想情况，但会导致训练不稳定）}$$

为稳定训练，用冻结参数的目标网络 $\hat{Q}_{\phi^-}$ 计算目标值（见下节）：

$$y_i = r_i + \gamma\max_a \hat{Q}_{\phi^-}(s_{i+1}, a)$$

训练损失：最小化预测值与TD目标的均方误差：

$$\mathcal{L}(\phi) = \mathbb{E}_{(s_i,a_i,r_i,s_{i+1})\sim\mathcal{D}}\!\left[\left(Q_\phi(s_i,a_i) - y_i\right)^2\right]$$

梯度（对 $y_i$ 视为常数）：$\nabla_\phi \mathcal{L} = -2\left(y_i - Q_\phi(s_i,a_i)\right)\nabla_\phi Q_\phi(s_i,a_i)$，用SGD更新 $\phi$。

技术1：目标网络

问题：若用同一网络同时生成目标值和预测值，目标在训练中不断移动（追着移动的靶子），导致训练不稳定。

解决：维护两个网络——Q网络（持续更新）和目标网络 $\hat{Q}$（每C步才复制Q网络参数）。目标值始终由 $\hat{Q}$ 计算，提供稳定的训练信号。

技术2：探索机制

训练时若完全贪心，智能体只利用已有知识，无法发现更好的策略。常用两种探索策略：

方法公式特点
ε-贪心以ε概率随机，1-ε概率贪心简单，但探索随机，与状态无关
玻尔兹曼探索$\pi(a|s) = \frac{e^{Q(s,a)/T}}{\sum_{a'}e^{Q(s,a')/T}}$按Q值概率采样，探索与状态相关

技术3：经验回放

问题：连续收集的 $(s_t, a_t, r_t, s_{t+1})$ 时序相关，直接用于SGD违反独立同分布假设，训练效率低且不稳定。

解决：将历史数据存入回放缓冲区（Replay Buffer），每次随机采样一批数据训练，打破时序相关性，同时实现异策略数据复用。

第7章：DQN进阶技巧

双深度Q网络（DDQN）

高估的数学根源：设真实Q值为 $Q^*$，估计值 $Q = Q^* + \epsilon$（误差 $\epsilon$ 均值为0）。DQN目标中：

$$\max_a Q(s',a) = \max_a(Q^*(s',a) + \epsilon_a) \geq Q^*(s', a^*) + \epsilon_{a^*} = \max_a Q^*(s',a) + \epsilon_{a^*}$$

即 $\mathbb{E}[\max_a Q(s',a)] \geq \max_a Q^*(s',a)$（取最大值操作放大了正误差）——这是系统性高估。

解决：选动作和评估动作由两个独立网络完成，使高估不再被单向放大：

$$y = r_t + Q'\!\left(s_{t+1},\; \underbrace{\arg\max_a Q(s_{t+1}, a)}_{\text{Q网络选动作}}\right) \quad \text{（目标网络 }Q'\text{ 评估该动作）}$$

由于 $Q$ 和 $Q'$ 误差独立，高估倾向相互抵消，期望偏差趋近于0。

效果：显著减少Q值高估，在多个Atari游戏上提升性能。

竞争深度Q网络（Dueling DQN）

思路：将Q值分解为状态价值 $V(s)$ 和优势函数 $A(s,a)$ 之和：

$$Q(s,a) = V(s) + A(s,a)$$

为什么好：很多状态下动作选择几乎不影响结果（如驾驶直线时），$V(s)$ 提供共享基础，$A(s,a)$ 专注于动作差异，提升数据利用效率。

分解不唯一问题与零均值约束的必要性：上式分解不唯一——对任意常数 $c$，令 $\tilde{V}(s) = V(s) + c$，$\tilde{A}(s,a) = A(s,a) - c$，则 $Q = \tilde{V} + \tilde{A}$ 同样成立，网络无法区分哪部分是 $V$ 哪部分是 $A$，梯度信号混乱。

解决方法：强制 $\sum_a A(s,a) = 0$（零均值约束），此时分解唯一（可证明）：

$$Q(s,a) = V(s) + \left(A(s,a) - \frac{1}{|A|}\sum_{a'}A(s,a')\right)$$

实现方式：网络输出原始 $A'$ 向量后，减去均值得到约束满足的 $A$。例：$A' = [7,3,2]$，均值=4，则 $A = [3,-1,-2]$。

零均值约束还强迫网络将"所有动作共有的好坏"归入 $V(s)$，梯度自然优先更新 $V(s)$，更新频率更高，数据效率更好。

优先级经验回放（PER）

思路：TD误差大的样本含有更多"意外信息"，应更频繁地被采样学习。给每条经验赋予优先级权重 $p_i \propto |\delta_i| + \varepsilon$，按权重采样。

注意：非均匀采样打破了无偏性，需引入重要性采样权重修正梯度更新。

多步方法

TD(0) 单步目标 vs 多步目标：

$$Q(s_t, a_t) \leftarrow \sum_{t'=t}^{t+N} r_{t'} + \gamma^{N+1} \hat{Q}(s_{t+N+1}, \cdot)$$

增大N：回报更接近真实（减少偏差），但方差增大；N是平衡偏差-方差的超参数。

噪声网络（NoisyNet）

传统ε-贪心缺陷：探索与状态无关，同一状态每次可能选不同动作，缺乏一致性。

NoisyNet：在网络参数空间而非动作空间加高斯噪声，同一回合内噪声固定，实现"状态相关的一致探索"——相同状态总会做出相同（噪声影响下的）决策。

分布式Q函数（C51）

不输出Q值的期望，而是输出奖励的完整概率分布（离散化为51个区间）。保留分布信息使智能体可以规避高方差/高风险的动作，本质上解决了期望值相同但风险不同的问题。

彩虹（Rainbow）：7种技术的组合

技术解决问题Rainbow中重要性
多步方法偏差-方差平衡最高
优先级经验回放样本利用效率高

第8章：DQN处理连续动作

DQN的核心操作 $\arg\max_a Q(s,a)$ 在离散动作空间可枚举，但连续动作空间无法穷举。

方案方法优点缺点
采样近似采样N个动作，选最大Q值简单不精确，N大则慢
梯度上升对动作变量 $a$ 做梯度上升理论精确计算量大，局部最优
特殊网络架构$Q(s,a) = -(a-\mu(s))^T\Sigma(s)(a-\mu(s)) + V(s)$可解析求最优函数形式受限
放弃DQN改用Actor-Critic（如DDPG）自然处理连续动作需两套网络

方案3详解：网络输出三个分量 $\mu(s)$（向量）、$\Sigma(s)$（正定矩阵，$\Sigma=LL^T$）、$V(s)$（标量），令 $a = \mu(s)$ 时第一项归零，Q值取最大，无需搜索即可求解最优动作。

总结与启发

DQN系列展示了如何将深度学习与Q-Learning有机结合：目标网络解决训练目标不稳定，经验回放打破数据相关性，二者是DQN成功的核心。进阶技巧从不同角度解决DQN的各类缺陷——高估（DDQN）、数据效率（Dueling、PER）、探索质量（NoisyNet）、值分布（C51），Rainbow的消融实验揭示了各技术的相对重要性。连续动作是DQN的固有局限，这正是Actor-Critic方法（下一章）兴起的根本动机。
