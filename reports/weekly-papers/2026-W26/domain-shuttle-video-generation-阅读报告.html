概述

DomainShuttle 是一个面向开放域主体驱动文本生成视频的新型框架，核心目标是同时实现高主体保真度与强生成灵活性——这两个目标在现有方法中往往相互制约。论文针对"域内（In-domain）"与"跨域（Cross-domain）"两种生成场景，提出了三个相互配合的技术组件：Domain-MoT（解耦视频与参考特征，引入域感知 AdaLN）、Video-Reference DualRoPE（为参考图像与视频 token 分配独立 RoPE 空间）以及 Cross-Pair Consistent Loss（提取与域无关的主体内在特征）。实验结果表明，DomainShuttle 在跨域主体一致性指标 CD-Score 上相比现有最优方法提升约 19%，同时在视频质量和文本可控性上保持竞争力。

研究背景：主体驱动视频生成

主体驱动视频生成（Subject-driven Text-to-Video, S2V）要求模型在给定一张或多张参考图像的条件下，依据文本提示生成包含该主体的视频。这一任务在视频个性化、创意内容生产、数字人等应用场景中具有重要价值。

两种核心场景

现有 S2V 方法主要面向两类不同的生成需求，它们对主体特征的保留程度要求截然不同：

场景 目标 典型应用 挑战
域内生成（In-domain） 最大化保留参考主体的外观、风格、环境等所有特征 数字人复刻、IP 角色动画 避免生成漂移，保持高相似度
跨域生成（Cross-domain） 保留主体内在特征，同时允许风格、语义、域属性灵活变化 真实人物→水彩/3D动画、幻想角色→真实场景 解耦内在特征与域属性，避免过拟合

现有方法的局限

现有方法（如 Phantom、MAGREF、SkyReels-V3、VACE 等）主要针对域内场景进行优化，过度追求主体保真度，导致其在跨域场景下表现欠佳：当文本提示要求风格迁移或语义变换时，模型要么无法遵循风格指令，要么在执行风格变换时丢失主体一致性。根本原因在于：这些方法未能有效解耦主体的内在特征（identity-level features，如脸部结构、物体形状）与域属性（domain-level attributes，如材质、光照、艺术风格）。

核心洞察： 理想的 S2V 方法应能像"穿梭机"一样自由在不同域之间切换——在域内场景下忠实还原主体，在跨域场景下灵活适应新域，而不是被迫在两者之间取舍。

组件一：Domain-MoT（域感知混合变换器）

Domain-MoT（Domain-aware Mixture of Transformers）是 DomainShuttle 的核心架构创新，解决了跨域 S2V 中主体内在特征与域属性相互纠缠的根本问题。

是什么

一种将视频潜变量与参考图像特征解耦到两条独立处理路径的变换器架构，并在参考图像分支引入域感知 AdaLN 进行域特定建模。

为什么需要

若视频特征与参考特征共享同一处理路径，域属性（如水彩风格、3D 卡通质感）会与主体内在特征（如人脸结构）相互污染，导致模型难以在跨域场景下既遵循风格指令又保持主体一致性。

怎么做

Domain-MoT 将视频潜变量 $\boldsymbol{f}_v$ 和参考图像特征 $\boldsymbol{f}_r$ 经 3D VAE 编码后分别进行 patch 化，随后在上下文内自注意力（In-context Self-Attention）中使用独立的 QKV 投影和独立的 RoPE：

$$\text{Attn}(\boldsymbol{f}_v, \boldsymbol{f}_r) = \text{softmax}\!\left(\frac{[\boldsymbol{Q}_v; \boldsymbol{Q}_r][\boldsymbol{K}_v; \boldsymbol{K}_r]^\top}{\sqrt{d}}\right)[\boldsymbol{V}_v; \boldsymbol{V}_r]$$

其中 $\boldsymbol{Q}_v, \boldsymbol{K}_v, \boldsymbol{V}_v$ 和 $\boldsymbol{Q}_r, \boldsymbol{K}_r, \boldsymbol{V}_r$ 分别来自视频分支和参考分支的独立投影矩阵。这一解耦设计保留了视频分支作为基础模型的原有能力，同时使参考图像分支专注于提取精确的主体特征。

更关键的是，域感知 AdaLN（Domain-aware Adaptive Layer Normalization）被引入参考图像分支，将域属性（如"水彩风格"、"3D 动画"等文本编码）注入参考特征的归一化过程：

$$\text{AdaLN}(\boldsymbol{f}_r, \boldsymbol{c}_d) = \boldsymbol{\gamma}(\boldsymbol{c}_d) \cdot \frac{\boldsymbol{f}_r - \mu}{\sigma} + \boldsymbol{\beta}(\boldsymbol{c}_d)$$

其中 $\boldsymbol{c}_d$ 为域条件嵌入，$\boldsymbol{\gamma}(\cdot)$ 和 $\boldsymbol{\beta}(\cdot)$ 为从域条件学习的仿射变换参数。这使得模型能在特征空间中显式区分不同域，实现更精确的跨域 S2V。

组件二：Video-Reference DualRoPE（双空间旋转位置编码）

在 Domain-MoT 解耦特征的基础上，DomainShuttle 进一步引入 VR-DualRoPE 机制，解决参考图像 token 与视频 token 在位置编码空间中的混淆问题，实现精细的主体级空间建模。

是什么

将参考图像 token 与视频 token 分配到相互独立的 RoPE（旋转位置编码）空间中，使两者的空间位置关系在注意力计算中被显式建模。

为什么需要

标准 RoPE 将所有 token（包括参考图像 token 和视频 token）编码在同一位置空间中。这导致两个问题：（1）不同主体的参考 token 在位置空间中相互干扰，难以区分；（2）同一主体的参考 token 与视频中对应区域的 token 缺乏有效的空间对应关系。VR-DualRoPE 通过独立空间分配解决这两个问题。

怎么做

标准 RoPE 通过旋转矩阵对 token 的位置进行编码。对于位置 $m$ 处的 query 向量和位置 $n$ 处的 key 向量，其注意力分数只依赖于相对位置 $m-n$：

$$\text{RoPE}(\boldsymbol{q}_m, \boldsymbol{k}_n) = \text{Re}\!\left[(\boldsymbol{q}_m e^{im\theta})(\boldsymbol{k}_n e^{in\theta})^*\right] = f(m-n)$$

VR-DualRoPE 为参考图像 token 分配独立的位置坐标系，使得：

  • 不同主体的参考 token 在各自独立的 RoPE 空间中被显式分离，避免相互干扰；
  • 同一主体的参考 token 在潜变量空间中被拉近，增强主体内聚性；
  • 参考图像 token 与视频 token 的位置关系通过独立坐标系精确建模，实现主体级别的精细空间控制。

组件三：Cross-Pair Consistent Loss（跨对一致性损失）

CCL 是训练阶段的监督信号设计创新，其目标是引导模型学习与域无关的主体内在特征，而非被域属性所干扰。

是什么

一种对比式训练损失，通过对齐同一视频对应的两组不同参考图像（域属性不同但主体相同），迫使模型提取主体的本质特征。

为什么需要

若仅使用重建损失训练，模型可能学习到将参考图像的所有特征（包括背景、光照、风格等域属性）都注入到视频中，而非仅提取主体内在特征。CCL 通过构造"同主体、不同域"的参考图像对，强制模型忽略域属性差异，聚焦于主体本质特征。

怎么做

在训练时，对于同一个视频，构造两组参考图像 $\mathcal{R}_1$ 和 $\mathcal{R}_2$，它们描述同一主体但来自不同域（如一组为真实照片，另一组为卡通风格）。CCL 约束两组参考图像在模型特征空间中的表示尽可能一致：

$$\mathcal{L}_{\text{CCL}} = \mathbb{E}\!\left[\left\|\phi(\mathcal{R}_1) - \phi(\mathcal{R}_2)\right\|_2^2\right]$$

其中 $\phi(\cdot)$ 为模型对参考图像的特征提取函数。通过最小化 $\mathcal{L}_{\text{CCL}}$，模型被迫在两组不同域的参考图像中找到共同的主体表示，从而过滤掉域属性的影响，提取真正的内在主体特征。总训练损失为扩散去噪损失与 CCL 的加权组合：

$$\mathcal{L} = \mathcal{L}_{\text{diffusion}} + \lambda \mathcal{L}_{\text{CCL}}$$

总结与启发

DomainShuttle 通过"解耦-独立位置编码-内在特征提取"三步走的设计路线，在开放域 S2V 任务中实现了此前被认为相互矛盾的两个目标：高主体保真度与强生成灵活性。其核心贡献在于将"域"作为一个独立的建模维度，而非让模型隐式地在主体特征和域属性之间权衡。

方法论层面的启发

1. 特征解耦是跨域泛化的基础

Domain-MoT 的设计揭示了一个重要原则：当任务涉及多个正交维度（如"主体身份"与"域风格"），为每个维度分配独立的处理路径，比让单一路径隐式建模更为有效。这一思路可推广到其他需要解耦多维属性的生成任务。

2. 位置编码设计对多模态对齐至关重要

VR-DualRoPE 的成功表明，当参考模态（图像）与生成模态（视频）在语义上存在对应关系但在物理空间上不完全对齐时，为二者分配独立的位置编码空间比共享空间更能捕捉精细的主体级对应关系。这对图像-视频联合建模具有重要参考价值。

3. 对比式训练损失可显式提取内在表示

CCL 的设计思路——通过"同主体、不同域"的图像对对比，迫使模型忽略域属性——是一种优雅的监督信号设计。类似的"不变性诱导损失"在其他需要提取域不变特征的任务（如跨域迁移学习、风格解耦生成）中同样值得借鉴。

4. "域内-跨域"双场景评估框架值得推广

DomainShuttle 提出的双场景评估框架（域内高保真 vs. 跨域高灵活性）比单一的"主体相似度"指标更能全面评估 S2V 方法的实际能力。未来的主体驱动生成研究应采纳这一更完整的评估视角。

局限性与未来方向

  • DomainShuttle 在域内 DINO-I 指标上（0.400）略低于 Kling 1.6（0.401）和 SkyReels-V3（0.407），说明在极端域内保真度场景下仍有提升空间。
  • 训练数据构建（构造"同主体、不同域"的图像对）需要额外的数据工程，可能限制方法的通用性。
  • 未来可探索将 Domain-MoT 的域感知建模扩展到更多模态（如音频驱动视频生成）或更细粒度的属性解耦（如姿态、表情、场景）。
