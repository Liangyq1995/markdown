标题Scaling the Horizon, Not the Parameters: Reaching Trillion-Parameter Performance with a 35B Agent
核心问题如何用35B参数的MoE模型，在长轨迹Agent任务上超越万亿参数级别大模型
开源地址github.com/InternScience/Agents-A1

1. 核心问题与动机

大型语言模型（LLM）的性能提升通常依赖于参数规模的堆砌——从7B到70B再到万亿参数级别。然而，万亿参数模型的训练和推理成本极为高昂，部署门槛极高。

Agents-A1 提出了一个颠覆性思路：不扩展参数规模，而是扩展 Agent 的"视野"（Horizon）。具体而言，通过构建更长的推理轨迹和跨多个异构能力域的智能体协同，一个仅有35B参数的MoE模型，可以在基准测试中达到甚至超越 Kimi-K2.6、DeepSeek-V4-pro 等万亿参数级模型的性能。

"The performance gap between small and large models can be bridged not by adding parameters, but by teaching agents to reason over longer, richer interaction horizons."

  • 长达45K tokens的轨迹数据难以收集和过滤
  • 多个异构域（数学、科学、编程、网页浏览等）的知识难以统一
  • 教师模型（Teacher）的专家知识难以向小学生模型（Student）迁移

4. 关键技术

4.1 长轨迹知识-动作基础设施

Agents-A1 构建了一套专门的长轨迹生成基础设施，连接四类组件：

  • 外部知识：检索增强（RAG）、工具调用、代码执行
  • 动作空间：Web浏览、文件操作、代码运行等
  • 观测反馈：环境返回的中间结果
  • 验证器：对每步动作的结果进行打分

生成轨迹平均长度达 45K tokens，远超普通SFT数据。

4.2 三阶段训练配方

Stage 1：全领域 SFT

在全部领域数据上进行有监督微调，对基座模型进行广泛的 Agent 行为对齐。这一阶段覆盖了数学、科学、编程、工具调用等多个领域，为后续专业化训练奠定基础。

Stage 2：域级教师模型训练

在6个异构领域分别训练专精的领域教师模型（Domain-Level Teacher），每个教师专精于某一领域（如分子生物学、数学奥林匹克、代码工程等）。

Stage 3：多教师域路由 On-Policy 蒸馏

这是最核心的创新。模型在推理时，根据当前任务的领域类型动态路由到对应教师，获取该领域的蒸馏监督信号：

$$\mathcal{L}_{\text{DOPD}} = \sum_{d=1}^{D} \mathbb{1}[domain=d] \cdot \mathcal{L}_{KL}(\pi_{\text{teacher}_d} \| \pi_{\text{student}})$$

同时引入 Salient Vocabulary Alignment（关键词汇对齐），专注于让学生模型学习教师模型在关键决策词汇（如工具调用名、关键推理步骤）上的分布，避免在无意义词汇上的梯度浪费。

Algorithm 1: Multi-Teacher Domain-Routed On-Policy Distillation

Input: Student $\pi_s$, Teacher set $\{\pi_{T_d}\}_{d=1}^{D}$, Trajectory buffer $\mathcal{B}$

for each training step do

batch ← sample($\mathcal{B}$) // 采样长轨迹 batch

for each trajectory $\tau$ in batch do

d ← DomainRouter($\tau$) // 判断领域

salient_tokens ← SalientVocabSelect($\tau$) // 关键词汇对齐

$\mathcal{L}$ ← KL_Loss($\pi_{T_d}$, $\pi_s$, salient_tokens)

end for

Backprop($\mathcal{L}$) // 更新学生模型

end for

return Student $\pi_s$ (35B MoE)

6. 消融实验与关键发现

  • 轨迹长度的作用：将平均轨迹从10K缩短至45K，性能显著提升，证实"扩展视野"的有效性
  • 域路由 vs. 单一教师：多教师域路由比单一通用教师提升约3-5个百分点
  • Salient Vocabulary Alignment：在关键词汇上聚焦的蒸馏比全词蒸馏更高效
  • MoE vs. Dense：相同激活参数规模下，MoE架构在多域任务上表现更优

7. 局限性

  • 长轨迹数据构建成本高，基础设施复杂
  • 45K token的推理轨迹在推理时延方面代价较大
  • 6个领域的划分可能不够覆盖所有真实世界任务
  • 结果依赖特定基准集，泛化到未见领域仍待验证

8. 核心洞见与读后评注

关键洞见：参数规模≠能力边界。在 Agent 范式下，模型的实际能力上界由其"有效视野长度"和"异构能力整合度"共同决定，而非纯粹参数量。

这篇论文最深刻的贡献在于对"Scaling Law"的重新解读：以往我们理解的scaling是指参数量，但Agents-A1表明还存在另一条scaling维度——Agent轨迹长度与域覆盖的协同扩展。

从工程角度，多教师域路由蒸馏是一个非常实用的框架：它允许在有限计算预算下，通过组合多个专家教师的知识来构建通才学生模型。这与集成学习的思想一脉相承，但在LLM训练范式下有独特的实现路径。

值得关注的是Salient Vocabulary Alignment这一细节设计——它揭示了蒸馏效率的核心：不是每个token都同等重要，关键决策节点（如工具调用、答案生成）的对齐才真正驱动能力迁移。这对未来的蒸馏方法设计具有重要启发。

未来方向：将此框架扩展到更多异构域，同时探索如何在更短的轨迹内实现同等效果（减少推理时延），以及结合强化学习进一步提升长轨迹规划能力。
