概述

Kwai Keye-VL-2.0-30B-A3B 是快手（Kuaishou）于 2026 年 6 月发布的开源多模态大模型，采用 Mixture-of-Experts（MoE）架构，总参数量 30B，推理时仅激活 3B 参数，兼顾能力与部署效率。该模型是快手 Keye 系列的第三代（前两代为 Keye-VL 和 Keye-VL-1.5），核心目标是将多模态理解从短视频感知推进到小时级长视频的全局上下文推理，同时具备代码、工具调用、搜索等 Agentic 智能场景的协作能力。

本论文提出了两项范式级创新来解决长期困扰多模态大模型的双重瓶颈：

  • 极端上下文扩展（Extreme Context Scaling）：传统全注意力机制在 256K token 的多模态序列下面临 KV 缓存爆炸和计算壁垒，被迫通过激进的帧下采样牺牲时序连续性。Keye-VL-2.0 首次将 DeepSeek Sparse Attention（DSA）适配到基于 GQA 的多模态架构，通过 MQA 风格的 Lightning Indexer 进行全局稀疏索引，将核心注意力复杂度从 $O(L^2)$ 降至 $O(Lk)$（$k=2048 \ll L$），实现无损 256K 上下文处理，支持 2 小时以上视频的连续帧分析。
  • 多模态对齐困境（Multimodal Alignment Dilemma）：将视频理解、工具调用等复杂能力直接注入模型往往触发灾难性遗忘，降低基础 STEM、数学和语言推理能力。Keye-VL-2.0 引入跨模态多教师在线策略蒸馏（MOPD），维护 13 个领域专家教师，通过动态路由将各领域的 token 级稠密反馈蒸馏回统一的 MoE 主干，在大幅提升 Agent 能力的同时稳健保留通用推理基线。

在基准评测方面，Keye-VL-2.0-30B-A3B 在 TimeLens 三个时序定位子集（ActivityNet 58.5、QVHighlights 70.1、Charades 58.4）上均超越 Gemini-3-Flash 和 Qwen3-VL-235B-A22B Thinking，在 LongVideoBench（74.1）和 Video-MME-v2（42.4 ACC）上达到同量级开源模型最优。代码能力方面，LiveCodeBench v6 达到 64.2，SWE-bench Verified 达到 62.0。工具调用方面，τ2-Bench 82.6 和 VitaBench 33.1 均为同量级最优。该模型以 CC BY 4.0 协议完全开源，为社区提供了一个高效、可扩展的多模态 Agentic 基础设施。

研究背景与动机

长视频多模态理解的核心挑战

随着 LLM 能力快速提升，多模态模型的应用场景正从图片问答、短视频理解向小时级长视频分析和多步骤 Agentic 任务演进。这一转变带来了两类根本性挑战：

  • 基础设施瓶颈：视频帧数量与序列长度呈线性增长，标准稠密注意力的 $O(L^2)$ 计算复杂度使 256K token 上下文在实际部署中几乎不可行；KV 缓存显存占用随序列长度爆炸式增长；视频 I/O 解码成为训练吞吐的瓶颈。
  • 算法困境：多任务联合对齐（视频理解 + 工具调用 + 数学推理 + OCR）会引发灾难性遗忘（Catastrophic Forgetting），不同任务的梯度方向相互干扰，导致模型在获得新能力的同时丧失已有能力。

现有主流方案普遍采用激进帧下采样（如 1~2 FPS）来规避计算瓶颈，但这会丢失细粒度时序信息，使模型无法进行精确的时序定位（Temporal Grounding）。Keye-VL-2.0 通过稀疏注意力机制从根本上解决了这一矛盾。

模型架构

整体架构概览

Keye-VL-2.0-30B-A3B 采用标准的多模态大语言模型（MLLM）范式，由四个核心组件构成：

  • 视觉编码器（ViT）：继承自 Keye-VL-1.5-8B，基于 SigLIP-400M-384-14，支持原生分辨率输入
  • 语言解码器（LLM）：基于 Qwen3-30B-A3B-Thinking-2507，提供强大的通用知识、指令跟随和推理能力
  • MLP 投影器（Projector）：将视觉特征映射到 LLM 表示空间
  • 稀疏注意力模块（DSA）：兼容 GQA 的稀疏注意力设计，支持 256K 多模态上下文

原生分辨率视觉编码

与 InternVL3 等采用动态切片（Dynamic Tiling）的方案不同，Keye-VL-2.0 选择原生分辨率编码策略：图像和视频帧保持原始尺寸和宽高比，通过 NaViT 的 Patch n' Pack 机制将不同尺寸样本打包进同一批次，结合 FlashAttention 实现无 padding 浪费的高效训练。这对于 OCR、文档理解、图表分析等细粒度场景尤为重要。

统一视频编码策略

视频帧被视为独立的高分辨率图像，由同一 ViT 编码器处理。每帧的视觉 token 前缀一个自然语言时间戳，为 LLM 提供明确的时序锚点。自适应视频像素预算（Adaptive Video Pixel Budget）根据视频时长动态调整每帧分辨率：短视频压缩更激进，长视频保留更多视觉证据。

核心技术

DSA 稀疏注意力机制

传统全注意力的计算复杂度为 $O(L^2)$，在 256K token 序列下不可行。Keye-VL-2.0 将 DeepSeek Sparse Attention（DSA）首次适配到 GQA-based 多模态架构，分三个子模块实现高效长上下文处理。

2.3.1 MQA 风格 Lightning Indexer

Lightning Indexer 采用 MQA 键共享设计，为当前查询 token $h_t$ 与每个先前 token $h_s$ 计算全局索引分数：

$$I_{t,s} = \sum_{j=1}^{H^I} w^I_{t,j} \cdot \text{ReLU}(q^I_{t,j} \cdot k^I_s)$$

其中 $H^I$ 为 indexer head 数，$q^I_{t,j}$ 和 $w^I_{t,j}$ 从 $h_t$ 导出，$k^I_s$ 是从 $h_s$ 导出的共享键。通过 ReLU 激活函数（替代 Softmax）实现非归一化的稀疏评分。

获得全局分数后，Top-k 选择形成稀疏索引集：

$$\Omega_t = \{s \mid I_{t,s} \in \text{Top-}k(I_{t,:})\}$$

设 $k = 2048$，核心注意力复杂度从 $O(L^2)$ 降至 $O(Lk)$，其中 $k \ll L$。所有查询头共享同一键头，大幅减少计算量和显存访问。配合 FP8 实现，即使序列含数十万 token 也保持高效。

2.3.2 GQA 稀疏聚合

在 GQA 主干中，查询头被分为 $G$ 个组，组内共享 KV 头。对所有组应用相同的稀疏索引集 $\Omega_t$。对第 $g$ 组，稀疏注意力输出为：

$$u_{t,g} = \text{Attn}(h_{t,g},\ \{c_{s,g} \mid s \in \Omega_t\})$$

所有组的输出拼接形成最终注意力表示。这一设计保留了 GQA 主干的表示结构，同时避免了对完整上下文的稠密注意力计算，实现了低显存、低计算代价的长程时空语义聚合。

2.3.3 稠密预热与稀疏自适应（两阶段训练）

DSA 采用两阶段训练策略，避免稀疏 indexer 从随机初始化在稀疏监督下学习的困难：

阶段一：稠密预热（Dense Warm-up） — 主模型保持稠密 GQA，大部分参数冻结，仅训练 indexer。目标是让 indexer 的全局分布覆盖所有 GQA 组的注意力分布。对查询 token $t$，聚合各组的稠密注意力分数，归一化得目标分布 $p_{t,:,g}$，预热损失为：

$$\mathcal{L}^I_{\text{warmup}} = \sum_t \sum_{g=1}^{G} D_{\text{KL}}(p_{t,:,g} \| \text{Softmax}(I_{t,:}))$$

此阶段使用约 2B 多模态 token。

阶段二：稀疏自适应（Sparse Adaptation） — 所有参数解冻，训练切换到稀疏模式。KL 损失仅在所选 Top-k token 集上计算：

$$S_t = \{s \mid I_{t,s} \in \text{Top-}k(I_{t,:})\}$$

目标分布在 $S_t$ 上截断并重新归一化：

$$\mathcal{L}^I_{\text{sparse}} = \sum_t \sum_{g=1}^{G} D_{\text{KL}}(p_{t,S_t,g} \| \text{Softmax}(I_{t,S_t}))$$

主模型以标准下一 token 预测损失优化，indexer 输入从计算图中 detach 以减少梯度干扰。最终目标函数：

$$\mathcal{L}_{\text{total}} = \mathcal{L}_{\text{NTP}} + \lambda \mathcal{L}^I_{\text{sparse}}$$

Algorithm 1: DSA 两阶段训练流程

Phase 1: Dense Warm-up // 约 2B 多模态 token

Freeze: ViT, LLM backbone; Train: Lightning Indexer

For each query token t:

Compute dense attention scores for all GQA groups

p_{t,:,g} = normalize(group-aggregated dense scores)

Loss: KL(p_{t,:,g} ‖ Softmax(I_{t,:}))

Phase 2: Sparse Adaptation // 全参数解冻

Unfreeze: all parameters

For each query token t:

S_t = TopK(I_{t,:}, k=2048)

Sparse attention: u_{t,g} = Attn(h_{t,g}, {c_{s,g} | s ∈ S_t})

Indexer loss: KL(p_{t,S_t,g} ‖ Softmax(I_{t,S_t}))

NTP loss on main model (indexer input detached)

L_total = L_NTP + λ · L_sparse

MOPD 跨模态多教师在线策略蒸馏

领域专项后训练引入了来自纯文本、图像、视频和 Agent 任务的异构能力，直接混合可能导致干扰（如推理 RL 后回答过短，Agent 训练后格式过度规范化）。MOPD 通过 13 个 RL 训练的领域教师，将各领域的 token 级稠密反馈蒸馏回统一 MoE 主干。

动态路由：给定提示 $x_i$，学生模型先生成在线策略响应：

$$y_i = (y_{i,1}, \ldots, y_{i,T}) \sim \pi_\theta(\cdot \mid x_i)$$

对状态 $s_{i,t} = (x_i, y_{i,\lt t})$，路由教师 $\pi^{r(i)}_T$ 提供 token 级反馈。

Top-k 重叠集稳定反馈：为避免在极低概率 token 上的不稳定比较，定义重叠集：

$$\Omega_{i,t} = \text{TopK}\!\left(\pi^{r(i)}_T(\cdot \mid s_{i,t})\right) \cap \text{TopK}\!\left(\pi_\theta(\cdot \mid s_{i,t})\right)$$

当 $\Omega_{i,t}$ 非空时，原始优势为：

$$A_{i,t} = \sum_{v \in \Omega_{i,t}} \bar{\pi}_\theta(v \mid s_{i,t}) \left[\log \pi^{r(i)}_T(v \mid s_{i,t}) - \log \pi_\theta(v \mid s_{i,t})\right]$$

其中归一化权重 $\bar{\pi}_\theta(v \mid s_{i,t}) = \pi_\theta(v \mid s_{i,t}) / \sum_{u \in \Omega_{i,t}} \pi_\theta(u \mid s_{i,t})$。若 $\Omega_{i,t} = \emptyset$ 则 $A_{i,t} = 0$。

策略梯度目标：

$$\mathcal{L}_{\text{MOPD}} = -\mathbb{E}\left[\frac{1}{|M_i|} \sum_{t \in M_i} \hat{A}_{i,t} \log \pi_\theta(y_{i,t} \mid x_i, y_{i,\lt t})\right]$$

其中 $M_i$ 为有效响应 token 掩码。进一步应用 token 类别感知优势缩放（下调格式 token，上调感知/推理 token），以及对长序列重复崩溃的局部惩罚：

$$\hat{A}_{i,t} = \tilde{A}_{i,t} - \lambda_{\text{rep}} \cdot \mathbb{I}[t \geq \tau_i]$$

Algorithm 2: MOPD 跨模态多教师在线策略蒸馏

Input: 13 domain teachers {Math, OCR, Grounding, Video, Code, Tool, Safety, ...}

For each training sample x_i:

// Step 1: 学生在线采样

y_i ~ sample(π_θ, x_i) // on-policy rollout

// Step 2: 动态路由到对应教师

teacher = route(x_i) // 按模态和任务类型路由

// Step 3: SPRR 对齐（分段提示-响应重新 tokenize）

SPRR_align(teacher, x_i, y_i)

For each token position t in y_i:

Ω_{i,t} = TopK(teacher) ∩ TopK(π_θ)

If Ω_{i,t} ≠ ∅:

Compute A_{i,t} (overlap-weighted KL advantage)

Else: A_{i,t} = 0

Apply token-category scaling + repetition penalty

Update π_θ with policy-gradient on L_MOPD

GSPO（Group Sequence Policy Optimization） 是 Keye-VL-2.0 RL 阶段的核心优化算法。给定查询 $x$，旧策略 $\pi_{\theta_{\text{old}}}$ 采样 $G$ 个响应 $\{y_i\}_{i=1}^G$，优化目标为：

$$J_{\text{GSPO}}(\theta) = \mathbb{E}\left[\frac{1}{G}\sum_{i=1}^G \min\left(s_i(\theta)\hat{A}_i,\ \text{clip}(s_i(\theta), 1-\epsilon, 1+\epsilon)\hat{A}_i\right)\right]$$

其中序列级重要性权重（对数概率平均后指数化）：

$$s_i(\theta) = \exp\left(\frac{1}{|y_i|}\sum_{t=1}^{|y_i|} \log\frac{\pi_\theta(y_{i,t} \mid x, y_{i,\lt t})}{\pi_{\theta_{\text{old}}}(y_{i,t} \mid x, y_{i,\lt t})}\right)$$

归一化优势：

$$\hat{A}_i = \frac{R(x, y_i) - \text{mean}(\{R(x, y_j)\}_{j=1}^G)}{\text{std}(\{R(x, y_j)\}_{j=1}^G) + \delta}$$

在 H800 GPU（$2/GPU-hour 定价假设）下，与 128K 上下文的全注意力相比：

消融实验与关键发现

DSA 的无损性验证

两阶段训练策略（稠密预热 → 稀疏自适应）的关键作用在于：稠密预热阶段使 indexer 的全局分布先对齐原始稠密注意力模型的行为，避免了在稀疏监督下从零学习的困难。论文报告在长上下文评测中，DSA 设计保留了稠密模型的全部能力，同时大幅降低推理开销，即"无损"压缩。

Video RL 的增量贡献

Video RL 阶段（约 31K 视频样本，冻结 ViT 和投影器）在通用视频基准上带来约 +1 个百分点的提升，并在 TimeLens 时序定位上有显著增益。时序视频定位（tIoU 奖励）、稠密字幕（LLM-as-Judge）和 FrameForge 合成视频（规则可验证）三类任务提供互补的视频监督信号。

MOPD 解决灾难性遗忘

通过维护 13 个领域专家教师并动态路由，MOPD 有效隔离了任务特定专长，避免了直接混合异构任务时的梯度干扰。Segmented Prompt-Response Re-tokenization（SPRR）确保教师 log 概率与学生响应 token 的严格对齐——即使是图像 token 数量、视频帧采样、chat template 或 mRoPE 位置的微小不匹配都可能将 KL 信号导向错误的 token 位置。

合成差异识别 RL 的设计价值

Synthetic-Data RL 框架通过程序化生成的差异识别任务提供规则可验证的奖励，无需额外学习的奖励模型。差异无关的重渲染扰动（颜色抖动、布局扰动、语义无操作变化等）防止模型依赖简单的像素级差分，强制学习真正的视觉理解。

ViT-LM 异构并行的吞吐提升

ViT 和 LM 采用独立的并行分片策略（而非绑定到同一 PP 阶段），配合两级负载均衡，端到端训练吞吐提升约 20%。DSA 优化（FlashInfer + TileLang）相比开源基准实现 2× 以上加速。

局限性

  • MLVU 未达最优：在 MLVU（82.8）上落后于 Qwen3.5-35B-A3B（85.6），说明在某些多任务长视频理解场景下仍有提升空间。
  • SWE-bench Verified 略低于同量级竞品：62.0 vs Qwen3.5-35B-A3B 的 63.5，仓库级软件工程任务的复杂上下文理解仍是挑战。
  • DSA 仅适用于解码器层：视觉编码器（ViT）仍使用全注意力，极高分辨率图像的编码成本未被 DSA 覆盖。
  • 多教师蒸馏的工程复杂度：维护 13 个领域教师模型需要大量的计算资源和严格的多模态对齐验证，对工程基础设施要求较高。
  • Video-MMMU 未超越 GPT-5-mini：在需要从教学视频中学习并应用领域知识的 Video-MMMU 上（80.0 vs GPT-5-mini 82.5），说明知识获取型长视频理解仍有差距。
  • 闭源模型对比不完整：部分基准（如 MLVU、Video-MME）缺乏 GPT-5-mini 和 Gemini-3-Flash 的可比分数，横向对比存在局限。

总结与启发

Kwai Keye-VL-2.0 是 2026 年上半年多模态大模型领域最值得关注的开源工作之一，其核心价值不仅在于基准数字，更在于它提供了一套可复现、可扩展的工程解决方案，将两个长期悬而未决的问题同时推进到新阶段。

关于 DSA 的深层意义：将稀疏注意力引入多模态架构的最大挑战不是算法本身，而是如何在 GQA 这种非 MLA 架构下保持表示质量。Keye-VL-2.0 的解法（MQA 风格全局索引 + GQA 分组聚合）优雅地解耦了"找到哪些 token 重要"（MQA 高效索引）和"如何聚合这些 token"（GQA 结构保持）两个问题。两阶段训练（稠密预热确保 indexer 分布对齐，稀疏自适应让主模型学会依赖动态证据）的设计哲学值得借鉴：新模块的引入不应强迫主模型从零适应，而应先让新模块向主模型靠拢，再共同演化。

关于 MOPD 的范式价值：多教师在线策略蒸馏代表了一种新的后训练范式——不是让单一模型同时学习所有能力，而是让专家教师在学生自己生成的轨迹上提供 token 级反馈，再将这些反馈合并回统一主干。这与人类学习的"分科教学 + 综合考试"有某种对应关系。Top-k 重叠集的设计尤其精妙：只在教师和学生都认为合理的 token 子集上计算 KL，避免了在极低概率区域的无效比较，同时保持了在线策略性（feedback 基于学生自己的 rollout）。

关于长视频理解的技术路线选择：Keye-VL-2.0 选择了"原生分辨率 + 时间戳注入 + 稀疏注意力"的路线，而非设计专用的视频编码器或时序融合模块。这一"简单但彻底"的方案——将视频帧视为独立高分辨率图像，用自然语言时间戳提供时序锚点——在工程上更易维护，在能力上也更容易从图像迁移到视频。TimeLens 上的 SOTA 结果（特别是 Charades 上的 58.4 mIoU，远超 Gemini-3-Flash 的 61.2 mIoU 反被超越）验证了这一路线的有效性。

对未来工作的启发：论文明确指出未来方向是将长视频理解与 Agent 工作流深度融合——从"被动理解视频内容"到"主动协调视频生产流程"（大规模检索、精彩片段提取、自动剪辑打包、营销文案生成）。这代表了多模态 AI 从感知工具向生产基础设施的演进路径，也是快手作为视频平台将技术转化为业务价值的核心逻辑。对于研究者而言，Keye-VL-2.0 提供了一个重要启示：在多模态大模型时代，基础设施创新（稀疏注意力、异构并行、高效 I/O）与算法创新（MOPD、Context-RL）同等重要，甚至前者是后者得以落地的前提。
