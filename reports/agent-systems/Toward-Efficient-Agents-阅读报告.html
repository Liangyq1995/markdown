1. 核心问题与动机

1.1 Agent 效率为何比纯 LLM 更严峻？

纯 LLM 的成本近似线性：

$$\text{Cost}_\mathrm{LLM} \approx \alpha \cdot N_\mathrm{tok}$$

Agent 的成本叠加多个来源，形成复利效应：

$$\text{Cost}_\mathrm{agent} \approx \alpha N_\mathrm{tok} + I_\mathrm{tool} \cdot \text{Cost}_\mathrm{tool} + I_\mathrm{mem} \cdot \text{Cost}_\mathrm{mem} + I_\mathrm{retry} \cdot \text{Cost}_\mathrm{retry}$$

其中 $I_\mathrm{tool}$、$I_\mathrm{mem}$、$I_\mathrm{retry}$ 分别为工具调用、记忆操作、重试的次数。每一步的输出成为下一步的输入成本，token、延迟、计算在多轮交互中复利累积。

效率的 Pareto 前沿视角：效率有两种互补定义——（1）固定成本预算下的最高效能；（2）相同效能下的最低成本。两者构成效能-成本的 Pareto 前沿。高效 Agent 的目标是将当前系统推向这条前沿。

2.2 工作记忆：文本型 vs 潜在型

类型代表方法机制优势局限
文本型工作记忆MemAgent, MEM1, AgentFold逐步压缩/改写，保持上下文恒定大小可解释，通用压缩可能丢失关键信息
潜在型工作记忆MemoryLLM, M+, Memory3KV Cache 或隐藏状态存储长期信息消除文本重编码开销可解释性低，依赖架构支持

3.2 BTP 背包问题工具规划（核心创新）

将有预算约束的工具调用建模为背包问题（Knapsack Problem）：

$$\max \sum_i v_i x_i \quad \text{s.t.} \sum_i c_i x_i \leq B, \quad x_i \in \{0,1\}$$

其中 $v_i$ 为工具 $i$ 的期望效用，$c_i$ 为成本，$B$ 为总预算。RL 奖励 $r = \text{正确性} - \lambda \cdot \text{总成本}$，训练智能体在预算约束下最大化任务价值。

4. 高效规划

4.1 单智能体规划策略分类

类别代表方法核心思路效率收益
自适应控制SwiftSage（快/慢双系统）简单任务快系统，复杂任务慢系统减少不必要的深度推理
预算约束Budget-Aware Planner显式建模计算预算，提前终止低效路径避免无效延伸
树搜索LATS（MCTS+自我反思）维护搜索树，回溯失败路径减少随机失败重试
成本感知剪枝CATS搜索过程中实时估算成本，剪枝高成本分支降低搜索空间
任务分解ReWOO（规划-执行解耦）预先生成完整规划，批量执行减少冗余 LLM 调用
模型路由HuggingGPT将子任务路由给专用小模型避免大模型处理简单任务
核心哲学转变：高效规划将推理视为资源约束控制问题，而非无界搜索。每一次推理扩展都需要评估其边际效用是否值得计算成本。这与 ToT、MCTS 等无预算意识的方法有本质区别。

4.2 多智能体协作效率

策略代表方法核心机制

动态剪枝AgentPrune, AgentDropout学习去除低效通信边，减少冗余协作

蒸馏协调MAGDI, D&R将多智能体集体智慧蒸馏入单智能体，消除运行时协调开销

7. 核心洞见与读后评注

效率是 Agent 研究的"欠账"
2023-2024 年 Agent 研究大量聚焦于"能否完成任务"（有效性），效率问题基本被忽视。这篇综述的贡献是第一次系统性地指出：当前的 Agent 系统虽然有效，但在实际部署中的计算成本、延迟和 token 消耗已成为可持续性瓶颈。效率不是优化项，而是能否真正商业化的决定因素。
成本复利效应的深层含义
Agent 的成本公式中，$I_\mathrm{retry}$（重试次数）是最危险的项——当 Agent 遇到困难任务时，重试可以无界增长，导致成本爆炸。这意味着高效 Agent 需要两种能力：（1）在简单任务上减少不必要的调用；（2）在困难任务上及时"知难而退"（设置合理的成本上界，而非无限重试）。
蒸馏协调：消除运行时多智能体开销
MAGDI 和 D&R 提出了一个反直觉的思路：训练时用多智能体协作生成高质量数据，然后将集体智慧蒸馏回单智能体——推理时直接用单智能体，完全消除运行时的协调开销。这是"offline多智能体，online单智能体"的范式，兼顾了多智能体的质量优势和单智能体的效率优势。
