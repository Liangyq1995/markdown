Ⅰ

CosyVoice 1：监督语义 Token 奠基

首次将监督 ASR 模型的量化表示用于 TTS · S³ Tokenizer + LLM + OT-CFM

A1. 核心贡献

关键洞察：传统 TTS 使用无监督方式（Encodec、HuBERT）学习语音 token，缺乏显式语义信息和文本对齐。CosyVoice 1 首次提出从有监督 ASR 模型（SenseVoice）中提取 token——即监督语义语音 Token（S³ Token），从根本上解决了内容一致性差的问题。

A2. 架构：四大组件

flowchart LR
    TXT["文本输入"] --> BPE["BPE 文本分词"] --> TENC["文本编码器\n对齐文本与语音语义空间"]
    SPEECH["参考语音"] --> S3["S³ Tokenizer\nSenseVoice + VQ\n单码本 4096 codes\n25Hz token 率"]
    TENC --> LLM["LLM\n自回归生成语音 token\n序列: S v text T token E"]
    S3 --> LLM
    LLM --> CFM["OT-CFM 条件流匹配\n语音 token + x-vector + 掩码梅尔谱\n生成梅尔谱"]
    CFM --> VOC["HiFiGAN 声码器\n梅尔谱 -> 波形"]

A2.1 S³ Tokenizer（监督语义语音分词器）

在 SenseVoice ASR 编码器中间层插入向量量化（VQ）层：

$$H = \mathrm{Encoder}_1(\mathrm{PosEnc}(X))$$ $$\mu_l = \mathrm{VQ}(h_l, C) = \arg\min_{c_n \in C} \|h_l - c_n\|_2$$ $$c_{\mu_l} := \alpha c_{\mu_l} + (1-\alpha) h_l \quad \text{（EMA 码本更新）}$$ $$\tilde{H} = \mathrm{Encoder}_2(\mathrm{PosEnc}(\bar{H}))$$

A2.2 LLM 序列构造与训练目标

$$\text{输入序列：} [S,\; v,\; \{\bar{y}_u\}_{u \in [1:U]},\; T,\; \{\mu_l\}_{l \in [1:L]},\; E]$$ $$\mathcal{L}_\text{LLM} = -\frac{1}{L+1}\sum_{l=1}^{L+1}\log q(\mu_l)$$

A2.3 最优传输条件流匹配（OT-CFM）

$$\phi_t^{OT}(X_0, X_1) = (1-(1-\sigma)t)X_0 + tX_1$$ $$\omega_t(\phi_t^{OT} \mid X_1) = X_1 - (1-\sigma)X_0$$ $$\mathcal{L}_{OT\text{-}CFM} = \mathbb{E}_{t, p_0, q}\bigl|\omega_t(\phi_t^{OT}(X_0,X_1)\mid X_1) - \nu_t(\phi_t^{OT}(X_0,X_1)\mid\theta)\bigr|$$

附加技术：余弦时间调度器（为早期生成步骤提供更多 ODE 步数）+ 无分类器引导（CFG）（训练时以 20% 概率随机丢弃条件，推理时 $\beta=0.7$ 增强生成质量）。

A4. 指令增强（CosyVoice-instruct）

在 base 模型基础上，通过指令微调支持三类可控维度：

  • 说话人身份：描述角色特征（如"Selene，神秘优雅的舞者"）
  • 说话风格：情感（happy/sad/angry）、语速、音高、性别
  • 细粒度副语言：笑声 `[laughter]`、呼吸 `[breath]`、强调词 `...`

CosyVoice 2：统一流式合成框架

FSQ 替代 VQ · 预训练 LLM 初始化 · 块感知因果 CFM · 无损流式合成

B1. 四大核心改进

① FSQ 替代 VQ

VQ 码本利用率仅 23%（963/4096），FSQ 达 100%（6561/6561）。ASR 错误率从 18.26% 降至 10.67%（CV EN），保留更多内容信息。

② LLM 初始化 + 去掉文本编码器和说话人向量

用预训练 Qwen2.5-0.5B 初始化，直接对齐文本和语音 token。去掉 x-vector 避免信息泄露（x-vector 携带语言和副语言信息，损害韵律和跨语言能力）。

③ 统一流式/非流式框架

流式：每 N=5 个文本 token 跟 M=15 个语音 token 交替混合。非流式：完整文本后跟完整语音 token。单一模型支持两种模式，几乎无损。

B2. FSQ 量化公式

$$\bar{H} = \mathrm{ROUND}(\mathrm{Proj}_\mathrm{down}(H)), \quad \hat{H} = \mathrm{Proj}_\mathrm{up}(\bar{H})$$ $$\mu_i = \sum_{j=0}^{D-1} \bar{h}_{i,j} \cdot (2K+1)^j \quad \text{（(2K+1)进制索引）}$$

FSQ 无需 EMA 更新码本，梯度通过 straight-through estimation 反传。码本大小 $(2K+1)^D = 6561$（$K=3, D=4$），100% 利用率。

B3. 块感知因果流匹配

流匹配目标（ODE 简化为线性路径）：

$$\phi_t^{OT}(X_0, X_1) = (1-t)X_0 + tX_1, \quad \omega_t = X_1 - X_0$$ $$\theta^{*} = \arg\min_\theta\; \mathbb{E}_{p_0,q,t}\bigl|\omega_t - \nu_t(\phi_t^{OT}\mid\theta; \mu, \tilde{X}_1, v)\bigr|_1$$

四种因果掩码，单模型覆盖不同场景：

掩码类型可见范围适用场景
Non-causal Mask全部帧离线，最高质量
Full-causal Mask仅过去帧极低延迟场景
Chunk-M Mask过去 + M 未来帧第一包，低延迟+一定质量
Chunk-2M Mask过去 + 2M 未来帧后续包，接近离线质量

B4. DPO 后训练（SFT 阶段）

$$\mathcal{L}_{DPO}(\pi_\theta;\pi_\mathrm{ref}) = -\log\sigma\!\left(\beta\log\frac{\pi_\theta(\mu_w|y)}{\pi_\mathrm{ref}(\mu_w|y)} - \beta\log\frac{\pi_\theta(\mu_l|y)}{\pi_\mathrm{ref}(\mu_l|y)}\right)$$

创新：直接用 ASR 后端重新预测生成的 token，得到 ASR 奖励，通过 Gumbel-Softmax 使采样可微分，无需完整 TTS 合成就能反传梯度，效率高 4 倍。

C3. DiffRO：可微奖励优化

传统 RL（如 DPO）需要完整 TTS 合成以区分正负样本，计算代价高且难以区分。DiffRO 直接在 token 层面优化：

$$\tilde{\mu}_t = \mathrm{GumbelSoftmax}\, P_{\pi_\theta}(\mu_t \mid \mu_{1:t-1}; Y)$$ $$R_{ASR}(Y) = \log P_{ASR}(\tilde{Y}_n = Y_n \mid Y_{1:n-1}; \tilde{\mu}_{1:T})$$ $$\pi^{*}_\theta = \max_{\pi_\theta}\; \mathbb{E}[R(Y)] - \beta D_{KL}[\pi_\theta(\mu|Y) \| \pi_{ref}(\mu|Y)]$$
$$D_{KL}[\pi_\theta \| \pi_{ref}] = \sum_{t=1}^{T}\sum_{k=0}^{Q} P_{\pi_\theta}(\mu_t=k)\log\frac{P_{\pi_\theta}(\mu_t=k)}{P_{\pi_{ref}}(\mu_t=k)}$$

Gumbel-Softmax 使离散采样变得可微，从而直接通过反向传播优化 LM 参数，无需 RL 训练循环。多任务奖励（MTR）还可联合优化 SER、MOS 预测等声音属性。

C4. 发音内嵌（Pronunciation Inpainting）

纯 BPE 文本输入对多音字、罕见词的发音缺乏控制。CosyVoice 3 扩展词表，支持文字与音标混合输入：

  • 中文：用拼音替代多音字（如 "重" → "zhong4"）
  • 英文：用 CMU 音素替代罕见词（如 "quinoa" → phoneme sequence）

C5. 自训练文本规范化

传统 TTS 依赖手工规则文本规范化（TN）。CosyVoice 3 用 LLM（Qwen-Max）生成 TN 数据，通过三路构建辅助训练集（规则 TN + LLM TN + 逆 TN），端到端直接接受原始文本输入。

横向对比与核心洞见

S³ Token → FSQ → 多任务 Tokenizer：Tokenizer 是每代最重要的进化
三代迭代中，Tokenizer 始终是性能提升的核心杠杆：(1) V1 将无监督 token 换成有监督 ASR token，内容一致性大幅提升；(2) V2 将 VQ（23% 利用率）换成 FSQ（100% 利用率），进一步压缩信息损失；(3) V3 将单任务 ASR 扩展到多任务（ASR+SER+LID+AED+SA），使 token 携带情感、语言类型等丰富信息。Tokenizer 的设计哲学：让离散表示尽可能保留"人类觉得重要的信息"。
DiffRO 相比 DPO/PPO 的架构优势
传统 TTS RL（DPO/PPO）需要：采样 → 完整 TTS 合成 → ASR 评估 → 计算奖励 → 反传，每步需要 4 次前向计算且梯度无法通过离散采样反传。DiffRO 用 Gumbel-Softmax 让离散采样变得可微，直接在 token 分布上计算 ASR/SER 奖励并反传——不需要运行完整 CFM 和声码器，效率提升约 4 倍，且奖励信号更精细（token 级而非序列级）。
统一流式框架的工程意义（V2 最重要的工程贡献）
流式和非流式以往是两个独立模型。CosyVoice 2 的关键发现是：两者本质上是序列构造方式的差异（文本-语音交替混合 vs 先文本后语音），可以在同一 LLM 下用不同输入格式统一训练。块感知 CFM 的四种掩码（non-causal/full-causal/chunk-M/chunk-2M）进一步将流式和非流式的质量差异从"模型差异"缩小到"上下文窗口差异"，使流式几乎无损。
"野外"（in-the-wild）是 V3 的核心定位转变
V1/V2 主要在广播语音（干净、标准）上取得优异性能，但真实世界的参考语音往往含背景噪声、方言口音、极端情感。CV3-Eval 基准的建立标志着 TTS 评估从"实验室环境"向"实际部署条件"的转变。CosyVoice 3 是迄今第一个在该基准上被系统验证的系统，9 语言覆盖（含 de/fr/ru/it/es）使其成为当前最通用的开源 TTS 系统之一。
