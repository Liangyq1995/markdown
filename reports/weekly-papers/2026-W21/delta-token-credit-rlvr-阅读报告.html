2. 核心问题与动机

RLVR 中有一个根本性的粒度错位：奖励在序列层面（整条响应对或错），但策略参数的梯度更新作用于每个 token。弄清"哪个 token 该获得多少信用"是提升样本效率和训练稳定性的关键。

2.1 Token 信用分配问题

在当前主流的 RLVR 方法（GRPO、DAPO 等）中，策略梯度被所有 token 均匀或按优势加权，而不区分 token 的判别价值。 这导致两个问题：

  • 格式化 token 主导：换行符、句号、数字标注等高频 token 在多条响应中高度共享，它们贡献的梯度方向接近各 side（正/负样本侧）的均值，形成"公共噪声"，会主导质心方向。
  • 真正有辨别力的方向被稀释：那些在正确响应中出现、在错误响应中不出现（或反之）的"稀疏但判别性"的 token，由于数量少，在简单平均下贡献权重不足。
论文原文："centroid construction can be dominated by shared high-frequency patterns, such as formatting tokens, diluting sparse yet discriminative directions."

2.2 直觉举例

考虑一道数学题，模型生成 N 条响应：正确的 $N^{+}$ 条和错误的 $N^{-}$ 条。

在所有响应中，"\\n"（换行）、"."（句号）、"="（等号）等 token 几乎无处不在。它们在两侧的梯度向量高度相似——这些方向对于区分"对与错"毫无贡献，却在数量上占据了大多数，拉偏了 $\bar{\mu}_{+}$ 和 $\bar{\mu}_{-}$ 的估计。

相反，关键推理步骤中的 token（如某个中间变量的正确赋值）仅在正确响应里出现，其梯度方向强烈侧特异，才是真正值得被放大的信号。

5. 关键技术详解

5.1 RLVR 策略梯度公式与推导

以 DAPO 为代表的 RLVR 方法使用以下代理目标进行策略优化。给定提示 $q$，模型采样 $G$ 条响应 $\{o_1, \ldots, o_G\}$，对第 $i$ 条响应计算规范化优势 $\hat{A}_i$。

DAPO/RLVR 代理目标：

$$J_\mathrm{RLVR}(\theta) = \mathbb{E}_{q \sim \mathcal{D},\, o_i \sim \pi_{\theta_\mathrm{old}}(\cdot|q)} \left[ \frac{1}{\sum_{i,t} 1} \sum_{i=1}^{G} \sum_{t=1}^{|o_i|} \min\!\left( r_{i,t} \hat{A}_i,\; \mathrm{clip}(r_{i,t}, 1-\epsilon, 1+\epsilon)\, \hat{A}_i \right) \right]$$

其中 $r_{i,t} = \dfrac{\pi_\theta(o_{i,t} \mid q, o_{i,\lt t})}{\pi_{\theta_\mathrm{old}}(o_{i,t} \mid q, o_{i,\lt t})}$ 是重要性权重比率。

策略梯度的一阶展开：

对于任意上下文 $c$ 下的候选 token $x$，对数概率的变化量可用一阶 Taylor 展开近似：

$$\Delta \log \pi(x|c) \approx \left( \nabla_\theta \log \pi_\theta(x|c)\big|_{\theta_\mathrm{old}} \right)^\top \Delta\theta$$

定义 token 梯度向量 $v_{i,t} \triangleq \nabla_\theta \log \pi_{\theta_\mathrm{old}}(o_{i,t} \mid q, o_{i,\lt t})$，则 RLVR 更新方向可展开为：

$$\Delta\theta_\mathrm{RLVR} \propto \sum_{A_i \gt 0} \sum_t A_i \cdot v_{i,t} \;-\; \sum_{A_i \lt 0} \sum_t |A_i| \cdot v_{i,t}$$

5.2 线性判别器视角的数学分析

引入 side-wise 总质量 $M_{+} = \sum_{A_i \gt 0} \sum_t A_i$ 和 $M_{-} = \sum_{A_i \lt 0} \sum_t |A_i|$，以及各侧的优势加权质心：

$$\bar{\mu}_{+} = \frac{\sum_{A_i \gt 0} \sum_t A_i \cdot v_{i,t}}{M_{+}}, \qquad \bar{\mu}_{-} = \frac{\sum_{A_i \lt 0} \sum_t |A_i| \cdot v_{i,t}}{M_{-}}$$

则策略更新方向变为质心差形式：

$$\Delta\theta_\mathrm{RLVR} \propto M_{+}\,\bar{\mu}_{+} \;-\; M_{-}\,\bar{\mu}_{-}$$

对于任意 token $(i,t)$，其对数概率的变化为：

$$\Delta \log \pi(o_{i,t}|\cdot) \propto v_{i,t}^\top \left(M_{+}\,\bar{\mu}_{+} - M_{-}\,\bar{\mu}_{-}\right)$$

核心发现： 上式恰好是一个线性判别器——token $v_{i,t}$ 的对数概率增减，取决于其梯度向量与"辨别方向" $w = \bar{\mu}_{+} - \bar{\mu}_{-}$ 的内积正负。

  • $v_{i,t}^\top w \gt 0$：token 的对数概率被增大（与正侧方向对齐）
  • $v_{i,t}^\top w \lt 0$：token 的对数概率被降低（与负侧方向对齐）
  • 共享高频 token 的 $v_{i,t}$ 在两侧差异不大，导致 $\bar{\mu}_{+} \approx \bar{\mu}_{-}$，判别器退化

最小二乘解释（Appendix D）： 论文进一步证明，优势加权质心也是以下加权最小二乘问题的解：

$$\bar{\mu}_{+} = \arg\min_{\mu} \sum_{A_i \gt 0} \sum_t A_i \cdot \|v_{i,t} - \mu\|^2$$

这意味着格式化 token（大量存在于正负两侧，梯度方向相近）会拉着质心偏离真正的侧特异方向，产生有偏估计。

5.3 DelTA 的 Token 系数估计算法

DelTA 通过在两侧质心与 token 梯度向量之间建立软分配，迭代精化质心，使正负侧质心更具对比性。

软分配系数的闭合解（通过熵正则化优化导出）：

对于正侧 token ($A_i \gt 0$)：

$$\alpha_{i,t} = \sigma\!\left( \frac{\|v_{i,t} - \mu_{-}\|^2 - \|v_{i,t} - \mu_{+}\|^2}{\gamma_{+}} \right)$$

对于负侧 token ($A_i \lt 0$)：

$$\alpha_{i,t} = \sigma\!\left( \frac{\|v_{i,t} - \mu_{+}\|^2 - \|v_{i,t} - \mu_{-}\|^2}{\gamma_{-}} \right)$$

其中 $\sigma(\cdot)$ 为 sigmoid 函数，$\gamma_{\pm}$ 为自适应温度参数。

质心更新：

$$\mu_{+}^{(k+1)} = \frac{\sum_{A_i \gt 0} \sum_t A_i \cdot \alpha_{i,t}^{(k)} \cdot v_{i,t}}{\sum_{A_i \gt 0} \sum_t A_i \cdot \alpha_{i,t}^{(k)}}$$

最终 token 系数：

$$\lambda_{i,t} = \lambda_{\min} + (\lambda_{\max} - \lambda_{\min}) \cdot \alpha_{i,t}^{*}, \quad [\lambda_{\min}, \lambda_{\max}] = [0.8,\; 1.2]$$

Algorithm 1: DelTA — 判别式 Token 系数估计

Input: token 梯度代理 {v̂_i,t}, 优势 {A_i}, 迭代次数 K, 范围 [λ_min, λ_max] = [0.8, 1.2]

Output: token 系数 {λ_i,t}

// Step 1: 初始化质心为优势加权均值

μ₊⁽⁰⁾ ← AdvWeightedMean(v̂_i,t : A_i > 0)

μ₋⁽⁰⁾ ← AdvWeightedMean(v̂_i,t : A_i < 0)

for k = 0, 1, ..., K-1 do

// Step 2: 计算自适应温度参数

γ₊ ← AdaptiveTemp(v̂_i,t, μ₊⁽ᵏ⁾, μ₋⁽ᵏ⁾ : A_i > 0)

γ₋ ← AdaptiveTemp(v̂_i,t, μ₊⁽ᵏ⁾, μ₋⁽ᵏ⁾ : A_i < 0)

// Step 3: 计算软分配系数 α_i,t

for each (i, t) with A_i > 0:

α_i,t ← σ( (‖v̂_i,t − μ₋⁽ᵏ⁾‖² − ‖v̂_i,t − μ₊⁽ᵏ⁾‖²) / γ₊ )

for each (i, t) with A_i < 0:

α_i,t ← σ( (‖v̂_i,t − μ₊⁽ᵏ⁾‖² − ‖v̂_i,t − μ₋⁽ᵏ⁾‖²) / γ₋ )

// Step 4: 用 α 精化质心

μ₊⁽ᵏ⁺¹⁾ ← Σ(A_i·α_i,t·v̂_i,t : A_i>0) / Σ(A_i·α_i,t : A_i>0)

μ₋⁽ᵏ⁺¹⁾ ← Σ(|A_i|·α_i,t·v̂_i,t : A_i<0) / Σ(|A_i|·α_i,t : A_i<0)

end for

// Step 5: 映射到 [λ_min, λ_max] 范围，并自归一化

for each (i, t):

λ_i,t ← 0.8 + (1.2 − 0.8) · α*_i,t // α* 为收敛后的 α

λ_i,t ← λ_i,t · (len(sequence) / Σλ_i,t) // 自归一化，保持期望总步长不变

return {λ_i,t}

5.4 质心重加权机制与代理目标

获得 token 系数 $\{\lambda_{i,t}\}$ 后，DelTA 对标准 RLVR 代理目标进行重加权：

$$J_\mathrm{DelTA}(\theta) = \mathbb{E}\left[\frac{1}{\sum_{i,t} \lambda_{i,t}} \sum_{i=1}^{G} \sum_{t=1}^{|o_i|} \lambda_{i,t} \cdot \min\!\left( r_{i,t}\,\hat{A}_i,\; \mathrm{clip}(r_{i,t})\,\hat{A}_i \right)\right]$$

自归一化项 $\frac{1}{\sum_{i,t}\lambda_{i,t}}$ 确保总更新步长期望不变，避免超参敏感性。

5.5 梯度代理的实用近似

全参数梯度向量 $v_{i,t} \in \mathbb{R}^{|\theta|}$ 维度极高，存储和计算代价昂贵。论文提出用最后一层 logit 层的输出行向量作为代理：

$$\hat{v}_t = (1 - p_t(y_t)) \cdot h_t$$

其中 $h_t$ 是最后一层 Transformer 的隐层表示，$p_t(y_t)$ 是当前 token 的预测概率，整体使用 stop-gradient（只用于估计系数，不参与反向传播）。

直觉： $(1 - p_t(y_t)) \cdot h_t$ 正比于 cross-entropy 对 logit 的梯度（softmax 的雅可比对角项），是梯度方向的一个廉价但合理的近似。消融实验（Table 4）表明，用 Top-K hidden-gradient 代理可进一步提升 +1.02 分。

7.1 对侧对比是否必要（Table 2）

论文验证了"必须使用对侧（opposite-side）信息才能产生有效的判别系数"这一核心假设：

变体AIME25AIME26HMMT25-NovHMMT26-FebAvg (4项)
DelTA（完整版） 26.4628.1218.5420.2723.27
DAPO（基线） 23.3324.1712.0816.8619.05

关键发现： 仅使用同侧对比（即不利用对侧质心信息）不仅无法提升，反而比 DAPO 基线还差 (-1.11 avg)。这证明了跨侧对比是 DelTA 有效性的根本来源，同侧内部的变化方差并不能捕捉真正的判别信息。

7.2 Token 选择实验

用 $\lambda_{i,t}$ 做硬选择（保留 top-50% token）对比 DAPO：

  • 保留高 $\lambda$ 的 top-50% token：明显优于全 token DAPO
  • 保留低 $\lambda$ 的 bottom-50% token：训练"快速崩溃"

这说明低 $\lambda$ token 不仅仅是无信息的，它们会积极地损害训练。这与直觉一致：格式化 token 的梯度方向可能引入伪相关，混淆模型对推理正确性的判断。

7.5 训练动态

对比 DelTA 与 DAPO 在 Qwen3-8B-Base 上的训练曲线（论文 Figure 中展示）：

  • DAPO：训练中后期奖励停止增长甚至轻微下降，响应长度缩短，token 熵上升——典型的训练退化信号。
  • DelTA：持续改进，响应长度保持较长，token 熵更低——模型对长链推理更"自信"，训练更稳定。

8. 核心洞见与读后评注

8.1 "判别器视角"的理论价值

将 RLVR 更新诠释为"token 梯度空间中的线性判别"这一视角，是本文最重要的理论贡献。这个框架的价值在于：

  • 它给出了一个统一的分析语言，将 GRPO、DAPO、FIPO 等不同方法的 token 权重差异化归纳为同一框架下的不同 $\rho_{i,t}$ 选择。
  • 它解释了为什么基于熵阈值（Forking Tokens）的方法能有效：高熵 token 往往对应梯度方向更具侧特异性的位置。
  • 它为未来方法设计提供了明确的优化目标：最大化正负质心之间的判别距离，而非单纯追求奖励信号的均匀传播。

8.2 格式化 Token 的"双重身份"

传统 RLVR 研究通常只关注"高熵 token"（模型在此处不确定），并认为这些位置是训练信号的主要来源。本文提出了一个补充视角： 不确定性高的 token 未必判别力强，关键是看该 token 在正负侧的梯度方向是否有系统性差异。

格式化 token 的熵可能也较高（因为格式可以有多种），但它们在两侧的分布相似，判别力为零甚至为负。 DelTA 通过跨侧对比精确识别出这类"高熵但低判别"的 token 并降低其权重，这是比单纯熵过滤更精细的信号。

8.3 迭代精化的必要性：一次性估计的偏差

消融实验显示，去掉迭代精化是最大的单点伤害（-3.30 分）。这在数学上可以理解为：

  • 第一轮质心估计 $\mu_{\pm}^{(0)}$ 受高频格式 token 污染，仍然偏向"公共方向"。
  • 基于这个偏斜质心计算的 $\alpha_{i,t}^{(0)}$ 虽然比均匀权重好，但仍不够准确。
  • 经过 $K$ 次迭代后，格式 token 因为在两侧分布相近（$\alpha_{i,t}$ 低），逐渐被边缘化；真正判别性 token 的 $\alpha_{i,t}$ 收敛到高值，质心被吸引向侧特异方向。

这是一个类 EM 算法的机制——初始估计偏差大，但迭代能自我纠偏。

8.4 与 FIPO 的对比：前向 vs. 判别

FIPO 用"未来 KL 影响力"来衡量 token 的重要性：影响后续 token 分布越大，该 token 越重要。这是一种序列内因果影响视角。 DelTA 则是一种跨序列判别对比视角：同一位置的 token，在正确响应和错误响应中的梯度方向差别越大，越重要。

两者捕捉的信息有互补性，这也解释了为什么 DelTA 在 14B 上的提升幅度（+2.62，相对 FIPO 的 37.29）小于 8B 上的提升（+3.26，相对 SAPO 的 25.14）：更大模型上 FIPO 的"未来影响"信号质量更高，边际改进空间相应缩小。

8.5 泛化性与局限性

泛化性（实验验证）：

  • 代码生成（LiveCodeBench）：有效，说明不依赖数学任务的特殊结构。
  • 不同基础模型（OlmO3-7B）：有效，说明不依赖 Qwen3 的特定权重分布。
  • 域外基准：有效，说明改进来自更好的推理能力而非过拟合特定题型。

潜在局限：

  • 需要计算 token 梯度代理向量，虽然用 stop-gradient 近似降低了成本，但仍比标准 RLVR 多一次前向传播相当的开销。
  • 超参 $[\lambda_{\min}, \lambda_{\max}]$ 和迭代次数 $K$ 的最优设置可能依赖模型和任务，需要调优。
  • 线性判别器假设：梯度空间中的"正负类分离"可能不是线性可分的，当前方法只捕捉了线性方向，非线性判别可能进一步提升。

8.6 对 RLVR 研究范式的影响

本文提示了一个重要研究方向：RLVR 的关键瓶颈可能不在奖励信号的设计（verifiable reward 已经足够好），而在于奖励信号如何被正确地"翻译"到参数更新空间中各 token 的贡献分配。

更广义地说，这与 credit assignment problem（信用分配问题）在时间维度（哪个时间步贡献了最终奖励）的经典研究有深层联系，但在 LLM 场景下，"时间"变成了"token 序列位置"，而"正负对比"则提供了监督信号来源。DelTA 给出了一个优雅且实用的解法。
