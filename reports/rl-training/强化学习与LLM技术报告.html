强化学习与大语言模型技术报告

本报告整合了深度强化学习基础理论、LLM与RL的结合、LLM核心架构与微调技术四个主题，适合对强化学习与大语言模型有一定了解的读者系统性回顾。

第一部分：强化学习基础

强化学习（Reinforcement Learning）是机器学习的一个重要分支，研究智能体如何在与环境的交互中通过最大化累积奖励来学习最优行为策略。与监督学习不同，强化学习不依赖人工标注的数据，而是通过环境反馈的奖励信号进行自我学习。

1.1 核心概念

强化学习的两大主体是智能体（Agent）和环境（Environment），二者持续交互：智能体感知状态、做出决策、接收奖励；环境响应动作、转移状态、给出奖励。

马尔可夫奖励过程（MRP）

在马尔可夫过程基础上加入奖励函数 $r$ 和折扣因子 $\gamma$，得到 MRP $\langle\mathcal{S}, \mathcal{P}, r, \gamma\rangle$。从时刻 $t$ 开始的回报定义为：

$$G_t = R_t + \gamma R_{t+1} + \cdots = \sum_{k=0}^{\infty}\gamma^k R_{t+k}$$

折扣因子 $\gamma \in [0,1]$ 体现了远期奖励的不确定性。价值函数（Value Function）是某状态的期望回报：

$$V(s) = \mathbb{E}[G_t|S_t=s] = r(s) + \gamma\sum_{s' \in \mathcal{S}}p(s'|s)V(s')$$

上式即贝尔曼方程（Bellman Equation），矩阵形式为 $\mathcal{V} = \mathcal{R} + \gamma\mathcal{P}\mathcal{V}$。

马尔可夫决策过程（MDP）

MDP 在 MRP 基础上加入动作，智能体的目标是找到最大化累积奖励的策略。MDP 中定义两类价值函数：

函数定义含义
状态价值函数 $V^\pi(s)$$\mathbb{E}_\pi[G_t|S_t=s]$从状态 $s$ 出发遵循策略 $\pi$ 的期望回报
动作价值函数 $Q^\pi(s,a)$$\mathbb{E}_\pi[G_t|S_t=s, A_t=a]$状态 $s$ 下执行动作 $a$ 后遵循策略 $\pi$ 的期望回报

两者关系：$V^\pi(s) = \sum_{a \in \mathcal{A}}\pi(a|s)Q^\pi(s,a)$，$Q^\pi(s,a) = r(s,a) + \gamma\sum_{s'}P(s'|s,a)V^\pi(s')$

最优策略满足贝尔曼最优方程：

$$V^*(s) = \max_{a \in \mathcal{A}}\left\{r(s,a) + \gamma\sum_{s' \in \mathcal{S}}p(s'|s,a)V^*(s')\right\}$$ $$Q^*(s,a) = r(s,a) + \gamma\sum_{s' \in \mathcal{S}}p(s'|s,a)\max_{a' \in \mathcal{A}}Q^*(s',a')$$

策略迭代 vs 价值迭代
  • 策略迭代：每轮先完整评估当前策略（多次迭代直到收敛），再做一次策略提升；计算量大但收敛快。
  • 价值迭代：每步直接使用贝尔曼最优方程更新，无需等待评估收敛；更新公式简单，但需要更多迭代次数。

1.4 时序差分算法

现实中往往无法获得精确的状态转移概率，需要通过与环境交互采样数据来学习——这类方法统称为无模型强化学习。时序差分（TD）方法是其核心，只需一步交互即可更新：

$$V(s_t) \leftarrow V(s_t) + \alpha\underbrace{[r_t + \gamma V(s_{t+1}) - V(s_t)]}_{\text{TD误差 } \delta}$$

Sarsa 算法 On-Policy

直接对动作价值函数 $Q$ 进行时序差分更新，用当前策略采样的 $(s, a, r, s', a')$ 五元组更新：

$$Q(s_t, a_t) \leftarrow Q(s_t, a_t) + \alpha[r_t + \gamma Q(s_{t+1}, a_{t+1}) - Q(s_t, a_t)]$$

采用 $\varepsilon$-贪婪策略平衡探索与利用，避免某些状态-动作对从未被访问。

Q-Learning 算法 Off-Policy

与 Sarsa 的区别在于用最大 Q 值的动作来估计目标，而不是实际执行的动作：

$$Q(s_t, a_t) \leftarrow Q(s_t, a_t) + \alpha[r_t + \gamma\max_a Q(s_{t+1}, a) - Q(s_t, a_t)]$$

Q-Learning 使用四元组 $(s, a, r, s')$，数据可来自任意行为策略，因此是离线策略算法。

Double DQN

普通 DQN 在计算 TD 目标时，选动作与评估价值都使用同一网络，导致系统性高估。Double DQN 将两步解耦：

$$\text{目标} = r + \gamma Q_{w'}(s', \underbrace{\arg\max_{a'}Q_w(s', a')}_{\text{训练网络选动作}})$$

Dueling DQN

引入优势函数 $A(s,a) = Q(s,a) - V(s)$，将 Q 网络分解为状态价值和优势两个分支：

$$Q_{\eta,\alpha,\beta}(s,a) = V_{\eta,\alpha}(s) + A_{\eta,\beta}(s,a) - \frac{1}{|\mathcal{A}|}\sum_{a'}A_{\eta,\beta}(s,a')$$

1.6 策略梯度

基于价值的方法通过学习值函数间接获得策略，而策略梯度方法直接对策略参数化并优化目标函数 $J(\theta) = \mathbb{E}_{s_0}[V^{\pi_\theta}(s_0)]$。

策略梯度定理给出梯度的形式：

$$\nabla_\theta J(\theta) = \mathbb{E}_{\pi_\theta}\left[Q^{\pi_\theta}(s,a)\nabla_\theta\log\pi_\theta(a|s)\right]$$

直觉理解：如果在状态 $s$ 执行动作 $a$ 后获得的回报为正（$Q > 0$），则增大该动作的概率；反之减小。

REINFORCE 算法用蒙特卡洛采样估计 $Q^{\pi_\theta}$，对完整轨迹 $\tau$ 计算：

$$\nabla_\theta J(\theta) \approx \frac{1}{N}\sum_{n=1}^N\sum_{t=1}^{T_n} R(\tau^n)\nabla_\theta\log\pi_\theta(a_t^n|s_t^n)$$

1.7 Actor-Critic 算法

REINFORCE 使用完整轨迹回报估计梯度，方差大。Actor-Critic 引入 Critic（价值网络）来在线估计 $Q$ 值，降低方差，同时保持无偏性。

Critic 损失函数（TD 误差）：

$$\mathcal{L}(w) = \frac{1}{2}\left(r + \gamma V_w(s_{t+1}) - V_w(s_t)\right)^2$$

广义优势估计（GAE）

GAE 在方差和偏差之间取得平衡，通过超参数 $\lambda$ 调节：

$$A_t^{\text{GAE}} = \sum_{l=0}^{\infty}(\gamma\lambda)^l\delta_{t+l}, \quad \delta_t = r_t + \gamma V(s_{t+1}) - V(s_t)$$
  • $\lambda=0$：单步 TD 误差，偏差大方差小
  • $\lambda=1$：完整蒙特卡洛回报，偏差小方差大
def compute_gae(rewards, values, gamma=0.99, lambda_=0.95):
    T = len(rewards)
    advantages = np.zeros(T)
    gae = 0
    for t in reversed(range(T)):
        delta = rewards[t] + gamma * values[t + 1] - values[t]
        gae = delta + gamma * lambda_ * gae
        advantages[t] = gae
    return advantages

1.8 TRPO 与 PPO

策略梯度的核心问题：步长太大会导致策略急剧恶化，而步长太小收敛太慢。TRPO 和 PPO 通过限制新旧策略的差异来解决这一问题。

TRPO（信任区域策略优化）

在 KL 散度约束下最大化代理目标：

$$\max_\theta \mathbb{E}\left[\frac{\pi_\theta(a|s)}{\pi_{\theta_k}(a|s)}A^{\pi_{\theta_k}}(s,a)\right] \quad \text{s.t.} \quad \mathbb{E}[D_{KL}(\pi_\theta \| \pi_{\theta_k})] \le \delta$$

PPO（近端策略优化）

PPO 用更简单的方式近似 TRPO 约束，主要有两种形式：

PPO-Penalty：将 KL 散度惩罚加入目标函数：

$$\mathcal{J}_{\text{PPO}}^{\theta'}(\theta) = \mathcal{J}^{\theta'}(\theta) - \beta \cdot \text{KL}(\theta, \theta')$$

PPO-Clip（更常用）：通过裁剪概率比直接约束策略变化幅度：

$$\mathcal{J}_{\text{clip}} = \mathbb{E}\left[\min\left(\frac{\pi_\theta(a|s)}{\pi_{\theta'}(a|s)}A, \;\text{clip}\left(\frac{\pi_\theta}{\pi_{\theta'}}, 1-\varepsilon, 1+\varepsilon\right)A\right)\right]$$

注意：PPO 虽然目标函数中用了重要性采样，但行为策略与目标策略通过 KL 约束保持接近，本质上仍是同策略（On-Policy）算法。

GRPO（群体相对策略优化）

PPO 需要额外的 Critic 价值网络（规模与策略网络相当），显存和计算开销巨大。GRPO 的核心思想是用群体相对优势取代价值网络：

  • 对同一 Prompt 采样一组候选输出（Group）
  • 以组内平均奖励作为基线，计算各输出的相对优势
  • 彻底摆脱独立 Critic 网络，大幅降低训练资源
$$A_i = r_i - \text{mean}(\{r_1, r_2, \ldots, r_G\})$$

1.9 模仿学习

当奖励函数难以设计或信号极稀疏时，可利用专家演示数据直接学习策略，无需奖励信号。

方法核心思想优缺点
行为克隆（BC） 将 $(s_t, a_t)$ 视为监督学习样本，直接拟合专家策略 简单易实现；存在协变量偏移问题（训练分布与测试分布不匹配）
逆强化学习（IRL） 从专家轨迹中反推奖励函数，再用RL优化 可得到可解释的奖励函数；计算复杂度高
GAIL 用判别器区分智能体与专家轨迹，策略以"欺骗"判别器为目标 结合GAN思想；训练稳定性要求高

将大语言模型（LLM）纳入强化学习框架，是当前对齐（Alignment）研究的主流范式。语言生成过程可以被自然地映射为一个序列决策问题。

KL 约束的作用

参考模型与策略模型之间的 KL 散度约束（$\text{KL}(\pi_\theta \| \rho)$）防止策略模型过度偏离 SFT 初始分布，避免出现「奖励欺骗」（Reward Hacking）现象——即策略钻奖励模型的空子而非真正提升质量。

修正后的奖励信号

$$R(x, y) = r(x, y) - \beta\log\frac{\pi_\theta(y|x)}{\rho(y|x)}$$

2.3 奖励模型

奖励模型在 SFT 模型基础上将 LM Head 替换为输出标量的 Reward Head，用偏好数据训练：

$$\mathcal{L}_{\text{RM}} = -\mathbb{E}_{(x,y_w,y_l)\sim\mathcal{D}}\left[\log\sigma(r(x,y_w) - r(x,y_l))\right]$$

其中 $y_w$ 为偏好回答，$y_l$ 为较差回答。通过最大化它们奖励分数之差，让奖励模型拟合人类偏好。

ORM vs PRM

类型全称评估粒度适用场景
ORM Outcome Reward Model 仅对最终结果打分 答案验证简单的任务（数学、代码）
PRM Process Reward Model 对推理过程每步打分 需要引导推理质量的复杂任务

3.2 注意力机制

Transformer 的核心是缩放点积注意力（Scaled Dot-Product Attention）：

$$\text{Attention}(Q,K,V) = \text{softmax}\left(\frac{QK^T}{\sqrt{d_k}}\right)V$$

除以 $\sqrt{d_k}$ 防止内积过大导致 softmax 进入饱和区（梯度趋零）。

Multi-Head Attention

将注意力空间分割为多个子空间，每个 Head 独立学习不同类型的特征关系：

$$\text{MultiHead}(Q,K,V) = \text{Concat}(H_1, \ldots, H_a)W^O$$ $$H_i = \text{Attention}(QW_i^Q, KW_i^K, VW_i^V)$$

每个 Head 的维度从 $d_k$ 降至 $d_k/a$，保持总计算量不变。

注意力变体对比

类型注意力范围典型模型特点
Full Attention全序列双向BERT理解任务最强，不适合生成
Causal Attention仅左侧单向GPT 系列自回归生成，当前主流
Prefix Attention前缀双向 + 后缀单向GLM兼顾理解与生成

3.3 归一化层

方法归一化维度特点典型应用
BatchNormbatch 维度（每个通道）依赖 batch 统计量，NLP 效果差CV 模型
LayerNorm特征维度（每个样本）独立于 batch，NLP 标准选择BERT、GPT
RMSNorm特征维度（只用均方根）去掉均值计算，更轻量LLaMA、Qwen

RMSNorm 计算：$\hat{x}_i = \dfrac{x_i}{\sqrt{\frac{1}{d}\sum x_i^2} + \varepsilon}$，再乘可学习参数 $\gamma$。

Pre-Norm vs Post-Norm：现代大模型普遍采用 Pre-Norm（先归一化再做注意力），提升深层模型的训练稳定性，缓解梯度消失。

3.4 位置编码

方法原理优点应用
Sinusoidal 固定正弦余弦函数编码绝对位置 无需学习，可外推到更长序列 原始 Transformer
Learned PE 可学习绝对位置 Embedding 拟合能力强 BERT、GPT-2
RoPE 对 Q/K 施加旋转变换，编码相对位置 天然相对位置、长序列外推好 LLaMA、Qwen、ChatGLM
ALiBi 在注意力分数上加线性偏置惩罚距离 直接处理超长序列，无需重训 BLOOM、MPT

RoPE 核心思想

对位于 $m$ 的 Query 和位于 $n$ 的 Key 施加旋转矩阵 $R_m, R_n$，使得内积仅依赖相对距离 $n-m$：

$$(R_m \vec{q})^T(R_n \vec{k}) = \vec{q}^T R_{n-m} \vec{k}$$

3.5 激活函数

现代 LLM 的 FFN 层普遍采用 SwiGLU 替代 ReLU，通过门控机制提升梯度稳定性：

$$\text{SwiGLU}(x) = \text{Linear}_1(x) \otimes \text{Swish}(\text{Linear}_2(x))$$ $$\text{Swish}(x) = x \cdot \sigma(\beta x)$$

LoRA 详解

LoRA（Low-Rank Adaptation）在预训练权重矩阵旁并联低秩矩阵，训练时只更新 $A, B$：

$$W = W_0 + \Delta W = W_0 + A \cdot B^T$$

其中 $A \in \mathbb{R}^{d \times r}$，$B \in \mathbb{R}^{d \times r}$，$r \ll d$。

初始化策略：$A$ 使用高斯随机初始化，$B$ 初始化为零矩阵。这样训练开始时 $\Delta W = 0$，不影响预训练模型的输出，保证训练稳定。

LoRA 过拟合防治

方法原理
减小秩 $r$减少参数量，降低模型容量
增大 weight decayL2 正则化限制参数幅度
增大 dropout随机屏蔽 LoRA 层参数，增强鲁棒性
扩充数据集更多样本使模型学到更泛化的特征

3.8 DeepSeek 系列创新

MoE 架构改进

DeepSeek-V3 对传统 MoE 做了三项改进：

  • 细粒度专家划分：将 $N$ 个专家拆分为 $m \times N$ 个小专家，激活 $m \times K$ 个，提升组合灵活性
  • 共享专家 + 路由专家：共享专家处理所有输入的通用信息，路由专家处理差异化信息
  • 可学习负载均衡偏置：在路由得分上加偏置 $b_i$，动态平衡各专家负载，避免独立均衡 Loss 影响主任务性能
$$\text{score}'_i(x) = \text{score}_i(x) + b_i$$
