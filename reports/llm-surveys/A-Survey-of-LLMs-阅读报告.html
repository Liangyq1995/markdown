LLM 的定义与特殊性：LLM 通常指参数量达数百亿以上的 Transformer 语言模型（如 GPT-3 175B、PaLM 540B）。核心差异在于涌现能力（Emergent Abilities）——当参数超过某个阈值后，突然出现小模型完全不具备的能力（如 ICL、CoT 推理）。

4. 适配（Adaptation）

4.1 RLHF 三阶段完整公式

奖励模型目标（Bradley-Terry 偏好模型）：

$$\mathcal{L}(\theta_\mathrm{RM}) = -\mathbb{E}_{(x,y_w,y_l)}\!\left[\log\sigma\!\left(r_\theta(x,y_w) - r_\theta(x,y_l)\right)\right]$$

PPO 策略目标（带 KL 惩罚）：

$$\text{obj}(\theta) = \mathbb{E}_{(x,y)\sim D}\!\left[r_\theta(x,y) - \beta\log\frac{\pi_\theta(y|x)}{\pi_\mathrm{SFT}(y|x)}\right]$$

4.2 参数高效微调（PEFT）对比

方法核心思路训练参数量特点
Adapter Tuning在 FFN/MHA 之间插入小 Adapter 模块<1%顺序插入，有延迟
Prefix Tuning在每层添加可学习前缀 token<1%占用 KV Cache
Prompt Tuning在输入端加可学习软提示<0.1%最简单，效果有限
LoRA$\Delta W = AB$（低秩分解，A,B 为小矩阵）0.1-1%目前最广泛，1×80G GPU 微调65B

LoRA 核心：冻结原始权重 $W_0$，训练低秩增量 $\Delta W = BA$，前向计算为 $h = W_0 x + \Delta W x = W_0 x + BAx$。

5. 使用（Utilization）

5.1 上下文学习（ICL）

ICL 不更新参数，通过在输入中提供少量示例让模型完成任务：

$$p(y|x,C) = \prod_{t=1}^{|y|} p_\theta(y_t \mid x, C, y_{\lt t})$$

其中 $C = \{(x_1,y_1),\ldots,(x_k,y_k)\}$ 为 $k$ 个示例。GPT-3 首次展示该能力；小于 60B 的模型通常不具备稳定的 ICL 能力。

5.2 思维链推理（CoT）关键发现

  • CoT 效果在 60B+ 模型才显著，100B+ 更明显
  • 训练代码数据可能是获得 CoT 能力的原因之一
  • 步骤越清晰，性能提升越大（GSM8K > MAWPS > SWAMP）

6. 能力评估

6.1 涌现能力 vs 扩展律

视角度量趋势
扩展律（Scaling Law）语言建模损失连续平滑改善，边际收益递减
涌现能力特定任务性能不可预测的突然跳跃
涌现能力的争议：部分研究认为涌现可能是非连续评估指标的人工产物——当改变评估指标时，"突然涌现"的曲线变得平滑。但从用户角度看，代码能通过测试 vs 不能通过，本就是离散判断。

8. 核心洞见与读后评注

四代演进的本质逻辑
从统计模型到 LLM，每代演进的核心驱动力不同：统计模型靠概率论，神经语言模型靠分布式表示，PLM 靠大规模无监督预训练，LLM 靠参数规模 × 数据规模 × 计算规模的协同扩展。Scaling Law 提供了理论基础，但涌现能力的出现是意外的惊喜——没有人能在 GPT-2 时代预测 GPT-3 会突然具备 ICL 能力。
LoRA 为什么如此成功
LoRA 成功的深层原因是：LLM 的权重矩阵本身具有低内在维度（Low Intrinsic Dimensionality）——有效的梯度更新实际上发生在一个远比矩阵维度更小的子空间中。LoRA 明确利用了这一性质：$\Delta W = BA$，其中 $r \ll \min(d,k)$ 捕获了真正重要的更新方向，而忽略了大量无意义的高频噪声。这使得用 1% 的参数量获得接近全参微调的效果成为可能。
"为什么预测下一词有效"的深层启示
Sutskever 关于侦探小说的比喻揭示了一个深刻事实：在自然语言中，理解 = 预测能力。能精确预测下一词的模型，必然已经理解了上下文的语义、结构和逻辑关系。这个看似简单的自监督任务之所以如此强大，是因为自然语言本身隐含了人类几千年的知识、推理和文化——而 LLM 通过压缩这些文本，隐式地学习了其中的规律。
