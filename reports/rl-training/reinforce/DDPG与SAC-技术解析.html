符号总表

本文统一使用如下符号约定，贯穿 DDPG 和 SAC 两章：

$\mu_\theta$ 确定性策略网络（Actor），参数为 $\theta$
$\pi_\theta$ 随机策略网络（SAC Actor），输出动作分布
$Q_\phi$ Q 值网络（Critic），参数为 $\phi$
$\theta^-,\phi^-$ 目标网络参数（慢速跟踪主网络）
$\tau$ 软更新系数，典型值 $\tau \approx 0.005$
$\alpha$ 温度参数（SAC），控制熵正则化强度
$\mathcal{H}$ 策略熵 $\mathcal{H}(\pi(\cdot|s)) = -\mathbb{E}_{a\sim\pi}[\log\pi(a|s)]$
$\rho^\mu$ 策略 $\mu$ 诱导的状态访问分布
$\mathcal{D}$ 经验回放缓冲区（Replay Buffer）
$\gamma$ 折扣因子，$\gamma \in [0,1)$

第 13 章 · DDPG 算法

DDPG（Deep Deterministic Policy Gradient）由 Lillicrap 等人于 2016 年提出，是将 DQN 的深度学习技巧与确定性策略梯度（DPG）理论相结合的 Actor-Critic 算法，专门针对连续动作空间设计。

13.1 连续动作空间的挑战

经典的 Q-learning 和 DQN 在动作选择时需要求解：

$$a^* = \arg\max_{a \in \mathcal{A}} Q(s, a)$$

当动作空间为离散有限集合时，枚举所有动作即可求解。但在连续动作空间（如机器人关节角度、力矩控制）中，$\mathcal{A} \subseteq \mathbb{R}^d$，无法枚举，直接优化也代价极高。

为什么不用 DQN 处理连续动作？

  • 离散化精度损失：将连续动作离散化会损失精度，且维度爆炸（$d$ 维各离散 $k$ 格 → $k^d$ 个动作）
  • max 操作不可微：无法对连续动作做梯度优化
  • DPG 解决方案：用策略网络 $\mu_\theta(s)$ 直接输出连续动作 $a = \mu_\theta(s)$，将 $\arg\max$ 替换为神经网络前向传播

13.2 确定性策略梯度定理（完整证明）

确定性策略梯度（DPG）定理是 DDPG 的数学基础，由 Silver et al. (2014) 提出。下面给出完整的五步推导。

目标函数定义

对于确定性策略 $\mu_\theta : \mathcal{S} \to \mathcal{A}$，性能目标为：

$$J(\theta) = \int_{\mathcal{S}} \rho^{\mu}(s)\, Q^{\mu}(s,\, \mu_\theta(s))\, ds = \mathbb{E}_{s \sim \rho^{\mu}}\bigl[Q^{\mu}(s,\, \mu_\theta(s))\bigr]$$

其中 $\rho^{\mu}(s)$ 是在策略 $\mu$ 下的（折扣）状态访问分布。

DPG 定理推导 · 5 步
1
展开梯度积分

对目标函数取梯度，积分与梯度可交换（Leibniz 法则）：

$$\nabla_\theta J(\theta) = \int_{\mathcal{S}} \rho^{\mu}(s)\, \nabla_\theta Q^{\mu}(s,\, \mu_\theta(s))\, ds$$

2
链式法则展开（关键步骤）

$Q^{\mu}(s, \mu_\theta(s))$ 对 $\theta$ 的梯度通过链式法则分解为两项：

$$\nabla_\theta Q^{\mu}(s,\, \mu_\theta(s)) = \underbrace{\nabla_a Q^{\mu}(s,a)\big|_{a=\mu_\theta(s)}}_{\text{Q 对动作的梯度}} \cdot \underbrace{\nabla_\theta \mu_\theta(s)}_{\text{策略对参数的梯度}}$$

注意这里 $\nabla_\theta Q^{\mu}$ 还有一个隐式项（通过 $\rho^\mu$ 对 $\theta$ 的依赖），处理见步骤 3。

3
递归展开 $\nabla_\theta Q^{\mu}(s,a)$

将 $Q^{\mu}$ 用贝尔曼方程展开：

$$Q^{\mu}(s,a) = r(s,a) + \gamma \int_{\mathcal{S}} p(s'|s,a)\, V^{\mu}(s')\, ds'$$

其中 $V^{\mu}(s') = Q^{\mu}(s', \mu_\theta(s'))$。对 $\theta$ 求梯度后再次应用链式法则，得到递归结构：

$$\nabla_\theta Q^{\mu}(s,a) = \gamma \int_{\mathcal{S}} p(s'|s,a) \nabla_\theta Q^{\mu}(s', \mu_\theta(s'))\, ds' + \gamma \int_{\mathcal{S}} p(s'|s,a) \nabla_a Q^{\mu}(s',a)\big|_{a=\mu_\theta(s')} \nabla_\theta \mu_\theta(s')\, ds'$$

4
反复迭代展开（无穷展开求和）

将步骤 3 的递归反复代入，每次展开引入一个新的折扣状态转移，最终得到：

$$\nabla_\theta Q^{\mu}(s,a) = \sum_{t=0}^{\infty} \gamma^t \mathbb{E}_{s_t \sim p(s_t|s,a,\mu)}\Bigl[\nabla_a Q^{\mu}(s_t, a)\big|_{a=\mu_\theta(s_t)} \cdot \nabla_\theta \mu_\theta(s_t)\Bigr]$$

将此代入步骤 1 的积分，并利用 $\rho^{\mu}(s) = \sum_{t=0}^{\infty} \gamma^t p(s_t = s)$ 的定义，求和可合并。

5
最终结果：DPG 定理

化简后得到优雅的确定性策略梯度定理：

$$\boxed{\nabla_\theta J(\theta) = \mathbb{E}_{s \sim \rho^{\mu}}\Bigl[\nabla_\theta \mu_\theta(s) \cdot \nabla_a Q_\phi(s,a)\big|_{a=\mu_\theta(s)}\Bigr]}$$

实践中用参数化 Critic $Q_\phi$ 替代真实 $Q^{\mu}$，并从经验回放采样估计期望。

DPG 与随机策略梯度（SPG）的对比

随机策略梯度定理：$\nabla_\theta J(\theta) = \mathbb{E}_{s,a \sim \rho^\pi}\bigl[Q^\pi(s,a)\, \nabla_\theta \log \pi_\theta(a|s)\bigr]$

DPG 定理：$\nabla_\theta J(\theta) = \mathbb{E}_{s \sim \rho^\mu}\bigl[\nabla_\theta \mu_\theta(s) \cdot \nabla_a Q_\phi(s,a)\bigr]$

关键区别：DPG 不需要对动作空间积分，计算量更小；但确定性策略本身不探索，需额外加噪声。

13.3 DDPG 的四大组件

DDPG 在 DPG 理论基础上，借鉴 DQN 的工程技巧，构建了四个核心模块：

1 Actor（确定性策略网络）

输出确定性动作 $a = \mu_\theta(s)$，通常为多层全连接网络，最后一层用 $\tanh$ 激活将动作限制在 $[-1, 1]^d$。

更新方向：最大化 $Q_\phi(s, \mu_\theta(s))$，即 DPG 梯度方向。

2 Critic（Q 值网络）

$Q_\phi(s, a)$ 同时接收状态 $s$ 和动作 $a$ 作为输入（与 DQN 不同，DQN 只输入状态输出所有动作的 Q 值）。

通常将状态先经过一层全连接，再与动作拼接后继续前向传播。

更新方向：最小化 TD 误差（Bellman 残差）。

3 目标网络（Target Networks）

为 Actor 和 Critic 各维护一个目标网络 $\mu_{\theta^-}$ 和 $Q_{\phi^-}$，用于计算 TD 目标值，避免自举（bootstrapping）不稳定。

使用软更新而非 DQN 的硬更新（见 13.4 节）。

4 经验回放（Replay Buffer）

存储转移元组 $(s, a, r, s', \text{done})$，随机采样小批量打破时序相关性，与 DQN 相同。

容量通常为 $10^5 \sim 10^6$，采样批量 $N = 64 \sim 256$。

13.4 软更新 vs 硬更新

硬更新（DQN）

每隔 $C$ 步直接复制主网络参数：

$$\theta^- \leftarrow \theta$$

  • 目标值在 $C$ 步内固定，之后突变
  • $C$ 过小：目标变化快，不稳定
  • $C$ 过大：目标过时，学习慢

软更新（DDPG）

每步以小步长 $\tau$ 移动：

$$\theta^- \leftarrow \tau\theta + (1-\tau)\theta^-$$

  • $\tau \approx 0.005$，目标平滑缓慢跟踪
  • 避免目标突变，训练更稳定
  • 类似指数移动平均（EMA）

软更新的直观理解：目标网络是主网络的"慢动作版本"，提供稳定的学习目标。$\tau = 1$ 退化为硬更新，$\tau = 0$ 目标网络永不更新。

13.5 完整更新公式

Critic 损失（TD 误差最小化）

$$\mathcal{L}(\phi) = \mathbb{E}_{(s,a,r,s') \sim \mathcal{D}}\Bigl[\bigl(r + \gamma Q_{\phi^-}(s',\, \mu_{\theta^-}(s')) - Q_\phi(s,a)\bigr)^2\Bigr]$$

TD 目标 $y = r + \gamma Q_{\phi^-}(s', \mu_{\theta^-}(s'))$ 用目标网络计算，在反向传播时视为常数（stop gradient）。

Actor 更新（策略梯度上升）

$$\nabla_\theta J \approx \frac{1}{N}\sum_{i=1}^{N} \nabla_\theta \mu_\theta(s_i) \cdot \nabla_a Q_\phi(s_i, a)\big|_{a=\mu_\theta(s_i)}$$

实现时：先计算 $a_i = \mu_\theta(s_i)$，再对 $-Q_\phi(s_i, a_i)$ 关于 $\theta$ 反向传播（最大化 Q 等价于最小化 $-Q$）。

目标网络软更新

$$\theta^- \leftarrow \tau\theta + (1-\tau)\theta^-, \qquad \phi^- \leftarrow \tau\phi + (1-\tau)\phi^-$$

探索策略

$$a_{\text{explore}} = \mu_\theta(s) + \mathcal{N}$$

其中 $\mathcal{N}$ 为探索噪声（高斯噪声或 OU 过程，见 13.6 节），训练时加入，评估时去掉。

13.6 OU 过程（Ornstein-Uhlenbeck）

Ornstein-Uhlenbeck（OU）过程是一种均值回归的随机过程，其随机微分方程为：

$$d\mathcal{N}_t = \theta_{\text{OU}}(\mu_{\text{OU}} - \mathcal{N}_t)\,dt + \sigma\,dW_t$$

OU 过程参数含义

参数含义典型值
$\theta_{\text{OU}}$回归速率，越大越快回到均值0.15
$\mu_{\text{OU}}$长期均值（通常为 0）0
$\sigma$扩散系数（噪声强度）0.2
$dW_t$维纳过程增量（白噪声）—

为什么用 OU 而不是简单高斯噪声？ OU 过程具有时间相关性（自相关），生成的噪声序列平滑、有惯性，更适合物理控制系统（如机械臂）——连续时间步的动作变化不会太剧烈，符合物理约束。

离散化实现（Euler-Maruyama 方法）：

# OU 过程离散化实现
class OUNoise:
    def __init__(self, size, mu=0.0, theta=0.15, sigma=0.2):
        self.mu = mu * np.ones(size)
        self.theta = theta
        self.sigma = sigma
        self.state = np.copy(self.mu)

    def reset(self):
        self.state = np.copy(self.mu)

    def sample(self):
        dx = self.theta * (self.mu - self.state) + \
             self.sigma * np.random.randn(len(self.state))
        self.state += dx
        return self.state

第 14 章 · SAC 算法

SAC（Soft Actor-Critic）由 Haarnoja 等人于 2018 年提出，是目前最流行的连续控制算法之一。其核心思想是将最大熵框架引入 Actor-Critic，同时优化累积奖励和策略熵，实现更好的探索与鲁棒性。

14.1 最大熵强化学习框架

标准 RL 目标 vs 最大熵目标

标准 RL 目标

$$\max_\pi \mathbb{E}\left[\sum_{t=0}^{\infty} \gamma^t r_t\right]$$

只最大化累积奖励，策略可能收敛到确定性策略，缺乏探索。

最大熵 RL 目标

$$\max_\pi \mathbb{E}\left[\sum_{t=0}^{\infty} \gamma^t \bigl(r_t + \alpha \cdot \mathcal{H}(\pi(\cdot|s_t))\bigr)\right]$$

同时最大化奖励和策略熵，$\alpha$ 控制两者权衡。

策略熵的定义：

$$\mathcal{H}(\pi(\cdot|s)) = -\sum_a \pi(a|s)\log\pi(a|s) = \mathbb{E}_{a \sim \pi}[-\log\pi(a|s)]$$

最大熵框架的三大优势

  1. 更好的探索：熵正则化鼓励策略保持随机性，避免过早收敛到局部最优
  2. 鲁棒性：高熵策略对环境扰动和建模误差更鲁棒，因为它保留了多种行为模式
  3. 样本效率：在 off-policy 设置下，随机策略覆盖更广的状态-动作空间，经验回放利用率高

边界条件：$\alpha \to 0$ 时退化为标准 RL；$\alpha \to \infty$ 时策略趋向均匀分布（纯探索）。

14.2 软贝尔曼方程（完整推导）

最大熵框架引入了"软"版本的价值函数，需要重新推导贝尔曼方程。

软贝尔曼方程推导 · 4 步
1
定义软状态价值函数 $V^\pi$

在最大熵框架下，状态价值函数包含熵奖励：

$$V^\pi(s) = \mathbb{E}_{a \sim \pi}\bigl[Q^\pi(s,a) - \alpha\log\pi(a|s)\bigr]$$

等价地：$V^\pi(s) = \mathbb{E}_{a \sim \pi}[Q^\pi(s,a)] + \alpha\,\mathcal{H}(\pi(\cdot|s))$

即：状态价值 = 期望 Q 值 + $\alpha$ × 策略熵

2
定义软 Q 函数

软 Q 函数满足标准贝尔曼方程结构（但 $V^\pi$ 含熵）：

$$Q^\pi(s,a) = r(s,a) + \gamma\,\mathbb{E}_{s' \sim p}\bigl[V^\pi(s')\bigr]$$

3
将步骤 1 代入步骤 2

将 $V^\pi(s') = \mathbb{E}_{a' \sim \pi}[Q^\pi(s',a') - \alpha\log\pi(a'|s')]$ 代入：

$$Q^\pi(s,a) = r(s,a) + \gamma\,\mathbb{E}_{s'}\Bigl[\mathbb{E}_{a' \sim \pi}\bigl[Q^\pi(s',a') - \alpha\log\pi(a'|s')\bigr]\Bigr]$$

4
最终：软贝尔曼期望方程

$$\boxed{Q^\pi(s,a) = r(s,a) + \gamma\,\mathbb{E}_{s', a' \sim \pi}\bigl[Q^\pi(s',a') - \alpha\log\pi(a'|s')\bigr]}$$

物理含义：相比标准贝尔曼方程，每一步的"奖励"额外加入了 $-\alpha\log\pi(a'|s')$（即熵奖励），将熵正则化嵌入 Q 值定义中。

14.3 SAC 的三个网络

1 Actor（随机策略网络）$\pi_\theta(a|s)$

输出动作分布而非确定性动作。通常建模为对角高斯分布：

$$\pi_\theta(a|s) = \mathcal{N}\bigl(\mu_\theta(s),\, \text{diag}(\sigma_\theta^2(s))\bigr)$$

网络同时输出均值 $\mu_\theta(s)$ 和对数标准差 $\log\sigma_\theta(s)$，通过重参数化技巧采样（见 14.5 节）。

2 双 Critic：$Q_{\phi_1}(s,a)$ 和 $Q_{\phi_2}(s,a)$

SAC 维护两个独立的 Q 网络，计算 TD 目标时取最小值：

$$\tilde{Q}(s,a) = \min_{j=1,2} Q_{\phi_j}(s,a)$$

为什么取 min？ 单 Q 网络倾向于高估 Q 值（函数逼近误差 + 最大化偏差），取 min 是保守估计，抑制高估，来自 TD3 的技巧（Clipped Double Q-learning）。

3 目标网络（Target Networks）

为两个 Critic 各维护目标网络 $Q_{\phi_1^-}$、$Q_{\phi_2^-}$，同样使用软更新。

注：SAC 原始论文还有目标价值网络 $V_{\psi^-}(s)$，后续版本简化为只用目标 Q 网络。

14.4 SAC 完整更新公式

Critic 更新（软贝尔曼残差最小化）

首先计算 TD 目标（用目标网络和当前策略采样 $a'$）：

$$y = r + \gamma\Bigl(\min_{j=1,2} Q_{\phi_j^-}(s', a') - \alpha\log\pi_\theta(a'|s')\Bigr), \quad a' \sim \pi_\theta(\cdot|s')$$

对两个 Critic 分别最小化 MSE 损失：

$$\mathcal{L}(\phi_i) = \mathbb{E}_{(s,a,r,s') \sim \mathcal{D}}\Bigl[\bigl(Q_{\phi_i}(s,a) - y\bigr)^2\Bigr], \quad i = 1, 2$$

Actor 更新（最大化期望软值）

Actor 目标：最小化 KL 散度等价于最大化期望软 Q 值减去熵惩罚：

$$\mathcal{L}(\theta) = \mathbb{E}_{s \sim \mathcal{D},\, a \sim \pi_\theta(\cdot|s)}\Bigl[\alpha\log\pi_\theta(a|s) - \min_{j=1,2} Q_{\phi_j}(s,a)\Bigr]$$

使用重参数化技巧（见 14.5 节）使梯度可传播：$a = f_\theta(\varepsilon, s)$，$\varepsilon \sim \mathcal{N}(0, I)$。

温度 $\alpha$ 自动调整（可选但推荐）

将目标熵 $\bar{\mathcal{H}}$ 设为超参数（如 $\bar{\mathcal{H}} = -\dim(\mathcal{A})$），自动调整 $\alpha$：

$$\mathcal{L}(\alpha) = \mathbb{E}_{a \sim \pi_\theta}\bigl[-\alpha\log\pi_\theta(a|s) - \alpha\bar{\mathcal{H}}\bigr]$$

等价地：$\mathcal{L}(\alpha) = \mathbb{E}_{a \sim \pi_\theta}\bigl[\alpha(\mathcal{H}(\pi(\cdot|s)) - \bar{\mathcal{H}})\bigr]$

直觉：若当前熵 $> \bar{\mathcal{H}}$，增大 $\alpha$ 鼓励更多探索；若熵 $< \bar{\mathcal{H}}$，减小 $\alpha$ 让策略更确定。

14.5 重参数化技巧（Reparameterization Trick）

Actor 更新需要对采样动作 $a \sim \pi_\theta(\cdot|s)$ 求关于 $\theta$ 的梯度，但直接采样是不可微的（离散梯度问题）。

重参数化推导
1
问题：直接采样不可微

若 $a \sim \pi_\theta(\cdot|s)$，则 $\nabla_\theta \mathbb{E}_{a \sim \pi_\theta}[f(a)]$ 无法直接用反向传播计算（采样操作无梯度）。

2
重参数化：将随机性分离

将动作改写为确定性函数 + 独立噪声：

$$z = \mu_\theta(s) + \sigma_\theta(s) \cdot \varepsilon, \quad \varepsilon \sim \mathcal{N}(0, I)$$

$$a = \tanh(z) \in (-1, 1)^d$$

$\varepsilon$ 与 $\theta$ 无关，梯度可通过 $\mu_\theta$ 和 $\sigma_\theta$ 正常反向传播。

3
log 概率的变量替换公式

由于 $a = \tanh(z)$ 是非线性变换，需用变量替换定理修正 log 概率：

$$\log\pi_\theta(a|s) = \log\mathcal{N}(z;\, \mu_\theta(s),\, \sigma_\theta^2(s)) - \sum_{i=1}^{d}\log\bigl(1 - \tanh^2(z_i)\bigr)$$

其中第二项 $\log(1 - \tanh^2(z_i)) = \log\bigl|\frac{\partial a_i}{\partial z_i}\bigr|$ 是 Jacobian 修正项（对数行列式）。

利用恒等式 $1 - \tanh^2(z) = \text{sech}^2(z)$，可数值稳定地计算为：

$$-\sum_i \log(1 - a_i^2 + \epsilon)$$

4
最终梯度形式

$$\nabla_\theta \mathcal{L}(\theta) = \nabla_\theta \Bigl[\alpha\log\pi_\theta(f_\theta(\varepsilon, s)|s) - \min_{j=1,2} Q_{\phi_j}(s, f_\theta(\varepsilon, s))\Bigr]$$

其中 $f_\theta(\varepsilon, s) = \tanh(\mu_\theta(s) + \sigma_\theta(s)\cdot\varepsilon)$，$\varepsilon$ 在计算梯度时视为常数。

# SAC Actor 采样与 log 概率计算（关键部分）
def sample(self, state):
    mean, log_std = self.forward(state)
    std = log_std.exp()

    # 重参数化采样
    normal = Normal(mean, std)
    z = normal.rsample()          # rsample() 支持梯度传播
    action = torch.tanh(z)

    # log 概率（含 Jacobian 修正）
    log_prob = normal.log_prob(z)
    log_prob -= torch.log(1 - action.pow(2) + 1e-6)
    log_prob = log_prob.sum(dim=-1, keepdim=True)

    return action, log_prob

14.6 DDPG vs SAC 全面对比

维度 DDPG SAC
策略类型 确定性策略 $\mu_\theta(s)$ 随机策略 $\pi_\theta(a|s)$（高斯分布）
动作空间 连续（仅） 连续（主要）；离散版本也存在
探索方式 外部噪声（OU/高斯），需手动调整 内置随机性（熵正则化），自动探索
Critic 数量 1 个 Q 网络 2 个 Q 网络（取 min，抑制高估）
目标函数 最大化 $\mathbb{E}[\sum \gamma^t r_t]$ 最大化 $\mathbb{E}[\sum \gamma^t(r_t + \alpha\mathcal{H})]$
温度参数 无 $\alpha$（可自动调整）
训练稳定性 中等（对超参数敏感） 较高（熵正则化提供隐式正则）
样本效率 中等 高（off-policy + 随机策略）
超参数敏感性 高（学习率、噪声参数） 中（$\alpha$ 可自适应）
典型应用 早期连续控制基准 MuJoCo、机器人控制、工业控制

小结

DDPG 和 SAC 代表了连续动作空间深度强化学习的两个重要里程碑。DDPG 将深度学习与确定性策略梯度结合，奠定了 Actor-Critic 连续控制的基础范式；SAC 引入最大熵框架，通过熵正则化同时提升了探索能力和训练稳定性，成为当前最广泛使用的连续控制算法之一。

核心公式速查

算法 公式 说明
DPG $\nabla_\theta J = \mathbb{E}[\nabla_\theta\mu_\theta \cdot \nabla_a Q_\phi|_{a=\mu_\theta}]$ 确定性策略梯度定理
DDPG Critic $\mathcal{L}(\phi) = \mathbb{E}[(r + \gamma Q_{\phi^-}(s', \mu_{\theta^-}(s')) - Q_\phi(s,a))^2]$ TD 误差最小化
软更新 $\theta^- \leftarrow \tau\theta + (1-\tau)\theta^-$ $\tau \approx 0.005$
SAC 软贝尔曼 $Q^\pi(s,a) = r + \gamma\mathbb{E}_{s',a'}[Q^\pi(s',a') - \alpha\log\pi(a'|s')]$ 熵嵌入 Q 值
SAC Actor $\mathcal{L}(\theta) = \mathbb{E}[\alpha\log\pi_\theta(a|s) - \min_j Q_{\phi_j}(s,a)]$ 最大化软值
重参数化 $a = \tanh(\mu_\theta(s) + \sigma_\theta(s)\cdot\varepsilon)$，$\varepsilon \sim \mathcal{N}(0,I)$ 使梯度可传播
学习建议：理解 DDPG 的关键是 DPG 定理的链式法则推导；理解 SAC 的关键是最大熵目标如何自然导出软贝尔曼方程，以及重参数化技巧如何解决随机策略的梯度估计问题。两者都是 off-policy 算法，可高效利用经验回放。
